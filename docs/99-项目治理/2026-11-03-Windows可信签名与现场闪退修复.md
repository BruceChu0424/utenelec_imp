# Windows 可信签名与现场闪退修复

用户要求同时处理 Windows 发布者签名和闪退，员工不关闭智能应用控制、Defender 或其他系统防护。本任务使用独立分支 `uimp/windows-signing-crash-20261103`，起点 `c75d6e1e3480057f4bec1a930475b402129f5a90`，保留主工作树的并行改动。此任务不授权正式打包、上传、生产激活、购买证书或更改员工系统设置。

精确匹配的旧 Release DLL/PDB 将新 RVA 定位到 `AccessibilityBridge::CreateRemoveReparentedNodesUpdate()` 内联 `ui::AXNode::id`，即旧源码 `child->parent()->id()` 的父节点访问。它与此前 `HitTestSync / 0xF5D3`、`get_accValue / 0xF8B44C` 的入口不同。本次原生红绿用例证实空父节点条件会产生访问异常；事故 ZIP 没有 dump，不能据此声称已恢复事故时寄存器、完整调用栈或具体业务节点。

当前 2.5.44 重建引擎已包含同一公共树补丁中的父节点保护和事务预检；本任务不再复制另一套生产修法。新增 test-only 根重挂载回归，验证拒绝坏树后原树仍可读取、随后合法更新能够继续提交。关闭该父节点保护时新用例产生 SEH `0xc0000005`；恢复后通过。对应受审 Release 引擎 SHA-256 为 `1c47300271ef26e5ec62cb133811516041ce1d980d14b4aaa73700b0109e969a`。

本次只读核对还发现，现有 2.5.44 Setup、已安装主程序和引擎均未做 Authenticode 签名；当前机器的个人证书存储中没有可用的公共可信代码签名证书，未见已配置的托管签名身份。用户已明确答复公司尚未申请证书。

## 证书办理要求

申请**公共可信 Windows 代码签名证书**，不是网站 HTTPS 证书、公司内网 CA、Ed25519 发布摘要密钥或自签测试证书。公司自有主程序、更新器、重建引擎、安装器及卸载器须使用审核后的公司发布者身份；第三方运行库可保留有效且受信的原发布者签名。

向能够受理公司注册地区的 CA 确认组织代码签名申请。常见准备材料包括：

1. 营业执照、法定公司全称及注册标识、注册地址、可核验的公司联系方式。
2. 公司网站、受公司控制且能收外部验证邮件的邮箱、授权申请联系人和审核所需的授权证明；具体项目以 CA 审核要求为准。
3. 受支持的 USB 硬件令牌或受控 HSM/云签名服务，以及正式构建机的密钥访问权限。私钥由硬件保护，限制能签名的人员和流水线；不把 PFX、令牌 PIN 或服务密钥写入仓库、聊天和构建日志。
4. 明确 Windows Authenticode、代码签名 EKU、SHA-256 文件摘要、RFC 3161 可信时间戳和目标系统兼容性。保留到期、轮换、撤销及访问审计流程。
5. 办好后提供公开证书/证书链及 SHA-256 指纹、硬件令牌或服务的配置位置；公开指纹用于发布者核验，私钥继续留在受控签名设备。

OV 和 EV 都需满足发行机构相应审核要求，不以购买 EV 承诺所有新文件都不会出现 SmartScreen 信誉提示。最终验收是在保持系统防护开启的目标 Windows 上完成安装、启动、卸载和应用内更新。

微软 Artifact Signing 的 Public Trust 组织注册地列表当前不含中国大陆。若使用中国大陆注册公司，不预设可开通此方案；先由提供方确认资格。Private Trust 不能代替面向员工默认 Windows 信任环境的公共可信签名。

## 本次低成本采购选择与自动换证边界

用户随后要求优先最低价或免费，并明确选择**保留现有 Setup/ZIP，采用最低价付费签名**。不因此改走 Microsoft Store，不擅自给公开仓库添加开源许可，也不采购此前讨论的 EV 套餐。

当前选定低价方向为 **Certum 企业 OV 云端代码签名（SimplySign），先按一年期申请**。SSLmentor 产品及公开订单页面的一年报价为 **US$177**；两年总价 US$264，三年总价 US$348，US$116 是三年方案的年均价，不是一年订单价。报价包含云端密钥服务，不需另购 USB Token，SimplySign 手机和桌面应用免费；每月上限 5,000 次签名，按文件签名计，不是按发布次数计。此处是 2026-11-03 的经销商公开报价，不承诺全网最低或未来续费同价。

供应商规则称非 EEA 企业提供 Company ID 后不加收其 VAT；中国本地税务及汇率、付款手续费另行核算。订单应按真实中国企业主体填写，并在付款前核实最终金额、拒签退款条款及 Certum 签发渠道。已确认卖方法定主体 Web security s.r.o.、捷克 ID 06927351 的公开登记与网站一致，但未找到 Certum 官方公开名册点名该经销商，不能把其自有合作伙伴标识写成已独立确认的授权证明。本次没有提交订单、付款、创建账号或开通自动续费。

初次申请仍需真实营业执照/组织登记、公司全称及注册地址、管理邮箱和授权管理员；管理员本人在 CA 指定页面完成证件/人脸等核验，非法定代表人按要求提交授权书。证件、人脸和 SimplySign 激活二维码不进入 Git、聊天或构建日志。Certum 官方组织核验来源包含中国登记信息，但个案仍由 CA 审核。

“有时限就自动获取最新”必须区分：

1. **已经签发的新证书**：Certum 文档说明会自动安装到 SimplySign 账户；在已授权签名会话内可批量签名。
2. **续费和 CA 续证**：官方流程仍要求 Renewal、确认付款、组织/授权人核验、生成新密钥并激活。多年产品也需要在单张证书有效期内重新签发；服务期内重签免费不等于无需核验。
3. **能够接入的自动化**：初次出证及身份基线确定后，自动检查到期、发现已签发新证、验证可信链/公司身份/签名权限并生成轮换候选；不能仅因证书日期最新就自动扩大发布者信任。现有叶指纹约束及新旧身份恢复合同继续保留。
4. **仍需负责人配合**：SimplySign 手机授权、付款和 CA 要求的身份复核。未发现普通零售账户公开的无人值守自动续证接口，不能承诺永久免费或零人工循环换证。当前尚无已签发公司证书，因此没有伪造到期日、启用实际自动续费或宣称已完成自动取证。
