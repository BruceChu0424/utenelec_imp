# 成本页布局与公共表格对齐

日期：2026-09-30。用户要求成本页的表格上移、置顶后表内滚动、按钮位置等完整对齐其他页面，并追问采用单价的编辑差异及“本批成本”的含义。

## 采用的现有范式

| 对照来源 | 本次采用的能力 |
|---|---|
| 货品组装信息 goods_bom_tab | 表格工具栏、选择摘要、右下悬浮动作、全屏内业务操作 |
| 采购/销售单据详情和 MasterDataTableView | 折叠头部、表格吸顶后内滚、表尾汇总、行菜单及数值右对齐 |
| 采购编辑、生产日报编辑 | 右下保存动作、公共悬浮组、底部安全区、编辑表吸顶 |
| UtenTableColumnKit / 平台表格 | 列固定、移动、拖宽、显隐与个人布局；不增加另一套行排序 |

成本页原本使用固定比例头部滚动区、表格独立 Expanded 与居中固定底栏，导致上方信息不能随整页收起，按钮和全屏入口也与其他页面不一致。现改为公共滚动容器和工具栏槽位，公共组件负责滚轮交接，不在成本页增加滚轮缩放或手工补偿。

工具栏使用当前源码 `UtenTableToolbar.controlHeight`，悬浮保存使用公共大号/主动作样式和安全区。历史文档中某些数值或旧按钮位置落后于当前组件，因此本次按现有真实对照页和 token 实现，不硬编码历史高度。

合计归入 `UtenTotalsSummaryBar` 表尾，移除重复顶部卡片与独立居中底栏。物料、费用、实际及历史视图分别使用现成 MasterDataTableView 或 UtenEditableGrid 的对应滚动、工具栏、菜单及全屏能力；保持原业务数据、计算层级及权限。

## 单价与金额名称

可编辑草稿中的普通计价物料，采用单价统一直接在单元格修改。已有可靠来源的价格自动预填并标来源，真实改值后才改为手工调整；聚焦和移动光标不改变来源。缺价在同一格填写。自制汇总、客供合同及已确认/历史/无编辑权状态保留只读，并说明原因。

行内原“调整”明确为“调整用量”；“本批成本/本批金额”改为“测算金额”。成品表头 input.batchQty 是测算数量，物料 CostLine.batchQty 是计价用量，二者不共用一个含糊标签。普通计价物料的测算金额为材料金额加本行费用；每成品单位成本显示为“每件/每套成本”等。自制汇总行仍是下层汇总，不能编辑成采购单价。

下载标签与页面同步，使用快照里的成品单位，不读取当前主档猜单位。本次 Java 仅调整 GoodsCostDocumentMapper 展示标签，未改公式、DTO、取价、真实产量、权限或迁移。
