# 添加列与金额计算

源码：`lib/shared/business_columns/`、`lib/shared/platform_tables/platform_table_picker.dart`、`lib/shared/widgets/column_editor_dialog.dart`。对应 ADR-136、ADR-137。

## 入口与适用业务

所有普通业务表格使用 MasterDataTableView、UtenEditableGrid 或 UtenRevisionTable 的共同展示与布局能力。公共表格的 `columnEditingEnabled` 默认关闭，只有新建、允许修改的草稿录入宿主或有对应编辑权限的基础资料维护列表显式开启后，才提供定义、复用扩展列和编辑扩展值的能力；同时仍须满足记录类型、单据状态和当前权限，加载中、保存中或已创建单据的继续处理阶段不能继续编辑列。不能仅凭使用了可编辑表格或表头叫“金额”“数量”就开放回写。

审核、详情、修订对照、清单、报表和选择器只提供当前表已有隐藏列的恢复以及显隐、顺序、宽度等个人布局调整。它们不提供新建列、从目录复用外部列或修改扩展值的入口；已有业务快照和个人辅助列继续展示，已有辅助公式继续按获准读取的原始值计算。页面门禁同时作用于按钮、弹窗提交和控制器写入，不靠单独隐藏按钮拦截。财务核价、质检、点收等固定业务字段原有操作继续由各自业务权限与状态控制。

| 场景 | 新增列用途 | 正式数据处理 |
| --- | --- | --- |
| 有对应编辑权限的基础资料维护列表 | 表头最右侧「添加列」，补充文字、数字或辅助计算 | 沿用对应主档与对象级写权限；仅查看或新增资料权限不能添加列，权限撤销后已打开的编辑器同步失效 |
| 销售报价、销售订单、采购订单、委外订单的新建/草稿明细录入 | 单据附加项；文字、数字或参与正式金额 | 服务端按列定义和输入值计算行金额，保存不可变商业快照，财审和后续履约沿用 |
| 采购/委外收退货、销售出退货等来源单据的新建/草稿录入 | 补充信息或辅助计算 | 核定费用随来源金额分摊，不能每收一次货再加一次固定费用 |
| 其它显式开放列编辑的新建/草稿录入表 | 文字、数字、计算展示 | 扩展值随真实记录与版本保存；不改写原生数量、库存、工资和已过账金额 |
| 审核、详情、修订对照、清单、报表、台账、历史和只读汇总 | 不新增列；保留已有列展示与布局调整 | 读取业务快照及获准使用的原始数值，不修改扩展值；没有可写记录身份时不提供虚假的编辑能力 |

已有即时库存辅助公式可读取在库、待处理、待入库和超收数量，但即时库存页面不开放新建或复用外部列。已有账户流水辅助公式读取收入、支出与余额的精确金额文本，并要求账户查看、余额查看和流水查看权限；货品价格权限不能代替账户权限。

应用级 `platform_table_display_facts.dart` 为 50 种公共模型补充明确的数值映射；页面私有模型和外置列构造器通过 `exactValueOf` / `exactListenableOf` 提供原始值与变化监听，覆盖质检、生产进度、库存分析、领出料、往来、资产、核价与结算。公式的可选项须同时满足页面实际列、数值来源和服务端白名单三项，不能仅因服务端登记了字段就虚构值。

往来、资产、供应商结算、委外超耗、采购核价、销售报价/订单核价及 IQC 拒收金额沿各自业务查询权限开放；对账、车间用料成本及库存健康金额增加只读 Exact 文本字段。旧接口缺少精确字段时不从 double 反造公式金额，原页面展示仍兼容。

重量公式统一使用千克，输入 850g 对应 0.85kg，切换展示单位不改变计算值；尚未实称或仅有学习估算时保留空值。混合货品/单位汇总不冒充可计算的单一数量。本次领料量引用当前控制器，不能误用待申请量。损耗率按百分数约定（10 表示 10%），BOM 缺陷比率注明 1 表示 100%。机器容器动态名称列仍保留展示；缺少稳定字段身份时不以易变列序号建立公式引用。

## 商业列弹窗

已开放列编辑的录入页中，“单据附加项”分为选择已有列、新建列、本单已添加三种操作。已有定义按编号复用，同名不同运算仍是不同列。审核与详情继续展示保存的附加项，不开放此编辑弹窗。

新建时先填写名称，再选择文字、数字或参与正式金额。只有选择参与正式金额后，才显示计算目标“本行金额”、加减乘除以及可修改的试算示例。示例不会作为默认值复制到各行。

各行实际输入值在表格中填写。加减是每行一次的固定金额，乘除是倍率；乘 0.9 表示按 90% 计算。按件费用须先明确换算，不能把固定行费用自动当作每件费用。多个费用按添加顺序计算，拖动表头只改显示顺序。

例如原金额 100，附加费填 20 后为 120，改填 30 后为 130，清空后恢复 100。用户手工填写总金额、通过总金额反算单价或数量时，修改附加项仍保留原基础金额并正向重算总金额；只有主动重新输入总金额才重新确定基础金额。该基数随本地草稿保存恢复。

空值不参与，0 是实际值；拒绝无效数字、除零、不能精确表示的除法和负最终金额。数字最多 120 个输入字符，文字最多 2000 字符；无效原文保留供用户修正，不截成另一个有效数字，也不静默置零。单格提示与保存校验使用一致规则。

“本单已添加”可查看各列的作用并明确移除。移除动作展示影响说明，确认后清除本单各行的这一列、重新计算金额，保存单据后持久生效；不删除公共目录定义，不影响其他单据。不具价格权限的用户不能创建、修改或移除费用列。有值的费用列继续保持可见。

弹窗打开期间单据刷新或行集合被替换时，选择结果应用于当前行集，避免访问已释放的旧行控制器。

弹窗打开期间若页面进入不可编辑状态，创建、复用和移除动作必须重新检查动态门禁；已经发出的目录创建请求即使随后返回，也不能把迟到结果写回本单。应用弹窗结果前再次检查门禁，不能因为改用当前行集就绕过页面状态限制。

## 通用扩展列弹窗

已开放列编辑的录入页分别展示搜索已有列与新建列。只读页面的列选择器仅列出当前表已有的隐藏列，不查询可复用外部列或提供新建表单。新建时按“名称 → 用途 → 公式”逐步展开；文字与数字记录不展示公式表单。公式由一个基础数值和有序运算步骤构成，每步可选择常数或已有数字列。切换引用来源后隐藏常数输入，并提供带括号的公式预览说明运算顺序。

名称、缺失引用、无效数字和除零在对应字段提示。权限撤销后旧数值来源失效，不能继续提交。读取失败可以重试，保存失败保留输入。保存期间禁止再次提交和关闭弹窗，避免误以为未保存而重复创建。

商业目录与通用目录都随账号、操作身份和权限变化重新鉴权；旧请求的迟到失败不能解除新请求的保存状态。失去金额权限时保留已选规则并禁用提交，不悄悄降级成普通数字记录。单据达到 32 个商业列时在创建公共目录定义之前拦截，可先在“本单已添加”移除不需要的列。

商业与通用弹窗共用主题、圆角、间距和布局外壳。内容单独滚动、操作区保持可达，适配键盘、窄屏、放大文字与深浅主题；长内容不把操作按钮挤出可视区域。

## 导出身份

费用列以定义 UUID 作为身份，标题只用于展示与旧模板匹配。同名加项和减项必须分别保留；名称恰好是“金额”或“数量”的费用列不能覆盖或隐藏系统列。当前投影仍决定导出哪些列，默认导出也必须保留所有实际费用列。
