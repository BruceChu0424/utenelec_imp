## 业务到实现

BOM 设计使用数量与真实使用数量见 [ADR-129](99-决策记录-ADR/ADR-129-BOM设计使用数量与真实使用数量.md)：BOM「数量」改名设计使用数量，所有本厂生产父件按核清实物净耗 / 用到该料的族产量学出真实使用数量，经唯一视图 `v_goods_bom_item_usage` 供物料分析、车间领料和 MRP 计算；分析快照锁定用量、守卫只比结构，拆批按冻结曲线，最后一次报工按实物清点退料，学习边按边所有权并可重新学习，超产比例按结构默认且只记人确认的值。入口见[基础资料·组装信息](03-页面/基础资料页.md)、[物料分析](03-页面/生产物料分析页.md)、[生产执行分段与报工](03-页面/生产执行分段与报工页.md)；本地验证与未部署边界见[收尾记录](99-项目治理/2026-09-27-BOM设计与真实使用数量验收.md)。

底层自制领料与 BOM 学习见 [ADR-119](99-决策记录-ADR/ADR-119-底层自制实际领料与BOM累计学习.md)：车间表格选填材料、仓库补全或与普通领料单原子批量出库、LQ 申请与真实 SL 单据追溯、真实出退料后累计单耗，以及分层超产默认与记忆 (学习口径、学习边所有权与超产默认/记忆已由 ADR-129 修订)。入口和交互见[我的车间任务](03-页面/我的车间任务页.md)、[生产领料任务中心](03-页面/生产领料任务中心页.md)，各轮通过及全量未完成的边界见[本轮收尾记录](99-项目治理/2026-09-26-领料申请批量出库与编号收尾.md)。部署状态独立于源码与本地验证。

物料准备与车间、采购、委外三个入口的现行操作、数量、追加及刷新规则见[页面说明](03-页面/生产物料分析页.md)，统一办理和实际合单分别见 [ADR-102](99-决策记录-ADR/ADR-102-物料分析一张表直接下单.md)、[ADR-120](99-决策记录-ADR/ADR-120-物料汇总办理与共享制造来源.md)。新合单保留原来源，已有单据不自动搬单。2026-09-26 本轮业务修复已收尾，极大混合单性能仍未全部通过；测试批次、实测边界及尚未部署的事实统一见[专项记录](99-项目治理/2026-09-26-物料准备统一流程修复.md)，后续工作使用[更新后的整改任务书](99-项目治理/全平台整改交接/03-后续工作流任务书.md)。[此前三产品诊断](99-项目治理/2026-09-25-物料汇总只读诊断.md)只记录当时现场；源码迁移头以[迁移目录](数据迁移/README.md)为准，不能代替安装事实。
