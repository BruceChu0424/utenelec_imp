# 财务筛选与资产台账界面整改

## 范围与设计

使用 `frontend-design`，沿用 Uten 的 Noto Sans SC 字体、正文层级与品牌 token。基础色为 background #F5F7FA、surface #FFFFFF、正文 #0F172A、次级正文 #475569、outline #E2E8F0、交互 teal #0F766E；实际实现引用主题角色以适配暗色。

台账是主工作区域：分类之后紧跟 180 宽搜索，其他业务条件按内容换行。日期常驻区只展示一个范围入口，通过最近一月、本月、上月及自定义处理查询。自定义在本地暂存，应用后才改参数，取消不请求；应付保留单边起止和清除能力。

设计复核删去四类冗余：装饰性分组标题、旧侧栏纵向筛选、重复新建入口、向业务用户暴露实现细节的说明。保留实际余额、期间、权限与动作限制；不同限制原因不得混同。

```text
页面标题 / 返回 / 刷新
[业务分类][短搜索]           [日期范围 / 业务条件]
[真实业务汇总，如适用]
表头工具 / 表格 / 分页                      [唯一主操作]
```

资产例外：汇总及安全限制在分类前；台账筛选使用表格稳定槽，避免请求状态切换中断输入法。窄屏的状态/类别/部门收进“筛选”对话框并暂存确认，避免多行工具条再次遮住表头。限制摘要分别呈现会计政策与核心落账状态，详细说明按需展开。

## 覆盖记录

| 页面 / 工作区 | 处理 |
|---|---|
| 资产与待摊：固定资产、长期待摊、月末、政策草稿 | 重排汇总/限制/分类，两个台账改横向筛选，消除截断和重复新建，保留工作流 |
| 应付结算：应付台账、委外超耗责任、月结批次 | 分类右侧短搜索，日期范围入口与清除，保留付款和权限规则 |
| 财务明细/汇总、客户预收、对账、成本、总账报表 | 共用 FinanceReportTablePage，分类右侧短搜索，单范围日期入口 |
| 账户流水报表、往来对账、应收应付台账、往来总览、旧账户对账入口 | 横向筛选，保留原默认日期、查询与表头语义 |
| 业务审核中心、采购审批、报价核价、销售订货确认、出货审核 | 源码核对，已有 UtenFilterToolbar 默认短搜索，保持既有业务视图 |
| 收款/付款/费用/收入/银行存取款列表 | 共用生命周期分类与短搜索，既有单一悬浮操作，源码核对 |
| 车间内料仓用量（财务入口） | 删除蓝色说明；期间与五类报表按内料仓开通记录识别仓库，保留车间范围校验 |

表单与审批详情内的业务必要字段、校验、权限和数量规则保持原契约；此次覆盖不等于每个账号的全量实机 UAT。
