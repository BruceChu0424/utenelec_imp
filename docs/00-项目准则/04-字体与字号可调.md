# 字体与字号可调规范

> 当前实现：用户字号档 = **整体缩放**（`UtenDisplayZoomBox`，文字/图标/卡片/间距一起变），叠在宽屏自动放大之上；系统文字缩放仍走 `MediaQuery.textScaler`；手机只放大文字。**2026-09-24 起档位按屏幕容量动态提供**（放得下才出现，默认「自动」），大字号时页面留白与导航不跟着放大（§一.1、§一.2）。最后核对：2026-09-24。

## 一、当前实现

| 职责 | 源码 |
|---|---|
| 字号档与持久化 | [`font_scale_provider.dart`](../../lib/shared/providers/font_scale_provider.dart) |
| 设置 UI | [`uten_font_scaler.dart`](../../lib/components/settings/uten_font_scaler.dart) |
| 整体缩放（倍率拆分 + 容器 + `UtenDisplayScale` 发布） | [`display_zoom.dart`](../../lib/core/responsive/display_zoom.dart) |
| 屏幕容量（档位上限、自动档推荐） | [`display_capacity.dart`](../../lib/core/responsive/display_capacity.dart) |
| 全局注入 | [`app.dart`](../../lib/app.dart) |
| 图标等比辅助（仅剩余文字缩放时） | [`scale.dart`](../../lib/core/responsive/scale.dart) |
| type scale | [`light_theme.dart`](../../lib/core/theme/light_theme.dart)、[`dark_theme.dart`](../../lib/core/theme/dark_theme.dart) |

`FontScale` 有八档，另有「自动」（默认）。设置页**只列出当前窗口放得下的档**（§一.1）：

| 档位 | 标签 | 因子 | 何时出现 |
|---|---|---|---|
| xSmall | 更小 | 0.75 | 始终 |
| small | 小 | 0.85 | 始终 |
| medium | 标准 | 1.0 | 始终 |
| large | 大 | 1.15 | 1080p@100%、1080p@125%、2K 等 |
| xLarge | 超大 | 1.3 | 1080p@100%、2K、4K |
| xxLarge | 特大（原「超超大」） | 1.5 | 1080p@100%、2K、4K |
| huge | 巨大 | 1.75 | 5K 及以上 @100% |
| giant | 极大 | 2.0 | 5K 及以上 @100% |

偏好保存到 `SharedPreferences` 的 `fontScale`（`auto` 或档位键；老版本存的五个键照常恢复；从未设置过 = 自动）。

**2026-09-20 起因子的生效方式（`UtenDisplayZoom.resolve`）**：

- 窗口宽 ≥ 600：因子作为**整体缩放倍率**（`Transform.scale` + `MediaQuery` 换算，见
  [02 §3.3.1](02-响应式与多端适配.md)），与宽屏自动放大（窗口宽 / 1920，≤1920 为 1）相乘；
  文字、图标、内边距、卡片尺寸一起放大缩小，画布相应变窄——1920 宽 + 超超大 1.5 =
  按 1280 宽画布布局再放大 1.5 倍，不会出现「文字大了容器放不下」；
- 整体缩放不把画布压到 600 以下（进入手机布局），不够的倍率由 `textScaler` 补足，
  总放大倍数恒等于因子；
- 手机（窗口宽 < 600）沿用只放大文字（画布本就窄）；
- 系统无障碍文字缩放（设备 `MediaQuery.textScaler`）原样保留，叠在上述结果之上。

### 一.1 按屏幕容量决定档位（2026-09-24 起）

用户反馈：系统缩放/系统字号开得大的机器（1080p 笔记本 150%，逻辑宽只剩 1280），再选
「超超大」画布只剩 853×440，一屏只看得到几行；大屏其实还放得下更大的档。于是档位参照
Windows「缩放」下拉框：**每台机器选项数不同，放得下才出现**。规则
（`UtenDisplayCapacity`，全部是逻辑像素，已含系统缩放与浏览器缩放）：

- **上限** `maxFontFactor`：整体缩放后的画布不小于 **1200×620**（再小表格只剩两三列、
  筛选栏折行、一屏不到十行）。宽屏自动放大之上照算——所以 2K/4K 大屏同一档的字比
  1080p 更大。系统无障碍文字放大原样保留，但占用同一份预算（系统已放大 1.25，
  应用档上限就除以 1.25）。标准档与缩小档永远可用。手机（< 600 宽）只放大文字，
  应用档 × 系统文字 ≤ 1.5。
- **手动档超上限**（窗口临时变小、分屏、换到小显示器）：按上限生效，窗口恢复后自动回到所选；
  偏好本身不改写。设置页保留该档选中并提示「暂按 xx% 显示」。
- **自动档**（默认）`recommendedFontFactor`：标准档画布够 **1360×700** 就用标准；不够
  （系统缩放把工作区压小）就往下找小一档，直到够为止，但**物理尺寸（因子 × 设备像素比）
  不低于 100% 基准**——只收回被系统放大的那部分，不会比一台 100% 缩放的普通屏更小。

常见机器（窗口约为屏幕减去任务栏/标题栏）：

| 机器 | 逻辑窗口 | 可选到 | 自动 |
|---|---|---|---|
| 1366×768 @100% | 1366×690 | 标准 | 100% |
| 1920×1080 @100% | 1920×1000 | 特大 150% | 100% |
| 1920×1080 @125% | 1536×816 | 大 115% | 100% |
| 1920×1080 @150% | 1280×672 | 标准 | **85%**（画布回到 1506 宽，物理仍 128%） |
| 1920×1080 @175% | 1097×580 | 标准 | **75%**（物理仍 131%） |
| 2560×1440 @100% / 4K @150% | 2560×1360 | 特大 150% | 100% |
| 3440×1440 带鱼屏 | 3440×1400 | 大 115%（高度先到顶） | 100% |
| 5K @100% | 5120×2780 | 极大 200% | 100% |

### 一.2 大字号时的展示方式（2026-09-24 起）

原则：**字放大，留白和导航不跟着放大**，把宽度让给内容。子树经
`UtenDisplayScale.fontZoomOf(context)` 读字号档带来的放大倍率（不含宽屏自动放大；手机为 1）：

- **页面左右留白**：`UtenContentContainer.gutterForWidth(width, fontZoom:)` 按倍率反向收
  （最小 12），窗口上看留白基本不变。1920 + 特大：每层容器每侧 48 → 31.5 窗口像素，
  外壳与页面两层容器合计每侧省约 33。
- **左侧导航**：`UtenSideNavRail.extendedFor` 在画布够宽之外再按窗口口径判一次：
  1920 窗口标准/大展开，超大起收成图标栏（Tooltip 补文字），省出约 200 窗口像素。
- **断点照常生效**：大字号画布变窄，表格、卡片网格、筛选栏按画布宽自动换成更紧凑的布局
  （列数减少、筛选折叠），这是整体缩放的既有行为。
- 新组件里「不该随字号放大」的尺寸（外层留白、装饰性空白）同样除以 `fontZoom`；
  文字、图标、点击目标、表格行高不除（它们正是用户要放大的东西）。

老口径（2026-08-04～09-19）是把因子只乘进 `MediaQuery.textScaler`，文字大了容器不跟，
表格列宽/固定宽卡片一放大就截断——`_measureText` 传 `textScaler`、固定宽改 `minWidth`
那些修补现在只在手机/系统缩放路径上仍有意义，桌面走整体缩放天然不溢出。

## 二、字体资产

- UI 字体族：`NotoSansSC`。
- `assets/fonts/NotoSansSC.ttf`（4,092,516 B）是主 UI 字体，包含既有子集及本轮数据库审计发现的
  7 个额外缺字；`assets/fonts/Roboto-Regular.ttf`（515,100 B）提供独立西文字形。
- `assets/fonts/NotoSansSCFull.ttf`（17,772,300 B）仅打印/PDF 时按需加载，不进入 Web 首屏。
- Web 镜像 Flutter 3.44.2 engine 的全部 724 个 Noto fallback WOFF2（144 family，
  共 21,739,792 B）到 `web/fallback_fonts/`，由 `fontFallbackBaseUrl` 指向同源并按缺字懒加载；
  PWA service worker 不预缓存这些分片。这样优先保证严格 CSP、离线可控和历史/未来罕见字完整性，
  同时避免把完整打印字体塞入首屏。
- `.github/scripts/verify-font-assets.ps1` 在 CI 构建前校验 Flutter 版本、5 个本地字体/许可和
  724 个 fallback 分片，共 729 个资产的文件大小与 SHA-256；manifest 不得包含本机绝对路径。
- 本轮对 161 张表、719 个文本列、9,245,430 个非空值、86,674,055 个字符做字形覆盖审计，
  当前库缺字为 0。后续每次全量迁移都必须重跑 glyph coverage gate，不能把当前快照当永久保证。
- Noto 与 Roboto 许可证随仓库保留；替换、升级 Flutter 或再子集化时必须同步许可、manifest、
  SHA-256 和中文/符号缺字检查。

## 三、页面用法

使用 Material type role：

```dart
final text = Theme.of(context).textTheme;

Text('页面标题', style: text.headlineSmall);
Text('正文', style: text.bodyMedium);
Text('辅助信息', style: text.bodySmall);
```

不要在页面重新乘 `FontScale.factor`；全局 `textScaler` 已经生效。只有确需与文字同步的图标或
紧邻固定尺寸，才使用：

```dart
Icon(Icons.info_outline, size: context.scaled(20));
```

布局间距通常保持 token 值，不应随字号无上限放大。文字变大时优先允许换行和容器增高。

### 3.1 fontSize 硬编码的收敛与豁免（2026-08-16 口径）

业务/组件代码里**禁止新建 `TextStyle(fontSize: 数字)`**；存量已全部收敛到
`theme.textTheme.<role>`（尺寸对号入座：48/36/28=display 三档、24/20/18=headline
三档、16/15=titleLarge/bodyLarge、14=bodyMedium|titleMedium|labelLarge（按字重）、
13=bodySmall|titleSmall、12=labelMedium、11=labelSmall）。微字号（10）用既有惯例
`labelSmall?.copyWith(fontSize: 10)`；其余字段（字重/颜色/行高/字距）一律 `copyWith`。

豁免清单（保留固定数值，不视为债）：

- **打印/PDF/纸面复刻**：`pw.TextStyle`（pdf 包）与 A4 纸面预览（固定磅值对齐纸面）；
- **图形绑定注字**：环形进度图中心百分比、头像首字（size×比例）、size 参数化的小徽章
  （如 UtenNotificationBadge、待排产逾期徽标）——尺寸跟图形走，不跟文字层级走；
- **组件尺寸变体体系**：UtenButton/ClickGuard 等 sm/md/lg 档位自带的字号阶梯
  （与 iconSize/padding/最小高联动，属组件设计 token，非文字层级）；
- 定义层 `core/theme/` 两个主题文件本身是磅值来源，合法。

## 四、禁忌

- 禁止用固定高度裁剪可变字号文字。
- 禁止页面写第二套字号倍率或覆盖 `MediaQuery` 为固定 1.0。
- 禁止把正文转成图片。
- 禁止只用颜色/字号表达状态，仍需文本或语义。
- 禁止为“对齐”关闭系统字体缩放。
- 禁止在整体缩放之下混用窗口坐标与画布坐标：`localToGlobal()` 不带 `ancestor`、手势
  `globalPosition` 是窗口坐标，Overlay 里 `Positioned` 是画布坐标（偏倍率倍）；定位浮层走
  `LayerLink` / `localToGlobal(ancestor:)` / `overlayBox.globalToLocal`。
- 禁止 `ReorderableListView`（SDK 拖影混用坐标），拖手柄换位用 `UtenDragReorderList`。

## 五、验收

- [ ] 自动与各档即时生效并可重启恢复；老版本存的五个档位键照常恢复。
- [ ] 设置页只列出当前窗口放得下的档（§一.1 常见机器表），隐藏档数与最大可用档有说明；
      手动档超上限时按上限生效并提示，窗口恢复后自动回到所选。
- [ ] 系统缩放 150%/175% 的 1080p 笔记本在自动档下画布 ≥ 1360 宽。
- [ ] 超大档起左侧导航收成图标栏，页面左右留白不随字号放大。
- [ ] 桌面（≥600 宽）切档时工作台卡片、图标、间距与文字同步放大缩小；手机只放大文字。
- [ ] 2560 宽窗口（2K@100% / 4K@150%）标准字号下，外壳与工作台观感与 1920 一致、两侧无大留白。
- [ ] 整体缩放 ≠ 1 时右键菜单、下拉浮层、表头设置列排序拖影、工作台分区拖影位置正确。
- [ ] 系统字体放大与应用档位叠加后，关键页面无溢出、遮挡或不可滚动字段。
- [ ] 按钮、Tab、表格、对话框、Toast、空状态和打印预览均检查。
- [ ] 图标与文字不会严重失衡，点击目标仍至少约 44 logical pixels。
- [ ] 中文、英文、数字、长姓名和金额边界通过视觉回归。
- [ ] Web 首屏只解析主 UI Noto + Roboto，不加载完整打印字体；fallback 同源按需加载且无远程请求。
- [ ] 字体供应链脚本验证 729 个版本钉死资产，数据库 glyph coverage gate 为 0 缺字。
- [ ] 打印中文不缺字，升级 Flutter 后重新镜像并校验对应 engine fallback 集。
