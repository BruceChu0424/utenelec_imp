# 官网询盘页（综合营销统一收件箱）

> 状态：✅ 已实现（源码候选；目标库迁移与岗位 UAT 未完成）。
> 官网留言统一收件箱：列表 + 详情跟进（开始跟进 / 关闭 / 一键转客户）。
> **Owner**：综合营销部 | **创建日期**：2026-09-04（补档，页面此前无文档）

## 一、页面与权限

- 路由：`/webinquiry`（列表）、`/webinquiry/:id`（详情）。
- **进入权限**：`webinquiry:view` (有效权限收口，非全员基础包；与工作台入口及路由一致)。
- **动作权限**（详情页按钮按权限显隐，服务端 `@PreAuthorize` 兜底）：
  - 开始跟进：`webinquiry:claim`
  - 关闭：`webinquiry:close`
  - 一键转客户：`webinquiry:convert_client`
- 页面权限面：`website.inquiry` (`page_permission_scope.dart`)。

## 二、页面结构

1. **列表页**（`website_inquiry_list_page.dart`）：返回/标题下方独立 `UtenFilterToolbar`，仅未处理、跟进中、历史单据三个分类，默认未处理；删除冗余全部进行中。历史保留已转客户和已关闭，分类切换回第 1 页；清除历史细筛仍留历史。下方为分页网格。
2. **详情页** (`website_inquiry_detail_page.dart`)：完整留言、来源信息、产品来源快照、跟进时间线与办理动作。
3. 来源保留网站 `sourceId`、页面、系列、每件产品独立 ID/名称/系列/来源标识和联系授权证据；多产品默认显示一件，可展开全部，不能按名称合并不同来源。
4. 跟进时间线使用后端事件，显示时间和人员姓名(工号)。只有本人已经认领、仍在跟进中且持有 `webinquiry:claim` 才显示新增跟进记录；后端再次核验归属，第二人不能覆盖已认领人。
5. 登录、服务器或权限变化使在途写回执失效；详情缓存随会话重建，旧身份的回执不能回填新身份。

## 三、后端与数据

- API：`/api/website-inquiries` (`lib/core/network/api_endpoints.dart`；
  server `features/webinquiry/WebsiteInquiryController`）。
- 汇入迁移与字段口径见 [../数据迁移/57-官网询盘汇入.md](../数据迁移/57-官网询盘汇入.md)。
- 详情扩展 `sourceContext` 与 `timeline`；`POST /{id}/follow-ups` 保存本人跟进记录；`GET /counts` 返回未认领/本人跟进/可办数量。网站先持久保存并可靠重试，IMP 入库后确认，界面不承诺断网期间即时汇入。
- “官网询盘”采用独立 `websiteInquiry` 徽标容器，避免与销售管理卡重复累加。官网内容维护见[官网管理页](官网管理页.md)。
