- UUID 非空时只按 UUID 匹配，不回落显示单号；UUID 为空时只匹配同为 NULL 的来源及归一化单号。保留行号归一化、同表自身排除、跨固定资产/待摊查重、软删除和已冲销过滤，以及原有跨两表的来源事务锁。

- 独立复核了资产查询、确认冲销、财务报表、总账及反审核动态 SQL：其表/列选择分别来自封闭种类、服务端列元数据、静态报表目录或受检标识符；未发现第二条外部 SQL 文本输入通路。没有将它们机械改写成同一种业务口径。
