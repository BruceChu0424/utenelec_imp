# 内联帮助提示

前端界面与设计文档默认使用 `frontend-design`。沿用 Uten 组件、主题 token 和权限/业务约束；纯说明使用既有 `UtenFieldHintIcon`，不新增第二套 Tooltip 实现。

## 放置方式

静态用途、口径、操作教学、规则解释与对应标题或字段同行。删除被替代的说明正文、说明卡及多余间距；不另建一行或一张卡只放提示图标。

| 场景 | 公共入口 |
|---|---|
| 页面标题 | `UtenAppBar(info: ...)`，包括自定义 `titleWidget` |
| 分组与分类标题 | `UtenSectionHeader(info: ...)` |
| 抽屉标题 | `UtenPanelHeader(info: ...)` |
| 模块入口卡 | `UtenHubCard(description: ...)`，说明自动收在名称旁 |
| 设置分组 | `SettingsSection(info: ...)` |
| 可展开设置项 | `SettingsItem(subtitle: ...)`，该参数承载帮助，显示在标题旁 |
| 摘要事实字段 | `UtenSummaryField(info: ...)`，保留原业务值 |
| 附件分组 | `AttachmentSection(info: ...)`，与上传格式提示合并 |
| 普通表单字段 | 沿用 `UtenInput.info`、`UtenInputDecoration.info` 等已有入口 |
| 表格列 | 沿用列头 `headerInfo`，避免同列每格重复提示 |
| 其他已有标签 | 标签与 `UtenFieldHintIcon(info: ..., dense: true)` 同放在有界 Row 中 |

提示支持鼠标悬停、点击、键盘聚焦和激活。保持完整原文与读屏语义；长内容在窄屏/放大字号下使用可滚动浮层，正文只应用一次字号缩放。图标的点击不能触发父级导航、切换开关或选择分类。

全局 `UtenTooltipNavigationHost` 只监听一次页面导航，离开页面时关闭包括保活标签页在内的旧提示，避免旧内容跨页遮挡。不要为每个单元格注册路由监听。

输入框内相邻的纯图标使用 `UtenFieldSuffixIcons`，提示图标采用 `compact: true` 的 28px 宽槽，业务图标采用 32px 宽槽；字段和原按钮高度保持原有规格。自定义纯图标选择器可显式使用 `UtenFieldSuffixIcon`；有文字、单位或未知业务内容的装饰不压缩，表格内零图标与字段聚合规则保持原有实现。

## 保留直接展示的信息

业务值、当前筛选范围、数量、任务进度、当前状态、真实错误、当前权限阻断、数据不完整/估算标记、未知提交结果继续直接显示。确认弹窗的操作影响、审核责任和不可逆后果保持可见。用户主动打开的帮助/指引内容无需再次藏到图标。

混合文案先拆开：当前事实保留，静态机制解释移至相应标签旁。不要仅因文字含“提示”或位于财务/安全模块就机械隐藏或保留。

## 检查范围

调整公共入口后同步核对所有适用页面、分类、标签页、抽屉与弹窗，并记录保留差异。验证标题与图标同一纵向中心、窄屏/大字号/深浅色、悬停/点击/键盘、完整原文、父操作不误触和调用方业务事实。源码盘点、Widget 回归、Web 构建与实际登录走查分别记录，不能互相代替。
