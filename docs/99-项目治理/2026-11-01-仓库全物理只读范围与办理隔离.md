## 权限目录与前提

V981 新增三个显式范围码：`warehouse_task:view:all`、`production_workshop_task:view:all`、`supplier_return_task:view:all`。均为 VIEW，`BULK_EXCLUDED + NON_DELEGABLE`，不是全员基础包，不自动授予既有部门、人员或模板；可由管理员明确授给部门或个人。部门继承不是个人追加的替代品，目录没有将它们设成逐人专属。

范围码不自动补原入口查看权限，不替代原单据归属、成本金额、附件、导出或智能查询资格。仓库范围覆盖进行中、已结束、物理历史及符合原入口资格的关联只读信息。V983 由 `permission-help.json` 全量生成 525 项说明；旧 V980 字节保持不变。五种资金单审核说明分别标明账户账面、核销、流水及总账的实际影响与时机，没有声称自动向银行转账。

合并任务中心对持新范围码的当前页行，用原物理关系与原车间关系一次批量核对完整 rowKey。新可读的外仓行变为 `HISTORY_DETAIL`；不保留 `canHandle`、`canApprove/canEdit`、提前入库、撤回或允许出库目标等写提示。没有按行反查制造 N+1，也没有在分页后丢弃不可办理行来伪造浏览数量。

选择器接口仅在 `forRead=true` 显式模式返回扩大的 `selectable`。同时返回原职责的 `commandSelectable`，并保留真实 `role/warehouseParticipant/keeperWarehouses`。Web 与 Flutter 共用该 DTO 和原 Uten 选择器；他仓选择不会作为徽章范围向原 badge 接口发送。默认旧 metadata 模式和原命令选仓行为保留。

## 原业务合同不能被范围码改写

原到货登记专用流程允许有资格的人顶班跨仓登记。`WarehouseDataScopeEndToEndTest.crossWarehouseRegistrationRetainsBusinessOwnerAndActionPermissionOnReplay` 已有明确合同；登记仍校验 action、完整来源、原业务 owner 和 replay，不能将其改成仅 keeper 仓可写。

因此“任务中心外仓行 history-only”和“旧登记页中本来合法的跨仓顶班”是两个入口的既有区别。新范围码没有扩大任何旧命令的可办集合，也没有删除旧顶班通道。普通总经办只读方案不授予这些操作码。

旧 `/warehouse/material-discovery/:requestId` 是“配置领料”办理表单：现有 any/all 路由合同要求 `stock_doc:issue` 与 `stock_doc:approve`；它的 member gate、detail 输入读取、confirm/batch 规则保持原样，不复制另一套只读 wizard。现代 VIEW-only 任务行由服务端返回 `HISTORY_DETAIL`，进行中和已结束均通过公共物理详情读取。Flutter 回归覆盖实际表格双击、普通页面/弹窗/命令式挂载三种导航以及旧办理深链被 VIEW-only 拒绝。旧 `WarehouseDrawTaskSegment` 已无生产调用方，不将其当作现代入口。

盘点命令的原对象资格是独立复核码与 posting gateway 的原车间可达范围；它不是按名称推定的所有 keeper 权限。新的只读车间可达集合不进入该 posting/command gateway。

## 发布前后的读取资格核验

`NativeTaskReadScopeInterceptor` 使用固定 GET 路由表，复用原 `ReadScopePublication/ReportReadScopeAdvice` 的前后核验，不给命令或任意 `/warehouse/**` 路径放行。原 method 上的 `BusinessTaskRead` purpose 保留。它在审计之后、通用 report plan 之前注册，避免 where-used 的专用读取证明被通用 production report 证明遮住。

仓库证明保留真实物理角色、职责仓和仓储成员信息；额外记录读取 all 标记及原 `OwnerVisibility` 的 visible/writable 集合。关联追溯复用 purchase/subcontract/production/workshop 已有 ledger 与原策略，范围码没有成为 owner 或写入授权。

V985 使用既有 ledger/domain 和 `fn_mark_native_scope_columns`，不新增 domain，不枚举业务 ID。新增 source 均来自实际读取谓词：
