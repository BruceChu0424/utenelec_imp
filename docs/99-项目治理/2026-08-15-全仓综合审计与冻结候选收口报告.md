### 2.3 四个固定宽度 Dialog 改为自适应（响应式规范）

AlertDialog 会对 content 做 intrinsic 宽度测量，`width: double.infinity` 会把测量传导进
shrink-wrap 的 ListView/表格 viewport 引发崩溃——因此 AlertDialog 场景用「屏幕宽度钳制」，
Dialog 场景用 `ConstrainedBox(maxWidth) + double.infinity`：

| 文件 | 原值 | 现值 |
|---|---|---|
| `lib/features/production/pages/production_plan_wizard_page.dart` | 固定 700 | `(屏宽-96).clamp(280,700)` |
| `lib/features/production/pages/production_plan_detail_page.dart` | 固定 980 | `(屏宽-96).clamp(280,980)` |
| `lib/features/production/widgets/where_used_product_detail_dialog.dart` | 固定 800 | `ConstrainedBox(maxWidth:800)+double.infinity` |
| `lib/features/finance/widgets/finance_asset_form_v2.dart` | ConstrainedBox 内再固定 920 | ConstrainedBox 内 `double.infinity` |

修复过程中 wizard 的固定宽度曾被替换为无限宽并被 `production_plan_wizard_page_test.dart`
的多纸用例捕获（ShrinkWrappingViewport intrinsic 崩溃），最终按上表方案收敛；相关 6 个测试
文件 22/22 通过。

## 3. 验证结论（无需修改的部分）

### 3.1 安全（达到或超过行业标准）

- 密码：Argon2id（OWASP 参数，19456KiB/iter2，长度上限防 CPU DoS，历史防重用）。
- PII：pgcrypto `pgp_sym_encrypt`，密钥绑定参数注入（不进 SQL 日志），密文版本前缀支持轮换。
- HMAC：HmacSHA256（身份证查重、附件上传授权），域分隔 + `MessageDigest.isEqual` 常量时间比较。
- JWT：HS256 fail-fast ≥32 字节、issuer 校验、每请求 DB 侧 authVersion/epoch 复核；
  refresh 为不透明随机串、DB 存 SHA-256。
- 授权：`@PreAuthorize` 829 处；101 个 Controller 中 6 个无注解均为正当豁免（登录/公共/自范围/访客）。
- 注入：47 处 nativeQuery 全参数化；`set_config` 亦绑定参数。
- 上传：fail-closed、HMAC 单用途授权、扩展名白名单+magic byte、路径穿越防护、25MB 上限。
- 日志：无 password/token 打印；短信验证码不落日志。
- 敏感数据：`.env` 被 gitignore 且未跟踪；`server/.env.example`、`website/.env.example`、
  `deploy/setup/*.example` 全部为占位符；`application-prod.yml` 强制 `UTEN_DB_PASSWORD` 等
  无默认值（base yml 的 `uten` 回退仅 dev 生效）；先前 gitleaks 388 项命中全部位于
  gitignore 的构建产物/本地文件。

### 3.2 业务联动（口径一致，链路闭环）

计划↔销售（`plan_order_item_links`）、计划下达→采购/委外申请（Facade 生成、业务侧只读）、
申请→订货→收货→IQC→入库、委外回厂按冻结 BOM 守恒消费发料、完工入库回写计划/订单预留、
销售出货扣预留+movable 双校验、红冲三链对称、超收 V201 服务端守卫——均与
`docs/07-业务链路` 一致（证据链略，见审计底稿）。已知**设计性取舍**（非缺陷）：
跨模块引用按契约§一不建 DB 外键，靠 `ProductionChainHealthService` 兜底；
`stock_balances.qty` 非负仅应用层+advisory lock 保证；TRANSFER 调拨路线文档自认未闭环。

### 3.3 部署与远程更新（内部服务器模式纯度通过）

pull-based（timer 5min→无特权 updater→仅 staging）、Ed25519 三层验签（channel→manifest→
归档摘要）、activate 必须 root+三重确认、timer 默认 disabled 且安装器断言、300s 健康等待、
迁移独立 unit（JVM `SPRING_FLYWAY_ENABLED=false`）、watchdog 双闸门+维护互斥、
失败原子 symlink 回滚+不兼容即 fail-closed。`deploy/` 无任何官网部署残留；internal-test
nginx 将官网 ingest 404 关闭；env 链路 example→sudoedit→原子晋升（0600/0640）无制品泄漏。
