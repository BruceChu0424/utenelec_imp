# 库存详情页

> 状态：✅ 已实现（2026-09-01 库存查询合并）。即时库存页双击货品行进入的
> 单货品库存工作台；原「库存余额」「出入库流水」两页并入本页
> （旧路由 `/stock/balance`、`/stock/movement` 重定向保深链）。
> **Owner**：仓库 / PMC 运营部 | **创建日期**：2026-09-01

## 一、页面与权限

- 路由：`/stock/item/:goodsId`（路由名 `stock-item-detail`；`/stock/` 前缀 →
  `stock:view`）。
- 余额调整动作另需 `stock:balance:adjust`（高权限，自动生成 `CHECK` 盘点单）。
- 页面权限面：`warehouse.stock-item`（V450，精确关联 `stock:view` 与
  `stock:balance:adjust`）。

## 二、页面结构

1. **页头**：货品信息（名称/编号/系列/建议库位，货品字典 lookup）。
2. **分段工具条**（`UtenFilterToolbar`，纯分类无搜索——后端按货品过滤，
   前端不制造假关键字）：
   - **库存余额**：该货品各仓/颜色余额表（仓库/颜色/当前数量/库存重量/最后变动，
     数量与重量可排序）。双击行弹余额详情层（当前数量与重量、权限提示、
     「查看流水」切到流水分段、授权账号「调整余额」→ 原余额页同款受控调整表单，
     幂等键 + 调整原因必填 + 结果展示 CHECK 单号）。
   - **出入库流水**：该货品全部来源流水（日期/类型/仓库/颜色/带方向符号的数量与
     实际重量/备注，默认时间倒序）；双击行回源单
     （采购/销售/委外单据详情或 `/warehouse/:code/:id`，映射与旧流水页一致）。
3. 服务端分页（每页 50，LIMIT/OFFSET + 排序白名单）。

## 三、性能口径（大数据量）

- 余额按货品：`idx_stock_balances_goods_cover (goods_id) INCLUDE (warehouse_id,
  color_id, qty, weight, last_movement_date)` 覆盖索引免回表（V450）。
- 流水按货品默认时间倒序：`idx_stock_movements_goods_date (goods_id,
  transaction_date DESC)`（V450）消除排序开销；老数据完全兼容，无行改写。

## 四、深链与兼容

- 即时库存行双击 → 本页（原行为是跳 `/stock/movement?goodsId=`）。
- `/stock/balance` → 重定向 `/stock/instant-inventory`；
  `/stock/movement?goodsId=X` → 重定向 `/stock/item/X`（货品详情、物料反查等
  旧深链继续可用）；无 goodsId 的 movement 旧链回即时库存。
- 余额调整链路（`POST /stock/balances/adjust`）与 CHECK 单语义不变。
