# 生产退料批量收料

> 路由：`/warehouse/material-returns/batch-receive`
> 别名：批量退料收料、整批生产退料

## 页面定位

仓库逐张核对已选生产退料单的实物数量并确认收料。

## 办理与边界

- 从入库任务中心的生产退料任务选择原单据进入，整批保留每张单据的来源身份。
- 查看需要 `stock_doc:view`，确认收料需要 `stock_doc:approve`；查看权限不包含确认权限。
- 按原单据核对货品、颜色、单位、仓库与原领料来源。数量带原计量单位，不能把不同物料合成一个收料数。
- 发送前重新核对当前身份与权限；每张单据的状态、版本、仓库范围及实际收料边界由服务端独立校验。
- 已成功的单据保持成功；回执未查明时先核对原结果，恢复原请求身份，不重新办理已成功成员。
- 返回保留原入库任务上下文，单张失败不抹掉整批已经完成的记录。
