# 侧栏边界与分栏握把修正

本次界面审查使用 `frontend-design`，保留 Uten 主题、布局尺寸和业务行为。

## 公共入口及覆盖

- Web 与 Flutter 桌面共用 `UtenSideNavRail`：移除导航栏最右侧额外绘制的灰线，继续由导航与正文背景区分区域。展开、折叠和导航权限不变。
- Web 与 Flutter 桌面共用 `UtenSplitHandle`：原 20 像素字体图标放在 12 像素握把中，超出可用宽度；改为完整位于握把内部的 2×3 圆点。保留 12 像素命中区、拖动、长按、键盘、双击复位及原有宽度偏好。
- Win7 WPF 候选的 `MainWindow` 侧栏也移除同类右边框。其货品页使用原生 `GridSplitter`，没有超宽字体图标，保留原生拖动行为；本次不将其标为完整 ERP 或 Win7 真机验收通过。
- Windows 最大化客户区裁剪由独立原生 `WM_NCCALCSIZE` 修复处理，不以 Flutter 页面内边距补偿。

## 验证边界

复用既有分栏、受控宽度、导航展开/折叠及运行时隔离回归。实际命令和结果保留在发布目录 `window-ui-runtime-regression.log`。用户运行中的 LocalTest 未替换；当前窗口不代表已加载本次源码修复。
