# UTEN 国际化官网内容策略

## 1. 国际化不是“多翻译几种语言”

新版官网按三层组织：

1. **品牌层**：用一致的视觉、产品语言与制造表达，让任何市场的访客先理解 UTEN 是什么。
2. **市场层**：先确认目的国家、安装体系、项目类型与所需文件，再讨论具体产品。
3. **语言层**：每个语言拥有独立 URL、标题、描述与索引策略；没有经过审核的产品事实使用英文或中文回退，并禁止把回退页伪装成完整本地化页面。

浏览器语言只决定首次访问语言，不能替代目标市场。英语访客可能采购中东项目，法语访客也可能采购非洲项目；标准、安装方式与文件必须由项目字段明确填写。

## 2. 对外信息架构

- **首页**：只讲当前主推/最新产品；每个产品采用“大幅产品视觉 + 一侧简洁说明”的编辑式叙事。系列跑马导航只承担快速入口，不堆砌全部目录。
- **产品中心**：先看设计系列，再进入系列按功能与开数选型。系列封面是一张多产品组合画面，产品详情再展示具体型号/款式。
- **空间试装**：帮助理解产品与墙面的视觉关系；明确是 2.5D 参考，不代替尺寸图、实物样品或安装验证。
- **制造与质量**：讲产品规划、制造协同、验证流程与型号级资料支持，不把一张历史证书扩张成全目录声明。
- **国际合作**：分别服务经销商、工程/选型团队、OEM/ODM 采购方、设计师与施工方，并使用结构化项目需求表。
- **专业资料**：采购指南、常见问题和文件申请入口；文件必须关联具体型号、目标市场、版本与用途。
- **公司与联系**：保留可信的公司、地址、联系方式和可核验历史；弱化过于本地、过时或无法证明的宣传。

## 3. 对外事实分级

每条重要内容必须属于以下状态之一：

| 状态 | 可对外方式 | 示例 |
| --- | --- | --- |
| Verified | 可以明确陈述，并记录证据来源与复核日期 | 公司法定名称、当前地址、经确认型号参数 |
| Source-backed | 可以谨慎表述，并标注范围或历史属性 | 公司档案中的实验室与生产活动 |
| Aspirational | 可以作为品牌主张，但不能伪装成既成业绩 | “让电气细节成为空间设计的一部分” |
| Needs review | 不进入公开硬性声明、筛选或证书下载 | 从旧名称推断的功能、未核验颜色、过期证书缩略图 |

可以增强情绪、设计愿景与服务态度；不得编造客户、项目、出口国家数量、产能、成立年份、认证、测试结果、电气参数、质保或交期。这些内容会直接影响安全、采购审批和法律责任。

## 4. 内容发布优先级

### P0：采购决策基础

1. **Choosing the Right Wiring Standard for Your Market** 目标市场与安装体系如何影响选型。
2. **How the UTEN Product System Works** 设计系列、功能产品、型号与表面款式的关系。
3. **OEM / ODM Project Brief Checklist** 首次需求应包含哪些技术与商务信息。
4. **Product Documents Before Approval** 规格书、尺寸图、安装说明和合规文件如何按型号核对。
5. 每个主推系列一篇完整系列页：组合封面、设计特征、功能矩阵、可用资料与咨询入口。

### P1：行业场景与合作能力

1. Hospitality & Guest-room Controls：酒店客房选型关注点。
2. Residential Series Coordination：住宅中如何保持开关、插座与弱电模块一致。
3. Distributor Range Planning：经销商如何按市场构建首批产品范围。
4. From Sample to Approved Specification：样品、颜色、尺寸与文件的确认流程。
5. Quality Review Explained：寿命、高压、阻燃与环境测试分别回答什么问题；只描述有证据的范围。

### P2：可信合作故事

只发布获得客户授权、具备项目名称/区域/时间/产品范围/图片来源的案例。经销商大会、营销活动与工程案例必须分开。无法确认的客户 Logo、国家地图和“全球领先”等内容不使用。

## 5. 多语言治理

- UI 可覆盖十种语言；产品事实当前优先完成中英双语，其他语言采用可见回退并 `noindex`，直到翻译被审核。当前 sitemap 只发布已审核的中英文页面。
- 文章、产品与系列分别记录“直接语言内容”状态；机器初稿不能自动发布。
- 电气单位、型号、标准编号、商标与文件名称进入术语表，不能逐句自由翻译。
- 阿拉伯语必须做 RTL 实机检查；德法西葡需检查长文本溢出；日/韩需检查字重与换行。
- 语言切换保持当前页面；市场选择是另一个维度，不跟语言绑定。

## 6. 后台与发布责任

- “首页推荐”控制首页当前主推产品；没有明确发布时间的数据不自动宣称发布日期。
- 系列后台维护组合封面、系列说明与父子层级；产品后台维护功能、开数、规格、款式与发布状态。
- 国际能力、合作页与资源页核心中英文可由站点设置维护；采购指南由新闻/文章模块维护。
- 项目询盘持久化目标市场、客户类型、安装体系、关注产品、需求类型、数量、时间与首选联系方法。
- 长期接入公司平台时，必须复用平台 SSO 与后端权限校验；“无需再次登录”不等于匿名后台。
- 发布前保留草稿、审核、发布人与版本历史；媒体、证书和产品资料应进入对象存储并记录适用型号与版本。

## 7. 上线前资料清单

公司需要补充并确认：

- 最新公司主体信息、品牌故事和可公开的真实发展节点；
- 当前厂房、生产线、实验室、团队和主推系列高清照片；
- 主推型号、功能、开数、额定参数、尺寸、安装体系、表面工艺与可售市场；
- 每份证书/声明的签发机构、编号、型号范围、标准、版本与有效期；
- OEM/ODM 可承诺范围、样品流程、包装与品牌规则；
- 获授权的国际合作案例与客户素材；
- 询盘保留期限、负责人、隐私联系人与跨境数据处理要求。

在资料补齐前，网站以产品发现、项目需求收集和资料申请为主，不把推断数据包装成已经核验的事实。
