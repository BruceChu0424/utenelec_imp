# 36 - 客户归属授权（每个销售只看自己的客户）

> **2026-08-26 前向覆盖**：现行规则以 [ADR-050](../99-决策记录-ADR/ADR-050-客户访问与人员数据交接分层.md)
> 和 V393–V399 为准。客户不区分内销/外贸/OEM；`owner_employee_id IS NULL` 改为“待分配”，
> 不再对普通员工公共可见；新客户默认当前员工且负责人必填。`user_data_scopes` 只增加只读查看，
> 精确绑定 raw owner，允许新授权查看离职员工原历史，不随其接手人扩大；单客户查看走
> `client_visibility_grants`，可写责任必须正式交接。`client:assign` 无部门/角色默认，仅超管或中央
> 个人显式 grant；客户交接把 client scope A 只展开为本批实际转出客户的逐客户只读 grant，不改成 B。
> 正常列表/字典/facets/导出/picker/候选数量统一排除软删除和 `LEGACY-FIN-CL-*` 财务占位。
> 下文 2026-07-28 的“公共客户”、
> 列表数量与“看+改”描述仅保留历史演进证据，不再是当前运行契约。

> 时间：2026-07-28 · 现行依据：[ADR-011](../99-决策记录-ADR/ADR-011-工作台部门分区与动态权限配置.md)

## 二、设计（与货品外贸同模型）

| 件 | 设计 |
|---|---|
| `clients.owner_employee_id`（V86） | 归属业务员；NULL=公共客户全员可见 |
| 权限点 `client:view:all`（V86） | 「查看全部客户资料」；默认不授任何部门，超管恒有 |
| **数据范围授权 `user_data_scopes`（V89）** | **中间档**：权限管理页按人勾选「能看哪些业务员的客户」，可见规则 = 公共 ∪ 本人 ∪ 授权归属人；查询期实时生效 |
| 可见性规则 | 服务端强制（`OwnerVisibility` 统一判定）：打在 `ClientService.list` + `facets` |
| 判定逻辑 | 共用组件 `security/OwnerVisibility`（显式三态 + 授权集合），货品/客户同用 |
| 归属迁移 | `migrate_client_owner.sql`：emp_id→employees.legacy_id，先清零再灌，幂等 |
