# 货架目视化清单页

> 路由：`/warehouse/shelf-labels`（`lib/features/warehouse/pages/shelf_label_page.dart`）· 权限 `stock:view`（全员）；Excel 导出 `stock_report:export`
> 上层：工作台 → PMC 运营部 → 仓库管理 hub → 「库存查询」分区 · 数据口径：货品主档 `goods.stock_place`（库位号）
> 后端：`GET /api/stock/shelf-labels`（+ `/racks`）· 导出 `POST /api/stock/reports/export` report=`shelf-labels`

## 一、定位

对标仓库现场挂牌「目视化管理清单 Visual Management List」（五金仓库物料库 / 塑胶仓库物料库，
挂牌右上角「A31库行」徽章）。把货品主档中已维护库位号的货品按 **库行 → 层 → 位** 自然排序分组，
列与挂牌完全一致：**库位号 / 物料编码 / 物料系列 / 物料名称 / 颜色**。

与「即时库存」的区别：本页**与库存数量无关**——货架固定摆放什么就列什么，用于打印张贴与盘点对位；
即时库存回答「现在有多少」，本页回答「放在哪、货架上应该有什么」。

库位号数据不在老库（老库 `B_Goods.StockPlace` 仅 151 行且为 `'18'/'20'` 等历史残值，与现场
`A31-3-1` 格式无关）。库位由仓库部门按现场挂牌整理 `data/shelf_labels.csv`，经
`migrate.sh --shelf-labels` 受控导入（见 [17-仓库管理-新库与迁移](../数据迁移/17-仓库管理-新库与迁移.md) §十二）；
日常新增/调整走货品资料详情的「库位号」字段（规格分组）。

**种子数据（2026-08-17）**：已按现场挂牌照片逐格核对整理 28 行进 `data/shelf_labels.csv`——
A31 库行（五金仓库）23 行（A31-3-1～A31-3-21，其中 3-4/3-5 两位各放两种物料，与挂牌一致）+
A39 库行（塑胶仓库）5 行（A39-1-1～A39-1-5，80N 系列白色塑胶件）。本地库未跑全量货品迁移，
导入时 28 行均报「未匹配」属预期；目标库 `--goods-data` 完成后重跑即匹配。
老库残值（如 `'19'`）会在清单中显示为独立库行，正式迁移后建议按格式校验治理（非标值置空）。

## 二、入口与导航

- 进入：仓库管理 hub「库存查询」分区 → 「货架目视化清单」卡片。
- 离开：返回仓库管理 hub（`UtenBackButton` 指定 `/warehouse`）。

- **抬头仓库**：只作打印标题（挂牌「五金仓库物料库」），不过滤数据——货品主档库位号全局唯一，
  货品与仓库没有归属关系；可用「标题覆盖」自由改标题（如分仓打印不同抬头）。
- **库行下拉**：数据源 `GET /api/stock/shelf-labels/racks`（stock_place 首段去重）。
- **搜索**：名称/编码/系列/库位号模糊。

## 四、打印版式（预览打印）

复刻挂牌：每个库行独立 A4 横版页；teal 头部（左「UTEN优腾 / 德国工匠·质造开关」，
中「{抬头}物料库 / 目视化管理清单 Visual Management List」，右白底「A31库行」徽章）；
五列斑马纹表格；每库行末尾 6 个**留白行**供现场手写补充（挂牌同款）。行多的库行自动分页。
PDF 用 NotoSansSC 全量字体（`assets/fonts/NotoSansSCFull.ttf`），与通用打印组件同路径。

## 五、Excel 导出

`POST /api/stock/reports/export` report=`shelf-labels`，列 = 库行/库位号/物料编码/物料系列/物料名称/颜色，
与页内筛选（rack/keyword）同口径；走统一加密导出 + 审计（`export_stock_report`）。

## 六、库位号联动全景（2026-08-17 增量）

库位号唯一权威 = 货品主档 `goods.stock_place`（货品资料详情「规格」分组可维护）；各业务口只读带出，不在单据上另存（`stock_document_items.place` 仅承载老库历史文本）。展示链路：

| 位置 | 展示方式 |
|---|---|
| 货品选择器（`showUtenGoodsPicker`/多选，全业务域通用） | 列表项副标题前置「库位 A31-3-1」（有库位才显示）——选品即见位置 |
| 仓库 9 类单据编辑/详情（已有） | 明细「库位号」只读列（选择器带回或 `goodsLookup` 补全） |
| 采购收货/退货 编辑+详情 | 明细「库位号」只读列（上架/拣货指引；到货登记模式列收窄时仍预取缓存供详情用） |
| 委外进仓/发料/退货/材料退 编辑+详情 | 同上（配置 `itemHasStockPlace`；损耗单不动公司库存、订货/申请无仓库，不加列） |
| 销售出货/其它出货/退货 编辑+详情 | 同上（恰为 `hasWarehouse` 三类；拣货指引） |
| 即时库存 / 7 类仓库明细报表（已有） | 「库位号」列 |
| 货架目视化清单（本页） | 五列挂牌口径 + 打印 + Excel |

## 七、相关改动

- 7 类仓库明细报表（调拨/其它入库/领料/退料/产成品进仓/出仓/盘点）统一加「库位号」列
  （`g.stock_place`），拣货/上架对位直接在报表可见。
- 单据编辑明细表已有只读「库位号」列（自主档带出）；库位是货品主档属性，单据行不另存
  （`stock_document_items.place` 仅承载老库历史文本）。
- 货品列表 API（`GoodsListItem`）新增 `stockPlace` 返回，选择器与各单据页共用。
