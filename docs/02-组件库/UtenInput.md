# UtenInput (通用输入框)

> 源码：[uten_input.dart](../../lib/components/inputs/uten_input.dart)。文本、密码、数字等通用输入，带客户端校验与全站框内提示约定。

关联下拉的普通表单选值可通过 `UtenDropdownField.selectedMaxLines: null` 自然换行显示完整名称。默认值仍为1；dense和flat表格变体继续保持单行。打开后的菜单候选项完整换行，`menuMatchContentWidth: true` 另按内容扩宽；菜单仍不超出当前安全区和键盘上方的可用空间，矮窗口中搜索、添加和选项共同滚动。选项及添加入口补足实际触控目标；深层缩进按剩余可读宽收敛，原层级/Tooltip/选项身份保留。参数只影响展示，不改变清除语义或 `onChanged`。

下拉菜单按字段上方或下方较充足的安全空间展开，不再固定限高320；候选较少时按内容收缩。货品等主档的共用内联词条编辑器启用 `menuMatchContentWidth`，窄列里的颜色等词条可以展开阅读，搜索后继续使用完整字典测得的宽度。窗口变窄、界面放大或键盘出现时，菜单收敛到可用边界，候选列表保持滚动可达。

下拉框支持从四边或四角拖动调整宽高，鼠标移到边缘时显示对应的缩放光标；顶部拖动区用于移动位置。调整后按账号和服务器保存字段的宽高及相对位置，下次打开或重新进入页面后恢复。同类主档字段的各行共用设置，普通选值、搜索、滚动和清空继续使用原流程；「恢复自动大小和位置」可清除该字段的手动设置。窗口或屏幕键盘变化只收敛当前显示范围，不覆盖用户保存的首选尺寸。

参考资料选择字段 `UtenReferencePickerField` 的完整选择入口统一使用 `UtenPickerIconButton`，以省略号图标替代「选择」文字，保留按业务字段命名的 Tooltip、键盘焦点和触控目标。异步选择窗口打开期间显示等待状态并防止重复打开，关闭后才恢复可用。输入候选搜索继续只查找，不凭显示名称写入关系身份；选中记录后才回填 UUID。组装信息的空行多选新增和已有行单选换件复用同一图标组件。

## 参数速查

| 参数 | 说明 |
| --- | --- |
| `label` | 框内标签；填写或聚焦时浮起，与下拉、日期和选择器保持一致；`required: true` 时附红 `*` |
| `hint` | 有 `label` 时空框默认显示字段名；不同于字段名的格式样例或业务说明自动收进框内信息图标。无标签的搜索框保留完整搜索范围 |
| `info` | 字段静态说明，收进框内信息图标，悬停、点击或键盘聚焦查看 |
| `errorMessage` | 外部字段错误，显示框内错误图标和红框，完整内容保留 live-region 语义 |
| `autofilled` / `warningMessage` | 历史或默认带出值使用黄框、浅黄底和框内警告图标；可传入具体来源说明 |
| `required` | 必填标签红 `*`；空值红框，填好恢复 |
| `validator` | 原生表单校验，与外部错误共用框内提示，不改变 `FormState.validate/reset` 行为 |
| `isPassword` / `obscureText` | 密码输入；`isPassword` 提供可见切换按钮，与提示图标共存 |
| `inputFormatters` | 字段级输入约束；中文自然语言字段通常不应设置 |
| `aiSensitive` | 敏感数值字段(成本/工资/信用额度/个人信息等, ADR-150)：AI 助手读页面时只发标签与状态，值、提示文字与说明都不发；标签命中平台敏感词时即使不标也不发；标签像密码/验证码/密钥的字段整条不发 |
| 其余 | `controller` / `keyboardType` / `maxLines` / `enabled` / `focusNode` 等常规项 |

## 字段提示

普通空字段直接显示业务字段名，例如「颜色」「所属仓库」「交货日期」，不使用「请输入 / 请选择 / 未选择」。`UtenInputDecoration` 从 `labelText` 或共享 `requiredLabel/fieldLabel` 读取字段名；未聚焦时字段名留在框内，聚焦但仍为空时也保留框内字段名，有值时浮动标签继续标明字段身份。必填红星、错误红框、预填黄框、清除按钮、禁用及辅助技术语义沿用原契约。

裸字段接入方式为 `UtenInputDecoration(InputDecoration(labelText: '制造年月', hintText: '如 2018-07'))`：空框显示「制造年月」，格式样例进入现有信息图标，可点按、悬停或键盘查看。自绘输入值可调用 `utenFieldPlaceholder(label: ..., hint: ..., fallback: ...)`。普通页面继续用现有 Uten 主题与 `UtenPageField`，表格保留独立紧凑尺寸；相关界面调整默认使用 `frontend-design`。

### 空值和例外矩阵

| 字段类型 | 空值呈现 | 保留的说明或状态 |
| --- | --- | --- |
| 文本、密码、数值、只读字段 | 框内字段名 | 格式、限制和生成规则进信息图标；不改真实值和校验规则 |
| 普通单选下拉、日期 | 按真实值设置 `InputDecorator.isEmpty`，空时由装饰显示字段名 | 选择菜单、清空动作、日期边界和禁用行为保留 |
| 年月 | 框内年月字段名 | `2018-07` 等格式样例进信息图标，既有手输和月选择都保留 |
| 人员单选、多选 | 有标签时显示角色字段名，无标签时显示「员工 / 人员」 | 部门范围、候选搜索及已选人数仍由原组件管理 |
| 没有标签的页面搜索、候选搜索 | 保留「搜索名称 / 编号」等真实搜索范围 | 不机械缩成「搜索」，不改变防抖和输入法组合保护 |
| 筛选入口、结构化编辑器 | 保留明确的「全部 / 不限」等业务状态 | `UtenFilterPickerField` 已在框内同时显示字段名和筛选状态；确需保留独立提示时显式用 `useFieldNameHint: false`，不能用于普通输入字段 |
| 表格输入 | 继续由表头承担字段身份；有明确空值字段名时直接显示 | 保留表格紧凑尺寸、单行和单位后缀，不用通用「请选择」替代业务名称 |
| 校验错误、拖放说明、选择面板汇总 | 保留动作或错误完整句子 | 它们不是输入框占位，例如「请输入有效年月」仍是有用的校验说明 |

### 业务调用点核对

| 模块与场景 | 本次口径 / 明确例外 |
| --- | --- |
| 员工入职、编辑、调岗、离职、联系与车辆 | 普通和只读字段统一装饰；离职日期按真实空值显示字段名；车牌示例移到信息图标，字段名不夹格式或“非必填”长说明 |
| 保安通行核验、通知与建议回复 | 通行码、祝福内容、回复内容以字段名占位；6位数字要求、回复处理说明和通知站内路径示例保留在信息图标 / 原校验 |
| 品质、研发任务、采购任务工作台与工作台概览 | 数量字段保持真实控制器值和单位后缀；无标签搜索保留检索范围；任务状态、分段和信息卡不冒充输入框 |
| 工作台测试数据清空确认 | `system-test-clear-confirm-input` 必须照抄完整确认短语，显式 `useFieldNameHint: false`；不改成通用字段名或改动确认条件 |
| 财务对账筛选 | 「全部账户」是实际筛选状态，保留该状态，不当成普通空值提示 |
| 锁定单据事实 | 销售锁定发运策略 / 报价来源、财务锁定原币 / 已有记账时刻显示原只读事实，不替换成默认占位 |
| 手工物料需求的行交期 | 空值表示继承单头，保留「同单头」及其继承规则 |
| 采购、销售、委外、库存及品质数量 / 金额 / 备注 | 普通与表格输入使用业务字段名；数字 `0` 仅在控制器本就登记真实零值时显示，格式和样本数说明进信息图标；自绘货品、仓库、车间 / 负责人字段复用 `utenFieldPlaceholder` |

| 内容 | 通道 | 视觉 |
| --- | --- | --- |
| 静态说明 | `info:` | 框内信息图标 |
| 校验错误 | `errorMessage:` / `validator` | 框内错误图标和红框 |
| 预填提醒 | `autofilled/warningMessage`；裸装饰使用 `applyAutofillHint` | 框内警告图标、黄框和浅黄底 |

同一字段的多类消息合并到一个图标，完整内容按错误、预填、说明排序；字段下方不显示提示，也不保留消息槽高度。业务调用方在人工编辑或明确确认后清除 `autofilled`；已有单据回显不冒充学习值。空值不标黄，校验错误和必填空仍优先标红。

父组件更换文本控制器时会立即切换显示、监听和必填状态，组件只释放自己创建的控制器，避免同一页面切换记录后继续编辑上一条记录。

图标支持悬停、点击和键盘聚焦，不影响原有输入、清空或密码按钮。详见 [UtenFieldMessage](UtenFieldMessage.md)。

## 使用约束

- 普通页面、卡片和弹窗使用 `UtenPageField`：桌面单行框体最小高 44、横向内距 12、16 号正文、10 圆角；触控最小 48，文字放大或多行内容可自然增高。搜索和筛选栏保留独立的 36 高度。
- 表格使用 `UtenTableCellInputTheme`（2026-10-16）：桌面视觉最小高 32、触控至少 48、横向内距 10、14 号正文和 6 圆角；竖向内距通过 `UtenEditableGridCellSpec.contentPaddingOf(context)` 按正文行高与视觉密度补偿，使真实轮廓与点击盒同高、同中线。下拉自动识别表格作用域；表外显式 `dense: true` 也使用同一紧凑规范。普通表单无需传 `dense`。

- 优先复用本组件，不在框下额外拼接说明或错误文字。
- 直接 `TextFormField` 必须使用 `UtenInputDecoration`，并配置 `errorBuilder: utenTextFieldErrorBuilder`。
- 页面禁止原生 `helperText:` / `errorText:`；需要裸字段时使用 `info` 或 `UtenFieldMessage` 并接入装饰适配器。
- 全站 AST 源码契约检查实际字段调用，适配器内部原参数转发是唯一精确兼容例外。

## 表格输入随内容加宽（2026-10-20）

`UtenEditableGrid` 与 `MasterDataTableView` 在表格单元格内统一接入
`UtenTableCellAutoWidth`。空框保留既有紧凑宽度；输入或选值后，按当前可见内容所需宽度
扩大整列，表头、同列其他行及冻结区域始终对齐。页面无需为获得自动加宽而逐列补写
`textOf` / `listenableOf`。

- 支持裸 `TextField` / `TextFormField`、`UtenInput`、数字及金额、日期及月份、下拉
  （含 flat 变体）、人员或主档选择器，以及带单位、图标、按钮的复合输入。
- 以真实显示值、当前字体与文字缩放、内边距及输入附属控件测量；占位文字、错误或说明
  文案、尚未选中的菜单候选不撑大列宽。密码按当前遮罩后的显示内容测量。
- 自动宽度只增不减，删除文字不立即缩列，避免编辑中抖动；自动增长通常封顶 480。
  `UtenEditableGrid` 保留已声明的大于 480 的宽度，`MasterDataTableView` 的声明宽度
  继续按既有自动拟合上限处理；两种表格均保留手动设置的更大宽度。超限内容沿用输入框内部滚动或选值省略，
  宽表继续通过原有横向滚动查看。
- 拖动列宽手柄后使用手动宽度，停止该列自动增长；双击手柄清除手动宽度并按当前内容
  恢复自动适配。
- 量宽只改变布局，不替换输入控件、控制器、焦点或选区，不改变校验、业务值、输入回调
  和权限。卡片视图继续服从卡片可用宽度，不将内容测量反馈为表格列宽。

`textOf` / `listenableOf` 仍用于早期宽度预估、实时筛选、冻结文本快照及 AI 等原有能力，
已有配置应保留；自动量宽不能代替这些业务可读文本来源。表外普通表单和弹窗继续遵循
`UtenPageField` 的响应式布局。

## AI 助手读字段与「AI 填入」黄框(2026-10-04, ADR-150)

`UtenInput`、`UtenDropdownField`、`UtenDateField` 挂载时向 [AiPageContext](AiPageContext.md) 登记(发问时才读): 标签、显示值、状态(正常 / 必填空 / 黄框预填 / 错误)、黄框或错误的原因、`info` 说明。

- **密码框(`isPassword` / `obscureText`)一律不登记**; 没有 `label` 的输入框不登记。
- 通用动作 `setField`(按标签设值): 只有启用状态的字段可设; 下拉按选项文字匹配(精确 > 忽略大小写 > 唯一包含), 日期写 `2026-10-04`。设值后字段显示黄框和框内提示「AI 填入, 请核对」, 并照常回调 `onChanged`; 用户再改这一格(或重新选择)黄框即消失。AI 填入的提示优先于调用方原有的预填提示。
- 只改本页输入, 不保存; 保存/提交仍是页面按钮。
- 选择器(`UtenMasterPickerField` 即客户/供应商字段、`UtenEmployeePicker`、`UtenEmployeeMultiPicker`)与工具栏 `UtenFilterPickerField` 只登记标签与所选名称(多选用「、」连接), **不提供设值动作**: 选哪个客户、哪个人仍由用户自己点。
