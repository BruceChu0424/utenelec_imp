# V553 系统设置生效语义说明

仅更新 `system_settings` 两条展示说明：庆典自动类型只支持生日与入职纪念日，下一次北京时间 08:00:07 计划任务执行；密码历史为 0 时关闭旧密码回溯，但当前密码仍不能重复使用。

回滚应用可继续读取现有表结构，说明文本无需回滚。迁移后的核验应比较两项配置值与迁移前完全一致，并检查说明已更新。源码测试不代替目标库执行证明。
