# 产量统计页

> 路由：`/production/output`（计划：`lib/features/production/pages/production_output_stats_page.dart`）· Phase 4
> 上层：[Phase4-生产实验室总览](Phase4-生产实验室总览.md)

## 一、定位

按产线/产品/班次/日期维度汇总产量，看趋势与不良率。manager 可切视角看全公司或某部门。

## 二、入口与导航
- 进入：production/manager 主导航「产量统计」。
- 离开：导出 → 下载。

## 三、响应式布局
筛选 + KPI + 图表 + 明细表（类似 [财务报表页](财务报表页.md)）。

- expanded：
```
┌──────────────────────────────────────────────┐
│ 产量统计  日期[本周▼] 范围[全公司▼]  [导出]    │
├──────────────────────────────────────────────┤
│ [总产量12800][合格率98.5%][不良200][达标率✅]   │  ← KPI
│ 产量趋势(折线)          产品占比(饼)           │  ← UtenChartPlaceholder
│ 明细表：产线 产品 班次 合格 不良 不良率          │  ← UtenDataTable
└──────────────────────────────────────────────┘
```

## 四、涉及的 Uten 组件
`UtenAppBar`（视角+日期+导出）/ `UtenViewContextSelector` / `UtenStatCard` / `UtenChartPlaceholder` / `UtenDataTable` / `UtenDropdown` / `UtenButton` / `UtenEmpty`。

## 五、功能点
1. **筛选**：日期范围（日/周/月）、范围（视角）、产线/产品。
2. **KPI**：总产量、合格率、不良数、达标率。
3. **图表**（占位）：趋势折线、产品占比饼、班次对比柱。
4. **明细表**：可排序、可下钻单条。
5. **导出** Excel。

## 六、功能链路图
```mermaid
flowchart LR
    F[选日期+范围] --> Q[查产量汇总]
    Q --> V[KPI+图表+明细]
    V --> EX{导出} --> FILE[Excel+审计]
```

## 七、涉及的数据实体
`ProductionOutput`（汇总源）/ `ProductionLine` / `Product` / `ProductionShift`。

## 八、权限要求
- production / manager（只读，可切视角）/ admin。`production:view`。

## 九、边界情况
- 无数据：图表 `UtenEmpty`。
- 性能档 lite：图表降级静态表。
- 网络：缓存上次结果。
