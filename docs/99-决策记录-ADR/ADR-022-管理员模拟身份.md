# ADR-022：管理员「切换人 / 模拟身份」

- 状态：已采纳
- 日期：2026-08-05
- 关联：[[ADR-013-系统设置与安全策略可视化]]、[[ADR-011-工作台部门分区与动态权限配置]]、`docs/00-项目准则/10-安全准则.md`

## 背景

超级管理员配置完各部门 / 各岗位权限（部门权限递归继承 + 个人加授 + 脱敏）后，无法直观验证「某个员工到底能看到什么」。只能肉眼对照权限管理页配置，或借该员工账号登录——没有密码也不安全。需要一个让 admin **以目标员工真实视角**查看工作台、页面、数据范围与脱敏的能力，用于核验权限配置是否正确。

## 决策

新增**仅超级管理员**可用的「切换人 / 模拟身份」：

1. **真后端模拟**：后端为 admin 签发一张 `sub=目标员工` 的 staff JWT（带额外 `imp=adminUserId` 标记）。因权限 / 数据范围逐请求由 DB 重算（`JwtAuthFilter`→`PermissionResolver`），目标 token 自动继承目标的有效权限与数据范围，零授权代码改动。
2. **二次密码 + 限时窗口**：进模拟模式前确认 admin 当前密码（防 access token 被盗滥用，对齐 ADR-013）；验通过签发 `modeToken`（签名 JWT，默认 15 分钟），窗口内可反复切换不同目标、免再输密码。
3. **只读**：新增 `ImpersonationWriteGuardFilter`（注册在 `JwtAuthFilter` 之后），凡主体带 `impersonatedBy` 且方法为 POST/PUT/PATCH/DELETE（白名单 `/admin/impersonation/end`、`/auth/logout`）一律 403 `IMPERSONATION_READ_ONLY`。目的是「验证能看到什么」，绝不以他人身份改业务数据。

端点（`/api/admin/impersonation/*`）：`enter` / `start` / `end` / `targets`。`enter`、`start`、`targets` 由 admin token 调（`principal.superAdmin`）；`end` 由模拟 token 调（主体=目标，按 `impersonatedBy` 审计）。

## 安全分析（命名攻击面 = 零）

- admin 身份 = `users.is_super_admin` 布尔列，逐请求从 DB 重读，**不**取决于用户名 / 角色 / JWT claim。把账号名改成 `admin` **不会**获得任何权限（登录账号是 11 位手机号；旧 `admin` 登录名 V205 已改为 `17665410007`）。
- staff JWT 仅含 `sub/typ/av/ae`，无权限 / 无 superAdmin 标记。模拟 token 多一 `imp` claim（admin 的 UUID，非 PII）。
- 模拟 token 不签发 refresh token：到期即退模拟，杜绝长留。
- 审计：`impersonation_enter` / `impersonation_switch` / `impersonation_exit` 三条 HIGH 事件；模拟期间请求级审计把真实操作人绑成 admin（`impersonatedBy`）。
- 模拟不跨应用重启：启动即清理残留模拟键。

## 关键约束与取舍

- **不加新权限点**：严格 superAdmin-only，superAdmin 本就绕过权限校验，新增 `impersonation:*` 权限点对超管无意义也无法做 kill-switch。复用既有 `authorization:manage and principal.superAdmin` 守卫。
- **前端会话模型（Option iii）**：模拟时 `sessionProvider.user=目标`、`actor=admin` 旁置。路由守卫 / 工作台卡片 / 内联 `can()` 全部 watch `sessionProvider` → 自动按目标重算，几乎零散点改动。admin 真实令牌存独立 secure_storage 键，全程不动。
- **`AuthInterceptor` 凭证路由**（最高风险）：管理端点（`/admin/impersonation/*` 除 `end`）始终带 admin token；业务请求在模拟激活时带模拟 token。模拟 token 401 时**退出模拟、恢复 admin**，不刷新、不登出 admin 主会话。
- **只读的边界**：只读验证「能看到什么」（显隐 + 数据范围 + 脱敏），**不**验证「写了是否真生效」——后者由权限管理页配置 + 后端单测另行覆盖。前端**不**因只读而 hide 写按钮（否则无法验证目标是否看得到该按钮）；点了写操作由后端 403 兜底 + 前端 toast。
- **`/end` 不作 JWT 吊销**：模拟 token 为无状态 JWT，`/end` 只记审计、不 denylist。可接受——token 只读、≤15 分钟、不签发 refresh。被盗 token 最多以目标身份读 ≤15 分钟。
- **实现注意（边界清理）**：模拟状态在所有会话边界清空——冷启动 **await** 清理后再恢复（防 `/auth/me` 抢跑串号）；会话失效 / 登录 / 改密 / 登出均清。模拟 token 到期仅清目标 token、保留模式窗口（窗口内仍可免密切换）；显式退出才彻底清。
