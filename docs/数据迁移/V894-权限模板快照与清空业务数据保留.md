# V894: 权限模板快照与清空业务数据保留

新增 `permission_templates`，保存模板名称、说明、权限码 JSON 数组、单调版本、创建/更新人和删除标记。名称在未删除集合中忽略大小写和首尾空白保持唯一。版本守卫要求每次更新递增一次，禁止物理删除和复活删除记录。

模板是管理员维护的操作权限快照，没有员工关联或角色成员表，不修改既有授权。权限应用仍由现有中央个人覆盖服务执行，涉及目录策略、必需依赖、差量预览、敏感项确认、step-up、旧会话失效和授权审计。

新表登记 FULL 授权行审计，并向 `business_data_reset()` 的现有分类清单增加 `permission_templates/PRESERVE`。迁移仅扩充清单，不执行清空，不推进授权 epoch，不修改已有权限或账号状态。

前向执行本迁移，不编辑任何已应用迁移，不使用 `flyway repair` 隐藏漂移。业务与安全决策见 [ADR-187](../99-决策记录-ADR/ADR-187-权限模板作为可预览的授权快照.md)；源码验证、目标库执行及发布验收分别记录。
