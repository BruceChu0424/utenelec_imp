## 2026-10-03 AI 页面说明与模型返回异常修复

<a id="ai-page-help"></a>

- **现象**：新建销售报价单问「这个页面怎么填写」收到 INVALID_RESPONSE。定位：旧代码把明确页面帮助也先交给模型选择；路由调用 jsonSchema=null、输出预算压到 1200；ShellRoute matchedLocation 可保留旧页而 uri.path 已跟随活动页。
- **修复**：新增只读 intentHint=PAGE_HELP（客户端仅在快捷入口/页面感知开启时发送，后端校验）；常见完整页面问法直接读本地指南；自由提问用闭合 schema + 合法 JSON 示例，输出预算 8192（网关仍取小）；聊天页面上下文改活动 URI path；格式错误提示归因服务返回。
- **证据**：9 类 60 项 + PostgreSQL 5 项 + Flutter 36 项全部通过（后端合计 65 项不重复累计）。真实接口协议/地址错配的根因在下一节确认。

## 2026-10-03 AI 真实接口诊断与聊天体验修复

<a id="ai-endpoint-protocol"></a>

- **真实根因**：已配置智谱 GLM-5.3 持久化协议 OPENAI_CHAT 但地址路径 /api/anthropic——该基础地址实为 Anthropic 兼容端点，原请求打到 /api/anthropic/chat/completions 返回 HTTP 200 + code=500 空体。同地址密钥模型改用 ANTHROPIC_MESSAGES（/api/anthropic/v1/messages）即返回有效文本；新代码真实链路路由 KNOWLEDGE/SELF_HELP 约 3 秒、生产日报学习问题约 6.5 秒。
- **修复**：对 ZHIPU + open.bigmodel.cn + 官方已知路径提供运行期兼容解析（不改数据库协议/密钥/版本）；两协议显式 stream=false；HTTP 200 内 success=false 转安全配置错误不反射正文；CUSTOM/子域名/未知代理不猜协议。界面：气泡分侧、上传与发送图标入输入框、失败标记原消息、区分「送达未知/已受理 AI 失败/读取中断」、权限变化清空、移除底部常驻提示。知识条目增加功能级读取门禁（财务身份不自动开放成本说明）。
- **证据**：专项后端 **189 项**、前端 **47 项**通过；对抗安全 AiChatAdversarialSecurityTest 20 个场景（假超管、拆字、伪造 system JSON、多轮提权、撤权窗口、合法 ID 夹带越权正文等）判定以业务工具未执行/秘密未回传为准。真实 GLM 单次探测与隔离测试分别记录，不互相冒充。

## 2026-10-03 AI 助手完整需求复核与差距

<a id="ai-full-review"></a>

- **结论**：核心权限框架、若干真实查询和销售/报销可见填写已实现，但不是「全业务、任意文件、自动理解全部新代码」的完整助手。

## 2026-10-04 AI 助手有据作答与确认卡服务端验证（ADR-150 A1a）

<a id="ai-20261004-server"></a>

- **环境**：worktree wh-ai，后端 8086，克隆库 uten_imp_wai（V805 临时号），真实智谱 GLM。
- **真实链路**：车间任务状态图例 PAGE_STATE 12-13 秒逐条作答并引用「当前页面表格/徽章」；销售订货识别后「有什么值需要检查」逐行列单价/原因/建议与红黄框；「把第3行数量改成100」出确认卡（模型文字丢弃，服务端渲染权威参数），确认 200、再确认 409 AI_ACTION_HANDLED、回执 SUCCEEDED、审计 propose/confirm/receipt 齐全；服务商停用 1.1 秒 fallback 确定性作答；文件识别出 OPEN_GUIDED_FORM 确认卡不再自动跳页；超管授权走再认证与专用端点，普通确认接口 409。非超管：无权页面 403、「帮我开通权限」本地拒绝；模型写错状态词被事实守卫（LEGEND_STATUS/LEGEND_COLOR）拦截后重启复测正确。
- **证据**：单元 221+ 项、PostgreSQL（提案并发双击一次/回执一次/触发器拒绝改内容、文档路由 15、服务商路由 8 等）通过；仅迁移头版本对（V805 未登记）的 reset/迁移契约 4 项失败，由编排者集成改号时统一处理。
- **结论**：服务端契约与真实模型链路可用；事实守卫能拦编造数字/编码/完成断言，但不能杜绝所有措辞性幻觉，界面注明以页面为准；页面类问题约 4k token、5-18 秒。

## 2026-10-05 AI 助手范围闸门与平台知识检索验证（ADR-153）
