# V487 工作台根视图顶层进度与分析级事实、段视图零料标志

- 状态：本地源码候选（未部署、未上 CI、未写现有业务库）。
- 类型：纯视图前向迁移（零表、零数据改写、零行为改写）。
- 关联页面：[生产调度工作台](../03-页面/生产调度工作台.md)、[我的车间任务页](../03-页面/我的车间任务页.md)、[生产计划单一键生成与全链路溯源设计](../03-页面/生产计划单一键生成与全链路溯源设计.md)。

## 动机（用户现场口径）

1. 生产调度与进度「进行中」表此前没有可量化进度：数量是文本摘要（计划/报工/FQC/实收拼接），且混入子层执行段——用户要的是**顶层产品（参与分析的销售下单产品）的完工占比进度条**，多张销售单联合分析也只按根产品聚合。
2. 表格里看不到「谁分析的、什么时候分析的」：根视图有 `owner_employee_id` 但不吐姓名，`analyzed_at` 完全没暴露。
3. 「计划详情明明没备料却显示备料完毕·可报工」：零料直制段（主档无 BOM 子件的叶子件，ADR-057 直接自制语义）`material_ready=TRUE` 是**空真**——它不需要领料，不是物料已到齐。状态机没错，是展示层把两种「可开工」混成一个词。

## 变更内容

### 1. `v_production_execution_workbench_roots` 追加五列（列尾追加，既有消费者按名引用不受影响）

| 列 | 来源 | 说明 |
|---|---|---|
| `owner_employee_name` | `employees.full_name`（ANALYSIS=分析 maker；PLAN=计划 maker） | 分析人姓名 |
| `analyzed_at` | `analysis.analyzed_at`（PLAN 根=计划 `created_at`） | 分析时间 |
| `root_planned_qty` / `root_inbound_qty` | 只统计**根分析行**（`parent_analysis_material_id IS NULL` 且 `source_type NOT IN ('MAKE_COMPONENT','SUBCONTRACT_MAKE')`）的计划段 | 子件锚点段、委外前置段的完工不冒充顶层进度 |
| `root_progress_ratio` | `LEAST(inbound, planned)/planned`，无段为 NULL | 顶层完工占比；NULL 不伪装 0% |

### 2. `v_production_execution_workbench_segments` 追加 `zero_material`

`material_requirement_mode = 'ZERO_MATERIAL'` 直通。读侧（车间任务、计划详情执行段、分析产品执行投影）据此把「READY+零料」显示为**「无需领料 · 可开工」**而不是「备料完毕」。

### 3. 不变的东西（刻意）

- V485 的单趟聚合结构与全部既有列语义不变（V487 只追加、不重排）。
- 零料段的报工门禁不变（`reportable` 本就放行零料段）；变的是展示词。
- 服务端 `groups` 端点的 `workshopDepartmentId/sort/order` 查询参数保留兼容——2026-09-06 起「进行中」页不再传（顶部筛选下线），车间任务页新增同款 `workshopDepartmentId` 筛选（超管多车间收敛视角）。

## 配套读侧变更（同批代码）

- `ProductionExecutionWorkbenchService.rootSelect()/groupRow()`、`segmentSelect()/segmentRow()` 增列映射；`ProductionExecutionWorkbenchGroup/Segment` DTO 同步。
- `/production/workshop-tasks/count` 从单一 `count` 扩展为 `count + preparing + readyToReport + inProgress`（与页面顶部分类**互斥**口径：三段相加=总数；徽章与列表同源同范围）。
- `/production/execution-workbench/{rootType}/{rootId}/related-documents` 读权限从仅 `production_execution:overview` 放宽为 `hasAnyAuthority('production_execution:overview','production_plan:view')`——生产计划详情页「本批次关联单据」卡片消费它展示采购/委外单据（行内容仍按各模块数据范围过滤，无权模块 `canOpen=false` 只显示单号）。
- 分析详情 `MaterialView.flowStage`：新增行级流程阶段键（见 `MaterialAnalysisFlowStageService`），BUY/委外沿单据链（下单→财务→收货→IQC→入库）、自制沿计划锚点执行段批量推导——表格「进度/待办」列与服务端单一口径对齐，前端只做词表渲染。
