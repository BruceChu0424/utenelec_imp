# UtenReferencePickerField

源码：`lib/components/inputs/uten_reference_picker_field.dart`。

用于模具关联、组装组件等“输入查找 + 完整选择窗口”的入口。按 `frontend-design` 维护，复用 Uten 输入框、主题、提示和紧凑控件规则。

- 空框提示为字段名称，例如“模具”“组件”。格式和搜索范围说明通过共用 `UtenInputDecoration` 的说明图标展示。
- 输入后经过 300ms 防抖，框下显示最多 8 个近似候选。拼音组合期间不请求接口；新输入、清除、失焦、打开选择窗口立即让旧响应失效。
- 右侧“选择”及候选区“展开分类和筛选”打开完整选择窗口，并携带当前输入。名称、编号、型号、规格、系列等列按实际字段分别查询，多个列条件取交集；日期、数值和状态使用对应控件。
- 输入只负责查找。关联 UUID 只由候选点选、完整窗口确认或显式清除修改；未完成的查找不能把任意文本当作已关联记录。
- 调用方持有 `TextEditingController` 和实际记录身份。单选字段可用 `onEditingDismissed` 恢复上一次已确认的显示名称；取消完整窗口保留原关联。BOM 多选候选仅加入待添加列表，保存仍由原有批量提交完成。
- 键盘上下键选择候选；有显式高亮时回车选中，无高亮时回车打开完整查找窗口；Esc 收起候选。候选不足空间时向上展开，定位使用实际候选高度，支持暗色与放大文字。

## 调用边界

`loadSuggestions` 与完整窗口必须共享相同的权限、分类根、禁用和占位排除以及业务资格。近似候选不是扩大可选范围的入口，也不能绕过 BOM 父级、环路、用量和期间组件规则。

调用方将真实读取边界和业务范围传入 `suggestionScope`，以 `isCurrent` 同步检查旧候选点击；边界变化即使尚未重建也不能继续提交。生产货品页注入 `SensitiveReadBoundary`，模具字段、完整窗口和 BOM 添加框记录读取代数；身份、服务端、权限或父级经历 A→B→A 时，旧请求和旧选择仍失效。纯组件测试可显式使用无边界的虚构数据源，生产调用不省略边界。

模具的“系列 / 分类”来源于模具真实所属分类 `categoryName`。当前数据没有单独系列字段，不新增虚构 `series`。模数/套数即老库 QTY/TQTY（2026-10-19 用户确认口径），完整模具窗口保留分类子树，右侧显示编号、系列分类、名称、位置、制造商和备注。

货品/BOM 完整选择窗口复用 `UtenGoodsPicker` 的七列明细表。专用盘点、库存历史反查等数据源仍使用其授权 API 和原有证据显示，不借此回退到主档全库搜索。
