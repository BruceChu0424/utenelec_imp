# V483 根供料产出账与改量事实账 · 行级审计触发器（窄向前修复）

- 版本：V483（`V483__root_supply_and_qty_change_audit_triggers.sql`）
- 日期：2026-09-05
- 性质：纯前向审计修复；**零表/零列/零数据改写**，只补两个行级审计触发器。

## 背景

[AuditTriggerCoverageMigrationContractTest](../../server/src/test/java/com/uten/imp/migration/AuditTriggerCoverageMigrationContractTest.java)
要求 V396 全量审计清扫之后新建的业务表必须「创建迁移内自带审计触发器，或由更晚的
窄向前迁移补齐」。本轮盘点发现两张漏网：

| 表 | 创建迁移 | 业务定性 |
|---|---|---|
| `preplan_root_output_events` | V478（根供料/产出交接） | 根产品现货交接与合格入库交接的追加式事实账（FULFILL/REVERSE） |
| `sales_order_qty_change_logs` | V482（销售确认后改量） | 财务确认后改量的以前→现在事实账 |

两个创建迁移字节已应用不可改（V478 另有固定字节校验，见 README 前文），按
V429（`production_daily_report_workers`）先例走**窄向前审计修复**。

## 内容

对两表各建一个 `trg_audit_<表名>`：`AFTER INSERT OR UPDATE OR DELETE ... FOR EACH ROW
EXECUTE FUNCTION fn_audit()`（共享脱敏审计函数），前置 `DROP TRIGGER IF EXISTS`
保证幂等重放安全。注册进契约测试 `POST_SWEEP_FORWARD_AUDIT_TABLES`
（表 → 483）。
