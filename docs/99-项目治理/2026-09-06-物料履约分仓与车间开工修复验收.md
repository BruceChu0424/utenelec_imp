# 物料履约、分仓与车间开工修复验收

日期：2026-09-06。范围：本地源码、定向自动化和可丢弃 PostgreSQL 测试库。未提交、未部署，未更新现有业务数据库。

## 修复结果

- 下达采购、委外和车间计划后保留本批需求及实物缺口；待补量独立扣除在途责任。
- 已备数量包含本批已分配的合格物料和已领用覆盖，精确到货不再次相加；安全库存按实际子仓保留。
- 同主仓内按物料选择不同子仓，合格到货保留原分析/物料归属；跨主仓保持公共入库边界。
- 下次收货默认仓复用同货品、颜色、同主仓的最近成功收货事实；每次实际仓留在收货单与既有审计中。
- 子件计划沿原树直属物料取得权益，齐套后按实际子仓生成领料单。一个需求分两仓时分别扣各仓预留，取消出库按原记录恢复。
- 计划明确指定的车间和负责人优先于学习默认，选填的结束日期不阻止开工；READY 直接开工由事务内精确授权和 START 事件保护。
- 未开工不显示或接受报工，报工选择器、服务端写校验与数据库共享任务视图均要求 IN_PROGRESS。
- 历史待料任务可显式重新检查物料；人工暂缓、未领料和其他分析的专属库存都不能绕过。
- 采购/委外“已下达”只读行点击选中时，缺口、下达数量和其余文字统一使用表格实际选中前景色；取消或切换选中恢复原语义颜色。自绘单元格不再把业务复选框集合当作表格单行选中状态。
- 委外任务中心的选中计数及“生成委外订货单”只渲染一组。宽屏/全屏沿表格批量操作槽，窄屏卡片沿现有内容宽度分支；历史未选日期不出现操作组，切换宽窄布局保留选择。

完整规则见 [ADR-073](../99-决策记录-ADR/ADR-073-本批物料履约与同主仓分仓领料.md)。前向迁移为 [V489](../数据迁移/105-V489同主仓物料履约.md)、[V490](../数据迁移/106-V490物料分析全批履约与分批计量.md)、[V491](../数据迁移/107-V491报工必须先显式开工.md)，目录 453 个唯一版本，无重号；旧迁移字节未修改。

数据库场景包括：先下达 WAITING 子件计划再在兄弟子仓合格入库自动 READY；塑料/五金分别领料并开工；同一物料分仓领用、重复点击、取消出库及错误实仓记账拒绝；计划人员及开始日继承、结束日留空直接开工、开工前报工拒绝；固定批次分两次计划分别计料；生命周期按实际入库而非下达完成；安全库存不能被其他仓的可用量代替或重复分配。

更新运行系统需要配套前后端和三份迁移。旧分析通过授权刷新重算，旧 WAITING 工单通过“重新检查物料”核实当前事实。本记录不表示用户当前运行的页面或业务库已经应用修复。
