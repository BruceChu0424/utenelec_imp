# 登录会话生命周期与异地登录提示修复

本轮从 `8937e02d2` 建立独立工作树 `uimp/login-session-lifecycle-20261103`。范围是员工登录、桌面进程关闭和被替换会话通知；没有数据库迁移，不改业务权限、库存、金额或写入重放规则。默认设计技能使用 `frontend-design`，沿用 Uten 弹窗、提示 icon 和等待遮罩。

## 根因与行为

1. Flutter 启动从持久化令牌恢复会话，旧会话已被其他设备替换时，原 `SessionKickNoticeHost` 直接订阅底层失效事件，在还没登录的页面也弹出“当前设备已下线”。现在由 `SessionNotifier` 确认结束的是本次可见登录后才发布提示；启动旧凭据失败只做清理。提示排队到下一帧或已显示后再发生登录，旧提示都不能覆盖新登录。
2. 原在线感知依赖普通请求或 30 秒 `/auth/me`。现在新增认证 JSON 长轮询 `GET /api/auth/session/watch`：仅绑定签名员工会话 sid 和主体，新登录事务提交后唤醒实际被撤销的旧 sid；25 秒无变化返回 active，客户端重新等待。服务端每 2 秒批查作为跨进程、漏事件和普通吊销的兜底。未认证、访客、错误主体不能订阅别人的会话。
3. 桌面关闭原先未结束登录。Flutter 桌面令牌改为进程内存，正常退出先执行原有离开确认、草稿落盘和未知提交保护，再本机登出、持久排撤销队列并最多等待 3 秒远端确认。旧版本落盘的令牌仅排队向原 issuer 注销，不恢复到新进程。WPF 启动同样退役上次进程凭据，主窗口关闭立即本机失效并有界等待注销。

最小化、失焦、切到后台不算关闭。移动端沿用原安全存储和后台语义。Web 保留每标签页 sessionStorage，正常关闭销毁本地会话，普通 F5 保留当前标签页会话；未用统一 beforeunload 登出破坏刷新。浏览器恢复已关闭标签页的策略、断网/断电/强杀时远端立即撤销不可由本机保证；桌面进程重开不会从旧凭据恢复，正常离线退出的撤销由加密队列后续重试。

已替换直接从原始失效事件显示弹窗的实现；旧 30 秒失效探测改为实时监听和旧服务器短探测，保留真人活动续期职责。各业务调用方继续通过既有 AuthInterceptor / SessionCoordinator，不复制登录或失效算法。再认证上下文和被动会话监听隔离，避免模拟身份时监听切换再认证所有者。

## 业务输入与提交保护

扩展业务复核发现即时退出会暴露原有的收尾缺口，因此本轮同步修复，不把“能退出”当成业务完整：

- `FormDraftMixin` 身份退休前同步抓取最后输入，随后立即禁止旧业务操作；本地保全使用退休前签发的 `FormDraftPreservationLease`，固定原服务器、用户、actor、dataset、reset 代、草稿 ID 和版本。它只拥有本机写入能力，不能发业务请求，也不能采用新登录的身份。
- 普通保存与退休保全共用 `FormDraftsNotifier._commitLocalDraft`，继续使用原 `FormDraftStorage` 的原子 CAS、历史和重置隔离。原 writer 的 CAS 即使在身份变化后落定，也先把已提交版本交给原 lease；最后输入又回到已保存值或空基线时，同样等待在途 writer 并保全最终值。
- 已存 Unknown、冻结正文、请求号和回执不能被退休快照推导为“已拒绝”。冲突、已删除或已完成的原记录保持原样，保全副本写为顶层 `lifecycle=RETIRED`，只进入原权限范围的只读历史；普通恢复及日报专用创建/附件恢复入口均拒绝重放。嵌套旧快照继续经过历史白名单投影。
- 存储失败时，独立于页面生命周期保留 detached 输入与退出 checkpoint；准备关闭最多等待 10 秒，超时取消关闭并撤下等待遮罩，实际写入继续保持原状态，晚完成后可重试。初始化的低 generation 恢复不被当作已确认新重置丢弃输入；已确认更高 reset 仍遵守底层 fence。
- WPF 发布页修复退休/Dispose 后跳过草稿保存、后台 SessionChanged 直接触碰控件，以及旧 owner 晚回包继续推进发布的问题。prepare/upload/publish 的晚成功和晚失败保留原 Unknown/编号，不自动推进或重发。存储失败留主窗退出 guard，新重试入口显示平台自有等待窗口并把 DPAPI/磁盘写入放到后台。

Flutter 直接使用公共 mixin 的入口清单与源码摘要见 `evidence/login-session-lifecycle-frontend-20261103.json`。这份清单证明公共入口接线范围，不代表所有页面都完成公司环境实机 UAT。客户端发布 lease 保留 metadata-only 白名单及 raw-CAS 契约差异，仍复用同一物理存储/history/reset 实现；WPF 保留独立 DPAPI/runtime 差异。
