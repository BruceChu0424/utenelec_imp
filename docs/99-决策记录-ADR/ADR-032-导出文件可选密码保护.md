# ADR-032：导出文件可选密码保护

> 日期：2026-08-09 · 状态：已实现，等待本轮完整运行验收 · 取代 [ADR-012](ADR-012-报表加密导出与列排序与行跳源头.md) 中“导出必须设置 6–128 位密码”的部分

## 当前行为

- 用户不填写密码时，下载普通 `.xlsx`。
- 用户填写任意 1–128 位密码时，服务端使用 OOXML Agile AES-256 加密；弱密码也允许。
- 超过 128 位由 Bean Validation 和共享下载服务拒绝。
- 密码保持原值，不 trim；只通过 JSON body 传输，不进入 URL、查询参数、日志或审计内容。
- 登录密码、首登改密和高危操作二次确认继续使用各自的强密码策略，本决策不放宽账号安全。

## 统一实现

- Flutter：`UtenExportButton` 是唯一交互入口，明确提供“直接下载”与“加密下载”。
- 请求：所有导出端点复用 `ExportPasswordRequest`。
- 后端：所有导出端点复用 `WorkbookDownloadService`；禁止各 Controller 自行判断或实现加密。
- 原有独立 `*:export` 权限、频率限制、并发闸门、行数上限、公式注入防护、HTTPS 和审计保持不变。

## 验收矩阵

| 输入 | 预期 |
|---|---|
| 字段缺失、`null`、空字符串 | 普通 Excel 可直接打开 |
| `"1"` 或其它 1–128 位值 | 加密文件只能用原密码打开 |
| 129 位 | 统一参数校验错误 |
| 无导出权限、超频、超行数 | 仍按原安全边界拒绝 |

本 ADR 只记录已经落入统一组件和服务的行为，不把历史测试结果当作本轮运行证据；最终结果以本次验收报告为准。
