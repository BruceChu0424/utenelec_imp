# ADR-190 基本单位日常字段简化

- 日期：2026-10-22
- 状态：源码实现，尚未部署
- 界面技能：`frontend-design`，沿用 Uten 组件与主题

## 决策

日常单位主档按编号、名称、状态同序维护，编号始终位于最前。删除列表、详情、编辑及导出中的计量维度和重量单位，不把技术换算参数当作员工必需填写的资料。列表复用货品的勾选、多选、行菜单及共享悬浮操作组；单条、批量启停与删除均确认，部分失败保留选择并显示原因，权限、身份及未保存编辑守卫继续生效。

库存仍有平行重量账，因此不删除已使用的计量规则。普通更新遗漏计量键时，服务端锁定并保留当前规则；显式计量请求继续执行既有合法性与库存引用保护。新建单位仅在名称精确命中现有 `WeightUnit` 封闭目录时登记标准换算，自定义名称不猜测系数，已有单位不因改名自动重新分类。

这把日常资料和换算规则分开，兼顾简洁及已有业务数据的稳定性。参考 [ERPNext 官方 UoM 文档](https://docs.frappe.io/erpnext/uom) 将单位及换算因子分开保存的做法；本项目仍以自己的数量、重量账和受控换算目录为准。

## 验证

三字段界面、保存不带计量键、旧 MASS/KG 规则保留、新标准单位识别、导出列集及既有库存引用守卫分别验证。没有重写已应用迁移，也没有修改存量库存或流水。
