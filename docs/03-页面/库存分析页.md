# 库存分析页

> 路由：`/warehouse/insights?segment=health|cycle-count|weight-alerts|learning`(`lib/features/warehouse/pages/warehouse_insight_page.dart`)
> 权限：`stock_report:view`(与仓库报表同级；供应商短重排名属于报表级数据) · 页面权限面 `warehouse.report`
> 上层：仓库管理 hub → 「库存查询」分区「库存分析」卡 · 决策：[ADR-135](../99-决策记录-ADR/ADR-135-仓库重量账与单重自学习.md) §3.4 / §3.5
> **创建日期**：2026-09-28 · **状态**：源码候选(本地定向测试；真实数据量下的查询耗时未测，见 §八)

## 一、定位

给仓库主管和 PMC 看的「仓库智能」页：哪些货压着不动、今天该盘哪些、称重暴露出哪些数量问题、哪些货品的单重还没学准。
所有数字服务端算好(一次查询一个范围，排序、分页、合计在服务端内存完成，业务日期取服务端 `BusinessTime.today()`)，页面只展示与跳转，不改任何库存。

## 二、入口与导航

- 进入：仓库管理 hub「库存查询」分区「库存分析」卡(只对持有 `stock_report:view` 的账号显示)。
- `?segment=` 直达分段(认不出回落「呆滞与库龄」)；KPI 卡点击也会切到对应分段并带上筛选。
- 行内「查看流水」「查看单重学习」打开[库存详情页](库存详情页.md) `?tab=ledger` / `?tab=weight`(需 `stock:view`，无权时提示)；
  「盘点建议」的「生成盘点单」打开新建盘点页(见[仓库单据编辑页](仓库单据编辑页.md) §三)。
- 离开：返回仓库管理 hub。

```
│ 分段表格(MasterDataTableView，服务端分页) + 合计条 / 悬浮按钮        │

```

- 2026-10-05 起([ADR-149](../99-决策记录-ADR/ADR-149-仓库数据范围服务端强制.md))：范围由服务端按本人仓库数据范围强制，选择器只对主管与多仓负责人出现(右侧滑窗)，选了仓带 `scopeWarehouseId`(越界 403)；下面「我的仓库(`warehouseScope=MINE`)」一档已删除。
- AppBar 复用任务中心的 `WarehouseScopeSelector`(`warehouse.taskScope` 记忆)：全部仓库(不带参数) / 我的仓库(`warehouseScope=MINE`) /
  指定仓库(`warehouseId`，含下级仓)。只作用于「呆滞与库龄」「盘点建议」。
- 默认范围 = 参与核算、非线边仓、未删除的仓库；显式选中单个仓库时按该仓精确统计(线边仓也算)；选主仓时只统计其下参与核算的非线边子仓。
- KPI 卡在窄屏单行横向滚动，不折行挤占表格高度。重量统一用 `WeightText` 口径(≈ 估算、未称、按「重量单位」显示偏好换算)。

| 卡片 | 取数 | 点击 |

## 五、四个分段

### 5.1 呆滞与库龄(`GET /api/stock/insights/health`)

- 筛选：搜索货品名称/编号、「仅呆滞」「库龄>180天」、ABC(A/B/C)；表头排序走服务端(`sort` + `order`)。
- 列：货品 | 编号 | 颜色 | 库存数量(单位内联) | 库存重量 | 最后入库 | 最后消耗 | 呆滞天数 | 0-30天 | 31-90天 | 91-180天 | 181-365天 | 超365天 |
  期初(无入库记录) | 近90天消耗 | 日均消耗 | 可用天数 | ABC | 库存金额(仅 `goods:cost:view`，无权时不下发、按金额排序返回 403)。
- 2026-10-10（全站表格 T9 口径）：独立「单位」列删除，「库存数量」单位直接跟在数字后（`formatQtyWithUnit`，
  保留 4 位小数、不再做千分位分组）；库龄分层 / 近90天消耗与库存数量同单位，沿用货品行单位。
- 合计条：服务端 `totals`(`qty` 按单位分组、`weightKg` 与 `weightKg_unknown_rows` / `weightKg_estimated_rows`、`out90`，有成本权限时 `amountLocal`)。
- 口径(`WarehouseInsightDefinitions`，纯函数有单测)：
  - 库龄：先进先出分层，入库类型 {1,4,9,11,13,17}(调入 7 只在对应调出腿不在范围内时算)，红冲按来源行冲减；分不到入库层的量记「期初(无入库记录)」。
  - 消耗：类型 {3,5,12,14,15,20} + 调出到范围外的 8；日均消耗 = 近 90 天消耗 / 90；可用天数 = 库存 / 日均(近 90 天无消耗不给)。
  - ABC：按近 90 天出库次数(红冲冲减)在所选范围全部货品里倒序排名，累计 < 80% 为 A、< 95% 为 B、其余 C，没有出库为 N。
  - 呆滞：有库存、近 90 天没有消耗、而且仍有存量的最新入库批次早于 90 天(没有入库记录视为很早)。
  - 最后消耗只回看 365 天。
- 行菜单 / 双击：查看流水(库存详情 `?tab=ledger`)、查看单重学习(`?tab=weight`)。

### 5.2 盘点建议(`GET /api/stock/insights/cycle-count`)

- 按「仓库 × 货品 × 颜色」出行(与盘点单明细同粒度)。列：货品 | 编号 | 颜色 | 仓库 | ABC | 上次盘点 | 距今(天) | 原因 | 优先级 | 库存数量(单位内联，2026-10-10 起统一走 `formatQtyWithUnit`) | 库存重量。
- 上次盘点 = 该仓该货品该颜色最近一张已审盘点单的单据日期(盘点无差异不产生流水，所以不看流水)；从未盘过按第一笔流水日期起算。
  周期按货品 ABC：A 30 天 / B 90 天 / C、N 180 天。
- 优先级分 = 到期比例 + 近期重量尾差 0.5 + 重量为估算 0.3 + 重量未知 0.3 + 近 30 天有动态却单重未学准 0.5；到期或有加分才建议；
  页面按分数分高(≥2) / 中(≥1) / 低。原因标签：到期、近期尾差、重量为估算、重量未称、单重未学准。
- 默认每仓每天最多 20 条(「每仓每天最多 20 条, 按优先级排」)，`showAll=true` 取消上限。
- 可勾选；右下悬浮「生成盘点单(N)」：按仓库分组，多仓时先选先盘哪个仓，然后打开 `/warehouse/CHECK/new` 并经 `extra` 传
  `StockCheckPrefill`(仓库 + 货品 + 颜色，只预填、不保存；实盘数量现场填)。该仓的行取消勾选，其余仓的勾选保留，回来接着生成。
  没有新建盘点单权限时按钮置灰并说明(按路由守卫同源判断，不写权限码字面量)。

### 5.3 称重异常(`GET /api/stock/insights/weight-alerts?days=`)

- 时间：近7天 / 近30天(默认) / 近90天。来源：称重观测里 `alert_level` 不是 NONE、仍有效且未排除的记录(按记录当时的应称重量、偏差、容差快照)，
  加上单重学习检测到的换批 / 换料(`goods_weight_estimates.regime_changed_at` 落在窗口内)。
- 列：日期 | 类型 | 货品 | 供应商或车间 | 单号 | 登记数量 | 称重折算 | 偏差 | 依据可靠度。类型：来料少数 / 来料多数 / 领料超发 / 领料少发 / 退料不符 /
  盘点差异 / 产成品数量不符 / 入库数量不符 / 出库数量不符 / 称样偏差 / 单重可能已变化(换批/换料?)。偏差按件数和百分比表达。
- 单号在有权打开来源单据时可点(仓库单据按 `sourceDocCode`，采购收货、委外进仓、委外出仓、销售出货按来源类型)。
- 「按往来方汇总」切换为汇总表：往来方 | 类别 | 次数 | 异常次数 | 平均偏差 | 差额重量(供应商来料少数与车间领料超发，与明细同一时间窗，各最多 50 条)。

### 5.4 单重学习(`GET /api/stock/insights/learning?filter=`)

- 用途：上线初期批量称样录入、需称样清单、与货品资料设计单重不一致清单。表头显示「称重覆盖率 N% (库存行重量为实称的占比)」。
- 筛选：需称样(默认：近 90 天有动态但没有学习结果、可靠度红或称重矛盾；按重量计的货品、有人工单重的、关闭学习的除外) / 与设计单重不符 /
  仅按领料推算 / 称重矛盾 / 全部；搜索货品名称/编号。
- 列：货品 | 编号 | 单位 | 当前单重 | 可靠度 | 依据 | 设计单重 | 与设计差异 | 最近称重 | 抽样数量 | 抽样重量(g) | 保存。
  抽样重量单位取账号的「抽样单位」偏好(默认克)；按件计的单位抽样数量必须是整数。
- 「保存」→ `POST /api/stock/weight/goods/{goodsId}/samples`(净重 + 单位，幂等键重试稳定)，成功后用返回的单重详情刷新本行；
  需要称样权限(`warehouse_inbound:stock_in` / `stock_doc:edit` / `stock:weight:manage` 任一)。
  行菜单「称样校准…」打开完整[称样校准弹窗](../02-组件库/WeighCountDialog.md)(供应商、皮重、新批次)。

## 六、接口与权限

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /api/stock/insights/health` | `stock_report:view` | `scopeWarehouseId`(ADR-149，取代 `warehouseId` / `warehouseScope`) / `categoryId` / `keyword` / `abc` / `onlyDead` / `agedOver180` / `page` / `size` / `sort` / `order`；返回 `{overview, items, page, size, total, totalPages, totals}` |
| `GET /api/stock/insights/cycle-count` | `stock_report:view` | `scopeWarehouseId`(ADR-149) / `showAll` / `page` / `size` |
| `GET /api/stock/insights/weight-alerts` | `stock_report:view` | `days` / `kind` / `supplierId` / `page` / `size`；另返回 `supplierSummary`、`workshopSummary` |
| `GET /api/stock/insights/learning` | `stock_report:view` | `filter` / `keyword` / `page` / `size`；每行按与 `/api/stock/weight/params` 相同的解析口径给当前单重 |
| `GET /api/stock/insights/goods/{goodsId}` | `stock:view` | 货品级 KPI(库存详情 / 货品详情顶部指标条用)，不含供应商级数字 |

- 金额字段只在持有 `goods:cost:view` 时下发。页面不写 `Perm` 字面量，按钮可用性走路由守卫同源判断与 `weightSampleAllowedProvider`。
- 审计：服务端 `AuditEventInterpreter` 把 `/api/stock/insights` 记为「仓库 · 库存分析」。
