# 销售订货单编辑页

> 路由：`/sales/orders/new`(新建)、`/sales/orders/:id/edit`(编辑)
> 别名：新建订货单、开订单、下订单、录订单、改订单、销售订单

## 一、定位

销售业务员录入客户订货的页面：客户、货品、数量、交货日期和商业条款。订货单是正式销售单据，单价不能在这里改；需要和客户议价的，先做[销售报价单](销售报价单编辑页.md)，财务核价、客户同意后再转成订货单。

这个页面只负责「填写和保存」。保存后的订货单是草稿，要在订单详情页点「审核」，系统才为它留出现货并送财务确认；财务确认后计划部才能看到并安排生产。

## 二、入口与导航

- 销售管理首页「新建单据」里的「新建销售订货单」，直接进入新建页。
- 报价详情点「转订货单」：系统生成订货单草稿并打开本页，报价核定的单价和折扣已经带入。
- 订货单详情：草稿点「编辑」；已审核或被财务退回的订单点「修改订单」。
- 新建页右上角「草稿(N)」打开订货单列表的草稿分段。
- 保存成功后进入这张订货单的详情页，在详情页继续「审核」。

## 三、响应式布局

- 手机：表头字段排成一列，明细表格可以左右滑动。
- 平板和电脑：表头字段按宽度排成多列；明细表格在下面，可以在「表头设置」里选显示哪些列、拖动排序。
- 保存按钮在右下角的悬浮操作区。

## 四、涉及的 Uten 组件

- 可编辑明细表格(与报价单、出货单共用；支持表头设置、勾选行和右键菜单)；
- 客户选择、员工选择(业务员)、下拉选择、日期选择；
- 「附件」区：放合同、客户确认件和图片，也是识别客户文件的入口；
- 明细下方的合计条：合计数量按单位分开显示，不同单位不相加。

## 五、功能点

### 5.1 表头

| 字段 | 说明 |
|---|---|
| 单据号 | 保存后系统自动生成 |
| 单据日期 | 开单日期 |
| 客户 | 必填；只能选分给你的客户。选好后自动带出客户资料里的默认结账方式、发运策略和币种(黄框，可以改) |
| 币种、税率(%) | 币种必填 |
| 结账方式 | 必填 |
| 业务员 | 必填，默认是你自己 |
| 交货日期 | 必填 |
| 合同号、签约地点 | 选填 |
| 发运策略 | 必填：「允许分批发货」或「整单齐套后发货」 |
| 备注 | 选填 |

### 5.2 明细

- 默认显示货品名称、英文名称、编号、颜色、数量、单位、单价、折扣、金额、备注；从客户文件识别来的行，有值时另显示文件型号、文件品名、文件单价。
- **单价不能改**：「单价由货品资料或来源单据带入，并由服务端锁定，不可在订货单修改。」复制出来的新行单价是空的，要重新选择货品取得当前价格。
- **折扣**填小数：1 是不打折，0.9 是九折；必须大于 0 且不大于 1，最多四位小数。
- **报价转来的行**：折扣只读，后面标「(报价核定)」；要改价请重新打开报价。换成别的货品后，这一行不再按报价的单价和折扣，保存时按货品标价重新计算。
- **数量**：「按本行单位填写客户订购数量。财务正在审核时不能修改；财务通过后再改会重新送审。」
- 没有价格查看权限的账号，单价、折扣和金额显示为「***」。

### 5.3 识别客户文件

1. 在「附件」区拖入或点击添加客户的订单文件，在文件卡上点「AI识别」；有两份以上待识别的文件时可以点「批量识别」。
2. 系统读出客户和明细填进页面。明细里已经有识别结果时再识别，会问你用新结果覆盖还是追加在后面。
3. 只有把握足够的货品才自动对应，其余行标黄，请逐行核对后再保存。价格从不取自文件。
4. 文件里有还没标价、或文件单价高于标价的货品时，订货单不能直接导入这些货品，提示「订货单不能直接导入这些货品, 要先做报价单交给财务定价。」，可以点「改为新建报价单」。
5. 系统发现这个文件可能已经录过时会提示「这个文件可能已经录过」，并列出是哪张单。
6. PDF 和图片要整份发给 AI 服务识别时，会先弹出提示请你确认。
7. 只能在新建或编辑草稿时识别。没有「使用 AI 识别客户文件」权限、或系统没有配置 AI 服务时，只按固定规则识别常见格式的 Excel。
8. 保存成功后，系统会记住客户对货品的叫法，下次识别更准；价格和折扣不会被学习。

### 5.4 保存

1. 点右下角「保存」，先检查必填项，没填的显示红框并阻止保存。
2. 再检查重复货品：同一货品、颜色、单位、换算率、折扣和文件单价都相同的行算重复，弹出「发现重复货品」，可以选「汇总合并」「删除重复行」(各行内容完全一致时才有)或「返回修改」(重复行整行标红)。
3. 新建保存成功提示「已创建」，进入订单详情；「附件」区的文件随后逐个上传，失败的留在页面可以重试，再点保存不会重复建单。
4. 草稿不占库存。

### 5.5 审核和送财务(在订单详情页)

- 在详情页点「审核」(需要「审核销售订货单」权限)，系统同时为订单留出现货并送财务确认；别人正在审核时按钮显示「他人审核中」。
- 财务在「销售订单财务确认」里确认后，订单才对计划部可见并进入排产。
- 销售审核不是财务审核，也不扣实物库存、不形成正式应收。

### 5.6 修改已审核订单

- 财务没有在审核时，可以点「修改订单」进入本页修改。页面提示「保存后将重新提交财务审核，并保留修改前后内容。财务正在审核时不可修改；已有排产、出货或资金事实的订单，请使用改量或先处理关联业务。」保存后提示「修改已保存，已重新提交财务审核」。
- 只改数量的，可以在详情页用「改量」，改完自动重新送财务确认。
- 被财务退回时，页面顶部显示「财务驳回，正在修订」和退回原因；保存后订单转为草稿，要重新审核，系统再提交财务确认。

## 六、功能链路图

1. 新建(或报价「转订货单」) → 填表头和明细 → 保存，得到草稿。
2. 订单详情「审核」 → 留出现货、送财务确认。
3. 财务确认 → 计划部可见，进入物料分析和排产。
4. 财务退回 → 「修改订单」修订 → 保存后转草稿 → 重新审核。
5. 已确认后「修改订单」或「改量」 → 重新送财务确认。

## 七、涉及的数据实体

销售订货单：单头(客户、币种、结账方式、业务员、交货日期、发运策略、合同信息)和明细(货品、颜色、数量、单位、单价、折扣、金额、备注)；来源报价；附件。

## 八、权限要求

- 新建需要「新增销售订货单」，编辑草稿需要「编辑销售订货单草稿」，审核需要「审核销售订货单」，审核后改数量需要「修改销售订货数量」。
- 业务员只看得到分给自己的客户；没有负责人的客户，业务员看不到也选不到。
- 单价、折扣和金额只有有价格查看权限的账号才看得到。

## 九、边界情况

- 打不开或加载失败：显示「销售订货单加载失败」和原因，「当前未加载任何可编辑数据。请重试，或使用左上角返回按钮退出编辑。」
- 某行没选货品：「第 N 行明细：请选择货品」。
- 折扣写错：「第 N 行明细：折扣须大于 0 且不大于 1，最多四位小数(1=原价，0.9=9折)」。
- 复制来的行没有单价：「第 N 行是复制的新订货明细，请重新选择货品以取得当前主档单价」。
- 保存中显示「正在处理销售订货单」，请勿重复提交或离开本页。
- 服务端拒绝保存时，页面如实显示拒绝原因。

## 十、常见问题

### 订货单上的单价为什么改不了

订货单锁价：单价来自货品资料或已核价的报价，服务端也会按这个价格重新计算金额。需要给客户特别的价格，先做销售报价单，财务核价、客户同意后再转订货单。

### 保存了，财务为什么看不到

保存只得到草稿。请到订单详情点「审核」，系统才会送财务确认。

### 客户文件里的货品没有标价怎么办

订货单不能直接导入没标价(或文件单价高于标价)的货品。点「改为新建报价单」，用同一次识别结果做报价单交财务定价，核价、客户同意后再转订货单。

### 被财务退回了怎么改

在订单详情点「修改订单」，按页面顶部的退回原因修改后保存；订单会转为草稿，再点「审核」重新送财务。
