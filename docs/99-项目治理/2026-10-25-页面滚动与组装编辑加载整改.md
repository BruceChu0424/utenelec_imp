# 2026-10-25 页面滚动与组装编辑加载整改

本次按 `frontend-design` 处理界面，沿用 Uten 主题、字体、组件和业务权限规则。改动覆盖滚动公共组件、版本对照、历史筛选、组装编辑及任务工作台加载；本地源码修改与服务器安装分开记录。

## 全页面滚动入口检查

扫描 `lib` 中全部 235 个页面源文件，以及公共组件和各模块内的滚动部件：共有 289 个含滚动构造的源文件、406 处滚动构造(包括横向滚动和分页视图)，178 个共用表格使用文件、22 个单据页面滚动条使用文件。完整清单为 `build/scroll-loading-audit-20261025/page-scroll-inventory.json`。

原全局 `UtenScrollBehavior.buildScrollbar` 无条件返回 child，导致普通详情、列表、网格和表单没有自动滚动条。单据公共包装和主档表格另有“表头未置顶先隐藏”的旧规则。本次统一为内容超出对应视口即提供竖向滚动条，支持直接拖动；短内容由实际滚动范围自动隐藏。

- 普通页面统一由 `UtenScrollBehavior` 提供，不要求每个页面重复声明控制器。
- 共享 PrimaryScrollController 时，自动滚动条按当前 ScrollPosition 独立驱动，避免多位置断言或拖动一个面板影响另一个。
- 已显式包住同控制器的 RawScrollbar/Scrollbar 不重复添加；覆盖层用 `UtenScrollbarOwnerScope` 声明所有权。
- 主档表格及单据页面保留已有内容滚动条和底部操作区让位；不再等待表头置顶。横轴通知不能污染竖向滑块。
- 长确认弹窗复用相同所有权与位置隔离规则。版本详情仅对自己拥有覆盖层的视口关闭自动包装。
- 逐一核对显式滚动条例外：压缩包预览和生产优先级列表移除未绑定控制器的旧包装；宽 CSV 预览使用独立横/竖控制器，竖条固定在可见视口右缘，未横滚到画布末端也能直接拖动。

该清单是源码范围检查，并不表示已用真实账号逐一打开全部页面。

## 版本详情与历史筛选

版本详情原每行重复前后标签、间距较大。桌面改为共享“字段 / 修改前 / 修改后”表头和紧凑数据行，修改后使用主题轻底色与强调色；顶部保留身份、操作摘要及恢复限制。窄屏及大字号使用完整前后值的纵向布局。

搜索匹配字段名、修改前值和修改后值，300ms 防抖并保护中文输入法组合输入。筛选只改变展示，恢复仍提交完整版本快照。修改历史“当前资料”改为与相邻工具栏按钮相同高度和中线的可删除筛选控件。

## 组装编辑稳定性与退出

原单元格 build 会逐组件请求整个子 BOM；每个回执 setState 重建全表，列定义也随之重复创建。选中、滚动和页面恢复会放大这一过程。

父编辑快照改为附带直接组件的紧凑主档数据，每批至多查询 250 个 ID，并保留可见/可写范围。读取直接组件不会递归读取其 BOM。进入编辑及展开时统一准备主档控件后再显示，单元格渲染不发请求；缓存列定义，并在编辑期间保留草稿快照，不因生命周期或宿主刷新重拉。

底部入口统一“退出编辑模式”，有修改时继续使用保存、丢弃、继续编辑的决定流程。顶栏返回显式等待该流程，系统返回继续受 PopScope 保护；现有货品的 BOM 会话单独注册页面键绑定的路由退出守卫，覆盖 go、替换和浏览器路由退出。确认保存失败不能退出。三种语言的相关文案同步更新。

## 首屏加载

采购、委外及仓库任务工作台原未选阶段也读取完整列表(size=1)，仍执行行、合计、状态、异常、待办和全部筛选桶等查询；仓库名称字典还阻塞业务结果发布。

新增同权限、同仓库范围的概览读取：入口只做一次分组聚合，不取历史明细、排序或表格筛选桶；用户选择阶段后再读取对应列表。辅助仓库名后台补齐，不阻塞已有随行名称的显示。

采购汇总报表先取业务结果，空结果不请求字典；有数据只补所需货品、供应商和颜色。其他已在后台解析名称的单据详情保持既有流程。认证刷新等必要串行路径保持原语义。

生产计划空列表不请求字典；有数据先显示随行车间与跟单员名称，部门筛选桶和缺失姓名后台补齐，并保留同读者回写护栏。预计到货只取供应商字典，到货异常只取供应商和仓库，产成品入库只取仓库，移除无关字典请求。

入口源码检查未发现全局普通业务 GET 串行队列或统一全字典预加载；四个主 Tab 按首次访问挂载。工作台的真实数据库聚合耗时仍需安装后测量。
