# V480 · 委外=自制同构直下的进度查询索引

> 2026-09-05。纯前向索引迁移，无数据改写、无权限码、无默认 grant。

## 背景

委外准备中心·分析来源页签（`/subcontract/preparations`）自 2026-09-05 起：

1. 委外部从「下达委外」一刻起参与跟踪（此前 V458 口径为成品入库前不参与）；
2. 新增「车间进度」列——服务端 `SubcontractMakeTaskService.tasks()` 按委托行
   （`production_plans.material_analysis_item_id = preplan_subcontract_make_tasks.preparation_item_id`）
   聚合 `production_execution_segments` 状态：`NOTIFYING_WORKSHOP → WAITING_MATERIALS →
   IN_PRODUCTION → PRODUCED → FULLY_NOTIFIED`。

## 变更

`production_plans` 此前没有 `material_analysis_item_id` 的索引，数据量增大后上述 LATERAL
逐行回表会退化为顺序扫描。补**部分索引**（仅未删除计划行，体量小、写入代价低）：

```sql
CREATE INDEX IF NOT EXISTS idx_production_plans_analysis_item
    ON production_plans(material_analysis_item_id)
    WHERE material_analysis_item_id IS NOT NULL AND is_deleted = FALSE;
```

同时服务端把该 LATERAL 只挂在列表查询（每页 ≤100 行），计数查询不挂，避免大表全量展开。
