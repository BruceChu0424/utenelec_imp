## 已证根因与共享修正

V942 的 Native 授权触发器以 TG_ARGV 声明权威列，却在这些列未变的普通数量、进度和主档学习更新上仍逐行进入回调。V1106 从实际 catalog 的同一列声明生成 NULL-safe UPDATE WHEN，INSERT/DELETE 仍原样发布；原域参数、ALWAYS/REPLICA/DISABLED/普通模式和注释保留。新建触发器继续走唯一 migration-owner `fn_refresh_native_scope_update_gates()` 维护入口，runtime 无 DDL 权限。没有缓存用户、授权、来源或事务证明。

摘要写入器原来把同一语句的每个域分成独立 INSERT，并对每行重复完全相同的 metadata owner 检查。现在将确实缺失的本事务域键一次 INSERT SELECT；owner 仍由原 `fn_guard_summary_read_metadata` 在每条写语句之前检查，空 UPDATE/DELETE 也拒绝 runtime 伪造。没有把校验搬到不计数 helper，也没有取消 owner 检查、来源事件或改统计口径。真实 marker 行仍是唯一去重证明，savepoint/rollback/compaction 后必须重新发布。
