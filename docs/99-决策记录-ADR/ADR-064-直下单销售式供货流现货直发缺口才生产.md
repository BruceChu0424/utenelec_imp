# ADR-064：直下单销售式供货流——现货直发、缺口才生产（无迁移）

- 日期：2026-09-02
- 状态：已决策；后端/Flutter 为源码候选，真实岗位 UAT 未完成（无 schema 变更，无目标库迁移项）
- 取代范围：ADR-062「V436/V447 已实现的直下单（先订货后前置自制）执行链继续有效」中
  「有子层级一律先自制」的部分。V436 的 DIRECT/MAKE 执行机制、V447 的缺口生产载体
  （SUBCONTRACT_PREPARATION 分析 + entitlement handoff）本身继续有效，只是触发条件收窄。
- 相关：ADR-062、[业务链路 08](../07-业务链路/08-委外全链路-订货出仓回仓重设计.md)、
  [方案与执行计划](../01-规划/2026-09-02-直下单销售式供货流-方案与执行计划.md)

## 一、问题

直接委外订货单（不经物料分析、手工新建）财务批准后，服务端按目标件活动 BOM 分流：
有子层级即整行 `MAKE_THEN_OUTBOUND`（待前置自制），**完全不看仓库现货**。业务后果：

1. 仓库现货充足甚至被本单「看得见却用不上」，仍要求计划员启动前置自制重新生产一遍；
2. 同一张订货单无法「现货部分先发、缺口部分再产」；
3. 计划部只能靠人盯「订货来源页签」发现待产任务，批准时没有缺口定向通知。

用户口径：直下单有子层应与销售同构——审批后判断仓库可用量（足量且未被其他订单
锁定），有货就通知仓库发货，没货或缺少才通知计划部生产。

## 二、决策

### 2.1 批准时按全局可用量拆行（销售 reserveOnApprove 同构）

`SubcontractMaterialPlanService.createPlanOnApproval` 对「有活动 BOM 子层且非 V458
前置谱系」的订货行，先查**全局可用量**（全仓账面 − 安全库存 − 全部生效预留，
`GREATEST(…,0)` 兜底，带货色锁；同单同货多行共享一个递减池防重复占用），然后拆行：

| 可用量 a vs 需求 q | 拆行结果 | 通知 |
|---|---|---|
| a ≥ q | 仅一行 `DIRECT_OUTBOUND`（q，READY） | 仓库 OUTBOUND_READY |
| 0 < a < q | `DIRECT_OUTBOUND`（a，READY）+ `MAKE_THEN_OUTBOUND`（q−a，ACTION_REQUIRED） | 仓库 READY + 计划部 SHORTAGE |
| a = 0 | 仅一行 `MAKE_THEN_OUTBOUND`（q，现状） | 计划部 SHORTAGE |

无子层级（DIRECT）与 V458 前置谱系（PREPARED_OUTBOUND）行为不变。

### 2.2 拆行复用既有执行机制（零新表、零新状态）

- **现货直发行**走 DIRECT 全链：批准即生成无仓出仓草稿 → 仓库选仓原子占用
  （`SUBCONTRACT_OUTBOUND_DRAFT` 预留替换重建）→ 实发消费；建议仓继承订单/申请头，仓库可换仓。
- **缺口行**走 V436 MAKE 全链：START_PREPARATION 一键建 SUBCONTRACT_PREPARATION 分析
  ——分析量取计划行量，拆行后即缺口量；产出经 V447 entitlement handoff 回填
  `prepared_qty` 后进入 V458 分批出仓投影。
- 现货直发行的 `bom_has_children_snapshot` 记 **true**（该货确有子层）：
  ①通过 reserveDraft 的「BOM 审批后变化」一致性断言；②前端据此区分文案。

### 2.3 缺口定向通知（新事件，老事件保留重放兼容）

新增 `EVENT_SUBCONTRACT_PREPARE_SHORTAGE`（ChainNoticeService 常量 + deliverOutboxEvent
switch 双登记 + `SubcontractChainNoticePort` 端口方法）：收件 = SUB_PLAN/DEPT_PROD 部门子树
×（`subcontract_preparation:view`+`:start`）双条件 + 订货 maker；内容带缺口量并说明
现货部分已另行通知仓库。`EVENT_SUBCONTRACT_PREPARATION_REQUIRED` 与其方法保留
（存量 outbox 消息重放），新批准不再发布。

### 2.4 取消/红冲/改量

- 订货红冲/计划关闭：`releasePlanReservations` 按 owner 释放（现货直发行经选仓占用的
  预留同样覆盖），缺口行进行中前置自制的既有守卫（requireOrderReversalAllowed）不变。
- 出仓红冲对称回减 issued_qty，既有逻辑不变。
- 直下单批准后不支持改量（现状边界，未扩大）。

## 三、兼容

- 在途已批准 MAKE_THEN_OUTBOUND 老单照旧走完（不重算、不拆行、不补通知）；
- LEGACY_BOM_COMPONENT 历史行不动；V458 分析谱系链（PREPARED_OUTBOUND）不动；
- 无子层级 DIRECT 行为不变（`bom_has_children_snapshot=false`，前端文案原样）。

## 四、验收要点

批准三态拆行（足量/部分/零库存）、同货多行共享池不超占、现货行 READY 通知仓库、
缺口行 SHORTAGE 通知计划部、缺口建分析量=缺口、产出回填可出仓量、现货直发行选仓
原子占用与 BOM 快照断言通过、出仓实发/红冲、订货红冲释放、在途老单不受影响、
越权与对象范围、通知收件人双条件。
