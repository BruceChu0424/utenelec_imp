## 改了什么

注塑颗粒这类料 (`goods.issue_method = 'PERIODIC'`) 不再按工单领料：仓库整批发到车间内料仓 (原线边仓)，车间随时盘点，两次盘点之间为一期，实际用量 = 期初 + 领入 - 退回 - 其它耗用 - 期末；结算时按已审报工产量 x BOM 单个重量 (理论用量) 的比例分到各成本范围。

### 新列 (goods)

| 列 | 说明 |
|---|---|
| `issue_method` | `ORDER` (默认) / `PERIODIC`；整批领料必须是重量单位 |
| `periodic_cost_basis` | `OWN` 按单重记到产品 / `SHARED` 辅料按主料理论分摊 / `EXPENSE` 记车间费用；只有 PERIODIC 有值 |
| `bulk_package_qty` | 每袋净重 (选填，大于 0) |
| `is_recycled_material` | 是否回收料 (默认否) |

发料方式与分摊方式只能经基础资料的切换服务改：`BEFORE` 触发器要求会话标记 `app.workshop_material_issue_method_switch = on`，提交时的延迟断言 `trg_assert_goods_issue_method_switch` 核对前提 (改为整批领料：全部 BOM 行已是期间边形状、没有未核清的按单需求；改回按工单：内料仓没有库存、没有在做的绑定工单、没有有效认料、未结算期间里没有期间行、流水或理论用量；改分摊方式：没有期间边与认料 (改成辅料或费用时)、内料仓账面为 0 且没有未结算期间的期间行或流水)。

### 全局守卫、开工门与报工截止

- 整批领料的料不能有新的按单需求 (`trg_guard_periodic_goods_demand` / `_upd`)、不能走车间直送 (`trg_guard_periodic_goods_direct_transfer`)。
- 开工门 `trg_workshop_material_start_gate` / `_ins`：NEED_CHOICE 提示先认料，NEED_BIN 提示本车间还没开启整批领料；绑定 `trg_workshop_material_bind_on_start` / `_ins`：按来源段有效料行 (INHERITED) -> 产品期间边 (BOM) -> 有效认料 (CHOICE) 建期间料行，起始日 = max(启用日, 已结算截止日 + 1)，不用开工时钟。
- 报工截止：`trg_wm_report_date_lock_upd` (日报状态、表头日期变化) 与 `trg_wm_report_item_date_lock` / `_upd` (明细新增或改挂段)；只看段绑定的内料仓，不看期间料行的有效区间。
- 内料仓进出与盘点：期间归属守卫 (普通进出只能记进开着的那一期；补录只能记进盘点中或已盘点未结算的那一期，已盘点时同一事务必须更正期间行)；来源核对 (本次登记、已审核的调拨/其它出库单与内料仓一侧流水)；流水视图合计 = 库存余额；内料仓服务登记的单据不能红冲；期间链逐期衔接、状态沿期号不升、恰好一个开着的期间；期间行 (期初 = 上期期末, 领入/退回/其它 = 本期流水, 两条盘点过账净额, 截至本期账面 = 期末)；结算 (分摊合计 = 计入量且恰好一行尾差, 计入 + 损失 = 实际, 理论明细与理论函数双向覆盖, 绑定本仓的段上已审报工都落在期间料行区间内, 有价值节点的分摊行已登记为成本投入)。

### 数据更新、权限与编号

- 自动配置的线边仓改名为"{车间}内料仓"，与运行期同一规则只给重名的追加" ({主仓})"；手工建的不改。权限描述里的"线边仓"改"内料仓"；`warehouses.is_line_side` 与 `stock_movements.movement_type` 注释更新 (新增 21 内料仓盘点耗用、22 内料仓盘盈)。
- 权限 7 个 (模块"仓库管理"、分类"车间内料仓")：`workshop_material:view` (VIEW)、`:issue` (EXECUTE)、`:request` (CREATE)、`:count` (EXECUTE)、`:choose` (EXECUTE)、`:setup` (CONFIGURE, BULK_EXCLUDED + NON_DELEGABLE)、`:reopen` (EXECUTE, INDIVIDUAL_ONLY, 高危)。默认授予：生产部 view/request/count/choose；仓储部 view/issue/count/setup；计划部、财税部 view；撤销结算不授予任何部门。权限面 4 个：`warehouse.workshop-material`、`warehouse.workshop-material-setup`、`production.workshop-material`、`report.workshop-material`。
- 编号命名空间：`WORKSHOP_MATERIAL_ISSUE` (ZL)、`WORKSHOP_MATERIAL_RETURN` (ZT)，按上海日期日流水，全局永久占号 (只挂 INSERT 取号 + 改号拦截)。
