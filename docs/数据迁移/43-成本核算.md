## 二、口径

1. **产品成本汇总**：货品 `source_e` 材料费 + work/make/lacquer/plating/machining/polish/electric/incidental/manage/lost/rent/casing_e 12 项费用 + 标准合计 `total` + 单位成本 `c_total`（25378 货品有值）；
   期间实际单位成本 = 成品入库流水（movement_type=13）`Σamount_local/Σqty` 加权；差异=实际−标准。
2. **附件 15 销售成本核算**（按客户）：E 销售出货金额=出货−退货（`amount_original`）；F 销售成本=Σ(数量×货品 c_total)；
   含工本比率=F/E；管理费 8%=F×8%；销售费用=E×费率（区域含 OEM→1%、含 外贸→6%、其余内销→25%）；税费 10%=E×10%（模板多数行未扣，本表统一算出供参考）；
   运费=NULL（无数据源）；净利润=E−F−管理费−销售费用−税费；净利润率=净利润/E；汇率=MAX(exchange_rate)。
   业务员=clients.emp_id→employees；总监=client_director_v。
3. **附件 7 铜柱加工费**：委外进仓按 加工商+货品 聚合 数量×最新非零单价=金额（keyword 按加工商，如 铜柱车间/黄庆哲；内部车间单据在 suppliers 内）。
4. **附件 7-1 酸洗入库明细**：委外进仓逐行（货品名含「酸洗」或供应商含「铜柱」）：时间/车间/货品/实际总重量/业务数量及单位/单号。
   **已与模板逐项核对一致**（2026-04：80N德式插L/N极 136.4KG/46010、13A-E极插套(酸洗) 51.35KG/38710）。
5. **附件 8 塑料耗用**（车间口径）[2026-09-28 起由 §五 取代, 以下为历史口径]：上月结存 C=累计(领用 DRAW−退料 WDRAW−耗用)；本月领用 D=movement_type 5；退料 E=type 6；
   产品入库耗用 H=成品入库行已登记实际总重量归属（两路：①BOM 组件 qty 占比；②无 BOM 且 goods.material 文本全库唯一命中材料货品名→全额归属；多命中不摊防错配）；空重量不得用 `m_weight × qty` 补造；
   账面结存=C+D−E−H；盘点数=期间最新 CHECK 行 count_qty；差异=盘点−账面；成品占材料比例=H/(C+D)×100。
6. **附件 8-1/8-2/8-3** [2026-09-28 起由 §五 取代, 以下为历史口径]：DRAW/WDRAW/FINISHED_IN 已审行直出；编号列按老视图口径 `g.code-colors.code`（已核对 280501039-15=深灰色 ✓）。
   退料 1219.4=1100+119.4 与模板一致 ✓。

## 三、已知局限（文档化）

- [2026-09-28 起不再适用, 见 §五] 附件 8「上月结存/账面结存」为**累计车间口径推算值**，老数据 BOM 稀疏（2495 个入库成品仅 ~76 行有 BOM），历史耗用摊不全，
  累计会漂移（模板手工数与系统推算不可比）；**本月领用/退料/产品入库明细为精确值**。随新数据 BOM 完善，口径自动收敛。
- V181 清理的是**当前** `goods_bom_items` 的 stub 误接边，不回写 `production_plan_costs`、历史入库或既有成本预算；
  因而不能用“活动 stub BOM 已为 0”消除上述历史耗用稀疏限制，也不得据此重算已审核历史成本。
- movement_type 映射已核实：5=DRAW / 6=WDRAW / 7,8=TRANSFER / 9,10=CHECK / 11=OTHER_IN / 12=OTHER_OUT / 13=FINISHED_IN / 14=FINISHED_OUT。
- 「安装挑选不良」「运费」无数据源，列占位 NULL。
- 附件 15 模板公式本身不统一（部分行不算税费/销售费用），本表统一口径并在上文注明。
- 材质唯一匹配探测按材质值去重（~50 值 × ILIKE），塑料耗用单页响应 ~3s。
- 现有通用 `weight` 没有净重/毛重/皮重和重量单位快照；历史空值或异常值必须显式显示缺证，
  不能进入自动补算。重量单位治理、历史补证和按实盘重量调整仍为 **NO-GO**。

## 五、2026-09-28 附件 8 换成车间内料仓结算结果 (ADR-131)

依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md) §7.5 与 §17.4。成品入库不再称重, 原"成品入库重量 × BOM 占比"与"材质文本推断"两条近似口径删除; 颗粒这类料改为整批发到车间内料仓、盘点计耗后, 附件 8 直接读每期结算结果。端点与前端入口不变 (`cost/plastic`、`cost/plastic-detail?kind=issue/return/finished`)。

**出表范围**: 按车间内料仓的期间出表, 只列**已结算**、且**期末日落在所选日期范围内**的期间; 按月查询就是列出期末日落在该月的各期。会计月报前请先让当月的内料仓盘点并结算 (操作顺序要求, 系统不拦)。

**附件 8 列对应** (列名列序保持会计模板原样, 末尾追加三列):

| 原列 | 新数据源 |
|---|---|
| 材料编码 / 材料名称 | 期间料行的料 (名称后接颜色) |
| 上月结存 | 期初实盘 (= 上一期期末) |
| 本月仓库领用 | 本期领入 (仓库发到内料仓) |
| 退料 | 本期退回仓库 |
| 安装挑选不良(待不良数上线) | 恒为 0; 表头直接注明"待不良数上线"。报工不良数上线后 (ADR-129 §2.13) = 不良 × 单个重量 |
| 产品入库数 | 主料: 理论用量 (良品 × BOM 单个重量); 辅料: 按主料理论分到产品的量; 记车间费用的料: 0 |
| 账面结存 | 期初 + 领入 − 退回 − 其它耗用 − 产品入库数 |
| 实际盘点数 | 期末实盘 |
| 差异 | 实际盘点数 − 账面结存 (负数表示多用) |
| 成品占材料比例% | 产品入库数 ÷ 实际用量 × 100 (实际用量大于 0 时才有值) |
| (新增) 其它耗用 | 试模、清机、报废料、其它 |
| (新增) 期间 | 期间起止日 |
| (新增) 内料仓 | 内料仓名 |

**附件 8-1/8-2/8-3**:

- 8-1 领料明细: 仓库发到内料仓的每一笔 (业务日期落在所选范围)。原"订单号"列改名"领料单号", 显示内料仓领料单号; 备注显示内料仓名, 上一期漏录补录的加"上一期漏录补录"。
- 8-2 退料明细: 内料仓退回仓库的每一笔, 编号列仍按"货品编号-颜色编号"。
- 8-3 产品入库明细: 有效结算的理论明细, 每行报工 × 所用的料; 重量 = 理论用量, 数量 = 报工产量, 材质 = 料名, 备注 = 内料仓与期间起止日。

**局限**: 第一期没有不良数, "安装挑选不良"恒 0; 回收料 (水口料) 回掺不记账, 浪费率会偏小; 没结算的期间不出现在附件 8, 看进行中的用量用[车间内料仓用量与结算页](../03-页面/车间内料仓用量与结算页.md)。
