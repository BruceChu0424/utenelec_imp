## 原始证据与根因

真实控制台在2026-11-01 09:37:31.443 UTC记录`Null check operator used on a null value`，发生在人工reload前；不能用新39的JS解释旧frame。通过只读SSH取得旧正式目录`/opt/uten-imp/releases/v2.5.38/web/main.dart.js`，21,083,037字节，SHA256为`e694952e4355208791b36ef8593a318f6d8906db193b470c1c74a012849d76fb`。旧目录SHA256SUMS条目相符，web/version.json绑定`6ea02b2929abae18b0dab76e8f3a35bb756b0c18`。没有source map。旧提交的simple-release.yml与_unsigned-candidate-build.yml均固定Flutter 3.44.2；本机同版本SDK工作区干净。

旧JS逐帧对应：

|---|---|
| 228339 | `WidgetsBinding.handleViewFocusChanged`通知`WidgetsBindingObserver.didChangeViewFocus` |
| 247406 | `_ViewState.didChangeViewFocus`的forward方向调用`findFirstFocus(ignoreCurrentFocus:true)` |

它不是本次已证明的业务State.context!晚回调。调试模式在同源`rendering/object.dart:3675`报`attached`断言；发布模式去掉该assert后在同方法的owner读取报Null-check。`FocusNode.context`仍存在不等于其RenderObject仍attached。

当前238的`UtenWidgetsFlutterBinding`及`ServerMaintenanceView`与旧38对应文件逐字相同。维护宿主在Navigator外使用独立FocusScope。可以在同层FocusScope的RenderObject.detach后、Focus元素deactivate/finalize前同步输入原生forward事件，复现同方法错误；普通route内部两个按钮不能复现这一形状。原生/DOM焦点通知允许同步到达当前帧，几何遍历早于退场元素清理。

发布JS栈没有旧FocusNode的debugLabel，不能从该证据确认具体哪个按钮或组件实例已脱离；维护类同层FocusScope是可复现的触发形状，而不是伪称恢复了当时完整widget树。可明确的是原生方向性聚焦在渲染退场窗口执行了几何遍历，且当前238保留此生命周期缺陷。

原始日志与匹配证据保存在`output/release-2539-resume/browser-transition-console.json`及`browser-transition-v38-evidence/`；本地失败日志`build-view-focus-before.log`保留，不改成成功结果。

## 唯一公共修复入口

`UtenViewFocusEvents`混入现有生产`UtenWidgetsFlutterBinding`。Web和现有Flutter桌面共用bootstrap入口，滚轮坐标换算mixin原样保留。

- 仅当前`SchedulerPhase.persistentCallbacks`收到focused且forward/backward方向时，把原事件延到同帧post-frame，等待`BuildOwner.finalizeTree`先移除退场Focus元素。
- 保存原view ID、事件方向和RenderView身份；每个view只保留最新方向意图。其后失焦、undefined方向或新的稳定事件取消旧意图，其他view事件不取消当前view意图。
- 原View已移除、捕获时无注册RenderView或同ID被新RenderView替代时，旧方向意图失效。回调不持有BuildContext，不访问disposed State，不对新视图重放旧聚焦。
- 稳定帧外方向事件、失焦与undefined方向仍同步交给Flutter。没有catch、异常抑制、FocusNode几何伪值、反复调度空闲帧或全项目mounted补丁。
- 不改维护状态机、子编辑器挂载、业务请求/unknown-submit、权限、数量、来源或键盘业务动作；延迟的是同帧方向性焦点遍历意图。

Win7 WPF使用自己的原生焦点系统，不消费Flutter WidgetsBinding/RenderObject。候选/未完成状态保持原样；不在本任务继续Win7/next UI开发或打包。
