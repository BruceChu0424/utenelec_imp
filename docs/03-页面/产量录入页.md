# 产量录入页（未实施提案）

> 计划路由 `/production/output/entry` 当前没有注册，计划文件
> `production_output_entry_page.dart` 不存在。本页不是现有生产日报录入能力的别名。

## 一、候选目标

车间人员按日期、班次、产线、产品录入合格数、不良数和备注，并查看近期本人记录。是否需要独立
“产量录入”，须先确认现有生产日报能否承载相同数据；禁止同时维护两套权威数量。

## 二、实施前必须决定

- 唯一业务键和重复录入规则；
- 合格、不良、投入、产出的数学关系及单位精度；
- 跨班次/跨日/返工/补录/冲销规则；
- 谁能创建、修改、撤销，撤销是否产生反向记录而非物理删除；
- 与生产计划、库存入库、成本和日报的事务边界；
- 是否真的需要离线。项目当前没有 `OfflineActionQueue`，不能承诺离线自动重放。

## 三、目标 UI

- compact：单列表单 + 服务端分页的近期记录；
- expanded：左表单、右近期记录；
- 组件：`UtenFormGrid`、`UtenDropdownField`、`UtenDateField`、`UtenInput`、
  `UtenActionButton`、`UtenResponsiveGrid`/`UtenPagedGrid`、`UtenNotify`、`UtenEmpty`。

项目没有 `UtenForm`、`UtenDropdown`、`UtenDatePicker`、`UtenListItem` 或独立
`UtenLoading`，不得按旧名称实现。

## 四、数据与安全验收

- [ ] 后端用事务和唯一/检查约束守住数量不变量。
- [ ] 重试有幂等键，不因防连点失效而重复记账。
- [ ] 写、改、撤销有独立权限和审计 before/after。
- [ ] 列表服务端分页、稳定排序，不全量加载长期历史。
- [ ] 与日报、计划、库存及成本口径自动对账。
- [ ] 并发、跨日、负数、小数精度、重复提交和越权测试通过。

**状态**：未排期产品提案；当前生产数据以已落地生产计划/日报模型为准。
