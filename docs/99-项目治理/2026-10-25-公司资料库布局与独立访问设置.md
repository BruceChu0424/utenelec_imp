## 完成的行为

- 删除原白色操作条。上传、新建采用公共右下悬浮按钮；刷新使用公共按钮并位于 AppBar 页面权限入口旁；搜索在功能行右侧，窄屏自然分两行。
- 左侧导航可收起为图标栏，窄屏使用目录抽屉；切换保留搜索、选择及列表。文件画布和详情滚动预留悬浮按钮空间，上传队列整体可滚动。
- 文件区空白右键提供有权限的新建、上传、复制文件、剪切、粘贴、取消剪贴板、详情和刷新；触屏使用“更多”。文件项右键不重复弹菜单，长按拖动保留。
- 复制每次重新核验来源并读取精确原件，再以独立新 owner 走标准上传协议；新名称和访问设置需在弹窗确认。剪切使用最新版本执行移动。文件夹支持移动，未提供递归复制。冲突不会覆盖。
- 新建文件夹、上传确认弹窗可直接指定人员、部门阅读范围及允许/拒绝、继承和可选密码；选定部门包含下级部门。初始设置和创建原子提交，不产生系统授权。创建者仅保留已有合法动作。
- 文件、文件夹都有独立 ACL 和密码。预览、转换预览、下载、附件原件和历史下载使用同一后端保护。已有资料的高级访问设置保留操作细分和本人再认证。
- 公司资料库显示和系统操作资格仍在总权限页/页面权限入口同一 surface 配置，与资料自身的访问设置分开。V931 使入口 view 可撤销，按条件保留原部门范围，不创建个人覆盖；上级部门继承和个人撤销照常生效。
- 导航和身份变化使旧搜索防抖失效；菜单、解锁后续操作、复制准备及弹窗受身份 epoch 保护。切回同一账号不能恢复旧异步操作，剪贴板和私有队列随边界变化清空。
- 创建先检查资料库入口查看资格；管理员恢复访问设置或主动撤销本人阅读权后，若无查看权只返回最小身份/版本回执，不返回文件名、说明、目录结构、附件身份或操作者等元信息。

## 迁移与启用

本轮唯一新迁移是 `V931__company_file_entry_access_and_password.sql`，不改 V925 或既有 Flyway 历史。精确核验旧 CHECK 后允许 FILE 密码，并保持其余状态约束；无法识别的旧约束明确拒绝，整事务回滚。初始密码仅在当前命令内存中参与 HMAC 和 BCrypt，不写日志、明文列、普通可猜测指纹或客户端持久队列；上传预留回执确认后释放初始密码引用。

字节继续使用统一私有附件存储，不新增 Web 静态目录、系统临时文件或第二套上传入口。[已有存储部署合同](../../deploy/company-files/README.zh-CN.md)指定独立媒体文件系统 `/var/lib/uten-imp-media/attachments`，包含挂载/容量/扫描门禁。本轮仅阅读仓库已有核验记录，没有重新认证现役磁盘容量或安装配置。公司服务器启用时需带上 V931，并按原维护窗口流程验证原件上传下载摘要、扫描/转换能力及备份恢复。

安全检查参考 [OWASP 文件上传](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)及[授权检查](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)；项目的统一附件和权限合同仍是实现依据。
