# 货品成本工作台

- 入口：基础资料 → 货品资料 → 货品详情 → 成本预算，深链 `/basicinfo/goods/:id?tab=cost`。
- 决策：[ADR-138](../99-决策记录-ADR/ADR-138-货品成本单与实际成本工作台.md)。数据结构：V753–V756。
- 成本页负责内部成本测算、实际归集核对和下载。销售报价、售价和利润目标留在销售模块。

## 页面与日常操作

页面默认只显示成本表，实际生产与成本依据、历史成本记录收在更多操作，打开后有明确返回成本表入口。成本表是日常核算的主体，员工直接在系统里完成，不要求先在 Excel 做表或导入。材料使用组装树表，名称、编号和单位分列；所有单元格只显示一行。来源、设计/真实量对照和长说明按需查看，不在格内叠上下两行。表格使用可用全宽，窄屏横向浏览，输入控制器跟随稳定 BOM 路径。

2026-09-30 简化：首次打开即可自动带出 BOM 并计算，不以“新建成本单”或填写参数为前提。只读 bootstrap 使用业务日期、本币/汇率 1、真实用量优先及自动取价，匹配有效通用/产品规则。默认按 1 个成品基本单位估算，主页面只读显示“按 N 单位测算”；测算数量在计算设置按需调整。原“本批产量”标签退役，不能让员工误以为要重新录实际生产。客户不猜测，有客户专用费用时再选客户；已有草稿继续恢复，人工输入不会被初始化覆盖。

名称、日期、币种、汇率、取价/用量方式和模板等低频项收在计算设置，导入、复制、模板维护等收在更多操作。修改用量或费用会自动重算；旧请求不能覆盖新输入，重算中和失败后的旧结果明确显示尚未更新。保存草稿仍使用服务端最新输入重算，打开/预览不会自动创建或确认成本单。已存草稿以原输入复算自动来源，变化标未保存；已确认及历史版本保持冻结。

汇总显示已知成本及完整时的单位成本；未知值不能当零。缺价时物料表仍完整显示，只有紧凑待核摘要，对应行标待补价；详细原因按物料名称/编号显示，不能把内部 UUID/BOM 路径铺满页面。物料行成本包含该行费用，费用明细是同一份费用的另一种展示，不重复加总。树父项小计不参与整单合计。

## 与全平台一致的布局和单价格

成本页参照货品组装信息、采购/销售编辑页、生产日报和统一表格规范，不再自建固定比例的头部滚动块和居中底栏。

- 物料及只读明细使用 `UtenCollapsingHeaderScrollView` 配合 `MasterDataTableView(primary: true)`：先收头部，表格置顶后再表内滚；反向先回表首，再展开头部。费用编辑复用 `UtenEditableGrid` 的吸顶/页内滚动机制。
- 设置、客户、费用列、下载和更多操作进入表格工具栏，使用 `UtenTableToolbar.controlHeight`，不在页面顶上另堆一套按钮。主要保存动作使用全站右下角悬浮组和保存样式，遵守底部安全区。
- 汇总通过表格 `summaryBar` / 编辑表 `footer` 的 `UtenTotalsSummaryBar` 展示，不在顶部卡片和底栏重复报合计。横向滚动条、末行及悬浮按钮避让沿公共组件，不能靠固定空白把滚动条推远。
- 列固定、向左/右移动、显隐、拖宽等沿公共表头能力。业务 BOM 顺序和计算层级不被当成列布局一起重排。
- 普通及全屏表格都保留保存、下载和必要操作；切换到其他成本视图或打开表外设置时安全退出全屏。历史数量与金额列右对齐，单元格仍只一行。

草稿里可计价物料的采用单价格统一可直接编辑：可靠来源自动预填并标明来源，员工实际改值后才成为手工调整，聚焦或移动光标不算修改。缺价就在同一单价格补；用量调整保持按需入口。自制汇总节点、按合同不计材料价的客供料及已确认/历史/无编辑权限状态保留只读，并在本行说明原因，不能把结构合计误改成采购单价。

“本批成本/本批金额”统一改为“测算金额”，含义如下；页面与下载采用一致名称：

| 字段 | 含义 |
|---|---|
| 测算数量 | 本次要计算多少个成品，在设置中维护 |
| 采用单价 | 本成本币种下，每个物料基本单位的价格 |
| 计价用量 | 该物料在本次测算中按用量曲线展开后的数量 |
| 测算金额 | 物料材料金额及本行费用之和；汇总节点显示下层汇总 |
| 每成品单位成本 | 该行对一个成品的成本贡献，随成品单位显示“每件/每套成本”等 |

例如测算 1000 件成品，每件用 2 个物料，每个 0.1 元，计价用量是 2000 个，材料金额 200 元；该行另有检验费 20 元，则测算金额 220 元、每件成本贡献 0.22 元。这不是车间已发生的实际归集成本。

## 实际产量自动读取

成本页不用重新输入车间产量。最新生产摘要只读查询本货品最近仍有效且可见的已审报工，定位其生产范围，并沿既有拆批/追加关系汇总同一范围。页面标明工单及报工日期，以“已审有效产量”表达；详细依据列出原已审完成、FQC 回退和另报不良。草稿报工和撤回不算入，返工后的有效量按既有车间进度口径处理，不累计重复的父段显示计数。此轮接线和回归见[单表入口与实际产量记录](../99-项目治理/2026-09-30-成本页单表入口与实际产量自动读取.md)。

数量依据复用 `fn_production_execution_cost_scope` / `fn_production_execution_cost_members` 和 `v_production_execution_workbench_segments.reported_qty`，不另建成本页报工账。不良数沿已审原始报工的独立字段归集，不重复算到分流行或返工来源。原计量单位无法证明一致时明确待核，不用当前主档换算旧数量。没有已审记录时说明暂无记录；查询失败与无记录分开显示。

实际生产数、测算数量和已分摊成本的产出数量分别保留：

| 数量 | 作用 | 维护来源 |
|---|---|---|
| 测算数量 | 将材料、整批固定费用及周期费用折算成这次成本 | 默认每 1 个基本单位，按需修改 |
| 已审有效产量 | 看最近生产范围实际完成情况，成本页只读 | 车间报工、审核、撤回及 FQC 回退 |
| 已估值有效产出数量 | 与同范围已分配实际成本配对计算单位实际成本 | 原生产价值/实物流转及撤回记录 |

车间已经报工但尚未 FQC/点收时仍能显示已审产量，不能因尚无估值对象就显示没有生产。历史累计产量不能自动填成一次测算数量，否则多批固定费用只收一次会压低单位成本。实时生产摘要不回写成本草稿、确认版本或下载快照；确认/历史页面不混入今天的实产数。

## 添加费用价格列

点击“添加费用价格列”，填写或复用费用名称，在对应物料行填价格，金额和汇总自动计算。常规费用默认按物料数量计费，其他算法放高级设置。仍支持每产品、整批固定、百分比和每周期计费；周期数量表示该周期的产出基数。价格、数量/基数、该项金额可以分别选择显示。

- 空白新格默认不适用；明确设为适用但价格待填是缺项。填 0 表示明确零费用，不能与缺失混淆。
- 新增列默认作用于本成本单；保存为模板需独立模板维护权限。
- 隐藏、拖动、改名不改变费用身份与金额。移除费用与隐藏不同，移除前展示确认。
- 费用表编辑价格列生成项时只更新 `priceCells`，不再写一份 `fees`。
- 百分比明确指定基数；依赖缺失、重复基数或循环被拒绝。基数不完整时该费用也不完整。
- 按周期计费必须填写每周期产出基数，例如 26 件、每周期 25 件按 2 个周期计费；缺基数可留草稿但不能确认，不能自动假定只做 1 个周期。数量覆盖仅用于按物料数量/按周期两种方式，其他方式不开放无效数量编辑。
- 自动模板列若已有人工填写或明确待填的单元，模板删列/改算法时保留为本单覆盖；未使用的自动列可以刷新。显式改列后由员工维护。

## 用量与价格

真实用量读 `v_goods_bom_item_usage`，允许使用且有数据时优先采用，否则回到设计值并显示原因。真实净耗已含损耗，不再自动加一次设计损耗；本单改量不改变 BOM 或学习事实。整包/固定批次按本次批量计算。

新单 AUTO 取价先读符合来源、颜色、单位、汇率等条件的已批准采购记录；外购物料无适用采购价时再尝试当天已核定库存参考。委外仅取批准加工价，不能用含材料的整件库存成本再叠加自供料。明确自制但缺 BOM 的物料保持结构待核，不伪装成外购查价。旧单显式选定的策略保持。

批准价默认按原记录价计算，不再要求员工逐料确认同一个默认税口径；有税率不等于含税，不能自动除税。显式不含税换算仍需依据，确认绑定来源行及版本，失效必须复核。原订单含扩展收费/折扣时不把整单金额除数量推广到另一批量，标记待拆分或手工核定。主档记忆价可能来自草稿，不能冒充批准成本；手工价格保留调整原因。

成本计算使用十进制与共享有理数曲线，避免将 0.00007 kg 提前变成 0.0001 kg。业务执行侧原四位取量合同不变；实际过账金额仍由现有价值账负责。

币种切换通过服务端换算并预览结果，保留原输入直到换算成功。外币必须明确提供汇率，不能默认为 1。模板保存原币、原汇率和金额；固定金额按模板币与本单币换算，百分比和数量不变。手填单价编辑器显示每基本单位的归一价格，例如 400 元/25 kg 显示为 16 元/kg，不能把 400 当成每 kg 的单价。

## 草稿、版本和模板

- 本机自动恢复与服务端草稿分开显示。统一草稿入口及货品成本页可继续恢复，恢复时复核当前用户、权限和单据版本。
- 服务端状态为 `DRAFT → CONFIRMED`，确认需独立权限。确认后复制成新草稿，不能覆盖原版。
- 保存使用版本锁和幂等请求号；重复请求不新建，冲突保留输入。确认前来源发生变化时要求重新计算保存。
- 成本单冻结货品/组件/客户名称、计量、价格、费用、模板和算法依据；已确认版、历史版不跟随当前主档改名或价格刷新。
- 模板按客户×产品、客户、产品、通用条件匹配，检查生效日和批量。通用模板不能绑定某产品的 BOM 路径；产品模板路径失效时明确提示。
- 查看成本不自动授予编辑、确认、导出或模板维护权限。
- 页面共用 `costWorkbenchCapabilityProvider`，从当前服务端授予的权限集派生成本与财务过账能力；单据编辑、确认、导出还必须与服务端对象 `canEdit/canConfirm/canExport` 取交集。撤回查看权限立即遮罩已加载内容，确认和导出弹窗等待期间撤权也会在提交前重新检查；保留未提交输入，不以本地能力代替后端授权。

## 导入与下载

成本 Excel 导入仅用于迁入旧资料，放在更多操作，不是日常计算步骤。新成本表直接从系统 BOM/价格/规则生成。上传旧表后仅解析缓存数值和公式证据，不运行公式、不读取外链；宏/嵌入对象仍拒绝。按产品区块逐行匹配到计价物料、转费用或明确跳过；不同计价单位必须确认换算，数量覆盖是显式选择。来源文件及映射前后输入保留在私有不可变存储/记录中。

重复导入会撤回上次导入仍拥有的内容；不删除其他手工项，员工已改动的导入字段发生冲突时须明确处理。换文件或 FEE/MATERIAL/SKIP 切换不能残留旧费用。原文件事务状态不明时保留，待精确引用核对，不冒险删除可能已提交的文件。

内部成本单支持 Excel/PDF、整单/物料/费用/选中行下载，可选密码；选中行文件标部分明细。预览、保存和下载使用同一服务端计算快照，当前费用表投影不会误套到物料表。Excel 保留完整十进制，超过 15 位有效数字按文本保真；PDF 横向拆列、重复表头和分页，不能省略金额尾部。超出可读/资源边界时提示缩小范围或用 Excel。

实际下载携带当前 `contentDigest`；来源变化返回 409，须刷新核对。下载和打印的成本权限与对象范围在服务端复核，不能通过只拥有售价权限绕过。

## 实际核对

按货品、工单、产出日期区间或成本修订查看。实际数据来自原库存价值、生产投入产出、周期耗用和分摊记录，不由当前 BOM×当前价生成。

- 日期筛选的是产出业务日期，投入保留原成本对象的完整范围。
- 分别列出整范围投入、整范围累计分配、所选产出分配、筛选外分配和在制，避免不同范围相除。
- 直接实耗和周期理论比例分摊分别标识；未进 BOM 的辅料费用不丢失。
- `APPLYING` 或未完成的修订不显示一半分摊结果，分配/在制投影为空并标待处理。
- 实际金额为 `VALUATION_BOOKED_LOCAL` 库存价值账面口径，精确来源区间另列。人工、管理等缺少实际来源时明确列缺项，不能宣称全成本已归集。
- 历史物料名称、编号和基本单位沿原实物/价值来源冻结，修订金额及区间沿该修订证据读取；改主档、补价或新增修订不会改写旧版本。旧记录缺冻结身份或金额修订依据时显示待核，不能用当前主档补成历史事实。
- 对比只选已确认预算；数量、币种和实际覆盖范围不一致时只并列解释，不用显示单位价反乘生成“实际差额”。

## 相关财务入口

财务 GL 报表工具栏的实际成本入账面板展示原价值过账及目标期间。打开只读，配置切换、指定差额期间、追加凭证、关闭期间都需要财务过账权限和具体确认。

实际成本过账默认关闭，启用需生效日期与真实新旧对账依据。旧 `COST_CARRY` 不自动删除重建；历史冲突保留待处理。切换后才发现但业务日期较早的补价也必须保留，不能当作“切换前”忽略。关闭期间不被后台改写，原过账到凭证的关系幂等且不可变。

默认关闭时，普通总账生成保留其他既有凭证流程，不自动启用这条成本过账分支。显式执行实际成本入账或关账须先启用并核对政策；启用后的缺价守卫不能因普通总账入口而绕过。

期间检查同时核对实际发货的价值覆盖情况；未定价且金额变化为零、尚未产生价值过账行的发货也属于待处理，不能绕过入账或关账检查。已经确定的真实零成本允许保持为零。
