# 销售缺货仲裁页（稀缺库存让单）

> 状态：✅ 已实现（源码候选；目标库迁移与岗位 UAT 未完成）。
> 主管仲裁工具页：现货不够多个订单分时，决定「谁让单」。
> **Owner**：销售（主管）| **创建日期**：2026-09-04（补档，页面此前无文档）

## 一、页面与权限

- 路由：`/sales/scarcity?goodsId=&colorId=`（路由名 `sales-scarcity`）；
  查询参数可从其它页面（如订单/预留视图）带货品深链进入。
- **进入权限**：`sales_order:reallocate`（单一权限码；permission_by_path.dart:465）。
- 服务端 API 同口径兜底：
  `GET /api/sales/orders/reservations/scarce`（稀缺占用视图）、
  `POST /api/sales/orders/items/{id}/yield-reservation`（让单重排）。
- 本页无独立页面权限面（surface）；属销售订货族动作页。

## 二、页面结构

1. **选货品**：`UtenGoodsPicker` 选定货品后加载该货品全部**生效预留**
   （跨颜色；按优先级升序、创建时间升序排列）。
2. **预留清单**：逐行展示订单/客户/颜色/数量/优先级/创建时间；
   高优先级行不允许让单（让单只能释放低优先级行的现货预留）。
3. **让单动作**：对低优先级行点「让单」——复用既有释放原语 + 出货驳回同款
   状态回退；释放的现货回公共池，缺口自动回调度待排产，并通知被让单的销售。

## 三、口径与边界

- 让单只动**软预留**（sales 预留表），不动库存账本；已出库/已排产行不可让单。
- 与销售现货预留生命周期的关系见
  [../07-业务链路/05-销售现货预留生命周期与稀缺仲裁.md](../07-业务链路/05-销售现货预留生命周期与稀缺仲裁.md)。
