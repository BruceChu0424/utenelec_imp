# V547 生产成品品质检查单聚合层

当前目录为 **V548 / 505 条迁移**；本篇记录 V547。纯前向新增两张业务表 + 单号命名空间 + 清空策略补丁，不回填历史，
不改 `production_fqc_inspections` 任何列或数量。

## 用户口径

「登记成品」对照采购到货登记：逐行选实际成品仓、备注随批留痕，「批量送检」把同一成品仓的行合并成一张品质检查单，
品质按单处置。决策见 [ADR-076](../99-决策记录-ADR/ADR-076-生产成品品质检查单聚合层.md)。

## 结构变化

- `business_identifier_namespaces` 注册 `PRODUCTION_FQC_SHEET / DOCUMENT / FQC`（`DocNumberPrefix.PRODUCTION_FQC_SHEET` 镜像），
  单号 `FQC` + YYYYMMDD + 6 位日流水，`fn_reserve_business_document_identifier` 终身占号。
- `production_fqc_inspection_sheets`：id、sheet_no（UNIQUE，`^FQC[0-9]{14}$`）、warehouse_id FK、warehouse_name_snapshot、
  receiver_employee_id FK、receiver_name_snapshot、remark（≤500）、source_kind（`ARRIVAL_SINGLE|ARRIVAL_BATCH`）、
  batch_idempotency_key（生成本单的登记命令键）、created_by、created_at。
  索引 (warehouse_id, created_at, id)、(created_by, created_at, id)；部分唯一 (created_by, batch_idempotency_key, warehouse_id)
  保证同操作者同命令同仓只有一张单（重放返回既有单）。
- `production_fqc_inspection_sheet_items`：sheet_id FK、inspection_id UNIQUE FK、registration_id FK、registration_item_id UNIQUE FK、
  line_no；UNIQUE(sheet_id, inspection_id)、UNIQUE(sheet_id, line_no)。
- 守卫（ENABLE ALWAYS）：头/行只追加；行的 inspection 必须 PENDING、与检查单同仓，登记批次/登记行同仓且对应同一报工行；
  提交前延迟守卫要求每张单至少一行。
- 审计：`trg_audit_production_fqc_inspection_sheets` / `trg_audit_production_fqc_inspection_sheet_items`（`fn_audit()`）。
- 清空策略：V504 同款补丁把两张表以 `CLEAR` 插入 `business_data_reset()`；ops 脚本同步（CLEAR 266→268）。

## 边界

- 检查单只是展示/办理聚合：待检数量、PASS/PARTIAL/FAIL、放行、恢复链、FINISHED_IN 全部仍在 inspection（ADR-054 §2.3）；
  检查单状态 = 投影（仍有 PENDING/PARTIAL 行为 ACTIVE，否则 CLOSED）。
- 历史 inspection 无检查单，品质待检处置按「无检查单」逐条显示；不回填。
- 角标 `GET /api/production/quality-inspections/count` 口径改为队列行数：`COUNT(DISTINCT COALESCE(sheet_id, inspection.id))`。
- 不新增权限码。

正式 SQL：`server/src/main/resources/db/migration/V547__production_fqc_inspection_sheets.sql`。
