# 安装器日志目录快捷方式编译根因修复

bdf8cfec52 的真实 Windows Release AOT 已完成并通过静态身份、正式 API/CLOUD/DR、固定引擎1c473、依赖锁及编译日志检查；后续正式 ISCC 返回2，首个明确错误为 `windows_installer.iss:122 Parameter Flags includes an unknown flag`。该失败和两流日志保留在本地正式输出目录，不当作已完成双包。

根因是 `[Icons]` 使用 `foldershortcut`。当前已审编译器自带 `whatsnew.htm` 在 Inno Setup6.3.0 的平台支持调整中明确删除了该选项；它原本用于旧 Windows 的开始菜单级联文件夹，Win7及以后早已不生效。模板要求6.5+，所以降级/更换为更高编译器均不是本次解决方案。[官方 Icons 文档](https://jrsoftware.org/is6help/topic_iconssection.htm)明确允许 Filename 直接指向目录，普通 `.lnk` 即保留打开日志文件夹的语义。

修复仅将 Flutter 与 WPF 候选模板中的日志链接改为标准目录快捷方式。保留原 Name、目录目标、运行时家族路径及 `[Dirs] uninsneveruninstall`，不移除日志入口、不清除卸载后日志、不压诊断；其他安装/升级/用户目录/包身份/依赖要求不变。全仓库 `.iss` 同类使用仅此两处，已统一修正。

新增真实编译器回归覆盖正式分支：使用有真实PE资源/执行文件和DLL标识、ELF64 snapshot结构及canonical8字段formal profile的隔离合成输入，调用公共producer实际ISCC编译，再核同一次产物的installerSha256绑定与完整verify_pair。没有执行/安装该测试Setup。此前仅有LocalTest实际编译检查，不能据此认定当前全部正式模板已编译；新增覆盖不使用mock替代真实编译。
