# Windows 窗口闪退修补与合并前检查点

## 原因与处理

本地测试 Windows 客户端 `2.5.35+2535` 在登录后展开、还原或最小化恢复时退出。
使用匹配 PDB 解析 Windows dump，确认两条无障碍访问失效路径：

1. `FlutterPlatformNodeDelegate::ChildAtIndex` 对空子节点直接调用 `id()`。
2. `AXNodeData::GetStringAttribute → get_accValue` 读取已失效节点的字符串数据。

源码确认 AXTree 的失败提交可能已释放节点却未完成删除通知；成功重挂载时，原 bridge 的
`OnNodeReparented` 也没有将 delegate 绑定到新的 AXNode。dump 未保存相关堆页，不能将此次具体释放点
归于其中某一条；修补和确定性测试同时覆盖两条已确认的源码生命周期漏洞。

完整引擎补丁提供空子项保护、拓扑候选预检、缺失重挂载子树补全与 AXNode 重绑。
属性/几何更新保留快速路径，原生对象身份保留；不关闭 Semantics，不吞进程访问异常，
不以清空无障碍树冻结查询作为修复。

窗口侧保留标准 caption/thick-frame 样式，由现有 `WM_NCCALCSIZE` 隐藏视觉标题栏，
让系统管理原生过渡及减少动画偏好；失活或最小化时不重新聚焦 child。
公共打包入口和独立 ZIP 重读均拒绝两份已确认闪退的引擎摘要，保留旧输出以便恢复。
