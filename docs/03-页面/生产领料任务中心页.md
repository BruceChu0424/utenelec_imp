# 生产领料任务中心页

> 状态：✅ 已实现（2026-09-04 更新 V470 出库即审核与取消出库语义）。领退料一站式工作台，
> 原 hub 的拣货工作台卡（履约工作台）与领料单/生产退料单据卡并入本页。
> **Owner**：仓库（PMC 运营部）| **创建日期**：2026-09-01

## 一、页面与权限

- 路由：`/warehouse/tasks/draw`（路由名 `warehouse-draw-tasks`）。
- **进入权限**：`stock_doc:view`。领料单/生产退料由生产链自动生成、无手工新建入口
  （2026-09-04 撤除，见「四、业务口径」）；草稿生产领料首次“出库”要求
  `stock_doc:approve ∩ stock_doc:issue`，同一事务审核并扣账；
  后续分批出库要求 `stock_doc:issue`，取消出库要求 `stock_doc:reverse_issue`，红冲仍按
  `stock_doc:reverse` 门控。
- 页面权限面：`warehouse.draw-tasks`（V450）。

## 二、页面结构

对齐品质部检查结果页范式：**进页面不预选大类**（内容区显示「在上方选择分类后
开始办理」引导空态，不加载任何分段数据）；各分段的小类行只随选中的大类出现
（结构上等价于大类未选时小类锁定）。

1. **页级工具条**：大类分段 = 待领任务 / 领料单 / 生产退料 + 胶囊搜索（关键字
   下发当前分段）。徽章只挂真实待办（**草稿不计入待办数**）：待领任务 =
   履约待领数；领料单 / 生产退料只有草稿与历史，不挂。
2. **待领任务段**（`WarehouseDrawTaskSegment`）：与 `/operations/workbench/warehouse`
   履约工作台同源（生产物料需求 × DRAW 领料单 open_qty 投影），**按领料单归组
   （2026-09-03 用户确认，与 ADR-065 修订后的采购/委外同口径）**：一行=一张
   DRAW 领料单，多物料单货品列显示「N 种物料 · N 行待领」、待领数量列显示行数，
   并新增领料单号列；单货品单据照旧逐列显示货品与数量。小类分段 =
   待完成(默认) / 待备料·待领取 / 部分领取 / 已领取，状态按整单出库进度
   （全部行未出库=待备料、出过一部分=部分领取、全部出完=已领取）；双击进对应
   `/warehouse/DRAW/:id` 领料单办理分批出库。草稿首次出库自动完成审核，不再先点独立
   “审核”；无对象权限的行只读（服务端裁剪）。
3. **领料单段 / 生产退料段**（`WarehouseStockDocSegment(DRAW|WDRAW)`）：
   不渲染 icon+标题分段头；状态小类（全部/草稿/已审/红冲）与出库进度小类
   （未出库/部分出库/已出完）**进页面均不预选**（空集 = 不过滤），各段不挂
   徽章（草稿不计入待办数）；全部分类栏最下方为总结行（左「共 N 条 · 双击办理」；
   2026-09-04 起无新建按钮，见「四、业务口径」）；双击进详情（生产 DRAW 为出库即审核、多轮
   分批出库、取消出库与红冲；其它库存单据保留各自审核门禁）。从领料单发起的退料带来源行锁定与最大可退量（`?drawId=`
   预填链路保留）。

## 三、角标口径

- 待领任务徽章 = `GET /operations/workbench/warehouse/count`
  （`countPending('WAREHOUSE')`：v_fulfillment_workbench_actions 中
  WAREHOUSE 部门 × DRAW 单 open_qty > 0 的**领料单张数**，2026-09-03 起
  与列表归组口径一致；未挂单的行级需求退回行级计数兜底）。
- 领料单 / 生产退料不挂徽章（草稿不计入待办数）。
- hub「生产领料任务中心」卡徽标 = 待领任务数（`WarehouseDrawTaskBadge`）；
  工作台仓库卡 = 三张任务中心卡之和。

## 四、业务口径与边界

- 生产链（物料分析/报工）生成的 DRAW/FINISHED_IN 单据禁止通用编辑/删除
  （`fn_is_production_linked_stock_document` 服务端守卫）。生产领料/退料域整体归
  生产链所有：领料单/生产退料不提供手工新建入口（2026-09-04 撤除）——手工单没有
  计划包与执行段映射，审核/出库会被台账守卫一致拒绝（「必须且只能关联一张有效生产
  计划」「没有且仅有一个有效生产计划包，禁止发料」）；临时性出入库请用其它入库/其它出库。
- 领料分批出库（issue）幂等；草稿首次出库的审核与扣账共用同一事务，响应丢失以同一
  幂等键重放不会重复扣库存。取消出库必须填写原因，以反向流水恢复库存和占用，不修改
  或抹除原出库历史；退料只退已领良品，数量 ≤ 来源行可退量。
