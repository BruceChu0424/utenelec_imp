# V491 报工必须先显式开工

- 新增前向迁移：`V491__workbench_report_requires_explicit_start.sql`。
- 关联：[ADR-073](../99-决策记录-ADR/ADR-073-本批物料履约与同主仓分仓领料.md)。

共享车间执行视图的 `reportable` 改为仅 `IN_PROGRESS`，根任务汇总的报工数量自动遵循该口径。`WAITING/READY/DISPATCHED` 均不可报工，状态说明提示先开工。

READY 直接开工的数据库守卫改为检查显式 START 命令的事务局部段 UUID 与预期版本，不能复用旧“报工自动开工”标记。命令仍受权限、对象范围、物料实发、版本与幂等检查保护，并追加 START 事件；未设置或设置错段/错版本的直接更新被拒绝。

服务端报工选择器及新建/审核报工一并严格检查开工状态，不再通过新建报工自动推进任务。现有计划、库存、报工单、执行事件和旧 `AUTO_START_ON_REPORT` 审计记录均原样保留。V487 已应用字节不修改。

本地隔离数据库验证结果记录在本次验收文件中；新增脚本不代表现有业务数据库已应用。
