## 问题与实际证据

用户要求计划下单后仍把子件锁给对应产品，委外能够使用自己的子件，并沿完整链路知道物料、数量和来源。子件出仓与委外成品回库必须保持不同货品身份。

本地 V645 业务库的只读核对发现：

- E 极酸洗件是 V51043，子件是 V51012，BOM 单耗 1；V51042 实际为 L 极酸洗件。
- 委外申请 EB20260924000001 共 5,000 件，其中产品需求 4,000、主动公共备货 1,000。
- V51012 已有 5,000 件合格实物入作业叶仓，且全部由采购实收精确归属到该产品的子节点。库存总量 5,000、分析预留 5,000、公共可用 0。
- 原下单锁与出仓选仓只读公共可用量，把本产品自己的到货误判为缺货。解除计划预留会破坏业务归属，不能作为修复。
- 同页另一条为 HV5ZJ012 前置自制任务，属于不同业务事实，并非同一委外件重复建单。

## 决策

### 1. 解锁与发料采用同一精确来源

唯一子件以直属投入边判断，子件可以采购，也可以有自己的生产 BOM。V646 前向更新判据，不再要求子件自身为 BOM 叶子；仍要求唯一活动投入边、按件单耗。子件自身先完成采购或生产、合格入作业仓，再由父委外任务发出该子件。多个直属投入物料仍按前置自制路线处理。历史已生成的前置生产事实不自动改写。

申请明细 → 委外供给行动及分摊 → 产品父物料节点 → 同一分析产品、直属 BOM 边的子节点 → 当前子节点库存权益 → 原合格入库预留。

只允许使用这条链命中的子件权益，以及正常公共合格库存。不按分析号和货号直接拿取其他产品或兄弟节点的料。作业叶仓、颜色、单位和真实入库仓继续作为约束。

任务中心、建单、送审、批准、仓库列表、选仓、可发量与实际预留共用 `fn_subcontract_component_available_stock` 的口径。子件已有可发量即可安排，发料按实际可动用量分批。

申请合并了多个产品来源时，父节点容量按原申请分摊份额确定；只有一个父节点的 4,000 需求 + 1,000 公共备货仍可使用为该节点准备的 5,000 子件。

### 2. 库存预留在同一事务交接

每个精确来源批次单独形成委外出仓预留和不可变交接记录。原权益的减少、原物理预留的转出、委外预留的建立必须在同一事务守恒。

- 草稿改单、删除或取消：未消费的交接恢复给原产品、原子节点、原收货批次。
- 发料审核：消费本次出仓单的预留并扣子件库存；不能消费另一张草稿的预留。
- 已交接或已发出的子件：禁止通过红冲原采购/生产入库、取消原申请或分析释放；必须先处理下游并恢复来源。
- 委外回厂：登记和合格入库仍落委外成品货号，按冻结单耗核销供应商保管的子件。

入库内核只登记待唤醒货品，在同一事务提交前、采购精确归属或红冲恢复完成后统一唤醒委外。这样不会把刚写入余额、尚未登记来源的瞬时公共量抢给其他订单；唤醒失败仍回滚整笔事务。

出仓红冲保留「先恢复原归属，由仓库再决定补齐出仓单」的行为。本事务刚被红冲的原计划行不自动重新派出，后续真实采购或生产入库仍可正常唤醒，其他等待计划不受这一例外影响。

分析展示把尚未出仓的委外专属预留记作原子节点已有覆盖，避免草稿期间重新提示采购。此数量不放回生产或其他任务的通用可领料池。实际出仓后按已发外事实收减子层需求，不再显示成仓内现货。

### 3. 两类任务立即打开同款详情

委外申请使用列表中已有的进度。前置自制任务原先先等待单笔详情接口才弹窗，形成一快一慢的点击体验。

两者现在都立即打开进度窗；前置自制先显示已知产品与任务摘要，在窗内加载权威详情、支持失败重试，动作仍受详情 `allowedActions` 控制。关闭后的晚响应不得重新弹窗。页面恢复时重读库存闸，旧请求不得覆盖新结果。红黄计数共享同一次请求与一次轮询。

任务详情列出原产品、销售单/行与归需求数量，公共备货独立列示。当前酸洗申请为原产品 4,000 + 公共 1,000；HV5ZJ012 前置任务为原产品 3,000 + 公共 1,000。申请多来源通过当前页一次批量查询返回，不能用一个 MIN 来源代表所有产品，也不对每行新增请求。

本地只读测量在 `jit=off` 下，前置任务精准 COUNT 为 0.173–0.298 ms，含车间进度的详情 SELECT 为 0.603–1.291 ms；没有后台慢查询证据，不改成两类业务共用一张事实表。

### 4. 损耗结案与分批回厂

发出 100 件、约定损耗 5%，累计合格回库达到 95 件即在范围内，包括恰好 95。确认入库时记录 5 件损耗并结束剩余收货，不再等待这 5 件。

低于范围仍通知委外选择继续分批或接受损耗结案。已经选择分批、且预计日期已过的案件，后续累计达到容差后解除旧逾期锁；保留原判定审计，不能因旧通知重新锁住。全部发料判断采用计划应发量，前置自制只备好部分、发完本批不等于全部发完；明确关闭余量的计划保留既有结案语义。
