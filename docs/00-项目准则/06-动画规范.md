# 动画规范

> 本文描述当前实现与新增代码约束。动画 token 位于 [`lib/core/theme/uten_anim.dart`](../../lib/core/theme/uten_anim.dart)；最后核对：2026-07-30。

---

## 一、原则

1. 动画用于解释状态变化，不用于掩盖等待或装饰每个页面。
2. 不改变布局的反馈优先：opacity、color、size；避免点击时造成 layout shift。
3. 尊重性能档。lite 关闭非必要循环动画和模糊，standard/rich 才启用增强效果。
4. `AnimationController` 必须释放；页面离开、组件隐藏或性能降级时不得继续后台运行。
5. 请求 debounce、通知停留时间和 mock 延迟不是视觉动画 token，不要混为一谈。

---

## 二、当前 token

```dart
abstract final class UtenAnim {
  static const Duration fast = Duration(milliseconds: 150);
  static const Duration normal = Duration(milliseconds: 300);
  static const Duration slow = Duration(milliseconds: 500);

  static const Curve standard = Curves.easeOutCubic;
  static const Curve enter = Curves.easeInOut;
  static const Curve exit = Curves.easeIn;
  static const Curve bounce = Curves.easeOutBack;

  static const Duration staggerInterval = Duration(milliseconds: 50);
  static const double liteDurationFactor = 0.5;
}
```

正确访问方式是 `UtenAnim.fast`、`UtenAnim.normal`、`UtenAnim.standard`，不存在旧文档中的 `UtenAnim.durations.*` 或 `UtenAnim.curves.*`。

## 三、时长选择

| 场景 | Token |
|---|---|
| 按下、悬停、开关等立即反馈 | `fast` |
| 展开/收起、Tab 内容切换、常规进退场 | `normal` |
| 登录页等有限的强调进场 | `slow` |
| 列表错峰间隔 | `staggerInterval` |

新增视觉动画禁止随意写 `Duration(milliseconds: ...)`。确有独立协议（例如通知宿主内部时序）时，应在对应基础设施中集中命名并测试。

---

## 四、性能档行为

| 能力 | lite | standard | rich | 当前实现 |
|---|---|---|---|---|
| `UtenCard` glass | 降级 solid | 降级 solid | 开启 blur | 已实现 |
| `UtenSkeleton` | 静态块 | 明暗循环 | 明暗循环 | 已实现 |
| 常规显式动画 | 可缩短/关闭 | 标准 | 标准 | 调用方按 `performanceProvider` 决定 |
| 数字滚动 | 不启用 | 不启用 | 不启用 | 没有 `UtenAnimatedNumber` |
| 通用 stagger/Hero 工厂 | 不启用 | 不启用 | 不启用 | 当前没有公共实现 |

不要引用不存在的 `UtenStaggeredList`、`buildFadeSlidePage` 或 `UtenAnimatedNumber`。若以后新增，必须先有真实业务需求、性能降级和 widget 测试。

## 五、实现模板

隐式动画优先：

```dart
final tier = ref.watch(performanceProvider);
final duration = tier.isLite
    ? Duration.zero
    : UtenAnim.normal;

AnimatedSize(
  duration: duration,
  curve: UtenAnim.standard,
  child: child,
);
```

需要控制器时：

```dart
class ExampleState extends State<Example>
    with SingleTickerProviderStateMixin {
  late final AnimationController controller;

  @override
  void initState() {
    super.initState();
    controller = AnimationController(
      vsync: this,
      duration: UtenAnim.normal,
    );
  }

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }
}
```

性能档会在运行时变化的组件还要在 `didUpdateWidget`、Provider 监听或等价位置启停控制器，不能只在 `initState` 判断一次。

---

## 六、交互与可访问性

- 动画期间按钮仍应保持语义状态，loading 时禁止重复触发。
- 焦点、键盘操作和 tooltip 不能依赖 hover 动画才可见。
- 进度未知时用 loading/skeleton；不要播放假的完成进度。
- 列表更新应保持稳定 key，避免整页重复入场和位置跳动。
- 删除、支付、审批等高风险操作的动效不能替代确认、幂等和审计。

## 七、提交前检查

- [ ] 只为状态变化增加动画，不是无意义装饰。
- [ ] 时长和曲线使用 `UtenAnim` 或有明确集中协议。
- [ ] lite 下无不必要 blur、循环动画或大面积重绘。
- [ ] 控制器已 dispose，隐藏/离页/降档后停止。
- [ ] 动画不会造成布局跳动、重复提交或可访问性丢失。
- [ ] 浅色、深色、窄屏及性能档切换已验证。
