## ✅ 每次开发前的对照清单（Copy 到 PR 描述里）

> 实现一个新功能 / 修改一个页面时，对照下列每一项确认。

### 命名
- [ ] 所有类名带 `Uten` 前缀（仅 Uten 组件库），或符合 Feature 命名
- [ ] 文件名 snake_case，页面用 `<feature>_page.dart`
- [ ] 路由路径 kebab-case
- [ ] 不出现 `MyButton`、`Widget1`、`temp`、`aaa` 这类随意命名

### 响应式与自适应
- [ ] 在 **compact（<600dp）**、**medium（600–840dp）**、**expanded（>840dp）** 三档下都测过布局
- [ ] 用 `LayoutBuilder` 或 Uten 响应式组件，不写死宽度高度
- [ ] 导航按断点分化：compact 底部悬浮胶囊 / medium+ 左侧 Rail；页面内容在三档宽度下不溢出、不被胶囊/Rail 遮挡
- [ ] 主 Tab 转场：compact 左右滑动 / medium+ 即时切换（不在大屏整页横移）
- [ ] 登录后页面文字可选可复制（`app_router.dart` 的 `ShellRoute.builder` 已套 `SelectionArea`，须在 Navigator 内；别挪到 `MaterialApp.builder`——会崩）
- [ ] 列表在窄屏单列、宽屏多列自适应

### 字体
- [ ] 字号全部走 `Theme.of(context).textTheme` 或 Uten 字号 token
- [ ] **不硬编码** `fontSize: 14` 这类数字
- [ ] 在字号=超大模式下不被截断

### 国际化
- [ ] 所有用户可见文案走 `AppLocalizations.of(context).xxx`
- [ ] **不硬编码** 中文或英文字符串到 Widget 里
- [ ] arb 文件中英文都补全

### 动画
- [ ] 动画走 Uten 动画 token（duration / curve 统一）
- [ ] 不在性能档=lite 下还跑重动画
- [ ] 列表进场用统一 stagger，不各写各的

### 性能自适应
- [ ] 在 **lite 档**下能正常跑（无模糊、无重动画）
- [ ] 用了 BackdropFilter / 粒子 / 复杂着色器的，包一层性能档判断
- [ ] 大列表用 `ListView.builder`，不用 `Column + List<Widget>`

### 中国大陆运行
- [ ] 新增运行时依赖不需要境外 CDN/字体/脚本；服务域名、字段、地域和留存已登记
- [ ] 业务日期使用 `Asia/Shanghai` 集中工具，数据库/JSON 时间协议仍为 UTC
- [ ] 搜索列表有 300–500ms 防抖且只让最新 GET 回写；写请求不自动重放
- [ ] 公司 NAT/运营商 CGNAT 下不会因低阈值 IP 桶让正常用户互相 429
- [ ] 中文输入法 composing、中文文件名、11 位/`+86` 手机号和身份证非法日期有回归测试

### 主题
- [ ] 颜色走 `Theme.of(context).colorScheme` 或 Uten 色 token
- [ ] **不硬编码** `Color(0xFFxxxxxx)`
- [ ] 浅色 / 深色模式下都可读（对比度够）

### 组件库
- [ ] 已有同类能力时复用 Uten 组件；页面私有布局可组合 Material 原语，但必须使用主题/token，
      且不得复制公共组件
- [ ] 缺组件时先补组件库再写业务（参考 [02-组件库/组件总览.md](../02-组件库/组件总览.md)）
- [ ] 组件复用而非复制粘贴

### 顶部通知
- [ ] 所有用户反馈走 `context.appSuccess/Error/Warning/Info`，**禁止** `ScaffoldMessenger.showSnackBar(...)`
- [ ] API 错误用 `context.appApiError(e)` 自动提取 `fieldErrors`
- [ ] 通知位置为顶部（status bar 下方），不允许底部
- [ ] 同一页面同时存在的通知最多 3 条，超出按 FIFO 出队（系统自动）

### 防连点 + 等待回执
- [ ] 任何触发网络请求的按钮必须用 `UtenActionButton`（自带 loading） 或 `UtenButton(isLoading: ...)`
- [ ] Switch / Slider / SegmentedButton 等联动控件：动作前后用 `ClickGuard.run()` + `isBusy` 守卫
- [ ] `onAction` 回调里用 `context` 前必有 `context.mounted` 守卫（异步回执后页面可能已 pop）
- [ ] 不在 `onAction` 内同步抛错；如需抛异常，外层 `try/catch` 转为 `appApiError` 展示
- [ ] 联动的几个控件（如 HVAC 开关 + 温度滑杆）共享同一个 `ClickGuard` 实例，避免不同控件独立互锁

### 安全
- [ ] 表单做客户端校验（长度、格式、必填），**后端独立再校验**（前端不可信）
- [ ] 密码只进入当次 HTTPS 请求 body、不得持久化；token record/待撤销 refresh 走 `flutter_secure_storage`，不进 shared_preferences
- [ ] 员工 token 使用单个权威 record；保存/清理 refresh 用完整快照 CAS，登录/改密 latest-intent，损坏记录写 tombstone 且不从旧双键复活
- [ ] 退出先激活 logout fence，再在跨标签 token 锁内把旧 refresh 持久交接到专用加密撤销队列，成功后才写 tombstone；交接失败保留 fence 与 token 供重试；该队列只重试幂等 logout，禁止复用为业务离线队列
- [ ] 仅精确 `status + code` 的 refresh 拒绝清会话；HTML/空体/未知 401、status/code 错配、503/429/超时均保留 token
- [ ] 自动连接只重试 GET/HEAD/OPTIONS 两次（400ms/1200ms）；POST/PUT/PATCH/DELETE 不因连接恢复重放；health 只认 200 + JSON `status=UP` 并带 jitter
- [ ] staff JWT 只含标准字段 + `sub/typ/av/ae`；服务端账号/权限解析故障为结构化 503；Tomcat/Nginx/设备审计头均有有限预算和边界测试
- [ ] 不硬编码密钥、URL、Mock 账号；密钥/部署类配置走 `.env`，**不进系统设置页**
- [ ] 路由守卫：未登录访问受保护页跳登录页；菜单/按钮按权限点 `hide`（**不是 disable**）
- [ ] 错误信息不暴露后端细节（stack/code/SQL），统一 `ApiException` → `context.appError(...)`
- [ ] **对象级授权**：列表、详情、更新、删除、审核、红冲和批量入口使用同一数据范围守卫；必须用他人 UUID 做越权负向测试
- [ ] **计划需求与商业订货分离**：采购/委外申请由计划下达且业务端只读；订货只从任务中心分解，一张单保持单供应商/委外商且单仓库
- [ ] **审核组审批授权**：订货/超量审批按财务部门资格 + `finance_order_approval:review` 实时判定（合格审核人 = 财务部树内持权者 + 跨部门点名加授，由 `WorkflowReviewerEligibility` 查库）；超管不在财务部且未被点名不可代审，前端仅服从服务端 `allowedActions`（V229/ADR-027）
- [ ] **超量到货 fail closed**：财务决定前不写库存/AP/订单累计；批准量仍由仓库再审，未批准量只交原下单人退回
- [ ] **候选不是部署事实**：公司目标库只确认到 V190；V196–V202 未完成迁移、岗位/实物 UAT、IQC 和签字前必须标生产 NO-GO
- [ ] **新增数据导出**：五道防线（独立 `*:export` 权限不复用 view / Bucket4j 频率 + 进程内并发闸门 / Agile AES-256 加密、密码入 body / 行数上限 / 审计）—— [§十.1](../05-架构/安全策略.md)
- [ ] **新增高危配置（系统设置）**：六道防线（`authorization:manage` + 超管限定 / Controller 与 Service 鉴权 / **二次密码确认** / 审计 / 类型校验 / 只允许策略阈值）—— [§十.2](../05-架构/安全策略.md)
- [ ] **用户可见 API 操作审计**：进入应用的 GET/POST/PUT/PATCH/DELETE/HEAD `/api/**` 必须有请求记录；写事务首个 DML 前绑定请求、用户与设备上下文；不得保存 query 值、正文、凭证或令牌
- [ ] **审计证据权限**：除超管固有全权限外，查看只允许个人 `audit_log:view`，导出再叠加个人 `audit_log:export`；禁止部门配置或继承
- [ ] **审计不可变与设备核对**：无人工修改/删除入口，只由留存任务自动归档清理；读取目标本机回执前必须联网完成服务端授权，拒绝或离线时零本机读取
- [ ] **报表行带元数据但不展示**：列 key 以 `__` 前缀（如 `__srcId`），`execute()` 自动过滤；前端 `row['__srcId']` 可读用于行点击跳源头

| 文字选择 | `SelectionArea` 包登录后外壳（`app_router.dart` 的 `ShellRoute.builder`，须在 Navigator 内，放 `MaterialApp.builder` 会崩）——Text 默认不可选 |
| 主 Tab 转场 | compact 左右滑动 / medium+ 即时切换（不在大屏整页横移，见 [02 §3.1.1](02-响应式与多端适配.md)） |
