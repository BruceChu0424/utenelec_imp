# 系统设置页

> 运行时可配的**安全/业务策略阈值**（超级管理员 `user:manage`）。改设置**立即生效**（不缓存），保存需**二次密码确认**。
>
> 位置：`lib/features/admin/pages/admin_system_settings_page.dart`
> 后端：`server/.../features/admin/systemsetting/`（`SystemSetting` entity/repo + `SystemSettingsService` + `SystemSettingController`）+ `V72__system_settings.sql`（建表 + 11 项种子）。
> **安全规范**：[../05-架构/安全策略.md §10.2](../05-架构/安全策略.md)（强制，新增高危配置功能照此）

---

## 入口

工作台 → 系统管理 →「系统设置」卡片。路由 `/admin/system-settings`，`permission_by_path.dart` 对 `/admin/` 前缀统一守卫 `user:manage`——**普通用户连入口卡片都看不到**。

---

## 可配项（4 类 11 项；默认值同 application.yml）

| 分组 | 设置项 | 默认 | 影响 |
|---|---|---|---|
| 安全策略 | 登录限流 / 锁定阈值 / 锁定时长 / 密码历史 / 导出限流 | 5/分·IP · 5次 · 15分 · 5个 · 10/分·用户 | `LoginRateLimiter`/`LoginService`/`PasswordService`/`ExportRateLimiter` |
| 登录令牌 | access TTL / refresh TTL | 15分 · 7天 | `JwtService` / `RefreshTokenService`×2 |
| 短信验证 | 验证码 TTL / 发送间隔 / 每日上限 | 5分 · 60秒 · 10条 | `VisitorSmsService` |
| 业务限制 | 导出行数上限 | 100000 | 6 处 `*ReportService.paginateAll` |

**不含**（绝不入配置页）：密钥类（jwt.secret / crypto / sms AK——涉密钥/轮换）、部署类（CORS / swagger / DB / legacy——启动时定）。这些走 `.env` / 环境变量 / Vault。

---

## 安全（五道防线，强制规范）

1. **路由守卫** `/admin/` 仅超管 → 普通用户看不到入口。
2. **`@PreAuthorize('user:manage')`** Controller 级。
3. **二次密码确认**：`SystemSettingsService.write` 用 `PasswordEncoder` 校验当前账号密码——即使 access token 被盗，改策略还需密码（防令牌泄露篡改安全策略）。
4. **审计**：`update_system_setting`（谁/哪项/旧→新值），审计页可查。
5. **类型 + 非负校验**：后端权威 + 前端提示。

---

## UI（精心设计）

按 4 类分组卡片（安全策略/登录令牌/短信验证/业务限制）+ 改动跟踪（dirty 项高亮 primaryContainer）+ 底部「保存改动(N)」+ 二次密码弹框（含危险操作警告）+ 顶部警告横幅（影响全员提示）+ 每项显示说明 + 上次修改时间。

---

## 改设置如何立即生效

`SystemSettingsService.readInt/readLong` **不缓存**，每次 `findById`（表仅 11 行 PK 查询亚毫秒）。各安全组件动态读取（替代硬编码 `*Properties`）：
- `LoginRateLimiter`/`ExportRateLimiter`：令牌桶阈值动态，变更后下次 check 检测到新值重建桶。
- `LoginService`（lockout 阈值/时长）、`PasswordService`（密码历史）、`JwtService`（access TTL）、`RefreshToken`×2、`VisitorSmsService`（短信 3 项）、6 处导出上限。

详见 [ADR-013](../99-决策记录-ADR/ADR-013-系统设置与安全策略可视化.md)。
