# 仓库委外出仓工作台页

> V304（ADR-042 · [业务设计](../07-业务链路/08-委外全链路-订货出仓回仓重设计.md)）。
> 仓库专属的委外材料出仓页面，与委外模块单据页**分立设计**（不复用、不跳转）；
> 全页无价格/金额/币种字段（材料按成本发出）。

## 入口与权限

- 仓库 hub → 任务中心「委外出仓」卡（角标 = 待出仓计划数，OPEN 且 计划量>已出仓）；
  **无 `subcontract_outbound:view` 时卡片与角标整组不显**。
- 路由：`/warehouse/subcontract-outbound`（任务中心）、
  `/warehouse/subcontract-outbound/:planId`（拣货出仓页）；静态段先于 `/warehouse/:code`。
- 权限（V305 独立权限点，权限管理页可授权/收回，默认仅 SUB_WH）：
  `subcontract_outbound:view` 看任务中心/计划详情；`subcontract_outbound:handle`
  拣货保存/审核出仓/关闭计划/补齐草稿。单据本身的编辑/审核另受
  `subcontract_material_issue:edit` 管辖（V304 授 SUB_WH）；两层独立可收回。
  委外/财务/品质默认不可见（UAT 已验证 403/授权可见/无 handle 不可操作）。

## 出仓任务中心页

- 任务卡：委外订货单号、委外商、交货日期、出仓进度（计划/已出仓/待出仓 + 材料行数）、
  未审出仓草稿号（有则显示「出仓草稿待拣货」）。
- 搜索：订货单号 / 委外商（防抖，只让最新 GET 回写）；下拉刷新与分页。
- 任务来源：财务批准委外订货单后系统按批准时 BOM 自动生成（无需手工创建）。

## 拣货出仓页

- 表头：订货单号/委外商/计划状态只读；出仓日期（默认今天）、**发出仓（必选）**、
  经办人（默认当前登录人，默认部门 SUB_WH 子树）、交货日期、备注。
- 明细行（按批准时 BOM 展开快照）：子件编码/名称、父件、冻结单耗、库位、
  计划量/已出仓，「本次出仓」默认 = 该行剩余量、可改小（分批出仓）。
- 操作：
  - 保存草稿（PUT `/api/subcontract/material-issues/{id}`，planItemId 逐行回传不断链）；
  - 审核出仓（确认弹明示三效果：材料出库转委商保管 / 冻结 BOM 单耗供回厂守恒消费 /
    余量自动续生下一批草稿）；
  - 「不再出仓」关闭计划余量（必填原因，留痕）；
  - 无草稿且有剩余量时自动经工作台「补齐出仓单」重建（红冲后补发等场景）。
- 出仓记录：该计划全部出仓单（单号/数量/仓库/审核人/状态）。

## 服务端联动（审核同事务）

1. 材料出库流水（type15, DIR_OUT）+ 库存余额扣减；
2. 供应商处子件台账 `at_supplier_qty = 本次出仓量`、冻结 `frozen_unit_qty = 计划 bom_unit_qty`；
3. 计划行 `issued_qty += 本次`（CAS 防超计划，超出 409「出仓量超过发料计划余量」）；
4. 计划 OPEN 且剩余量 > 0 且无未审草稿 → 自动续生下一批出仓草稿。

红冲：反向入库 + 计划 `issued_qty` 回减；有下游回厂消费/材料退/损耗的出仓单先红冲下游
（既有守卫）。订货红冲：软删未审草稿 + 计划 CANCELED。

## 与其它页面的分工

| 页面 | 归属 | 职责 |
|---|---|---|
| 本页（出仓任务中心 + 拣货） | 仓库 | 委外材料出仓的执行 |
| 预计到货任务中心 / 登记实际到货 | 仓库 | 委外成品回厂的执行（既有） |
| 委外订货单详情「全链路进度」 | 委外 | 只读跟踪出仓/回厂/IQC/应付，单号点进只读详情 |
| 物料分析供给进度（MATERIAL_ISSUED 步） | 计划/销售 | 委外材料出仓进度同步可见 |
