# 采购、委外退货的库存成本与商业贷项

供应商贷项沿用已批准来源单据的原币、本币金额。库存退回价值来自实际库存估值与原出库反向事实，不能按供应商贷项覆盖加权平均库存价值。

例如收费 10、赠品 1、总货款 100，入库 11 的加权平均价值为 100。实际退回 1 的库存价值为 9.0909：退赠品没有应付贷项，应记录价差损失 9.0909；退收费品的商业贷项为 10，应记录价差收益 0.9091。库存数量、估值、应付贷项分别保留真实来源。

V845 新增稳定过账用途 `PROCUREMENT_RETURN_VARIANCE`，要求 `EXPENSE` 类启用科目的 UUID。财务按正常系统用途配置入口补齐映射；不按科目名称、路径或任意第一行推断。原有 `AP_POST` 金额不变，附加 `PROC_RETURN_VARIANCE` 凭证以“实际库存成本 − 商业贷项”为有符号金额，借价差损益、贷库存资产。负数表示收益。

投影只处理非历史导入、当前已审采购及委外退货。每行通过原出库事件、库存节点及稳定退货明细 UUID 验证实物数量和成本来源；后续估值变动按原节点及所属明细汇总。来源不完整、成本未完成或缺用途映射时，在删除旧投影之前阻止重生成。

同期间重新生成只保留一份价差投影。反审按原单身份清除对应价差凭证，实物仍按原出库实际价值镜像恢复；历史单据和未能证明身份的旧凭证不因此被重写。正常总账的全期间未完成成本守卫保留。

`system_posting_style_roles` 已有表级审计触发器与业务清空目录 `PRESERVE` 策略覆盖新增用途行。V845 不新增业务表、索引或现金事实，不改变既有用途键和已配置科目。
