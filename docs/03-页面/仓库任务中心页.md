## 结构：大类 + 小类两级分段

- **大类行**（第一行，带页级搜索与仓库范围选择器）：出库 / 入库 / 生产领料 / 品质检查结果 / 委外成品退货 / 委外损耗 / 车间内料仓 (2026-09-28 新增)。进页面不预选大类（未选显示引导空态，不发请求）。
- **小类行**（选中大类后出现）= 原各任务中心页自己的分段，以嵌入态复用整页能力（小类行、表格、办理动作与独立页完全一致）：
  - 出库 → [出库任务中心](出库任务中心页.md)（销售出库/委外出库/其它出库/产成品出库）
  - 入库 → [入库任务中心](入库任务中心页.md)（采购入库/委外入库/产成品入库/其它入库）
  - 生产领料 → [生产领料任务中心](生产领料任务中心页.md)（待领任务/领料单/生产退料）
  - 品质检查结果 → [品质部检查结果](品质部检查结果页.md)（来源行 + 状态行原样保留）
  - 委外成品退货 / 委外损耗 → 时间门控的历史视图（只读，不挂数）
  - 车间内料仓（[ADR-131](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md)）→ 按权限显示待发料 / 待收退回 / 盘点审核 / 周期盘点 / 记录。有发料权限时显示「直接发料」；仅持仓库盘点审核权限也能进入大类与审核队列。「盘点审核」内嵌[库存盘点审核页](库存盘点审核页.md)，点击申请进入真正审核明细并可原位返回队列，直接按整单审核，无用途卡片勾选；通过后自动刷新队列和待办。父分类与子分类共用同一左侧边界。顶栏同名按钮直接定位该子分类。「周期盘点」保留期间状态与[期间盘点页](车间内料仓盘点页.md)，仅对有查看及周期录入／审核权限的人显示；2026-10-01 起记录「状态」与「盘点」「结算」列按状态铺整格底色（开着绿／盘点中蓝／待结算琥珀／结算失败红等，见[车间内料仓页](车间内料仓页.md)）。

旧三路由 `/warehouse/tasks/{outbound|inbound|draw}` 与 `/warehouse/quality-results` 构建本页并预设对应大类（通知深链、收藏、`?section=/?view=` 参数原样透传），不再是独立页面。

## 徽章口径（准则 14 不变）

- 大类红数 = 原各卡同源入口：出库 `warehouseOutboundCenter`、入库 `warehouseInboundCenter`、生产领料 `warehouseDrawCenter`、品质检查结果 `warehouseQualityResult`（均随徽章汇总一次带回，ADR-108）。
- 品质检查结果大类另挂黄数（等待检查结果 = 货已收、等品质部出结论），与注册表黄链同源。
- 委外成品退货 / 委外损耗是历史只读大类，不挂数（准则 14 §二）。
- 车间内料仓大类：红数取 `warehouseWorkshopMaterial`（待发料＋待收退回）与 `warehouseStockCountReview`（库存盘点待审）的独立入口并集，各计一次；黄数仍只为真实周期 `COUNTING`。顶部快捷入口与审核子分类共用审核待办数，0 隐藏，不将每个 `OPEN` 期间算成待办。没选仓取统一徽章汇总(服务端已按本人仓库范围)；选了仓取同一汇总接口带 `scopeWarehouseId`(ADR-149，不再用 `PENDING` 列表 size=1 凑数)，列表和计数共用服务端条件，主仓包含子仓。页内多处显示不再累计进模块。
- hub「仓库任务中心」卡角标 = warehouse 容器待办累计（服务端目录求和，与顶栏两枚药丸、工作台仓库卡同源同数）。
- 仓库范围（[ADR-149](../99-决策记录-ADR/ADR-149-仓库数据范围服务端强制.md)，V802，取代 ADR-115 的「我的仓库」）：服务端按本人范围强制过滤列表、大类与分段计数、徽章。主管顶栏是小标签，点开右侧滑窗(先主仓后子仓，首行「全部仓库」)可挑任一仓；负责多个仓的子仓负责人同样的滑窗(首行「我负责的全部仓库」，只列自己的仓)；只负责一个仓显示只读标签「我负责：xx」；其他人不显示。选了仓时大类数与分段数取 `/workbench/badges?scopeWarehouseId=`(只算仓库模块入口)，没选仓取全站徽章汇总(服务端已按本人范围)；库存单据各分段的「草稿」数同样带上所选仓(`/documents/status-counts?scopeWarehouseId=`)，与旁边列表同一范围；范围变化即重拉大类计数与分段列表。记忆的仓不在当前可选范围内时回到本人默认范围；返回本页或点「刷新」会重取本人可选范围(负责关系刚改过时不会一直拿旧范围请求、得到「所选仓库不在你负责的范围内」)。本人默认范围里自己还没提交的库存单据草稿不论在哪个仓都列出并计入草稿数(顶班在别的仓建的草稿不会从自己的列表和草稿箱里消失)，挑了某个仓就只看那个仓。
