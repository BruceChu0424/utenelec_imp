# 页面布局与滚动条统一验收

状态：公共布局代码及调用迁移已完成；最终运行版本和逐页视觉验收尚未完成。不能把本文件当成全部页面已验收的证明。

## 本任务的范围

使用 `frontend-design`，保留现有 Uten 主题、业务和权限规则。正文占用尽可能宽的工作区，不强制采用 95% 比例。

| 项目 | 公共合同 |
| --- | --- |
| 主轨位置 | 页面最右侧，绘制带 14 窗口像素，距右边 2 像素，覆盖整个可用高度，包括顶部操作区。尊重安全区和键盘遮挡。 |
| 内容右缘 | 一个入口负责 24 窗口像素末端边距，即轨道安全带 16 加内容间距 8。顶部操作、卡片、主表及翻页区对齐，不叠加旧局部槽。 |
| 可见性 | 仅实际溢出时显示轨道、胶囊滑块和上下按钮；无溢出全部隐藏。布局宽度不随绘制可见性反复变化。 |
| 交互 | 保留拖动、轨道翻屏、滚轮、上下按钮单击及长按，遵守已有缩放和 Shift 横滚规则。 |
| 独立区域 | 左分类树、嵌入表、弹窗和滑窗保留独立滚动及局部 16 画布单位安全槽，不误接页面主轨。 |
| 下拉框 | 可滚动选项保留滚轮和键盘操作，隐藏可见竖向轨道。真正的结构化选择面板与短选项菜单分别处理。 |
| 导航 | 工作台保留自己的偏好；进入其他页面默认收起，当前页手动展开有效，进入下一页再收起。 |
| 按钮 | 同角色及同组使用一致尺寸和间隔；顶栏、普通工具栏、浮动触控入口按各自角色判断。 |
| 提示 | 纯说明移到相邻信息图标；错误、权限、业务数量及必填限制继续可见。 |

公共入口为 `UtenPageScrollbarHost`、`UtenPageChromeMetrics`、`UtenPageEdgePadding`、`UtenContentContainer` 及主表共享布局归属。活动域隔离保活页面，弹窗暂停背景轨道绘制而不改变背景宽度。表格填满可用视口，实际字段列宽及用户设置保留。
