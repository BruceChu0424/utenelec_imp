## 二、V437：委外页面权限，默认零授权

V437 新增以下活动权限，并通过 `permission_surface_permissions` 精确关联页面：

- `subcontract_preparation:view/start` → `subcontract.preparation`；
- `subcontract_inquiry:price:view` → `subcontract.inquiry`；
- `subcontract_order:price:view` → `subcontract.order`；
- `subcontract_return:price:view` → `subcontract.return`；
- `subcontract_waste:suggestion:view` → `subcontract.waste`；
- `subcontract_report:price:view` → `subcontract.report`；
- 计划生成 EC 所需的 material-issue view/edit/delete/approve/reverse 同时精确关联
  `warehouse.subcontract-outbound`，但不包含空白 create。

迁移明确不插入 `department_permissions`、`role_permissions`、`user_permission_overrides` 或
`manager_permission_delegations`。若目标库已人工创建同名权限且存在任一授权来源，V437 在激活前
直接失败，防止占位行变成静默扩权。已停用的 `subcontract_outbound:handle`、
`finance_order_approval:review` 和 `subcontract_application:edit` 必须继续 inactive/unassignable。

服务端与 Flutter 使用同一页权限；`finance:view:all` 可受控查看服务端未脱敏的商业字段，
但不能绕过对象范围、写动作或服务端 `priceMasked`。材料出仓/材料退当前页面无商业单价事实，
其历史成本形字段只允许 finance-wide 权限解密。

## 三、V438：财务前商业快照与冻结

采购或委外订单进入财务 `PENDING/APPROVED` 时，数据库触发器同时锁定并校验：

1. 来源订单存在，币种启用、汇率大于 0、税率在 0..100、结算方式启用；
2. 至少一条有效明细，数量大于 0、单价非负、原币/本币金额非负；
3. `amount_original = round(qty * price, 4)`，`amount_local = round(amount_original * rate, 4)`；
4. 单头原币/本币合计分别等于明细合计，审批 `amount_snapshot` 等于单头本币合计。

一旦存在 `PENDING/APPROVED` case，供应商、币种、汇率、税率、结算方式、金额合计及明细集合/
来源/数量/价格/金额不可插入、删除或改写；业务纠错必须走驳回、红冲或新的受控事实，不能在财务
查看期间静默换价。`ENABLE ALWAYS` 保证普通复制角色不能绕过商业快照守卫。

V438 另明确：`subcontract_wastes.deduct_amount` 是建议责任金额，不自动成为负应付；历史
`deduct_posted` 只为旧事实可读/可反向兼容。

## 四、V439：采购页面价格权限，默认零授权

V439 新增并精确关联：

| 权限 | surface | 保护字段 |
|---|---|---|
| `purchase_order:price:view` | `purchase.order` | 订货结算、币种、税率、单价与金额 |
| `purchase_return:price:view` | `purchase.return` | 退货结算、单价与反向应付金额 |
| `purchase_report:price:view` | `purchase.report` | 报表价格/金额列及相关筛选、排序 |

`purchase_receipt:price:view` 只继续保护收货页面。V439 不复制其历史部门/个人授权，也不写任何
新 grant；同名占位权限若已有授权，迁移先失败。权限管理员须按真实岗位显式补授权并保留审批记录。
未补授权的历史账号看到数量/重量/实物状态，但商业字段由服务端置空并标记 `priceMasked=true`；
这属于预期 fail-closed，不得临时改回 receipt-price 全域解密。
