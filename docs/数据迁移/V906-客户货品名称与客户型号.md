# 货品客户名称与型号

每条货品继续以当前 UUID 和独立货品编号管理，只存一组可选客户货品名称、客户型号。不同客户已有不同货品编号的做法保持原样。

|界面字段|数据库与 API|维护规则|
|---|---|---|
|客户货品名称|V906 新增 `goods.client_goods_name`；`clientGoodsName`|可空文本；不以普通名称、简称或客户公司名推断|
|客户型号|既有 `goods.c_number`；`cNumber`|沿用旧库 CNumber，与货品自身 model 独立，不重复建列|

基础表单、查看页和默认列表把客户货品名称放在货品名称旁，把客户型号放在自身型号旁。共享列布局继续保留用户保存过的列序、隐藏和宽度，仅按声明位置插入尚未保存的新列；没有重置用户布局。

两个文本遵守当前货品 UUID、goods 权限和对象范围、版本冲突与历史恢复合同。旧客户端未传字段时保留原值；显式空白或 null 清空。列表、详情、正常保存及导出均提供字段。普通 XLSX 导入只识别明确的“客户货品名称”“客户品名”及“客户型号”；两个客户名称别名同时出现时拒绝冲突。该名称不会从“客户名称”、普通货品名称、简称或开票名称推断。没有增加客户多值关系，也没有修改单据名称默认值或打印规则。

V906 为旧不可变 goods 快照在读取比较时补新列的 NULL 默认，保留 V903 的 BOM 分支；不改写旧历史证据。后续实际非 NULL 的客户名称仍会被 CAS 比较识别。
