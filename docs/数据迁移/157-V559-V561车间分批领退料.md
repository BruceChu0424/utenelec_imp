# V559–V561 车间分批领退料

本组迁移截至 V561 / 519 项；后续成本来源由 [V562](158-V562分批生产共享来源成本池.md) 补齐，当前目录以[总索引](README.md)为准。设计见 [ADR-077](../99-决策记录-ADR/ADR-077-车间明确提交领料后进入仓库任务.md)、[ADR-078](../99-决策记录-ADR/ADR-078-完整子批生产与实际用料余料退仓.md)。本文记录迁移影响，不能代替目标业务库安装回执。

| 迁移 | 新事实与约束 | 历史行为 |
|---|---|---|
| V559 | 既有执行段事件账新增 DRAW_REQUEST 与精确 draw_document_ids；仓库各读取/发料路径使用统一门禁 | 不回填虚构申请；已有真实出库继续办理，历史未发料任务由车间补提交 |
| V560 | production_material_return_requests / items / cancellations 三表追加式记录；精确 ISSUE 额度在待收阶段冻结；保留原仓、物料、颜色、单位及换算 | 不提前增加库存；既有 WDRAW 及其 GOOD_RETURN、反向历史保留，正式实收仍由仓库授权操作 |
| V561 | production_execution_segment_splits；执行段新增来源、根段、累计起点和物料快照；需求保存 split_root_demand_id；窄范围来源及数量守恒约束 | 原冻结量不改小；显式拆分以保留原段、追加子段方式完成；人工暂缓、已领/已报、旧正式供给绑定或 BOM 改变不可通用拆改 |

V560/V561 的新增事实表进入既有业务测试清理 CLEAR 策略，审计仍保留；受控操作脚本同步至 V561/519，CLEAR 273、PRESERVE 96。脚本仅为维护源文件，本轮未对业务库执行清理。迁移演练头、数量及两份白名单合同同步更新。

领料提交记录不代表发料；退料申请不代表实收。仓库入账必须继续经过原存货台账、权限与实物核对，分批的生产量、物料和销售分摊总量必须等于来源冻结数量。重试、冲销和撤回分别留下来源事实，不修改历史流水。

部署必须使用同一版本的后端、前端及迁移；保留已应用迁移原字节。目标升级失败按现役发布流程恢复已验证备份或前向修复，不降级覆盖库存、领退料或分批历史。当前验证仅针对隔离环境，未更新运行中的业务系统。
