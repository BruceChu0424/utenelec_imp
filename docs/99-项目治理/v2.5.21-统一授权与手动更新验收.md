## 员工可见变化

- 表头中的名称、编号、型号、规格、备注等文本列支持关键词搜索，按回车或同一行的“搜索”按钮后关闭菜单，结果显示在下方表格；多列条件取交集。日期时间、数量金额、状态和单位等列继续使用原有范围、选项或排序。
- 已接入服务端查询的主档、销售/采购/委外单据和采购工作台，在授权范围内先筛选再分页；服务端候选支持继续搜索和加载，不能只在首批候选中找。其他仅加载部分行的表格按已加载范围搜索，并说明范围。表格文字支持拖选及复制，与业务行勾选分开。
- 普通表单、选择器与日期等空字段直接显示字段名称；格式示例和填写说明放在说明入口。真实空状态不再伪装成已填写，已有有效数值、单位和个人显示偏好继续保留。
- 模具与 BOM 组件选择使用左侧分类、右侧明细表，能同时查看编号、系列、名称、型号、规格、颜色等信息。模具和组件输入提供近似候选，按钮打开完整选择窗口并带入关键词；多列筛选、跨页选择及 BOM 用量、循环和兼容校验继续生效，当前组件范围不会被查询意外扩大。
- 货品导出补齐模板回导所需字段，分类按真实路径识别；修改模板后可按原导入校验处理，歧义不自动猜测。分类编号前缀支持数字开头，分类备注可显示在名称旁；历史编号、类别身份和编号占用规则保留。
- 采购订货单增加预览打印，审核栏取实际财务审核员。采购任务历史按订单真实物料明细逐行展示并增加供应商，保留同单号及各行真实数量；申请待分解和工作台支持按当前筛选导出，超出配置上限明确提示，不截断导出。
- 货品操作记录可查看本人最近十次资料修改，并按当前条件撤回或取消撤回；后续修改、业务引用和权限变化会重新核对，操作与审计留痕。历史记录不会成为绕过业务状态、数量、编号或访问权限的修改入口。
- 财务确认、报价核价、订货审批和 FQC 等功能使用实际有效授权，不再额外要求属于特定部门或必须另有个人点名。查看、批准、驳回和敏感字段仍按各自明确的权限设置办理。
- 权限开关、服务端能力、操作按钮、待办和会话刷新使用一致规则。普通授权变更后，有效登录会话可刷新取得新权限；撤权不会被旧界面、过期委派或晚到响应恢复。
- 独立动作不会因另一个页面的查看权限被误挡；只有允许自动授予的普通读取才辅助补齐，已收回、敏感或不在授权上限内的读取不会被偷偷加回。
- 审核失败保留实际原因，区分没有授权、占用、版本或状态变化、通信失败，以及操作结果尚未确认。操作已成功但页面刷新失败时，不再误报为提交失败，也不自动重复提交。
- 更新页面改进版本、阶段、原因及处理建议的显示。主机作业跨后端重启保存，结果未知时按原任务核对；旧主机助手没有详细原因时明确提示尚未确认原因。

权限规则见 [ADR-181](../99-决策记录-ADR/ADR-181-操作资格统一使用有效权限与准确失败提示.md)，检查范围与分组测试见 [授权行为一致性记录](2026-10-16-全平台授权行为一致性检查与修复.md)。货品历史规则见 [ADR-182](../99-决策记录-ADR/ADR-182-货品操作历史与可控撤回.md)；表格、选择器和打印行为分别见 [MasterDataTableView](../02-组件库/MasterDataTableView.md)、[UtenGoodsPicker](../02-组件库/UtenGoodsPicker.md)、[UtenReferencePickerField](../02-组件库/UtenReferencePickerField.md) 和 [采购打印预览](../02-组件库/PurchaseOrderPrintPreview.md)。

## 兼容与发布边界

统一候选迁移头版本为 **V872，共 798 条**，在 v2.5.20 的 V870/796 基础上只追加 `V871__goods_operation_history.sql` 和 `V872__category_prefix_digit_start.sql`，不改写、删除或重排已发布迁移。V871 增加货品操作历史及对应审计、撤回和测试清空保留规则；V872 放宽四类主档分类编号前缀的首字符限制。

升级保留已有账号、授权配置、业务数据、数量与来源事实、稳定身份和客户端偏好，不通过重建数据库、重新分配编号或清空存储完成。迁移演练须从当前公司 V870/796 的完整配套备份创建隔离副本，先验证恢复，再核对升级后的 V872/798、旧行摘要、权限与附件原件；备份文件校验不能代替实际恢复。

现役 `simple-release.yml` 从同一最终提交构建应用 JAR、独立 migrator 和完整 Web，核对迁移集合、生成 SHA256 清单并签名上传 OSS，最后更新云端版本指针。该流程不生成原生桌面安装包，也不会自动安装 Linux 主机助手或 systemd 单元。

服务器继续通过设置页手动检查并选择立即或预约更新；自动拉取定时器保持停用。主机组件与应用版本分别验收，应用包不会自动安装主机助手或 systemd 单元；相关独立安装、worker 身份与能力要求见 [服务器运维说明](../../deploy/simple/SERVER_OPERATIONS.zh-CN.md)。公司升级已在本次最新授权范围内，仍须在最终 CI、签名制品、配套备份恢复和维护窗口核对后执行，并保留实际升级收据。

公司 LAN 测试清空能力的启用与关闭沿用 [ADR-067](../99-决策记录-ADR/ADR-067-工作台系统测试区与业务数据一键清空.md) 和 [现役 Runbook](../../deploy/simple/RUNBOOK.zh-CN.md)。截至本候选说明更新，尚未取得结束测试期或关闭该能力的新决定；不能为了“零警告”关闭测试能力、切换运行 profile 或降低既有告警等级，也不宣称现场开关已关闭或启动日志已为零 WARN。

## 手动更新后核对

1. 在服务器设置点击“检查版本更新”，应发现 `v2.5.21`；仅检查不会下载、迁移或重启。
2. 选择更新后查看同一持久任务的阶段和结果；断开或重连后继续核对原任务，结果未确认时不重复提交。
3. 更新完成后核对实际运行版本、健康状态与页面版本；刷新 Web 后应显示本版说明，原设置和业务数据仍保留。
4. 用已授权的非财务部门账号核对对应审批；再核对撤权后的按钮与操作拒绝是否一致。出现失败时，保留具体提示和任务标识以便定位。
5. 用系列与名称组合搜索核对模具/BOM 的分类范围、颜色和跨页选择；核对表格文字复制不改变业务勾选。按真实分类导出、修改并回导模板，核对编号、颜色、单位及既有未改字段。
6. 核对采购同单多行、供应商、各行订货与收货数量、当前筛选导出和打印财务审核人；有无金额权限分别验证。核对本人货品操作撤回、后续修改或业务引用阻止撤回、取消撤回及审计记录。

## 验证口径

已有跨模块权限、真实 PostgreSQL/HTTP、界面、表格搜索与选择、模板回导、采购打印及更新门禁的分组回归，只作为各自被测来源的证据。各分组有重叠，不汇总成最终集成的全量用例数字，也不以单一分支通过代替最终提交验证。

合并与发布要求最终提交的 Quality Gate、CodeQL 和依赖扫描通过，前后端构建、启动与日志按实际结果验收；主动触发拒绝的测试日志与真实服务告警分别核对，保留上述已授权测试期开关提示。实际发布结果以 GitHub Actions、签名制品、OSS 回读为准；公司升级、健康稳定性与真实岗位操作另记验收。本页不预填“CI 全绿”“已发布”“已安装”或“零 WARN”结论。
