# 模拟身份（切换人）

> 仅超级管理员可见。用于以目标员工真实视角核验其权限配置（工作台卡片 / 页面 / 数据范围 / 脱敏）是否正确。详见 [[ADR-022-管理员模拟身份]]。

## 入口

工作台首页（`/dashboard`）页头，仅 `is_super_admin` 且非模拟中时显示「切换人」chip（`ActionChip`）。模拟中由顶部常驻横幅接管「切换 / 退出」。

## 操作流程

1. 点「切换人」→ 弹密码框（二次密码确认，ADR-013）→ 输 admin 当前密码 → 进入模拟模式（限时窗口，默认 15 分钟）。
2. 打开目标选择器（搜索姓名 / 工号，始终以 admin 凭证加载 `/api/admin/impersonation/targets`，含「最近」高亮）→ 选员工。
3. 后端为该员工签发 `sub=目标` 的 staff token（带 `imp=admin`），前端进入目标视角；顶部横幅常驻 `正在以 {name} 身份查看（只读） · {dept} · {position} · 剩余 Xm · [切换] [退出]`。
4. 「切换」→ 免密再选员工（窗口内）。「退出」或窗口到期 → 恢复 admin。

## 行为要点

- **真实视角**：卡片 / 页面 / 数据范围 / 脱敏全部按目标权限（后端逐请求按 `sub` 重算）。不是前端预览。
- **只读**：模拟期间一切写 / 审 / 删 / 导出被后端 403 拦截（`IMPERSONATION_READ_ONLY`），前端 toast 提示。写按钮**不隐藏**——否则无法验证目标是否看得到该按钮（正是要查的配置）。
- **不跨重启/不跨标签页**：模拟键随标签页级存储（Web：sessionStorage，ADR-061），冷启动与关闭标签页都丢弃模拟状态，重新进需再输密码。
- 不能模拟超级管理员；目标账号须活跃。
