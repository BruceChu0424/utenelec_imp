## 一、为什么扁平（不分树）

老库 `B_Unit` 实测 `ParentID` 全为 0（66 行扁平），与 `B_Color` 同构（见 [12](12-基本单位-老库溯源.md) §一）。故新库**不建分类树**，仅一张扁平主档表 `units`，业务字段 `编号/名称/状态`。

---

## 二、新库表设计

### `units`（主档，Flyway `V40__unit.sql`）

```
id(UUID PK, default gen_random_uuid()) · legacy_id(INT UNIQUE=B_Unit.ID)
code(Number 编号) · name(Unit_Name，如 个/套/只/kg) · status(使用/禁用)
审计4列 · is_deleted · deleted_at
```

- 索引：`legacy_id` / `code` / `status`。
- 继承链：`Unit extends SoftDeletableEntity`。无审计触发器、无 `@Version`（与 goods/colors 同）。

## 四、后端 API

`/api/master/units`（扁平，无 categoryId）：

- `GET /api/master/units?keyword=&nullFields=&code=&name=&status=&page=1&size=20` → 分页
- `GET /api/master/units/facets` → 各字段可选值桶 + 空值计数
- `GET /api/master/units/dict` → 全量字典（货品编辑表单选单位用，按名排序）
- `GET /api/master/units/{id}` → 详情
- `POST`（`unit:edit`）→ 新建；`PUT /{id}`（`unit:edit`）→ 编辑；`DELETE /{id}`（`unit:edit`）→ 软删

请求体 `UnitSaveRequest`：`name`(必填) / `code` / `status`。
包 `com.uten.imp.features.master.unit`（`Unit` / `UnitRepository` / `UnitService` / `UnitController` + 6 DTO）。与 `ColorService` 同构。

## 五、老库迁移代码（仅 Shell）

| 路径 | 用途 | 文件 |
|---|---|---|
| **Shell** | 主档批量 | `migrate_unit.sql`、`migrate.sh --unit-data` |
| **导出** | 老库 → CSV | `export_legacy.ps1 UnitData`（→ `data/unit.csv`） |

无 Java 迁移器（同颜色，扁平非 SystemItem）。

### 5.1 设计要点

- 扁平入库；`name` `NULLIF(BTRIM(..., ' ' \|\| chr(12288)), '')`（修 ` 套` 前导空白，空串→NULL）。
- 保留噪音行（换算系数/开关插座名），保证货品引用不悬空。
- 幂等：`TRUNCATE units`（`session_replication_role=replica`）后 COPY+INSERT。

## 六、如何触发迁移

```bash
powershell -ExecutionPolicy Bypass -File server/legacy_migration/export_legacy.ps1 UnitData   # 老库→CSV
bash server/legacy_migration/migrate.sh --unit-data                                           # CSV→units
```

## 七、迁移校验（实测，2026-07-25）

```sql
SELECT count(*) AS total,
       count(*) FILTER (WHERE status = '使用') AS in_use,     -- 66
       count(*) FILTER (WHERE status = '禁用') AS disabled,   -- 0
       count(*) FILTER (WHERE name IS NULL) AS blank_name     -- 1
FROM units;
-- ✔ 单位 总 66，使用 66，禁用 0，空名 1
```

**结果**：66（使用 66 / 禁用 0 / 空名 1）——与老库 `B_Unit` 完全对账。trim 生效。

## 八、前端（与颜色/货品同级）

- `/basicinfo` → 基础资料 hub：新增 **基本单位** 卡片入口（`straighten` 图标）。
- `/basicinfo/unit` → **基本单位页**（`UnitPage`）：扁平列表，标题行 `[图标][单位(N)][搜索框][添加]` + 全屏 `MasterDataTableView` + 详情/CRUD（复用共享组件，流程同 `ColorPage`）。
- 列：编号 / 单位名称 / 状态；详情行加 `旧编码`(legacy_id)。
- **货品单位名称解析**：货品表「单位」列原显 `#unit_legacy_id`；现后端 `GoodsService` 按 `unit_legacy_id` 解析 `units.name`，列表/详情显示单位名（如「个」）。颜色同理（见 [11](11-颜色资料-新库与迁移.md) §八）。
