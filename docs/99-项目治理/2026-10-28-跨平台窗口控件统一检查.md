# 2026-10-28 跨平台窗口控件统一检查

用户范围：全系统、各平台统一窗口关闭及相关控件；公司资料库预览与 Windows 登录界面一致。按 `frontend-design` 执行，并复用 Uten 主题、组件和响应式规则。

上一轮补充曾要求关闭、缩小、展开紧挨组成一组，并采用 macOS 排列。用户最新修正：关闭必须位于最右侧；现行所有平台均从左到右为最小化、展开/还原、关闭，整组在窗口右侧，下载等工具不得穿插。最新要求覆盖此前排列要求。已新增公共 `UtenWindowControls`，原生控制条、浮窗及附件预览均迁入。组内没有额外间隔，普通桌面和原生圆形之间均为 8dp，缺少的控件不占位。

## 设计与比较

| 既有入口 | 原有能力与差异 | 统一处理 |
|---|---|---|
| `DesktopWindowHost._WindowButton` | 红/黄/绿实心圆、白图标，Windows/macOS 排列、原生拖动、固定 36dp 控制条 | 提取公共按钮，删除私有重复实现，保留原生尺寸和动作 |
| `UtenDialogHeader` | 统一弹窗标题、busy 禁用、提示、窄屏重排；关闭为灰色裸 × | 统一组合红色圆形 `UtenCloseButton` |
| `UtenPanelHeader` | 紧凑侧栏/选择面板、缩放补偿、动作组；关闭为裸 × | 同一公共关闭组件 |
| `UtenFloatingWindow` | 拖动、缩放、收起浮球、Esc 和草稿现场；控制按钮为裸图标 | 红色关闭 + 黄色最小化，保留回调、浮球动画和拖动边界 |
| 各模块自定义标题 | 原回调决定返回值、权限、忙态和未保存流程，图标和尺寸不统一 | 迁入公共关闭按钮，保留原回调与明确 48dp 命中尺寸 |
| 两类货品/基础资料操作历史 | 关闭文字放在刷新操作行 | 移到标题末端，使用公共关闭组件，保留 busy 守卫 |
| 公司资料库/附件预览 | 共享 `AttachmentPreviewDialog`，含下载、全屏、内容滚动和 Esc | 通过公共标题统一关闭；全屏/还原接入绿色公共组件 |
| 通知、目录、AI 聊天、追溯与位置选择 | 独立裸 ×，通知存在无 Overlay 测试宿主 | 统一红色关闭；无 Overlay 时保留语义标签并关闭 Tooltip |

配色取现有 `UtenColors.error/warning/success`，字号和主体布局沿用主题。普通关闭圆形 28dp、原生 22dp，保持同一视觉语言；桌面 40dp、触控至少 48dp 命中区。返回继续使用用户选定的品牌青色圆形 `UtenBackButton`。

- 公共实现与使用合同：[UtenCloseButton](../02-组件库/UtenCloseButton.md)。样式、禁用、焦点、语义、命中尺寸只在该入口维护。
- 公共标题、侧栏、浮窗和应用顶栏操作面板均已迁移；所有已有调用方同步获得统一样式。
- 逐项检查 `lib/components`、`lib/shared`、`lib/core` 和所有 `lib/features`；直接窗口关闭入口覆盖管理、基础资料、公司资料库、工作台、财务及应付款、通知、生产、品质、销售、库存和仓库。
- 初次图标审计后补查文字关闭、原生 `CloseButton`、`CloseButtonIcon`、Cupertino 控件和直接 × 字符；两个历史面板与品质详情标题也已迁移。
- 全部接入位置记录在 `output/window-controls-unification/source-callers.json`，含文件、行号和源码片段。该清单包括公共标题的间接接入，不代表每一个入口均由员工手工操作。

## 保留差异与清理

用户再次强调所有关闭入口一致后，补查全部 `lib`，取消早先对底部文字“关闭”的样式例外。功能专项最终补迁 48 个入口(47 个文件)，逐项清单见 `feature-close-migration-inventory.json`，包括权限失效、未知提交、明细、历史、价格、打印、上传队列和条件关闭状态；公共/共享的打印、导出、附件、权限失效、称重和再认证也补迁。发布说明、客户端发布、价格解释、批量结果、庆典和 AI 说明的纯退出同样迁入公共标题。已经有标题关闭时删除重复页脚关闭。

本轮还修复打印预览滚动后标题关闭离屏的问题：标题与关闭固定在滚动区外；320×320、2 倍字号使用紧凑标题，纸面与工具栏继续滚动。公共顶栏递归提取布局包装内的窗口控件，避免被收进“更多操作”或遗留在左侧。

保留表单决策“取消”的动作布局，保留系统文件选择器与系统日期/时间选择器。搜索清空、移除附件/规则/行、退出多选、业务驳回/取消、订单或询盘结案和状态 × 均不属于窗口关闭。没有关闭入口的流程不擅自增加关闭权限。条件状态区分真正关闭与取消决策，保留返回值及忙碌/未知提交约束。

最新位置复核将路由错误/无权页、销售/仓库任务中心、财务读取退役页和应付款详情/操作页的 13 处左侧关闭迁到右侧 actions，普通返回仍在左侧。`UtenAppBar` 保留右侧关闭和完整窗口组的独立空间；权限及业务动作在它们左侧，窄屏只折叠业务动作。

预览下载复用 `UtenButton` 的 tonal/small 样式、下载图标和本地化文字，保留加载状态与重复提交守卫，位于窗口组外的左侧。

原 `DesktopWindowHost._WindowButton` 已移除；公共标题和自定义窗口不再维护同责关闭视觉。原始关闭回调、返回值、未保存确认、busy/提交/下载禁用、Esc/遮罩/返回协议和身份权限边界由原宿主保持。公共按钮等待异步退出确认并防止连续激活，覆盖迁移前顶栏动作已有的防重复能力，避免草稿确认后连续 pop。没有修改业务计算或服务端。
