# 2026-10-23 业务清空永久删除验收

本轮按用户最新要求彻底删除“工作台 → 清空业务数据”，不再保留本地开发开关。决策见 [ADR-192](../99-决策记录-ADR/ADR-192-业务数据清空功能永久删除.md)，数据库说明见 [V919](../数据迁移/V919-业务数据清空功能永久删除.md)。原服务器撤权与网关封闭记录保留为历史证据，本轮没有连接或更新公司服务器。

## 删除与保留边界

- 删除前端系统测试区、清空弹窗、仓库、待确认记录读写、API 端点、专用权限与多语文案；本机 Debug 超管同样无入口。
- 删除 Java Controller、Service、附件清理实现、排水闸/过滤器/开关、专用 ports 与无效测试；通用调度器保留状态观测和正常关闭，AI 保留租约、取消和旧结果隔离。
- 移除平台扩展字段中仅服务于清空的保留标记接口、包装器及当前 SQL 写入；历史列保留兼容。
- V919 删除数据库清空入口与专用 helper，移除十二个普通历史保护函数的测试清空例外；保持正常六个物化视图刷新及原 owner 成员边界。清空专用权限及四类当前授权关联全部删除，活动权限模板清除旧码，已删除模板历史保留；退役时保留此前有效的负责人委派，不复活陈旧委派。
- 保留历史迁移原字节、审计名称和已有数据代际读取协议，防止旧草稿或 AI 结果复活；不执行任何实际业务清空、不修改业务记录或附件。
- 所有 Nginx 模板继续封闭旧命名空间；现行 YAML 与新装环境模板没有恢复开关。普通增量构建精确清理旧清空类与旧 AI 指导资源，避免源文件删除后生成类复活。
