# V628 车间路线随时可换与逐种物料事实

- 迁移：`V628__workshop_route_switch_and_material_facts.sql`。
- 决策：[ADR-095](../99-决策记录-ADR/ADR-095-车间路线开工前随时可换与逐种物料事实.md)。
- 依赖：V609 冻结耗用曲线与可产量函数；V611 路线门与增量备料；V618/V619 直送来源批次视图 `v_workshop_direct_supply_lots`；V622 按段物料覆盖集合。

只换函数/视图，不加表、不加列、不改任何数据行，重放由 Flyway 版本保证。

| 对象 | 变化 |
| --- | --- |
| `fn_can_change_execution_route(uuid)` | 冻结尺改为「段状态 ∈ WAITING/READY/DISPATCHED 且无日报行」；实际领料、直送投入、预留不再冻结路线 |
| `fn_execution_start_material_ready(uuid)` | 开工门按 `start_route`：CONTINUOUS = 各项必需料共同支持正产出(含开工同事务投入的指名直送料)；其它 = 每种物料实领量 ≥ 需求量。`continuous_supply` 只再表示「按增量备料」 |
| `v_production_execution_segment_materials` | `ready` 只对 `start_route='CONTINUOUS'` 接受部分覆盖；列清单与 V611 相同，依赖视图 `v_production_execution_segments` 定义不变 |
| `fn_execution_segment_material_summary(uuid)` 新增 | 每种需求只落一个桶：ISSUED / SHORT / SHORT_DIRECT / DRAWABLE / AWAITING_WAREHOUSE / LINE_SIDE_PENDING / PREPARING，另给已投料与已预留的可产量 |
| `fn_execution_segment_material_facts(uuid)` 新增 | 逐种数量：需求 / 预留 / 已申请待发 / 可申请 / 线边仓待投 / 净实领 / 缺口 / 直送已交接 / 直送待分配 / 状态 |

存量影响：所有活动工单的 `start_route` 与 `continuous_supply` 保持原值。已确认持续生产的工单
`continuous_supply=TRUE`、齐套工单为 FALSE，新旧开工门在这两种组合下结论一致，升级后没有任何
在途工单被新门锁住或放行。曾被旧冻结尺锁住的持续生产工单升级后即可在「我的车间任务」改选。

应用侧同批：`ProductionExecutionSegmentService.confirmRoute` 改路线时的 `continuous_supply` 更新规则
与开工侧 `requireMaterialsIssuedForStart`/`requireDispatchPreconditions` 改看路线；车间任务列表每行
LATERAL 汇总一次(计数查询不付这笔代价)；新增只读端点 `GET /api/production/workshop-tasks/{segmentId}/materials`
(`production_execution:view`，范围与列表同源)；到货进展卡缺口扣仓库可用量。

发布前应在恢复副本验证：旧持续生产 READY 工单改齐套后状态不退、实领事实不删；已开工工单改路线 409；
分批只在未动过的任务可选；混合供料工单的汇总桶与实际库存/领料一致；`v_production_execution_segments.material_ready`
对齐套工单在部分覆盖时为假。

回退：不能撤销迁移或改 Flyway 历史；若异常，前向再发一版把 `fn_can_change_execution_route` 收紧即可，
数据无需修补(本迁移未改任何行)。
