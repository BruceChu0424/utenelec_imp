# 39 - 销售单据归属授权（每个销售只看自己的单）

> 时间：2026-07-28 · 依据：用户要求把 V85/V86/V89 归属模型推广到销售单据
> 用法：`bash migrate.sh --sales-owner`（幂等，已挂 `--all` 末尾）
> 关联：[35 货品](35-货品归属授权-外贸按员工.md) · [36 客户](36-客户归属授权-按业务员.md)（同模型第四弹）

## 一、老库取证

- 归属源 = `seller_legacy_id`（老库 S_Order/S_Out/S_OtherOut/S_Withdraw.Emp_ID，已随单据迁移在库）。
- 分布（订货单）：尹志斌 1971 · 张龙 1753 · 苏君丽 854 · 王浩然 356 · 朱德洪 232 …
- 报价单（sales_quotes）老库无归属字段 → **本期不隔离**（全员可见）。

## 二、设计（同模型三件套 + 中间档）

| 件 | 设计 |
|---|---|
| `owner_employee_id` × 4 表（V91） | 订货 / 出货 / 其它出货 / 退货；NULL=公共 |
| 权限点 `sales:view:all`（V91） | 「查看全部销售单据」 |
| 数据范围 `user_data_scopes` scope='sales'（V91） | 中间档：权限管理页按人勾选「销售单据可见业务员」 |
| 过滤面 | 4 个销售 Service 的 list（Specification 谓词，与货品/客户同款）；`OwnerVisibility.evaluate("sales", "sales:view:all")` |
| 归属迁移 | `migrate_sales_owner.sql`：seller_legacy_id→employees.legacy_id，幂等 |

## 五、边界

- 报价单不隔离（老库无归属字段）；销售报表按单据展示不做行级隔离（管理分析口径，后续按需）。
- 销售出货/退货编辑页的「从上游引入」单据列表同样受 list 过滤（同源 Service），不会出现越权选单。
