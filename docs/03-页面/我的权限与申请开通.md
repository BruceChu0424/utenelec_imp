# 我的权限与申请开通

> 别名：没权限、打不开页面、无权访问、按钮是灰的、怎么开权限、找谁开通、缺少操作权限
> 路由：`/access-denied`(无权访问页)、`/page-permissions/:surfaceKey`(业务页右上角「权限设置」打开的本页权限设置)

## 一、定位

给全体员工看：打不开某个页面、看不到某张卡片、点了按钮提示没有权限时，是怎么回事、该找谁开通。给部门负责人看：怎样在业务页面上给本部门的人开通这一页的权限。

## 二、为什么会打不开或看不到

### 打开页面时显示「无权访问」

页面标题是「无权访问」，正文写「当前账号没有访问此页面的权限」和「如需处理这项业务，请联系权限管理员授权。系统未打开目标页面，也未执行任何操作。」，下面有「返回工作台」按钮。这说明你的账号没有这个页面需要的权限，系统没有打开页面，也没有做任何操作。

### 模块首页上少了几张卡片

各模块首页和工作台只显示你有权限打开的卡片。别人能看到、你看不到的卡片，就是你还没有对应的权限。

### 点了按钮提示「缺少操作权限」

能打开页面不等于能做页面上的所有操作：查看、新建、编辑、审核、红冲等操作各有各的权限。提示「缺少操作权限：…」时，说明你缺这一个操作的权限。可以把这句提示发给管理员，或者贴给 AI 工作助手，问它缺的是哪项权限。

### 数据只能看到一部分

有些数据还按范围控制，例如仓库人员只看到自己负责的仓库的单据，业务员只看到分给自己的客户。这是数据范围，不是页面权限；需要调整时请联系你的负责人。

## 三、找谁开通

### 部门负责人

你所在部门的负责人可以在业务页面右上角点「权限设置」，给本部门(含下级部门)的人开通这一页的权限。「权限设置」按钮只有部门负责人和超级管理员看得到。部门负责人由人事在「部门管理」里设置。

### 系统管理员

部门负责人开不了的权限(见下文「哪些权限负责人开不了」)，或者需要跨部门开通的，请找超级管理员在系统管理的「权限管理」里开通。

### 还没有登录账号

还没有登录账号的同事，要先由负责账号支持的人在「账号支持」页开通账号，再开通权限。员工档案里没有手机号时不能开通账号，要先在员工档案里补录手机号。

### AI 助手能帮我开吗

不能。AI 工作助手会回答「开通权限要由管理员在权限设置里办理，我不能代为授权。」它可以告诉你缺哪项权限、能不能打开某个页面，你再去找负责人或管理员。

## 四、部门负责人怎么给同事开权限

1. 打开要授权的那个业务页面，点右上角「权限设置」，进入这一页的权限设置。
2. 在左边按部门筛选，或按姓名、工号搜索，选中员工。
3. 右边只显示这一页的权限(部门负责人只看到这一页里自己有的权限)：打开表示开通，关闭表示收回，然后保存。
4. 保存后被授权的同事重新打开这个页面再试；仍打不开时，请他退出后重新登录再试。

### 哪些权限负责人开不了

右边的权限后面写着原因时不能修改，常见原因：

| 显示的原因 | 意思 |
|---|---|
| 不在你可转授的权限范围内 | 负责人只能把自己本来就有的权限转给别人；你自己也是别人转授来的权限不能再往下转 |
| 这项权限只随超级管理员身份生效 | 只有超级管理员才有，不能单独开通 |
| 超级管理员已明确收回 | 超级管理员对这个人收回过这项权限，负责人不能再开 |
| 已由基础、部门或中央个人授权生效 | 这个人已经通过部门配置或管理员开通有了这项权限，不用再开 |
| 不能修改本人权限 | 负责人不能给自己开权限 |
| 不能修改超级管理员权限 | 超级管理员的权限不在这里改 |
| 尚未开通登录账号 | 先开通账号 |
| 账号当前不可用 | 账号已停用或已删除 |

这些情况请找超级管理员处理。

## 五、权限是怎么来的

- 大部分权限按部门配置，同部门的人默认相同；
- 超级管理员可以给个人单独开通或收回；
- 部门负责人可以在业务页面上给本部门的人开通这一页的权限；
- 有些审核类操作除了权限，还要求你在相应部门在职，例如财务审核只有财务部门在职人员或被点名加授的人能做。

## 六、常见问题

### 我能打开页面，但按钮是灰的

按钮灰着有两种可能：缺这个操作的权限，或者单据当前状态不允许(例如财务正在审核时不能改订单)。把鼠标停在按钮上或看页面上的提示，一般会写明原因。委外任务中心里「等物料齐套」的申请不能勾选，是因为物料不够，不是权限问题，见[委外申请页](委外申请页.md)。

### 开通了还是打不开

先重新打开这个页面；还不行就退出后重新登录。仍然打不开，请把「无权访问」页面或提示的截图发给开通的人核对。

### 新来的同事怎么开权限

先确认他有登录账号(没有的话先开通账号，员工档案里要有手机号)。他所在部门的大部分权限按部门配置自动带上；还缺的页面权限，由部门负责人在那个页面右上角「权限设置」里开通，负责人开不了的找超级管理员在「权限管理」里开通。

### AI 助手说「这项暂时不能查看」

AI 助手按你的部门和权限两样一起判断能查哪些业务的数据。你不在这个业务的部门，或者没有这项业务的查看权限时，它就查不了。见[AI工作助手使用说明](AI工作助手使用说明.md)。
