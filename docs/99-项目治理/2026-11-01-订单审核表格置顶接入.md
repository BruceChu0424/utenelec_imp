# 订单审核表格置顶接入

基线 `bd7e8525b`；独立分支 `uimp/sales-review-table-pin-20261101`。本项为前端呈现与滚动交互接入，使用 `frontend-design`，沿用 Uten 主题、字号、间距与审核业务约束。用户明确手机端公共触摸协调由其他任务处理，本项不修改公共滚动组件。

## 公共入口与调用方

| 入口 | 已有实现 / 本项结果 |
|---|---|
| 销售单据列表 `sales_doc_list_page.dart` | 已使用 `UtenCollapsingHeaderScrollView` 与 `MasterDataTableView(primary: true)`，保留 |
| 订单进度 `sales_order_progress_page.dart` | 已使用相同公共入口，保留 |
| 出货任务 `sales_shipment_task_workbench.dart` | 已使用相同公共入口，保留 |
| 订单审核 `sales_manager_review_page.dart` | 将固定提示/筛选栏移入公共折叠头，表格启用 `primary`；待审核、历史记录以及报价/订货混合队列共用此实现 |

公共滚动权威仍为 `lib/components/layout/uten_collapsing_header_scroll_view.dart`，表体控制器由 `lib/features/basic_data/widgets/master_data_table_view.dart` 的 `primary` 接入。页面没有新增滚轮监听器、触摸手势、交接阈值或第二套滚动实现。

上滚先收起流程提示与分类/搜索栏，表格到达内容区上沿后才滚动数据行；反向先让数据行回顶，再展开顶部。交接截停、停顿窗和空行程继续使用公共默认值。顶栏刷新、表格工具条、表头和悬浮批量批准保持原入口；未知提交提示位于正文顶部，不随普通折叠头消失。权限、认领、金额精度、跨页选择、筛选、分页与未知提交的业务处理未改动。

## 平台范围与保留差异

- Web 与现有 Flutter 桌面共用同一 Dart 页面；本轮完成 Flutter widget 交互验证，没有声称已进行线上浏览器或公司环境验收。
- 手机仍接入公共容器的现有响应式分支；本轮既有窄屏布局、金额与悬浮动作回归通过，不代表窄屏触摸时序已解决。其公共机制按用户指定留给独立任务。
- Win7 WPF `W7-BIZ-217` 仍为 `todo`，该业务页尚未迁移。已在唯一台账追加本次呈现合同及手机任务边界，保留状态、负责人、DoD、既有证据和历史；没有开放原生占位写入口。原生后续迁移须对照同一“顶部收起→表内滚动→反向恢复”合同，不能把后端共享视为本端已完成。源指纹由最终集成任务基于 canonical 源统一刷新。
