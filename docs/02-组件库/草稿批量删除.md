# 草稿多选与悬浮删除

草稿列表复用 `MasterDataTableView` 的前置勾选框、表头全选与右下角 `batchActionsBuilder`，不在各页另铺底栏。交互骨架由 [DraftBulkDeleteMixin](../../lib/shared/mixins/draft_bulk_delete_mixin.dart) 统一提供。

## 页面接入

- 仅真实草稿分段且当前用户有该类删除权限时启用 `selectable`；`idOf` 对列表已标明的只读、历史、已审、财审中等非草稿返回 `null`。列表尚未返回负责人或可删标志时，仅对已选记录读取详情复核，避免加载整页详情。不能仅凭 `status=0` 判断出货/采购/委外草稿。
- `selectedIds`、`onSelectedIdsChanged` 分别接 `selectedDraftIds`、`selectDraftIds`。加载及执行删除时禁止新勾选；`rowKeyOf` 仍使用稳定业务 ID。
- `batchActionsBuilder` 返回 `buildDraftDeleteButton(documentLabel:, delete:, reload:)`。`delete` 必须复用原业务接口，按最新详情复核单据状态、对象权限及并发版本；详情读取之后再核对当前身份、页面与选择仍有效。
- 切单据类型、状态、历史、筛选、分页时清选择；重新加载后 `retainDraftSelection` 只保留仍在当前可操作范围内的 ID。
- 既有生产计划批量删除继续使用服务端单事务接口，不改成逐条删除；同样只允许草稿选择。

## 公共行为

1. 未选择时按钮禁用；确认弹窗显示所选数量与单据类型，取消不发删除请求。
2. 使用原删除接口逐条执行；只把确认成功的 ID 从选择中移除，明确失败保留并显示原因。
3. 网络超时、断连或服务端 5xx 不能断言删除未发生：停止后续删除，刷新列表并提示核对，不自动重试。
4. 操作期间防重复点击；确认后或执行过程中选择范围、登录身份变化即停止。
5. 完成后重取列表、分段数量和共享徽章汇总；刷新失败不把已经成功的删除说成失败。

覆盖销售订货进度及五类销售单据、采购三类、委外四类、钱流五类、仓库各类单据及任务中心内嵌草稿、生产计划/日报、本人报销草稿。仓库生产自动单与不可删除的库存调整记录、财务历史导入记录、报销版本已变化等情况按原业务边界拒绝。

回归包含共享删除取消/部分成功/不确定结果/身份隔离，以及各模块正常删除、权限和最新状态校验。保存后的审核跳转见[路由设计](../05-架构/路由设计.md)。
