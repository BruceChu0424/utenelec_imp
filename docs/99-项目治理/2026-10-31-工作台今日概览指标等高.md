# 工作台今日概览指标等高

- 范围：前端呈现，使用 `frontend-design`，沿用 Uten 主题、字号及间距。
- 来源：用户反馈“未读通知、待排产产品、执行中订单”高度不一致。
- 根因：后两项标题旁的 `UtenFieldHintIcon(dense: true)` 带最小点击高度，无提示图标的标题行仅由文本撑高，导致数字上移。
- 修复：`_StripMetric` 的标题行统一使用 `UtenEditableGridCellSpec.heightOf(context)` 作为最小高度，与提示图标共用尺寸来源；大字号仍可自然撑高，窄屏保留换行。

## 调用方与平台核对

| 平台 / 入口 | 处理与差异 |
|---|---|
| Web / Flutter 桌面：`DashboardPage → DashboardOverviewSections → _DashboardOverviewBody → DashboardOverviewPanel → _MetricStrip → _StripMetric` | 共用一个实现，全部指标同步生效，无平台或架构分支。 |
| Win7 WPF 候选：`DashboardView.Load → metrics → Surface` | 只读指标使用统一的纵向列表，每项为标题与数值同行的 `DockPanel`，没有可选提示图标造成的高度分歧；保留现有布局，本次无需对应代码修补。完整工作台迁移及 Win7 真机验收仍未完成。 |
| 后端 `/dashboard/overview` 及两端 DTO | 本次无契约、计算、权限、数值、来源或路由变更。 |

仅现行 `_StripMetric` 负责 Flutter 指标布局，无新增重复实现或需要迁移的平行入口。
