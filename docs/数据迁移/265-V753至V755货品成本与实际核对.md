# V753–V756 货品成本与实际核对

源码目录头为 V756/684。迁移安装事实需读取目标数据库，不能从源码头推断。

| 迁移 | 新对象与作用 | 保留/清空 |
|---|---|---|
| V753 | goods_cost_sheets、goods_cost_snapshots、goods_cost_commands、goods_cost_templates；确认快照、CAS/幂等及独立成本操作权限 | 四表 PRESERVE |
| V754 | 实际 COGS/覆盖视图、inventory_cost_gl_policy、periods、period_choices、links；按原价值过账追加凭证及目标期间 | policy PRESERVE；其余三表 CLEAR |
| V755 | goods_cost_imports、goods_cost_import_mappings；原文件对象身份、缓存证据、base_input 与应用结果，私有引用联合视图 | 两表 PRESERVE |
| V756 | 实物过账/价值取得原身份冻结、不可变守卫、原来源身份追溯函数及实际发货成本覆盖视图 | 不新增表，沿既有分类 |

权限新增 goods:cost:edit/confirm/export/template。已有 cost:view 不自动升级为写入、确认或导出；管理员按既有授权界面配置。原 goods:view、goods:cost:view 和对象范围仍需满足。

V754 不启用真实成本过账，也不重写已有 COST_CARRY。启用前应核对库存价值/总账差额、生效日期和遗留凭证，之后通过财务面板执行明确操作。回溯发现的新差额不会因业务日期在切换前被漏掉。

V755 的 evidence/base_input/result_input 只追加。工作簿保存于既有私有不可变存储，数据库记录版本、尺寸和 SHA-256；通用孤儿核对通过 v_private_document_storage_references 识别其有效引用。未知事务完成状态保留文件等待核对。

V756 不把今天的货品资料回填到旧实物或价值历史。新事实冻结货品和基本单位身份，旧事实沿已有不可变来源读取，证据缺失/歧义显式待核。历史金额区间沿原修订读取，不回退到当前节点余额。成本覆盖按实际发货/价值事件业务日期计算；即使缺价暂未产生金额过账行，也参与入账和关账待处理检查。

旧 Flyway 原件不修改。新测试须用真实迁移或准确增量基线，分别覆盖干净安装、来源读取、幂等与并发、不可变历史、业务清空保留及对象权限。
