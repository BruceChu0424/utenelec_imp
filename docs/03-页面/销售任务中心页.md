- **大类行**：订货进度 / 出货单 / 客户零星发货 / 退货单 / 报价单 / 历史其它出货。进页面不预选大类（未选显示引导空态，不发请求）。
- **各大类正文 = 原独立页整页嵌入**（embedded：小类行、搜索、表格、行级办理动作与独立页完全一致）：
  - 订货进度 → [销售订单生产进度](销售订单生产进度.md)（草稿/进行中/可发货/历史记录 + 六个小类；2026-09-25 大类行最前加「草稿」段）
  - 出货单 / 客户零星发货 / 退货单 / 报价单 → 销售单据列表页（各状态分段 + 历史记录时间门控）
  - 历史其它出货 → 列表页预选「历史记录」段（只读历史）
  - 嵌入页不自套 SafeArea/内容容器与顶部空行程（2026-09-24 修正：双重边距曾把
    小类行推离父分类行与左缘，现与仓库任务中心同款——宿主页统一提供容器与间距）。

    按钮）与历史时间行都放折叠头里随页滚走，body 只剩表格——大字号下滑到头后
    表头紧贴大类行 + 表格工具条之下；采购/出入库单据列表与报销列表同批对齐。

## 徽章口径（准则 14）

- 订货进度大类：红 = `salesAttention`（财务驳回 + 可分批发货，注册表入口）**+ 订货草稿**（`drafts.salesOrder`，2026-09-25 用户口径「草稿也要红色通知数量徽章」：本人开了头没交出去的单也是待办），黄 = `salesOrderInFlight`（在途订单数）——黄数与 hub「销售任务中心」卡角标同源同数。
- 订货进度正文（进度页）大类行另有「草稿」分段置顶：红徽章取 `progress/stage-counts` 的 DRAFT 桶（后端 `:stage='DRAFT'` 门控，草稿只进该段与计数桶，不污染链路大类/历史记录）；草稿行双击直达编辑页继续办单。
- 出货单大类红数 = 草稿 + 财务已退回（读 `documentStatusCountsProvider`，分段计数，不进注册表）；退货/报价大类红数 = 草稿。
- 客户零星发货刻意不挂：草稿与「出货单」同属 sales_shipments 同表，挂两处是同一批单数两遍（准则 14 §三）。
- 历史其它出货是只读历史，不挂数（准则 14 §二）。

## 与三段式的关系

hub（销售管理）= 任务中心卡（本页）+ 新建单据五卡（新建报价/订货/出货/客户零星发货/退货，creator-only 直达 `/sales/:seg/new`，一律不挂徽章）+ 报表 + 稀缺仲裁。
