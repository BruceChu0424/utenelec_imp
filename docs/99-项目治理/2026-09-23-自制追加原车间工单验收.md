# 2026-09-23 自制追加原车间工单验收

本轮修复物料分析准备页追加自制只合并计划、不合并车间工单的问题，并按用户后续要求把主表「需要数量」固定为销售/计划汇总来源需求。工单设计与迁移分别见 [ADR-104](../99-决策记录-ADR/ADR-104-追加自制并入未开工的生产计划.md) 和 [V647](../数据迁移/232-V647未领料车间工单原位追加.md)；来源 `sourceRequiredQty` 是无新迁移的只读投影/显示变更，实际执行 `requiredQty` 保留，见 [ADR-099](../99-决策记录-ADR/ADR-099-计划量单一入口与子层按计划产出展开.md)。

## 验收范围

| 场景 | 必须观察的结果 |
|---|---|
| 未执行任务 3000 追加 1000 | 计划和 ZX 工单 UUID/单号不变，原任务合计 4000，任务数不增加 |
| 原来源 3000、下单后再追加 1000 | 主表「需要数量」保持来源 3000，实际计划/工单及备料按 4000；预览、刷新、幂等重放不将来源量改大 |
| 多层 BOM、非基本来源单位、整包/固定批次 | 来源先乘根 `unitRate`，再按保存的精确规则逐边计量；来源需要量不从平均单耗或动态锚点配额推导 |
| 同物料多路径与汇总视图 | 每条真实路径分别计算来源需要量后相加，不因某一父件超量/追加改大；实际备料和下单建议继续按各路径计划变化 |
| 合法修改来源或 BOM 后刷新 | 来源需要量按新来源/依据重算；“固定”不等于永久保留旧来源数字 |
| 级联下单页列名与执行权威 | 动态需求列称「本批备料需求」；采购、委外、预留、缺口和车间物料仍使用实际 `requiredQty`，不被 `sourceRequiredQty` 替代 |
| 连续追加与同幂等键重放 | 每次新意图只加一次；重复请求不多建段、不重复加量 |
| 已有预留、未提交 DRAW | 原预留、DRAW 及来源保留，只补差额；实际叶仓不重标 |
| 原量已齐套、追加量缺料 | 不再宣称新总量齐套；保留旧准备事实，真实到料后补齐 |
| 固定批次/整包计量 | 按冻结耗用规则对累计产量取整；不能把追加数量单独取整后相加 |
| 已提交领料、未发料 | 追加另建新计划/工单，原请求与数量不被改写 |
| 已发料/开工/报工/拆批 | 原工单不改量，追加另建单 |
| 草稿、无料、未确认路线 | 草稿保持审核分权；无料不造空需求/DRAW；未确认路线不自动确认 |
| 销售归需求与公共备货、换车间 | 销售只累加归需求份；公共备货单独分账；车间不同另建单 |
| 并发追加与领料/开工 | 锁后重查边界；旧版本、旧预览不能跨增长写入 |
| 迁移、审计、清库 | 旧迁移字节不变；新证据表有审计且不可改删，目录 V647/598 与清库一致 |
