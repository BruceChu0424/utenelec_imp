本修复延续生产 2.5.43 `bd7e8525be1ef52db2a6cfb10268fdbd8310844c` 上的业务人员引用修复。已有新建、编辑、收货等动作包含该动作需要的辅助选择；不另授员工档案或主档查看权限，也不因此开放主档详情、财务资料和修改入口。本次不改变任何真实授权配置、产品版本或数据库迁移。

## 隐私和生命周期合同

客户、供应商关键词继续放在 POST 请求体，避免用户粘贴的联系方式进入 URL。`search` 和 `search-context` 四个新精确 POST 标为纯读取，不推进业务写修订号；其他 POST、未知提交和自动重试规则不变。面板保留现有会话、权限、服务器和范围版本围栏，过期响应、跨身份结果和混合版本的分类元数据不能回写。

业务侧栏不显示联系人、电话、地区、银行账号、税号或财务余额，不增加主档跳转。只取得辅助引用，不会获得主档写权限或改变单据本身的数量、金额、归属和后端校验。

## 2026-11-02 发布集成的后端边界修复

本次集成的架构回归实测发现 `master -> org` 新依赖：辅助主档权限直接调用人员引用服务，部门引用控制器直接使用组织部门服务及其私有 DTO。修复通过 `application.port.CurrentStaffAuthorityPort` 保留原 `BusinessEmployeeReferenceAccess` 的真实在岗、账号状态和最新授权快照校验；部门树沿用既有 `OrganizationReferencePort`，由组织适配器委托原 `DepartmentService.employeePickerTree`。唯一的六字段 `DepartmentPickerNode` 移入 application port，全部组织、人员和辅助主档调用方使用同一份投影，不复制树算法，不扩大允许的模块依赖表。

这是服务端代码边界修复：HTTP 字段、业务权限和候选范围不变，Web、Flutter 桌面及后续 WPF 调用的合同不变，原生未迁移状态不变。验证入口为 `ArchitectureBoundaryTest`、`OrganizationReferenceAdapterTest`、`DepartmentEmployeePickerSecurityContractTest`、`BusinessMasterReferenceHttpPostgresTest` 和 `BusinessEmployeeReferenceHttpPostgresTest`；本次集成的执行结果在发布回执中按实际源码单独记录，不能沿用上段的历史前端测试数。

### 根因与唯一公共入口

`624f779cc` 将公共选货切换为业务引用，`6d3674137` 的 `GoodsReferenceProjection` 无条件丢弃价格、折扣和库存合计；销售与 BOM 调用方仍依赖原货品列表中的这些值。结果是有标价的销售行显示空价、建议折扣回落到 1，重选仍然拿不到；BOM 组件价格与替换预览库存也受影响。

修复仍复用 `GoodsService.list → GoodsReferenceProjection → DioGoodsRepository → showUtenGoodsPicker`，没有新增逐行取价请求、第二套价格算法或通用详情权限。投影只透传 owning 服务已经脱敏的价格和折扣，库存预览单独要求原主档读取能力。搜索、分类、状态、对象范围、分页、排序和分桶仍用原实现；返回 `writable=false`，业务选择不获得主档写权限。

| 字段/入口 | 保留的权限与合同 |
| --- | --- |
| 货品价格 | `goods:price:view` 或原有 `goods:price:edit` 可见性；无权限不返回，不从业务创建、数据全看、财务或销售价格权限推定 |
| 主档建议折扣 | 独立的 `goods:discount:view`；价格权限不代替折扣权限，空/0 的单据默认策略保持不变 |
| 销售报价/订货的显示、保存 | 继续独立执行 `sales_order:price:view` 与服务端 `priceMasked`；不放开订单改价、报价核定锁价或服务器金额权威 |
| BOM 替换的库存预览 | 仅原 `goods:view` 可得到 `stockQty`，普通业务动作不获得库存合计或成本 |
| 单位、颜色、库位、起订量、订货倍数、所属仓库/车间、整批发料、分摊方式、每袋数量、回收料 | 按原业务引用合同完整保留；不把销售标价当采购/委外默认价 |

可执行的跨语言样例：[business-master-references/v1.json](../../contracts/business-master-references/v1.json)。价格/折扣仅样例中的合成回归数据，服务器仍读取并验证真实主档。
