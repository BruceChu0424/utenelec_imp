# 优腾·综合管理平台（Uten IMP）

> **Uten Integrated Management Platform** — 制造业 200–1000 人规模的一体化企业管理后台。
> 一套 Flutter 代码覆盖 手机 / 平板 / 桌面 / Web，按部门（行政与人力资源/生产/工程研发/PMC/品质/综合营销/新媒体/轨道/财税）+ 权限点分权展示。

## 🛠 技术栈

- **Flutter 3.41+ / Dart 3.x** —— 最新 stable，企业主流

- **go_router** —— 官方推荐路由，支持 Web/深链 + 路由守卫

- **flutter_secure_storage** —— access / refresh token 等敏感数据安全存储
- **very_good_analysis** —— 严格 lint 规则

## 🚀 如何运行

```bash
# 1. 安装依赖
flutter pub get

# 2. 生成国际化文件（修改 arb 后需重新生成）
flutter gen-l10n

# 3. 运行（自动检测平台）
flutter run

# 4. 指定平台
flutter run -d chrome        # Web（推荐：浏览器拉宽即可看到响应式效果）
flutter run -d windows       # Windows 桌面
flutter run -d android       # Android（需模拟器或真机）

# 代码检查
flutter analyze

# 格式化
dart format .
```

> Flutter SDK 安装见 https://docs.flutter.dev/get-started/install
> 当前已验证：Flutter 3.44.2 stable、Windows 桌面、Web 构建均通过。
>
> **本机 Flutter SDK 路径：`D:\Software\Flutter\flutter`**（Flutter 3.44.2 / Dart 3.12.2，
> 满足 pubspec 的 `^3.12.2` 要求；不在系统 PATH，Git Bash 里跑检查用：
> `"/d/Software/Flutter/flutter/bin/flutter" analyze`）。
> 注意机器上另有两个旧 SDK 不要用：`D:\Software\Flutter`（Dart 3.12.1，版本不够）、
> `D:\Software\flutter_flutter`（OpenHarmony 分支 Dart 3.9.2）。
> 若 PATH 无 PowerShell，需先 `export PATH="$PATH:/c/Windows/System32/WindowsPowerShell/v1.0:/c/Windows/System32"`。
