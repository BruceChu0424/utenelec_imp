# ERP 登录与远程办公使用说明

核对日期：2026-10-29。本文供员工和超级管理员照着操作，不涉及服务器密码、备份解密密钥或业务数据恢复命令。

**2026-10-29 简化**：远程办公不再需要绑定验证器、输入动态验证码或在管理端开总开关。外网访问只有一个
条件——超管在「账号与权限管理」里给该员工开通了外网授权；开通后员工在外网用与公司内网完全相同的
ERP 账号和密码登录即可。

## 先确认打开哪个网站

| 使用场景 | 入口 | 谁可以用、填什么账号 |
| --- | --- | --- |
| 在公司正常办公 | 公司原有 ERP 客户端或原内部入口 | 使用本人现有 ERP 登录账号和密码 |
| 出差、在公司外使用 ERP | [https://justplayit.cn](https://justplayit.cn) | 已获外网授权的员工；同一套 ERP 登录账号、密码，无其它验证 |
| 超管日常管理人员和权限 | 在公司内部入口登录原 ERP | 使用超级管理员自己的 ERP 账号，再从系统设置、账号与权限管理操作 |
| 公司主站故障时的独立救援 | [https://admin.justplayit.cn](https://admin.justplayit.cn) | 仅已单独绑定的救援超管；独立救援口令及独立动态码 |

## 超管：今天谁出差，就开通谁

1. 从公司**内部入口**，以超级管理员本人登录 ERP。
2. 打开「系统设置 → 账号与权限管理」（按员工）。
3. 搜索员工姓名、工号或登录账号，选中正确人员。
4. 在人员详情顶部的「云端(外网)访问授权」卡上点击「授权外网」，确认即生效。不再需要重新输入
   管理员密码，也没有人数上限。
5. 让员工在公司外的网络（例如手机移动网络）测试一次，确认能用同一 ERP 账号和密码登录。

需要收回时，在同一张卡上点击「取消授权」。授权变更（开通或收回）都会让该员工现有登录立即下线，
需要重新登录；这只控制从哪里能登录，不改变该员工原有的业务权限。

## 员工：出差时怎么登录

1. 用电脑或手机浏览器打开 [https://justplayit.cn](https://justplayit.cn)。不需要填写服务器 IP、端口或阿里云控制台账号。
2. 等 ERP 登录页面加载完成。外网线路带宽有限，首次加载大资源约需一分钟，避免反复刷新导致重新加载。
3. 输入与公司内网相同的 ERP 登录账号和密码，点击登录——和在公司里登录完全一样，没有第二步验证。
4. 登录后正常使用 ERP。桌面客户端同样会先自动探测公司内网，连不上时自动切换到外网入口。

没被开通外网授权的账号在外网登录时，页面只会提示「无法连接服务器，请检查网络连接后重试」——
这不是网络故障，需要先请超管开通外网授权。

## 常见问题

- **外网登录提示“无法连接服务器”**：先确认账号已获外网授权；若已授权仍连不上，检查当前网络或
  稍后再试，仍不行再联系管理员。
- **授权被收回后还能用吗**：不能。收回后现有登录立即下线，外网重新登录会被拒绝。
- **以前绑定的验证器还要用吗**：不需要了。动态验证码机制已于 2026-10-29 退役，验证器可以删除。
- **在家登录和在公司的权限一样吗**：一样。外网授权只开放登录入口，业务权限与在公司时完全相同。
