# 本机草稿历史与销售草稿字段候选

本包基于 Main `c4263d1e8b475ce56b58f3ce02cedb2441c17f4c` 的干净导出，属于 R2.01/R2.04/R2.05 的小包。集成及运行成绩以 `closeout15/topic-coordination/ready/draft-ui-b01.json` 与逐文件 SHA 回执为准；本文本身不表示已合 Main、安装、CI 或全模块验收。

## 本机留存与查询

原提交的删除会移除 payload，完成会只剩完成标记。本包对新保存、删除、完成保留不可变原快照，活动草稿保留终态标记阻止旧页面复活。已有格式的有效原草稿导入历史；旧版本已经删除的文件或已经丢失 payload 的完成标记不能恢复，不补造内容。

原生平台以用户/代操作人/服务器摘要隔离目录，使用独立 scope 锁、递增序号索引、不可变内容文件及落盘事务日志。重启先恢复未完成事务，再继续读写。历史页按序号 seek，每页只读取有界数量的元数据，点击一项才读取其 payload。新增记录不移动旧游标；损坏的单项保留并跳过。原格式文件用兼容终态标记隔离旧 writer。

Web 使用 IndexedDB v2，在同一事务中提交活动草稿、历史元数据、历史内容及 scope 序号。升级导入在版本事务内完成；旧页面阻塞升级时提示关闭旧页后重试。存储内容按设备/浏览器保留，不是跨设备备份；本包不实现自动销毁或历史清空。

## 当前权限与可见字段

历史入口复用每个 `FormDraftCategoryTable` 的类别范围，列表不读取 payload 或任意自由文本标题。进入历史只读详情不重新打开新建表单，不恢复已删除/完成的快照。用户、代操作人、登录纪元、服务器或权限改变时重新取数；已打开详情还校验原身份及类别。

公共历史读取 API 与显示采用同一份显式字段投影，不提供原始 JSON 入口。销售、采购、委外路由用现有配置核对模块、原创建权限和当前查看权限。价格字段再按当前独立价格权限（采购/委外复用配置的财务授权规则）显示。员工入职的证件/电话/银行信息与工资各按独立查看权限显示，不把编辑权限当查看权限。只读投影不能写回草稿；原始快照不因撤权而被清空。

当前可展示商业单据的已存表头标识、日期、行标识/来源、货品、数量/重量、客户型号与允许查看的价格，以及入职资料的已接通字段。字段缺失不补零。未知扩展列、附件、AI结果、冻结提交原包以及未接通的其它表单只保留原件，不递归展示其任意内容。其它模块 typed 投影及附件的当前对象权限仍需逐族接通，本包不宣称历史详情字段全面完成。

## 销售字段与保存链

修复旧草稿恢复后价格控制器仍渲染真实文字的问题。普通格、冻结格、金额与合计在当前权限撤销时一并遮蔽，重新授权可继续读取原值；服务端 priceMasked 继续作为额外约束。客户文件原价遵守既有 IntakeResultFilter 合同，不能和系统销售价格混作同一权限字段。

已填写的可选机加价、围数、材料价、压铸价等沿用原 Uten 网格列并显现。既有草稿往返继续保留数量原文、自身行ID、双来源ID、颜色/单位、客户文件值、行备注和扩展列。恢复后向既有 API 的请求回归不能替代数据库实际落库验收。

订单进仓数量由下游事实派生，SalesOrderService 不接受客户输入为真值。本包将该列标为只读历史参考并停止在订单保存请求中上送，旧草稿原值仍保留。没有新增业务数据库列或改变数量核算。

## 验证与剩余

### R1 共享依赖组合

依照 `topic-coordination/shared-contracts/ui-r1-v3.json`，保留本包原始预审快照后，核对 SHA 并接入 `form_draft.dart` 与纯路由 helper，按输入至输出差量手动组合 `form_draft_store.dart`，没有覆盖本组历史机制或其它任务文件。该依赖包原先仅静态准备，不将其当作已运行成绩。

当前仅持日报查看权限的原身份可以核对已冻结的原提交；这不等于模拟身份的 `AuthenticatedScope.readOnly`，后者保持不得读取专用原请求或确认的边界，但仍可按当前权限查看本机历史。确认检查原身份/服务器、完整协议字段、原文字节摘要与回执，并走同一 CAS；成功才产生历史，失败不写检查点或幽灵历史。普通保存不得擦掉或更换已有冻结命令。非 ACTIVE、完成标记、key/ID 错配、迟到身份变化及损坏协议均拒绝，原件保留。

日报协议的 `bodyJson` 与畸形协议值不进入公开草稿或历史投影。公共历史先作通用 typed 敏感字段投影，再作协议移除。通用**活动草稿**仍承载各编辑器/弹窗的完整恢复输入；不能直接删掉其价格、附件等字段，否则下次自动保存会丢失原文。全活动 Provider 的敏感投影需要原编辑恢复链先接入独立的私有读取接口，此接口需与 FormDraftMixin 的当前拥有者组合；本包没有冒充完成该项。

保存/CAS 的成功 Future 等待本机事务写入及锁释放；Web 成功由 IndexedDB transaction.oncomplete 确认。身份切换会另启新作用域读取，等待旧请求结束不代表新读取也结束。Provider 销毁后清除其作用域、权限与存储引用，并拒绝保留旧 Notifier 引用发起的新操作；已进入文件事务的 I/O 不承诺撤销，但只能完成在原来绑定的作用域，不能更新新会话状态。编辑页 widget 关闭仍可沿原有写入 Future 保存，两种销毁不能混同。运行证据及生命周期边界见本批回执。

新增路由 helper 依赖完整 R1 恢复页面/路由包。本包的共享存储验证不能替代 R1 页面验收，集成方须组合相应功能包后再验证导航。

候选目录内执行定向静态分析。Flutter VM/界面及真实 IndexedDB 测试须在协调 grant 下执行，精确命令、源码清单、成功/失败/跳过与日志写入同批 receipt，不引用旧 WIP 成绩。

本包没有修改生产日报页面/仓储、FormDraftMixin、原生附件历史、system_test_area、已合迁移或实际数据库/8080。其它模块的完整字段/真实持久化、大范围布局/键盘/返回链、历史数据权限策略和最终组合运行仍属于父步骤剩余工作。专用测试清空的本机历史边界也须由该功能拥有者明确接入，不以普通删除或过期清理代替。
