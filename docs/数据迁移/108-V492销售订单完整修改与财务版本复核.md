# V492 销售订单完整修改与财务版本复核

日期：2026-09-07。状态：本地源码候选；未提交 GitHub，未访问或修改公司目标数据库。

## 业务变化

销售自审后，财务尚未认领或已结束审核时，销售可从订货详情和订单进度详情进入“修改订单”。尚无物料分析、排产、出货、客户预收或正式应收等关联事实时，允许修改表头、折扣、数量以及增删明细。保存复用原行 UUID；更换商业身份的行使用软版本留存，释放并重建有效预留，自动重新提交财务。被驳回的完整修订仍先回草稿，销售核对后自审重报。

已有下游事实的订单继续使用改量专用命令及其锁定量、执行分摊和预留守恒校验。不能通过完整编辑更换已有收款/发运的客户、币种或货品。财务驳回修改后数量时保留当前数量与历史事实；销售可继续受控改量重报，或在满足取消守卫后取消。减量刚好结清剩余承诺的订单仍必须进入财务复核，不会因 `is_closed=true` 丢出待办。

## 数据结构与兼容

- `sales_order_revision_logs` 保存每次商业变更的前后 JSONB 快照、操作者和实际变化时间。快照同时保留关系 UUID 与当时显示内容，财务看到可读的前后值。
- 新表有 `(order_id, changed_at DESC)` 索引、`fn_audit` 行级审计和禁止 UPDATE/DELETE 的触发器。历史 `sales_order_qty_change_logs` 同步补不可改写守卫，V482/V483 字节保持不变。
- `sales_orders.finance_review_revision` 单调递增。存量改量日志按每单可证明的事实数量初始化版本；不伪造旧订单修改详情、审核人或审核时间。
- `business_data_reset()` 的受控清理白名单登记 `sales_order_revision_logs=CLEAR`，配套 ops 脚本与审计覆盖测试同步维护。
- 上次 `finance_confirmed_at` 作为本轮展示基线，确认后修改清单归档隐藏，事实日志不删除。新改量时间使用 `clock_timestamp()`，避免等待锁的事务开始时间落在上次确认之前而漏显示。

## 并发与接口

- `SALES_ORDER_FINANCE_CONFIRM` 认领和续租先锁销售订单；销售修改、改量、取消等在同一订单锁内拒绝任何有效认领，包括操作人自己持有的财务认领。
- 财务详情先认领再读取。确认/驳回拒绝他人的认领，办结释放租约。过期租约先 flush 释放唯一键，再创建替代认领。
- 所有任务类型的心跳续租共用新认领的权限、员工身份与目标资格校验；撤销对应操作权后续租返回 403，不能刷新租约。权限仍有效也不能替他人续租，销售订单离开可审核状态后不能继续占用。
- 财审认领、续租和接管还复用实际审核资格服务。销售沿用 `SalesOrderFinanceConfirmerEligibility`，采购/委外沿用 `WorkflowReviewerEligibility`，保留有效个人明确授权例外；不把单独持有权限当成审核资格。采购/委外认领接受有效 `finance_order_approval:approve` 或 `:reject`，不再使用已退役的 `:review`。释放及强制释放继续允许清理已办结任务。
- 单笔确认/驳回提交 `expectedRevision`；批量确认提交按订单 UUID 映射的 `expectedRevisions`。有过修改的订单缺版本或版本不符均返回 409。版本 0 继续兼容旧客户端；客户端不能用无版本请求越过新商业修改。
- 列表和计数均支持 `changesOnly=false/true`，分别为首次审核与修改复核；省略继续返回原合计口径。修改页路径 `/finance/sales-order-changes`，详情沿用 `/finance/sales-order-confirmations/:id`，权限沿用 `sales_order_finance:view/confirm`。
- 批量操作固定锁序、全部版本校验通过后才统一确认，任一版本冲突整批无确认事实。

## 验证与边界

定向单元测试覆盖完整差异提取、旧版本拒绝、批量版本失败无写入、自持认领阻止销售写入。真实隔离 PostgreSQL 测试覆盖整单编辑、折扣金额重算、行 UUID 保留、首次池转修改池、审核中编辑/取消拒绝、再次修改后的旧版本冲突、确认后归档与日志禁止改写。Flutter 定向测试覆盖首审表格、批量确认、只读权限、修改详情、深链返回和驳回取消。

这些证据仅说明源码与隔离库行为；不替代公司非空库回放、真实多岗位浏览器验收、历史资金/库存对账和恢复演练。旧来源已执行的订单不能通过绕过守卫修改历史商业与资金事实。
