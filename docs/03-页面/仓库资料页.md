# 仓库资料页

基础资料的仓库资料沿用货品资料的 `frontend-design` 方案和 Uten 主题，使用相同配置的 `UtenSplitView`、`UtenCategoryTreeView`、`UtenHierarchySearchHeader` 与 `MasterDetailCard`。左侧目录使用层级铺色、整行展开和选中反馈，可搜索名称、编号并按用途、状态筛选；右侧为简洁资料卡和即时库存表。窄屏保留搜索头，通过共享目录入口选仓。

- 左树行内新增、编辑、删除复用货品页的 `UtenHierarchyNodeActions`；按钮和右键/长按菜单由同一份 `UtenHierarchyNodeOperations` 生成，同一权限与回调只定义一次。菜单还提供启停、设置负责人。主仓加号新建直属子仓，普通子仓加号新建同级仓；两者上级都固定为主仓，不能形成第三层。主仓没有删除、停用入口；车间内料仓没有新增、编辑、删除、启停入口，仍由车间内料仓模块管理。
- 信息卡使用标题、副标题展示编号、上级、用途、位置、核算、车间、负责人、状态与备注，管理按钮归入左树。仓库目录的打印导出在页顶；库存的打印导出在表格工具条，各自使用对应权限。
- 编辑复用货品的 `MasterInlineEditController`、`MasterInlineEditActions`、`MasterInlineEditGuard`、懒加载字段单元格，以及基础资料的 `MasterInlinePageMixin`。点左行编辑或右下「编辑模式」后，`MasterInlineRecordEditor` 将相同单元格排列成资料字段网格，不再走旧的整表编辑弹窗。新增仍用共享 `MasterEditForm`。
- 编辑模式支持逐字段修改、跨仓保留草稿、统一「保存 N 行修改」与「取消编辑」。刷新、搜索、筛选、资料历史、启停/删除及离页复用未保存确认；账号、服务器或权限变化立即清除旧草稿。库存表在编辑模式下继续只读。
- 保存复用 `PATCH /master/inline-edit/warehouses/{id}` 的字段原值比较与行锁，只上送变更字段，未改备注、车间等字段由服务端保留；并发冲突保留未保存草稿并提示刷新，不覆盖后续修改。每仓为独立事务，已保存行从草稿移除，失败行保留。仓库原有服务继续复核单主仓、内料仓、库存引用和启停权限。V887 将仓库 PATCH 接入同一操作历史锁与审计链。
- 库存按实际存放仓查询，不能用货品所属仓代替。主仓汇总下级核算仓并明确提示；具体仓库包含自身真实库存，线边仓、不良品仓与非核算叶仓均可直接查看。
- 库存表与独立即时库存页共用列定义，补全分类、货品名称、编号、颜色、系列、库位、主档归属仓、型号、客户型号、规格、备注、库存数量与重量、待检量、合格待入库量、多排数量。数量内联单位，重量保留估算与未知语义。只保留该仓真实余额(含零余额)或待检、待入库记录，不会列入全公司的无关空零货品。
- 表格恢复表头设置、全屏、服务端支持的颜色/系列/主档归属仓筛选、排序、分页与每页条数、全范围总数与合计、重量单位和打印导出。未获接口支持的列不做当前页文本筛选。打印分批读取最多前 2000 行；下载沿用 `stock_report:export`，同步传递 `warehouseRelatedOnly` 和当前筛选范围。主档归属仓列为归属事实，不代替库存实际存放仓。
- 双击库存行进入已有出入库流水，保留仓库、颜色或无颜色、仓库类型和来源页。返回后刷新该仓库存。快速换仓、搜索、账号或权限变化时，旧响应不能覆盖当前结果。
- 仓库资料查看不自动授予库存查看。即时库存及流水仍要求 `stock:view`，成本继续由服务端遮罩；没有库存权限时显示明确提示且不请求库存。已打开打印预览在撤权、换账号或换服务器后也清除内容，不能继续打印旧数据。

接口复用 `GET /stock/instant-inventory`，仓库资料传 `warehouseId`、`warehouseRelatedOnly=true`、`includeDefective=true`、`includeLineSide=true`。`warehouseRelatedOnly` 默认关闭，仅选仓时生效；列表、总条数、合计、facets 和分类定位共享服务端条件，原独立即时库存页的默认行为保留。

实现：[WarehousePage](../../lib/features/basic_data/pages/warehouse_page.dart)、[WarehouseInventoryPanel](../../lib/features/basic_data/widgets/warehouse_inventory_panel.dart)。回归覆盖页面分栏和响应式、详情及库存迟到响应、权限撤销、单色与无颜色流水、真实仓库库存存在性及原即时库存兼容。

架构登记：既有 `WarehouseInventoryPanel` 只读复用库存模块的查询模型、仓库范围、查询仓储、列定义以及服务端报表合计契约，不另写一套数量汇总或权限裁决。`basic_data → stock/report` 仅登记此面板，架构测试同时钉住精确来源文件，不能据此给其它主档增加跨模块业务调用。该核对同步已存在的页面设计与主线代码，不改变库存、成本或单据写入行为。
