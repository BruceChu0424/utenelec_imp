# 字体与界面大小规范

> 当前实现（2026-10-13）：所有设备按个人界面倍率整体缩放，默认 100%。文字、图标、按钮、卡片和组件间距一起变化；系统非线性字体缩放原样继承。窗口变窄由响应式布局换行、换列处理，不自动降低所选倍率。

### 一.1 档位与默认

新选择提供 85%、100%、115%、130%、150%、175%、200%，另有“自动（100%）”。所有窗口都显示这些选项，不按窗口大小隐藏、截断或降低倍率。旧 `xSmall` 75% 保存值照常恢复，只在已经选中时显示为兼容档。

- 自动档采用标准 100%，继承系统显示与无障碍设置，不根据 DPR 或窗口大小自动缩小。
- 宽屏不再额外乘“窗口宽 / 1920”；宽屏通过增加列数、并列面板和表格工作区利用空间。
- 每个倍率都代表同一套组件整体等比变化。320 宽手机在 200% 下按 160 宽画布重排，不能保留固定桌面宽度并裁剪。
- 字体、图标、控件内边距、点击区域与卡片内容同步变化；卡片宽度仍受视口约束，高度随内容增长。外层装饰留白可以按可用空间收敛。
- 缩小档的触控目标以窗口口径保持至少 48，由 `UtenControlMetrics` 换算画布下限；不能让画布 48 经 85% 后变成不可点击的 40.8。

85%～200% 的档位阶梯用于保留既有选择和渐进调整，并非研究证明的唯一最佳比例。[W3C Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)要求可放大到 200% 且不损失内容或功能；[Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)要求通常内容能在等效 320 CSS 像素宽度重排。具有二维语义的数据表仍可横滚，分类栏和普通表单不能以横滚替代重排。

### 一.2 个人偏好与旧值迁移

`fontScaleOwnerProvider` 采用真实操作者 UUID，代操作时为 `actor.id`，正常登录时为 `user.id`。本机 `SharedPreferences` 使用 `fontScale.user.<UUID>`；没有服务器同步或设备指纹，同一个账号在不同设备可独立调整。

旧 `fontScale` 键及所有档位值保留原样。第一次真实登录时，`fontScale.legacyMigration` 一条 JSON 记录同时绑定账号与旧初值，其他账号不得回读该全局值。已有个人键优先；首次账号即使已有个人键，也认领遗留值，防止第二人误继承。匿名和登出界面使用标准 100%。

个人选择按操作次序落盘。账号变化、登出、provider 销毁或更新选择后的迟到响应不得更新当前界面；原操作只写入开始操作时捕获的账号键。

### 一.3 缩放、系统字号与坐标

`UtenDisplayZoomBox` 在手机、平板和桌面统一使用 `OverflowBox → Transform.scale → SizedBox`，先通过窗口命中范围，再进入按“窗口尺寸 / 界面倍率”布局的有界画布。`MediaQuery` 的 size、devicePixelRatio、padding、viewPadding、viewInsets、systemGestureInsets 和 displayFeatures.bounds 同步换成画布口径，保护安全区、软键盘和折叠屏铰链。

系统 `TextScaler` 原样保留，尤其不能使用 `TextScaler.linear(system.scale(1))` 取代非线性策略。`context.scaled()` 仅让邻近图标等跟随系统正文 14 的比例，不再重复乘应用倍率。[Flutter 指南](https://docs.flutter.dev/release/breaking-changes/android-14-nonlinear-text-scaling-migration)建议在系统字号 200% 下验证可用性。

浮层使用 `LayerLink`、`localToGlobal(ancestor:)` 或 `overlayBox.globalToLocal()`。窗口 globalPosition 与画布 Overlay Positioned 不可混用。滚轮只在 `UtenDisplayZoomPointerEvents` 入口统一除一次倍率，不在表格和页面再次补偿；Shift 横滚、触控板精度、触屏拖动和平台默认响应保持原契约。

大字号下表格仍遵循“先收页面头部、再滚表内”的既有交接次序，不能因进入紧凑布局改变滚轮语义。

## 二、字体资产

- UI 字体族：`NotoSansSC`。
- `assets/fonts/NotoSansSC.ttf`（4,092,516 B）是主 UI 字体，包含既有子集及本轮数据库审计发现的
  7 个额外缺字；`assets/fonts/Roboto-Regular.ttf`（515,100 B）提供独立西文字形。
- `assets/fonts/NotoSansSCFull.ttf`（17,772,300 B）仅打印/PDF 时按需加载，不进入 Web 首屏。
- Web 镜像 Flutter 3.44.2 engine 的全部 724 个 Noto fallback WOFF2（144 family，
  共 21,739,792 B）到 `web/fallback_fonts/`，由 `fontFallbackBaseUrl` 指向同源并按缺字懒加载；
  PWA service worker 不预缓存这些分片。这样优先保证严格 CSP、离线可控和历史/未来罕见字完整性，
  同时避免把完整打印字体塞入首屏。
- `.github/scripts/verify-font-assets.ps1` 在 CI 构建前校验 Flutter 版本、5 个本地字体/许可和
  724 个 fallback 分片，共 729 个资产的文件大小与 SHA-256；manifest 不得包含本机绝对路径。
- 本轮对 161 张表、719 个文本列、9,245,430 个非空值、86,674,055 个字符做字形覆盖审计，
  当前库缺字为 0。后续每次全量迁移都必须重跑 glyph coverage gate，不能把当前快照当永久保证。
- Noto 与 Roboto 许可证随仓库保留；替换、升级 Flutter 或再子集化时必须同步许可、manifest、
  SHA-256 和中文/符号缺字检查。

## 三、页面用法

使用 Material type role：

```dart
final text = Theme.of(context).textTheme;

Text('页面标题', style: text.headlineSmall);
Text('正文', style: text.bodyMedium);
Text('辅助信息', style: text.bodySmall);
```

不要在页面重新乘 `FontScale.factor`；全局整体缩放已生效，系统 `textScaler` 独立继承。只有确需与文字同步的图标或
紧邻固定尺寸，才使用：

```dart
Icon(Icons.info_outline, size: context.scaled(20));
```

组件间距保持设计 token，随应用整体倍率一起变化。文字变大时允许换行和容器增高；外层装饰留白可按可用空间收敛。

整体缩放树必须先以窗口坐标进入 `OverflowBox`，再由 `Transform.scale` 转到有界画布 `SizedBox`。不能把窗口大小的OverflowBox放在Transform之下：75%/85%时会出现右侧和底侧的可见区域无法命中的死区。窗口边缘四角点击、拖动、滚轮/Shift横滚和菜单必须实测；滚轮仍只在绑定层换算一次。

## 3.1 fontSize 硬编码的收敛与豁免（2026-10-13 口径）

业务/组件的文字层级统一从 `theme.textTheme.<role>` 取值，禁止另建页面字号阶梯。
完整应用主题下不使用数字字号兜底；兼容不完整主题的兜底不代表产品默认值。
当前阶梯由 `uten_typography.dart` 统一定义：
48/36/28 为 display，24/22/20 为 headline，18/16/14 为 title，16/14/13 为 body，
14/13/13 为 label。普通正文/输入用 bodyLarge，密集表格和业务值用 bodyMedium，
辅助说明用 bodySmall。字重、颜色、行高、字距按语义 `copyWith`；不要再以旧角色
表映射或把普通辅助文字强制降至 10～12。

豁免清单（保留固定数值，不视为债）：

- **打印/PDF/纸面复刻**：`pw.TextStyle`（pdf 包）与 A4 纸面预览（固定磅值对齐纸面）；
- **图形绑定注字**：环形进度图中心百分比、头像首字（size×比例）、size 参数化的小徽章
  （如 UtenNotificationBadge、待排产逾期徽标）——尺寸跟图形走，不跟文字层级走；
- **组件尺寸变体体系**：UtenButton/ClickGuard 等 sm/md/lg 档位自带的字号阶梯
  （与 iconSize/padding/最小高联动，属组件设计 token，非文字层级）；
- 定义层 [`uten_typography.dart`](../../lib/core/theme/uten_typography.dart) 是统一字号来源；明暗主题调用同一个 `buildUtenTextTheme`，不另存字号表。

## 四、禁忌

- 禁止用固定高度裁剪可变字号文字。
- 禁止页面写第二套字号倍率或覆盖 `MediaQuery` 为固定 1.0。
- 禁止把正文转成图片。
- 禁止只用颜色/字号表达状态，仍需文本或语义。
- 禁止为“对齐”关闭系统字体缩放。
- 禁止在整体缩放之下混用窗口坐标与画布坐标：`localToGlobal()` 不带 `ancestor`、手势
  `globalPosition` 是窗口坐标，Overlay 里 `Positioned` 是画布坐标（偏倍率倍）；定位浮层走
  `LayerLink` / `localToGlobal(ancestor:)` / `overlayBox.globalToLocal`。
- 禁止 `ReorderableListView`（SDK 拖影混用坐标），拖手柄换位用 `UtenDragReorderList`。

## 五、验收

- [ ] 所有手动档及自动档即时生效；原 75% 和其他旧档可恢复。
- [ ] 所有窗口可选 85%～200%，窗口变化不降低倍率，不根据 DPR 抵消系统设置。
- [ ] 字体、图标、按钮、卡片、间距在手机/平板/桌面同步放大；普通内容可换行、换列。
- [ ] 同设备账号 A/B 设置独立，登出为标准；代操作不写入目标员工，旧全局值只迁移一次。
- [ ] 连续选择按顺序落盘；换账号、登出和销毁后的迟到写入不覆盖当前界面。
- [ ] 系统非线性 TextScaler 在多个字体角色原样继承，系统 200% 下无关键文字丢失。
- [ ] 320/390/768/1280/1536/1920/2560 宽窗口、横竖屏与分屏检查，分类栏与表单不水平拖动。
- [ ] 安全区、键盘避让、手势区域和折叠屏几何正确；浮层锚点、点击、拖影与拖条命中正确。
- [ ] 滚轮窗口位移不随倍率加速，Shift 横滚和触控板小增量保持；表格滚动交接保持。
- [ ] 所有档位触控目标在窗口口径至少 48；中文、英文、长姓名与金额边界检查。
- [ ] Web 首屏只解析主 UI Noto + Roboto；fallback 同源懒加载，打印字体按需加载。
- [ ] 字体供应链和数据库 glyph coverage 按既有发布流程复核；打印/PDF 保持纸面字号契约。
