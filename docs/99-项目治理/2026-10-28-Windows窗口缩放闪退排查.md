# Windows 窗口缩放闪退排查（本地测试）

## 现场与已确认原因

本地测试安装包为 `2.5.35+2535`，安装路径为 `D:\Software\UIMP-LocalTest`。
用户报告登录后第一次展开，或反复展开、还原至第三次时进程退出。
已实际复现；Windows Application Error 同时记录 `0xc0000005` 和后续
`0xc000041d`，故障模块为 `flutter_windows.dll`，RVA 为 `0x3e745`。
安装目录 EXE、引擎 DLL 的 SHA-256 均与打包输入一致。

使用当前 Flutter 3.44.2 对应的本地 PDB 和 LLDB 解析现场 dump，调用链为：

```text
FlutterPlatformNodeDelegate::ChildAtIndex
AXPlatformNodeWin::GetTargetFromChildID
AXPlatformNodeWin::get_accChild
oleacc!AccessibleChildren
UIAutomationCore
Win32 message pump
```

`GetUnignoredChildAtIndex(index)` 返回空后，原引擎直接调用 `id()`；故障指令读取
`[RAX+0x48]` 时 `RAX=0`。现场请求子项 1，对应索引 0；调用方已通过缓存的子项数量检查，
但实际查询没有对应子节点。现有 dump 缺少相关堆页，不能进一步认定缓存失效的具体生命周期。

## 修复与验收边界

原先仅启动 10 秒的 smoke 检查没有覆盖登录后的窗口操作，不能作为该问题的验收证据。
每个候选必须实际覆盖展开、还原、最小化/恢复，并在操作后遍历原生无障碍树。
不使用屏蔽 `WM_GETOBJECT`、关闭所有 Semantics、吞掉访问异常或修改二进制指令作为修复。

原生控件已增加稳定的明确无障碍按钮节点，保留重复激活保护和业务关闭的等待/忙碌保护。
取消原生控件的悬浮 Tooltip；普通业务控件仍保留 Tooltip。
主工作目录并行新增的 `DesktopWindowHeaderSurface` 和根 Overlay 保留。
这些控件改动通过 61 项定向 Flutter 回归和定向 analyze，但不能独立证明引擎崩溃已解决。

## 收尾复核捕获的第二条失效路径

第一版空节点保护已完成新增 7 项、delegate 共 15 项及 bridge 15 项回归；
其客户端也完成了原生 53 步窗口动作。但正常客户端仍于本地时间 22:17:39 发生异常，
新引擎 SHA-256 为 `a5f0e1c7d685a022995ce49ed8529fb72523b0a3e9634ac10a8b0754af23df14`。
该候选未发布，桌面副本已移至任务的 rejected 目录；公共打包器也已拒绝此精确摘要。

新栈为 `memcpy → AXNodeData::GetStringAttribute/GetString16Attribute → get_accValue → UIA`，
读取字符串的源地址无效。栈上没有直接析构帧，但不能据此排除滞后 COM 查询和节点销毁交错。
对应 dump 缺少 delegate 堆页，具体释放点没有被直接证明。

源码另确认两项生命周期漏洞：AXTree 的失败提交可能已释放节点却未完成删除通知，
而成功重挂载的 `OnNodeReparented` 回调原本没有将 delegate 绑定到新 AXNode。
后续修补在拓扑变化批次预检完整候选，必要时补全可达子树再提交；属性/几何更新保留快路径。
重挂载只更新底层 AXNode 绑定，保留原生对象身份。新增回归必须验证字符串读取、
delegate 与 live tree 指针一致，以及下一批标签/值/形状更新仍可用，不能只证明进程不退出。

本次仍只准备本地测试更新：目标显示版本 `2.5.36`、构建 `2536`，连接
`http://127.0.0.1:8080/api`，本地 catalog 在
`D:\uten_legacy_rehearsal\20261023_latest\storage\client-releases`。
最终发布沿用独立 `client_release:publish` 权限和本人再认证；截至本记录未创建或发布版本。
用户要求的展开/还原动效采用保留标准窗口样式的系统 DWM 过渡，且不在失活/最小化时抢回焦点。
