# 车间内料仓盘点页

> 2026-09-28 新增, 设计依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md) §5.7、§5.8。手机优先。

车间内料仓 (原名线边仓) 不设固定盘点周期: 什么时候需要就盘, 有盘点权限的人就能盘。相邻两次盘点之间是一期。提交盘点时系统按"截至本期的账面 − 实盘"当场过出本期实际用量, 随后在后台自动结算, 把用量按"报工量 × BOM 单个重量"的比例分进各工单成本。想按月对账, 请在月底盘一次 (页面有提示, 不强制)。

## 入口

- [车间内料仓页](车间内料仓页.md) 的「盘点」按钮。
- [仓库任务中心](仓库任务中心页.md) 大类「车间内料仓」小类「盘点」, 列出各内料仓本期状态, 点"打开盘点页"。

## 一期的四个状态

开着 → 盘点中 → 已盘点 → 已结算。

| 动作 | 什么时候能做 | 结果 |
|---|---|---|
| 开始盘点 | 本期"开着" | 在开始清点实物的那一刻点。截止日默认今天, 一键可选"截止到昨天" (交班时盘)。本期变"盘点中", 下一期同时开出; 之后发的料、退回、其它耗用都算到下一期 |
| 录入 | 盘点中 | 逐行保存, 两人可以同时录; 每行点完就存, 断网只影响正在录的那一行 |
| 撤回盘点 | 盘点中, 且下一期还没有任何进出和盘点 | 本期回到"开着", 刚开出的下一期删掉, 已录的数不保留 |
| 提交盘点 | 盘点中 | 系统核对后按实盘过账, 本期变"已盘点", 后台开始自动结算 (1-3 秒提交完, 结算结果稍后出来) |
| 更正盘点 | 已盘点 (含撤销结算之后), 且下一期还没提交盘点 | 填更正原因, 出一张新版本盘点单 (带上一版全部的数), 可以补上漏盘的料; 改完再提交, 系统按新数自动重新结算 |

## 录入方式

**机台卡片** (每台机一张, 来自[车间内料仓设置页](车间内料仓设置页.md)的机台与容器): "3 号机 | 在用料 | 干燥机料斗 [满|半|空] | 储料桶 [满|半|空]"。

- 档位说明写在页面上: 超过四分之三算满, 四分之一到四分之三算半, 不到四分之一算空。满 = 容量, 半 = 容量的一半, 空 = 0。
- 用量很小的料可以改"直接填公斤" (称得公斤)。
- "本机停机、全空"一键把这台机的容器都记空。
- 先选这台机在用的料, 再点档位。

**袋料** (每种料一张卡): "整袋 __ 袋 × 每袋 __ 公斤", 每袋默认取货品资料的每袋净重; 开口袋可以加多行过秤数。搅好还没上机的料, 选主料、填公斤。

**其余记 0**: 列出"有账或本期有进出、但还没填"的料, 一次确认全部记 0 (用完了的料要明确填 0)。

**打印空白盘点表**: 打印后现场手写, 再回来录入。

顶部显示进度: "已录 X / Y 个容器, A / B 种袋料"。

## 提交时的核对

提交前系统检查, 不满足就列出来不让提交:

- 本车间启用的每台机的每个启用容器都要有一行 (提示"还有 N 个容器没录: ...")。
- 截至本期账面不为 0 或本期有进出的每种料至少一行, 0 也要明确填 (提示"还有 N 种料没填: ...", 并提示用"其余料都用完了, 记 0")。
- 过秤行要填公斤或删掉; 还有行正在保存时稍等再提交。

提交后:

- 实际用量 = 期初 + 领入 − 退回 − 其它耗用 − 期末实盘。大于 0 记"内料仓盘点耗用"; 小于 0 (实盘比账上多) 记"内料仓盘盈", 产品本期这种料分 0。
- 截至本期的账面 = 实盘。
- 结算在后台进行, 页面显示"已提交盘点, 系统正在自动结算", 每 2 秒查一次进度, 这次结算尝试结束后自动刷新本期。后台每尝试一次结算 (不管成功、被拦还是失败) 都会更新这一期, 所以提交后要更正时, 等状态刷新后再点"更正盘点"; 如果提示"这一期已被别人改过", 刷新页面再点一次即可。

## 结算被拦住时

只有三种会让数据算错的情况才拦结算, 系统自动通知该补的人, 补完自动结算 (每 10 分钟重试一次, 有盘点权限的人也可以点"立即重试"):

| 情况 | 谁来补 |
|---|---|
| 截止日及以前还有没审核的报工 | 报工审核人审核; 不要的草稿由制单人删掉 |
| 有产量但 BOM 里没填单个重量的产品 | BOM 维护人补单个重量 |
| 某种料有产品在用, 但这一期从来没发进过内料仓 | 仓库在直接发料里勾"这批料是上一期漏录的"补录; 或车间核对是不是认错了料 (改认料或换料) |

其它异常 (有实际没理论、盘盈、浪费率超出范围、试模清机等用料偏多) 不拦结算, 在[用量与结算页](车间内料仓用量与结算页.md)标红。

## 给开发看的对照

- 路由 `/workshop-material/count?periodId=` (没有期间 id 时回车间内料仓页), 页面 [workshop_material_count_page.dart](../../lib/features/warehouse/materialbin/pages/workshop_material_count_page.dart), 卡片 `machine_count_card.dart`、`count_bag_material_card.dart`, 打印用 `UtenPrintPreviewButton`。
- 路由守卫 `workshop_material:count`; 查看盘点单要 `workshop_material:view`。按钮只看 `allowedActions` (如 `EDIT_COUNT`、`SUBMIT_COUNT`)。
- 接口: `POST /api/workshop-material/periods/{id}/start-count`、`/withdraw-count`、`/correct-count`; `GET /api/workshop-material/counts/{id}`; `PUT`/`DELETE /api/workshop-material/counts/{id}/lines/{clientLineKey}` (行键由页面生成: 容器行、整袋行、过秤行各一种前缀); `POST /api/workshop-material/counts/{id}/zero-rest`、`/submit`。盘点页只拿到期间 id, 靠 `GET /api/workshop-material/periods/{periodId}` 找盘点单, 截至 2026-09-28 服务端尚未提供 (ADR-131 §17.7)。
- 过账: 21 型"内料仓盘点耗用"、22 型"内料仓盘盈"及各自原路冲回; 更正与已盘点补录共用一个对称过账调整方法。自动结算见 ADR-131 §17.2 (提交后投递后台执行器, 属性 `uten.workshop-material.auto-close.enabled`)。
- 测试: `test/features/warehouse/workshop_material_count_page_test.dart`; 服务端 `WorkshopMaterialCountPostgresTest`、`WorkshopMaterialClosePostgresTest`。
