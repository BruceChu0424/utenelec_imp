# 自适应布局组件

> 当前布局能力以 `lib/components/layout/` 为准。断点判断优先使用父容器约束，而不是假设窗口宽度等于内容宽度；最后核对：2026-07-30。

---

## 一、选择指南

| 场景 | 当前组件 |
|---|---|
| 页面内容最大宽度与 gutter | `UtenContentContainer` |
| 普通卡片瀑布流 | `UtenResponsiveGrid` |
| 服务端分页卡片 | `UtenPagedGrid` + `UtenGridPager` |
| 列表筛选 + 表格（上下） | `UtenListTwoPane` |
| 响应式表单 | `UtenFormGrid` |
| 筛选区 | `UtenSegmentedFilter` / `UtenFilterToolbar` |
| 可折叠区块 | `UtenCollapsibleSection` |
| 区块标题/底部动作 | `UtenSectionHeader` / `UtenBottomActionBar` |
| 单据可编辑明细 | `UtenEditableGrid` |
| 主数据/报表表格 | `MasterDataTableView`（基础资料模块共享实现） |

项目没有 `UtenMasterDetail`、`UtenTwoPaneLayout`、`UtenContentWidth` 或 `UtenScaffold`。
应用壳位于 `features/shell/`。

---

## 二、按容器宽度适配

页面可能被侧栏、弹窗或分栏挤窄，因此用 `LayoutBuilder` 的 `constraints.maxWidth`：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 600) return const CompactBody();
    if (constraints.maxWidth < 840) return const MediumBody();
    return const ExpandedBody();
  },
);
```

`MediaQuery` 适合读取安全区、键盘 inset、屏幕方向等设备信息，不适合决定嵌套内容的列数。

## 三、卡片集合

### 3.1 `UtenResponsiveGrid`

默认按父容器宽度形成：

- `<500`：1 列
- `500–799`：2 列
- `800–1099`：3 列
- `1100–1499`：4 列
- `1500–1899`：5 列
- `≥1900`：6 列

可以通过 `UtenResponsiveColumns` 覆盖 compact/medium/expanded 列数，并用
`minColumns`/`maxColumns` 限制。`itemBuilder` 的第三个参数是真实格宽，卡片内部需要时据此适配。

该组件按索引轮流分配到独立 Column，视觉上是分栏瀑布流，不保证严格的逐行阅读/键盘顺序。对
严格表格语义或需要按行比较的数据，使用表格组件。

### 3.2 `UtenPagedGrid`

长列表优先使用服务端分页。`UtenPagedGrid<T>` 负责当前页展示和分页控制，但后端仍必须：

- 1-based 页码和受限页大小；
- 确定性排序，最后包含唯一键；
- 返回 `items/page/size/total/totalPages`；
- 过滤与排序在数据库执行。

不能因为使用了分页 UI 就先拉全量数据。

## 四、列表—详情与表单

`UtenListTwoPane` 用于列表页的「筛选在上 / 表格在下」编排（2026-09-10 起所有断点统一「筛选在上 / 表格在下」，不再左右分栏）：筛选区整宽渲染并按可用高度 45% 封顶、内部可滚，表格区 `Expanded` 占满剩余高度；极矮视口（横屏 + 超大字号）整体改为可滚并给表格最小可用高度。左右分栏只保留给分类树主档页的 `UtenSplitView`（树 + 详情，不是筛选 + 表格）。
调用方提供清楚的业务状态；不要重新创建不存在的 `UtenMasterDetail`。

`UtenFormGrid` 统一字段网格，但校验、权限和提交状态仍在页面/Provider。底部主要动作使用
`UtenBottomActionBar`，异步提交使用 `UtenActionButton`。

---

## 五、滚动与约束

- 一个轴向只设置一个主要滚动容器，避免嵌套无限高度。
- 表格横向滚动由表格组件处理，不在页面再套第二套同步滚动。
- 列表 item 使用稳定 key，分页切换后释放不再需要的页面数据。
- 键盘弹出时表单仍能滚到错误字段。
- 使用 `SafeArea` 处理系统区域；桌面宽屏仍通过 `UtenContentContainer` 控制阅读宽度。

---

## 六、可访问性

- 窄屏重排不能改变动作含义或隐藏必要信息。
- 文字放大时允许换行，不用固定高度裁切。
- 触摸目标至少约 44 logical pixels。
- 只靠左右位置表达主次的布局，在 RTL/键盘阅读顺序下仍须合理。
- 双栏切单栏后，返回操作和焦点落点必须明确。

---

## 七、检查清单

- [ ] 列数按父容器而非屏幕宽度计算。
- [ ] 长列表服务端分页、稳定排序、页大小有上限。
- [ ] 没有引用已删除或从未实现的布局组件。
- [ ] 无嵌套无限滚动、溢出和固定高度文字裁切。
- [ ] compact/medium/expanded、字体放大和键盘路径已验证。
- [ ] 选择的布局符合数据语义：卡片、列表、表格、编辑明细不混用。
