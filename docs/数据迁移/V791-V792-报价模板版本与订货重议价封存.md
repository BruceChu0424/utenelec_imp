# V791–V792：报价模板版本与订货重议价封存

关联业务规则：[ADR-139](../99-决策记录-ADR/ADR-139-销售报价议价客户确认与货品报价历史.md)。

V791 在 `sales_quote_template_evidence` 增加确切模板版本及人工确认列映射，并约束其不能覆盖。历史版本仅在来源任务能唯一对应不可变版本时回填；无法证明时留空，要求重新上传核对，不能用今天的模板版本代替。已清理的 AI 任务不会删除客户长期学习知识。

V792 在 `sales_orders` 增加首次替代报价 UUID、人员和时间。仅原订单按业务规则安全终止后才能登记重新报价；首次登记不能夹带客户、状态、金额等业务字段改写，登记后旧订单永久只读。新报价取消或删除不解除封存。没有为历史订单猜测或回填替代关系；受控测试清空继续需要原有鉴权证明。

两条均为前向迁移，保留原报价、订单和价款历史，不修改货品资料价格。部署须备份并核对迁移顺序，同批升级服务端与客户端：下载请求增加报价与模板版本，重新报价后的订单有明确只读状态。旧客户端不能通过省略版本绕过验证。

不得通过修改旧迁移、删除采用证据或清除首次替代字段来降级。尚未接受新业务时可按发布方案恢复一致的升级前备份；接受新业务后应保留商业事实并前向修复。
