# V732 制造公共供给按来源筛选后计算

- 日期：2026-09-26；源码目录 V732／661。
- 迁移：`V732__scoped_make_public_supply_reader.sql`。

全量合单压力测试发现：制造公共备货视图先物化所有计划来源，计算全库成品实收和认领，再由调用方筛选当前分析。随着无关生产历史增加，仅办理十组物料也可能达到原有事务超时。V729 解决的是采购和委外公共供给，这条制造来源查询仍需单独处理。

新增唯一计算函数 `fn_preplan_make_public_supply_sources(target_analysis, source_plan_item)`，直接继承原视图十五列及完整数量表达式。分析筛选在来源 CTE 内按同主仓、货品、颜色、单位及有效物料执行；单条来源校验直接按计划明细 UUID 筛选。实收和认领只计算选中的完整来源，不裁剪认领行、不改变私有/公共份额、身份、计量或取消规则。

原视图改为两个空参数的兼容包装，返回列及类型不变。候选查询、准备预算和写入前完整锁范围使用按分析查询；认领余量复核、成品入库分账及三个数据库守卫使用单来源查询。所有原数量和权限守卫保留，未调高超时、放宽失败门槛或改变事务回滚行为。

不新增业务表，不改库存及业务历史。迁移从当前定义精确生成新的函数并替换已确认的调用点，定义不符合预期时中止；旧迁移字节不变。应用依赖 V732 时应先备份并前向迁移，再激活对应服务。回退应用可继续读取兼容视图，保留新增函数；本文件不是现场部署或数据库安装证明。

验证包括原视图十五列类型及完整结果等价，认领、部分取消、实收、停用和按真实成本顺序完整反向，分析及单来源范围，以及十组独立/关联物料合单在原门槛内完成。无关来源探针证明旧分析联接会访问范围外来源，而新分析及单来源读取不会；旧视图精确点查原本可以下推索引条件，不将其误称为必然全表计算。完整回执和未完成的全量边界统一见[收尾记录](../99-项目治理/2026-09-26-领料申请批量出库与编号收尾.md)。
