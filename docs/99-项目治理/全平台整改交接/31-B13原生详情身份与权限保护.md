# B13 原生详情身份与权限保护

销售、采购、委外、财务详情统一保护已显示内容、未返回请求、输入框及确认窗口。身份/服务器/只读状态改变时，旧内容隐藏、旧窗口退出、旧回调不能重新发布数据。权限刷新加载或失败时不使用上一次权限继续显示；确认后重读原生详情，重新获取价格遮蔽、允许动作及当前范围。同身份采购输入保留；基准数量或占用变化会阻止保存，用户核对后才能采用当前基准。

首次进入也必须等非空登录身份和已确认权限；等待期间不发详情 GET，确认后只发一次。接受结果时同时核对确认代次、身份、访问代次和请求代次，避免迟到的首次权限把旧价格或旧动作带回页面。
