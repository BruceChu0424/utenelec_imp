# 2026-10-28 货品导入三模式与组装信息ID回导

> 会话批次：货品资料导入/导出四项改造（导入模式三选一、组装信息ID 回导、AppBar 导入入口、导出文件名/路径弹窗）。与 2026-10-28 早前「/分隔+仅系统标识匹配」批次同树叠加，全部未提交。

## 需求定稿（用户口径）

1. **AppBar 右上角加「导入货品」**：原入口在表格工具条左簇，必须先在左侧树选中分类才挂载；AppBar 入口不依赖分类选中。工具条入口保留（2026-10-19 口径）。
2. **导入三模式**：所有入口先弹三选一——新建货品（不看系统标识、全部新建、类别沿用文件列）/ 修改货品（只按系统标识匹配在库货品走差异核对，未匹配行报错）/ 混合导入（现行为，默认）。模式名用户允许微调，最终采用上述三个。
3. **组装信息ID**：不采用「是否复制组装信息」是/否列，不改数据库结构。导出新增「组装信息ID」列，值=「货品编号-BOM」（有组装信息才有值，无则空）；导入该列有值即把该编号货品的整棵组装信息复制到本行货品下，空=不复制。三种模式均生效。
4. **导出文件名/路径弹窗全站统一**：所有 `UtenExportButton` 导出先弹文件名（必填）+保存位置（桌面版，默认**桌面**，可浏览）+密码同框；Web 只有文件名。

## 实现要点

### 后端（server/src/main/java/com/uten/imp/features/master/goods/）

- 新增 `importing/GoodsImportMode.java`（CREATE_ONLY/UPDATE_ONLY/MIXED，宽松解析 CREATE/UPDATE 简写）。`GoodsImportDetectRequest/GoodsImportCommitRequest` 加 `mode` 字段；Controller 五个端点带 `@RequestParam(required=false) mode`（octet-stream）/ body 字段（JSON）。**重载形态：mode 放全参形态末位**——mode 放首位会与既有 `(byte[], Map)` 重载产生 null 调用二义性（编译期实测）。
- `GoodsImportService`：detect/commit 各加一个 mode 末位全参重载，旧短重载委托 MIXED；`detectParsed` 分派——CREATE_ONLY 跳过 UUID 身份解析（保留编号占用/复用历史拦截，报错文案带「新建导入请清空或修改该编号」）；UPDATE_ONLY 对无 UUID/未匹配/软删三情形行报错。`ImportPlan` 固化 mode，`requireAndConsumePlan` 校验 detect/commit 一致。
- 组装信息ID：`HEADER_ALIASES` 加 `bomRef`（组装信息ID/id/Id）；后缀常量 `-BOM` 定义在 `GoodsExportProjection.BOM_REF_SUFFIX`（goods→importing 单向依赖）。检测 `planBomCopy`：剥后缀→normCode→按编号查在库货品→查运营组装行（`findGoodsWithOperationalRows`/实体行缓存）→组件未删未停用可见、`goods:bom:create`（替换已有组装另需 `goods:bom:delete`）→错误记行；指向自身返回 null（回导默认值无操作）。提交 `copyBomOnImport`：目标无组装行=APPEND、有=REPLACE（expectedItemIds 取自 `findOperationalEdges`），行带 `copiedFromBomItemId` 保留源行内容，整体走 `GoodsBomPasteService.paste`（可见性/停用/成环/权限全套校验复用）。**撤回零改动**：`goods_bom_items` 在操作历史 TABLES 里，导入事务写的 BOM 行随同一笔 GOODS_IMPORT 历史操作 replay 恢复。
- merge 行只有组装复制没有字段变化：`hasWork` 加 `bomSourceGoodsId != null` 分支；`applied.isEmpty()` 早退前先复制 BOM 再 `merged++`。
- 导出：`GoodsService.export` 加「组装信息ID」列（`g.isHasBom() ? code+"-BOM" : ""`，list 已算 hasBom）；`GoodsExportProjection` 强制保留列集 +1（bomRef→组装信息ID）。
- 依赖注入沿用字段 `@Autowired`（`bomRepo/bomPaste/bomAccess`），构造器不动，既有 ~15 个手工 `new GoodsImportService(...)` 的测试零改动，新测试用 `ReflectionTestUtils.setField` 打桩。
