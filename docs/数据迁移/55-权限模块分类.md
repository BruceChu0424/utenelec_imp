# 权限模块分类（V228 基线 + V234 增量）

> 权威来源：`V228__permission_module_taxonomy.sql` 基线；V234 新权限在 `V234__production_material_analysis.sql` 就地写 module/category
> 配套：[权限管理页](../03-页面/权限管理页.md)、[54-部门默认权限矩阵](54-部门默认权限矩阵.md)
> 日期：2026-08-07

## 模型

权限目录两级分类，由 `permissions` 表两列驱动：

| 列 | 级别 | 含义 |
|---|---|---|
| `module` | 一级·功能模块 | 基础资料 / 销售管理 / … / 系统管理（共 11 个，顺序固定） |
| `category` | 二级·子类 | 货品资料 / 销售订货 / … |

后端 `GET /api/admin/permission-catalog` 按 `(module, category)` 分组下发；前端「功能模块 → 子类 →
权限项」两级折叠。一级模块显示顺序由 `DepartmentPermissionAdminService.MODULE_ORDER` 固定，
不依赖 `sort_order`。

## 设计原则

- **按功能模块命名，不用部门名**：权限按功能划分，一个部门常跨多模块（如财务部同时管财税 + 部分基础资料），用部门名会把财务部权限拆散。
- **合并历史拆散的同域分组**：库存（旧「库存」+「库存管理」）、生产（旧「生产」+「生产管理」+「生产计划」+「生产报表」）、报销（旧「报销」+「员工报销」）。
- **质检/收货待检随单据流**：`sales_return_quality:*` 归销售、`procurement_inspection:*` 归采购；品质检测模块仅留实验室 `lab:test:*`。
- **V228 只改分类，不改授权**：不增删权限点、不动 `department_permissions`，有效权限计算不变。
- **新增权限点须就地写 module + 规范 category**（在各自的版本化迁移里），避免落入兜底「其他」。

## 归类表（module → category → code）

### 1 基础资料
- **货品资料**：goods:view / edit / export / view:all / price:edit / cost:view / discount:view
- **物料分类**：material_category:view / edit
- **模具分类**：mould_category:view / edit　·　**模具**：mould:view / edit
- **客户分类**：client_category:view / edit　·　**客户资料**：client:view / edit / export / view:all
- **供应商分类**：supplier_category:view / edit　·　**供应商资料**：supplier:view / edit / export
- **颜色**：color:view / edit　·　**单位**：unit:view / edit　·　**币种**：currency:view / edit / export
- **仓库**：warehouse:view / edit　·　**账户资料**（银行账户）：account:view / edit / export　·　**收付款类别**：payment_style:view / edit

### 2 销售管理
- **销售报价**：sales_quote:view / edit
- **销售订货**：sales_order:view / edit / price:view / change_planned / priority / reallocate / confirm_partial_shipment
- **销售出货**：sales_shipment:view / edit / reject / warehouse-work　·　**其它出货**：sales_other_shipment:view / edit
- **销售退货**：sales_return:view / edit / disposition　·　**销售退货质检**：sales_return_quality:view / handle
- **销售报表**：sales_report:view / export　·　（含 sales:view:all 全单可见）

### 3 采购管理
- **采购申请**：purchase_request:view / edit　·　**采购订货**：purchase_order:view / edit / submit_finance
- **采购收货**：purchase_receipt:view / edit　·　**采购退货**：purchase_return:view / edit
- **采购报表**：purchase_report:view / export
- **到货异常**：supplier_return_task:handle　·　**收货质检**（IQC，采购/委外共用）：procurement_inspection:view / handle

### 4 委外管理
- **委外询价**：subcontract_inquiry:·　**委外申请**：subcontract_application:·　**委外订货**（含 submit_finance）：subcontract_order:
- **委外进仓**：subcontract_receipt:·　**委外材料出仓**：subcontract_material_issue:·　**委外退货**：subcontract_return:
- **委外材料退货**：subcontract_material_return:·　**委外材料损耗**：subcontract_waste:（以上各 view/edit）
- **委外报表**：subcontract_report:view / export

### 5 生产管理
- **生产计划**：`production_plan:view` / `production_plan:edit` / `production_plan:forward_rd` / `production_plan:approve` + `production_plan_cost:view` + `production:view`（旧遗留）+ `planning_supply_request:view`（MRP 缺料）
- **物料分析**：`production_material_analysis:view` / `production_material_analysis:manage` / `production_material_analysis:route` / `production_material_analysis:notify` / `production_material_analysis:generate` / `production_material_analysis:reallocate` / `production_material_analysis:bom_override`
- **生产日报**：production_daily_report:view / edit　·　**生产报表**：production_report:view / export　·　**物料反查**：production_where_used:view

V234 对上述新增权限写入 `module='生产管理'`：7 个 `production_material_analysis:*` 使用 `category='物料分析'`，`production_plan:approve` 使用 `category='生产计划'`。`bom_override` 不授任何部门，只允许超级管理员固有能力或逐人加授；权限管理页不得因“本模块全部授权”把它批量放行。

### 6 仓库管理
- **库存**：stock:view / edit / balance:adjust + inventory:view（旧遗留）
- **仓库单据**：stock_doc:view / edit　·　**仓库报表**：stock_report:view / export　·　**预计到货**：warehouse_inbound:view

### 7 财税管理
- **销售收款**：finance_receipt:·　**采购付款**：finance_payment:·　**一般费用**（钱流费用单）：finance_expense:·　**其它收入**：finance_other_income:·　**银行存取**：finance_bank_transfer:（各 view/edit）
- **应收应付与账户流水**：ar_ap_ledger:view + finance_reconciliation:view
- **资产与待摊**：finance_asset:view / edit / approve / post / dispose / export + finance_asset_period:manage
- **总账过账**：finance_post:execute　·　**发运审核**：finance_shipment_audit　·　**订货审批**：finance_order_approval:view / review
- **钱流报表**：finance_report:view / export　·　**敏感驾驶舱**：dashboard:finance-sensitive:view（`workflow_assignment:manage` 已于 V229 退役；订货审批走 `finance_order_approval:review`，审批人由财务部门资格 + 此权限决定，见 ADR-027）

### 8 工程研发
- **研发任务**：rd_task:view / edit / resolve

### 9 人事行政
- **员工档案**：employee:view / create / edit / delete / pii:view / pii:edit / compensation:view / compensation:edit / export
- **部门**：department:view / edit　·　**工资条**：payroll:view:self / view:all / generate / review / publish / export
- **报销**（费用报销申领）：expense:apply / approve / pay
- **访客**：visitor:apply / view / approve / check-in / blacklist / host-confirm
- **个人信息**：profile:edit:self / review　·　**通知**：notice:read / publish　·　**意见箱**：suggestion:submit / reply

### 10 品质检测
- **检测记录**：lab:test:view / upload

### 11 系统管理
- **审计中心**：audit_log:view / export（个人-only，部门不可授）
- **授权管理**：authorization:manage（个人-only）
- **账号管理**：account:support（账号锁定/启停/重置）+ user:manage + viewcontext:scoped（管理视角）

> 兜底：V228 之后任何未被归类的新权限点落为 `module='其他'`，权限页单独成段、便于发现后补归类。V234 上述 8 个权限已显式归入“生产管理”，不得落入兜底。
