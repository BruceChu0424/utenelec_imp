# 出库任务中心批量与委外草稿核对

## 范围与当前状态

本次为源码候选，覆盖仓库出库任务中心的销售、委外、其它、产成品四类列表与详情。复用入库已有的 `MasterDataTableView` / `UtenEditableGrid`、独立核对页、二次确认、提交置忙及返回刷新。工作区另有生产领退料、工作台等并行修改，未提交、发布或重启服务。

销售保持财务放行及拣货状态机；委外保持真实目标件、EC 草稿、实际仓和专属预留；其它与产成品保持整单审批写库存。批量逐单独立事务，异常停止后续，已完成单据不重放。取消选择只影响本次办理，不删除原草稿明细。

其它/产成品详情与批量页调用新增出库核对接口，持单据锁校验 `expectedReviewToken` 后进入原有审批内核。单据在核对后发生数量、货品、单位换算、仓库、来源或行集合变化时拒绝，需重新核对。保留旧审批入口兼容，不把核对 token 当作授权或幂等凭据。
