# Windows 本地测试运行时隔离与交付

本阶段实现共享构建身份，不改变正式连接配置。用户已接手业务操作，助手只核验独立身份、私有路径和真实登录首屏；不把离线引擎压力测试或首屏核验描述为完整 ERP 验收。

## 唯一入口和适用端

- Dart 唯一标志 `UTEN_LOCAL_TEST=true`，唯一模型 `lib/core/runtime/client_runtime_profile.dart`，Windows 由 `tool/generate_native_runtime_profile.dart` 生成同源原生资源和 `data/uten-runtime-profile.json`；Android 复用该模型，同时保留 Gradle 的 `.local_test` 原生身份。Web 不开放 LocalTest。
- schemaVersion 1 的完整字段：`schemaVersion/buildProfile/applicationId/nativeProductName/displayName/runtimeFamily/networkScope/selfUpdatesAllowed`。正式值为 `formal/com.uten.uten_imp/优腾综合管理平台/UTEN/flutter/trusted-configured/true`，本地值为 `local_test/com.uten.uten_imp.local_test/UTEN Local Test/UTEN 本地测试/flutter/loopback-only/false`。
- Windows 真实 PE 同时写入 `UtenBuildProfile/UtenApplicationId/ProductName`；Dart 在读取偏好和凭据前核对原生身份。正式旧 runner 的 MissingPlugin 兼容保留，LocalTest 缺失或不匹配立即失败。WPF 候选没有迁移为本 LocalTest 分发组合，不宣称支持。

## 隔离与保留差异

- LocalTest 仅允许显式 loopback `/api`，CLOUD 为空或等于同一 API，DR 控制面必须为空。传输层固定 loopback socket、DIRECT，跨源重定向和外部 URL 启动均拒绝；不放松正式 HTTPS/TLS 合同。
- 网站 CMS bridge 本地仓库不调用外部桥接，云容灾注册和原生/Dart自更新均关闭。所有 URL launcher 调用迁移同一 guard，正式行为保持。
- Windows `path_provider_windows 2.3.0` 只解析 `0409` 英文版本字符串。LocalTest 使用独立英文 ProductName 资源表；正式保留原 `0804` 表和既有插件回退存储行为，避免意外移动正式账号。偏好、secure storage、草稿、设备注册跟随独立 support 目录；secure storage 默认不启用旧 Credential Manager 兼容迁移。不读取或检查正式内容。
- 临时缓存、默认导出、原生日志、更新日志也分开。Windows 实际 support 为 `%APPDATA%/Uten/UTEN Local Test`，cache 为 `%LOCALAPPDATA%/Uten/UTEN Local Test`，日志为 `%LOCALAPPDATA%/com.uten.uten_imp.local_test/client-logs/flutter/x64/Release`。实际路径写入 `localtest-runtime-receipt.json`，无凭据正文。
- 本地校验阶段先显示无 Provider/偏好/联网的启动状态，每项 await 有界失败并显示阶段及异常类型。独立 bootstrap `.log` 记录阶段和耗时；日志磁盘故障不阻止可见隔离校验页。共享诊断继续保存请求类型、脱敏路径、耗时、取消/异常、更新阶段和无响应；路由监听只记录 committed `fullPath` 模板，不记录路由参数、查询、extra 或输入。
