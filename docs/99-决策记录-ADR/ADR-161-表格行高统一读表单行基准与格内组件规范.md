# ADR-161 表格行高统一：读表单行基准与格内组件规范

- 日期：2026-10-06。
- 状态：已接受(2026-10-06；前端 + 测试 + 文档，无迁移、无服务端改动、零新增权限码)。本地未 commit。
- 编号：开工时 main 最大 ADR-159(在途分支)，取 ADR-161(在途分支占 ADR-160)；合并撞号就顺延并同步本文件名与引用。
- 关联：ADR-150(AI 页面上下文，格内提示图标在表格里零尺寸的不变量保持)、[MasterDataTableView 组件文档 · 行高统一口径](../02-组件库/MasterDataTableView.md)、[UtenTableCellAction](../02-组件库/UtenTableCellAction.md)。同日的「编辑格控件 39 统一口径」是它的姊妹篇(先落)。

## 一、背景与用户要求

用户实测(2026-10-06)：委外任务中心「领料」段、我的车间任务，表格行高明显比生产调度与进度「进行中」段高；要求全站表格行高统一成「进行中」那个样子，并明确**修法是改单元格里的组件，不是把格子撑大**、不搞打补丁式修改、旧代码直接删。

## 二、根因(全部实测，Widget 测试量高)

`MasterDataTableView` 无固定行高：行高 = 整行最高格内容 + 格子纵向留白 8×2。基准表(生产调度与进度·进行中)全部单行文本格 → 行 ≈37。偏高页的格子内容混入了更高的组件：

| 根因 | 现场 | 行高后果 |
|---|---|---|
| 状态格可点分支 `InkWell > Padding(vertical: 8)` | 委外领料状态格、车间任务状态格(开工/领料入口) | 51+(+14) |
| 只读表里放 39 高描边下拉(dense) | 车间任务「下一步」选路线下拉 | 55(+18) |
| 按钮主题最小触控高：TextButton min 40、UtenButton min 44、IconButton min 40 | 车间任务「允许超产比例」续报/申请按钮、全站多页动作列 | 52-60 |
| 文本两行(maxLines: 2 / softWrap) | 车间任务「物料」摘要、多页原因/说明列 | 53(+16) |
| 各页自拟的 TextField contentPadding 压缩值 | 盘点/质检/分析等编辑表 | 45-60 不等 |
| 徽章格内降级文本可两行 | UtenStatusBadge/UtenDocStatusPill 降级路径 | 超长状态词撑高 |

Flutter 层事实：`InputDecorator` 对无 `suffixIconConstraints` 的 suffixIcon 默认包 48×48 最小触控槽(前一日已修)；`TextButton`/`FilledButton` 主题 `minimumSize(0,40)`+v8 padding；这些「善意的最小触控面」在表格格子里就是行高噪声。

## 三、决策

1. **读表基准 = 单行文本**(≈37)：读表(所有列都无输入控件)里任何格子的内容高度不得超过单行文本。行高依然内容驱动，本口径靠约束格内组件执行，不给表格加固定行高。
2. **规范件**(见组件文档)：
   - 格内动作用新组件 `UtenTableCellAction`(文字动作，高度=文本行)；
   - 格内内联下拉用 `UtenDropdownField` 新增的 `flat` 形态(文本+小箭头，无边框，弹层与描边形态同一套)；
   - 格内文本一律单行+省略号+Tooltip；
   - 可点状态格不垫垂直 Padding(格子 8×2 留白已是点击区)；
   - 徽章格内降级单行。
3. **编辑表基准 = 39 控件**(≈55 行)：TextField 统一 `isDense`+主题装饰(删各页压缩 hack)，下拉统一 `dense`，表内超过 39 的按钮换 `UtenTableCellAction`，Checkbox 包 `materialTapTargetSize: shrinkWrap`。与 2026-10-06 早先「编辑格控件一律 39」的口径衔接：同一种控件全站同高，不再每页自拟。
4. **例外**：`UtenTreeTableCell` 的 48dp 展开按钮是成文触控设计(其组件文档)，树表行高不受本口径约束；表头 minHeight 44、卡片(compactCards)形态不在本口径内。
5. **行为锁**：`test/components/layout/master_table_row_height_uniformity_test.dart`(读表各类格型内容高度 ≤ 单行基准即绿) + `test/components/layout/grid_cell_height_uniformity_test.dart`(编辑格全状态 39)。改格内组件前先跑这两个。

## 四、被替换/删除的旧写法(不留注释尸)

- `InkWell > Padding(vertical: 8)` 状态格两层垫(两页)。
- 只读表里的 `TextButton`/`UtenButton`/裸 `IconButton` 动作位。
- 读表里 `dense` 下拉(改 `flat`)、`maxLines: 2`/`softWrap` 文本、Column 两层进度格。
- 编辑表 TextField 自拟 contentPadding(v6/v8)压缩值及「收紧到与纯文本行同高」类过时注释。
- `UtenTableColumnKit.md` 中「备注列会换行」的旧口径描述。

## 五、影响面

- 共享组件：`uten_dropdown_field.dart`(flat)、`uten_table_cell_action.dart`(新)、`uten_status_badge.dart`/`uten_doc_status_pill.dart`(降级单行)。
- 页面：委外任务中心(领料)、我的车间任务(点名两页) + warehouse/stock/production/finance/quality/sales/hr_task/admin/basic_data/shared 的同类站点(三路并行清扫，各自跑页面测试)。
- 文档：MasterDataTableView.md 新增「行高统一口径」、UtenTableCellAction.md(新)、UtenTableColumnKit.md 勘误。
- 不改：服务端、权限、路由、迁移。

## 六、修订(2026-10-08)：格内输入框改「库存盘点实盘格」紧凑口径

用户拍板(2026-10-08)：全站自研表格内的输入框统一为「车间内料仓 → 库存盘点 → 实盘数量」常驻输入格的紧凑尺寸，上下边距收窄，**取代本文 2026-10-06 的「格高 39 逻辑像素」规格**。第三节第 3 条「编辑表基准 = 39 控件(≈55 行)」及正文其余一切 39/55 数字均已失真(输入格从 ~48 高变 ~38 高，含输入格的行随内容下移约 8-12 逻辑像素，具体随字体)，以本修订为准；正文按决策记录惯例原文保留，不再照做。

- **单一事实源新位置**：规格抽到新文件 `lib/components/inputs/uten_table_cell_spec.dart`(类名仍为 `UtenEditableGridCellSpec`；`lib/components/layout/uten_editable_grid.dart` re-export 维持旧 import 路径)。
- **数值**：`contentPadding` 由 `symmetric(14,12)` 改 `fromLTRB(10,6,10,6)`(= 实盘格口径)；`pickerCellPadding` 由 `(14,13,14,13)` 改 `(10,7,10,7)`(选择格 bodyMedium 行高比输入文本矮约 1px/侧，垂直补偿 +1；`grid_cell_height_uniformity_test` 校准)。
- **三个宿主注入点**：新共享注入组件 `UtenTableCellInputTheme`(同文件)——编辑表行级(`UtenEditableGrid`)、读表 `MasterDataTableView` 数据格、读表卡片格(`master_data_card_list.dart`)三处宿主共用；读表内联输入格(约 42 处裸 `isDense` TextField)由此一并紧凑，不再吃全局主题 (14,12)。
- **dense 联动清单**：`UtenDropdownField` dense 形态的硬编码 (10,12) 改为引用 `UtenEditableGridCellSpec.contentPadding`；库存盘点实盘格(`stock_count_inline_editor.dart`)自带装饰改引同一常量；`UtenDepartmentPicker` 新增 dense 形态(财务表格部门格启用)；`WarehouseHierarchyDropdown` 新增 dense 透传(出入库编辑表/委外出库表启用，并删除无人再传的遗留 `contentPadding` 参数)；`LinePricingAmountCell` 后缀按钮最小高 40→24；`business_columns_row` 附加列输入格去掉自带 border:none+vertical:10 改吃行级注入；`start_confirmation_sheet` 选料格改用 `pickerCellPadding` 且单行；物料分析汇总表下单格去掉固定高 40 包装。
- **边界不变**：全局 `inputDecorationTheme`(表单/弹窗，14·12)保持不动——本口径只管表格格内；第三节例外条款(树表 48dp 展开按钮)与「读表基准 = 单行文本」不变。
- **行为锁**：`test/components/layout/grid_cell_height_uniformity_test.dart` 基线改为注入环境下的紧凑格；改格内组件前照旧先跑两个行为锁。
