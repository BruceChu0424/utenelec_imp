# V759 货品成本权限页面映射

V753 创建了成本草稿编辑、确认、下载和模板维护四个权限码，但没有把它们登记到页面权限目录。
这些权限保持 `BULK_EXCLUDED` 且允许显式委派；缺少页面关联时，负责人无法在实际页面找到授权入口。

货品详情中的 `GoodsCostTab` 使用这四项能力，所属页面权限面为 `basic.goods`。V328 的 `goods:`
前缀规则只在该次迁移中填充关系表，运行期的 `PermissionSurfaceRegistry` 不会再次展开前缀。

V759 仅将以下既有权限 ID 关联到已启用的 `basic.goods`：

- `goods:cost:edit`
- `goods:cost:confirm`
- `goods:cost:export`
- `goods:cost:template`

迁移不新建权限码，不改变权限 ID、`grant_policy`、敏感级别或基础包，也不写部门和个人授权。
这四码仍须显式选择，不随全部授权、模块或分组批量授予。缺少既有页面或任一权限时迁移失败，
不会猜测替代页面或重新创建已退役权限。唯一键上的 `ON CONFLICT DO NOTHING` 保证直接重放幂等。

历史 V753 和 V747 字节保持不变；V759 是唯一前向补丁，当前源码为 **V759 / 687**。
本迁移只增加目录关系，不改变清库对象集合、业务数据或金额事实。

验证由 `GoodsCostPermissionSurfaceMigrationPostgresTest` 覆盖干净最新库、V758→V759 单步升级、
再次 Flyway 执行零条、SQL 重放、真实页面目录读取、原目录及授权快照保留、批量策略和禁用页面拒绝。
`FlywayMigrationImmutabilityTest` 固定 V753 原 checksum `1617160736`。
迁移及权限目录合同测试结果待本轮独立 PostgreSQL 回归完成后登记；不代表目标业务库已升级。
