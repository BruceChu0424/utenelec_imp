# 我的车间任务页（/production/workshop-tasks）

> 2026-09-04 V470 新增。车间人员的第一入口：只看「与我有关」的生产执行段——
> 本人主职/兼职所在车间子树、本人负责、或本人管理的车间（车间经理）的执行段，
> 按计划结束日期升序排列。同批上线的姊妹页：`/production/progress`（生产进度
> 总览，`production_execution:overview`，跨制单人查看仍须 `production_plan:view:all`）。

## 一、入口与权限

- 路由：`/production/workshop-tasks`（`production_routes.dart`；dashboard「车间生产任务」卡直达）。
- 路由守卫：`production_execution:view`（`permission_by_path.dart`）。
- 服务端口径（`ProductionWorkshopTaskController` → `ProductionExecutionWorkbenchService.workshopTasks`）：
  - 未绑定员工身份 → 空列表（不报错）；
  - 列表恒加「等待/齐套/已派工/进行中」四态过滤（终态在进度总览/历史查）；
  - 范围 = 执行段车间部门子树（`WITH RECURSIVE`，含兼职部门）内：
    本人负责的段、本人在册车间子树的段、本人管理的车间子树的段；
  - 关键字搜索单号/段码/销售单号/货品/颜色/车间；状态切片（备料中/可报工/进行中）。
- 报工动作：须同时持有 `production_daily_report:view + production_daily_report:create + production_execution:view`
  （三码交集；缺报工权限的行会显示「缺少生产报工权限」原因，不渲染报工按钮）。

## 二、页面结构

- 顶部：搜索框 + 状态分段（备料中 / 可报工 / 进行中，默认不选=全部四态）。
- 表格行（`v_production_execution_workbench_segments` 投影）：计划号、段码、
  销售单号、车间、负责人、货品编码/名称/颜色/单位、计划量/已报/剩余、FQC 待检
  与合格/不合格、完工入库待入/已入、段状态、物料状态（齐套高亮）、仓库齐套/
  已发料、计划起止日期。
- 双击行 → 生产执行分段详情（报工/分段操作沿用执行分段页动作与权限）。

## 三、边界与坑

- 「预计到货=前端会话层」无关本页；本页所有口径服务端权威。
- 2026-09-04 修复记录：`segmentSelect()` 尾部误带 `FROM` 子句导致本页 500
  （双 FROM 语法错误），已修并加「select 列清单不得含 FROM」契约锁
  （`ProductionExecutionWorkbenchServiceSortTest.segmentSelectIsPureColumnList`）。
