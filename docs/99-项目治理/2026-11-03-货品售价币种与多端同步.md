# 货品售价币种与多端同步

候选分支：`uimp/goods-currency-selection-20261103`；基线：`dfe3f3b67`。本记录对应本地候选源码，不代表已合入主链、已部署、已发布或 Win7 真机验收。

## 请求与修改分类

用户要求货品资料表格在价格右侧增加币种，币种文字用明显不同颜色；详情、新建、编辑同步，币种始终沿用对应价格权限。另要求离开表格到详情或其他页面后返回时取消原选中，同责页面一起修复。

本次含前端呈现、共享数据与权限契约、服务端保存/默认价保护。Web 与现有 Flutter 桌面复用同一 Dart 页面；WPF 仅同步已迁移的货品只读和单位入口，不开放未迁移写功能。

## 数据与权限合同

- `goods.currency_id` 为售价 `price` 的可空币种关系。响应字段为 `currencyId/currencyCode/currencyName/currencyIsBase`；写入只接受 `currencyId`。本次迁移为 V995。
- 历史通用售价没有可靠的币种证据，采购/委外学习价的币种不能挪用。迁移不回填、不默认人民币；页面显示“未登记”。
- 新建/更新/表内编辑/复制的币种修改与 `goods:price:edit` 一致；主档列表、详情与价格相同，`goods:price:view`、`goods:price:edit` 或超管可见。无价格权限不输出币种身份、名称和本位币证明。
- 通用更新缺少 `currencyId` 表示保留原币种，显式 `null` 表示清空；旧客户端保存其他字段不丢失币种。停用/删除币种不能新选，既有引用可原样回传。
- 币种字典允许货品价格编辑用途，币种资料管理权限保持独立。历史入口沿用其现有“历史价格需要显式查看权”规则，币种与历史价格同权；已可见的货品售价币种历史可显示自身引用名称，不另要币种目录权限，也不开放币种目录。
- 导出币种紧随价格，投影键为 `currencyId`，单元格为币种名称；无价权限时不导出。中文“币种”回导按现有主档名称/编号唯一匹配，不自动创建币种；缺列或空格保留原值。检测计划绑定解析出的币种 UUID，检测后同名币种被替换为新 UUID 时拒绝旧计划，须重新检测，防止未核对的身份替换。
- 操作历史、版本恢复和撤回校验纳入币种。V995 扩展既有 `fn_goods_bom_history_schema` 兼容入口，把旧快照缺失的新列按 null 比较，不改历史前后快照、并发 token 或原价格；后续已登记的非空币种仍能被并发校验发现。

## 售价消费保护

已登记币种只有服务端 `currencyIsBase == true` 才可直接当作本位币新默认价。明确外币、缺证明的已登记币种不填本位币预览，交由权威核价；不自动换汇。旧 `currencyId == null` 保留升级前的默认价业务语义，但不因此填入币种证据。

覆盖销售主价权威查询、客户文件识别候选、报价核价页当前主价对照、BOM 新增/换组件默认价，以及 Flutter 销售挑货品的锁定价预览、文件折扣预览和识别面板手工候选。已保存单据、来源订单、报价冻结价与已有 BOM 价格不重算。

## 调用方迁移与保留差异

| 平台/入口 | 状态与证据 |
|---|---|
| Web / Flutter 货品表格 | 价格右侧新增币种；价格权限同时控制列和表头设置；已有个人列序通过现有声明锚点把新列插在价格之后，不重排其他个人列。 |
| Web / Flutter 双击详情 | 商务区价格后显示币种名称和同源颜色。 |
| Web / Flutter 整页新建/编辑 | 同一选择字段；仅查看价格时锁定币种，未授权隐藏；清空显式提交 null，价格不因选币种被换算。 |
| Web / Flutter 表内新建/编辑 | 共用选择器和字段权限；原有草稿、版本、未知提交合同保留。 |
| 复制、导入、导出、操作历史 | 同步字段、权限、关系验证和历史兼容；导入预览可按“币种”修正。 |
| 销售 / BOM 消费 | 见上节本位币默认价边界。 |
| WPF 货品列表/内嵌详情 | 既有只读入口完成同价可见性、遮罩、颜色与离页清选中；x86/x64 fixture 证据见下。 |
| WPF 货品新建/编辑/BOM/导入等 | 未完成迁移，不开放写入口；相关 W7-BIZ 台账仍为 in_progress。 |

没有保留另一套货品币种选择器或独立 C# 色板。平台导航方式不同：Flutter 走路由/保活页，WPF 走实际原生视图与窗口；各自清临时操作选中，保留业务输入。
