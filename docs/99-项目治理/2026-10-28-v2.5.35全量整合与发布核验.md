1. 收齐每轮完整测试结果；已明确的独立根因边等待边修复，保留原有运行以收集完整证据，源码冻结后重新验证公共入口和调用方。
2. 推送完整 `main`，核对同一提交最新 Quality、CodeQL、OSV、Material forecast 全部完成成功，且没有 warning/failure 批注。
3. 通过既有 Simple Release 签名发布；不能使用允许 CI 仍运行的例外。
4. 配套安装本轮主机公共助手，校验原像、回读摘要，保留既有 DR 调度和恢复边界。
5. 验证签名发行、完整成套备份及真实非空副本迁移。历史 874 个迁移字节不变，新增 V949–V968 共 20 个迁移。
6. 正式激活由既有独立运维 worker 执行，保留完整十分钟预告、备份、迁移和稳定健康门禁，不直接更换 `current`。
7. 独立核对物理 JAR、进程、提交、版本、Flyway、入口和当前进程实际日志。不能仅凭服务 active 或某个 HTTP 200 宣称激活完成。
8. Windows 从同一审核提交生成相同版本、构建号和正式双 HTTPS 配置的 Setup.exe 与更新 ZIP；交付、安装验收和授权发布分别记录。
