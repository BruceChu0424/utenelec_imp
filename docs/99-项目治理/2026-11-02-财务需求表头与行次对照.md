# 财务模板字段和行次逐项对照

本附件是[复刻实施清单](2026-11-02-财务需求复刻实施清单.md)的字段合同。来源为用户提供的工作簿及两张资产清单内嵌图。以下顺序按原文件保存；工作簿中的空白格式区、辅助算式区不并入业务表头。金额与来源缺失不得用改列名的方式掩盖。

“当前列”来自调研基线源码声明，表示接口结构，不表示公司实账已验收。正式模板按目标顺序输出，技术状态/来源信息放在表外或下钻；不同币种或单位必须拆表或明确分组。用户已明确：先按财务原稿复刻，财务认可后再优化。
