# 即时库存页

> 路由：`/stock/instant-inventory`（`lib/features/stock/pages/instant_inventory_page.dart`）· 权限 `stock:view`（全员）
> 上层：工作台 → PMC 运营部 → 仓库管理 hub → 「库存」分区 · 数据口径：[32-即时库存](../数据迁移/32-即时库存.md)

## 一、定位

对标老系统「即时库存」窗口：按**货品类型**浏览当前库存。左树顶部统一搜索既查分类名称/编号，
也查货品名称/编号/型号/客户型号；货品命中会展开所属分类完整路径，右侧用同一关键词显示库存结果。
右侧仍保留当前分类/仓库内的精细搜索。表格展示库存数量 / 库存重量 / 成本金额 / 多排数量；
仓库下拉的“全部”表示参与核算仓库聚合。

与「库存查询（余额）」页的区别：余额页按仓+货+色逐行、供仓管对账；本页按货品+颜色聚合、
带分类树导航与成本/多排视角，供 PMC/管理层看盘。

本页的聚合行只用于查询，点击后仍直接进入货品流水，不在跨仓聚合数量上修改库存。授权余额调整
只能从 [`/stock/balance` 的单一余额详情](库存列表页.md)发起，避免一次操作误改多个仓库维度。

## 二、入口与导航
- 进入：仓库管理 hub「即时库存」卡片。
- 离开：返回仓库管理 hub（`UtenBackButton` 指定 `/warehouse`）。

## 四、数据链路

```
左树：/api/master/material-categories/tree（货品资料同款）
定位：GET /api/stock/instant-inventory/search-category-ids?keyword=&categoryRootIds=
右表：GET /api/stock/instant-inventory?categoryId=&warehouseId=&keyword=&includeDefective=&page=&size=&sort=&order=
      └ goods 货品驱动 LEFT JOIN stock_balances 聚合（全部=仅 is_accountable 仓库）
        —— 无余额货品也列出（库存 0），与老系统「分类下全是内容」一致
        × material_categories（所属类型）× colors / units（名称解析）
        × production_plan_items 可排余量预聚合（多排数量）
```

- 数量/重量：余额表当前值（历史=StockGoods 最新年 FactQTY/FactWeight 迁移，V80；
  增量=单据审核同事务联动，仓库单据含重量，盘点不联动重量）。
- 成本金额 = 货品成本 `c_total` × 数量（老库 B_Goods.CTotal × FactQTY 口径）。
- 排序白名单：qty / weight / costAmount / moreQty / name（默认数量降序）。
- 仓库下拉「全部」= 6 个真实仓（IsCal=0 参与核算，2026-07-28 修反转 bug）；幻影仓可单选。
- 「含不良品仓」开关（V81 `warehouses.is_defective`，按名称识别）：默认开=老系统口径
  （不良仓计入全部）；关掉即剔除 成品不良品仓/原材料不良仓；指定单仓时开关置灰。
  **选择按账号服务端持久化**（`user_preferences` key `stock.instantInventory`，
  模式同工作台布局：本地缓存即时渲染 + 登录后服务端同步 + 防抖 800ms 推送，
  provider：`lib/features/stock/providers/instant_inventory_prefs_provider.dart`）。
- **加密 Excel 导出**：`UtenExportButton` → `POST /stock/reports/export`（report=`instant-inventory`，
  后端 `StockReportService.export` 独立分支复用同款查询全量分页拉取）；
  五道防线齐备：`stock_report:export` 独立权限（V71 已种子）+ 限流拦截器 + Agile AES-256 密码
  + 10 万行上限 + 审计（`export_stock_report`）。
- 轻量定位端点与右表使用同一货品语义：分类与货品只排除 `is_deleted=true`；禁用品和
  `auto_created` 历史 stub 均保留。关键词仅匹配货品名称、编号、型号、客户型号；不把规格、材质等
  右表不支持的字段误算成树命中。每次要求 1–32 个当前可见分类根，无效根零命中。

## 五、涉及的 Uten 组件

`UtenAppBar` / `UtenBackButton` / `UtenCategoryTreeView`（受控关联搜索分类树，含「全部」顶行）/

共享搜索契约见 [UtenHierarchySearch](../02-组件库/UtenHierarchySearch.md)。

## 六、功能点
1. **左侧统一搜索**：分类名称/编号即时命中；货品通过专用轻量端点返回全部匹配分类 ID，补齐祖先并展开，默认定位首个有效分类。根分类超过 32 时分批取并集，客户端拒绝树外 ID。
2. **右侧承接结果**：货品命中时沿用同一关键词；只命中分类时显示该分类全部库存；未分类货品命中时可退回全局关键词结果。点击包含命中货品的相关分支保留关键词，清空左框恢复完整树。
3. **竞态与状态**：300ms 防抖，但每次按键立即使旧定位/库存请求失效；手动点树取消待执行搜索。加载、失败、无结果在树旁显式反馈；compact 正文与抽屉搜索文字同步。
4. 分类树点选（父类=子树汇总），“全部”清除分类过滤；compact 抽屉选择后自动收起。
5. 仓库下拉切换即重查；右表精细搜索防抖重查；刷新按钮重查当前页。
6. 数量/重量/成本金额/多排数量/名称 5 列表头排序（回第 1 页）。
7. 数字列格式化：最多 2 位小数去尾零；null 显示「—」。
8. **行点击 → 出入库流水页**（`/stock/movement?goodsId=<本行货品>`，push 保活本页筛选）：
   从余额一行到账本流水；流水页左栏显示货品 chip，可清除改看全部货品；仓库下拉可叠加过滤。
9. 加密 Excel 导出（report=`instant-inventory`，导出参数与当前筛选/排序/不良仓开关同步）。
## 七、权限与边界

- 页面、聚合查询和轻量定位使用 `stock:view`；分类树仍由 `material_category:view` 控制，定位端点不会顺带授予树权限；加密导出另需 `stock_report:export`。
- 本页不显示 `stock:balance:adjust` 操作，不能在聚合行直接修正库存。
- 授权调整只修正数量；不改单位成本或库存重量，但 `goods.c_total × qty` 的展示金额会随数量变化。
- 详细调整、审计和历史订单规则见
  [仓库盘点修正与历史单据处理](../数据迁移/50-仓库盘点修正与历史单据处理.md)。
