# 货品 BOM 并排对比与替换

分支：`uimp/goods-bom-comparison-20261101`；基线：`48ca76f73`。分类：前端交互及已有 BOM 编辑合同调用；不新增业务计算、数据库迁移或发布。

## 设计计划与复核

沿用 frontend-design 和 Uten 主题。浮窗外壳、标题栏、货品页头与内容统一使用当前主题 surface（浅色 `#FFFFFF`），不再混用灰色外壳与白色内容；主页面原有 `#F5F7FA` 背景保持独立。正文 slate `#0F172A`、操作 teal `#0F766E`、相同 success `#047857`、差异 error `#B91C1C`；深色使用现有主题及语义色。字体沿用应用中文字体及 textTheme，编号与精确数量保持原文。窗口内容统一左右 12px；窗口外沿 8px，中央保留可点击且可拖动的三点手柄。

```text
┌ 左货品 / 更换 / 上下 BOM ┐ ⋮ ┌ 右货品 / 更换 / 上下 BOM ┐
│ 名称、编号、组件表       │   │ 名称、编号、组件表       │
└─────────────────────────┘   └─────────────────────────┘
                 点击 ⋮ → BOM 对比 / 均分
┌ BOM 对比 · 相同 / 差异 / 左独有 / 右独有 · 重新分析 ───────┐
│ 左货品                   │ ⋮ │ 右货品                  │
│ ☑ 差异组件（红，展开逐字段）                            │
│ ✓ 相同组件（绿，可折叠查看）                            │
│ 选中替换方向 / 全部组件替换方向 / 服务端影响预览          │
└─────────────────────────────────────────────────────────┘
```

直接复用组装信息的 `MasterDataTableView`、`UtenTreeTableCell.compact` 及其列宽测量、表头设置、勾选、树形连线和横向滚动，不另画列表卡片。左右垂直滚动联动，根组件勾选共用同一个集合。差异字段作为子行展开；共用子装配仍读真实 BOM，不开放隐含的共享子装配写入。中央手柄承担清晰的操作位置；状态有文字，不单靠红绿。比较以 UUID 配对，位置变化单独提示；差异默认展开，相同默认折叠。替换选中项和全部组件均提供两个方向，明确目标、增加/修改/删除、共用范围及最后确认。左右选择货品后丢弃旧比较和勾选，身份/权限/请求代次变化后旧结果不得发布。窄窗口保留横向双栏滚动；三个及更多窗口从标题栏选择具体比较对象。

## 公共入口和调用迁移

| 已有入口 | 处理及必要差异 |
|---|---|
| UtenSplitView 内部分隔线 | 抽出公共 UtenSplitHandle，分类分栏、并排浮窗、BOM 对比复用；宽度约束及持久化仍由各宿主维护 |
| BusinessWindowHost / UtenFloatingWindow | 保留路由、Provider、编辑器实例；固定左右身份，不随窗口置顶交换；重排响应窗口大小变化 |
| MasterDataTableView / UtenTreeTableCell.compact | GoodsBomTab 与新增 GoodsBomComparisonTables 直接共用同一组件，未复制表头、勾选或行渲染引擎；比较以只读投影、行语义颜色及字段子行表达差异 |
| GoodsDetailPage / GoodsDetailBody / GoodsBomTab | Web 与 Flutter 桌面共用；浮窗成为本地布局域，避免继承主页面的单侧边距；保存后统一刷新已打开 BOM |
| bomComponentCopyBody | 唯一实现迁到 `models/goods_bom_copy.dart`；原数量控件文件再导出兼容所有既有调用，比较模型直接引用。复用精确设计字段及来源复制合同；不复制实际用量、学习归属或已核对状态 |
| GoodsBomEditDraft → /bom/edit/snapshot、preview、commit | 复用服务端权限、版本指纹、环路/重复/期间料校验、共用影响及未知保存回执保护；对比是预览，不成为业务权威 |
| WPF W7-BIZ-025 / W7-BIZ-034 | 完整货品详情/BOM 多窗口尚未迁移；本次合同接续要求登记到唯一台账，不开放原生写入占位入口 |

整份替换针对当前货品直属组件清单（含对子装配的真实引用），不会递归覆盖共享子装配的配方或货品主档。共有 UUID 的子装配本来就引用同一份 BOM；左右独有装配展开读取真实子组件。目标独有组件仅在被勾选或明确整份替换时删除。数量、单价等按原始十进制文本比较，等值尾零不造成假差异；库存及真实用量不是配方冲突。
