# ADR-179 货品价格分析与可追溯建议

- 日期：2026-10-13
- 状态：已接受，源码实施；发布和真实历史回测独立验收。
- 关联：ADR-068、ADR-109、ADR-138、ADR-139。

## 业务决定

货品价格分析从已批准单据读取事实。采购货价、委外加工费和销售成交价分别统计；报价草稿、赠品、退货及重复审核不作为独立成交。供应商、颜色、计价单位及其冻结换算率、币种、税率、批量条件必须可以比较。费用尚未拆分或身份依据缺失的记录保留明细和原因，暂不进入建议价。

历史加权均价使用可比金额合计除以对应收费数量。今日参考采用按独立订单归组的时间加权中位数，用对数价格的MAD计算参考区间。权重考虑时间和本次批量相似程度，大单不无限支配议价参考。无成交日不补零；无新记录不制造每天涨跌。

样本不足、有效样本过少、数据陈旧、查询范围未完整覆盖时不能给出已核正常的判断。指定批量与所有历史源单均相差超过十倍时，也标记批量依据不足；归一化后的有效样本数不能证明批量可比。历史金额和已知统计可以继续显示，说明适用限制。参考区间不是已经校准的概率预测区间。初始最小波动带采用10%相对尺度，不用固定四位金额容差吞掉微小单价的大幅波动。

采购和委外录单提示显著高价及低价，包含参考、均价、偏差和金额影响。黄色提醒不改原单价、总价输入、数量或来源锁价。保存与提交完成后再次用服务端有效金额核查；建议服务不可用时保存成功仍保持成功，并明确核查不可用。

自制产品的报价参考绑定适用的已确认成本测算和明确填写的目标销售毛利率。使用成本除以一减毛利率，与成本加成分开。批量、客户或费用范围不适用时不能直接摊薄固定费用。库存实际成本尚缺人工及制造费用时保留缺项，不能宣称完整实际制造成本。旧算法确认的成本版本继续留存；新报价需要复制复核并以现行财审汇率来源重新确认，不自动消费可能含旧取价问题的金额。

## 权限与说明

价格分析有独立查看授权，并同时沿用来源单据、商业价格及负责人范围。先过滤可见事实再统计；汇总、图表、提醒和AI说明不能扩大读取范围。成本测算另外要求成本查看权。授权页面提供独立选择，不自动给所有员工开通。

AI通过注册的只读查询说明价格依据，绑定货品、条件及证据版本。账户、权限、对象归属或数据变化后重新核验。敏感商业金额留在应用内部；数字、算法结果及确定性解释由服务器生成。建议不自动保存、确认或改写主档。

## 数据库和算法实现

统一只读来源视图保留批准版本、原金额、原数量、单位、商业条款、财审汇率及商品身份快照。分析基于数据库一致性快照，在LIMIT之前应用负责人范围；复合索引支持货品明细和审批版本查询。明细可按期间和游标继续读取。超过分析范围时明确数据不完整，不以最近少数记录冒充全历史均价。

首版统计在Java服务内确定性计算，无在线模型训练或外部AI调用。每次响应提供算法版本、截止时点和依据摘要。同一次批量核查复用相同条件结果；前端约300毫秒合并核查并以身份、行及条件版本丢弃旧结果。当前初始半衰期、样本下限和波动容差属于版本化初始策略，真实历史回测后再调整。

V859修正默认价存储精度；零收费赠品不覆盖正常记忆价。成本取价采用财审case汇率并把审批版本加入依据摘要；自制汇总继承后代待核状态。历史实际成本版本根据自身产出基准验证完整性。既有单据、库存价值、确认成本版本及凭证不重写。

## 验证和发布

回归覆盖极端价格、零MAD、批量差、源单拆行、未知费用、总价倒算、赠品、财审汇率、撤回、单位换算变化、负责人范围、权限撤销和异步旧响应。时间回测只使用当时已知的有效事实，不提前引入后来补录或修正的金额；历史成交不是最优议价标签，异常样本还需采购和财务复核。

代码验证、隔离迁移、目标业务数据核查、真实岗位验收和上线证据分别记录。未经真实数据压测，不宣称已达到页面延迟目标；未经覆盖率校准，不显示算法准确率。
