# 服务器更新

> 路由：`/admin/server-operations`
> 别名：服务器更新、版本检查、预约更新、发布源配置

## 定位

为授权运维人员提供版本检查、预约更新和更新进度核对。

从服务器状态页进入。超级管理员也可从系统设置进入，配置本公司使用的发布源。本页管理独立部署的公司服务器，客户端自身的版本升级提示与此分开。

## 权限

| 范围 | 条件 |
|---|---|
| 查看状态及作业 | 超级管理员，或拥有 `server_status:view`、`server:update`、`server:cleanup` 中任一权限的员工 |
| 检查版本、立即更新、预约更新 | 超级管理员，或拥有 `server:update` 的员工 |
| 配置发布源 | 同时具备超级管理员身份和 `authorization:manage` |
| 取消预约 | 具有更新权限，且为该预约发起人或超级管理员 |

访客及必须先修改密码的账号不能进入。代操作会话不能执行更新、取消预约或修改发布源。更新、预约、取消和保存发布源须再认证；手动版本检查和预约时间核对无需再认证。运维更新与清理权限由超级管理员逐人授权，不能通过部门负责人身份再次转授。

## 检查与更新

1. 页面显示本机当前版本、上次检查时间、发布源是否就绪及最近作业。进入、刷新、查看进度和工作台提醒只读取本机状态，不连接 OSS。
2. 点击“检查版本更新”才访问发布源。检查只记录结果，不下载或激活版本；发现新版本后可选择“立即更新”或“预约更新”。没有每日自动检查选项。
3. 立即更新需确认目标版本和可能的短时服务中断。作业依次检查版本、下载并验签、创建并核验配套备份、按需迁移数据库、激活版本，再检查后端启动、数据库和健康状态。
4. 页面按服务器持久作业显示排队、运行、成功、失败或需要恢复处理。关闭页面不撤销作业；重新进入后继续核对原作业。

提醒注明这是上次检查的结果，不代表持续监控云端。发现可用版本后，具有更新权限的人员可看到数量徽章与通知、普通提醒——徽章有两处：工作台「服务器状态」卡角标（计入待更新版本数）与服务器状态页「服务器更新」按钮上的待更新数红徽章（2026-10-22 起独立的工作台更新卡退役，本页是常驻入口）；版本成功激活后清除对应提醒。发布源变更后不能沿用旧源的检查结果。

更新请求绑定发布源修订和当前版本，确认的目标版本也随作业保存。源、版本或权限变化时须重新核对。网络超时或响应不明时只查询原作业，不自动重新提交更新；需要恢复处理时先由超级管理员核查备份与健康状态，不能反复点击更新，也不把数据库恢复承诺为自动回退。

## 预约时间

选择服务器当地日期及凌晨 `02:00` 或 `03:00`，先点击“核对预约时间”，再确认预约。页面显示服务器返回的当地时间和时区，提交该次核对得到的准确时刻，不用手机或浏览器时区推算。

服务器只接受至少一分钟后、未来三十天内的时间；夏令时造成的不存在或重复时刻会被拒绝。预约保存后由服务器到点执行，关闭页面不影响预约。到点仍会重新核验权限、发布源、运行绑定和目标版本，核验不通过不会擅自换版本执行。取消预约按原作业回执确认，结果未明时不重复取消。

“自动拉取定时器”说明旧自动拉取计划是否停用，与本机预约执行器分开。停用旧自动拉取计划不表示已保存的预约不会执行。

## 发布源配置

服务器更新和受控主机清理仅支持已安装本机运维助手的 Linux 部署。Windows 等不支持的平台显示普通信息提示，
不提供检查、更新、预约或发布源配置操作，也不弹出更新提醒；工作台更新徽章为零，不将平台限制记为读取失败。
权限标志仍表示账号权限，不因环境变化而授予或撤销。Linux 上助手失联或响应无效仍显示故障原因，
更新徽章保留上次数字并标记本次未算出，不把未知更新状态冒充零。
若仍有原作业、历史回执或结果未知的请求，平台限制提示不会隐藏其请求标识和诊断，也不会清除状态或重放操作。

| 字段 | 填写与生效规则 |
|---|---|
| OSS 区域域名 | 填区域域名，不含 `https://`、Bucket、端口或路径 |
| Bucket 与发布目录前缀 | 指向本公司受信发布目录；前缀可留空 |
| 访问密钥 ID、访问密钥 | 只写，不回显已有原文；留空保留，换 ID 时同时填新密钥 |
| 明确清除访问凭据 | 单独勾选，不能同时填写新凭据 |
| 发布签名公钥 | 填完整 `ssh-ed25519` 公钥；已配置时留空保留，页面可核对公钥指纹 |

保存使用当前修订作并发校验，服务器成功写入并读回后才提示配置生效。保存本身不检查、下载或激活版本；更新作业占用期间不能更换发布源。保存结果未确认时重新读取配置核对，不凭旧表单重复覆盖。访问凭据不写入浏览器偏好或表单草稿；账号、服务器或权限边界变化后旧编辑结果失效。

- 页面：`lib/features/admin/pages/server_operations_page.dart`；预约和发布源分别使用 `server_update_schedule_dialog.dart`、`server_update_source_editor.dart`。
- 接口：`/api/admin/server-operations/status`、`/source`、`/updates/check`、`/updates`、`/updates/schedule-preview`、`/updates/latest`、`/updates/{jobId}`、`/updates/{jobId}/cancel`。
- 权威：`ServerOperationsController`、`ServerOperationsService` 与本机受控运维助手。助手不可用时显示不可用原因，不以开发版本或空数据冒充已安装事实。
