# 06 - 动画规范

> 动画是用来"让人感知到系统在响应"的，不是用来炫技的。本项目动画**强度中等**，所有时长/曲线走统一 token，**禁止开发者各写各的**。
> 本准则是 [00-准则索引与开发清单.md](00-准则索引与开发清单.md) 第 5 条"动画规范"的展开。
> 动画与性能档强耦合，详细降级规则见 [07-性能自适应.md](07-性能自适应.md)。

---

## 一、设计目标

| 目标 | 说明 |
|---|---|
| 中等强度 | 不素到像静态 PPT，也不花到让人晕。进场、转场、反馈三类必有 |
| 统一 token | 时长、曲线集中定义在 `UtenAnim`，禁止业务里裸写 `Duration(milliseconds: 250)` |
| 全局复用 | 同一类动画（如卡片点击）在所有页面表现一致 |
| 性能档联动 | lite 档自动压缩时长/禁用重动画；rich 档才放完整效果 |
| 不拖累滚动 | 列表项动画必须轻量，绝对不在 builder 里跑重动画 |

---

## 二、动画 Token（集中管理）

所有时长与曲线放在**单一文件** `lib/core/anim/uten_anim.dart`，全项目通过 `UtenAnim.durations.normal` 这种方式访问。

### 2.1 `UtenAnim` 常量定义

```dart
// lib/core/anim/uten_anim.dart

/// 项目统一动画 token。所有动画必须从这里取时长和曲线。
///
/// 禁止在业务代码里裸写 `Duration(milliseconds: xxx)` 或 `Curves.xxx`。
class UtenAnim {
  UtenAnim._();

  /// 时长档位。
  static const durations = _Durations();

  /// 曲线档位。
  static const curves = _Curves();
}

class _Durations {
  const _Durations();

  /// 快速反馈：按下、tap ripple、小图标切换。150ms。
  final Duration fast = const Duration(milliseconds: 150);

  /// 标准动画：卡片进场、对话框出现、tab 切换。300ms。
  final Duration normal = const Duration(milliseconds: 300);

  /// 慢速：页面转场、首屏入场、大型 stat 卡片。500ms。
  final Duration slow = const Duration(milliseconds: 500);

  /// stagger 列表项之间的延迟。50ms。
  final Duration staggerStep = const Duration(milliseconds: 50);
}

class _Curves {
  const _Curves();

  /// 标准曲线：常规过渡。推荐默认值。
  final Curve standard = Curves.easeOutCubic;

  /// 进场曲线：元素从无到有出现。
  final Curve enter = Curves.easeInOut;

  /// 退场曲线：元素从有到无消失。快出避免拖沓。
  final Curve exit = Curves.easeIn;

  /// 弹性曲线：仅在明确的"上拉刷新"、"成功打勾"等场景用。
  final Curve spring = Curves.elasticOut;
}
```

### 2.2 使用约定

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按下/点击反馈 | `durations.fast` | `Curves.easeOut` |
| 卡片进场 | `durations.normal` | `curves.enter` |
| 对话框出现 | `durations.normal` | `curves.enter` |
| Tab 切换内容 | `durations.normal` | `curves.standard` |
| 页面转场 | `durations.slow` | `curves.standard` |
| 列表 stagger 步进 | `durations.staggerStep` | — |
| 主题/色切换 | `durations.normal` | `curves.standard` |

## 三、标准动画场景

### 3.1 页面转场（go_router + CustomTransitionPage）

转场风格：**fade + 轻微向上滑入**（slight slide）。

```dart
// lib/core/router/uten_page_transitions.dart

CustomTransitionPage<void> buildFadeSlidePage({
  required Widget child,
  required GoRouterState state,
}) {
  return CustomTransitionPage<void>(
    key: state.pageKey,
    child: child,
    transitionDuration: UtenAnim.durations.slow,
    reverseTransitionDuration: UtenAnim.durations.normal,
    transitionsBuilder: (context, animation, secondaryAnimation, child) {
      final curve = CurveTween(curve: UtenAnim.curves.enter);
      final fade = Tween<double>(begin: 0.0, end: 1.0).animate(
        curve.animate(animation),
      );
      final slide = Tween<Offset>(
        begin: const Offset(0, 0.04), // 仅 4% 高度的轻微上滑
        end: Offset.zero,
      ).animate(curve.animate(animation));
      return FadeTransition(
        opacity: fade,
        child: SlideTransition(position: slide, child: child),
      );
    },
  );
}

// 在路由配置里
GoRoute(
  path: '/payroll/slip-detail',
  pageBuilder: (context, state) => buildFadeSlidePage(
    child: const PayrollSlipDetailPage(),
    state: state,
  ),
),
```

> 性能档联动：lite 档把 `transitionDuration` 砍半并退化为纯 `FadeTransition`，去掉 slide（见 [07-性能自适应.md](07-性能自适应.md)）。

### 3.2 列表项 stagger 进场

前若干项依次延迟出现，避免整列"砰"一下全部蹦出。

```dart
// lib/components/lists/uten_staggered_list.dart

class UtenStaggeredList extends ConsumerStatefulWidget {
  final int itemCount;
  final IndexedWidgetBuilder itemBuilder;
  final int animatedItems; // 只对前 N 项做 stagger，超出直接显示

  const UtenStaggeredList({
    super.key,
    required this.itemCount,
    required this.itemBuilder,
    this.animatedItems = 6,
  });

  @override
  ConsumerState<UtenStaggeredList> createState() => _UtenStaggeredListState();
}

class _UtenStaggeredListState extends ConsumerState<UtenStaggeredList> {
  @override
  Widget build(BuildContext context) {
    final tier = ref.watch(performanceTierProvider);

    // lite 档：直接渲染，无 stagger，避免滚动卡顿
    if (tier == PerformanceTier.lite) {
      return ListView.builder(
        itemCount: widget.itemCount,
        itemBuilder: widget.itemBuilder,
      );
    }

    return ListView.builder(
      itemCount: widget.itemCount,
      itemBuilder: (context, index) {
        if (index >= widget.animatedItems) {
          return widget.itemBuilder(context, index);
        }
        return _StaggeredItem(
          index: index,
          child: widget.itemBuilder(context, index),
        );
      },
    );
  }
}

class _StaggeredItem extends StatefulWidget {
  final int index;
  final Widget child;
  const _StaggeredItem({required this.index, required this.child});

  @override
  State<_StaggeredItem> createState() => _StaggeredItemState();
}

class _StaggeredItemState extends State<_StaggeredItem>
    with SingleTickerProviderStateMixin {
  late final AnimationController _c;
  late final Animation<double> _anim;

  @override
  void initState() {
    super.initState();
    _c = AnimationController(
      vsync: this,
      duration: UtenAnim.durations.normal,
    );
    _anim = CurvedAnimation(parent: _c, curve: UtenAnim.curves.enter);
    // 延迟 = index * staggerStep，最多 6 项后不再延迟
    final delay = UtenAnim.durations.staggerStep * widget.index;
    Future.delayed(delay, _c.forward);
  }

  @override
  void dispose() {
    _c.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return FadeTransition(
      opacity: _anim,
      child: SlideTransition(
        position: Tween<Offset>(
          begin: const Offset(0, 0.08),
          end: Offset.zero,
        ).animate(_anim),
        child: widget.child,
      ),
    );
  }
}
```

> 关键点：**只有前几项**做 stagger（默认 6 项），超出的直接渲染。否则长列表会一直延迟出现，体验差。

### 3.3 卡片点击反馈

两种方案二选一，**全项目保持一致**：

| 方案 | 适用 | 实现 |
|---|---|---|
| Material Ripple | 默认，所有列表卡、按钮 | `InkWell` / `UtenCard` 自带 |
| Scale 按下 | 强调交互（大卡片、入口卡） | `UtenPressableScale` 包一层，按下时 scale=0.98 |

```dart
// lib/components/feedback/uten_pressable_scale.dart
class UtenPressableScale extends StatefulWidget {
  final Widget child;
  final VoidCallback? onTap;
  const UtenPressableScale({super.key, required this.child, this.onTap});

  @override
  State<UtenPressableScale> createState() => _UtenPressableScaleState();
}

class _UtenPressableScaleState extends State<UtenPressableScale> {
  bool _down = false;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTapDown: (_) => setState(() => _down = true),
      onTapUp: (_) => setState(() => _down = false),
      onTapCancel: () => setState(() => _down = false),
      onTap: widget.onTap,
      child: AnimatedScale(
        scale: _down ? 0.98 : 1.0,
        duration: UtenAnim.durations.fast,
        curve: Curves.easeOut,
        child: widget.child,
      ),
    );
  }
}
```

### 3.4 数据数字滚动（rich 档专属）

Dashboard 上的统计数字（如"本月产量 12,345"）从 0 滚到目标值。

| 性能档 | 行为 |
|---|---|
| rich | `UtenAnimatedNumber`，0→目标值滚动 1.2s |
| standard | 同 rich |
| lite | **直接显示最终值**，不滚动 |

```dart
// lib/components/feedback/uten_animated_number.dart
class UtenAnimatedNumber extends ConsumerWidget {
  final int value;
  final TextStyle? style;
  final NumberFormat? formatter;

  const UtenAnimatedNumber({
    super.key,
    required this.value,
    this.style,
    this.formatter,
  });

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final tier = ref.watch(performanceTierProvider);
    final fmt = formatter ?? NumberFormat.decimalPattern();

    // lite 档直接显示，省掉 Tween 开销
    if (tier == PerformanceTier.lite) {
      return Text(fmt.format(value), style: style);
    }

    return TweenAnimationBuilder<int>(
      tween: IntTween(begin: 0, end: value),
      duration: const Duration(milliseconds: 1200),
      curve: UtenAnim.curves.enter,
      builder: (context, v, _) => Text(fmt.format(v), style: style),
    );
  }
}
```

### 3.5 加载骨架屏（Shimmer）

| 性能档 | 行为 |
|---|---|
| rich / standard | Shimmer 闪烁（用 `UtenSkeleton`） |
| lite | 静态灰色占位，**不闪** |

> 实现见组件库 `UtenSkeleton`，内部读 `performanceTierProvider` 自动决定是否启动 shimmer animation。

### 3.6 主题切换（亮/暗模式）

切换主题时整树做 fade 过渡，避免突兀白屏/黑屏。

```dart
// 在 MaterialApp 上用 AnimatedTheme 不够（只动画 ThemeData），
// 整树切换靠 AnimatedSwitcher 包一层根 Widget，配合 FadeTransition。
```

> 性能档联动：lite 档不做整树 fade，直接切（节省一帧合成）。

## 四、性能档联动（速查）

> 完整规则见 [07-性能自适应.md](07-性能自适应.md)。

| 动画场景 | lite | standard | rich |
|---|---|---|---|
| 页面转场 | 纯 fade，时长砍半 | fade + slide | fade + slide |
| 列表 stagger | ❌ 禁用，直接渲染 | ✅ 前 6 项 | ✅ 前 6 项 |
| 卡片按下反馈 | ✅ ripple（轻量） | ✅ ripple + scale | ✅ ripple + scale |
| 数字滚动 | ❌ 直接显示 | ✅ 开启 | ✅ 开启 |
| 骨架屏 | 静态灰色 | ✅ shimmer | ✅ shimmer |
| Hero | ❌ 禁用 | ❌ 禁用 | ✅ 仅 standard 及以上 |
| BackdropFilter 模糊 | ❌ 禁用 | 轻度 | 玻璃模糊 |
| Lottie | ❌ 禁用 | 关键反馈 | 关键反馈 |
| 主题切换 fade | ❌ 直接切 | ✅ fade | ✅ fade |
| 时长缩放 | ×0.5 | ×1.0 | ×1.0 |

> lite 档铁律：**禁用 BackdropFilter、禁用复杂着色器（ShaderMask 自定义）、动画时长统一压缩 50%**。

## 五、Hero 动画

| 规则 | 说明 |
|---|---|
| 使用场景 | 仅"列表 → 详情"跨页过渡（如产量列表 → 产量详情） |
| 性能档门槛 | **仅 rich 档**开启；standard 及以下退化为普通 fade 转场 |
| 同屏 Hero 数 | 同一页面同一时刻**最多 1 个** Hero，避免 z-order 抢占 |
| 内容限制 | Hero 内只能是图片/简单图形，不包裹文字（文字会重排抖动） |
| tag 命名 | 用稳定业务 ID，如 `Hero(tag: 'production_output_$id')`，不要用 index |

```dart
// 列表项
Hero(tag: 'production_output_${item.id}', child: UtenThumbnail(...));

// 详情页
Hero(tag: 'production_output_${item.id}', child: UtenHeroImage(...));
```

## 六、Lottie 使用规范

| 规则 | 说明 |
|---|---|
| 用途 | **只**用于关键反馈场景：表单提交成功打勾、空状态插画、首次引导 |
| 禁用 | 不用于背景装饰、不加在按钮上、不做加载转圈（加载用骨架屏） |
| 性能档 | lite 档禁用 Lottie，改为静态 PNG 或纯文字 |
| 资源 | 放 `assets/lottie/`，snake_case 命名（`success_check.json`） |
| 大小 | 单个 Lottie 文件 ≤ 30KB，超过则让设计压缩 |
| 缓存 | 用 `lottie` 包自带的 cache，避免每次解码 |

## 七、禁忌（PR 直接打回）

| ❌ 禁止 | ✅ 应该 |
|---|---|
| 业务里裸写 `Duration(milliseconds: 250)` | 用 `UtenAnim.durations.normal` |
| 业务里裸写 `Curves.easeInOut` | 用 `UtenAnim.curves.enter` |
| 每个开发者各定义各的时长 | 统一从 `UtenAnim` 取 |
| 列表 `itemBuilder` 里跑 `AnimationController` 不释放 | 用 `UtenStaggeredList` 封装好的组件，或确保 `dispose` |
| 在 lite 档下还跑 BackdropFilter / 着色器 | 读 `performanceTierProvider` 包判断 |
| 长列表每项都做 stagger | 只前 6 项做 stagger |
| 滥用 Lottie 做装饰 | Lottie 仅限关键反馈 |
| 同屏多个 Hero | 同屏最多 1 个 |
| 把文字包进 Hero | Hero 内只放图片/简单图形 |
| 动画时长超过 600ms（除转场） | 转场用 `durations.slow`，其它最长 `normal` |
| 用 `setState((){})` 触发动画 | 用 `AnimationController.forward()` |

## 八、对照清单（每次提交前自检）

- [ ] 所有动画时长取自 `UtenAnim.durations.*`，没有裸写 `Duration(milliseconds: xxx)`
- [ ] 所有曲线取自 `UtenAnim.curves.*`，没有裸写 `Curves.xxx`
- [ ] 用了 BackdropFilter / ShaderMask / 复杂着色器的，包了一层 `performanceTierProvider` 判断
- [ ] 列表进场用 `UtenStaggeredList`，stagger 只对前 6 项
- [ ] 列表 `itemBuilder` 里的 AnimationController 都有 `dispose`
- [ ] 数字滚动组件在 lite 档下直接显示终值
- [ ] 骨架屏在 lite 档下不闪
- [ ] Hero 只用在"列表 → 详情"，且同屏最多 1 个，内容不含文字
- [ ] Lottie 只用在关键反馈场景，单文件 ≤ 30KB
- [ ] 动画时长不超过 600ms（页面转场除外）
- [ ] 三档（lite / standard / rich）都跑过一遍，无卡顿
