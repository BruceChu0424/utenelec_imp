# ADR-137 全平台可扩展表格与统一投影

状态：已接受（2026-09-29）。本地实现与验证，不代表目标业务库迁移、远端 CI 或岗位验收。补充 ADR-136；不改变其商业金额、核价和模板内容清理规则。

## 范围与业务含义

所有交互表格经 `MasterDataTableView`、`UtenEditableGrid` 或 `UtenRevisionTable` 接入同一列展示、顺序、宽度、隐藏、公式与用户偏好机制。定义、复用扩展列和编辑扩展值只在明确开放的新建、草稿录入页面或有对应编辑权限的基础资料维护列表提供，不能由公共表格类型推断。清单由 Dart AST 生成，见 [全平台表格库存](../99-项目治理/platform_table_inventory.md)。原文件预览展示原文件；签名、票据图片和打印布局用的 Table 不作为可编辑业务记录。

“全平台”不表示每一种数量都能随意加减。销售报价/订货、采购/委外订货的费用列复用 ADR-136 的商业计算链，按业务权限进入金额与后续收发/财务快照。其它真实记录的文字、数值与辅助公式存独立扩展字段；数量、库存、工资、资产折旧、成本和已过账金额仍由所属业务内核计算。汇总、监控、台账及不可编辑历史可以继续展示已有个人辅助计算，不提供新建或复用外部列入口，不给它们伪造可写行 ID。

销售基础默认十列：货品名称、英文名称、编号、颜色、数量、单位、单价、折扣、金额、备注。文件型号、文件品名、文件价格在确有来源数据时显露；新建无文件不显示空文件列。其他模块保留自己的业务默认列。

## 唯一组件与数据契约

2026-09-30 补充：商业列、通用公式及单元格编辑共用 `ColumnEditorDialog` 的滚动与操作区布局，按名称、用途、公式渐进展开。即时库存补齐页面已显示的数量原始事实；账户流水独立 `view_account_statement` 计算范围，要求账户/余额/流水查看权限，不能借通用货品价格能力读取余额。详细行为与覆盖边界见 [添加列与金额计算](../02-组件库/添加列与金额计算.md)。

2026-10-01 页面边界补充：公共表格的 `columnEditingEnabled` 默认关闭，由新建或允许修改的草稿录入宿主显式开启，并叠加现有权限、单据状态、加载/保存状态和已创建单据检查点限制。审核、详情、修订对照、清单和选择器只允许恢复当前表已有的隐藏列以及调整显隐、顺序、宽度等个人布局；不能定义新列、从目录复用外部列或修改扩展值。列按钮、弹窗提交和控制器写入使用同一门禁，不能只隐藏一个入口。弹窗打开后若页面进入不可编辑状态，迟到的创建、选择或移除结果不得回写本单，即使弹窗结果已切换为应用于当前行集也须再次复查。该开关不改变财务核价、质检或出入库等原有固定业务字段的岗位操作。

应用层 `platform_table_registry.dart` 为真实模型登记 scope、业务 UUID、规范表格键、原始数值访问器和可编辑条件；共享控件不 import 具体业务。`PlatformTablesHost` 统一挂载偏好和当前表格投影，并在登录用户、操作人、代管身份变化时重建。

基础资料维护列表是上述清单只读规则的明确例外：货品、模具、客户、供应商及六类独立主档列表按各自 `:edit` 权限开启 `columnEditingEnabled`，表头最右侧直接显示「添加列」。仅查看或新增资料权限不开放添加列；权限变化须同步更新入口及已打开的弹窗，服务端继续复验主档权限与记录级写入条件。

新建、修改、详情、审核使用同一规范表格键。例如 `sales.quote.items`、`production.plan.items`、`expense.claim.items`。不同页面上的字段别名在登记处映射，不复制偏好。`PlatformRowDraft` 随表单草稿保存、复制时去掉旧持久化身份；未加载字段绝不被空数组覆盖。输入变化直接驱动计算，禁止从 `toStringAsFixed`、本地化金额或带单位的显示文本反解析公式基数。

允许编辑列的录入页可在模块字段目录中搜索复用新增字段；选择过的列留在当前用户的布局中，新定义不强制推给所有用户。排名利用使用次数和最近使用，支持相似名称检索。辅助公式是受限数据结构：常数、允许的业务数值、已有数字列，以及有序加减乘除；禁止执行用户表达式代码。BigDecimal/Decimal 计算、循环依赖检测、除零错误、复杂度上限与金额依赖权限在前后端均处理。

普通只读表可以恢复已有计算列的显示，但不新增或从目录选入计算列，也不因此向业务记录写入选用标记；已开放列编辑的可写表单则把选用的 CALCULATED 列以 null 选用标记随原单据事务保存，由服务端计算并冻结审核值。修改旧行必须先读取完整原扩展值及 CAS 版本，不能用未加载的空值覆盖已有字段。历史实体缺少某列快照时显示空值，不按后来新增的公式补算；已有个人 view_* 辅助计算仍只用当前获准展示的历史原始数值。

服务端 `PlatformColumnResourceAdapter` 是每个模块唯一的资源访问边界。目录定义、批量读取、独立扩展字段修改、整张单据保存、导出都复用它。领域适配器调用原有详情查询/权限策略，不把“知道一个 UUID”当成有查看权。

## 保存、并发与历史

`@PlatformColumnDocumentSave` 在业务保存外层开启同一事务：保存前验证原行身份、版本和可写状态；业务内核保存正式明细后，把扩展值迁移到新的实际 UUID。行重建、删除、调整顺序不按 UI 下标猜旧身份。旧客户端省略已存在的扩展数据而无法证明来源时，要求刷新，不能悄悄丢弃。

生产日报会把一个输入拆成多个正式产出；其 `DOMAIN_LINEAGE` 由业务保存代码明确登记输入与输出关系，并校验货品/颜色/单位和数量守恒。聚合行、物料辅助行不能冒用主产品的保存能力。新建专属权限依赖本事务真正持久化的记录证明，不能借幂等重放修改一张已有单据。重放只认可原父单据下的既有明细归属与同内容，不二次写值。

单据扩展值写入使用版本 CAS、固定顺序父记录锁和保存前状态复查。提交、审核、结清或领域政策禁止修改后，旁路扩展字段接口同样拒绝。四类商业单据继续使用 ADR-136 的冻结快照；版本对照明确传入历史 snapshot，不以当前字段值冒充过去。

## 权限

权限分开返回为 `canCreate`、`canWrite`、`canDefine`、`canViewPrice`；按钮只是反馈，服务端始终复验。读与写复用原模块的查看、新建、编辑、负责人/申请人、仓库/组织及状态范围。拥有定义或写入权限不自动开放审核、详情等页面的列编辑；页面门禁只能进一步收紧能力，不能替代服务端授权。只读展示列属于个人配置，不扩大任何业务写权限。代管会话不写个人目录或偏好；缓存与异步偏好提交按账号和操作身份隔离。

价格、成本、工资及依赖它们的公式继承敏感权限。无原始金额权限不能借文字列定义、公式引用、隐藏列、搜索目录、批量读或下载间接取值。模板下载继续要求报价查看/导出/价格和客户范围；AI 学习回执要求对应单据访问，重试复查原识别来源、任务归属和当前权限。前端只显示步骤与计数，不展示识别载荷、联系人原文或内部异常。

同一登录人的权限变化也会失效能力缓存、取消旧请求并重新鉴权；已打开的敏感字段编辑器随之遮罩、禁止保存，其他未提交输入保留，不靠重建整张业务表单丢弃输入。报销 schemaVersion=2 同时冻结表头和明细扩展字段；驳回修改、重提及其打印各读对应版本，schemaVersion=1 的旧快照按缺失字段兼容。

## 预览与下载

`TableColumnProjection` 只传当前显示的规范列 ID、标签、顺序和宽度；当前路由和最近表格上下文共同定位，多表歧义时要求明确 tableKey，不复用上一路由的表头。服务端从白名单恢复原生列、从目录恢复公式定义、按稳定 UUID 读取扩展值，拒绝客户端自报公式及越权列。

公共打印预览、PDF 与 Excel 使用同一投影；报价客户模板把当前投影写回模板的明细区，缺少的当前费用/辅助列补入。模板不覆盖当前单据的币种、折扣与实际金额。原始附件预览仍是原始附件，不据业务表头篡改它。

## AI 学习与重试

识别可额外提取有来源的包装、规格、认证、尺寸、费用等信息列；文本来源逐字校验，最多接受有限字段，编号和型号保留前导零，混合数值/文本按文本处理。它们先作为不参与金额的参考列；不能按文件中的指令自动改账。

确认并保存单据后学习客户货品对应、英文名称、允许的客户资料、字段习惯及客户文件版式。V751 为每次学习保存独立回执及分步状态，失败保留可重试证据，所有步骤成功后才消耗识别任务。过期任务不无限保留。重试不能以旧识别结果覆盖后来人工确认的数据。

V752 用“单据 × 客户 × 文件货品对应”证据去重：同单反复保存、A/B/A 交替保存不增加可信次数；撤销/改匹配同步撤回原证据。老统计作为保守基线，不把旧次数再加一遍；全局可信度仍以不同客户数计。相似模板按字段语义、位置和样式归并，明显不同模板独立保留，下载可选一个、多个或全部。

## 数据迁移、检查与后续维护

新增 V750–V752，详见 [迁移 264](../数据迁移/264-V750至V752全平台扩展列与学习回执.md)。定义和主档扩展值保留；清业务数据时只清业务记录扩展值，不能误删主档。学习回执与临时候选按业务清空，保留已确认学习依据的既有治理规则。审计/清空/保留三清单同步登记。

后续新增页面优先复用三种公共表格，登记明确的 tableKey；需要持久字段时必须实现真实资源适配器及权限，新增数值基数同时提供原始值、变化监听和服务端白名单。不能仅凭页面名字自动开放任意表。库存 `--check`、迁移治理契约、金额/权限/幂等/并发及打印投影回归共同作为检查点。
