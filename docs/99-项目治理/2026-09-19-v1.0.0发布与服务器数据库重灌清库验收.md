   143 员工 / 7 账号 / 138 货品；
6. **清测试业务数据**：执行项目标准清库脚本 `server/ops/reset_business_data.sql`
   （fail-closed 白名单推进至 V606；`-v confirm=CLEAR_BUSINESS -v expected_database=uten_imp
   -v expected_system_identifier=7672666251697880435`，单事务）——比手工白名单更权威，
   保留主档/人事/权限/治理证据（审计 134,708 条留痕），业务事实/库存/金额/期初归零；
7. 坑④权限修复（恢复以 `uten` 进行而 migrator 固定用 `uten_migrator`）：
   `REASSIGN OWNED BY uten TO uten_migrator` + 库/schema 属主 + `uten` 的 DML/序列/函数
   GRANT + default privileges；
8. `uten-imp-updater activate v1.0.0`：自动 pg_dump 备份
   （`/var/backups/uten-imp/uten_imp-v1.0.0-20260919-164930.E015v4.dump`）→ migrator
   validate 562 → 应用 V605/V606（V604 跳号）→ 原子切换 current → 健康检查通过。

> 首次激活因坑④权限失败一次（migrator 报 UTEN_MIGRATION_FAILED、细节按设计不回显），
> 应用保持停止、库未受损，修复权限后重试成功——更新器的失败-关闭行为符合设计。
