# 账号权限工作台交互调整

范围：模板工作台、部门目录、权限范围导出、开通账号多选。此记录对应 2026-10-26 本地源码，不代表发布或生产验收。保留工作区内其他并行修改。

## 设计及已有实现比较

采用 `frontend-design`。沿用现有 NotoSansSC 字体、青绿主色、浅灰页面背景、白色权限面板、Uten 间距及圆角 token；左侧资源目录，右侧直接设置权限，主操作统一放右下角。新建弹窗只收集基本信息，避免把完整权限目录放进弹窗。

| 已有入口 | 比较及处理 | 保留差异 |
|---|---|---|
| `AdminPermissionWorkspace` | 继续共用分栏位置、拖动宽度和窄屏切换 | 各模式分别拥有草稿 |
| `UtenFloatingActionGroup`，公司资料库等页面 | 模板新建、导入、保存统一使用已有悬浮组，正文保留其滚动留白 | 窄屏/大字号允许组内滚动 |
| 原 `_TemplateEditor` | 移除权限弹窗，基本信息改用 `PermissionTemplateMetadataDialog`，权限改为工作台直接编辑 | 从员工另存模板复用基本信息入口，应用模板仍用原有预览确认 |
| `UtenDepartmentTreeView` / `UtenHierarchyTreeView` | 部门左侧目录替代单选下拉，与货品分类共用树；深色骨架行文字保留对比度 | 管理员专用树源、可选层级、未保存切换确认保留 |
| 原整体导出及文件读取 | 文件读取统一 `pickPermissionArchiveBytes`；范围裁取、命名和模板文件格式统一 | 部门/员工/基础包快照与模板快照有不同合同，不能混作整体恢复 |
| 单人开通流程 | 多选调用批量编排，复用员工仓库权威开通命令与一次性凭据弹窗 | 单人流程保留；批量逐人结果、未知结果停止 |

## 数据和生命周期保护

- 模板仓库接收服务端返回的完整 `PermissionTemplate`，保存后推进 `version`。650ms 防抖、单通道排队，保存中新增选择留在草稿并使用新版本继续保存。
- 模板分类首次进入后保留在 `IndexedStack`，纳入全局未保存标记；切换分类与分栏宽度不重置草稿。明确错误保留选择；网络/服务端未知结果停止队列，显式重新加载前不重放。
- 模板更改不会直接改变已应用员工；应用预览、敏感确认、依赖校验、并发版本和再认证仍由原服务端负责。
- 局部权限文件带独立范围包装，服务器接收的仍是原严格权限 DTO。局部导入界面不提供超出文件声明范围的选项。
- 全局 ZIP 同时包含全部模板库；任一来源失败不输出缺项包，单文件 16MiB、完整包 32MiB 上限，按文件让帧并使用无压缩条目控制内存。清理后的同名文件自动消歧，不能覆盖其他模板。包内 JSON 仍走原配置预览和模板新建入口，不拓展服务端恢复事务或权限来源。
- 超级管理员固有权限由身份决定，不属于普通员工可恢复配置；其单员工导出入口禁用并说明原因，整体备份不包含密码、超级管理员身份或外网资格。
- 批量开通先统一确认，逐人提交。服务端检查已有账号、在职状态及手机号；不自动重试结果不明的写入。密码不进入结果列表、文件或审计截图。
- 异步文件选择、读取、保存、导出及账号命令继续检查登录身份/读取边界；不增加数据库迁移，不改变数量、金额、库存或权限计算。
