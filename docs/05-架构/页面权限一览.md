# 页面×权限码一览

> 生成自 2026-09-03 全量路由审计（逐条 GoRoute × `permission_by_path.dart` 单一数据源核对）。
> **本表是导览快照，不是第二数据源**：守卫以 `lib/core/router/permission_by_path.dart`
> （`requiredAnyPermFor` / `requiredAllPermsFor`）为准，页面以 `app_router.dart` +
> `production_routes.dart` 注册为准；改守卫请改代码并同步本表（契约测试见 §五）。
> 「登录即可」= 路由层无权限码；`404` = 已知前缀但未知/无权限单据段（fail-closed，超管同样 404）。

## 一、守卫语义

- **any-of**：列出全部码，任一满足即放行。
- **all-of**：叠加的组合门槛（与 any 同时生效），如入职页 `employee:create + employee:pii:edit + department:view`。
- **登录即可**：仅要求员工会话（数据范围仍由后端把关）。
- 单据族（采购/销售/委外/钱流/仓库/生产日报）的 `:seg/new`、`:seg/:id/edit`、`:seg/:id` 路由按 URL 段经
  `DocumentPermissionCatalog` 派生 create/edit/view 码；无对应动作码的段（如采购/委外「申请」只读）→ 404。
