# ADR-009：后端安全加固与功能补全（Wave 4）

> 日期：2026-07-23 · 状态：已实施（javac 21 全量编译零错误；V22/V23 迁移与运行时行为待启动冒烟）
> 前置：[ADR-008](ADR-008-后端代码结构重构.md) · 原则：企业系统，安全首位

## 背景

ADR-008 重构收尾时遗留四项决策点 + 审计发现的两处安全尾巴。所有者决策：全部按最高标准落实，安全优先。

## 决策与执行

### 1. Employee.version 乐观锁补递增（修）

- `version` 为手动 Integer 字段（非 JPA `@Version`），现已在**全部写路径**（直改/调岗/离职/转正/删除 + ProfileChange 直改与审批）一致递增。
- 并发语义：员工提交修改申请（快照 version=N）→ HR 直改该员工（version=N+1）→ 审批该申请时版本不符 → **409「档案已被他人修改，请刷新后再审」**，不再静默丢更新。此为设计意图。

### 2. 证书/学历功能补全（建表未建功能 → 全链路打通）

- 入职（可选 `certificates`/`educations` 列表原子写入）、员工详情（响应新增两列表）、HR 编辑（非 null 时整体替换，空数组=清空）。
- 脱敏判断：证书/学历为员工本人数据、不含第三方 PII，全角色可见不脱敏（与 emergencyContact 的第三方手机号性质不同）。

### 3. 生产关闭 swagger（关）

- prod：`springdoc.api-docs.enabled=false` + `swagger-ui.enabled=false`（端点不注册 → 404）。
- Security 白名单配置驱动（`uten.security.swagger-enabled`，base=true / prod=false），prod 关闭后 swagger 路径**回落认证保护**（双重保险：即使 springdoc 被误开也不匿名暴露）；`UTEN_SWAGGER_ENABLED` 可临时覆盖。

### 4. JwtAuthFilter 逐请求状态检查（优化）

- 验签后每请求恰好 1 次**主键级闭投影查询**（只取 status/mustChangePassword/superAdmin/deleted 列，无实体图），`status != active || deleted` → 401（响应体与全局异常同形状，前端 401 触发登出）。双主体（员工/访客）均覆盖。
- 效果：被锁定/停用的用户**立即**失去访问（原残留 15min access token 窗口关闭）；200-1000 人规模下单 PK 查询亚毫秒级。
- mustChangePassword 维持服务端既有强制（mcp 时仅授 `CHANGE_PASSWORD` 权限，`@PreAuthorize` 天然拦截）。

### 5. 审计覆盖补全 + V18 坏触发器修复（V22 + V23）

- **V22**：`department_roles` / `user_permission_overrides` / `emergency_contacts` 补 AFTER 审计触发器（复用 V05/V09 通用 `fn_audit()`，复合主键表 target_id 为 NULL、完整行存 JSONB，已注释说明）。
- **V23**：V18 的 `audit_profile_change_requests()` 引用了 audit_log 上**不存在的** `before_jsonb`/`after_jsonb` 列（全仓唯一自造函数的异类）——触发器创建成功但首次触发即报错并**回滚整个事务**，意味着个人信息修改链路在部署 V18 的环境上整体不可用。V23 DROP 坏触发器/坏函数，改用通用 `fn_audit()` 重挂。
- 访客账号首次 INSERT 无 actor：改为 persist 前预生成 UUID + `tx.bindActor`。
- 清理：ProfileFieldPolicy 恒等冗余与永不匹配的死条目；AuditService 双入口收敛为单一 `logExplicit`。

## 验证与残留

- 每批 javac 全量编译零错误；API 仅新增可选/响应字段，契约向后兼容；既有 21 个迁移零改动（V22/V23 为新增）。
- 待启动冒烟重点：V22/V23 迁移执行、提交一笔资料修改验证审计落库、锁定用户立即 401、prod swagger 404、版本冲突 409。
- 已知可接受残留：`ProfileChangeDto.Page` 与 `PageResponse` 字段名双轨（前端契约，不动）。
