# 01 - 命名规范

> 标准化的命名是大型项目可维护性的第一道防线。本规范**全局强制**执行，PR 不符合规范不予合并。

---

## 一、品牌与项目代号

| 对象 | 名称 | 说明 |
|---|---|---|
| 产品中文名 | **优腾综合管理平台** | 官方对外名称 |
| 产品英文名 | **Uten Integrated Management Platform** | 官方英文名称 |
| 项目代号 | **Uten IMP** | 简称，用于内部沟通、文档、仓库 |
| Dart 包名 | `uten_imp` | 已是项目根目录名，pubspec.yaml `name` 字段 |
| 仓库目录名 | `uten_imp` | — |

---

## 二、Dart / Flutter 代码命名

### 2.1 总则
遵循 [Dart 官方风格指南](https://dart.dev/guides/language/effective-dart/style) + 本规范补充。

### 2.2 命名规则表

| 对象 | 规则 | 示例 | 反例 |
|---|---|---|---|
| 类 / 枚举 / typedef / Widget | UpperCamelCase | `EmployeeRepository`、`PayrollStatus` | `employee_repository`、`EmployeeRepo` |
| Uten 组件库 Widget | `Uten` 前缀 + UpperCamelCase | `UtenButton`、`UtenPersonCard`、`UtenInput` | `MyButton`、`UtnBtn`、`CardWidget` |
| 变量 / 函数 / 参数 | lowerCamelCase | `currentUser`、`fetchEmployees()` | `current_user`、`CurrentUser` |
| 常量 | lowerCamelCase | `defaultPageSize`、`maxRetryCount` | `DEFAULT_PAGE_SIZE` |
| 私有成员 | 前缀下划线 `_` | `_handleLogin`、`_data` | `handleLogin`（如果应私有） |
| 异步返回 | Future 明确类型 | `Future<List<Employee>>` | ❌ `Future<dynamic>` |
| 枚举值 | lowerCamelCase | `PayrollStatus.pending` | `PayrollStatus.PENDING` |

### 2.3 文件命名

| 文件类型 | 规则 | 示例 |
|---|---|---|
| 所有 Dart 文件 | snake_case | `employee_repository.dart` |
| 组件库文件 | `uten_<name>.dart` | `uten_button.dart`、`uten_person_card.dart` |
| 页面文件 | `<feature>_page.dart` | `login_page.dart`、`payroll_slip_page.dart` |
| 对话框文件 | `<feature>_dialog.dart` | `confirm_delete_dialog.dart` |
| Provider 文件 | `<name>_provider.dart` 或 `<name>_notifier.dart` | `theme_provider.dart` |
| Model 文件 | `<entity>.dart`（单数） | `employee.dart` |
| 测试文件 | `<被测文件>_test.dart` 同名加 `_test` | `uten_button_test.dart` |

### 2.4 目录命名

| 对象 | 规则 | 示例 | 反例 |
|---|---|---|---|
| Feature 目录 | **单数** | `features/employee/` | ❌ `features/employees/` |
| 子层目录 | 复数（表示集合） | `pages/`、`widgets/`、`providers/`、`models/`、`repositories/` | — |
| 组件库分类目录 | 复数 | `components/buttons/`、`components/cards/` | — |
| 文档目录 | `编号-中文名` | `00-项目准则/`、`03-页面/` | — |

> 单复数规则：**Feature 是"一种业务能力"，用单数**；目录内是"同类集合"，用复数。

### 2.5 路由命名

| 对象 | 规则 | 示例 |
|---|---|---|
| 路由路径 | kebab-case，全小写 | `/payroll/slip-detail` |
| 路由常量名 | lowerCamelCase + `Route` 后缀 | `payrollSlipDetailRoute` |
| 命名路由 name | kebab-case | `payroll-slip-detail` |

### 2.6 Provider / Notifier 命名

| 类型 | 命名 | 示例 |
|---|---|---|
| Provider | `<Name>Provider` | `ThemeProvider`、`CurrentUserProvider` |
| Notifier（Riverpod） | `<Name>Notifier` | `ThemeNotifier`、`LoginNotifier` |
| AsyncNotifier | `<Name>AsyncNotifier` | `EmployeeListAsyncNotifier` |
| Provider 标识 | camelCase + `Provider` 后缀 | `currentUserProvider`、`employeeListProvider` |

### 2.7 状态枚举命名

页面/请求状态用统一的枚举：

```dart
enum LoadStatus { idle, loading, success, failure }
enum SubmitStatus { idle, submitting, success, failure }
```

不要 `enum PageState { loading, loaded, error }` 这种各异命名。

## 三、文档与资源命名

### 3.1 文档文件

| 类型 | 规则 | 示例 |
|---|---|---|
| 准则文档 | `编号-中文名.md` | `01-命名规范.md`、`07-性能自适应.md` |
| 页面文档 | `页面中文名.md` | `登录页.md`、`工资条详情页.md` |
| 组件文档 | `Uten组件名.md` | `UtenButton.md`、`UtenPersonCard.md` |
| ADR | `ADR-编号-决策名.md` | `ADR-001-技术栈选型.md` |

### 3.2 资源文件（assets）

| 类型 | 规则 | 示例 |
|---|---|---|
| 图标 / 图片 | snake_case + 语义后缀 | `logo_primary.svg`、`icon_payroll_active.png` |
| 状态分类 | 放对应子目录 | `assets/icons/`、`assets/images/`、`assets/lottie/` |
| 多分辨率 | `@2x`、`@3x` 后缀 | `logo_primary@2x.png` |
| Lottie | snake_case | `loading_dots.json`、`success_check.json` |

## 四、Git 命名（预留）

| 对象 | 规则 | 示例 |
|---|---|---|
| 分支 | `<类型>/<简述>` | `feature/payroll-list`、`fix/login-crash`、`docs/adr-riverpod` |
| Commit | Conventional Commits | `feat(payroll): add slip list page`、`fix(auth): handle token expiry` |
| PR 标题 | `feat/fix/docs/ refactor (scope): 简述` | `feat(auth): 登录页UI实现` |

类型：`feat`（新功能）、`fix`（修复）、`docs`（文档）、`style`（格式）、`refactor`（重构）、`test`（测试）、`chore`（杂项）。

## 五、业务术语统一

为避免一个概念多种叫法，规定：

| 中文 | 英文（代码用） | 路由段 | 说明 |
|---|---|---|---|
| 员工 | employee | `/employee` | 不叫 staff / worker / user |
| 部门 | department | `/department` | 不叫 dept / group / team |
| 工资条 | payroll slip | `/payroll/slip` | 不叫 salary / wage |
| 报销 | expense | `/expense` | 不叫 reimbursement |
| 通知 | notice | `/notice` | 不叫 notification（避免和推送混淆） |
| 实验 / 检测 | lab test | `/lab/test` | 检测数据上传 |
| 空调控制 | hvac | `/hvac` | Heating Ventilation Air Conditioning |
| 流水线 | production line | `/production/line` | 不叫 assembly / line |
| 产量 | output | `/production/output` | 不叫 yield / production-amount |
| 库存 | inventory | `/inventory` | 不叫 stock |
| 工作台 | dashboard | `/dashboard` | 登录后首页 |
| 颜色 | color | `/basicinfo/color` | 老库 B_Color；扁平主档（非树）。**美式拼写**，与既有 `goods.color_legacy_id` 一致（不写 colour） |
| 基本单位 | unit | `/basicinfo/unit` | 老库 B_Unit；计量单位扁平主档（个/套/只…） |
| 设置 | settings | `/settings` | — |
| 个人资料 | profile | `/profile` | "我的"页面 |

## 六、检查清单（每次提交前自检）

- [ ] 类名带 `Uten` 前缀（仅 Uten 组件库）或符合 Feature 命名
- [ ] 文件名 snake_case，页面用 `_page.dart`、组件用 `uten_*.dart`
- [ ] 没有出现 `My`、`Temp`、`Test1`、`aaa`、`foo` 等随意命名（测试代码除外）
- [ ] 路由路径 kebab-case
- [ ] 业务术语使用第五节的统一叫法
- [ ] 新增了组件/页面，对应的文档已同步创建
