# 08 - 委外全链路重设计：订货 → 仓库出仓 → 加工 → 仓库回仓

> 2026-08-19 重设计。本文是委外链路的**当前权威业务设计**；与 22 号文 §三/§十二 的
> 历史口径冲突时以本文为准（22 号文仍是表结构与迁移口径的权威）。
> 触发来源：bruce 2026-08-19 需求 —— 「委外是先仓库出货、然后才仓库进货；出仓/进仓
> 都是仓库自己的页面，数据通用但按角色显隐；委外只留订货单+全链路进度」。

## 一、业务链路确认（与采购的根本差异）

委外 = **公司的物料发给委外商加工，加工成品再回收入库**。所以委外与采购不同：

- 采购：订货 → 财务批准 → **只进**（收货→IQC→入库→立应付）。
- 委外：订货 → 财务批准 → **先出**（材料出仓给委外商）→ 委外商加工 → **再进**
  （成品回厂→IQC→入库→立应付）→ 结案核销（余料退回 / 损耗扣款）。

## 二、单据与页面分布（谁执行、谁可见）

| 单据 | 业务归属 | 操作页面 | 委外可见 | 仓库可见 | 财务可见 |
|---|---|---|---|---|---|
| 委外申请单 | 计划部产生 | 委外模块只读列表/详情 | ✅ 只读 | ❌ | ❌ |
| 委外订货单 | 委外部门 | 委外模块列表/编辑/详情（**详情内含全链路进度区**，新） | ✅ 全量 | ❌（不进订货单，价格/加工费隔离） | ✅ 审批 |
| 委外材料出仓单 | **仓库执行** | **仓库新页：出仓任务中心 + 拣货登记页**；委外经订货单进度点击查看只读详情 | ✅ 只读（经进度） | ✅ 数量/重量/库位（本无价格） | ✅ |
| 委外进仓单 | **仓库执行** | 仓库「登记实际到货」独立页（已有）+ 历史列表（V302 价格脱敏） | ✅ 只读 | ✅ 无价格（V302 脱敏） | ✅ |
| 委外退货单（成品退） | 仓库执行 | 仓库 hub 入口（共享单据页，价格脱敏） | ✅ | ✅ 无价格 | ✅ |
| 委外材料退货单 | 仓库执行 | 仓库 hub 入口（余料回仓） | ✅ | ✅ | ✅ |
| 委外损耗单 | 委外申报、仓库可查 | 委外订货单进度区「损耗核销」发起 + 仓库 hub 可查 | ✅ | ✅ | ✅ 扣款进应付 |
| 委外询价单 | 未启用 | **hub 卡片移除**（表结构与权限保留，不再露入口） | — | — | — |

**显隐原则**：仓库页面一律不出现加工单价/金额/币种（出仓单本无价格；进仓登记页已有此设计）；
委外不进仓库作业页面，只在订货单进度区看状态与单号、点击进只读详情；
采购/委外/财务的审批入口唯一（财务订货审批任务中心），业务侧只见「等待财务通过」。

## 三、数据模型（V304）

### 3.1 委外发料计划 `subcontract_material_plans` / `subcontract_material_plan_items`（新）

财务批准同事务按**当时 BOM** 展开生成，是仓库出仓的权威依据与进度口径：

- plans：`order_id UNIQUE`（一单一计划）、订货单号快照、`status OPEN/CLOSED/CANCELED`。
- plan_items：`order_item_id`（订货明细）、`parent_goods_id/parent_color_id`（父件=订货货品）、
  `goods_id/color_id/unit_id/unit_rate`（子件=待发材料）、`bom_unit_qty`（冻结单耗）、
  `planned_qty = 订货量 × bom_unit_qty`、`issued_qty`（出仓审核回写）。
- 剩余可出仓量 = `planned_qty − issued_qty − 未审草稿占用量`（草稿行实时聚合）。

### 3.2 出仓单明细挂计划行

`subcontract_material_issue_items.plan_item_id UUID NULL → plan_items(id)`：
自动草稿与仓库拣货保存时写入；审核/红冲按它回写 `issued_qty`。历史手工单为 NULL，
不参与计划进度（仍是合法历史）。

### 3.3 损耗扣款

`subcontract_wastes.deduct_amount NUMERIC(18,4) NULL`（本币扣款额，默认 NULL=0 不扣款）、
`deduct_posted BOOLEAN NOT NULL DEFAULT FALSE`。审核时 `deduct_amount > 0` →
立负应付（AP / SRC_SUBCONTRACT_WASTE / 负数）；红冲对称反立账（已核销则拒）。

### 3.4 权限 seed（V304 + V305，只追加）

- `SUB_WH`（PMC 运营仓储部）+= `subcontract_material_issue:view/edit`、
  `subcontract_return:view/edit`、`subcontract_material_return:view/edit`、`subcontract_waste:view`
  ——「谁执行出入仓谁有权」，与 V296 收货权限同先例。
- **V305 独立权限点**（bruce 2026-08-20 口径：权限管理授权才可见/可操作）：
  `subcontract_outbound:view`（看出仓任务中心/计划详情）与 `subcontract_outbound:handle`
  （拣货保存/审核/关闭计划/补齐草稿）管辖 `/api/warehouse/subcontract-outbound/*` 与
  仓库 hub 卡片显隐；默认仅授 SUB_WH，其它部门在权限管理显式授权。
  单据本身仍受 `subcontract_material_issue:view/edit` 管辖，两层独立可收回。
- 仓库执行的进仓/成品退/材料退单对「关联订货单归属人」只读放行（`LinkedOrderReadGate`），
  委外进度区点击单号可溯源详情；写操作不走该门。
- DEPT_SALES 保持既有委外权限。

## 四、后端设计

### 4.1 手工订货放行（第二条来源）

- `lockAndValidateFinanceSubmission`：不再要求每行必挂申请明细；`application_item_id`
  为空的行 = 手工行，跳过申请来源校验（数量/价格/金额完整性校验不变）。
- `applyFinanceApproval`：仅对非空来源行回写 `ordered_qty` / 重算申请结案；
  生产 peg 迁移本就只处理非空来源行（V250 口径不变）。
- 手工单财务批准后同样生成发料计划 + 预计回厂任务，两条来源在仓库视角完全一致。

### 4.2 发料计划与自动出仓草稿（`SubcontractMaterialPlanService`，新）

- `createPlanOnApproval(orderId)`（MANDATORY 事务，由订货 `applyFinanceApproval` 末段调用）：
  逐订货明细查 `goods_bom_items` 一级活动子件（排除 is_deleted 与 auto_created stub），
  有计划行 → 建计划 + 按剩余量自动生**一张**出仓草稿（EC 单号服务端取号、委外商=订货单、
  发出仓留空待仓库拣货、明细带 `plan_item_id`）；订货货品无 BOM 子件 → 不建计划
  （= 委外商自备料，进度区显示「无需发料」）。
- `syncAfterIssueApproved(issueId)`（出仓审核同事务末段调用）：按 `plan_item_id` 回写
  `issued_qty`（CAS 防超：issued + 本次 ≤ planned 才放行，超出即「出仓量超过计划余量」409）；
  计划 OPEN 且仍有剩余量且**无未审草稿** → 自动生下一批余量草稿（分批出仓闭环）。
- `syncAfterIssueReversed(issueId)`：`issued_qty` 对称回减（不自动补草稿，由工作台手工补齐，
  避免红冲-重建草稿抖动）。
- `cancelForOrderReversal(orderId)`（订货红冲同事务）：删除未审自动草稿（已审的由既有
  红冲守卫先行拦截）+ 计划置 CANCELED。
- `closePlan(planId)` / `regenerateDraft(planId)`：仓库工作台动作 —— 「不再出仓」关闭余量
  （须无未审草稿，留原因）；「补齐出仓单」在有剩余量且无草稿时手工重建草稿。

### 4.3 仓库出仓工作台 API（`/api/warehouse/subcontract-outbound`，新）

- `GET /tasks`：OPEN 计划分页列表 —— 订货单号/委外商/交货日/计划行数/计划量合计/
  已出仓合计/待出仓合计/未审草稿号（有则给草稿 id）。计数接口供 hub 角标。
- `GET /tasks/{planId}`：计划行明细（父件→子件、planned/issued/草稿占用/剩余、
  库位/系列快照）+ 该计划全部出仓单（单号/状态/量/审核人/时间）。
- `POST /plans/{planId}/draft`：补齐出仓草稿（剩余量>0 且无未审草稿时）。
- `POST /plans/{planId}/close`：不再出仓（关闭余量，必填原因）。
- 草稿的**编辑与审核仍走既有** `/api/subcontract/material-issues` 端点
  （`subcontract_material_issue:edit` 已 seed 给 SUB_WH）：草稿 maker 置空（系统生成），
  服务层对「计划生成的草稿」放行仓库编辑/审核（maker 为空且挂计划行时，
  以 `subcontract_material_issue:edit` 权限放行，不再要求归属人匹配；自有手工单维持 maker 隔离）。

### 4.4 订货单全链路进度 API

`GET /api/subcontract/orders/{id}/progress`（`subcontract_order:view` + 归属可读）返回：

- `financeStatus`：订货单状态 + 财务审批 case 状态/时间。
- `materialPlan`：计划行（父件/子件/计划量/已出仓/待出仓）+ 计划状态；无计划 → `noneRequired`。
- `issues`：出仓单列表（id/单号/状态/总数量/审核人/审核时间）。
- `receipts`：进仓单列表（id/单号/状态/总数量/IQC 状态/审核时间）+ 订货行已收/订货量。
- `supplierLedger`：供应商处材料台账（子件：发出/已消费/已退/已损耗/结存，V221 口径）。
- `apSummary`：已立应付加工费合计、损耗扣款合计（ar_ap_ledger 按来源聚合）。
- `returns/wastes`：退货单与损耗单摘要列表。

### 4.5 损耗单扣款与默认值

- 编辑页选发料行后**默认损耗量 = 该行供应商结存**（全量核销）、**默认损耗率 = 损耗量/发出量**，
  均可改；表头「扣款金额（本币）」默认 0 = 公司自行承担，填写即向委外商追偿。
- 审核：`deduct_amount > 0` → 负应付立账（`ap_posted` 同型标记 `deduct_posted`）；
  红冲先 `reverseArAp`（已核销拒）。

## 五、前端设计

### 5.1 仓库（新页面，独立设计，不复用委外单据页）

- **委外出仓任务中心** `/warehouse/subcontract-outbound`：计划卡列表（订货单号/委外商/
  交货日/待出仓量/草稿状态角标），点卡进拣货页；支持搜索与刷新；空态「暂无待出仓」。
- **委外拣货出仓页** `/warehouse/subcontract-outbound/:planId`：计划行表（子件编码/名称/
  颜色/单位/计划量/已出仓/本次出仓默认=剩余量可改小、库位提示）+ 表头（发出仓必选、
  经办人默认本人、交货日、备注）+ 「保存草稿」「审核出仓」（确认弹：材料出库+转供应商处
  保管+余量自动生下一批草稿）。**全页无价格字段**。
- 仓库 hub：任务中心加「委外出仓」卡（角标=待出仓草稿/计划数）；单据区加
  委外材料出仓单/委外成品退货单/委外材料退货单/委外损耗单 四张历史卡（共享列表页，
  权限与脱敏兜底）。

### 5.2 委外（瘦身 + 进度）

- hub 只留：任务中心（分解/待退回）、**委外订货单**、计划下达的委外申请（只读）、报表三张。
  询价/发料/进仓/退货/材料退/损耗六张卡移除（路由与权限保留，历史直达链接不受影响）。
- 订货单详情新增「全链路进度」区（仅 order 类型渲染）：
  ① 节点条：下单 → 财务审批 → 材料出仓 → 成品回厂 → 结案核销，逐节点状态/时间；
  ② 出仓计划与出仓单表（单号可点进只读详情）；③ 进仓单表（含 IQC 状态，可点击）；
  ④ 供应商处材料结存表 + 「损耗核销」「材料退」入口（带默认量）；
  ⑤ 应付摘要（加工费已立账/损耗扣款）。

### 5.3 损耗/材料退默认值

损耗编辑页选发料行后自动带出默认损耗量（=该行结存）与损耗率，扣款金额默认 0；
材料退编辑页默认量 = 该行结存（可改小）。

## 六、边界分支清单

| 分支 | 处理 |
|---|---|
| 质量不行（IQC FAIL） | 不进库存；退回供应商任务（既有）；已入库后发现 → 委外退货单（type18 出库 + 反向应付，既有） |
| 回厂数量少（发 1 吨回来不足） | 回厂按实际量×冻结单耗消费；差额留在供应商结存 → 材料退（回仓）或损耗（核销+可选扣款） |
| 回厂数量多（超量） | 既有到货异常 → 财务定案（全收/部分/退回） |
| 损耗默认值 | 默认=该行供应商结存全量，损耗率自动推算，人工可改；扣款默认 0 |
| 分批出仓 | 草稿改小审核 → 余量自动生下一批草稿，直至出完或手工「不再出仓」 |
| 出仓红冲 | 反向入库 + 计划 issued 回减；有下游消费/退料/损耗则先红冲下游（既有守卫） |
| 订货红冲 | 已有进仓/退货/已审发料则拒；通过后删未审出仓草稿 + 计划 CANCELED |
| 无 BOM（委外商自备料） | 不建计划不生草稿；进度显示「无需发料」 |
| 多级 BOM | 只展开订货货品的一级子件（与 V221 冻结单耗口径一致）；下级件视为委外商自制，不管控 |
| 手工订货单 | 无申请来源；财务批准后同样生计划/出仓草稿/预计回厂 |
| 历史老单 | 无计划行，出仓记录不挂 plan_item_id；进度区按实有单据展示，不受新链路影响 |

## 七、财务联动（不新建财务卡片）

- 加工费：进仓审核立应付（既有，AP/SUBCONTRACT_RECEIPT）。
- 成品退货：反向应付（既有）。
- 损耗扣款：损耗单审核按扣款金额立**负应付**（新，AP/SUBCONTRACT_WASTE），
  在应付汇总「冲销」口径与供应商对账单中自然体现 —— 委外商与采购共用 suppliers 主档，
  应付汇总/对账单无需新卡片。
- 材料本身不动应付：材料是公司自有库存（出仓只是位移，库存金额仍在公司账上）。
