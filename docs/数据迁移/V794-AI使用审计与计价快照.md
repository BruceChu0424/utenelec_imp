# V794 AI 使用审计与计价快照

本迁移新增列、索引并扩展服务商公开历史中的非密钥计费字段，不修改旧调用的金额，也不回填旧问题。隔离阶段曾验证 V794/719；合回主目录后，包含单设备登录 V793 的完整目录为 V794/720，已在临时数据库重新验证。本文不代表业务数据库已经安装。

- `ai_jobs` 在接受请求的同一入队事务保存有界、脱敏的问题摘要。原文件字节、系统提示词和模型回复不进入该摘要。成功、失败、本地回答及拒绝请求均可以按任务追溯；旧任务没有摘要时显示不可用。
- `ai_call_logs` 延续每次尝试一条记录，包括重试。服务商未返回或返回无效 token 数时保存 NULL；旧 SDK 保存的 0 无法证明是真实零用量，因此新审计查询保守按未知处理。
- 超管设置每百万 token 单价和币种。价格在逻辑调用开始时冻结，重试沿用该快照；后来改价不会改旧费用。价格只匹配配置时的模型，更换模型后必须重新确认单价。
- 单价计算是估算，不是供应商账单。真实金额没有可信供应商依据时为空；按币种分别汇总，不自动换算。套餐模式不会按次数伪造费用，5 小时或每周额度尚未接入时明确显示未接入。
- 读取跨员工记录要求真实超管及 `authorization:manage`；模拟身份不能查看。改计费配置还要求再认证和版本匹配，成功变更沿已有安全列审计和服务商版本历史保留。
- 调用日志仍在独立 READ COMMITTED 短事务写入，并在目标表锁之后核验清库世代。旧数据集的在途调用不得写入清空后的新数据集。

新增列沿用三个已有表的保留、归档与显式测试清空政策，没有新表或默认赋权。普通员工没有新增审计查询权限。费用配置的审计和公开历史只含非密钥字段。
