# 48 · 财务验收操作指引（给财务同事）

> 目的：用一个月（建议 **2026-04**，与手工 Excel 同一期间）把系统新出的报表和手工表对一遍，确认可以替代手工。
> 建议验收顺序：先对账单 → 再成本核算 → 最后总账。每张表都附「在哪看 / 对什么 / 预期 / 常见问题」。
> 原则上全程只读。第六节两个动作类功能只能在授权测试环境执行；第五节资产与待摊只允许使用
> 无真实财务影响的测试草稿和隔离测试数据，当前不得走真实核心落账。

---

## 〇、准备（2 分钟）

1. 登录系统，确认你有「钱流报表」查看权限（看不到入口找系统管理员开通 `finance_report:view`）。
2. 进入 **财税部 → 钱流管理**，下方「钱流报表」分区有 8 张卡片：
   应收应付 / 明细报表 / 汇总报表 / 往来对帐单 / 账户流水 / **对账单** / **成本核算** / **总账报表**。
3. 每张报表页上方都有：**起止日期**（验收统一选 2026-04-01 ~ 2026-04-30）、**关键字框**（输客户/供应商/货品名或编号）、表头排序、翻页、**导出**（Excel，需设 4 位以上密码，导出即得加密文件，用该密码打开）。

## 一、应收/应付汇总表（C1 · 附件 3/6）

**在哪**：「汇总报表」卡 → 应收款汇总 / 应付款汇总。

| 对什么 | 预期 |
|---|---|
| 应收多了 3 列：**结算期限**（如「月结30天」）、**铺底额**、**超出铺底额** | 铺底额在 基础资料→客户资料 表单里维护（财务分组），维护后汇总表即出数；超出铺底额=应收余额−铺底额（小于 0 显示 0） |
| 应付按供应商一行一户：上月余额/货款/付款/退货/冲销/货款余额 + 模具款 4 列 + 应付合计 | 与附件 3 结构一致；模具款暂无数据源，列为空属正常 |
| 恒等式 | 上月余额+发货+退货−回款=应收余额（抽 2~3 个客户手算核对） |

## 二、对账单（C2 · 附件 1/2/4/5，原全手工）

**在哪**：「对账单」卡，5 个页签。

| 页签 | 模板 | 操作与对照 |
|---|---|---|
| 委外加工对账单 | 附件 1 | 关键字输委外商（如 川琪），选 2026-04。列：期初/本月入库/允许损耗 3%/本月出货/结存/加工费/减扣材料款。⚠️ **历史月份的"本月入库（发料）"会偏少**——老系统发料数量未迁入新系统（全为 0），所以期初/结存对历史月份失真；**本月出货（进仓）和加工费是准的**。新单据正常录入后自动正确 |
| 采购外放加工对账单 | 同附件 1 | 同上，采购核对供应商欠料用 |
| 供应商对账单 | 附件 2 | 关键字输供应商（如 智谦），选月份。送货日期/物料/数量/含税单价/金额，退货为负数行并标「（退货）」 |
| 其他应收款对账单 | 附件 4 | 铜材加工按重量：进仓重量/发出重量/损耗 0.5%/滚动结余/加工货款。⚠️ 老数据里金本的进仓记在「铜柱车间」名下，可按车间名查 |
| 客户对账单 | 附件 5 | 关键字输客户（如 欧普），选月份。开单日期/货品/颜色/数量/含税单价/金额，退货负数行 |

**验收点**：抽 1 家委外商、1 家供应商、1 家客户，把系统行数与金额和手工表逐行对；不一致先看「关键字是否把对方名字输全」「日期是否同月」。

## 四、总账报表（C3 · 附 9~16 + 科目余额表）

**在哪**：「总账报表」卡，8+2 个页签。全量历史凭证已生成（2019 年至今 9 万多张，借贷平衡）。

| 页签 | 模板 | 对照 |
|---|---|---|
| 科目余额表 | — | 日期选月份；每个科目 期初/本期借/本期贷/期末 |
| 资产负债表 | 附 9 | **资产总计 = 负债+权益总计（系统内恒等）**；对照手工表的行项目位置即可，金额以总账为准 |
| 年度利润汇总表 | 附 10 | 行=项目，列=1~12 月 |
| 月度利润表 | 附 11 | 本月+本年累计两列。2026-04 实测：营业收入 3,704,007.54、营业成本 1,068,641.56、净利润 2,505,759.76 |
| 制造/管理/销售费用明细 | 附 12/13/14 | 行=费用项目，列=月份。⚠️ 人工/社保/招待等**无数据源的项为空**；资产折旧/摊销只有存在已批准的月度批次才有数，当前生产核心落账门禁关闭，不能为“让报表出数”而绕过 |
| 经营损益表 | 附 16 | 选 2026-04：应收账款（销售额基数）3,704,007.54；材料费按货品类别展开（塑胶类 16.09% 等）+ 占销售比 |
| 固定资产折旧清单 / 长期待摊摊销清单 | — | 见第五节 |

**常见问题**：存货、应付账款余额**偏大**——材料领用出库暂未结转（无原材料/生产成本科目，属已知口径上限，不影响利润表）；附件 14 模板按业务员拆费用，系统按费用科目出（费用单上没有业务员字段）。

## 五、固定资产与待摊（C5）

**在哪**：钱流管理 → **资产与待摊**（概览 / 固定资产 / 长期待摊 / 月结过账）。

> **当前生产结论：NO-GO。** `UTEN_FINANCE_ASSET_POSTED_WORKFLOWS_ENABLED=false` 必须保持；
> 不得录入真实资产后尝试激活、处置批准或待摊提前终止批准，也不得让运维或数据库人员直改状态。

仅在授权 UAT 环境按以下顺序验证：

1. 财务负责人先配置并复核类别、成本/累计/费用/来源过渡科目、期限、残值和必备资料代码；
2. 资产会计创建**测试草稿**，补齐来源引用、关键日期、部门/地点/责任人和金额，提交；
3. 由另一名具有 `finance_asset:approve` 的人员审批或驳回，验证发起人不能自审；
4. 在隔离种子数据具备可计提对象时，进入“月结过账”选择开放期间和折旧/摊销类型，先做**预览**，
   核对笔数、逐项金额、尾差、异常和输入指纹；
5. 发起人提交月度批次，另一名复核人审批，再由符合本人回避规则的过账人员执行；
6. 对运行编号、逐项合计、凭证借贷和折旧/摊销清单；两类运行均完成且差异为零后才测试关账；
7. 发现错误时只能创建引用原批次的**正常反向批次**。原批次、原日志、原凭证必须保留，严禁
   删除当期后重建；
8. 刷新、超时或断网后，进入“批次历史”人工刷新并按运行编号回查最终状态，不能盲目重复提交。

当前月度反冲只覆盖折旧/摊销批次，不是资本化、处置或终止业务事件反冲。初始确认、处置清算、
提前终止、退款/贷项、TAX 账和历史期初不属于本轮可验收生产能力。完整 UAT 清单和放行条件见
[51](51-资产与待摊专业化全链路.md)及
[专项验收报告](../99-项目治理/2026-08-01-资产与待摊全链路实现与验收报告.md)。

## 六、对账单/汇总表都对了之后：两个流程类新功能（C6）

### 6.1 报销（一般费用单）自动做会计分录
- 费用单**审核**后系统自动生成总账分录（借：费用科目，贷：付款账户），详情页头部「总账」显示状态。
- 财务在详情页点「**财务确认**」完成入账确认（状态变"财务已确认"）；红冲会自动删掉分录。
- 验收：开一张小额测试费用单（如 66 元办公费），审核 → 看「总账」列 → 总账报表·科目余额表里该科目有数 → 财务确认 → 红冲 → 分录消失。

### 6.2 现金客户发货要财务先审
> V124 以下内容保留财务审核功能本身；发运后的纠错规则已由 V187–V189 收紧。
> 所有 `SHIPPED` 禁止普通红冲，财务验收不得沿用 2026-07-29 的“发货后红冲删除测试单”步骤。

- **现金结算客户**（目前 28 家，结算方式=现金）的出货单，仓库点「审核」会被拦：*现金结算客户须财务审核发货后再审核出货单*。
- 财务在出货单详情页点「**财务审核**」（按钮旁会提示该客户**未收余额**，方便核对到款）；月结客户不受限制。
- 验收必须在隔离测试库、专用测试客户和专用测试订单上执行：先验证现金客户未财务审核时仓库动作被拦，再完成财务审核并验证放行。若单据尚未进入 `SHIPPED`，只按当前服务端允许的草稿反审/清理路径收尾；若继续验证到 `SHIPPED`，应确认普通红冲被拒绝，并另建销售退货单验证“退货审核进入 V189 质量冻结、仅 `GOOD_RELEASE` 回可售库存”。禁止通过红冲或删除清理已发货测试单。

## 七、发现问题找谁 / 常见疑问速查

| 现象 | 解释 |
|---|---|
| 委外对账单历史月份"发料/期初/结存"不对 | 老系统发料数量未迁入（全 0），新单据正常后自动正确 |
| 塑料耗用"上月/账面结存"与手工差很多 | 系统推算口径，老 BOM 不全导致；以本月发生列为准 |
| 存货/应付余额特别大 | 材料出库未结转（已知上限），不影响利润与应收应付往来 |
| 费用明细表里人工/折旧/社保是空 | 人工/社保仍缺数据源；折旧/摊销只在已有合法月度批次时出数，当前不得为出数而绕过资产核心门禁 |
| 报表数字和手工表差几分钱 | 系统按单精确到分累加，手工常有四舍五入差；尾差以系统为准 |
| 想再生成凭证 | 通用总账只可重建其明确拥有的 7 类 AUTO 来源，不能触碰资产凭证；资产错误必须走关联原批次的正常反冲 |
