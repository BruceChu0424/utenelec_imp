# V948 客户财务分权与多人负责人

对应 `V948__client_financial_fields_and_co_owners.sql`。本迁移为前向候选，不修改既有 Flyway 历史，也不表示目标公司数据库已执行。

新增默认关闭的 `client:finance`，挂接客户资料权限面。管理员通过现有权限页显式开通，原个人授权、部门授权和收回记录保持有效；迁移不自动增加财务部门、销售部门或指定人员的权限。

新增 `client_co_owners` 保存额外负责人，保留 `clients.owner_employee_id` 作为主负责人。客户及员工组合唯一，员工必须符合在职与启用账号条件。正式离职前完成主/共同负责人交接。新增完整前后负责人数组到追加式访问变更事件，旧事件原值不回写。

共同负责人表接入 FULL 行审计、客户读取范围失效和修改历史；修改历史只展示并引导专用访问设置流程，不能通用恢复负责人。当前旧业务清空入口已在 V919 退役，本迁移不重建该入口。

验证应覆盖：空库完整迁移、单人兼容、多人读取与对象写范围、批量不同旧主负责人替换、版本冲突整批回滚、移出负责人只读继承、离职责任交接、财务请求及行内/历史回放越权拒绝。实际执行结果见[本轮回归记录](../99-项目治理/2026-10-27-登录历史与客户资料权限及多人负责人.md)。
