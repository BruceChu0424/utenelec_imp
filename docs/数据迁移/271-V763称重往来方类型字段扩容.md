# V763 称重往来方类型字段扩容

## 原因

V743 的 `goods_weight_observations.counterpart_kind` 为 `VARCHAR(12)`，同表 CHECK 和服务端合法类型均包含 `SUBCONTRACTOR`（13 字符）。委外出仓录入实称重量后，审核写称重观测会报字段过长并回滚；相关委外入库称重同样使用该类型。

## 变更

追加 `V763__weight_observation_counterpart_kind_width.sql`，将字段扩为 `VARCHAR(32)`。不修改 V743，不删除记录，不替换 `SUBCONTRACTOR` 为其他往来方，不移除类型与 ID 成对存在的 CHECK。

V761/V762 在并行任务中已有候选说明，本次预留更高编号避免冲突。当前工作区实际 SQL 文件数单独统计；发布前须核对最终迁移目录，不可把候选说明当作 SQL 已并入或已部署的证据。

## 验证与执行边界

在隔离 PostgreSQL 16 测试库执行完整迁移，并覆盖带重量的委外草稿重复保存、审核与红冲，确认记录保留和数量对称。用户当前业务库未执行此迁移。

上线前按既有发布流程完成备份、迁移验证和运行版本确认。应用回退时可保留扩宽字段；不得缩回 12 字符，因为成功写入的合法 `SUBCONTRACTOR` 无法容纳，缩回会失败或破坏业务能力。
