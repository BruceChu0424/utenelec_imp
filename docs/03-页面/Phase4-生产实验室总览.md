# Phase 4 — 生产 / 实验室现状

> 上层：[页面总览](页面总览.md)。本文只记录当前可运行范围，不把历史 Mock 页面或规划路由计为已实现功能。

## 当前边界

- **生产管理**：生产计划、生产日报、BOM 成本、排程/进度和生产报表使用 `/production` 真实模块。
- **库存与仓库**：即时库存、库存余额和出入库流水使用 `/stock/*`；仓库业务使用 `/warehouse`。
- **实验室检测**：当前没有可访问页面、注册路由或后端 API。原 `/lab/test*` 纯 Mock 实现已删除。
- **空调控制**：当前没有可访问页面、注册路由、设备通道或后端 API。原 `/hvac*` 纯 Mock 实现已删除。
- 工作台仍显示“检测记录”和“空调控制”，但两者均为不可点击的“功能规划接入中”占位，不会跳转到 Mock 或无效路由。

## 当前页面

| 功能 | 路由 | 现状 |
|---|---|---|
| 生产管理 | `/production` 及子路由 | 真实后端候选；发布仍需目标库、对账和岗位 UAT |
| 库存余额 | `/stock/balance` | 真实后端；调整动作需独立权限并产生审计单据 |
| 出入库流水 | `/stock/movement` | 真实后端；可回查来源单据 |
| 流水线看板旧提案 | 无 | 未实施；现有排程/进度页承担相关能力 |
| 产量录入/统计旧提案 | 无 | 未实施；优先使用生产日报与真实生产报表 |

## 权限与数据

- 现行生产、库存和仓库页面继续使用各自真实路由权限与服务端数据范围。
- `lab:test:view` 和 `lab:test:upload` 权限常量仅为未来兼容保留；当前不对应任何 Flutter 路由或 API。
- `LabTest` 和 `HvacDevice` 等历史概念不是当前 Dart 模型，也没有可供验收的权威业务数据。

## 发布边界

实验室和空调占位不能计入功能数、UAT 通过数或生产能力。重新实施时必须从真实服务端合同、设备/检测数据模型、服务端授权、审计和端到端验收开始；不得恢复本地内存 Mock 作为上线功能。
