# 审批只读检查

2026-10-11 用户决定：先停用新增的审批改单能力，审核人查看提交的业务内容并作出审批决定；原有财务核价保留。本次逐模块阅读页面、编辑表单、路由、仓库和财务接口、领域保存权限及共享扩展列授权，按每条业务链判断，不以名称批量禁用输入。

| 页面和链路 | 当前边界 |
|---|---|
| 采购、委外订货财务审批 | 数量、单价、总金额、允许超收/损耗等提交事实只读；删除金额编辑、保存审核修改及 amend 接口；保留认领、版本、审批意见、财务换算汇率和通过/驳回。 |
| 销售订单财务确认 | 订单商业事实只读；删除单价/折扣核改及 amend 接口；保留原报价对照、销售修订历史、确认备注和驳回。 |
| 采购/委外收货、退货、领退料、损耗详情 | 删除新增“修改后审核”入口和专用审核保存模式；正常制单草稿编辑按 edit 权限与归属校验，审核按原 approve 权限执行。 |
| 销售报价财务核价 | 保留原有成交价、折扣、赠品和最新标价刷新；删除数量、独立报价基价编辑、删行。旧 API 参数被拒绝，含已停用改单内容的旧草稿不能恢复执行。 |
| 财务收款、付款、费用、其他收入、银行转账 | 删除修改后审核页和专用审核保存接口；审核只过账已存原金额，编辑仍须 edit 和对象写范围；职责分离、反审及资金事实保留。 |
| 生产计划、生产日报 | 删除修改后审核模式和 draft-review 接口；旧 review 深链重定向到只读详情；材料余料决策及常规审核协议保留。 |
| 库存单据 | 删除修改后审核模式与专用 review 写接口；保留只读出库库存核对 outbound-review / approve-reviewed 以及实际仓库执行。 |
| 报销、员工档案修改、工资、访客、库存盘点审批 | 原申报信息只读；审批理由、独立打款事实、访客用途决定和盘点处置保留。 |
| IQC/FQC、批量质检、超量到货、质检退回结算与资产工作台 | 实际检验、批量入库、超量批准量、贷项和资产核算参数是各自业务职责，保留；不能借审批权限修改原提交单据。 |

共享扩展列已移除以 approve 权限代替 edit 权限的审核保存上下文。审批附件只读，实际仓库作业凭证依其原执行权限办理。普通制单人修改、受控销售修订、历史删行/金额修改快照、红冲与反审谱系继续遵守既有权限和事实协议。

迁移 SQL 与历史业务记录不改写，旧 FINANCE_EDIT 等事件仍可查。专用旧写接口关闭；不能只隐藏按钮而留下审核越权保存旁路。

验证以本次针对性 Flutter、权限/API 单元测试和独立 PostgreSQL 业务链结果为准。此检查属于源码与本地验证，不表示服务器、安装包或全量 CI 已升级。
