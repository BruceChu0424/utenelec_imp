# 仓库单据编辑页(其它出入库 / 产成品进出仓 / 调拨 / 盘点)

> 路由：`/warehouse/:code/new`、`/warehouse/:code/:id/edit`(`lib/features/warehouse/pages/stock_doc_edit_page.dart`)；
> 详情 `/warehouse/:code/:id`(`stock_doc_detail_page.dart`，布局与凭证附件见[出入库记录页](出入库记录页.md) §十、§十一)。
> 权限：`stock_doc` 六类动作码按单据类型派生(见[页面权限一览](../05-架构/页面权限一览.md) §3.7)；生产链自动生成的 DRAW / FINISHED_IN 禁止通用编辑。
> 本文只记 2026-09-28 [ADR-135](../99-决策记录-ADR/ADR-135-仓库重量账与单重自学习.md) / V743 起的称重与盘点口径；
> 表头字段、单号自动生成、草稿与审核链沿用原实现。**最后更新**：2026-09-28

## 一、定位

仓库手工单据(其它入库 OTHER_IN、其它出库 OTHER_OUT、产成品进仓 FINISHED_IN、产成品出仓 FINISHED_OUT、调拨 TRANSFER、盘点 CHECK)
的新建 / 编辑页：表头表单 + 明细 `UtenEditableGrid`。数量是唯一的库存、成本与对账事实；每行可选录重量，只进仓库重量账与单重学习，永不阻断保存与审核。
入口在[仓库管理枢纽页](仓库管理枢纽页.md)「新建单据」区；盘点单还可以从[库存分析页](库存分析页.md)「盘点建议」按仓库预填生成。

**仓库用途(2026-10-04 [ADR-146](../99-决策记录-ADR/ADR-146-不良品仓业务规则与可用量单一口径.md))**：表头仓与行仓按单据类型的用途选——其它入库/产成品进仓只能选良品仓；其它出库/报废两类都可；
盘点两类都可；产成品出仓只能从良品仓出。调拨的调出仓两类都可，调入仓下拉只列与调出仓同类的仓(换了调出仓类别会清空调入仓)，
服务端同样拒绝跨类的普通调拨。良品与不良品之间只走库存详情的「转不良品仓」「不良复判转回」(调拨类型 + 独立权限 + 原因，一次建单并过账)；
这类调拨单的详情页显示「调拨类型」与「原因」，红冲还需要对应通道的独立权限。

## 二、明细表的重量列

- **非盘点单**：「数量」后一列「实称重量(kg)」(共享[重量格](../02-组件库/WeightGridColumn.md))。
  工具条「称重单位: 千克▾」切换录入单位；格子接受 850g、1.2t、3斤、2lb；0 或空 = 没称。
- **盘点单**：列序 账面 | 实盘 | **账面重量**(只读) | **实盘重量**(可选) | 盘盈亏。
  账面重量与账面数量一起按所选仓库读余额(`GET /api/stock/balances`，含估算标记「≈」，未知显示「未称」)；
  填了实盘重量，审核后该仓库维度的账面重量按实盘重量定(盘点定重)。
- **「数量 + 单位」内联(2026-10-10 全站表格口径)**：明细表的独立「单位」列已删除——
  数量/实盘输入格的单位显示在输入框尾部(suffixText)，账面/盘盈亏只读格单位直接跟在数字后
  (`formatQtyWithUnit`)；控制器文本保持纯数字，解析与提交口径不变。
- **采集口径按单据类型**：
  - 盘点：称重计数主按钮「填入数量和重量」，实盘数量空着时填实盘重量会按单重推算实盘数量(黄框、`qtyFromWeight`)；
  - 其它入库 / 产成品进仓：同上，数量空着时按称重推算数量；
  - 其它出库 / 产成品出仓 / 调拨：出库口径，占位「应称 X」，⚖ 称重计数反推「需要 N 个 → 秤上应显示约 Y kg」，只填重量。
- **行右键菜单**(单行且已选货品)：「称重计数...」「称样校准...」(称样校准保存后刷新该货品单重)。
- **偏差**：学到单重时按容差核对，WARN 琥珀框 / ALERT 红框 + ⓘ 件数说明；单重未学准不核对。表尾「实称 X (未称 N 行) · 称重偏差 N 行」。
- 按重量计的货品 / 行单位(基本资料单位登记了「等于哪种重量单位」)：重量格只读「=25 kg」，不提交重量。
- 保存校验：看不懂的重量拦下(「看不懂，例：850g、1.2t、3斤、12」)；盘点实盘数量为 0 时不能再填实盘重量。
- 已保存单据重开时恢复重量；保存时按称重折算过的数量继续显示黄框(「保存时按称重折算的数量」)。表单草稿同时保存重量与 `qtyFromWeight`。

## 三、生成盘点单预填(StockCheckPrefill)

- 库存分析「盘点建议」勾选行后点「生成盘点单(N)」，按仓库分组：一次只开一个仓库的新建盘点页(多仓时先问「先为哪个仓库生成盘点单?」)，
  经 GoRouter `extra` 传 `StockCheckPrefill(warehouseId, lines: [StockCheckPrefillLine(goodsId, colorId)])`；
  路由 `/warehouse/CHECK/new` 只对盘点新建认这个 extra(其它单据类型与编辑态忽略)。
- 页面按预填设置仓库(须是当前可选叶仓)、建未保存的明细行(同一货品同一颜色只一行；名称、编号、单位按主档带出)，再照常按仓库读取账面数量与账面重量；
  实盘数量与实盘重量现场填。预填只是未保存的草稿行，不改任何库存。
- 盘点建议按「仓库 × 货品 × 颜色」出行，预填行带颜色；无颜色货品 `colorId` 为 null。

## 四、请求与服务端规则

- `POST/PUT /api/stock/docs` 的 `items[]`：
  - 非盘点单：`weight`(千克，4 位)；盘点单：`countWeight`(实盘重量，千克)，另有 `qty` = 账面、`countQty` = 实盘；
  - `qtyFromWeight: true` 仅在数量由称重推算时发送。
  - 服务端规则：盘点行忽略 `weight`，其它单据忽略 `countWeight`；`countWeight` 配实盘数量 0 返回 400；按重量计的货品填 `countWeight` 返回 409
    「第 N 行按重量计的货品不用单独填重量」；按重量计的货品 / 行单位的 `weight` 被丢弃(重量账按数量精确换算)。
  - 盘点行保存时写账面重量快照 `book_weight`(只显示)；审核时若该行填了实盘重量且账面重量已变化返回 409(请刷新)，没填实盘重量的行只刷新快照，不拦。
- 审核过账：
  - 行重量按实称(MEASURED)记到流水，数量与重量同一语句写余额；未称行由重量账按库存均重或学到的单重推算(估算带「≈」)。
  - 盘点：先过账盘盈 / 盘亏数量(盈亏为 0 也照样处理重量)，再对填了实盘重量的行写一条 COUNT 重量调整(盘点定重，前值 = 当时账面重量，后值 = 实盘重量)；
    红冲盘点时先镜像数量流水，再对每条盘点定重写 REVERSAL(撤销盘点重量)。
  - 单重学习：手工单审核时，称过且不是按称重推算数量的行记称重观测——其它入库与手工产成品进仓记 OTHER_IN(参考证据，带单据供应商)，
    其它出库 / 报废 / 产成品出仓记 OTHER_OUT、调拨记 TRANSFER(核对证据)，盘点记 COUNT(参考证据；授权余额调整生成的盘点单不记)；红冲时标为已红冲。
- 出库复核指纹(`StockDocOutboundReviewFingerprint`)包含 `qtyFromWeight` 与 `countWeight`。
- 详情 `GET /api/stock/docs/{id}` 的 `items[]` 增加 `qtyFromWeight`、`countWeight`、`bookWeight`、`issuedWeightKg`、`issuedWeightEstimated`；
  详情页通用明细表的重量列改名「重量」并移到数量组之后(未称显示「未称」，不是 0)，盘点单另显示「账面重量」「实盘重量」。
- 仓库报表：盘点明细报表 `bookWeight` = 账面重量快照、`actualWeight` = 实盘重量，均为 `weight` 类型(千克)并有合计；
  报表页按用户显示单位换算，导出列头带「(千克)」。
