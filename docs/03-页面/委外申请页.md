# 委外申请页

> 路由：`/subcontract/applications/:id`(委外申请详情)
> 别名：委外申请、委外任务、外发申请、委外下单、为什么下不了委外单、委外锁住

## 一、定位

委外申请是物料分析「下达委外」后生成的委外需求：哪个委外件、要多少、什么时候要。申请本身只读，不能在委外端新建或修改；委外人员在委外任务中心「待处理」里勾选申请，生成委外订货单。

直属物料不够时，申请会锁住、不能下单。原因是委外加工价每天不一样，财务批准订货单那天价格就定了；物料没齐就先下单，等物料齐了价格可能已经对不上。所以现有物料够做几套，才能下几套。

## 二、入口与导航

- 委外管理首页「委外任务中心」→「待处理」分段：一行是一张还有未下单数量的委外申请。
- 收到「委外可下单：…」通知卡时，点开直接进入「待处理」并按申请号搜索。
- 打开委外申请列表的地址，会直接转到委外任务中心；委外申请没有单独的列表页。
- 委外申请详情可以从生产计划详情里的「委外申请」链接打开，只能查看，不能修改。
- 新建或编辑申请的地址只显示说明：「计划委外申请不能在委外端新建」「申请由物料分析下达。请回到委外任务中心选择已下达且仍有余量的申请明细。」，并提供「进入委外任务中心」按钮。

## 三、响应式布局

- 委外任务中心按分类显示「草稿 / 待处理 / 进行中 / 历史记录」(「待处理」内子分类 委外申请/领料)，默认不选分类，选了才加载。
- 「待处理·委外申请」是表格，可以按列筛选、勾选多行；手机上可以左右滑动。
- 「齐套情况」在弹窗里打开。

## 四、涉及的 Uten 组件

- 任务中心表格(勾选、列头筛选、搜索框)；
- 状态标签；
- 「齐套情况」只读弹窗；
- 底部的「生成委外订货单(N)」按钮。

## 五、功能点

### 5.1 「待处理」里申请的状态

| 状态 | 什么时候出现 | 能不能下单 |
|---|---|---|
| 缺 BOM·已通知研发 | 委外件还没有可以发外的直属物料(缺 BOM) | 不能勾选；不计红数，等研发补好 BOM。研发任务被取消而 BOM 仍缺时，行上有「通知研发完善」 |
| 等物料齐套 | 还有没下单的数量，但直属物料连一套都不够 | 不能勾选、不能生成委外订货单；照样留在「待处理」并计红数。行上提示「直属物料还没齐，委外价格每天不同，物料齐了才解锁下单」 |
| 可部分下单·可下单 N | 物料够做一部分 | 可以勾选，这次最多下 N |
| 待下单 | 物料够做全部剩余数量 | 可以勾选 |

### 5.2 齐套情况

行上点「齐套情况」，打开只读弹窗：

- 顶部：剩余未下单、够做套数、可下单。「可下单 = 剩余未下单与现有物料够做的套数取小，订货数量超出会被拒绝。」
- 每种直属物料一行：每套用量、需要、专属库存、已被占用(别的还在办的委外订货单要领走的量)、现在能用、还缺、够做套数。
- 够做套数最小的那种物料，就是卡住下单的料。弹窗会说明还缺的物料是否已经在途：在途的到货入库后会自动提醒；没有在途的请联系计划安排。

「现在能用」= 物料分析分给这张申请的专属库存 + 公共可用库存，再扣掉其它还在办的委外订货单(草稿、在审、财务退回、已批准未结案)还要领的量。只算良品仓，不算不良品仓和车间内料仓。

### 5.3 生成委外订货单

1. 在「待处理」勾选可以下单的申请(可以跨申请勾选)，点「生成委外订货单(N)」。
2. 进入委外订货单编辑页，数量按「这次能下多少」预填：几张申请一起选时，需求日期早的先用公共库存，各自的专属库存只给自己；能下 0 的明细不预填。
3. 预填数量可以改。改大(包括超过申请剩余量)要物料够，保存、提交财务、财务批准时系统都会再核对；不够时会点名缺哪种物料、要多少、现在能用多少。减少数量、删除草稿不受限制。
4. 手工直接新建的委外订货单只能用公共库存。

### 5.4 下单之后

财务批准委外订货单后，在委外任务中心「待处理·领料」提交领料，仓库把直属物料发给委外商；委外商加工好分批回厂，经来料质检合格入库。见[委外专属工作台与页面权限](委外专属工作台与页面权限.md)。

### 5.5 可下单提醒

申请可以下单的数量比上次提醒时多了，系统给采购委外部门里能生成委外订货单的人发「委外可下单」行动卡；数量变成 0 时撤回这张卡。

## 六、功能链路图

1. 物料分析「下达委外」 → 委外申请(待处理)。
2. 系统按直属物料算这次能下多少：一套都不够显示「等物料齐套」，够一部分显示「可部分下单」。
3. 物料到了、能下单了 → 「委外可下单」提醒。
4. 勾选申请 → 「生成委外订货单」 → 提交财务 → 财务批准。
5. 「领料」 → 仓库发料 → 委外加工 → 分批回厂 → 来料质检 → 入库。

## 七、涉及的数据实体

委外申请(来源计划、委外件、数量、需求日期、状态)；直属物料的专属库存和公共可用库存；委外订货单。

## 八、权限要求

- 看申请和「齐套情况」需要「查看委外申请」。
- 生成委外订货单还需要委外订货的查看、新建等权限；缺了时按钮旁提示「缺少委外申请查看、订货查看、新建或下单权限，请联系管理员按岗位授权」。
- 申请只能由物料分析下达，任何人都不能在委外端新建或修改。

## 九、边界情况

- 勾选了不在「待处理」的任务：提示「只能选择「待处理」的任务」。
- 所选任务已经进入订货或回厂阶段：提示「所选任务已进入订货或回厂阶段，不能再次下单」。
- 计划还没下达：提示「计划申请尚未下达，请刷新后重试」。
- 加载失败：显示「无法加载委外任务」和「重试」。

## 十、常见问题

### 为什么我下不了委外单，勾选框是灰的

先看这一行的状态：「等物料齐套」说明直属物料连一套都不够，物料齐了才解锁；「缺 BOM·已通知研发」说明在等研发补 BOM。点「齐套情况」可以看到具体缺哪种料、还缺多少。如果按钮旁提示缺少权限，才是权限问题。

### 物料够做一部分，能先下一部分吗

能。状态会显示「可部分下单·可下单 N」，这次最多下 N，剩下的等物料再到。

### 委外申请能改数量吗

申请本身不能改。要多下，在生成的委外订货单上改大数量(物料要够)；要调整需求，回到物料分析处理。

### 锁住的申请为什么还算红数

锁住的申请仍然是要委外人员跟进的事，所以照样留在「待处理」并计红数；只有缺 BOM 的不计，因为那时在等研发。
