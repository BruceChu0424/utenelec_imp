## 一、变更总览

V458 反转**分析来源**有子层级委外件的时序，并放宽直下单的整批门禁：

```text
物料分析准备 · SUBCONTRACT 路线（服务端按活动 BOM 分流）
  ├─ 无子层级：立即生成只读委外申请并通知委外部（V436 语义不变）
  └─ 有子层级：不生成申请、不通知委外部
       → 原分析内创建 SUBCONTRACT_MAKE 前置自制任务（子树委托，与 MAKE 同构）
       → 齐套检查 → 计划向导 → DRAW 领料 → 报工 → FQC → 成品实收入库
       → 账本 produced/notified + SUBCONTRACT_PREPARE_TASK 专属预留
       → 满批自动 / 未满批手动分批 → 生成委外申请并通知委外部
       → 委外任务中心分解 → 订货 → 财务批准
            → 该行 flow_mode=PREPARED_OUTBOUND / READY_OUTBOUND
            → 任务预留切片释放并等量转为该行 SUBCONTRACT_OUTBOUND 预留
       → EC 出仓 → 回厂 → IQC → 仓库确认入仓（推进原分析）
```

直下单（委外部直接新建订货单）保持 MAKE_THEN_OUTBOUND 先自制后出仓，
但任一批次实收即释放可出仓量（分批出仓）；通知只在首片与整批完成发出。

## 二、结构变更

| 对象 | 变更 | 权威用途 |
|---|---|---|
| `production_material_analysis_items.source_type` | + `SUBCONTRACT_MAKE` | 原分析内的委外件前置自制任务行；子树需求委托给它（唯一索引与维度触发器与 MAKE_COMPONENT 同构） |
| `preplan_supply_actions.external_document_type` | + `SUBCONTRACT_MAKE_TASK` | SUBCONTRACT 路线有子层时标记为自制任务而非申请 |
| `preplan_subcontract_make_tasks` | 新表 | required/produced/notified 守恒账本；`notified = Σ批次` 由延迟触发器强制；取消仅允许 produced=notified=0 |
| `preplan_subcontract_make_task_batches` | 新表 | 每次通知一批：application/application_item/allocation/qty/幂等键 |
| `subcontract_material_plan_items.flow_mode` | + `PREPARED_OUTBOUND` | 下单前自制已完成的行；shape：prepared=planned、READY_OUTBOUND 起步、指向原分析 SUBCONTRACT_MAKE 行 |
| `stock_reservations` owner | + `SUBCONTRACT_PREPARE_TASK` | 自制产出在通知/订货前扣住公共可用量（supply=PRODUCTION_FINISHED_IN） |
| `fn_assert_subcontract_preparation_source` | 扩展 | PREPARED_OUTBOUND 行必须能经批次账本追溯到 ACTIVE 任务且数量/维度一致 |
| 出仓分配 / FINISHED_IN 血缘断言 | 扩展 | 接受 PREPARED_OUTBOUND；转换后的预留沿用 PRODUCTION_FINISHED_IN 溯源 |

## 三、关键路径与 API

| 动作 | 位置 | 说明 |
|---|---|---|
| 下达分流 | `MaterialAnalysisCommandService.createExternalDocument` SUBCONTRACT 分支 | 有活动 BOM 子件 → `createSubcontractMakeTask`（任务行+账本+通知生产，不出申请） |
| 成品入库钩子 | `SubcontractMakeTaskService.afterFinishedInboundApproved`（挂 `ProductionCompletionReverseService`，先于分析刷新） | 预留+账本+满批自动通知；维度/换算/冻结仓不符 fail-closed |
| 分批通知 | `POST /api/production/material-analyses/subcontract-make-tasks/{taskId}/notify`（`production_material_analysis:notify` + 本人策略） | qty ≤ LEAST(required,produced) − notified；幂等键重放 |
| 任务进度 | `GET /api/production/material-analyses/subcontract-make-tasks`（`production_material_analysis:view`） | 物料分析页「委外件前置自制」卡 + 委外准备中心「分析来源」页签 |
| 订货批准 | `SubcontractMaterialPlanService.createPlanOnApproval` | 批次谱系 → PREPARED_OUTBOUND + 预留转换 + EC 草稿 + 通知仓库 |
| 直下单分批 | `afterFinishedInboundApproved` CASE 放宽 | prepared>0 即 READY_OUTBOUND；首片/整批通知 |

## 四、兼容

- 在途 V436 单据（已生成申请或已订货）继续按原链执行，仅享受分批出仓放宽。
- V458 迁移只新增约束/表/断言，不回填、不改写历史行；`LEGACY_BOM_COMPONENT` 不动。
- audit 覆盖与 reset 白名单（CLEAR）已登记，reset 目录门扩至 V458/420。
- 前端：委外 Hub 去教学区改为任务/单据/报表/历史兼容四组；8 个列表页去责任头；
  委外准备中心双页签；物料分析页新增前置自制卡与「通知委外」入口；
  `/subcontract/preparations` 路由守卫放宽为 `subcontract_preparation:view`
  或 `production_material_analysis:view`。

## 五、验收清单

下达分流、委托不重复备料、FINISHED_IN 预留+账本+自动通知、手动分批上限与幂等重放、
PREPARED_OUTBOUND 批准即时出仓与预留转换、直下单分批出/进/PASS、红冲三层守卫
（成品入库 notified>produced-after 阻断；订货红冲预留转回任务；出仓红冲对称）、
取消守卫、越权/对象范围、并发 CAS、通知收件人（SUB_PLAN/DEPT_PROD 与委外部）。
