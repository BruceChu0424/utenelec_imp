# 货品资料详情与编辑页

路由为 `/basicinfo/goods/new?categoryId=...` 和 `/basicinfo/goods/:id`。界面遵守 `frontend-design`，复用 Uten 表单、页签、颜色选择器和主题。

基本信息的“型号”是货品自身型号，“客户型号”维护已有 `goods.c_number`。客户型号从新增、详情回显、编辑到 API 保存共用 `cNumber`，不新建另一份客户型号字段。旧客户端不传该键时服务端保留原值，显式传空才清除。

“颜色”维护原来的主颜色 `colorId`，以颜色 UUID 提交；字段内说明交代它是货品默认主颜色。单据行颜色、库存颜色维度和 BOM 颜色沿用各自原有规则。

整页新增或编辑保存成功后自动关闭并返回实际来源：优先恢复 push 栈下页面，深链读取 `returnTo`，没有来源时回货品资料页。新增提交前保存本机草稿，服务端确认成功后完成本机草稿，再返回来源；本机清理异常不把已成功的业务保存误报为失败。校验失败、冲突或网络失败保留页面和输入；更新成功后不再以额外详情读取作为是否成功的条件。

已保存货品仍可再次打开详情，通过“组装信息”维护 BOM；保存基本信息不更改数量单位生命周期、来源、BOM 或库存关系。
