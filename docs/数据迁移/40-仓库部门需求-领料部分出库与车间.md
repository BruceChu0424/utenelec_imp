## 二、DRAW 部分出库设计（V97）

**语义变更**：DRAW 审核 0→1 不再直接动库存（审核 = 确认领料单）；库存流水（T_DRAW）由出库动作分轮产生。历史已审 DRAW 单迁移时回填 `issued_qty=qty` + `issue_status=2`（旧语义「审核即全部出库」保持账目一致）。

**接口**（`/api/stock/docs`，权限 stock_doc:edit）：

```
POST /{id}/issue          分轮出库：{lines:[{itemId, qty}]}，每行 ≤ qty−issued_qty
POST /{id}/issue/reverse  反出库：每行 ≤ issued_qty（红冲前须全部反出库）
```

- 金额/重量按 本次/行总量 比例分摊写流水；并发与审核/红冲同一把 PESSIMISTIC_WRITE 行锁。
- 全部出完 → `is_closed=true`；反出库回减后自动复位。
- 红冲守卫：有 `issued_qty>0` 的行 → 400「请先全部反出库再红冲」。

**前端**：详情页 DRAW 已审时显示「出库 / 反出库 / 红冲」按钮（按行输入本次数量，默认填满剩余/已出）；明细行显示 数量·已出库·剩余；头部 kv 显示领料车间 + 出库进度。
