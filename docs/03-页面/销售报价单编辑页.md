# 销售报价单编辑页

> 路由：`/sales/quotes/new`(新建)、`/sales/quotes/:id/edit`(编辑)
> 别名：新建报价单、做报价、报价、改报价、给客户报价

## 一、定位

销售给客户做价格方案的页面。报价单不是正式订单：填好保存后，在报价详情点「提交财务核价」，由财务逐行定价格和折扣；财务确认后，销售和客户确认，再「登记客户同意」，然后「转订货单」生成订货单草稿。

报价阶段可以改这张报价的单价、折扣和数量，不会改动货品资料里的标价。

## 二、入口与导航

- 销售管理首页「新建单据」里的「新建销售报价单」，直接进入新建页。
- 在销售订货单上识别客户文件时，如果有还没标价的货品，点「改为新建报价单」会用同一次识别结果打开本页。
- 报价详情：草稿或财务退回的报价点「编辑」。
- 新建页右上角「草稿(N)」打开报价单列表的草稿分段。
- 保存成功后进入这张报价的详情页，在详情页「提交财务核价」。

## 三、响应式布局

- 手机：表头字段排成一列，明细表格可以左右滑动。
- 平板和电脑：表头字段按宽度排成多列；明细表格在下面，可以在「表头设置」里选显示哪些列、拖动排序。
- 保存按钮在右下角的悬浮操作区。

## 四、涉及的 Uten 组件

- 可编辑明细表格(与订货单共用)；
- 客户选择、员工选择(业务员)、下拉选择、日期选择；
- 「附件」区：放客户文件，也是识别客户文件的入口；
- 明细下方的合计条。

## 五、功能点

### 5.1 表头

字段顺序和新建订货单一致，有效期放在最后：

| 字段 | 说明 |
|---|---|
| 单据号 | 保存后系统自动生成 |
| 单据日期 | 开单日期 |
| 客户 | 必填；选好后自动带出客户资料里的默认结账方式 |
| 币种 | 选填，新建时自动带本位币 |
| 结账方式 | 选填，财务核价时可以改 |
| 业务员 | 选填，默认是你自己 |
| 交货日期 | 选填 |
| 合同号 | 选填；识别客户文件时会带入客户单号 |
| 有效期 | 必填，新建时默认今天往后 30 天(黄框，可以改)；过期的报价不能转订货单 |
| 备注 | 选填 |

### 5.2 明细

- 单价由货品标价带入，可以修改这次报价的单价和折扣，不会改变货品资料；没有单价可以留空，交给财务填写。
- 折扣填小数：1 是不打折，0.9 是九折；空着的折扣格显示「财务核价时填写」。
- 默认显示货品名称、英文名称、编号、颜色、数量、单位、单价、折扣、金额、备注；从客户文件识别来的行，有值时另显示文件型号、文件品名、文件单价。
- 没有价格查看权限的账号，单价、折扣和金额显示为「***」。

### 5.3 识别客户文件

与[销售订货单编辑页](销售订货单编辑页.md)相同：在「附件」区添加客户文件，在文件卡上点「AI识别」，识别出的客户和明细填进页面，标黄的行逐行核对后保存。报价单可以导入还没标价的货品，交给财务定价。价格从不取自文件。

### 5.4 保存

点右下角「保存」，先检查必填项；新建保存成功提示「已创建」并进入报价详情。保存只得到草稿，财务还看不到。

### 5.5 提交核价和之后的步骤(在报价详情页)

| 报价状态 | 你能做什么 |
|---|---|
| 草稿 | 编辑、删除、「提交财务核价」、取消报价 |
| 待财务核价 | 财务认领前可以「撤回」回到草稿再改；这期间不能修改 |
| 财务退回 | 按退回原因修改后重新提交，或取消报价 |
| 已核价(待客户同意) | 和客户确认后点「登记客户同意」；也可以「重新修改」回到草稿(要重新核价)或取消 |
| 已核价(待生成订货单) | 点「转订货单」生成订货单草稿 |
| 已转订货单 | 只能查看，可以「查看订货单」 |
| 已取消、作废 | 只能查看 |

- 提交时提示：「提交后财务会逐行定价格和折扣, 这期间你不能修改这张报价。」
- 报价在财务确认之后又被修改、重新提交或财务撤销确认，原来登记的客户同意就失效，要重新登记。
- 转订货单时提示：「根据双方同意的当前报价生成订货单草稿，带入核定单价、折扣及条款。请核对信息后保存、审查并提交财务审核。」生成后自动打开订货单编辑页；这些行的折扣在订货单上不能再改。
- 提交、撤回、财务修改价格、财务退回、财务确认、重新修改等动作都会写进详情页的「核价记录」。

## 六、功能链路图

1. 新建报价 → 填写 → 保存，得到草稿。
2. 报价详情「提交财务核价」 → 财务认领后修改、退回或确认。
3. 财务确认 → 销售与客户沟通 → 「登记客户同意」。
4. 「转订货单」 → 订货单草稿 → 在订货单上保存、审核、送财务确认。
5. 客户不接受：「重新修改」后再提交，或填写原因取消报价。

## 七、涉及的数据实体

销售报价单：单头(客户、币种、结账方式、业务员、交货日期、合同号、有效期)和明细(货品、颜色、数量、单位、单价、折扣、金额、备注)；核价记录；转入的订货单。

## 八、权限要求

- 新建需要「新增销售报价单」，编辑草稿需要「编辑销售报价单草稿」。
- 财务核价由财务部门里有「销售报价财务核价」权限的人办理，见[销售报价财务核价页](销售报价财务核价页.md)。
- 单价、折扣和金额只有有价格查看权限的账号才看得到。

## 九、边界情况

- 打不开或加载失败：显示「销售报价单加载失败」和原因，可以重试或返回。
- 报价已提交核价、已核价或已转订货单时不能直接编辑；要改先「撤回」或「重新修改」。
- 有效期已过的报价不能转订货单。
- 服务端拒绝保存时，页面如实显示拒绝原因。

## 十、常见问题

### 报价上的单价能改吗，会不会改到货品资料

能改这张报价的单价和折扣，不会改货品资料里的标价。最后的价格以财务核价为准。

### 财务核完价为什么还不能转订货单

还要和客户确认，并在报价详情点「登记客户同意」；登记后才能「转订货单」。

### 已经提交核价了想改怎么办

财务还没认领时点「撤回」回到草稿再改；财务已经确认的，点「重新修改」回到草稿，改完要重新提交核价。

### 以前给这个客户报过什么价在哪里看

在货品资料详情的「报价记录」页签，要同时有「查看货品」和「查看销售报价核价任务」两项权限。
