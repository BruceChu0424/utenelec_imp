# 2026-10-13 全平台界面整改覆盖与验收

> 源码基线：a7e3fc9db；实施工作分支：uimp/platform-ui-scale-20261013；上游 main 合入点：0e422bde1（包含03b0cce0f）、6a52bc1db（包含7ee4018d3批量性能整改）、2d53767ea（包含99a020bc1统一物料撤回文字入口）。本文记录静态覆盖、统一组件迁移和已执行的自动化回归。静态盘点不是逐页实机 UAT；生产部署与业务数据写入不在本次工作内。

## 覆盖口径

- 31 个 feature 目录中有30个UI feature；`report` 仅提供报告仓库接口，没有页面/组件。合入上游后按实际文件盘点，以文件名 `*page.dart` 计 200 个页面文件。
- `pages` 目录共 225 个 Dart 源文件，包含页面、同文件多页面以及物料分析等拆分实现，不能当成同等数量的独立页面。
- 同时扫描 307 个 feature `widgets` 文件和 121 个共享组件文件（含新增UtenFilterChip）；弹窗扫描另覆盖 `shared`、`intake`、`payables`、`templates` 等入口，包括此次上游新增的价格核对提示。
- 所有页面通过应用入口接收统一字号、等比界面缩放及控件主题；下表的组件链表示该文件直接引用的共享入口，隐含子组件仍须沿实际页面流程验收。
- 页面无横向溢出与数据表横向滚动是不同契约：业务明细表允许横向查看完整列；分类导航、操作栏、标题和表单不能靠横滚或缩小字号兜底。
