# 分类树连接线与滑窗统一

日期：2026-10-26。范围：本地 Flutter 源码与验证，未发布。

## 用户要求与设计方案

用户提供旧式分类树参考图，要求货品资料等左侧分类列显示父子连接线，展开/收起图标小一些，尽量不增加行高，并覆盖所有类似页面。后续补充将层级缩进和各种选择滑窗纳入同一范围。

本次使用 `frontend-design`，遵守项目现有组件、主题和业务约束。设计沿用 Uten 的紧凑业务界面：名称左对齐，层级用缩进与细虚线共同表达，末位兄弟在所在行收口，展开父节点向下引出连接，叶子保留对齐槽。配色和字体继续复用现有 token：

| 用途 | 既有值或入口 |
|---|---|
| 主层级 | `UtenColors.teal800`，`#115E59` |
| 第二、第三层级浅底 | `treeLevel2 #BCDED8`、`treeLevel3 #DDEEEA` |
| 浅色基础表面 | `#FFFFFF`，实际取主题 `surface` |
| 正文、次要文字、轮廓 | 主题 `onSurface` / `onSurfaceVariant` / `outline` 系列 token |
| 字体 | 现有 `NotoSansSC` 与 `bodyMedium` 等主题文字样式，使用实际 `TextScaler` |

每级缩进基准为 12px；窄栏共用同一视觉深度预算，先为展开位、选择控件、层级徽标、尾部动作及短标题留宽，再分配缩进；空间不足时可减小缩进步长或降低视觉深度上限。预算按整棵树的控件角色计算，不按某一行有没有计数或是否禁用分别改变轨道，完整祖先路径、真实层级及节点模型保留。预算的具体计算以最终 `UtenHierarchyTreeView` 源码为准，不在调用方抄写另一套宽度公式。展开位使用 14px 方框和 12px 加减号，图形缩小，桌面 32px 独立点击区与触摸最小点击区继续由 `UtenControlMetrics` 管理。原紧凑树桌面 36px、触摸 48px 的行高合同保持，标准树保留原有行高计算。

```text
[-] 成品
 :-- [-] 外贸系列
 :    `-- 外贸白色
 `-- 内销系列
```

方案核对：用户要求的连接关系是主要变化；保留现有层级色、选中反馈和文字，避免另外引入装饰、字体或更高的行。`flatLevelColors` 的历史名称继续兼容，含义调整为紧凑层级配色，所有取值都保留公共缩进、连接线与加减按钮。

### 删除与保留边界

- 删除供应商快捷选择中的手写 `ListView.builder` / `ListTile`、`supplier-category-option-*` 私有行 key、文件夹与子目录箭头、展示用 `_flatten` 和 `depth` 缩进。按稳定 ID 查找已选节点保留在字段状态中，不改变分类模型。
- 供应商选择仍只在 `UtenPickerConfirmBar` 确认后更新表单 `categoryId`；取消、关闭和返回不会回写 pending；再次打开保留已确认分类的选中反馈。父分类和子分类均可选，不套用货品数量剪枝或系统分类禁选规则。
- 保留 `UtenCategoryTreeView` / `UtenDepartmentTreeView` 作为领域配置包装；分类标签、部门层级徽标、公司根显隐、选择谓词属于必要差异，不复制公共树行。
- 公司文件侧栏仅有“文件库/回收站”两个非层级导航项，排除；卡片式 `department_org_chart_dialog.dart` 组织架构图排除；普通详情 `ExpansionTile`、设置折叠区、非层级状态分类和下拉选项不因此强制改成树。

## 业务、性能与交互保护

本次仅调整树的展示与连线共用能力，不改服务端、数据库、业务计算、库存数量或归属、币种/单位/精度、分类来源、历史、权限接口和权限裁剪。持久化节点仍按稳定 ID 识别，不从名称或唯一根数量推断透明包装根；可选谓词和系统节点规则继续由调用方决定。

树沿用既有同级业务排序或 `sortByCode` 配置、搜索排名/命中祖先链、外部搜索反馈、展开状态、单多选、右键/长按动作和独立展开命中区。结构投影只读取最终渲染顺序，过滤及隐藏包装根后重新对齐续线；折叠与动画不重放业务请求。虚拟化、行计划缓存、长分类名省略与完整路径 tooltip、实际字体缩放及触摸点击区继续使用公共实现，不截断模型换取性能。
