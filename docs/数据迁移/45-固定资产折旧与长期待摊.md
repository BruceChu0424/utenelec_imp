# 45 · 固定资产折旧 + 长期待摊摊销（C5）

> 依赖 C3 总账（V122）。2026-07-29 落地。

## 一、结构与口径

- **V123**：`fixed_assets`（编号/名称/部门/费用科目/原值/残值率默认 5%/年限月/开始期间/状态）+
  `deferred_expenses`（编号/名称/费用科目/总额/摊销月数/开始期间/状态）+
  `fa_depreciation_log`/`da_amortization_log`（asset+period 唯一，防重复计提，回链 voucher）。
- **科目种子**（auto_created）：`/152/` 累计折旧（ACCOUNT 贷方备抵）、EXPENSE 043 一级子「折旧费」「摊销费」。
- **直线法**：月折旧=原值×(1−残值率)/月数；**末月=剩余应提**（防尾差）；摊销无残值同构。
- **计提过账**：折旧 借 资产费用科目（默认折旧费）/贷 累计折旧；摊销 借 摊销费/贷 /139/ 待摊费用。
  每期间一张凭证（FA-YYYY-MM / DA-YYYY-MM），每资产两条分录。
- **幂等**：计提先删该期间 FA_DEP/DA_AMT 凭证（级联分录）与日志，再全量重建——重跑安全。

## 二、API

| 功能 | 端点 |
|---|---|
| 资产 CRUD | GET/POST `/api/finance/fixed-assets`，PUT/DELETE `/{id}`（软删） |
| 待摊 CRUD | GET/POST `/api/finance/deferred-expenses`，PUT/DELETE `/{id}` |
| 计提折旧 | POST `/api/finance/fa/depreciate?period=YYYY-MM` → `{assets: n}` |
| 计提摊销 | POST `/api/finance/fa/amortize?period=` → `{items: n}` |
| 折旧清单 | GET `/api/finance/reports/fa/depreciation-schedule`（原值/月折旧/已提月数/累计折旧/净值） |
| 摊销清单 | GET `/api/finance/reports/fa/amortization-schedule`（总额/月摊销/累计/余额） |
