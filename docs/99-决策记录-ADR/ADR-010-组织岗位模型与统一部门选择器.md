# ADR-010：组织/岗位模型定稿与统一部门选择器

> 日期：2026-07-23 · 状态：已实施（后端 javac 编译零错误 / 前端 analyze 零问题；运行时待冒烟）
> **2026-08-01 修订（V175）**：组织树已拍平——总经办从「决策层」降为「一级部门」，制造/营销/财税三中心从总经办下提到公司（UTEN）下。
> **2026-08-03 修订（ADR-020 / V206）**：管理中心仍是不可移动的结构基线，但已改为可承载直属员工、岗位和负责人的业务组织；中心负责人可在服务端对象范围内管理子孙部门。本文与此相冲突的表述均由 [ADR-020](ADR-020-入职工号岗位与管理中心用人语义.md) 取代。

## 背景

组织树（V02/V07）已上线五级模型（公司 → 决策层 → 管理中心 → 一级部门 → 二级班组 [→ 三级科室]），但岗位表（positions）一直无数据、无 API，导致「入职选岗位」「部门权限配置」等场景语义不清。所有者与产品对齐后定稿本模型。

## 决策

### 组织/岗位语义

| 层级 | 是否可选中 | 岗位 |
|---|---|---|
| 公司（优腾电器） | ❌ 不显示在选择器中 | 无 |
| 历史决策层 | ❌ 仅作结构节点 | 无 |
| 管理中心 | ✅ 可挂直属人员、负责人和岗位，结构位置锁定 | 中心领导/直属岗位 |
| 一级部门（生产部/PMC运营部/财税部…） | ✅ | **领导层岗位**（部长/副部长/主管…） |
| 二级班组（采购部/注塑车间/人力资源组…） | ✅ | **班组岗位**（组长/副组长/员工…） |
| 三级科室 | ✅（预留，HR 可自行加层） | HR 自定义 |

- 岗位挂在组织节点下（`positions.department_id`），`level` 文本表示职级（领导层/班组管理/员工，HR 可自由扩展）。
- 管理中心在员工归属、岗位和负责人场景可选；在车间/班组等专用选择器中仍受场景节点策略限制。
- 公司/决策层/管理中心的父级关系是组织基线，不允许在通用部门编辑中移动；“不可移动”不再等于“不可挂人”。
- 服务端仍拒绝结构基线换父；但允许管理中心设置本节点直属在册员工为负责人。业务部门移动仍在事务锁内递归更新整棵子树的 `level/path`。
- **V24 模板种子**：为全部现存部级/组级节点自动播种 3 个模板岗位（集合式 INSERT，幂等），供调试；HR 随后在部门管理页自由增删改——模板只是起点，不是约束。
- 入职：选部门（单选）→ 岗位下拉只显示该节点岗位，**「领导层」分区排最前**；提交 `positionId`（后端 DTO 已有该字段，契约兼容）。

### 统一部门选择器 `UtenDepartmentPicker`

全公司所有「选部门」场景一个组件：入职表单、员工编辑、权限管理·按部门。

- **抽屉交互**：compact → 85% 高底部抽屉；medium/expanded → 右侧滑入 420 面板
- 树内搜索（自动展开命中路径）、逐级展开/收起、层级小标签
- **单选/多选**双模式：多选带 Checkbox + 底部「已选 n 项/清空/确定」操作条
- 选中显示**完整路径**（一级部门起、`-` 连接，如 `PMC运营部-采购部`）
- 权限管理·按部门用多选模式：一次给多个部门批量配同一组角色（全量覆盖语义——多部门已有角色通常不一致，取并/交集有歧义，故编辑从空开始）

### 岗位管理入口

部门管理页 → 可选层级节点旁徽章按钮 → 岗位抽屉（按 sortOrder 列表，添加/编辑/删除，职级输入带建议 chips）。守卫 `department:edit`。

## 备选方案（未采纳）

| 方案 | 不选原因 |
|---|---|
| 所有结构节点都可挂人 | 公司/历史决策层仍只是结构根；仅管理中心按真实业务放开 |
| 岗位全自动模板、不给 HR 管理 | 各公司岗位叫法不同，必须可增删改（所有者明确要求） |
| 多部门配角色取已有角色并集预填 | 语义歧义（交集丢权限、并集超授权），从空开始全量覆盖最明确 |

## 影响

- 后端：V24 迁移（模板岗位种子）、`PositionService/Controller`（CRUD，`department:view/edit` 守卫）。
- 前端：`UtenDepartmentPicker` / `UtenPositionPicker` / `position_manager_sheet`；入职、员工编辑、权限管理·按部门三处接入；部门管理页加岗位管理。
- 已知待验：V24 在已有数据的库上执行；入职提交 `positionId` 落库。
