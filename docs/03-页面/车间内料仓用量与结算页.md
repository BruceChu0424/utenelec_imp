# 车间内料仓用量与结算页

> 2026-09-28 新增, 设计依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md) §5.8-§5.10、§7。

看车间内料仓 (原名线边仓) 每一期用了多少料、浪费多少、分到每个产品多少、每件材料成本多少; 同时看结算状态, 需要时立即重试或撤销结算。

## 入口

生产管理枢纽的报表中心、钱流管理枢纽的报表区, 各有一张「车间内料仓用量」卡 (同一个页面, 不挂数)。车间成员只看本车间的内料仓; 其他部门有查看权限的人可以看全部。

## 页面结构

顶部筛选: 选内料仓、选期间 (或全部期间) / 日期范围。下面是结算状态和五个分段。

### 结算状态

显示所选期间的状态: 还没盘点 / 正在盘点 / 已盘点正在结算 / 被拦住 (列出"差什么、谁来补", 例如"还有 3 张报工没审核; 负责: 报工审核人或制单人") / 结算没成功 (附原因, 系统会自动重试) / 已结算 (第几次结算、时间、经办人)。结算进行中每 2 秒自动刷新。

| 按钮 | 谁能点 | 做什么 |
|---|---|---|
| 立即重试 | 有盘点权限的人 | 被拦住的事补完了、不想等 10 分钟的定时重试时点 |
| 撤销结算 | 只有被逐人授予"撤销车间内料仓结算"权限的人 | 只能撤这个内料仓最近一期, 且下一期还没提交盘点; 必须写原因 (2 到 500 个字), 并再输一次登录密码。撤销只把这一期已分到各工单的材料成本退回, 数量不动; 期间回到"已盘点" |
| 重新结算 | 同立即重试 | 撤销后改完 (更正盘点、补审或红冲报工、改单个重量) 点它; 不点的话 24 小时后系统自动重新结算 |

### 分段一: 用量表 (每期 × 每种料)

期初、领入、退回、其它耗用、期末、盘点推算耗用、理论、差额、耗用差异率、盘点依据、处理方式、标红原因; 有"查看货品成本"权限的人另看单价、金额 (现值) 与结算时金额。

- 盘点推算耗用 = 期初 + 领入 − 退回 − 其它耗用 − 期末（期初是上一期盘点）。期初或期末含容器估盘时明确标记，不能当作称重实耗。
- 理论 = 报工量 × BOM 单个重量; 辅料 (色母) 没有理论, 显示的是分摊基数 (当期主料理论合计), 辅料只看每期总用量。
- 耗用差异率 = (盘点推算耗用 − 理论) ÷ 理论, 只算主料; 超出 -30% 到 +50% 标红。差异混有估盘、单重偏差、漏录与未单列损耗，不能直接解释为报废率或员工浪费。
- 处理方式: 按理论比例分到工单 / 有实际没理论, 记损失 (标红) / 盘盈 (产品本期分 0) / 本期没用 / 记车间费用。
- 其它标红: 试模清机等用料偏多 (超过本期期初 + 领入的 10%)、有实际用量但没有报工、盘盈没有参考价按 0 计。

### 分段二: 产品用料 (每期 × 产品 × 料)

完工、单个重量 (克)、理论、分摊实际、口径、实际 / 完工 (克)、材料金额、单件材料成本 (金额两列要成本权限)。

- 口径: 本期这种料只有这一个产品用时显示独占期平均耗用；其它行标"按理论比例分摊"。两者均继承期初和期末的盘点依据，独占不等于实测单耗。
- 单件材料成本 = 材料金额 ÷ 完工。

### 分段三: 耗用差异率趋势

按料、按期的折线, 横轴是每一期的起止日; 虚线之外 (低于 -30% 或高于 +50%) 标红。只画主料。

### 分段四: 缺单重清单

未结算期间里有产量、但 BOM 没填单个重量的产品: 期、产品、料、产量。每行"去填单重"跳到该产品的 BOM。缺单重会拦住整期结算, 补完后系统自动结算。

### 分段五: 收发明细

内料仓的每一笔进出: 业务日期、类型 (发料 / 退回仓库 / 试模清机等用料 / 盘点耗用及冲回 / 盘盈及冲回)、料、数量 (进为正、出为负)、来源单据、操作人、所属期; 上一期漏录补录的标"(补录)"。分页。

## 与财务附件 8 的关系

财务 → 成本核算 → "塑料耗用明细" (附件 8) 与本页同源: 列名列序保持会计模板原样, 数据换成车间内料仓已结算各期的结果, 按期末日落在所选月份的期间出表。列怎么对应沿用成本核算 §五口径（43-成本核算.md 已清理，现行说明以本页与财务报表页为准）。会计月报前请先让当月的内料仓盘点并结算 (这是操作顺序要求, 系统不拦)。

## 给开发看的对照

- 路由 `/reports/workshop-material`, 页面 [workshop_material_reports_page.dart](../../lib/features/production/pages/workshop_material_reports_page.dart), 模型 `workshop_material_report_models.dart`, 仓储 `workshop_material_report_repository.dart`; 生产与财务两个枢纽都在 `hub_catalog.dart` 登记同一路由。
- 路由守卫 `workshop_material:view`; 立即重试与重新结算 `workshop_material:count`; 撤销结算 `workshop_material:reopen` + 再认证 (逐人授予, 不授任何部门)。金额列按 `goods:cost:view`, 没有时接口返回空值, 页面整列隐藏。
- 接口: `GET /api/workshop-material/reports/bin-usage`、`/product-usage`、`/waste-trend`、`/missing-weights` (都直接返回数组)、`/ledger` (分页); `GET /api/workshop-material/periods?binId=`; `GET /api/workshop-material/periods/{id}/close-status`、`POST .../close-retry`、`POST .../reopen`。字段与形状见 ADR-131 §17.5。
- 测试: `test/features/production/workshop_material_reports_page_test.dart`; 服务端 `WorkshopMaterialClosePostgresTest`、`PlasticUsageAttachmentPostgresTest`、`WorkshopMaterialAllocationCalculatorTest`。

- 2026-09-30 新增 `openingCountBasis` / `closingCountBasis`，从本期与上一期当前已提交盘点按材料及颜色派生，撤回与草稿不冒充已生效事实。兼容保留 `actualQty` / `wasteRate` / `exclusivePeriod` 等原接口字段名与原账务算法；来源未知时明确显示未知，不默认称重。
- 产品用量同时下发 `materialUnitName` 与 `materialUnitKgFactor`，重量因子来自既有单位治理。理论／分摊耗用按材料基本单位显示，单重和独占期平均值按因子换算成克。缺换算档案时保留基本量，克列明确提示未设置换算，不能默认把所有材料当公斤。
