# V717 基础资料五主档导出权限

## 背景

2026-09-25 用户口径「基础资料里其他资料的导出打印都要对应优化」：货品/客户/供应商/
币种/账户五个主档已有加密导出（V71 口径：导出独立权限点，「能看」≠「能导出」），
模具/颜色/单位/结算方式/仓库五个主档此前**完全没有** Excel 导出，也没有打印入口。

本迁移只做权限侧登记（服务端导出端点与前端按钮在代码侧同批落地）：

1. 五个导出权限点：`mould:export` / `color:export` / `unit:export` /
   `settlement_method:export` / `warehouse:export`（module/category 跟随各自
   `:view` 在 V228/V453 的归类；action_type=EXPORT）。
2. 挂 `basic.*` 权限面：V328 的前缀规则只在 V328 一次性展开，之后新增码须显式
   挂面（V453/V636 同款 `WITH mapping(...) AS (VALUES ...)` 写法）。
3. 按 V71 同款「导出跟随查看」回填：持有对应 `:view` 的部门自动获得 `:export`，
   避免现有用户断权；超管恒有全部权限不受影响。

## 注意

- 权限在 JWT claim，上线后用户须重登，新 token 才带 `:export`（旧 token 导出 403）。
- 只插权限目录与授权，不加表、不改存量数据；幂等（ON CONFLICT），重跑安全。
- 导出端点列集与各自前端表格一致（「表格显示啥导出啥」）：模具六实列
  （模数/套数/模具类型/制造商四列是老库占位恒空，不带）、颜色三列、单位四列
  （计量维度出中文）、结算方式七列（含账期口径一句话摘要，与前端逐字对齐）、
  仓库七列（负责人来自 warehouse_keepers，「、」连接、「—」兜底）。

## 关联

- 服务端端点：`POST /api/master/{moulds,colors,units,warehouses}/export`、
  `POST /api/master/reference-methods/settlement-admin/export`。
- 前端：模具页走共享明细区 `MasterPaneExport` 配置（自动带打印预览按钮）；
  颜色/单位/结算方式/仓库四页在表格工具条挂 `UtenPrintPreviewButton` +
  `UtenExportButton`（打印预览用页面列渲染，天然与表格一致）。
