# Windows 运行库、内网连接与批量发布修复

## 原因与最终行为

公司安装后报缺少 `VCRUNTIME140.dll`、`VCRUNTIME140_1.dll`、`MSVCP140.dll`。
旧发布输入未附带开发电脑已有的 VC 运行库，原“完整包”检查也未验证 PE 依赖闭合。
紧急修复从批准的正式 2.5.32/2532 payload 出发，加入 10 个微软有效签名的 x64 CRT DLL；
仅排除完整证据证明未使用的 JNI 产物，保留原 EXE、AOT、连接配置和固定更新器。

随后用户在内网使用原生软件时，自动模式走外网并被权限拒绝，强制本地则连接失败；网页虽可使用，
仍显示证书“不安全”。正式客户端原先没有公司 CA 信任配置。新增应用范围的公开 CA 信任，员工无需
手动认证或导入系统证书，正常账号密码、权限及远程 MFA 保持原规则。

发布窗口沿用 `frontend-design` 和 Uten 主题组件，两个文件卡片保留选择和进度，
底部固定唯一批量发布按钮。窄高与大字号场景仍可操作底部动作，不复制上传服务或改变授权接口。

## 唯一公共入口及迁移清单

| 公共入口 | 接入范围和合同 |
|---|---|
| `windows/CMakeLists.txt` | MSVC Profile/Release 自动复制正式 CRT 目录；核心库、架构、Debug 及安装前摘要检查 |
| `deploy/client/package_windows.py` | 唯一有界 PE 读取与依赖门禁，Setup/ZIP 共用，完成后独立重读 ZIP；不依赖开发机 DLL |
| `deploy/client/build_windows_installer.py` | 一份完整 payload 生成双包；保留各输出校验、失败回滚与运行库/省略证据 |
| `lib/core/network/company_tls.dart` | 统一原生 CA 初始化与 Dio 工厂，按实际请求来源选择公司/公共传输 |
| `company_tls_io.dart`、`company_tls_stub.dart`、`company_tls_policy.dart` | 原生仅信任批准公司来源的公开 CA；Web 无额外 CA；错误保持明确类型 |
| `health_probe.dart`、`server_selection.dart`、`connection_recovery.dart` | 内网探针、健康检查和恢复共用传输；证书失败保持路由，前台显示结果 |
| `api_client.dart`、员工/访客拦截器及访客客户端 | 普通、审计和刷新工厂只换共享传输入口，身份、令牌及签发服务器合同不改 |

公开公司 CA 由现有严格 SSH 及主机身份围栏只读取回，没有读取私钥或修改公司服务。
PEM 字节 SHA-256 为 `e8479fe7113e0efd5d877cb5a35611454d8fd641728fedd8840e1501deb23763`，
DER 证书 SHA-256 为 `e7945de9bd75a272e04ef77f9a14538ab42c97a63a71b67fe66c12a123406994`。
来源限于批准的 `https://192.168.1.13:443` 与 `https://imp.utenelec:443`；不修改默认
SecurityContext、系统根证书库或 `badCertificateCallback`，不跟随公司请求重定向转交凭据。

  `D:/Projects/uten_imp/build/windows-runtime-hotfix-20261027/` 包含源码/证书来源及桌面交付摘要。
- 永久防漏：60/60 Python 回归、14/14 实际 CMake 检查通过，含两种配置自动复制完整 CRT 与负向拒绝。
  证据 `build/windows-runtime-prevention/verification.json`。
- 发布窗口：38/38 回归、定向静态分析通过，已检查固定底部按钮预览。
- 公司 TLS：90/90 定向网络/认证回归，含 15 项实际回环 TLS、资源及失败边界；17 项静态分析无问题。
  证据 `build/company-tls-native/verification.json`。
- 最终完整 Windows Release、安装包与 ZIP、内置 CA 字节及实际 PE 依赖检查以交付回执对应，
  生成或模拟测试不能代替公司员工电脑的最终登录验收。

## 保留差异与未完成边界

更新 ZIP 不覆盖固定更新器；首次安装包包含固定更新器。普通公网来源不增加公司 CA，Web 保留浏览器 TLS。
现有用户权限、数据库及公司服务器没有修改。源码版本保持当前平台版本，客户端补丁构建号由实际交付记录标识。

Windows Authenticode 发布签名凭据当前未配置，现有安装程序未签名。运行库来自微软、文件 SHA 校验通过，
均不能等同于本软件已获得发行者签名或 SmartScreen 信誉；该外部依赖须如实保留。
