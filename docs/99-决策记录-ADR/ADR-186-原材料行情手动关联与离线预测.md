- 关联：[ADR-179](ADR-179-货品价格分析与可追溯建议.md)。
- 当前接口：[自动行情合同](../../services/material_forecast/CONTRACT.md)。

## 货品只需关联一次

用户在所选货品的采购价格分析中，选择沪铜、沪铝或沪银主力基准并确认。数据库记住货品和行情品种的关系，后续价格及预测由后台自动更新，不需要重复上传 CSV，也不需要每次重新选择。取消只丢弃本地选择，解除关联必须明确确认。

内置品种目录独立于价格快照，即使采集服务尚未运行，也可以先保存关联。没有行情时展示已关联品种及真实同步状态，不伪造报价。页面按服务端指定的节奏自动 GET 新结果；更新行情不会修改关联版本，也不会重复提交 PUT。

原有“今日参考价格”仍按授权内部成交计算。外部期货基准提供独立行情参考，不能未经材料含量、单位、税费、加工费和现货基差校准，直接替代货品采购单价、主档记忆价或确认成本。

## 公开来源与价格口径

首选上期所官方公开日终统计与延时行情。技术验证已直接取得铜、铝、银数据，不使用 AKShare 采集接口，也不需要提供行情账户密钥。接口和数据时间由本地 worker 统一处理，前端不直连外站。

- [日周统计](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/)的日终 JSON 按日期提供各合约收盘、结算、成交量和持仓量。当前路径为 `https://www.shfe.com.cn/data/tradedata/future/dailydata/kxYYYYMMDD.dat`。
- [上期所英文首页](https://www.shfe.com.cn/eng/)标示延迟行情。固定延迟接口 `/data/tradedata/future/delaymarket/delaymarket_cu.dat` 及 al/ag 对应接口保留官方时间，界面明确至少延迟 30 分钟，不冒充付费实时流。
- [官方年度下载清单](https://www.shfe.com.cn/reports/tradedata/datadownload/download.json)提供历史压缩档案；首版以有界、渐进的逐日回填建立本地共享缓存，先有最新报价，再补齐模型历史。

公开接口可免费访问不等于数据开源或无条件商用再分发许可。[日周统计使用说明](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/)与[一般版权声明](https://www.shfe.cn/disclaimer/)分别适用。本功能面向公司内部参考，不提供行情转售或对外公共分发；运营方仍需按实际用途核对来源条款。没有把实时 Level-2 授权要求泛化为日终公开统计必须购买订阅，也没有承诺上期所授予了无条件商用许可证。

新浪日线技术上可免费读取，但其[自身服务协议](https://finance.sina.com.cn/roll/2021-05-12/doc-ikmxzfmm2033220.shtml)对商业读取及源页面外展示有明确限制，因此不作为默认来源。PC 按聚碳酸酯处理，目前未找到与上述金属接口相当的稳定免费官方源；本版不把 PP/PVC 期货冒充 PC，也不提供虚构的可关联品种。

## 主力选择和换月

铜、铝使用 CNY/吨，白银使用 CNY/千克。内置品种明确为期货基准，不标成现货或供应商可成交报价。

本系统按前一交易日已知持仓量选择本日主力合约，并列时选择最近交割月。缺失所选合约的有效价格时不以本日事后持仓量偷换选择。该透明规则是本系统对公开合约统计的衍生基准，不宣称交易所发布了同名主力指数。

训练序列采用同一合约前后交易日结算价比值前向连接，去除单纯换月价差造成的假涨跌。模型预测和区间再按最新实际主力结算价位折算。模型误差也折算到同一当前价位，证据中明确这一口径；不是原始历史每笔成交误差或实盘交易收益。未知缺口不能当作前一交易日跨越连接，网络失败也不能当作休市。

盘中延迟报价单独保存、单独计算时效，只用于行情参考，不混入已完成交易日的日终训练标签。官方市场时间和本地抓取时间分开保存，不擅自减去 30 分钟制造一个行情时间。

## 预测与历史证据

模型仍使用免费开源 [StatsForecast](https://github.com/Nixtla/statsforecast)，Apache-2.0，CPU 即可运行。统计候选和末值 Naive 基线采用相同有界窗口，先选型、后独立验收；1/5/20 各跨度均需胜过对应基线且区间覆盖达到门槛。

自动取得的旧日终档案不含当时的修订版本谱系。本地原始缓存保留真实抓取时间及后来修订，不把今天抓到的历史价格伪装成系统过去已经观察到的版本。利用这些档案做的回放明确标记 `LATEST_HISTORY_REPLAY`。

历史回放通过门槛时可以展示 `RESEARCH_ONLY` 研究预测、区间和价格倾向，但不能标成真实逐时验证，也不能产生主动采购指令。未胜基线、覆盖不足或数据不足时保留基线或不足状态。任何历史结果都不承诺未来准确率。

未来 1/5/20 按有效报价期计数，没有精确交易日历时不虚构未来自然日期。库存、需求、采购交期及供应商报价尚未联合优化，因此行情方向不能单独决定今天是否应下单。本模块不自动改价或下单。

## 自动采集和界面刷新

独立 Python 常驻进程统一采集三个全局品种，与货品关联数量无关，不向来源发送货品、员工、供应商、库存或内部成交信息。固定官方 HTTPS host/path 白名单、有限响应大小、超时、串行低频请求、退避和本地缓存共同限制采集行为；403/429 不绕过限制。

首次启动先更新最新有效日终和延迟行情，随后渐进回填历史。新数据到达后自动重新生成模型快照；没有新交易时也按有界周期重新核查生成状态，不把抓取时间当作价格发生时间。失败保留上次完整文件并写安全错误码，不打印原始业务载荷。

健康文件提供心跳、各品种最近尝试/成功和下次同步时间。没有新鲜心跳显示采集服务未连接；只有真实处理阶段才显示正在同步或回填。一次性命令不会假装常驻自动更新已经运行。同步失败可以继续显示尚有效的旧报价，但必须说明失败及原报价时间。

Spring 只读取固定配置目录的快照和健康文件，不在请求事务或原有调度线程里联网/训练。页面按 60 秒及报价/预测到期时间的较早期限刷新 GET；后台暂停，恢复后复核，选择和保存期间延后。到期即停止过期预测信号；价格和关联展示不因一次刷新失败而被静默改写。

## 权限、部署和升级

保持现有采购价格分析权限和货品可见范围。保存及解除关联还要求货品编辑权、真实写范围、锁后重检、CAS 和事务审计。V890 保留关联版本墓碑及身份摘要，不因行情更新改变关联版本，不增加分类查看权限，不修改已应用迁移。

界面继续按 `frontend-design`，复用 Uten 主题、按钮、确认栏、窄面板和字号响应规则；已关联品种、自动同步状态、延迟报价、日终结算和预测各自标明含义。

常驻 worker 的安装、监管和共享目录需要随应用部署一次配置，员工正常使用只需在界面选择品种。CSV 工具保留为诊断及旧版读取兼容，不属于本次内置品种关联流程。

依赖新版由 Dependabot 每周提出候选并运行真库离线回归，来源采集更新、模型重算与代码发布分别执行。生产继续走项目发布门禁，不在进程启动时盲目升级依赖。代码验证、公开接口连通、真实市场预测效果、公司库升级、常驻服务运行和上线分别报告。
