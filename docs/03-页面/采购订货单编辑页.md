# 采购订货单编辑页

> 路由：`/purchase/orders/new`(新建)、`/purchase/orders/:id/edit`(编辑)
> 别名：新建采购订货单、下采购单、采购下单、开采购单、改采购单

## 一、定位

采购员向供应商下单的页面：货品、数量、单价，以及每一行的供应商、结账方式、币种、税率和允许超收比例。采购订货单保存后要提交财务审核组，财务批准后仓库才会看到预计到货。

和销售订货单不同，采购的商业条款都在明细行上：一次可以给多个供应商下单，保存时系统按「供应商+条款组合」自动拆成几张订货单。采购不填汇率(2026-10-10 口径)：前端按汇率 1 提交，财务审批时再填真实汇率。

## 二、入口与导航

- 采购任务中心「申请待分解」：勾选计划下达的采购申请明细，点「生成采购订货单」，进入本页并带入这些明细(数量先按申请剩余量预填，可以改)。
- 采购管理首页「新建单据」里的「新建采购订货单」，手工新建。
- 本页明细表上方「从上游引入」，也可以把申请明细引进来。
- 订货单详情：草稿点「编辑」。
- 新建页右上角「草稿(N)」打开采购订货单列表的草稿分段。

## 三、响应式布局

- 手机：表头字段排成一列，明细表格可以左右滑动。
- 平板和电脑：表头字段排成多列；明细表格在下面，可以在「表头设置」里选显示哪些列、拖动排序。
- 保存按钮在右下角的悬浮操作区。

## 四、涉及的 Uten 组件

- 可编辑明细表格(带行级商业条款列，支持勾选多行「统一设置条款」)；
- 供应商选择、货品选择、员工选择(采购员)、日期选择；
- 「附件」区：放合同、供应商确认件和图片；
- 明细下方的合计条。

## 五、功能点

### 5.1 表头

| 字段 | 说明 |
|---|---|
| 单据号 | 保存后自动生成 |
| 单据日期 | 开单日期 |
| 采购员 | 经办人 |
| 交货日期 | 要求供应商交货的日期 |
| 单据备注 | 选填 |

币种、税率、结账方式不在表头，都在明细行上；汇率采购不填，前端按 1 提交，财务审批时填。

### 5.2 明细

| 列 | 说明 |
|---|---|
| 货品名称、编号、颜色 | 选货品后带出 |
| 申请来源 | 从申请带入的行显示来源申请，可以点开查看 |
| 供应商 | 每行必填 |
| 数量 | 「按本行单位填写本次数量，箱、个、千克不要混填」；单位跟在数量输入框后面显示，不再单列；可以超过申请剩余量(超量备货) |
| 允许超收% | 紧跟数量列。「供应商送货允许多于订货量的比例。例如填 5，订 100 件累计最多可收 105 件，在这以内照常入库、立应付；超过的部分才转财务审批。留空 = 不允许超收(按 0%)。」按货品记住上次填写的值并自动带出；财务批准后不能再改 |
| 单价、总金额 | 单价按本行单位和币种填写；数量、单价、总金额可以联动计算，直接填总金额时按已有数量算出单价 |
| 结账方式、币种、税率(%) | 每行必填；税率在 0 到 100 之间 |
| 备注 | 每行可填 |

- **自动带出**：选好货品后，系统按货品和供应商资料带出默认供应商、结账方式、币种、税率和允许超收比例；有完整记录时还会带出上次的采购价。带出的值显示黄框，请核对。资料里没有时，币种按人民币、汇率 1、税率 0 先填上，需要你核对。
- **统一设置条款**：勾选多行后，在选中行上右键(触屏长按)选「统一设置条款」，一次写好供应商、结账方式、币种、税率，留空的项保持各行原值。右键请点在行首复选框或货品名称这类不是输入框的位置。
- **只提交勾选的行**：新建时只有勾选的行会生成订货单。有未勾选的行时会提示：来源申请的未勾选行仍留在待分解，手工添加的未勾选行不会保存。

### 5.3 保存和提交财务

1. 点右下角按钮：有「采购订货提交财务」权限的人看到「保存并提交财务审核」，没有的人看到「保存订货单草稿」。
2. 保存前检查每一行：没选供应商、结账方式或币种，税率不在 0 到 100 之间，数量不是大于 0 的数字，采购单价无效，允许超收不在 0 到 100 之间，都会逐行列出要改的行。
3. 发现重复货品(同一供应商、同一条款组合下的同一货品、颜色、单位、换算率)时，弹出「发现重复货品」，可以选「汇总合并」「删除重复行」(各行完全一致时才有)或「返回修改」。
4. 保存成功：按「供应商+条款组合」拆成几张订货单。提交了财务的，提示「订货单已保存并提交财务审核组；下一步由财务在「订货审批任务中心」审核」；只保存草稿的，提示下一步由有权限的人员提交财务审核。
5. 编辑已有的订货单时，一张单只能有一套供应商和条款，改其中一行会同步到全部明细行。

### 5.4 财务审核之后

- 财务审核组里任何一位有资格的财务人员都可以认领审批；批准后仓库出现预计到货，货到时登记。
- 被财务退回的，按原因修改后重新提交。
- 财务批准后要改数量，有「采购订货单批准后改量」权限的人在订货单详情点「改量」，改后立即生效并重新送财务复核；复核驳回不会自动把数量改回去。
- 到货超过「订货量+允许超收量」时，整张收货单先不入库，转财务审批，见[仓库到货登记页](仓库到货登记页.md)。

## 六、功能链路图

1. 物料分析「下达采购」 → 采购申请。
2. 采购任务中心勾选申请明细 → 「生成采购订货单」 → 本页核对供应商、条款、数量和单价。
3. 「保存并提交财务审核」 → 按供应商和条款拆单 → 财务审核组审批。
4. 财务批准 → 仓库预计到货 → 到货登记 → 品质检验 → 入库、立应付。

## 七、涉及的数据实体

采购订货单：单头(单据号、单据日期、采购员、交货日期、备注)；明细(货品、颜色、数量(含单位)、单价、总金额、供应商、允许超收%、结账方式、币种、税率、备注、来源申请)；附件。汇率采购不填，按 1 提交，财务审批时填。

## 八、权限要求

- 新建需要「新增采购订货单」，编辑草稿需要「编辑采购订货单草稿」，从申请生成订货需要「将采购申请分解为采购订货」，提交财务需要「采购订货提交财务」，批准后改数量需要「采购订货单批准后改量」。
- 财务审批由财务审核组办理，见[ADR-027 财务审批改为权限授权的审核组](../99-决策记录-ADR/ADR-027-财务审批改为权限授权的审核组.md)。

## 九、边界情况

- 同事正在分解同一张采购申请时，保存被禁用，并提示是谁正在分解，请稍后再试。
- 所选申请明细已经全部分解时，提示「所选申请明细已全部分解，请返回任务中心刷新」。
- 新建时没有勾选任何行：提示「请先勾选要生成订货的明细行」。
- 订货单已建成但后续处理没完成时，提示「订货单已创建，后续处理未完成。点击保存继续处理，不会重复创建。」
- 保存了但没能提交财务时，提示原因，请到订货详情重新提交。

## 十、常见问题

### 为什么一次保存变成了好几张订货单

保存时按「供应商+条款组合」自动拆单：不同供应商，或同一供应商但结账方式、币种、税率不同的行，会进不同的订货单。(采购前端汇率恒 1，不参与区分；编辑既有单沿用单上记录的汇率。)

### 数量能比申请的多吗

能。可以超过申请剩余量做超量备货，多出来的部分不属于原申请。

### 允许超收填多少合适

按和供应商的约定填，例如填 5 表示订 100 件累计最多收 105 件。留空等于 0，严格按订货量收。

### 批准后还能改数量吗

能，用订货单详情的「改量」，改后重新送财务复核；新数量加上允许超收量，不能低于已经收到的数量。
