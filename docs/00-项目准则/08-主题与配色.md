# 主题与配色规范

> 本文描述当前 Flutter 主题实现，不是设计草案。主题源码集中在 `lib/core/theme/`；最后核对：2026-07-30。

---

## 一、单一事实来源

| 职责 | 源码 |
|---|---|
| 品牌色、中性色、语义色 | [`uten_colors.dart`](../../lib/core/theme/uten_colors.dart) |
| 圆角、间距、阴影 | [`uten_tokens.dart`](../../lib/core/theme/uten_tokens.dart) |

| Material 3 深色主题 | [`dark_theme.dart`](../../lib/core/theme/dark_theme.dart) |

## 二、当前色板

### 2.1 品牌主色

| Token | 色值 | 用途 |
|---|---|---|
| `UtenColors.teal500` / `primary` | `#14B8A6` | 浅色主题主要交互、按钮、选中态 |
| `UtenColors.teal400` | `#2DD4BF` | 深色主题 primary、焦点与高亮 |
| `UtenColors.teal50`～`teal950` | 青绿色阶 | 容器、边框、悬停、按下和反相前景 |

浅色主题 `ColorScheme.primary` 是 `teal500`，深色主题是 `teal400`。旧文档中的 `kUtenGreen` 不存在，不能再使用。

### 2.2 浅色中性色

| Token | 色值 | 用途 |
|---|---|---|
| `background` | `#F5F7FA` | 页面背景 |
| `surface` | `#FFFFFF` | 卡片与对话框 |
| `surfaceLow` / `surfaceMid` / `surfaceHigh` | `#F8FAFC` / `#EEF1F5` / `#E3E8EF` | 容器层级 |
| `textPrimary` | `#0F172A` | 主文字 |
| `textSecondary` | `#475569` | 次要文字 |
| `textTertiary` | `#94A3B8` | 辅助文字 |
| `border` / `borderStrong` | `#E2E8F0` / `#CBD5E1` | 分隔与边框 |

### 2.3 深色中性色

| Token | 色值 | 用途 |
|---|---|---|
| `darkBackground` | `#0B1120` | 页面背景 |
| `darkSurface` / `darkSurfaceLow` / `darkSurfaceHigh` | `#101A2C` / `#1E293B` / `#334155` | 容器层级 |
| `darkTextPrimary` | `#F1F5F9` | 主文字 |
| `darkTextSecondary` | `#94A3B8` | 次要文字 |
| `darkTextTertiary` | `#64748B` | 辅助文字 |
| `darkBorder` / `darkBorderStrong` | `#1F2A3D` / `#334155` | 分隔与边框 |

### 2.4 语义色

| 语义 | 主色 | 浅底/深色前景 |
|---|---|---|
| success | `#10B981` | `successBg` / `successOnDark` |
| warning | `#F59E0B` | `warningBg` / `warningOnDark` |
| error | `#EF4444` | `errorBg` / `errorOnDark` |
| info | `#3B82F6` | `infoBg` / `infoOnDark` |

业务状态必须映射到语义，而不是按页面随意选色。例如“已完成”用 success，“待处理”通常用 warning，“失败/拒绝”用 error，“说明性状态”用 info。

## 三、使用规则

### 3.1 业务页面

优先读主题：

```dart
final theme = Theme.of(context);
final colors = theme.colorScheme;

Text('标题', style: theme.textTheme.titleMedium);
Icon(Icons.check, color: colors.primary);
```

只有主题未暴露、且确属全局语义 token 时才直接引用 `UtenColors`：

```dart
const UtenStatusBadge(
  label: '已完成',
  type: UtenStatusBadgeType.success,
);
```

禁止：

```dart
// 禁止在业务代码新增裸色值，也禁止只适配浅色模式。
Container(color: const Color(0xFF14B8A6));
Text('说明', style: const TextStyle(color: Colors.grey));
```

`Colors.transparent`、`Colors.white`/`black` 只在透明或明确反相前景等框架语义中使用；业务状态仍必须走主题或 `UtenColors`。

### 3.2 间距、圆角与阴影

- 间距使用 `UtenSpacing.s4`～`s48`。
- 圆角使用 `UtenRadius`；主题控件已有默认 shape 时不要重复覆盖。
- 阴影使用 `UtenElevation.low/mid/high(isDark: ...)`，不得在页面复制 `BoxShadow` 数组。
- 玻璃、模糊和高成本阴影还须服从性能档，详见[性能自适应](07-性能自适应.md)。

### 3.3 字体与缩放

- 全局字体为 `NotoSansSC`。
- 页面使用 `Theme.of(context).textTheme` 的 Material type role，不硬编码常规字号。
- 用户字号通过 `fontScaleProvider` 统一作用于 `MediaQuery.textScaler`；组件不得再次手动乘倍率。
- 图标不要跟随字体无限放大，必要时在组件内部设置合理边界。

## 四、主题模式

应用向 `MaterialApp.router` 同时提供 `buildLightTheme()`、`buildDarkTheme()` 和 `themeMode`。`ThemeNotifier` 支持：

- `ThemeMode.light`
- `ThemeMode.dark`
- `ThemeMode.system`

选择值保存到本地 `SharedPreferences` 的 `themeMode`。这只是界面偏好，不包含密钥或业务数据；不要把敏感信息放进同一偏好机制。

---

## 五、组件主题覆盖范围

浅色和深色主题均集中配置：

- typography、AppBar、Card、Divider；
- Filled/Elevated/Outlined/Text/Icon Button；
- InputDecoration；
- NavigationBar/NavigationRail；
- Chip、Dialog、SnackBar、ListTile；
- ProgressIndicator、FloatingActionButton；
- Switch、Checkbox、Radio、TabBar。

因此页面应先使用 Material 主题默认值或 Uten 公共组件。只有明确的新全局设计规则才允许修改 `light_theme.dart` 和 `dark_theme.dart`，并且两份主题必须同步评估。

## 六、变更检查

主题或公共组件变更至少完成：

1. 浅色、深色各检查窄屏和桌面宽屏。
2. 检查默认、hover、focus、pressed、disabled、loading、error 状态。
3. 检查文字对比度、键盘焦点和语义标签。
4. 运行 `flutter analyze` 和相关 widget 测试。
5. 搜索业务层新增裸色：

```powershell
rg -n "Color\\(0x|Colors\\." lib/features lib/shared
```

命中不等于必然违规，但每一处都要说明为什么不能使用主题或语义 token。
