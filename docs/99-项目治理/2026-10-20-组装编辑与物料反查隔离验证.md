## 已实现

| 范围 | 结果 |
| --- | --- |
| 组装信息模式 | 默认只读；右下已选数量、编辑模式、审计模式；编辑时按细分权限显示添加、删除，右键或双击编辑；刷新位于详情右上价格分析左侧 |
| 组件复制粘贴 | 右键自动选行并保留已有多选；按选中分支复制，祖先与子孙不重复平铺；可跨产品粘贴至顶层或选中组件的子层 |
| 保存与同步 | 每动作暂存当前页面内存草稿；预览实际修改父件、共享影响及单重提醒，二次确认后原子提交；取消保留草稿；不改写冻结需求或历史耗用 |
| 权限与身份 | 进入编辑需要编辑权，新增/删除继续复核独立权限；撤权或切换身份清理旧草稿、剪贴板与敏感弹窗；保留回调不能继续提交 |
| 并发与回执 | 原始内容指纹、图锁及锁后重读；服务端 HMAC 保护指纹；成功提交回执丢失时复用原预览凭证，禁止重复写入 |
| 货品编辑历史 | 正式提交写入历史，预览不留正式记录；按真实命令权限复核撤回与重做，跨层移动不被误判为额外新增/删除权限 |
| 物料反查 | 产品名称、编号、颜色分列；三列保持可见，其余个人布局保留；当前有效 BOM 关系多选后可预览共享影响并二次确认替换 |
| 导出 | 全部筛选结果导出 Excel/PDF，可选密码保护；记录组件、条件、操作员姓名(工号)、时间、数量单位和来源；独立导出权限、限流、并发闸门及审计 |
| 视觉与语言 | 沿用 Uten 组件和主题，新增界面文案补齐中/英/韩；窄屏、横屏、大字体、深浅色及全屏均有回归和中文截图 |

草稿保存在当前页面会话内，不承诺应用关闭或浏览器刷新后的恢复。导入与重新学习沿用独立检测/确认流程，执行前先处理当前草稿。
