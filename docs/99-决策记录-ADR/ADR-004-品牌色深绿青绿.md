# ADR-004 - 品牌色：深绿 + 青绿

- **状态**：已接受，2026-07-30 实现校准
- **日期**：2026-07-21

---

## 上下文

平台需要一套贯穿始终的品牌色。用户选择"深绿 + 青绿"。

## 决策

保留“深绿/青绿”的品牌方向；当前交互色实现统一为 teal 色阶。浅色主题 primary 为
`teal500 #14B8A6`，深色主题 primary 为 `teal400 #2DD4BF`。原草案 `#0F3D2E`
不再是现行 `ColorScheme.primary`，源码也没有 `kUtenGreen`。

## 色值

| Token | Hex | 含义 |
|---|---|---|
| `teal500`（浅色 primary） | `#14B8A6` | 主要交互 |
| `teal400`（深色 primary） | `#2DD4BF` | 深色高对比交互 |
| 语义色 success | `#10B981` | 成功 |
| 语义色 warning | `#F59E0B` | 警告 |
| 语义色 error | `#EF4444` | 错误 |
| 语义色 info | `#3B82F6` | 信息 |

详细色阶（50–900）见 [../00-项目准则/08-主题与配色.md](../00-项目准则/08-主题与配色.md)。

## 理由

### 为什么深绿 + 青绿？

| 维度 | 说明 |
|---|---|
| 品牌呼应 | "优腾"：优 = 品质（深绿，稳重可靠）、腾 = 腾飞（青绿，科技向上） |
| 行业契合 | 制造业：绿色 = 环保/品质/可持续；青绿 = 现代化转型 |
| 视觉舒适 | 深绿不刺眼、长时间看不疲劳（适合后台高频使用） |
| 区分度 | 区别于常见的企业蓝（钉钉/企微/飞书都是蓝），有辨识度 |
| 双模式适配 | 浅色模式：白底深绿稳重；深色模式：墨绿黑底青绿高亮，科技感强 |

### 为什么不用蓝/紫/红？

- **蓝**：太常见（钉钉/企微/飞书/腾讯/阿里），缺乏辨识度
- **紫**：互联网感强，制造业用违和
- **红**：过于刺激，长时间看不舒适，且红色在中国有特定语义（停止/警告）

### 为什么 token 化？

- 将来换主色 = 改一个常量，全项目跟着变
- 深浅模式共享 token，不用重复定义
- 设计师/开发对齐有统一语言

## 后果

### 正面
- 品牌识别度高，区别于市面同类后台
- 视觉舒适，适合长时间办公
- 深浅模式都能用同一套品牌色

### 负面
- 深绿在某些低端 LCD 屏幕上可能偏色（需测试）
- 部分员工可能习惯蓝色后台，需要适应期

## 缓解措施

- 全部 token 化，发现色值问题可快速调整
- 在多台设备（含低端屏）上验证色彩还原
- 提供主题预览页，用户切换前后对比明显

## 可逆性

**高**。颜色集中在 `uten_colors.dart`，但改品牌色仍须同步检查 `light_theme.dart`、
`dark_theme.dart`、语义对比度、组件状态和视觉回归，不能只改一个常量就直接发布。
