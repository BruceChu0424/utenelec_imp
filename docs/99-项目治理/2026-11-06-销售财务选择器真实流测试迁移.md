## 根因与迁移

旧测试模拟 GET 或普通 JSON POST 页，而当前主档读取走生产 `ApiClient.postSummaryStream`，要求一个响应内的有界 page、complete 与 EOF。四个 API doubles 现在继承唯一 `MasterSummaryStreamTestApi`，只提供原授权行集，保留真实 ApiClient、Dio、ResponseBody、MIME、字节解析与完整结果验证。公共入口已由 `90519a896` 与格式提交 `ec3620959` 独立交付。

- `sales_doc_edit_intake_test.dart`：继续读取唯一 `contracts/business-master-references/v1.json`，七组主档/价格/折扣独立授权、初选/重选、39.13 与 0.2 原值及精确 78.26 结果不变。Native 真实读文件；Web 由受控命令注入原字节 Base64，缺/非法立即失败，没有 JSON 副本或生产 assets。读取计数对应实际摘要流，不把摘要读取当作单据写入。
- `sales_doc_edit_v187_test.dart`：原可选客户、选中后重新核验及新隐藏客户拒绝保持不变。原订单策略、币种、精确总额、只读、原单据与未知写入断言全部保留。Native 继续保存原 PNG；Web 仍实际 toImage 并验证 PNG 字节，仅本机 File 落盘按平台分支。
- `finance_batch_entry_test.dart`：原供应商候选字面数据不变，摘要流读取在业务命令记录外，选中后变隐藏仍不得落入新行。原金额原文、币种、来源、整批原子性、501 上限、取消/硬关闭恢复、未知提交同正文重放与 1000 次快速编辑不变。
- `finance_party_selectors_test.dart`：报表及历史月结允许历史禁用往来方，保持原 UUID/名称、不可清空的必选、当前读取身份与 A-B-A 退休；新业务的可选规则不被放宽。每例明确初始化 SharedPreferences 测试存储，真实 I/O 推进暴露的 MissingPluginException 不再留作未完成异步任务。

实际浏览器 I/O 与 fake widget clock 必须共同推进。只在真实摘要读取阶段使用已有 `pumpAndSettleWithIo`：货品面板打开及分类触发读取后、客户/供应商面板读取后。保持原 100ms 帧步与 10min fake deadline，不改默认入口，不吞错误、不加预算；其他断言及流程等待保留原意。

完整 Chrome 还识别出旧倍率夹具的跨平台错误：兼容数字 10 被 Native double.toString 变成10.0，Web得到10。真实 OrderItemDto#getUnitRateExact 经 DecimalText.of 明确去尾随零为字符串10；本例现在补真实 unitRateExact:'10'，仍严格逐字校验原倍率10、税率/币种/重量/折扣与禁止提交二进制金额。没有将兼容浮点字串当作精确业务权威，也没有修改生产序列化或增加宽松数值比较。
