# 生产超产与追加处理说明

适用人员：计划员、车间负责人及有相应权限的报工人员、品质人员、仓库人员。

自制任务按同一规则办理，不按注塑、五金、装配车间分别设置例外。采购和直接外发委外不使用这里的生产超产比例；委外前需要我方自制的部分，按自制任务办理。

## 先分清四个数量

| 名称 | 按什么填写或判断 |
| --- | --- |
| 计划数量 | 本任务批准生产的数量 |
| 允许超产比例 | 原任务在计划外可以承接的比例，默认 10%，可以设为 0% |
| 本次实际产量、实际用料 | 按本次真实产出和真实耗用填写；报工可分多次 |
| 合格实收量 | 品质放行后，仓库实际收下的数量；它才形成相应可用库存 |

**允许超产比例不会自动增加计划数量，也不会自动多发物料。** 同货品不同任务分别核对，不能借用其他任务或其他订单的未完成额度。

## 计划员：下达前填写初始比例

1. 在生产计划草稿的产品“排产量”后填写“允许超产比例”。新建计划进入物料分析准备时，所填比例随对应产品带入。
2. 也可以直接在“物料分析准备”主表的“下单数量”后填写。进入下达桶的“父件 + 下层一起下单”详情后，父件和各自制子件都能分别填写。
   下单后进入“补下层物料”时，自制行也使用同一比例输入；采购和直接委外行不套用生产比例。尚未认领的公共在途会显示待认领，不会仅因为别的计划存在公共供给就把本任务催办结束。
3. 逐行核对数量、比例、车间、负责人，再下达。父件填 15%、子件填 25%，各自按自己的比例执行，不会把父件比例套给全部子件。
4. 更改父件数量、等待下层重新计算、切换同一分析内的下达页面时，已填比例会保留。空值、负数或超过四位小数的百分比需先改正；0%表示不允许原任务承接计划外产量。
5. 下达后，到生产计划详情或“我的车间任务”核对当前生效比例。准备页的输入是**本次下达的内容**；修改它不会追改已经下达的旧工单。

采购和直接外发委外行显示“—”。表格较宽时可横向滚动到比例列；手机、窄屏或放大字号后，也要逐行核对，不能只看父件一行。

新任务默认已确定“持续生产”路线，可以更改。路线默认确定后，仍需核对真实到料、领料或交接，并由车间人员明确开工。

## 车间与计划部：调整已下达任务的比例

1. 有权限的车间人员在“我的车间任务”找到对应任务，申请调整比例并填写原因。
2. 申请期间仍执行原比例。例如原比例 10%、申请 15%，页面显示当前有效值和待审批申请；提交申请本身不代表已经改成 15%。
3. 计划部收到通知后进入比例审批待办，核对产品、计划量、申请原因和差异内容。与销售改单送审相同，**原内容为红色划线行，新申请为绿色行**，同时有原内容、申请内容的文字标识。
4. 审批通过后，新比例才生效；退回后继续执行原比例。退回原因及前次申请记录保留，修改后可重新申请。

已有待审申请时先查看原申请。遇到“状态已变化”等提示，应重新核对当前任务和处理结果，再决定是否重试。

## 车间：如实报工，越限办理追加计划

以下例子均以原计划 100 件、当前比例 10%为例，且没有其他待提交报工占用。

| 实际情况 | 应如何办理 |
| --- | --- |
| 实际生产 100 件 | 原任务报工 100 件 |
| 实际生产 108 件 | 原任务报工 108 件；其中需求部分 100 件，超产 8 件合格实收后归公共库存 |
| 实际生产 130 件 | 弹窗办理追加生产计划：原任务承接 100 件，追加计划承接 **30 件**；不是原任务 110、追加 20 |
| 已合法报收 105 件，后来又生产 25 件 | 保留已登记的 105 件；本次尚未登记的 25 件办理追加，不能再追加 30 件重复计算前面的 5 件 |
| 初始比例为 0%，实际生产 101 件 | 原任务承接 100 件，追加计划承接 1 件 |

办理追加时：

1. 在报工表填写本次真实产量和实际用料，超过有效范围后按提示进入追加计划。
2. 核对自动带入的产品、颜色、单位、车间、负责人，以及“本次实际产量、归原工单、独立追加计划”三个数量。原表输入保留，不能为了通过校验把实际产量改小。
3. 计划部审批追加计划。审批通过只代表本次追加获得批准，还没有完成报工、品质和入库。
4. 车间核对同一批实物及真实物料来源，按页面提示“确认原批次并续报”，回到原报工内容继续核对提交。
5. 主管审核报工，后续由品质检验、仓库按实物点收。需要补料的，先按下一节办理。

**追加 30 件是已核准的固定批次。** 它关联原批次续报，不能再独立报一次 30 件，也不能通过调比例把这批变成 33 件。报工草稿重新打开后，原批次总量与追加关联仍保留；可以核对备注和实际耗用，不能拆成两份重复申报。

## 分次报工、下工序转移与真实用料

### 分次与在制品

同一开放任务可以分次报工，每次只登记本次新增产量。草稿也会占用可申报份额；发现重复草稿先核对处理，不能改用“公共超产”绕过。

例如原计划 1000 件：第一批报 500 件时，已经登记了本批全部真实投入；后续 500 件是在同一任务内继续完成，且没有新增耗料，本次新增耗料可以为 0。必须能够追溯同一任务前批已登记的真实投入。不能拿任意旧领料记录配合零耗用，补出一批新的超产库存。

### 转给下工序

只按下工序有来源关系、尚未覆盖的真实需求交接。超产部分进入仓库，品质合格并实收后作为公共库存，不自动扩大下工序的计划。

例如计划 100 件、实产 108 件，下工序当前只需接收 80 件：满足交接条件时转 80 件；剩余原需求 20 件与公共超产 8 件分别保留归属，进入仓库流程。跨车间按正常仓库交接办理，不能因为允许超产就跳过交接。

### 实际用料超过原额度

| 情况 | 处理方式 |
| --- | --- |
| 实产 130，真实耗料仍是原已领的 100 | 核对原批次来源，按真实耗料 100 登记，不因追加 30 件产出再重复耗料 30 |
| 实产 130，真实需要耗料 130，原只领了 100 | 对原材料申请新增 30，计划部批准后安排备料、仓库实际发出，再登记真实耗用 |
| 实产 108，仍在产量允许范围内，但真实需要耗料 130 | 同样申请材料增量；产量未越限不等于可以超额领料 |

申请“追加用料”时选原任务的对应材料，填写本次新增量和原因。计划部核对原定额、已批准追加、本次新增及申请前后差异后审批。**已批准 30 不等于已经领到 30。** 仓库仍需实发，车间不能把手填实耗 130 改成 100 来通过校验。

该入口用于原材料的新增用量；换料、换颜色或增加另一种材料需按相应变更流程核对，不能在原材料名下混报。

## 品质与仓库：检验、清点、实收分别确认

1. 车间填写实际完工申报量，疑似不良也应如实说明，由品质登记通过、返工、报废等实际处理结果。
2. 仓库接货时核对产品、颜色、单位、来源批次、仓库和库位。
3. 使用“清点上架后送检”时，逐行手工填写实物清点数量。输入框不会自动填成申报量；只有与本批申报量核对一致，才可在品质合格后自动点收入库。
4. 实点数与申报数不同，返回使用“登记并送检”，品质放行后人工按实际数量点收。多出的实物先核对报工来源；少收到的不能按申报数补齐。
5. 品质未放行、尚未收到或已明确退回的数量，不能当作合格实收量。公共超产也要经过同样的检验和点收。

例如公共产出 30 件，品质放行 25 件，本次仓库实收 20 件：当前公共库存只增加 20 件；其余 5 件合格待收，另外 5 件按品质的实际结论处理。公共实收不代替原订单尚未收到的数量。

## 退回、取消与异常核对

| 遇到的情况 | 操作及应看到的结果 |
| --- | --- |
| 比例或追加用料申请被退回 | 查看原因后修改重提；原有效比例、原有材料授权不变 |
| 计划部取消追加生产计划 | 填写取消原因；原报工表中的实际数量不被自动改小，需回原表核对后续处理 |
| 已批准材料增量不再需要 | 由有权限人员按页面可用操作办理撤销用料授权并填写原因；已有发料、占用或耗用时，先处理相应实际业务 |
| 取消或退回提交失败 | 原因输入保留，先确认当前处理结果再重试；页面未成功返回不代表操作已完成 |
| 报工、库存或下游已经使用这批货 | 按实际业务的反向流程逐步处理；不能直接删除历史或再做一张反向数量单来抵消 |
| 工单停止、取消、未开工，或没有可核对的物料来源 | 先解决任务状态或来源问题，不能用超产比例绕过 |
| 已结束的旧批次发现漏报 | **当前没有专门的自动更正入口。** 保留原报工、领用、耗用和仓库清点记录，交计划、车间及仓库共同核对；不要伪造新领料或另报一批来补数 |

已通过库存盘点记入库存的差额，不能再作为生产报工入库一次。同一批漏报必须先查清是否已经通过其他单据入账，避免“盘点增加一次、生产入库又增加一次”。

## 员工验收核对表

在测试环境按自己的权限核对以下场景，记录单号、实物数量和页面结果。

| 核对场景 | 应看到的结果 |
| --- | --- |
| 准备主表和下达详情填不同父子比例，随后修改父件数量 | 数量按最新结果更新；各行比例保留，最终计划及任务带入各自比例 |
| 填 0%、清空、填负数或多于四位小数 | 0%可下达；无效输入标出并阻止提交，原输入保留 |
| 已下达任务申请 10%改15%，分别测试待审、退回、通过 | 待审与退回仍为10%；通过后为15%；审批页能辨认红色划线旧行与绿色新行 |
| 计划100、比例10%、实产130 | 原100、追加30；审批后关联原批次续报，不重复申报或耗料 |
| 同一任务分批报工，后批使用前批已登记的在制投入 | 核对真实投入与剩余产量，后批新增耗料为0时不重复耗料 |
| 申请新增材料30，依次停在待审、已批准未实发、已实发 | 三个状态可区分；未实发时不能当作已领或已耗 |
| 实点少于申报、分批点收、品质部分放行 | 库存只随合格实收增加，未收及未放行数量仍可追踪 |
| 取消或退回时网络失败后重试 | 原因仍在；重新读取实际状态后处理，不多建申请或重复入账 |

手机、窄屏及放大字号时，至少核对比例输入、差异行、原因弹窗和审批按钮是否可滚动查看、完整输入和操作；不要仅以桌面宽屏显示正常代替这些检查。
