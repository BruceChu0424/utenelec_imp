# 车间内料仓上线与使用说明 (整批领料 + 盘点计耗)

> 2026-10-04 开通与整批领料分开([ADR-147](../99-决策记录-ADR/ADR-147-车间内料仓开通单一真源与发料来源仓.md), [V802](../数据迁移/V802-车间内料仓开通单一真源.md))：内料仓先「开通」(只收车间直送)，要整批领料再「开启整批领料」，两步都在「车间内料仓」的车间总览里办，可勾选多个车间一起办。车间直送不再第一次直送时自动建仓：收料车间没开通时，报工里转下一道工序的这部分送入仓库，并提示「{车间}还没开通内料仓，请仓库在「车间内料仓」开通后再直送」。上线时注塑车间(已开整批领料)回填为「整批领料中」，用过直送的车间(如装配第一车间)回填为「已开通」。下文第 3 步已按新入口改写。

> 2026-09-30 最新上线口径：车间已有余料直接用盘点模式录实物目标，由仓库审核后建立期初，不要求实物退回再领出。下文旧「先其它入库再调拨」的准备步骤由[盘点送审流程](../03-页面/库存盘点审核页.md)替代；历史已有领用事实仍不得重复记入。

> 2026-09-28。给仓库、车间、BOM 维护人、计划和财务看的操作说明。设计依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md); 各页面细节见文末链接。

## 一、这是什么

颗粒这类料 (以后也可以是别的散装料) 不再一张工单一张工单地领:

- 仓库把整袋料直接发到"{车间名}内料仓" (就是原来的线边仓, 改了名字, 车间直送照常用)。这一步只是把料挪到车间, 还不算用掉。
- 车间照常报工, 不按工单领料, 也不用填用了多少料。
- 第一次也不按工单领颗粒，最多在开工确认表里认一次材料。使用内料仓的进行中任务详情始终提供「新建补料申请」（需要申请权限），足料也可提前申请；缺料提示不变成仓库先发料才能开工的门槛。
- 什么时候需要就盘点一次。盘点时系统算出这一期实际用了多少: **期初 + 领入 − 退回 − 其它耗用 − 期末实盘**。
- 系统随即自动结算: 按"报工量 × BOM 单个重量"的比例, 把实际用量和金额分进各工单的成本。
- 只有三种会让数据算错的情况才拦结算, 系统会通知该补的人, 补完自动结算。

## 二、上线顺序 (一次性, 按顺序做)

### 第 0 步: 先退料清账 (仓库 + 车间)

上线时先清点车间已有的整袋、散料、搅拌待用料与机桶余料，再按原账归属衔接。下述退料／调入是保留历史来源的账务流程，不要求员工为每张工单重新申领，也不得把同一份余料重复新增库存。

- 正在做的注塑单, 已经按工单领出来、还没用掉的颗粒, 走原来的**生产退料**退回仓库并清账。否则这些工单上"按工单领过、没清账"的颗粒会挡住下一步, 系统会逐张列出是哪张工单、差多少没清。
- 车间手上从来没入过账的余料, 用**其它入库**按核定价放进普通仓库 (不要用期初导入, 期初导入不会增加仓库的实物数量)。

### 第 1 步: 标记颗粒为整批领料 (基础资料)

也可以先由车间直接选料、填数量提交申请，仓库第一次按申请发料时在同一页确认材料用途并办理；员工无需先到基础资料操作。本节保留给上线前集中准备资料的人员，实际申请流程不以此为前置。

在货品资料里打开这种料, 把"发料方式"改为"整批领到车间内料仓", 再选"分摊方式":

| 料 | 分摊方式 | 说明 |
|---|---|---|
| 颗粒 (主料) | 主料 | 在产品 BOM 里填单个重量, 按报工量分到各工单 |
| 色母 (辅料) | 辅料 | 不写进 BOM, 按当期主料用量分到各产品 |
| 只想记费用的料 | 记车间费用 | 用量记车间费用, 不分给产品 |

同时填"每袋净重 (公斤)" (默认取货品已有的整包装量), 水口料、破碎料勾"回收料"。

切换前系统会先列出影响, 确认后一次办完:

- 用到这种料的 BOM 行会自动改成"只填单个重量"的形状; 按包装或按批计量的行标红, 要先在 BOM 里改成按每件。
- 选"辅料"或"记车间费用"时, 用到这种料的 BOM 行会从 BOM 里去掉 (辅料不写进 BOM)。
- 以后要改回"按工单领料": 内料仓里这种料要先清空、没结算的期间里没用到它, 改回后相关 BOM 行自动恢复为开工前必须领齐。
- 还有按工单领过、没清账的工单时不能切换 (回到第 0 步)。

### 第 2 步: 填单个重量 (BOM 维护人)

两种填法, 选一种:

- **逐个填**: 在产品的 BOM 里加颗粒这一行, 数量列显示为"单个重量 (克)", 按克填。
- **批量填**: 仓库 → 车间内料仓设置 → 上线准备。列出近 12 个月这个车间做过的产品, 老库材质能对上的颗粒已预填; 可一键"勾选行用货品资料单重填入", 再逐个核对标黄的行。保存需要 BOM 新增和编辑权限。

单个重量填**件重, 不含水口**。小于 0.1 克或大于 5000 克会要你再确认一次; 与货品资料单重差 20% 以上标黄。一个产品同时用两种料 (双色、双料) 时才加第二行颗粒; 只是换料请改原来那一行。

没填完也可以先上线: 缺单重的产品照常开工生产, 结算时才会拦住并通知补单重。

> 上线时正在生产、还没有 BOM 的产品, 建议先在这一步填上单个重量, 再做第 3 步开启车间。

### 第 3 步: 开通内料仓并开启整批领料 (仓库, 有设置权限的人)

工作台 → 车间内料仓 (不带车间进入时是车间总览) → 勾选一个或多个车间 → 右下「开通(N)」或「开启整批领料(N)」 (也可以在行菜单里点; 双击未开通的车间直接打开开通面板):

1. 发料来源仓 (选填): 仓库往这个内料仓发料时, 有货就默认从这里出; 不选就按货品所属仓库。先点主仓, 再点子仓, 只能选启用中的良品子仓 (例如塑胶仓库)。"{车间名}内料仓"由系统建在唯一主仓下, 不用选位置。
2. 要整批领料就勾「同时开启整批领料」(已开通的车间点「开启整批领料」), 再选启用日。
3. 所选车间正在生产、还没选料的产品会按产品合并列出, 在同一个面板里一次选完 (选用哪种颗粒, 或"本产品不用车间内料仓的料")。

多个车间一起办时全成全败: 有一个车间不能办, 一个都不办, 并逐个列出原因。开启整批领料时内料仓必须是空的。设错了可以「撤销」, 一次退一步 (整批领料中 -> 已开通 -> 未开通), 只限于还没进过料、没有任务接上、没收过直送的时候。

### 第 4 步: 配置机台 (仓库)

车间内料仓设置 → 机台与容器 → "批量新增机台": 例如 21 台, 每台两个容器 (干燥机料斗 50 公斤、储料桶 100 公斤)。个别机台容量不同就单独改; 不用的机台停用; 盘点用过的机台只能停用不能删。

### 第 5 步: 第一次发料 (仓库, 启用日当天)

仓库任务中心 → 车间内料仓 → "直接发料": 选车间、领料人, 逐行填料和袋数 (公斤自动算), 确认。第 0 步退回和其它入库的料, 也经这一步进内料仓。

### 第 6 步: 第一次盘点 (车间或仓库, 有盘点权限的人)

在开始清点实物的那一刻点"开始盘点", 手机上逐台机点满/半/空、数袋、开口袋过秤, 提交。系统自动结算第一期。建议第一期盘得早一点 (例如一周), 先看看耗用差异率和缺单重清单, 把 BOM 单个重量校准。

### 上线后第一次登录

新权限写在登录凭证里: **上线后每个人要退出重新登录一次**, 才能看到车间内料仓的卡片和按钮。

## 三、日常怎么用

### 仓库

- **车间来人就直接发料** (主路径): 选车间、料、袋数、领料人 (默认上一次的领料人), 一次确认。
- **有申请就按申请发**: 仓库任务中心「车间内料仓」→ 待发料 → 打开 → 确认。
- **收退回**: 待收退回 → 按实收填公斤、选退到哪个仓 → 确认。
- **漏录补录**: 盘点开始前已经发了、当时忘了录的料, 发料时勾"这批料是上一期漏录的", 选补到哪一期、写原因。只能补到"盘点中"或"已盘点、还没结算"的那一期。
- **水口料**: 不进内料仓。交回仓库走"其它入库", 回收料金额自动填 0。
- 发到内料仓的调拨单不能红冲, 发错了让车间退回。
- 请领候选、可发数量、默认发料来源只算良品仓: 不良品仓的料不会出现在候选里, 也不能当发料来源 ([ADR-146](../99-决策记录-ADR/ADR-146-不良品仓业务规则与可用量单一口径.md))。

### 车间

- **新产品第一次开工**: 在"我的车间任务"勾选任务点开工, 弹出开工确认表, 按产品一行选"用料" (多数已预填, 核对后点确认即可) 和生产路线, 点「确认并开工」。同一个产品以后开工自动带出, 不用再选。
- **嵌件注塑件** (塑料 + 嵌件, 没有 BOM): 选颗粒, 并勾"还要按工单领别的料 (例如嵌件)"。塑料从内料仓用, 嵌件照常按工单领, 领完再开工。
- **不用内料仓的料的产品**: 选最下面一项"本产品不用车间内料仓的料 (按工单领料)", 照原来的领料流程。
- **照常报工**, 不填用料。
- **申请领料 / 退回 / 试模清机等用料**: 在「车间内料仓」页办。试模、清机、报废料的用量单独登记, 不摊给产品; 不登记的话会体现在耗用差异率里。
- **中途换料** (少用): 车间生产任务行菜单"这张工单改用别的料", 选新料和从哪天起改用; 只影响这一张工单。以后都用新料, 请改产品的用料或 BOM。

### 盘点 (有盘点权限的人)

- 不设固定周期, 需要时就盘。**想按月对账, 请在月底盘一次。**
- 在开始清点实物那一刻点"开始盘点"; 之后发的料自动算到下一期。
- 每台机一张卡点满/半/空：满和半为容量估算，空仅用于确实无料；有残料时尽量称重后直接填公斤，不再把不到四分之一的一桶料直接记成零。袋料数整袋，开口袋过秤；搅好未上机的料按主料称。估盘标记会随期末和下一期期初传入耗用报表。
- 用完了的料点"其余料都用完了, 记 0"。
- 提交后系统自动结算。盘错了在下一期提交前可以"更正盘点"。

### 结算被拦住时 (系统会通知, 补完自动结算)

| 情况 | 谁来补 |
|---|---|
| 截止日及以前还有没审核的报工 | 报工审核人审核; 不要的草稿由制单人删掉 |
| 有产量但没填单个重量的产品 | BOM 维护人补单个重量 (补完最多 10 分钟内自动结算) |
| 某种料有产品在用, 但这一期从来没发进内料仓 | 仓库补录漏录的发料, 或车间核对是不是认错了料 (改认料或换料) |

其它情况 (有实际没理论、实盘比账上多、耗用差异率超出 -30% 到 +50%、试模清机等用料偏多) 不拦结算, 在用量报表里标红。结算连续失败 3 次, 系统改为每天重试一次, 并通知有设置权限的人"请联系系统管理员"。

### 报工日期与结算

- 一期结算以后, 这一期日期里的报工不能再新建、审核或红冲 (系统会提示报工日期请填下一期起始日或以后)。
- 截止日及以前的报工, 在结算前照常可以新建、审核、红冲。
- 夜班跨零点按报工单表头的日期归期。

### 撤销结算 (少用, 只有被逐人授权的人)

用量与结算页 → 撤销结算: 只能撤最近一期, 且下一期还没提交盘点; 要写原因并再输一次登录密码。撤销只退回已分到各工单的材料成本, 数量不动。改完 (更正盘点、补审或红冲报工、改单个重量) 后点"重新结算"; 不点的话 **24 小时后系统自动重新结算**。

### 财务

- 附件 8 (塑料耗用明细) 改为读车间内料仓的结算结果, 列名列序不变, 按期末日落在所选月份的期间出表。
- 结算前注塑件的成本是暂估, 结算后才完整。**会计月报前请先让当月的内料仓盘点并结算。**

## 五、默认谁有什么权限

| 能做的事 | 默认给谁 |
|---|---|
| 查看车间内料仓与用量报表 | 生产部 (含各车间, 车间成员只看本车间)、仓储部、计划部、财务部 |
| 发料到内料仓、接收退回 | 仓储部 |
| 车间申请领料、退回、登记其它耗用 | 生产部 |
| 盘点 (含立即重试结算) | 生产部、仓储部 |
| 认料、换料 | 生产部 |
| 开通内料仓、开启整批领料、改发料来源仓、撤销、机台、上线准备 | 仓储部 (不随部门批量授权, 不能转授) |
| 撤销结算 | 不授给任何部门, 由超级管理员逐人授予, 每次操作要再输密码 |

权限上线后要重新登录一次才生效。
