基线 `54475dc63`，分支 `uimp/category-prefetch-sweep-20261103`。承接销售任务中心子栏与首屏修复，按相同根因扩查实际任务中心、工作台和关联业务列表。修改分类为客户端读取编排与呈现，共享服务端业务权威；不改数据库、后端 API、审批、数量/金额、库存归属、历史来源或未知提交语义。采用 `frontend-design`，保留既有 Uten 组件、主题和布局。

## 公共实现与清理

- `PreparedPageRead<T>` 是完整第一页交接入口，继续复用 `PagedReadCache`。只消费显式准备的查询一次，保留行、分页、totals/facets、能力和原响应快照。完成后短龄可采用，超行预算不缓存也不截断。
- 新增 `PagePreparationCoordinator`，将原销售私有队列迁入公共入口；各模块只提供合法业务查询的 jobs。不同职责的业务过滤仍由原 repository/领域配置维护。
- `pagePreparationBudgetProvider` 在同一 App scope 内共用两个物理投机读取槽。旧在途传输结束前不释放预算；跨分类、模块、身份/权限/写修订和短暂离开都不会重置成额外两条。排队工作发出前重新检查当前归属/可见性。
- 隐藏期间等槽位的同类任务保留恢复能力；切类退休旧等待；慢请求期间反复开关会清理已退休等待者，不积累旧页面 closure。投机失败不变成业务写入重放。
- 旧任务同步退休、视图通知延后合并；避免写后重新进入时，仓库实例惰性重建在 Widget 构建期间发通知而触发断言。各模块共用 `pagePreparationRetirementCallback`。
- 本端写、读取范围、权限、管理员、账号/代办身份、API/仓库实例变化退休准备 lease。仅 API 地址相同不能复活旧实例数据；仓库、来源、部门、阶段、日期、页大小、排序和列筛选等完整入键。
- 显式刷新、写后刷新和用户筛选仍读最新查询。前台先读时，正在进行的引用计数与完成后的短龄标记阻止尾队列再发同一准备 GET；多前台读只在最后一个结束后解除在途标记。
- 出货财务表与 billNo facets 共用 `salesShipmentTaskFilter`；财务准备页与前台解析共用 snapshot 入口。删除已被公共入口替代的销售私有双 worker 逻辑和短交私有 count，实现一次维护。
- 生产/盘点以静态 extension 包装原有虚方法，调用方显式传入准备 lease；原 `implements/noSuchMethod` 替身与覆盖仍按原接口分派，不因增加读取包装改变 repository/共享草稿 Provider 的依赖图。有界内存 lease 的采用期限仍为 15 秒，不用 idle Timer 延长有效期。
