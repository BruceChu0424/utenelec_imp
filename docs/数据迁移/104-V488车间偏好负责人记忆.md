# 说明104 · V488 车间偏好负责人记忆

- 日期：2026-09-06
- 状态：本地源码候选（未部署）
- 迁移：`V488__workshop_preference_responsible_worker.sql`
- 关联：docs/03-页面/生产物料分析页.md（下达车间预填）、V192（车间偏好表）

## 问题

「下达车间」（物料分析车间桶计划表）此前只记忆**车间**（V192
`production_goods_workshop_preferences`，goods_id 唯一）；**负责人没有记忆**——每次
预填只能从组织树带出车间主管（manager），计划员手工选过的负责人不会被记住，
表现为「明明操作过一次，负责人还是不自动显示」。

## 改动

1. `production_goods_workshop_preferences` 新增 `responsible_employee_id uuid
   references employees(id) on delete restrict`。
2. 存量回填：按「与已学习车间一致的最近一次确认执行段负责人」一次性回填
   （`DISTINCT ON (product_goods_id) ... order by created_at desc`，仅存量 9 行量级）。
3. 学习（服务端 `ProductionGoodsWorkshopPreferenceService`）：
   - `learnFromConfirmedSegments`（正式排产确认）与 `learnSelection`（车间改派，改派
     现在车间或负责人任一变化都会触发）同时学习负责人；
   - 一批内同货多段不同负责人=歧义不更新；未填负责人不算歧义、也不清旧记忆；
   - upsert 规则：车间变更时负责人整体跟随本次选择（未选则清空）；车间不变时
     本次未选保留旧记忆。
4. 读取（`findValidByGoodsIds`，预填端点 `GET /material-analyses/default-workshops`）：
   LEFT JOIN 在职员工（未删除且 `status='active'`），离职员工不泄漏进预填；
   追加 `responsibleEmployeeId/responsibleEmployeeName` 字段。

## 前端预填优先级（bucket 下达车间计划表）

显式路线种子（排产下钻指定）> **学习记忆的车间+负责人**（同批带出，黄标提醒核对）>
组织树车间主管；手工换车间时若恰为记忆车间，也带出记忆负责人。

## 兼容

- 纯加列+回填，不改任何既有列语义；无新权限码、无新表（系统测试清空白名单无变化）。
- 旧客户端不传/忽略新字段不受影响。
