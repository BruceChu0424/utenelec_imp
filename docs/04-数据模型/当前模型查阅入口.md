# 当前模型查阅入口

本页补足当前本地集成的结构入口；版本及迁移头见[当前候选状态](../99-项目治理/当前版本验证.md)。表结构以[实际Flyway目录](../../server/src/main/resources/db/migration)为唯一来源，DTO、权限和动作以各Owning服务为准。旧[实体字典](实体字典.md)、[ER草图](ER草图.md)及分版本关系图保留演进来源，不能作为当前全库清单或目标库已安装的证明。

## 订单交付与资金来源

```mermaid
flowchart LR
  Order[订货单明细] --> Frozen[本单交付计划与冻结BOM]
  Frozen --> Component[实际交付组件与必要加工]
  Component --> Shipped[仓库真实出库]
  Shipped --> AR[本批正式应收]
  AR --> Receipt[收款明细明确引用本批]
  Receipt --> Approved[核准款与当前还欠]
  Order --> Deposit[订单真实预收]
  Deposit --> Applied[实际应用到本批]
  Applied --> Approved
```

图表示来源与动作关系，不把草稿或预览画成已经发生的库存/资金事实。

## 审批与既有模型的读法

当前“我的申请”及报销分级审批的员工入口、阶段配置、负责人回避及实际权限见[使用入口](../03-页面/我的申请与审批中心.md)和[配置指南](../07-业务链路/我的申请与审批权限配置指南.md)。V1000–V1002是这些功能的结构来源，当前启动须核对配套目录全部迁移。

旧ER中 `ApprovalNode/ApprovalRecord` 的通用目标模型不等于现行固定阶段源码，更不能据此宣称进行中的可视化流程任务已完成；工资付款申请不在该申请入口范围。Win7独立迁移的任务状态仍以唯一台账为准。

## 审计、精度与历史

V1059对既有财务点分版本表前向登记审计策略，保留规定列与隐私缩减及原业务守卫；不能改旧迁移、补造历史或把全部敏感正文写进日志。金额、币种、计量单位、原始输入和显式精度选择继续按各自合同保存，不能因为这一张概览合并不同语义。

本页没有连接或修改数据库，也没有据源码存在推断公司部署完成；历史日期、原审计回执和旧字段名分别保留其来源。
