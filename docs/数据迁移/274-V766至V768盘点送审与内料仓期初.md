# V766–V768 盘点送审与内料仓期初

2026-09-30。用户最终口径：即时库存原表进入盘点模式，改实盘数量／重量；保存仅送审，普通仓财务审核，车间内料仓仓库审核，通过后才改库存。新入口默认不授予，由超级管理员逐人授权。

- **V766**：`stock_count_requests`、`stock_count_request_lines`、`stock_count_request_events`，不可改写的申请快照与审核证据，PK 全局单号。批准与库存过账同事务，过期数量／重量／单位禁止覆盖；驳回、撤回不动库存。
- **V767**：三项个人权限 `stock:count:submit`、`stock:count:finance_review`、`stock:count:warehouse_review`，新页面权限面，默认无部门授权。既有车间周期盘点录入保留草稿能力，实际提交过账需仓库审核权限；快捷直接改库存入口退役。
- **V768**：`workshop_material_count_adjustment_postings`，批准的首次实物期初和后续账面修正来源、23 型库存流水、期间期初与修正独立核算。物料已经在车间时不虚构仓库调拨或领料；未知价值保持待核定，数量、重量、价值与来源核对在同一事务。

普通仓获批后生成真实 CHECK；车间按批准事实过账，首期无历史实物的项目为 OPENING，其余为 ADJUSTMENT。日常周期盘点仍沿原计耗结算；人工账面修正不冒充生产耗用。原值、新值、差额、申请人、审核人及库存来源可追溯。

V766 新增3张 CLEAR 表，V768 新增1张 CLEAR 表，无新 PRESERVE 表；同步运行时清空策略、停机脚本与契约索引。当前源码 V768/694，版本／数量须发布前按实际目录复核。未修改已应用 V740/V765 字节。
