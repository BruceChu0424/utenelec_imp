# V540 停用仓既有库存与自动齐套恢复

当前目录为 **V540 / 499 条迁移**；CLEAR 266 张、PRESERVE 96 张保持不变。迁移不会重写库存余额、原单、成本或把等待工单直接改为就绪。

## 仓库状态与既有实物

新单或重新选择仓库时，停用仓和停用祖先继续拒绝。已经存放在停用子仓的实物仍属于原仓，不能因位置停用而从物料分析中消失。合法现货按同主仓、货品、颜色的预算核对；已有合格专属来源仍须匹配原入库、原分析和受益节点。实际领料沿原仓和真实预留办理，不要求重新启用仓库。

删除仓、未知仓、非核算位置、非叶仓、其它主仓公共库存及其它任务专属库存不因此开放。主仓公共安全数仍只保留一次，成本池仍按实际子仓、货品、颜色区分。

## 漏掉到料回调后的自动恢复

`ProductionReadinessReconciler` 复用原 `ProductionExecutionReadinessService` 完整齐套命令。到料回调继续即时处理，后台补偿修复旧版本、停机等原因留下的等待任务：

- 非 cloud 后端启动约5秒后开始，每轮完成60秒后继续；默认启用，可由 `uten.production.readiness-reconcile.enabled` 关闭。
- 每轮最多25个候选，按执行段 UUID 游标轮转；批内超过3秒后不再启动下一项。候选读取限2秒，每项独立事务限6秒、锁等待500毫秒、SQL限5秒；单项失败不挡后续轮次。
- 只处理已批准、未关闭/取消/停止、允许自动齐套的 WAITING 工单。继续获取原库存及业务锁，核对全部需求后才一次性预留、生成实际分仓 DRAW 草稿并通知对应办理人员；不留下部分预留，不替员工实际领料或开工。
- 现有清业务排水门禁仍控制定时任务准入。旧库尚未具备 V540 守卫时跳过自动补偿，不尝试半套系统写入。

上述时间是调度和资源边界，不是全部积压任务的完成时限。真正缺货、尚未检验或来源不符的任务仍等待。

## 系统动作与追溯

新增 `preplan_stock_entitlement_events.system_reason`。仅系统自动齐套产生的 `FORMALIZE` 允许 `created_by` 为空，且必须保存 `AUTOMATIC_READINESS_RECHECK`；其它事件继续保留真实用户与原外键。

应用内部显式系统重载要求无当前登录用户，并核对事务内 `app.production_readiness_reconcile=v1`、空 `app.actor_id` 和 `app.actor_account=系统自动核对备料`。数据库约束与触发器再次核对这些值，以及原批准等待工单、需求、来源预留、目标预留、货品/颜色、实际仓和受益节点。空操作人不是全局免登录能力，不新增系统假员工或公开系统操作接口。

审计保留系统名称及固定原因，原来源操作人和计划/工单负责人仍可追溯。原人工方法及其它事件仍使用真实登录；人工 INSERT 保持旧列集合，避免尚未升级的开发库普通操作因新列缺失失败。

## 实现与专项验证

正式 SQL 为 `server/src/main/resources/db/migration/V540__existing_stock_in_disabled_leaf_warehouses.sql`。Java 入口位于 `features/production/fulfillment/ProductionReadinessReconciler.java`、`ProductionExecutionReadinessService.java`，专属归属链经 `application/port/PreplanAnalysisPegPort.java`、`features/production/analysis/PreplanAnalysisStockPegService.java` 和 `PreplanStockEntitlementService.java`。上述路径相对 `server/src/main/java/com/uten/imp/`。

当前用户 V539 的独立备份副本启动后，已齐料的 SJ15 任务自动就绪并从原仓领出 10,000，原7张计划和2张收货单不变；其余3段仍等待，未被批量改写。重复核对不增加预留、审计或通知。真实 PostgreSQL 另覆盖停用子仓旧库存、系统归属和三种直接数据库绕过请求被 `preplan_system_formalize_actor_guard` 拒绝；新系统入口及原流程38项单测、调度器3项单测通过。

该说明记录专项证据；最终提交的组合测试、数据库版本和公司服务器激活仍由统一发布验收记录确认。V537、V539 的历史兼容说明继续适用，V540 正式冻结后不再修改其字节。
