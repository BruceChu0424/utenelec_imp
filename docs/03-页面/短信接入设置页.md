# 短信网关设置

> 路由：`/admin/sms-settings`
> 别名：短信接入、短信网关设置、短信服务商配置

## 定位

为本公司配置验证码短信服务，核对来源与生效状态。

从系统设置的短信分组进入。短信接入设置管理服务商、签名、模板及访问凭据；验证码有效期、发送间隔和每日限额仍由该分组管理，两者分别保存。

## 权限

仅同时具备超级管理员身份和 `authorization:manage` 的员工可以查看和保存。访客、必须先修改密码及代操作会话不能使用。保存、停用或恢复部署配置均须再认证；普通授权管理员及仅有服务器更新、清理权限的人员不能操作本页。

## 配置来源与字段

页面显示配置来源、当前选择、实际生效服务商、状态及原因。来源“部署环境”表示继承本公司部署配置；“数据库覆盖”表示使用本页显式保存的覆盖配置，返回标识为 `DATABASE`，存储模式为 `OVERRIDE`。

| 字段或状态 | 规则 |
|---|---|
| 服务商 | 生产环境提供停用及阿里云短信；开发日志方式仅在服务器明确允许时出现，不能在生产环境开启或通过页面开放验证码 |
| 短信接口域名 | 从服务器给出的官方允许列表选择，不接受自定义域名、OSS Bucket、协议、端口或路径；停用时可留空 |
| 签名与验证码模板 | 启用阿里云前填写，模板编号须以 `SMS_` 开头 |
| 访问密钥 ID、访问密钥 | 只写，已有原文和密文均不回显；只显示已配置状态和掩码提示 |
| 生效状态 | 分别说明已就绪、已停用、部署规则阻止、配置无效或密钥不可读取，不能仅凭已保存判定可发送 |

未知的旧部署域名保留用于核对，但不会作为可发送目标。官方允许列表缺失时禁止启用未知地址，须读取有效列表后修正。页面不维护另一套宽泛域名通配规则。

## 保存与凭据

两项密钥留空表示保留当前有效凭据；更换时须同时填写 ID 和密钥。更换接口域名时须提供新凭据，或明确清除凭据并停用，避免把旧凭据发送到新地址。“明确清除已保存凭据并停用短信”是独立操作，不能同时填写新凭据。

保存使用当前配置修订作并发校验；其他人已修改时须重新读取并确认，不能用旧表单覆盖。首次从部署环境改为数据库覆盖时，只有显式保存才会将需要保留的有效凭据加密保存；打开页面或读取状态不会自动复制环境密钥。服务器未完成凭据加密初始化，或已有凭据不可解密时须先处理，不能将空白输入误当新密钥。

成功保存后用于下一次发码，无需重启应用；已经开始的发送使用原先快照，不会因配置切换自动重发。保存执行本机配置校验，不发送测试短信，也不改变已有验证码、发送记录、频控或校验规则。本页没有测试发送按钮。

保存结果未确认时先重新读取服务器配置核对。账号、服务器或权限变化后旧表单和异步结果失效，敏感输入不进入偏好、草稿或恢复记录。

## 恢复部署配置

“恢复部署配置”须单独确认，停止数据库覆盖，并放弃当前未保存编辑。恢复后下一次发码重新使用本公司现有部署环境配置，不是恢复通用默认值，也不修改部署环境文件或其原始密钥。

恢复操作不同时提交新密钥或清除指令，配置版本继续递增，旧表单不能在恢复后重新覆盖新状态。恢复后的实际服务商仍受部署环境及生产安全限制；部署配置无效或被阻止时会如实显示，不承诺短信已经可用。

## 相关实现

- 页面：`lib/features/admin/pages/admin_sms_settings_page.dart`；模型 `sms_settings.dart`、仓储 `sms_settings_repository.dart`。
- 接口：`GET /api/admin/sms-settings`、`PUT /api/admin/sms-settings`；写入只接收当前修订与显式配置或恢复指令。
- 权威：`SmsSettingsController`、`SmsSettingsService`、`SmsGatewayRuntime`、`SmsEndpointPolicy` 与 `SecretCipher`。
