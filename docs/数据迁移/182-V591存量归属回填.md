# V591 存量货品归属「仓库 / 生产车间」一次性回填

> 2026-09-15 · 用户实测反馈：V590 的自动回写只对**今后**的入库/排产生效，库里既有的库存、历史入库与历史排产不会倒灌，货品资料表格里存量货品的「所属仓库 / 归属车间」仍是一片空白。

## 做了什么

三条 `UPDATE ... SET ... FROM (SELECT DISTINCT ON ...)`，全部**只填空**（`IS NULL` 守卫——人工改过 / Excel 回填值先到先得，本迁移绝不覆盖；重放幂等）：

1. **归属仓 = 最新入库流水**：`stock_movements` 每货品按 `transaction_date DESC, created_at DESC, id DESC` 取最新一条 `direction=1` 的仓库——与 `StockService` 自动回写的「最新入库仓」同一语义。
2. **无入库流水的货品 → 最大在库仓**：`stock_balances` 每货品按 `qty DESC` 取最大在库量的仓——货现在大部分躺在哪个仓。
3. **归属生产车间(+负责人) = 最近执行段**：`production_execution_segments` 每产品货品取最近一条的 `workshop_department_id` / `responsible_employee_id`（与 V488 给偏好表做过的存量回填同一取数口径；负责人只在货品当前值为空时补，不覆盖）。

## 顺序与触发器

- 全部是 UPDATE、无 DDL：goods 的审计/行触发器排队事件不与任何 ALTER 冲突（V259/V587/V590 同款规矩）。
- 本地开发库已在 V590 应用前手工执行过第 1/2 条同款 SQL（迁移守卫保证 Flyway 重放时幂等空跑）。

## 与 Excel 回填的关系

`import_product_lists.py` 第 3 段（按产品名称匹配、只填空）与本迁移正交：谁先到谁生效，另一方自动跳过。推荐顺序 = 迁移（事实）先行、Excel 补没有库存的货品——本地库 2026-09-15 已按此执行（Excel 补建塑胶仓库/包材仓库两个 `auto_created` 存根，写入 78 行）。
