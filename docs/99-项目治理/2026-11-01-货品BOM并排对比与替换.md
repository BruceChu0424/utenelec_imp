# 货品 BOM 并排对比与替换

分支：`uimp/goods-bom-comparison-20261101`；基线：`48ca76f73`。分类：前端交互及已有 BOM 编辑合同调用；不新增业务计算、数据库迁移或发布。

## 设计计划与复核

沿用 frontend-design 和 Uten 主题。浮窗外壳、标题栏、货品页头与内容统一使用当前主题 surface（浅色 `#FFFFFF`），不再混用灰色外壳与白色内容；主页面原有 `#F5F7FA` 背景保持独立。正文 slate `#0F172A`、操作 teal `#0F766E`、相同 success `#047857`、差异 error `#B91C1C`；深色使用现有主题及语义色。字体沿用应用中文字体及 textTheme，编号与精确数量保持原文。窗口内容统一左右 12px；窗口外沿 8px，中央保留可点击且可拖动的三点手柄。

```text
┌ 左货品 / 更换 / 上下 BOM ┐ ⋮ ┌ 右货品 / 更换 / 上下 BOM ┐
│ 名称、编号、组件表       │   │ 名称、编号、组件表       │
└─────────────────────────┘   └─────────────────────────┘
                 点击 ⋮ → BOM 对比 / 均分
┌ BOM 对比 · 相同 / 差异 / 左独有 / 右独有 · 重新分析 ───────┐
│ 左货品                   │ ⋮ │ 右货品                  │
│ 编码 → 名称 → 颜色 → 规格 → 设计使用数量                 │
│ ☑ Q70045 … 相同单元格绿 / 不同单元格红（不额外加行）     │
│ 自动编辑 / 分侧保存 / 选中或全部替换 / 服务端影响预览     │
└─────────────────────────────────────────────────────────┘
```

直接复用组装信息的 `MasterDataTableView`、`UtenTreeTableCell.compact` 及其列宽测量、表头设置、勾选、树形连线和横向滚动，不另画列表卡片。左右垂直滚动联动，根组件勾选共用一个集合。编码强制作为第一个数据列，后面默认是名称、颜色、规格、设计使用数量；独立的新版比较布局键防止旧名称/状态优先布局被重放。仅在实际不同的单元格标红，相同字段保持绿色；不产生差异字段子行，箭头只展开真实子装配。缺失组件的对应数据格标红；库存/学习等上下文不冒充可复制配方。内部真实关联仍以 UUID 为准，编码是优先核对入口，不按同名硬配对。

有权限的可写根货品进入后自动创建普通 `GoodsBomEditDraft`，单元格沿用组装页公共 `BomInlineEditCell`、输入主题及选择器。数量、备注、颜色、计量规则等修改先暂存，合法输入约 250ms 后重新比较；规格、型号等主档字段仍要求服务端货品可写能力和 `goods:edit`，并以共用属性预览同步两侧。编码、学习/真实用量和未获授权的字段只读。实际子组件仍可在其所属根的编辑会话内维护，保存预览继续披露共享影响。

左右根使用独立事务，不把两份无关 BOM 当作同一组装树提交。各侧保存复用 snapshot/preview/commit、版本、权限、期间料和未知回执合同；一侧保存不能清掉另一侧有效或无效的草稿。所有输入控制器由会话持有，过滤隐藏、滚动卸载、临时只读与延迟回执不会丢失输入；相同十进制值重新比较时不改写用户的尾零原文。未保存编辑先保存或明确放弃后才允许跨窗替换或切换对象。直接改单元格与选中/全部替换继续各自显示准确影响预览，未知保存结果仍只能核对原请求。身份/权限/请求代次变化后旧结果不发布，离开确认框随原窗口所有者关闭。窄窗口保留横向双栏滚动；三个及更多窗口可从标题栏选择具体比较对象。

## 公共入口和调用迁移

| 已有入口 | 处理及必要差异 |
|---|---|
| UtenSplitView 内部分隔线 | 抽出公共 UtenSplitHandle，分类分栏、并排浮窗、BOM 对比复用；宽度约束及持久化仍由各宿主维护 |
| BusinessWindowHost / UtenFloatingWindow | 保留路由、Provider、编辑器实例；固定左右身份，不随窗口置顶交换；重排响应窗口大小变化 |
| MasterDataTableView / UtenTreeTableCell.compact | 组装页和比较页共用表格与树形组件；比较通过列定义的 cellColor 标记具体格子，清除旧行级着色、comparisonValue 列和虚拟差异字段行 |
| BomInlineEditCell / BomTableInput | 普通 GoodsBomTab 的所有 `_lazyCell` 调用及比较页共用激活、焦点、原生文本选择屏障与输入主题；旧包装体移为公共实现，不复制另一套输入皮肤 |
| bomDesignQuantityValid / bomDesignQtyError | 数量控件、普通/批量维护、基准产量、换件用量和比较编辑共用有限且大于零的判断；期间料特殊语义与服务端舍入仍由原合同负责 |
| GoodsBomComparisonEditor / BomLiveEditController | 比较专用的实时输入缓冲与根会话编排；普通组装页保留既有集中 flush 时机，不强行改变其工作流。输入快速回退、无效值、跨侧保存及未知结果均有回归 |
| GoodsDetailPage / GoodsDetailBody / GoodsBomTab | Web 与 Flutter 桌面共用；浮窗成为本地布局域，避免继承主页面的单侧边距；保存后统一刷新已打开 BOM |
| bomComponentCopyBody | 唯一实现迁到 `models/goods_bom_copy.dart`；原数量控件文件再导出兼容所有既有调用，比较模型直接引用。复用精确设计字段及来源复制合同；不复制实际用量、学习归属或已核对状态 |
| GoodsBomEditDraft → /bom/edit/snapshot、preview、commit | 复用服务端权限、版本指纹、环路/重复/期间料校验、共用影响及未知保存回执保护；对比是预览，不成为业务权威 |
| WPF W7-BIZ-025 / W7-BIZ-034 | 完整货品详情/BOM 多窗口尚未迁移；本次合同接续要求登记到唯一台账，不开放原生写入占位入口 |

整份替换针对当前货品直属组件清单（含对子装配的真实引用），不会递归覆盖共享子装配的配方或货品主档。共有 UUID 的子装配本来就引用同一份 BOM；左右独有装配展开读取真实子组件。目标独有组件仅在被勾选或明确整份替换时删除。数量、单价等按原始十进制文本比较，等值尾零不造成假差异；库存及真实用量不是配方冲突。
