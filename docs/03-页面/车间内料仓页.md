# 车间内料仓页


> 2026-10-10 两项口径修订：① 车间内流转免预开通([ADR-174](../99-决策记录-ADR/ADR-174-车间内流转免预开通内料仓.md), [V837](../数据迁移/V837-车间内流转免预开通.md))——审核直送时系统按需开通收料车间的内料仓，车间不必为了流转先走开通流程，「未开通」态只剩从未直送过的车间；② 分类栏下方的说明卡片(「这个内料仓只收车间直送, 还没开启整批领料」)按用户口径删除，进入车间子页直接见表格。 ③ 库存盘点送审改版：常驻「盘点说明(选填)」输入框删除，说明挪进「保存并送审」的确认弹窗(选填，与盘点会话页同款)；送审成功后表格保留刚提交的内容并在最前加「状态」列盖「待审核」，账面/现存照旧可见(审核通过前不动库存)，右下只剩「退出盘点」「盘点历史」，退出才清空。

> 2026-10-04 开通单一真源([ADR-147](../99-决策记录-ADR/ADR-147-车间内料仓开通单一真源与发料来源仓.md), [V802](../数据迁移/V802-车间内料仓开通单一真源.md))：车间总览改为三态——**未开通**(灰)、**已开通**(蓝, 只收车间直送)、**整批领料中**(绿)，状态由服务端给出；分段「全部车间 / 未开通 / 已开通 / 整批领料中」带数，可搜车间或仓库。列为 车间、状态、内料仓、发料来源仓(没选时显示「按货品所属仓库」)、本期，行高与全站普通表格一致。有设置权限时可勾选多个车间，右下按勾选行可办的动作出现「开通(N)」「开启整批领料(N)」「撤销(N)」(全成全败, 一个车间不能办就一个都不办并逐个列出原因)；行菜单提供 查看内料仓 / 开通内料仓 / 开启整批领料 / 修改发料来源仓 / 撤销这一步，双击一行直接打开该车间内料仓(未开通的打开开通面板)。开通面板取代原「开启整批领料」弹窗：发料来源仓走全站仓库滑窗(先点主仓再点子仓, 只能选启用中的良品子仓, 塑胶仓库等子仓都选得到)；「修改发料来源仓」时另有开关「不指定来源仓, 按货品所属仓库发料」，打开后去掉已设的来源仓(之后那个仓库就能正常停用或改用途)，可勾「同时开启整批领料」，开启时把所选车间正在生产、还没认料的产品按产品合并列出、一次选完。撤销一次退一步(整批领料中 -> 已开通 -> 未开通)，只能撤销设错的：内料仓已有进出、收过直送或整批领料已经在用时不能撤销，确认框逐个说明。进入**已开通但没开整批领料**的车间时，直接列出现在放在内料仓里的料(只读)——原来的说明卡片「这个内料仓只收车间直送…」已按 2026-10-10 用户口径删除；**未开通**的车间显示「「{车间}」还没开通内料仓」与开通说明，有设置权限的人可直接点「开通内料仓」，否则提示找仓库开通。原「开通与设置」右下按钮收进总览工具栏「机台与上线准备」。

> 2026-10-01 通用入口：计划／生产工作台不带 `workshopId` 进入时先显示车间总览，包含已启用和未启用车间，支持状态筛选和搜索；有设置权限时可逐行去开通／设置，右下保留「开通与设置」。不会默认选择第一个仓。任务、通知等明确带车间的入口仍直达对应仓；仓内「更多操作」提供车间总览和本车间设置。仅设置权限可以看配置总览、开通及管理机台，不会读取库存；查看库存仍需内料仓查看权限。

> 2026-10-01 顶部与操作区：账期放在仓名副标题，正文顶部仅保留车间切换、现存／记录导航及必要状态。右下悬浮主操作为申请领料、库存盘点；退回、试模试机等用料、周期盘点和盘点历史收进「更多操作」，依原权限显示。进入库存盘点后，添加物料、保存并送审、退出为右下悬浮，表格末尾留出滚动空间(上方常驻「盘点说明(选填)」输入框 2026-10-10 已删，说明改在送审确认弹窗里，见顶部注记)。库存盘点送仓库审核，周期盘点用于期间计耗，入口命名明确区分。

> 2026-10-04 盘点说明选填([V795](../数据迁移/V795-盘点说明选填.md)，[ADR-151](../99-决策记录-ADR/ADR-151-表单草稿回到初始值单重参数结构化契约与入库登记单批合一.md) §4)：不填说明可直接「保存并送审」，服务端把空白统一存为空，最多 500 字，超出时提示「盘点说明最多500字」；说明框与即时库存页共用同一个输入框(2026-10-10 起两处常驻输入都已删除，说明统一在送审确认弹窗里填写)。此前因数据库约束仍要求至少 1 个字，不填说明会回 409「数据已被其他操作更新」且刷新也无效；守卫与约束的拒绝现在按真实原因提示，不再伪装成并发冲突。

> 2026-10-01 状态配色：车间总览「状态」、本页与任务中心的申请「状态」及「盘点」「结算」列按状态铺整格底色——已启用／开着＝绿，盘点中／系统自动结算中＝蓝，待处理／已盘点待结算／差资料＝琥珀，结算没成功＝红，未启用／已取消／已撤销／已结算＝灰；与全站状态列口径同源（`wm*StatusBadgeType` → `udenStatusBadgeCellColor`）。

> 2026-09-28 新增, 设计依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md)。上线顺序与日常用法见[车间内料仓上线与使用说明](../07-业务链路/车间内料仓上线与使用说明.md)。

车间内料仓是车间自己的料架 (原名线边仓)。颗粒这类"整批领料"的料由仓库按袋整批发进来, 只换位置、不算耗用; 车间照常报工, 不按工单领料。本页给车间看"内料仓里现在有多少、估计还剩多少", 并办理申请领料、退回、登记试模清机等用料, 以及进入盘点。

## 入口

- 工作台"生产部"一组, 紧挨"车间生产任务"的「车间内料仓」卡 (不挂数)。
- [我的车间任务页](我的车间任务页.md) 顶栏的「车间内料仓」按钮, 直接带上当前车间。
- 通知里"报工没审, 车间内料仓结不了账""请补产品的单个重量""有料没发进内料仓却已经在用"三类提醒, 点开落到本页。

车间成员只看得到、只办得了本车间的内料仓; 其他部门有查看权限的人可以切换看全部车间。还没有开通内料仓的车间, 页面提示"请找仓库在「车间内料仓」里开通" (2026-10-04 起, 开通与整批领料分开, 见页首)。

2026-09-30：切换器位于空态外，列出服务端允许查看且已启用的内料仓。当前目标未启用或不可见时不自动替换，但可主动选择其它可见仓。切换时先清空原仓数量与动作，再读取新仓，申请／退回／盘点始终使用当前选择。

## 页面内容

**顶部状态条** (本期起止与结算状态, 服务端算好, 页面只显示):

| 状态 | 显示 |
|---|---|
| 开着 | 本期起始日; 可以正常领料、退回、登记 |
| 盘点中 | "正在盘点。盘完点「提交盘点」, 系统会自动结算。" 盘点开始后发的料自动算到下一期 |
| 已盘点, 结算中 | "已盘点, 系统正在自动结算, 稍等片刻就好。" 页面自动轮询 |
| 已盘点, 被拦住 | 列出"差什么、谁来补" (例如"还有 3 张报工没审核, 负责: 报工审核人或制单人"), 补完后系统自动结算 |
| 已盘点, 结算没成功 | "结算没成功, 系统会自动再试", 附最近一次失败原因的大白话 |
| 已撤销结算 | "已撤销结算, 改完请点「重新结算」; 24 小时后系统会自动重新结算" |
| 已结算 | 结算时间与经办人 |

**现存表** (每种料一行): 料号、料名、颜色、估计还剩、账面、上次盘点 (日期与数量, 没盘过显示"还没盘过")、本期领入、本期退回、其它耗用、估计已用、仓库还有, 以及提示列。2026-10-10「数量+单位」全站口径: 数量列单位内联在数字后(如「12 公斤」), 列头不再带「(公斤)」;盘点模式下原「单位」列撤除(账面数量内联盘点基准单位, 实盘数量输入框单位做后缀):

- "估计已用" = 本期已审报工量 × BOM 单个重量, 是估算, 盘点结算后才是实际用量。
- "估计还剩" = 账面 − 估计已用, 用来判断要不要申请领料。
- 提示列: "有 N 个产品没填单个重量, 估计已用偏少""有 N 张报工还没审"。

内料仓里还没有料时, 表格位置显示"仓库直接发料或车间申请领料后, 这里会显示每种料的现存"。

**记录**: 本车间的领料申请、退回申请与完成情况 (单号、类型、来源、料、状态、申请人、申请时间、完成时间); 待处理的申请可以取消 (填原因)。

## 能办的事

按钮是否出现只看服务端随数据给的"可办动作", 没有权限的人看不到按钮。

| 按钮 | 做什么 | 说明 |
|---|---|---|
| 申请领料 | 搜索选择物料，数量填几袋 (已设每袋净重自动算出重量)，也可直接改重量，可多种料一起 | 无需提前设置发料方式，使用中的重量原料可直接申请；搜索与分页覆盖全部候选；显示仓库可发与车间估计余量，提交只生成申请并通知仓管，不动货品、BOM 或库存 |
| 退回 | 选内料仓里有的料和公斤数 | 提示"只退没拆袋、没掺色母的料"; 仓库按实收确认后料才退回仓库 |
| 试模清机等用料 | 选料、公斤数、用在哪 (试模 / 清机 / 报废料 / 其它, 选"其它"要写说明) | 当场从内料仓记出, 记车间费用, 不摊给产品; 用量报表单列 |
| 盘点 | 进入[车间内料仓盘点页](车间内料仓盘点页.md) | 有盘点权限才出现 |
| 立即重试 / 重新结算 | 被拦住的事补完后不想等, 或撤销结算后改完了 | 有盘点权限才出现 |

所有提交都带防重复标记: 网络不稳定没确认结果时, 填写的内容保留, 再点一次不会重复登记。

## 不在本页做的事

- 认料 (新产品第一次开工选用哪种料) 与换料在[我的车间任务页](我的车间任务页.md)的开工确认表和行菜单里办。
- 仓库发料、收退回在[车间内料仓发料页](车间内料仓发料页.md)。
- 用量、浪费率、产品单耗与撤销结算在[车间内料仓用量与结算页](车间内料仓用量与结算页.md)。
