# 销售退货质检冻结处置区

> 状态：V189 已实现（嵌入“销售退货单详情”）；本文只描述前端展示与操作口径。数据库、库存及历史兼容的最终口径以 V189 迁移和销售退货全链路文档为准。

## 一、入口与适用范围

- 入口：`销售管理 → 销售退货单 → 已审退货详情`。
- 仅已审核退货显示质检冻结区；草稿和已红冲退货不显示。
- 退货审核后的实物先进入独立质检冻结台账，不属于可售库存，不参与 ATP、预留或拣货。
- 只有“良品释放”会由服务端正式增加可售库存；“报废”和“返工”只登记受控处置，不增加库存。

## 二、权限与数据范围

| 权限 | 页面行为 |
|---|---|
| 无 `sales_return_quality:view` | 不请求质检接口、不显示冻结数据；因无法核验冻结事实，详情页不开放退货红冲 |
| 有 `sales_return_quality:view` | 在退货 owner/委派范围内查看收货冻结、良品释放、报废、返工、待处置余量和状态；处置按钮只读锁定 |
| 同时有 `sales_return_quality:view` + `sales_return_quality:handle` | 在已经能够打开的退货详情中，可对 `PENDING` / `PARTIAL` 且余量大于 0 的行处置；专用接口具备跨 owner 对象旁路，但当前页面没有独立任务发现入口，不能据此宣称 PMC 可端到端领取他人任务 |

前端显隐不是安全边界。服务端普通销售退货列表/详情仍按负责人/委派范围过滤；质检 GET/POST 的对象策略调用虽使用专用操作旁路，但 Flutter 质检卡只嵌在退货详情页，当前没有跨 owner 任务列表或 PMC 工作台。

因此跨 owner 质检仍是 **NO-GO**：必须补最小任务投影/真实入口，并验证 view+handle、handle-only、已知 UUID、返回投影及“不授予退货编辑/红冲”的正反向矩阵，才可写成完成。

## 三、展示字段与状态

每一条退货明细显示以下基本单位口径：

- 收货冻结量 `receivedBaseQty`
- 已良品释放量 `releasedBaseQty`
- 已报废量 `scrappedBaseQty`
- 已转返工量 `reworkBaseQty`
- 待处置余量 `remainingBaseQty`
- 退货单位与单位换算率 `unitRate`
- 状态：`PENDING` 待质检、`PARTIAL` 部分处置、`DISPOSED` 已全部处置、`REVERSED` 收货已撤销

数量最多输入 4 位小数。未知状态不开放处置，避免客户端对未识别状态作乐观推断。

## 四、处置交互

三个动作都打开明确的确认表单，并要求：

1. 处置数量必须大于 0，且不得超过服务端返回的待处置余量；
2. 必须填写原因或检验依据，最多 500 字；
3. 提交期间按钮禁用并显示进度；
4. 服务端冲突或网络错误在表单内显示，允许修正或重试；
5. 成功后使用服务端返回的整单最新投影整体刷新，不能仅在客户端自行减数量。

“报废”使用危险操作样式并与正常释放区分；任何按钮都不会以“可点击但无响应”的方式占位。

## 五、历史兼容与红冲

- V189 不给历史已审退货补造收货、检验或处置事实。接口返回空列表时，页面明确标记“通常为 V189 前历史退货”；不显示任何质检处置按钮。
- 如果新审核退货返回空列表，页面要求联系管理员核查，不能手工释放库存。
- 质检台账尚未加载完成、加载失败或当前账号无查看权限时，详情页暂不开放退货红冲。
- 任一行已发生良品释放、报废或返工，或返回客户端未识别状态时，详情页隐藏直接红冲，并解释必须走后续受控纠错；服务端仍是最终防线。
- 历史空台账和 V189 新流程中“全部未处置”的冻结收货仍可按服务端规则红冲。

## 六、接口

- `GET /api/sales/returns/{returnId}/quality`
- `POST /api/sales/returns/{returnId}/quality/{returnItemId}/dispose`

处置请求：

```json
{
  "action": "GOOD_RELEASE | SCRAP | REWORK",
  "baseQty": 2.5,
  "reason": "检验单或责任依据"
}
```

## 七、验收要点

- 无查看权限时不发质检请求。
- 只读用户能看到全部数量与状态，但没有处置动作。
- 历史空台账有清楚说明，不伪装成“待质检 0”。
- 数量为空、非正数、超过余量或原因为空时不能提交。
- 成功处置后余量和状态立即刷新；已发生处置时红冲入口同步关闭。
- 小屏、深色模式和文字放大时内容可换行，操作按钮保留可读文本及标准触控区域。
