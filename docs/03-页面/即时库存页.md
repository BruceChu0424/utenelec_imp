# 即时库存页

> 路由：`/stock/instant-inventory`（`lib/features/stock/pages/instant_inventory_page.dart`）· 权限 `stock:view`（全员）
> 上层：工作台 → PMC 运营部 → 仓库管理 hub → 「库存」分区 · 数据口径：[32-即时库存](../数据迁移/32-即时库存.md)

## 一、定位

对标老系统「即时库存」窗口：按**货品类型**浏览当前库存。左树选分类（含子树汇总），右侧表格看
库存数量 / 库存重量 / 成本金额 / 多排数量；顶部仓库下拉（全部=参与核算仓库聚合）。

与「库存查询（余额）」页的区别：余额页按仓+货+色逐行、供仓管对账；本页按货品+颜色聚合、
带分类树导航与成本/多排视角，供 PMC/管理层看盘。

## 二、入口与导航
- 进入：仓库管理 hub「即时库存」卡片。
- 离开：返回仓库管理 hub（`UtenBackButton` 指定 `/warehouse`）。

- **compact**：表格全宽，分类树收进 endDrawer（AppBar 右侧树图标开合）。

## 四、数据链路

```
左树：/master/material-categories/tree（货品资料同款）
右表：GET /api/stock/instant-inventory?categoryId=&warehouseId=&keyword=&page=&size=&sort=&order=
      └ goods 货品驱动 LEFT JOIN stock_balances 聚合（全部=仅 is_accountable 仓库）
        —— 无余额货品也列出（库存 0），与老系统「分类下全是内容」一致
        × material_categories（所属类型）× colors / units（名称解析）
        × production_plan_items 可排余量预聚合（多排数量）
```

- 数量/重量：余额表当前值（历史=StockGoods 最新年 FactQTY/FactWeight 迁移，V80；
  增量=单据审核同事务联动，仓库单据含重量，盘点不联动重量）。
- 成本金额 = 货品成本 `c_total` × 数量（老库 B_Goods.CTotal × FactQTY 口径）。
- 排序白名单：qty / weight / costAmount / moreQty / name（默认数量降序）。
- 仓库下拉「全部」= 6 个真实仓（IsCal=0 参与核算，2026-07-28 修反转 bug）；幻影仓可单选。
- 「含不良品仓」开关（V81 `warehouses.is_defective`，按名称识别）：默认开=老系统口径
  （不良仓计入全部）；关掉即剔除 成品不良品仓/原材料不良仓；指定单仓时开关置灰。
  **选择按账号服务端持久化**（`user_preferences` key `stock.instantInventory`，
  模式同工作台布局：本地缓存即时渲染 + 登录后服务端同步 + 防抖 800ms 推送，
  provider：`lib/features/stock/providers/instant_inventory_prefs_provider.dart`）。

## 五、涉及的 Uten 组件

`UtenAppBar` / `UtenBackButton` / `UtenCategoryTreeView`（分类树，含「全部」顶行）/
`MasterDataTableView`（统一表格：列宽自适应+排序+分页）/ `UtenSearchBar` / `UtenEmpty`。

## 六、功能点
1. 分类树点选（父类=子树汇总），「全部」清除过滤；compact 抽屉选择后自动收起。
2. 仓库下拉切换即重查；搜索防抖重查；刷新按钮重查当前页。
3. 数量/重量/成本金额/多排数量/名称 5 列表头排序（回第 1 页）。
4. 数字列格式化：最多 2 位小数去尾零；null 显示「—」。
