# 工作台软件下载与 Windows 安装更新验证

日期：2026-10-26。范围为本地源码、配置模板和隔离测试。**没有生成实际 ERP Windows 安装包，没有上传或部署到服务器。** 用户已要求等待并行任务结束并再次明确下令；未来本地测试与公司服务器分发包必须分别使用各自后端连接，待用户实测确认后才上传。

## 最终使用流程

- 工作台页头右侧“软件下载”进入独立页面，返回保留工作台。自动将当前 Windows、Android、macOS 或 iOS 设备放在最前；未知系统不伪称 Windows。只有 Windows 安装程序可下载，其他三个平台标注暂时无法下载。
- 中文完整名称为“优腾综合管理平台(UIMP)”，其他语言完整名称为“Uten Integrated Management Platform (UIMP)”。
- 首次安装使用标准 Setup.exe，在当前用户可写的固定程序目录安装，保留既有安装位置、固定更新器及快捷方式。以后点软件内的“立即更新”，自动下载更新 ZIP、校验、退出、备份替换及重启，不重新运行首次安装向导或选择目录。已保存草稿和设置按原更新机制保留。
- 一次应用构建可准备同源的 Setup.exe 与更新 ZIP。发布表单共用版本、架构、说明，两个区域分别上传发布、分别确认结果。两份都保存在公司服务器专用 catalog，由首次安装者下载 EXE、运行中的客户端按原规则发现并下载 ZIP。一个区域成功不等于两个都发布成功。
- 上传、发布、撤回继续使用 `client_release:publish`，正式发布和撤回继续再认证。目录及 Setup.exe 下载允许已登录员工和真实系统超管；超管不要求虚构员工档案，普通无档案账号、访客及须改密账号仍拒绝。
- 下载进度、错误和保存反馈使用公共动效 token；完成/失败复用居中提示，失败只在用户确认后重试，取消不弹成功窗。账号、服务器变化只关闭本页持有的弹窗，已有安全和业务弹窗优先。节能、减少动画和隐藏 ticker 模式直接采用静态反馈。

发布 intent 按真实元数据和包用途维护；只移动光标、选中文本或无语义格式变化不应创建新的发布意图。选择其中一份文件不影响另一份的回执恢复，变更架构不复用不匹配文件。测试覆盖未知回执、部分成功、撤权及晚回执隔离。

## 服务器路径与费用边界

正式/Simple 模板指定 `/var/lib/uten-imp-media/attachments/client-releases`，internal-test 指定 `/data/uten-imp/attachments/client-releases`。两者均位于已有私有 media 写边界内、应用 `current` 与静态 Web 根之外；模板要求上传后保留 10 GiB。这里是独立逻辑命名空间，并非新建文件系统或独立磁盘配额。

两种软件包都保存在公司服务器，不在管理员电脑与员工之间建立直接推送。客户端查版本和下载只使用当前公司业务后端，不查询 OSS。服务器发布源继续仅在显式手动检查或已确认更新作业中访问；外网远程通道仍可能使用云端流量，不能承诺所有网络活动免费。

备份同时保存原始元数据和包，兼容 Setup.exe、旧完整 ZIP 及更新 ZIP。部署前必须同步备份三件套，合并目录配置、确认成功备份、隔离恢复及认证下载；没有执行生产操作。详见[客户端部署与存储](../../deploy/client/README.zh-CN.md)。
