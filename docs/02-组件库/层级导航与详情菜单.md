# 层级导航与详情菜单

前端设计默认使用 `frontend-design`，沿用 Uten 深绿与青绿主题、NotoSansSC 字体及公共控件 token。

分类浏览统一使用 [UtenHierarchyTreeView](../../lib/shared/widgets/uten_hierarchy_tree_view.dart)。单选及浏览选择由行末圆形对勾表达，选中时从右侧短距离滑入，旧项退出；固定标记槽保证文字位置稳定。多选保留复选框。动画由 `UtenMotion` 统一尊重减少动画、性能档和ticker状态，层级底色与负责人、系统保护、停用等业务标记保留。

货品、模具、客户、供应商、收付款类别与仓库目录取消常驻新增、编辑、删除图标。右键和长按保留节点操作，右侧 [MasterDetailCard](../../lib/shared/widgets/master_detail_card.dart) 提供44以上的右上角菜单入口。[UtenHierarchyDetailMenu](../../lib/shared/widgets/uten_hierarchy_detail_menu.dart)把选中节点的即时动作builder传给卡片，打开时重算权限和保护条件；系统未分类根可新增子分类、不可改删，虚拟汇总节点没有写动作。

复制名称和分类路径属于只读辅助操作，不产生业务写入。树的展开、收起继续使用树内已有右键动作；卡片不复制维护另一份展开状态。部门树保留负责人图标，删除统一在右侧菜单和右键入口；部门岗位管理、架构图及花名册、账户编辑也由同一详情卡生成菜单。

菜单把窗口指针坐标转换到根overlay的局部坐标，并使用该overlay的实际布局约束决定左右和上下翻转；不以可能描述其他画布的MediaQuery尺寸裁边。嵌套预览或界面缩放时，弹层继续紧邻触发按钮，并限制在实际可用区域内。

定向验证覆盖真实UUID创建、系统根保护、禁用类别、权限撤销与迟到详情、未保存编辑离开、主仓和内料仓只读边界、菜单取消零写入、暗色、窄屏大字及减少动画。
