# 08 - 主题与配色

> 🎨 **本规范全局强制。** 任何业务代码取色必须走 `Theme.of(context).colorScheme` 或 `UtenColors` 常量，
> **禁止硬编码 `Color(0xFFxxxxxx)`**。换主色只改 `UtenColors.kUtenGreen` 一个常量即可全屏生效。
>
> 配套准则：[07-性能自适应.md](07-性能自适应.md)（深色玻璃拟态只在 standard 及以上档启用 blur）、
> [09-组件库使用规范.md](09-组件库使用规范.md)（所有 UI 走 Uten 组件，颜色由主题驱动）。

---

## 一、设计目标

| 目标 | 说明 |
|---|---|
| 品牌色统一 | 深绿 `#0F3D2E`（主，品质/稳重）+ 青绿 `#14B8A6`（强调，科技/腾飞） |
| 双模式 | 浅色（白底）+ 深色（墨绿黑底），用户可切换，跟随系统也可 |
| 全 token 化 | 所有颜色进 `UtenColors` 常量或 `ColorScheme`，**换主色只改一个常量** |
| 对比度达标 | 所有文本符合 WCAG AA（正常文本 4.5:1，大文本 3:1） |
| 性能档联动 | 玻璃拟态 blur 只在 standard 及以上档启用，lite 档降级为半透明实色（详见 [07-性能自适应.md](07-性能自适应.md)） |
| 即时生效 | 主题切换无重启，Riverpod 驱动 `MaterialApp.router` 的 `themeMode` |
| 持久化 | 用户选择写入 `shared_preferences`，下次启动恢复 |

## 二、品牌色板

### 2.1 主色与强调色

| 名称 | 常量 | 色值 | 用途 |

| UtenGreen（主色） | `UtenColors.kUtenGreen` | `#0F3D2E` | 品牌主色，Primary；品质、稳重、深森林绿 |
| UtenTeal（强调色） | `UtenColors.kUtenTeal` | `#14B8A6` | Secondary/Tertiary；科技、腾飞、点缀高亮 |

| 语义 | 常量 | 色值 | 用途 |
|---|---|---|---|
| success | `UtenColors.success` | `#22C55E` | 成功状态、通过、达成 |

## 三、浅色主题与深色主题

### 3.1 浅色主题（默认）

> **关键决策**：浅色模式下 `primary` 用 **green600 `#039855`（鲜亮绿）**，不用深森林绿。
> 原因：深森林绿 `#0F3D2E` 在白底上偏沉、不够鲜活；鲜亮绿在按钮、Tab 选中、金额上
> 都更有活力，且与深色模式（青绿）色相相近，深浅切换时品牌感连贯。
> 深森林绿保留为 `UtenColors.deepGreen`，仅用于头像渐变等装饰场景。

| 元素 | 色值 | 来源 |
|---|---|---|
| 页面背景 surface | `#F8FAFC` | slate50 |
| 卡片表面 surfaceContainer | `#FFFFFF` | — |
| 主色 primary | `#039855` | **green600 鲜亮绿**（统一主色） |
| 强调 secondary | `#14B8A6` | UtenTeal |
| 正文 onSurface | `#0F172A` | slate900 |
| 次要文本 | `#475569` | slate600 |
| 分割线 outline | `#E2E8F0` | slate200 |

### 3.2 深色主题

> **关键决策**：深色模式下 `primary` 用青绿（teal400 `#2DD4BF`），**不用 green600**。
> 原因：green600 在深色背景下对比度不足、看起来发糊；青绿更亮、更鲜活，
> 与"全部已读"等链接字色保持一致，深浅模式切换时品牌感连贯。

| 元素 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#0B1120` | slate-950 偏冷，比纯黑柔和 |
| 卡片表面 | `#111827` | gray-900，比背景亮一档 |
| 主色 primary | `#2DD4BF` | **teal400 青绿**（不是深绿），保证暗底可读 + 品牌连贯 |
| 主色按钮 | `#14B8A6` | teal500，按钮实心背景 |
| 强调 secondary | `#2DD4BF` | 同 primary |
| 正文 onSurface | `#F1F5F9` | slate-100，高对比 |
| 次要文本 | `#94A3B8` | slate-400 |
| 弱化文本 | `#64748B` | slate-500 |
| 分割线 outline | `#1E293B` | slate-800 |

### 3.3 浅色模式导航选中色

> 浅色模式下 Tab 选中态用 **green600 `#039855`**（鲜亮绿），
> 不用 primary 深绿——深绿在白底上太沉。
> 选中背景用药丸高亮 green50 `#ECFDF3`。

### 3.4 玻璃拟态卡片

仅 **rich 性能档**才启用 `BackdropFilter` 模糊。**注意：登录页已不再使用玻璃拟态**，改为 `UtenCard variant: solid` 实心浅色面板（详见 3.5）。`glass` 变体保留为 rich 档可选样式，供未来情感化页面（如引导、欢迎页）按需启用。

- 背景：半透明 `white.withOpacity(0.65)`（浅色）/ `darkSurface * 0.7`（深色）
- 模糊：`ImageFilter.blur(sigmaX: 16, sigmaY: 16)`
- 边框：青绿 30% 透明 1px

降级策略（详见 [07-性能自适应.md](07-性能自适应.md)）：

| 性能档 | 表现 |
|---|---|
| lite | 不模糊，降级为实心卡片 |
| standard | 降级为实心卡片（仅 rich 启用玻璃） |
| rich | sigma=16 玻璃模糊 |

### 3.5 登录页配色策略

登录页（`lib/features/auth/pages/login_page.dart`）配色与全站中性主题保持一致，**品牌色集中收敛到登录按钮一处**，其余元素全部跟随主题。

- **背景**：统一深色，上下渐变 slate-900 `#0F172A` → slate-800 `#1E293B`。**浅色模式与深色模式均保持深色**——不再使用大块深绿/青绿渐变，避免和浅色模式的中性页面反差过大。
- **登录面板**：`UtenCard variant: solid, elevation: high` 实心卡片。浅色模式为白色（`surface`），深色模式为 slate-900，跟随主题。**不再是玻璃拟态**。
- **文字**：全部跟随 `theme.textTheme`，不硬编码白字。
  - 标题：`headlineSmall`（默认 `onSurface`）
  - 副标题：`bodyMedium` + `onSurfaceVariant`
  - 页脚：`bodySmall` + `onSurfaceVariant`
  - 演示提示框：`surfaceContainerLow` 背景 + `onSurfaceVariant` 字色（不再用白色半透明）
- **品牌色（仅此处出现）**：登录按钮 `UtenButton type: primary`（绿色主按钮），不再用 secondary。
- **Logo 方块**：保留 teal 渐变（装饰场景，不受交互态 primary 统一规则约束），尺寸不变。
- **其他控件跟随主题**：记住设备 Checkbox 用默认主题 Checkbox（不自定义白色填充）；忘记密码用默认主题 TextButton（不硬编码 teal300 下划线）。

> 主题切换时，背景固定深色不变；面板、文字、按钮随 `themeMode` 在浅色/深色之间切换。

### 5.3 `ThemeProvider`（Riverpod，绑定到 `MaterialApp.router`）

```dart
// lib/core/theme/theme_provider.dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:shared_preferences/shared_preferences.dart';
import 'uten_theme.dart';

/// 主题模式状态。
class ThemeModeNotifier extends Notifier<ThemeMode> {
  static const _prefsKey = 'uten_theme_mode';

  @override
  ThemeMode build() {
    // 启动时异步从 prefs 恢复；先返回系统默认，下次 tick 再切换。
    _load();
    return ThemeMode.system;
  }

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    final saved = prefs.getString(_prefsKey);
    state = switch (saved) {
      'light' => ThemeMode.light,
      'dark' => ThemeMode.dark,
      _ => ThemeMode.system,
    };
  }

  Future<void> set(ThemeMode mode) async {
    state = mode;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_prefsKey, mode.name);
  }
}

final themeModeProvider =
    NotifierProvider<ThemeModeNotifier, ThemeMode>(ThemeModeNotifier.new);

/// 把当前 ThemeMode 翻译成实际生效的 ThemeData。
final themeDataProvider = Provider.family<ThemeData, Brightness>((ref, _) {
  // brightness 由 MaterialApp 根据 themeMode 自动选；这里返回两套各一份备用。
  return buildLightTheme(); // 默认占位，下方 App 用 theme/darkTheme 双传。
});
```

```dart
// lib/main.dart（节选）

  title: 'Uten IMP',
  theme: buildLightTheme(),
  darkTheme: buildDarkTheme(),
  themeMode: ref.watch(themeModeProvider), // 即时切换
  routerConfig: goRouter,
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
)
```

> 切换 UI 用 `UtenThemeSwitcher`（见 [../02-组件库/UtenThemeSwitcher.md](../02-组件库/UtenThemeSwitcher.md)），
> 内部调用 `ref.read(themeModeProvider.notifier).set(ThemeMode.dark)` 即可即时生效。

## 六、玻璃拟态卡片实现

> 仅 standard 及以上档启用 blur，lite 档降级为半透明实色。

```dart
// lib/components/cards/uten_card.dart（节选）
import 'dart:ui';
import 'package:flutter/material.dart';

class UtenCard extends StatelessWidget {
  final Widget child;
  final bool glass; // 是否走玻璃拟态（深色+rich/standard 才建议 true）

  const UtenCard({super.key, required this.child, this.glass = false});

  @override
  Widget build(BuildContext context) {
    final cs = Theme.of(context).colorScheme;
    final isDark = cs.brightness == Brightness.dark;
    // 性能档来自全局 Provider，详见 07-性能自适应.md
    final perfTier = PerfTierScope.of(context); // enum { lite, standard, rich }

    // 决定模糊半径
    final double sigma = !isDark || !glass
        ? 0
        : switch (perfTier) {
            PerfTier.lite => 0,        // 降级：不模糊
            PerfTier.standard => 8,
            PerfTier.rich => 16,
          };

    final BoxDecoration box = BoxDecoration(
      color: isDark
          ? (sigma > 0
              ? Colors.white.withOpacity(0.06) // 玻璃层
              : cs.surfaceContainer)            // lite 降级实色
          : cs.surfaceContainer,
      borderRadius: BorderRadius.circular(12),
      border: Border.all(
        color: isDark && sigma > 0
            ? Colors.white.withOpacity(0.08)
            : cs.outline,
      ),
    );

    final content = DecoratedBox(decoration: box, child: child);

    if (sigma == 0) return content;

    return ClipRRect(
      borderRadius: BorderRadius.circular(12),
      child: BackdropFilter(
        filter: ImageFilter.blur(sigmaX: sigma, sigmaY: sigma),
        child: content,
      ),
    );
  }
}
```

## 七、对比度要求（WCAG AA）

| 文本类型 | 最低对比度 | 检查方式 |
|---|---|---|
| 正常文本（< 18px 或 < 14px 加粗） | **4.5:1** | 用 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) 或 Flutter 插件 `contrast_checker` |
| 大文本（≥ 18px 或 ≥ 14px 加粗） | **3:1** | 同上 |
| 非文本 UI（图标、边框） | 3:1 | 同上 |

关键组合自检：

| 组合 | 比值 | 是否达标 |
|---|---|---|
| 浅色：`#1E293B` on `#FAFAFA` | ≈ 14:1 | ✅ |
| 浅色：`#475569` on `#FAFAFA` | ≈ 7:1 | ✅ |
| 浅色：`#FFFFFF` on `#0F3D2E` | ≈ 11:1 | ✅ |
| 深色：`#E6EDE9` on `#0A1F17` | ≈ 14:1 | ✅ |
| 深色：`#14B8A6` on `#0A1F17` | ≈ 6.5:1 | ✅ |

> ⚠️ 不要在浅色模式用 `green500` 当文字色（在白底上对比度仅约 7:1，但小字过粗会糊）；
> 长文本始终走 `onSurface`，主色只用于按钮、链接、强调。

## 九、禁忌

🚫 禁止硬编码 `Color(0xFFxxxxxx)` 在业务代码里——一律走 `UtenColors` 或 `colorScheme`。

🚫 禁止替换 `colorScheme` 中部分字段后留下其他默认蓝——必须整套覆盖。

## 九点五、交互态颜色规则（重要）

> **统一原则**：所有交互态（选中 / 激活 / hover / 链接）颜色都跟随 `colorScheme.primary`。
> 浅色模式 primary = green600 鲜亮绿；深色模式 primary = teal400 青绿。
> 业务代码**不要硬编码 `UtenColors.green600` 或 `UtenColors.teal400`**，统一用 `colorScheme.primary`。

| 组件 | 选中背景 | 选中字色/图标色 | 规则 |
|---|---|---|---|
| SegmentedFilter（"全部/未读"筛选） | `colorScheme.primary` | `colorScheme.onPrimary` | 跟随主题 |
| 悬浮胶囊导航 · 滑块（UI v4） | `teal500`（`UtenColors.teal500`） | 白色（未选中为 `onSurfaceVariant`，按跟手距离插值） | 固定主色 |
| 胶囊导航 · 外壳 | 浅 `white*0.85` / 深 `#1C2523*0.78` + `outlineVariant` 描边 | — | 玻璃拟态 |
| TextButton（"全部已读"等链接） | 透明 | `colorScheme.primary` | 跟随主题 |
| 主按钮 / FAB | `colorScheme.primary` | `colorScheme.onPrimary` | 跟随主题 |
| 金额数字 | — | `colorScheme.primary` | 跟随主题 |

**色值对照**：

| 模式 | primary | onPrimary |
|---|---|---|
| 浅色 | `#039855` green600 | `#FFFFFF` 白 |
| 深色 | `#2DD4BF` teal400 | `#042F2E` teal950 墨绿 |

**装饰渐变例外**：头像方块、登录页背景等装饰场景用 `UtenColors.deepGreen`（`#0F3D2E` 深森林绿）起手，到青绿过渡——这些不是交互态，不受 primary 统一规则约束。
