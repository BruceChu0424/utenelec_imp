# 外网访问与连接页

> 路由：`/admin/remote-access` · 实现：`lib/features/admin/pages/admin_remote_access_page.dart`
入口：系统设置及平台配置导航。设计遵循 `frontend-design`，复用 Uten 主题、窄内容容器、设置区块和紧凑行；
宽屏身份与操作横向排列，窄屏自然换行，不增加独立控制台。新增文案提供中文、英文与韩文。

只有本人超级管理员且当前权限包含 `authorization:manage` 才可进入；前端入口、深链及页内动作统一限制，
后端仍独立裁决。账号、代操作身份、业务重置代次或接口地址变化后销毁旧页面，迟到结果不得覆盖新来源。

| 部分 | 行为 |
|---|---|
| 连接与状态 | 读取服务端确认的本地/远程来源、远程通道配置及观察时间；未配置显示“未接入” |
| 外网总开关 | 只在公司内网修改；关闭不改变内部办公路径 |
| 人数上限 | 默认5，允许1–10000，不能低于当前已授权人数；扩大前须先做带宽与压测评估 |
| 授权名单 | 显示姓名、账号及是否绑定验证器；授权去现有账号权限管理，撤权直接复用现有接口 |
| 验证器重置 | 公司内网核实身份、填写原因并经过再认证后重置；目标全部会话失效，目标须重新绑定 |

`GET /api/admin/remote-access/status` 是唯一状态来源，不能用客户端地址、TCP可达或HTTP 200推断办公身份。
策略通过 `PATCH /api/admin/remote-access/policy` 提交 `{enabled,maxUsers,expectedVersion}`；服务端控制再认证、
并发版本及人数锁。保存后重新读取状态并对照本次期望；网络失败或读回不确定时不宣称成功，先刷新核查。
远程通道只展示策略，禁修改总开关及上限，仍可按后端权限撤权。

已有外网资格还需要总开关开放、入口可用与当前会话MFA通过，不额外增加业务数据权限。管理入口不提供任意URL探测、
数据库地址、云全权限密钥或“自动切主”开关。线路延迟、备份共同恢复水位、双WAN/云入口HA尚无对应实机证据时不显示绿色指标。

源码和定向测试可验证页面/接口契约，不能替代证书、可信来源、真实MFA设备、跨运营商性能、断线、撤权、灾备及部署验收。
正式开放须沿现役签名发布链及部署Runbook完成现场检查。本轮不改变业务草稿服务器命名空间，也不实现通用离线写队列。
