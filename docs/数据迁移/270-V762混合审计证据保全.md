# V762 混合审计证据保全

状态：本地前向迁移候选，8项真实数据库及2项调度器定向验证通过，未应用到本机业务库或公司服务器。设置页接线和根整合仍在进行。承接R0.04紧急保护及W17，不表示R4生命周期底座完成。

原V671的每日任务会把超过在线期限的整月分区移入归档，并直接删除超过总期限的归档分区。一个月同时包含业务决定、来源变化、安全与普通技术事件，年龄不足以证明这些记录都可以销毁。本候选暂停这一整区删除能力，保留正常归档和当前/未来月份预建，避免等待R4时先失去证据。

## 迁移合同

- 仅用`CREATE OR REPLACE`替换既有`fn_audit_retention_run()`；原十列返回签名、OID、所有者、EXECUTE权限、SECURITY DEFINER、固定search_path及5秒锁等待限制保持。
- 到期的热分区仍先计数、验证月份约束，再整月DETACH/ATTACH；任何失败都在同一事务回滚，完成事件不提前写。
- 已有归档只读分区元数据；超总期限的`preserved_partitions`在搬移后按实际归档目录计算，`preserved_partition_count`是其数量。未统计的旧归档行数不冒充0；实际`dropped_rows`固定0、`dropped_partitions`为空。
- 完成事件声明`purge_mode=PRESERVE_UNCLASSIFIED`。缩短月份或反复调度不能绕过保全；重启、回退应用也不能恢复数据库自动删除。重新启用销毁必须有另一次经过分类、冻结、引用和恢复证明的前向变更。
- 只读能力`fn_audit_retention_purge_mode()`将保护声明绑定到已安装函数体、执行配置及SECURITY DEFINER摘要。实施被回退或漂移时返回UNKNOWN，避免设置页仅凭客户端版本或保存值假称已保护。该函数不执行留存，也不暴露原函数体、秘密或业务数据。

会增加归档保留空间，这是防止不可逆证据丢失的临时选择。仍须按R4/R5落实分类、冻结、压缩、历史访问、恢复与合法销毁；不能把本保护当作所有审计应永久保留。没有启用任何新的业务/附件删除。
