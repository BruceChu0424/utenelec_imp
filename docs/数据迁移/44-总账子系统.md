# 44 · 总账子系统 + 8 张总账报表（C3）

> 来源：《ERP财务部门需求附件.xlsx》附 9~16 + 部门汇总。2026-07-29 落地。
> **关键发现**：`payment_styles`（124 节点树：INCOME/EXPENSE/ACCOUNT/LIABILITY/EQUITY，path/level 编码）
> 就是老系统的收支科目树，费用/收入行 100% 挂接——C3 直接复用为总账科目表，不另建 gl_accounts。

## 一、结构

- **V122 `general_ledger`**：`gl_vouchers`（凭证：单号/期间/来源/source_type，UNIQUE(voucher_no,source_type)）
  + `gl_entries`（分录：科目 style_id→payment_styles / direction 1借-1贷 / amount / 源单关联 / entry_date+period 冗余列），
  四审计列一次带全；`account_style_id(uuid)` 函数：accounts.style_legacy_id→payment_styles.legacy_id，无挂接 CASH→/101/ 其余→/102/。
- **GlPostingService**：7 类 AUTO 过账（全 set-based SQL）：
  销售立帐 借113/贷031（退货红字）；采购+委外立帐 借123/贷203；收款 借账户/贷113；付款 借203/贷账户；
  费用 借行科目/贷账户(=行合计)；其它收入 借账户/贷行科目；销售成本结转 借041/贷123（出货行 Σqty×c_total，单号-CB）。
- **幂等**：`POST /api/finance/gl/generate?period=` 先删该期间 AUTO 凭证（级联）再重建；
  `POST /api/finance/gl/generate-all` 重放全部历史期间。

## 二、报表（/api/finance/reports/gl/*，finance_report:view；导出复用 /finance/reports/export）

| 报表 | 端点 | 口径 |
|---|---|---|
| 科目余额表 | `gl/trial-balance` | 期初/本期借贷/期末；资产费用借正、负债权益收入贷正 |
| 附 9 资产负债表 | `gl/balance-sheet` | 固定行（货币资金 101+102 / 应收 113 / 其他应收 172+173 / 存货 123 / 待摊 139 / 固定资产 151 / 应付 203 / 应交税费 221 / 其他应付 204+205 / 实收资本 301 / 未分配利润=321+累计损益净额）；期末+年初两列 |
| 附 10 年度利润汇总 | `gl/profit-annual` | 收入=031+032 贷净；成本=041+042 借净；税金=税金；销售费用=销售类 8 科目；管理费用=043 其余；财务费用=手续费；营业外收入=033 贷净；行×12 月 |
| 附 11 月度利润表 | `gl/profit-monthly` | 同上行集，本月+本年累计 |
| 附 12 制造费用明细 | `gl/manufacturing-expense` | 生产产值=成品入库流水金额；模具维修/物料消耗/水电费/品质部/仓储/安装/注塑/轨道/铜柱/酸洗=对应科目；加工费=委外进仓行金额（单头老库全 0） |
| 附 13 管理费用明细 | `gl/admin-expense` | 销售额=031 贷净；房租/工资/餐费/办公/电话/汽车/证书/快递/设计/劳动用品/人事/其它=对应科目 |
| 附 14 销售费用明细 | `gl/sales-expense` | 销售费用/外贸部/OEM部/运费/快递/淘宝/慕朵/证书 8 科目×12 月 |
| 附 16 经营损益表 | `gl/operating-pl` | 销售额基数=031+032 贷净；材料费=DRAW 月耗用(qty×c_total)按货品一级类别；工费=餐费+委外加工费；一般管理费=模板行映射科目；占销售比=金额/销售额 |

year/month 参数缺省由通用报表页 dateTo 推导（通用页零改造直接可用）。前端：财务 hub「总账报表」卡 8 chip，路由 `/finance/report/gl`。

## 四、已知局限（文档化）

- **存货(123)/应付(203) 余额偏大**：只过了采购/委外入库与销售成本结转，材料领用出库（DRAW→生产）无对应科目（无原材料/生产成本科目），未过账——存货只进不出，属口径上限；需待 C5/二期补科目后再结转。
- 账户级余额（102 各行）未与 accounts.init_balance 对账：期初未建开账凭证，余额=过账净额（2019 年起全量重放后即为全生命周期净额）。
- 附 12 直接/间接人工/资产折旧、附 13 福利/社保/招待/维修/交通、附 16 折旧/广告/装卸/物业/检测/报关等无数据源，列占位 NULL。
- 附 14 模板按业务员拆分（外销/苏君丽等）：费用单据无业务员维度，按费用科目出行，不可按人推导。
- DIRECT_RECEIPT/DIRECT_PAYMENT 立帐行未过账（收付款由 finance_receipts/payments 进账，避免重复）。
- 财务费用=手续费科目（利息收支无独立科目）。
