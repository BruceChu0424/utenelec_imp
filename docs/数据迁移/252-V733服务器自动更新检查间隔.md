# V733 服务器自动更新检查间隔

新增 `system_settings.updater_check_interval_days`，出厂值 `7`，保留同名已有值。类型、范围、名称与分组统一登记在 `SystemSettingKey`；本迁移不修改已应用迁移，也不访问 OSS。

管理员通过现有系统设置批量保存入口修改，继续执行超级管理员权限、敏感操作再认证、期望原值防覆盖、行锁和审计。合法范围为 `0..365`；保存时规范为十进制整数，等价输入不会重置修改时间。

- `0`：关闭自动检查，保留手动更新。
- `7`：服务器当地时间每周日 05:00 检查。
- 其他正整数 `N`：从设置修改的当地日期加 `N` 天首次检查，之后每 `N` 天 05:00 检查。

操作系统调度器读取数据库设置后执行真实更新检查，并写入只读状态文件。`GET /api/admin/system-settings/updater-status` 比较当前设置与调度器已应用的值、修改时间和最近本地检查时间；缺失、异常、过期或尚未同步均不会报告为已生效。应用本身不执行系统命令，也不因读取此接口而访问 OSS。

源目录增加到 **V733/662 条**。源文件、打包产物、目标数据库实际安装与调度器安装须分别核实。
