# V473 生产领料“取消出库”权限文案

## 目的

`stock_doc:reverse_issue` 的历史目录名称是“红冲仓库单据发料”，容易让员工把它与整张
库存单据红冲混为一件事。当前生产 DRAW 详情页把该动作统一称为“取消出库”：它只在首次
报工前，按原出库行对称恢复库存和物料占用；必须填写原因，且不删除、覆盖原出库流水。

V473 只前向更新该既有权限的 `name/description`。权限 code、既有部门/个人授权、权限面、
兼容 API `/issue/reverse`、库存流水和业务数据均不改变，也不修改已经应用的 V328 字节。

## 权限与操作边界

- 草稿生产领料首次“出库”：`stock_doc:approve ∩ stock_doc:issue`；审核与首轮扣账同事务。
- 后续分批出库：`stock_doc:issue`。
- 取消已出库量：`stock_doc:reverse_issue`，原因必填；首次报工或下游消耗后失败关闭，应走
  精确生产退料。
- 整张单据红冲仍是独立的 `stock_doc:reverse`，不能用“取消出库”代替。

## 迁移与发布边界

本迁移不重写历史出库/取消流水，不增删 grant。空库与非空库都只更新一个权限目录行；若
该权限不存在或更新结果不符合当前文案，迁移以 `23514` 失败关闭。目标库迁移、权限界面
人工复核、仓库实物 UAT 与恢复演练仍是独立发布门禁。
