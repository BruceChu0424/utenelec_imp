# V593 采购/委外链「主档默认值」单一事实源

> 2026-09-15 · 用户口径：与货品归属仓/客户默认条款同一模式——新建采购订货单选货品自动带出绑定的供应商，供应商出来自动跳出币种/税率/结账方式，采购/委外单价放进货品资料，全部支持实时更新（每次下单写回最新）。

## 做了什么

**列（先加列/索引，再回填，V259/V587/V590/V592 顺序规矩）**：

| 表 | 列 | 说明 |
|---|---|---|
| goods | default_purchase_price NUMERIC(18,6) | 采购单价：订货行价预填；保存采购单写回最新行价 |
| goods | default_subcontract_price NUMERIC(18,6) | 委外加工单价：同上（委外单） |
| goods | （复用）default_supplier_id | 货品绑定的供应商：订货选货品自动带出；每次下单写回 |
| suppliers | default_currency_id UUID→currencies | 默认币种：选供应商后预填；每次下单写回 |
| suppliers | default_tax_rate NUMERIC(18,4) | 默认税率：同上 |
| suppliers | （复用）default_settlement_method_id (V452) | 默认结账方式：同上（成对过触发器） |

**存量回填**（全 IS DISTINCT FROM 只填差异，重放幂等）：
- 货品两价：最近一张未删采购/委外单该货品行价（行 id 最大者）；
- 货品默认供应商：采购+委外两源合并取「最新一张单」的供应商；
- 供应商条款：最近一张未删采购单头条款；**结账方式只回填「使用中且未软删」的字典值、price_style 旧快照随字典 legacy_id 成对写入**（V452 触发器要求，V592 客户侧事故同款教训）。

## 写回（ProcurementMasterDefaultsSyncService，MANDATORY 挂单据事务）

保存采购单（create/update，`orderRepo.save` 后）→ ①行货品写默认供应商+采购单价（空价保值）②单头条款写供应商行。保存委外单同理（委外价列）。结账方式与 price_style 成对写、只认「使用中」字典；值没变不落盘。

## 预填（/purchase-orders/last-terms 与 /subcontract-orders/last-terms）

主档优先：goods.default_supplier_id → 供应商主档条款（币种/税率/结账方式、汇率取币种现行汇率）→ 货品默认单价（LastTermsPerGoods 新增 purchasePrice/subcontractPrice）。无主档绑定的货品回落旧「最近订单推导」，但主档单价仍优先带上。

## 主档展示/维护

- GoodsDetail 新增两价字段（只读，随载荷下发）；Goods 实体映射。
- SupplierDetail 新增默认币种（+名）/税率字段；SupplierSaveRequest 开放（币种 presence 语义、校验存在未软删；税率直传）。
- 前端：货品详情/供应商详情展示与表单接线（见前端批次）。
