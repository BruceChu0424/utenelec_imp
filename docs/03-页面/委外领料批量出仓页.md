# 委外领料批量出仓

> 路由：`/warehouse/subcontract-outbound/batch`
> 别名：整批委外发料、批量委外出仓

## 页面定位

仓库集中核对委外人员已提交的领料单并逐张办理实际出仓。

## 办理与边界

- 从委外待发料任务选择原领料单进入，恢复整批原来源与本机拣货输入。
- 查看需要 `subcontract_outbound:view`；执行还需 `subcontract_outbound:execute`，保存与确认分别叠加 `subcontract_material_issue:edit`、`subcontract_material_issue:approve`。
- 按冻结的直属物料和原计量单位核对数量、称重、仓库、经办人及行备注，不以整批显示总数替代每源预算。
- 服务端逐张检查原委外订货来源、可领额度、版本、状态、库存和本人仓库范围。
- 未确认成员继续留在原任务；回执未查明时核对原出仓操作，已确认成员不再次保存或出仓。
- 返回原委外任务上下文，成功与未完成成员分别保留，整批恢复不复制领料单。
