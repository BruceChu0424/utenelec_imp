## 四、会话惯例（本项目工作方式）

1. **每完成一项**：后端 `bash compile-check.sh`（javac 全量）+ 前端 `dart analyze`（见 §五）+
   重启后端 + E2E（临时测试账号，测完即删）+ 更新对应 docs + README 状态表 + 本文件。
2. **Flyway 迁移**：实体继承 BaseEntity 必须一次带全四审计列（created/updated_at/by，V94 教训）；
   建表 SQL 带齐索引；**有并行任务在抢版本号**——新迁移先用 `ls db/migration | tail` 看最新号，
   撞号（启动报 "Found more than one migration with version N"）就把**未应用**的文件重编号。
3. **附件 Excel 原件**在 `_scratch/finance_req.xlsx` + `_scratch/all_dept_req.xlsx`（模板列结构照抄）。

## 五、操作手册（编译/重启/测试）

```bash
# 后端编译（输出到 C:\Users\bruce\AppData\Local\Temp\uten-classes，即启动 classpath）
cd /d/Projects/uten_imp && bash compile-check.sh   # EXIT_OK = 通过

# 重启后端（应用新迁移 + 新类）
PID=$(netstat -ano | grep ":8080" | grep LISTEN | head -1 | awk '{print $NF}')
taskkill //PID $PID //F && sleep 2
export PATH="$PATH:/c/Windows/System32/WindowsPowerShell/v1.0:/c/Windows/System32"
powershell.exe -NoProfile -Command "Start-Process -FilePath 'C:\Program Files\Microsoft\jdk-21.0.11.10-hotspot\bin\java.exe' -ArgumentList '@C:\Users\bruce\AppData\Local\Temp\uten-args.txt' -WorkingDirectory 'D:\Projects\uten_imp\server' -RedirectStandardOutput 'D:\Projects\uten_imp\server_run.log' -RedirectStandardError 'D:\Projects\uten_imp\server_run.err.log' -WindowStyle Hidden"
sleep 25 && grep "Started UtenImpApplication\|ERROR" server_run.log | tail -2

# 前端分析（flutter.bat 因 SDK 3.12.1 < pubspec 3.12.2 不能 pub get；依赖已解析，直接用 dart）
"/d/Software/Flutter/bin/cache/dart-sdk/bin/dart.exe" analyze lib/features/xxx

# 数据库（docker exec 必须 -i，否则 stdin 进不去、静默空跑）
"/c/Program Files/Docker/Docker/resources/bin/docker.exe" exec -i uten-imp-postgres psql -U uten -d uten_imp -c "SQL"

# E2E 测试账号套路：/tmp/HashGen.java（Argon2id 哈希，全 m2 classpath）→ psql 插 employees/users/user_roles(employee)
#   + user_permission_overrides 加授权限点 → /api/auth/login 拿 JWT → 测完 DELETE 三表 + 业务数据
# 注意：git-bash /tmp ≠ Windows Python 的 /tmp（写 _scratch/）；curl 中文必须 --data-binary @UTF-8文件
```
