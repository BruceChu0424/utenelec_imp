# ADR-138 货品成本单与实际成本工作台

- 日期：2026-09-29；2026-09-30 增补自动计算与简化交互。
- 状态：已接受，代码实现；初次实现见[2026-09-29 记录](../99-项目治理/2026-09-29-货品成本工作台实现与验证.md)，自动计算与简化交互见[2026-09-30 记录](../99-项目治理/2026-09-30-货品成本表自动计算与交互简化.md)，均不代表业务库已部署。
- 修订范围：ADR-129 的新增预算读者、ADR-137 的成本显示适配、旧主档成本页。原 BOM/执行/库存事实与已有迁移字节保留。

## 决定

1. 成本采用独立草稿与不可变版本，不把测算直接写回 goods.c_total/BOM/库存。确认独立授权，历史快照保留原身份和名字。
2. 成本页只负责成本；报价、售价、利润目标由销售负责。客户×产品条件用于本方成本分摊，向客户收费不冒充成本。
3. 真实用量沿权威视图，缺失或非线性回退设计规则；已含损耗不重复加损耗。共享曲线保留执行取整合同，预算沿有理数到最终金额投影。
4. 可新增费用价格列，员工填价格，后端计算费用。列与费用表是一份来源的两种投影，隐藏列不改变成本，父子树不重复归集。
5. 价格必须有明确单位、税币和版本来源。草稿记忆价不是批准价格；已批准行存在正式附加收费时不得擅自跨批量均摊。未知保留不完整状态。
6. 采用独立成本权限。公共辅助显示 scope 为 view_goods_cost，不能继承售价权限；正式金额仍由成本服务计算。
7. Excel 导入保留原文件、缓存值/公式证据、完整映射和应用前后输入；不执行外链或公式。重导入进行三方恢复，保留手工修改及不可变旧证据。
8. Excel/PDF读同一计算快照；未知金额不变零，精确金额不省略，当前扩展值不混入历史下载。事务状态未知时不删除已提升文件。
9. 实际读取价值账和冻结成本修订，不把经验用量当实际过账。期间选择与完整成本范围分开，部分处理不显示假完整值，缺失人工/间接费用明确说明。
10. GL消费原实际价值过账。新旧切换需对账，已关闭期间差额需要明确目标期间；既有凭证不自动重写，来源到凭证一一幂等。
11. 界面材料、数量、单价等单元格只显示一行。详情与解释放提示/查看详情，复用 Uten 表格、输入保护、草稿、汇总和修订组件。
12. 模板固定金额保存原币与汇率，切币使用服务端纯换算；数量和百分比保持不变。未知汇率不推断为 1，基本单位单价与来源计价基数明确区分。
13. 实际修订冻结原身份及金额区间；旧事实证据缺失只标待核，不从当前资料回填。入账和关账同时检查无金额过账行的未定价实物流，真实已确定零成本与缺价分别处理。
14. 成本表直接在系统内生成。只读初始化自动提供日期、本币、用量/取价和匹配规则，打开不要求先建单或导入；保存/确认仍是明确动作。低频设置按需展开，表格及保存下载保持可见。
15. AUTO 对外购物料采用可靠批准价，缺失时再查当日已核定库存参考；委外加工价与整件成本严格区分。默认批准价按原记录使用，显式税调整的来源与版本保护保留；不以简化操作为由伪造价格或清除员工选择。
16. 缺价是行级待核状态，不能隐藏整张物料表。诊断通过物料名/编号和简短摘要表达，内部路径仅供定位，不直接堆在业务页面。
17. 主屏只保留成本表；实际依据和历史记录按需打开。实际产量自动读取最近明确生产范围的权威已审进度，保留撤回/FQC/返工与计量单位语义；测算数量默认每 1 个成品基本单位。实际量不回写测算数量或冻结版本，不以全历史累计量摊薄单批固定费用。
18. 计算设置渐进展开，普通层只维护测算数量与可选客户，日期/币种/汇率/策略/模板等低频参数放默认折叠的高级选项。客户条件改变后模板候选与异步回执必须绑定最新客户上下文，清空客户恢复通用/产品规则；界面精简不改变已有成本输入、保存与确认边界。

## 后果与边界

新增 V753 成本对象、V754 实际价值过账桥、V755 私有导入证据、V756 原实物/价值身份冻结及实际覆盖口径。草稿、模板、来源及确认版本保留；实际 GL 政策保留，期间与凭证关联随业务清空。新增表均登记审计、清库策略、主档引用及必要索引；V756 只扩展既有事实表和函数，不改变清库分类。

旧主档预算只作历史参考，不再从新成本页全量 PUT。旧委外允许损耗仍可通过窄接口维护。销售可引用确认成本版本，成本页不增加销售报价工作流。

完整接口与岗位操作见[货品成本工作台](../03-页面/货品成本工作台.md)。应用未明确拥有某物料/客户访问范围时拒绝整份敏感结果，不能通过合计或下载绕过。
