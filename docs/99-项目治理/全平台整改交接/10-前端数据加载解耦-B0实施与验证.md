# B0：前端数据加载解耦与响应性

日期：2026-10-23。承接旧数据长期运行方案复核；用户随后授权分阶段实施，第一阶段优先消除加载与大数据处理导致的页面卡顿。遵循 `frontend-design`，复用现有 Uten 控件、主题与业务身份，不重做视觉。

## 验收口径

网络等待、解析、业务投影、Widget 构建/布局、附件与 PDF 是不同阶段。`async`、`Future.microtask` 或多一个 spinner 均不能证明计算离开了 UI 线程。

- 原生平台：大 JSON 使用 isolate；PDF 完整布局与保存均在可终止 isolate 中。
- Web：大 JSON 与 PDF 使用同源 Worker；需要 Dart 对象的物化与其他不能移交的纯展示工作按实际耗时切片，让出真实事件循环。
- 查询只允许当前身份、权限、服务器和请求代次发布。取消读取不表示业务写入没有发生，禁止自动重放已发送命令。
- 后端等待时局部显示进度，保留可用内容与独立输入、导航；数据尚未准备完毕不能发布半份统计或启用错误的业务操作。
- 性能记录包含数据规模、构建标识、帧间隔与构建/光栅阶段。200ms 是本轮排除明显冻结的底线，不能当成流畅目标。目标是普通操作及时反馈、长计算不连续占用主线程、旧结果不覆盖新结果。

## 本包实现范围

| 共享链路 | 实施内容 | 保护的语义 |
|---|---|---|
| API JSON | 大响应原生 isolate / Web Worker；Web 物化按耗时切片；取消向物化传播 | Unicode、空值、精确数字字符串、非 JSON/stream/bytes、自定义 decoder |
| 分页仓库与报表 | 46 仓库的 76 个通用分页解析入口；10 报表文件的 11 个读取入口；服务器 totals/facets 保持原值 | 分页、总计、精确金额、服务端权威统计 |
| 读取归属 | 单调 epoch 围栏覆盖账号、权限和服务器切换及 A→B→A；旧 data/error/loading 均不回写 | 不显示旧身份数据，不清除新请求等待状态 |
| 物料分析 | 模型、共享仓库维度、展示投影、展开和模式切换切片；按精确 UUID 复用索引；只发布完整投影 | 原始来源、操作组与物理行身份、数量、路线、草稿、并发数量变化 |
| 树结构 | 共享 subtree 计算由逐行前扫改深度栈；缓存可见投影与排序 | 断层深度、祖先续线、折叠、顺序 |
| 公共表格 | 显示/筛选/排序缓存，排序键每行提取一次；列宽按实际 2ms 预算逐格推进，首帧仅标题与最小宽 | 用户列宽、长尾内容、筛选与选中 |
| 仓库批量预读 | 4-worker 有界读取，稳定顺序；过期/失败停止新增读取；按收货单一次分组草稿 | 提交事务、未知提交状态、仓库及来源规则 |
| 采购价格分析 | 300ms 防抖后才创建完整快照；捕获切片；旧证据立即失效 | 精确数量/价格/汇率、原有请求分批与权限 |
| 附件预览 | 原生大文件后台解析；Web 文本/CSV/ZIP 真切片；有限展示但保留真实总数 | 多字节边界、带换行引号 CSV、GB18030、ZIP64、原件字节 |
| 打印 | 屏幕纸页懒挂载；PDF 完整生成移出 UI；取消/权限变化终止 Worker/isolate；已编译 Worker 随资产发布 | 全文复制、自然纸张分页、标题、原文、字体与数量字符串 |

公共入口调用审计：`lib/features/**/pages/*.dart` 共 234 个页面文件（不是独立路由数），15 类工作流；MasterDataTableView 在 180 个 features 文件中引用、EditableGrid 47 个。方法为共享入口深查与代表页面验证，**这些数字不能写成全部页面逐一完成 UI 或性能验收**。

## 可复现验证

正式本地工具：`tool/b0_responsiveness_harness.dart`、`tool/serve_b0_harness.py`。仅合成数据，不连接业务数据库；假 API 拒绝非 GET。真实物料页面用 500 产品 / 2,000 物料及固定两秒延迟。PDF 用 2,800 行；CSV 用 100,000 数据行和一个标题行；JSON 用约 3.9MB / 30,000 行。

```powershell
$env:CI='true'
$env:DART_SUPPRESS_ANALYTICS='true'
$env:PUB_HOSTED_URL='https://pub.dev'
flutter build web --profile --no-pub --no-web-resources-cdn --no-wasm-dry-run --dart-define=B0_BUILD_ID=<reviewed-build> -t tool/b0_responsiveness_harness.dart
python tool/serve_b0_harness.py --root build/web --evidence-dir <outside-git-evidence> --port 53871
```

浏览器打开 `http://127.0.0.1:53871/?auto=material&run=<run-id>`，也可选择 `json`、`pdf`、`csv`。自动物料场景调用真实模式控件回调，记录六次切换；不把它描述为真实指针输入延迟。采样期间不要读取 accessibility tree、截图或运行构建/测试；另做实际输入验证。结果写到本地证据目录，不提交业务数据或机器临时日志。

PDF Worker 的可重现生成和源哈希检查见 [PDF_WORKER.md](../../../tool/PDF_WORKER.md)。修改对应输入后必须更新资产和 receipt；`flutter run/build` 无需用户手工执行预处理。

## 集成与后续阶段边界

本任务在独立 worktree `frontend-loading-b0`、分支 `uimp/frontend-loading-b0-20261023` 实施。主工作区有并行未提交修改，禁止覆盖、清理或整树复制。合并最新 `origin/main` 后复跑分析、相关行为回归和浏览器性能；源码、测试、PR 门禁、main 合并、服务器激活和设备 UAT 分别记状态。

下一阶段数据治理继续按现行永久保留协议处理报表读模型、快照/异步导出、容量与备份；不得恢复旧方案的历史数据到期删除或破坏性压缩原件。B0 发现的编辑器大单据挂载、导入编码与草稿快照等残余风险必须有明确复核，不因共享网络层完成而自动记为通过。
