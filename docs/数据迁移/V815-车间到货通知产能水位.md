# V815 车间到货通知产能水位

> 2026-10-06 · [ADR-165](../99-决策记录-ADR/ADR-165-车间到货通知产能水位与车间负责人受众.md)（修订 ADR-091 §2.3/§八）

## 改动

- `production_execution_segments` 新增列 `arrival_notice_capacity numeric(18,4)`：
  「物料到货进展」行动卡上次评估时的**可支撑产能水位**。NULL＝从未评估，按 0 对待。
- 只加列，不改存量数据、不加权限码、不建触发器。

## 行为

- `ChainNoticeService.publishWorkshopMaterialArrival` 每次到货事件按路线评估「当前可支撑产量」：
  - BATCH＝分批领料核对页的「当前可齐套生产量」（`ProductionExecutionBatchService.currentSplitCapacity`，
    与页面同一个数，剩余段自动扣前批）；
  - CONTINUOUS＝已备预留产能 `fn_execution_material_output_capacity(segment, FALSE)`；
  - FULL_KIT＝齐套全有或全无（WAITING 且全部缺口被盖住＝`planned_qty`，否则 0）。
- **只有当前产能 > 水位才发卡**（弹窗文案带「（现有物料可支撑生产 X 单位）」）；
  发卡或回落都把水位同步成当前值（`IS DISTINCT FROM` 值不变不写）。
  到货撤销（物料状态更新卡）不受闸门约束，仍即时通知并同步水位。
- 列只在通知投递线程（outbox delivery，段行 `FOR UPDATE` 锁内）更新；表为 FULL 行级审计，
  水位变化自然留痕，无需单独登记。

## 受众（同批 Java 改动，无迁移）

`workshopRecipientUserIds` 收窄为「车间子树各部门负责人 ∪ 任务负责人 ∩ 车间任务权限」；
计划部等职能岗个人加授权限也不收卡；车间无任何负责人时兜底回旧全成员池。
