# 10 - 颜色资料 · 老库溯源

> 本档记录老系统颜色资料源表 `B_Color` 的真实结构、数据现状与迁移约束。
> 新库设计与迁移见 [11-颜色资料-新库与迁移.md](11-颜色资料-新库与迁移.md)。
> 与货品/模具/客户/供应商资料同属基础资料（同标准、同流程），但**颜色是扁平字典（无分类树）**，与四主档「分类树 + 主档」双表结构不同。
> **建立时间**：2026-07-25 · **状态**：实地连老库 LocalDB 探查完成（PowerShell + SqlClient）

---

## 一、结论

- 老库颜色表 = **`B_Color`**（基础数据 `B_` 前缀，见 [01-YTDQ老库总览.md](01-YTDQ老库总览.md) §四）。
- **实测为扁平表**：`ParentID` 全部为 `0`（151 行无一例外），**并非早先文档/README 误称的「自引用树」**——本次探查更正。
- 货品通过 `B_Goods.MColorID`（INT）引用本表 `ID`（→ 新库 `goods.color_legacy_id`）。

## 二、老库表结构

### 2.1 `B_Color`（颜色字典，5 列）

| 列 | 类型 | 可空 | 含义 |
|---|---|---|---|
| `ID` | int | 否 | 主键（货品 `MColorID` 引用它） |
| `ColorName` | varchar(50) | 否 | 颜色名称（如 灰色/白银/香槟金） |
| `Number` | varchar(50) | 否 | 编号 |
| `ParentID` | int | 否 | 父级（**实测全为 0 → 扁平**） |
| `Status` | varchar(10) | 否 | 状态（使用/禁用） |

### 2.2 被引用关系

- `B_Goods.MColorID → B_Color.ID`（货品主颜色）。
- `B_Unit`（基本单位）见 [12-基本单位-老库溯源.md](12-基本单位-老库溯源.md)，与本表同构。

## 三、数据现状（实测）

| 维度 | 值 |
|---|---|
| 总行数 | **151** |
| 根（`ParentID=0`） | 151（全部扁平，无嵌套） |
| `Status` 分布 | 使用 141 / 禁用 10 |
| `ColorName` 空串 | 1 条 |
| `Number` 重复 | 有（`01`×18、`02`×2、`101/102/103`×2、`48`×2）→ **编号不唯一** |
| 货品实际引用 | 134 个不同 `MColorID`（17 个颜色未被任何货品引用） |

样例（`SELECT TOP 5 * FROM B_Color`）：`343 灰色/1/0/使用`、`344 白银/2/0/使用`、`345 白色/3/0/使用`、`586 枪色/01/0/使用` …。

## 四、数据质量风险（迁移必须处理）

- **名称噪音**：尾点（`拉丝.`、`铂银.`）、中文逗号（`铂金，`）、重复名（`铂银`×2、`铂金`×2）。→ 迁移**原样保留**（不擅自改义），用户可在 UI 禁用/删除；仅 `trim` 首尾空白。
- **空名称 1 条**：迁移时空串 → `NULL`（`NULLIF(BTRIM(...), '')`）。
- **编号重复**：`code` 列**不设 UNIQUE**（与货品/供应商一致）。
- **货品引用孤儿 4 个**：`B_Goods.MColorID` 出现 `0`(空值哨兵)/`94`/`194`/`424` 不在 `B_Color` 中。→ 新库货品颜色名称解析时这些解析不到 `name`，前端回落显 `#legacyId`（`0` 视为无颜色，`name` 为 null）。

## 五、字段映射初稿

| 老库 `B_Color` | 新库 `colors` | 转换 |
|---|---|---|
| `ID` | `legacy_id` | 直接（INT UNIQUE，溯源 + 重跑幂等） |
| `Number` | `code` | 直接（不唯一） |
| `ColorName` | `name` | `NULLIF(BTRIM(..., ' ' \|\| chr(12288)), '')`（去半角/全角空白，空串→NULL） |
| `Status` | `status` | 直接（使用/禁用） |

## 六、迁移数据源（已落盘）

- `server/legacy_migration/data/color.csv`（UTF-8 无 BOM，管道符 `\|` 分隔，首行表头 `legacy_id\|code\|name\|status`，RFC4180 引号转义）。
- 由 `export_legacy.ps1 ColorData` 从老库 `B_Color` 导出。

---

## 七、迁移要点（给迁移代码的输入约束）

1. **扁平入库**：无分类树、无 `parent_id`、无 `level/path`，仅 `legacy_id/code/name/status` 四业务列。
2. **trim + 空串→NULL**：`name` 去 `BTRIM` 含全角空格 `chr(12288)`，空串存 NULL。
3. **保留噪音行**：不删尾点/逗号/重复，保证货品 `color_legacy_id` 引用不悬空。
4. **幂等**：`TRUNCATE colors`（`session_replication_role=replica` 绕 FK）后重新 COPY+INSERT，可重跑。
5. **`code` 不 UNIQUE**：老库大量重复编号。
