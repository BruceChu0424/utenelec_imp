# 全平台表格表头检索、筛选、排序、汇总与右边线检查

日期：2026-10-28。当前状态：本次任务已完成，相关前后端回归与静态检查通过。

本次按用户连续确认的范围检查业务列表、详情、弹窗、报表、历史、修订和编辑表格。先读实际列定义、真实显示来源、分页和权限合同，再决定列的交互；搜索工具只用于定位入口，没有脚本按列名批量改配置。保留工作区其它并发改动，未提交、未打包、未部署或变更生产数据库。

## 一、交互判断

应用 `frontend-design`，沿用 Uten 组件、NotoSansSC 字体与现有主题 token。浅色基底 `#F8FAFC`，文字 `#0F172A`，边线 `#E2E8F0`，交互主色 `#0F766E`，错误强调 `#B91C1C`；深色模式继续使用主题的对应语义色。本次不另造主题或表格外观。

菜单按“搜索 → 排序 → 所有/候选/空值”组织；查候选与提交表格条件职责分清。按用户最终纠正，左侧搜索图标删除，ⓘ放输入框内部右侧；范围/单位/语法只悬停或点按、键盘焦点时弹面板，不常驻占行。桌面默认绘制高度36，绿色搜索按钮与输入框边框上下及高度相同，大字号和触控按实际文字/命中要求自适应。浮层继续随缩放、窗口、键盘和锚点移动重新布局，搜索与选项可滚动。

| 实际数据职责 | 采用的方式 | 保留的边界 |
|---|---|---|
| 单号、名称、编号、规格、备注 | 独立文字条件、必要的精确候选与排序 | 多列条件求交集；显示值与检索字段保持相同来源 |
| 状态、币种、单位、类型、部门等 | 可搜索的精确候选，组织/分类继续用树 | 用真实 ID/状态编码，不用翻译后的名称替代业务关系 |
| 单值数量、金额、计数 | 精确数字、比较和闭区间；适合时数值排序 | 不经 double 丢精度；未知/隐藏不作零；汇率/比例/单价/余额不求和 |
| 日期与时刻 | 年/月/日或闭区间；适合时先后排序 | 时刻由服务端转中国业务日；LocalDate 不偏移日期；历史不猜补未知日 |
| 重量 | 已有明确单位的范围合同，或带单位显示候选 | 输入 g/kg/t 与 canonical kg 不直接用裸数字比较；估算标记不当实称 |
| 多单位、多币种与聚合数量 | 保留分组和各自权威合计；聚合后筛选 | 不把 SUM 塞入错误的源行 WHERE，不把不同单位相加 |
| BOM/父子行/日报产品与物料 | 命中后保留所属完整上下文组 | 不打散树，不把筛选后可见行当完整提交模型，不自行展开折叠节点 |
| 修订前后快照 | 命中一侧保留完整修改前后组 | 不任意排序破坏配对，不把旧值与新值相加 |
| 操作、选择、固定资格与整批执行清单 | 保留实际动作及资格控制 | 不给“查看/审核/删除”按钮制造无意义数据搜索；不隐藏必须核对的执行项 |
| 纸面打印、标签、固定权限目录/核对表 | 保留其版式、完整输入或目录搜索 | 不把文档版式或权限矩阵机械改成业务列表 |

## 二、唯一公共入口

| 能力 | 实现与合同 |
|---|---|
| 阅读表格 | `lib/features/basic_data/widgets/master_data_table_view.dart`；服务端分页仅开放声明的 `serverColumnSearchKeys`/原有服务器合同，禁止当前页假检索 |
| 编辑表格 | `lib/components/layout/uten_editable_grid.dart`、`uten_grid_header_filter_cell.dart`；必须有真实文本/精确值和监听源，检索只改变视图，不删源行或修改提交范围 |
| 菜单自适应 | `lib/components/layout/uten_table_header_menu.dart`；阅读表和编辑表共用几何与滚动，Overlay 坐标转换兼容应用整体缩放 |
| 十进制条件 | `lib/shared/search/numeric_column_query.dart` 与服务端 `NumericColumnFilter`；数字默认精确相等，支持 `= != > >= < <=`、`-5..5`，最多128字符，非法条件保留输入并提示 |
| 日期条件 | `lib/shared/search/calendar_column_query.dart` 与 `JpaColumnSearch.businessDateBounds`；统一年/月/日与闭区间语法，本地日期不把相对时间/不完整日猜补成事实 |
| 服务器 typed 查询 | `JpaColumnSearch`、`SqlColumnSearch` 与各领域固定表达式白名单；所有值参数绑定，条件位于正确聚合层及 count/page 之前 |
| 层级上下文 | `lib/shared/search/retain_hierarchy_filter_context.dart`；公共 Master/Grid 的 `filterContextRows` 由调用方定义实际分组，保留原顺序和对象身份 |
| 草稿/历史包装 | `form_draft_category_table.dart` 转发声明、范围说明和记录上下文；历史/修订保留敏感性、精确原文及显式禁用配置 |
| 右侧闭合线 | `UtenTableRowRightEdge` 与 `UtenTableCellFrame`；单格边线画于内容前景，不透明表头/编辑器不能遮线；行闭合覆盖拟合空白，随内容横滚 |
| 上游引入 | `uten_doc_link_picker_sheet.dart` 唯一状态机；采购/委外/销售三链路把单号、往来方条件传给完整已审服务器查询，保留来源上限和旧响应隔离 |

原来的阅读/编辑菜单宽高计算合并到同一个公共入口；没有在每个业务页面复制弹层。服务端业务算法、币种、单位、价格和库存归属不为 UI 统一而合并。针对不同源、聚合层和权限的必要字段差异留在显式领域配置。

## 四、有界报表打印

额外核实到旧预览虽然声明最多前2000行，却一次请求 `size=2000`，服务端可将页长钳制到500或更低。单页请求不能保证取到声明的前缀。

新公共入口 `lib/features/report/shared/report_print_preview.dart` 用真实分页读取原有前2000行上限，保留重复的单据头 ID 明细，关闭无关 count/facets/totals 扫描；短页不是结束证明。条件、排序、权限/身份与读取代次固定，首批列定义冻结，逐格让帧，读取范围/字段发生变化即拒绝发布半成品。

迁移：采购、委外、仓库、生产计划、销售主报表和客户下钻、财务报表、往来对账、应收应付概览、账户流水。仓库继续使用所选重量显示单位；账户流水保持原入账顺序。已有 `loadCompletePrintSnapshot` 用于必须完整且有唯一实体 ID 的主档/库存打印，合同不同，本次保留，不将2000行上限套给它。
