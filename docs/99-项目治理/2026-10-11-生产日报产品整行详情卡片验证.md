# 生产日报产品整行详情卡片验证

本次为 2026-10-11 对日报新建／编辑页的结构调整，继续在隔离分支 `uimp/daily-report-surplus-review` 实现。没有修改主工作区或部署。后续根据实际使用反馈改为永久竖排、货品列缩进、淡色背景与有背景色的折叠按钮，并复核精确数量链路；当前验证见 [竖排卡片与数量链路复核](2026-10-11-生产日报竖排卡片与数量链路复核.md)。下方测试表保留第一次详情卡片调整的验证记录，不替代后续源码验证。

## 最终结构

- 主表仅放报工产品，默认保留列顺序：货品名称、编号、颜色、完工申报量、超限原因、不良数、来源子任务、备注。领料量、本次实际用料、产出去向、去向数量从主表列和表头设置中移除。
- 每个产品下面的整行详情组件不受主表列宽限制。产出去向在上、子件用料在下，所有宽度均竖排，左边缘按共享选择列宽从货品列起点缩进。去向淡青、用料淡蓝灰，输入框保持原主题。卡片各有自然高度，短表没有填充空行。
- 去向卡片按工单／接收名称／去向数量单行显示；用料卡片按名称／编号／颜色／领料量／本次实际用料单行显示。完整名称、菜单项及受限原因可查看全文。材料输入列 192px 是按真实应用字体、单位与信息图标测量得出的宽度，`10850.1234` 未聚焦时无内部横滚、四位尾数全部可见。
- 两区独立折叠，头部始终显示条数、数量核对或填写状态，采用明确的深绿背景按钮，支持键盘和只读浏览。折叠正在编辑的去向区先完成原有失焦处理；多个货品的折叠状态、手工值和来源不会串行。
- 详情按当前面板宽度布局，主表横滚时补偿其位移；不是额外主表行，不参加选择、复制、删除或导出行数。

## 数据与共享组件

去向全集仍在产品的 `allocationRows`，用料全集仍在页面的 `_materialRowsByProduct`／`_allMaterialRows`。卡片复用原有数量和实耗单元构建器、控制器及业务回调，折叠／筛选／横滚不改变 UUID、额度、登记或提交。删除产品与换来源后，卡片事实在输入框拆下后释放；共享用料仍只有一份可写事实，镜像直接显示四位小数原文。

`UtenEditableGrid.rowDetailsBuilder` 为可选 API，默认 null 保留既有宿主行为。通过稳定产品身份维持插入／删除／筛选后的详情状态，已验证 LTR／RTL、动态高度、滚条、冻结列和键盘输入。

共享 `UtenDropdownField.selectedLabel` 仅影响收起文本，完整菜单／搜索／AI 字段事实仍保留原标签及业务 value；同名项按 value 区分。普通菜单悬停全文采用可布局定位的 overlay，修复当前 SDK 下 Follower 内 Tooltip 的断言。菜单项新增稳定 key，清空项与合法 null value 项使用不同命名空间。
