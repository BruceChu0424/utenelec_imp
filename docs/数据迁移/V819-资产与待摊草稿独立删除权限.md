# V819 资产与待摊草稿独立删除权限

用户要求删除与编辑分开配置。原资产工作台将草稿删除并入 `finance_asset:edit`，导致只授权编辑也能够删除。V819 新增 `finance_asset:delete`，动作类型为 DELETE，挂到 `finance.asset`，钱流父页通过现有层级包含它。

默认零授权，不把已有编辑权转为删除权。沿用资产编辑的管理边界 `NON_DELEGABLE + BULK_EXCLUDED`，由超管显式配置；超管自身仍按既有全目录策略生效。原查看、编辑、审核、过账、处置权限不变。

两类单据的 DELETE 控制器、工作流服务及 `allowedActions` 统一使用新权限。前端新增独立删除能力，行菜单和详情页据此展示，并在确认弹窗结束后重验当前权限。数据库操作仍锁定当前单据、检查草稿状态及预期版本；不得删除待审、已审或已过账记录。

回归覆盖只有编辑不能删除、只有删除不能编辑、撤权后拒绝、错误版本拒绝、非草稿拒绝、超管保留能力，以及全迁移后新码零授权。收付款类别 DELETE 实际始终拒绝并要求禁用，个人申请取消及主档附属字段移除不是整份业务记录删除，本次不新增空权限码。本说明不代表业务服务器已经安装。
