# ADR-168：常用模块权限分组

- 日期：2026-10-08。
- 状态：用户授权实施；源码及本地回归不代表公司服务器已部署。
- 遵循 ADR-109（权限目录单一事实源）与 V228 定下的约定：module 归类的权威在迁移链上，后续改动在各自迁移里直接写。

## 1. 背景与需求

工作台「常用功能」组的五张卡（我的访客 / 基础资料 / 工资条 / 我的报销 / 意见箱）里，四张自助卡对应的
权限码原先散在「人事行政」模块的访客 / 工资条 / 报销 / 意见箱子类里。管理员要控制"谁的工作台上看得到
工资条"这类诉求时，必须在目录里翻找分属不同子类的码，控制面不直观。

用户要求：权限设置页面里出现一个「常用模块」分组，里面有这几项；有权限的人才看得到这些卡片，
"不给你工资条就没得显示"。

## 2. 决策

**只归组、不加码、不改判定。**

1. 新一级模块「常用模块」（V831），收四个既有自助码，子类与工作台卡片同名、sort_order 按卡片顺序固定：

   | 码 | 名称 | 子类 | 卡片 | 默认来源 |
   |---|---|---|---|---|
   | `visitor:host_confirm` | 接待访客 | 我的访客 | 我的访客 | V679 部门白名单（NON_DELEGABLE） |
   | `payroll:view:self` | 查看本人工资条 | 工资条 | 工资条 | 全员基础包 |
   | `expense:apply` | 提交报销申请 | 我的报销 | 我的报销 | 全员基础包 |
   | `suggestion:submit` | 提交建议 | 意见箱 | 意见箱 | 全员基础包 |

2. `DepartmentPermissionAdminService.MODULE_ORDER` 把「常用模块」排在目录最前；按员工 / 按部门 /
   全员基础包三段视图同一份目录，全部生效。
3. 卡片显隐判定**不变**：仍是路由守卫 `requiredAnyPermFor` 那一份（ADR-109 单一数据源），收回权限
   → 卡片消失且直达路由被拦，不会出现"卡片在、页面 403"或反之的分裂。
4. 管理码不动：`payroll:view:all/generate/review/publish/export`、`expense:approve/pay/settings`、
   `visitor:approve/check_in/verify/blacklist`、`suggestion:reply` 留在「人事行政」各自子类。
5. 授权策略与基础包口径不动：三码仍在全员基础包（~~要整体关掉就到「全员基础包」页移出，再按部门 /
   个人加授~~ **2026-10-09 起该口径由 ADR-170 废止：三码已是钉死码，管理页不可移出**），接待访客仍是 V679 白名单码。V831 只 UPDATE `module/category/sort_order`，
   迁移内失败关闭断言锁定"分组恰好四码 + baseline / grant_policy 维持 V677/V679 现状"。

## 3. 边界：基础资料卡不设单一码

工作台「基础资料」卡落点是 `/basicinfo` hub，显隐 = hub 守卫 = 子卡守卫并集（货品 / 客户 / 供应商等
十余个主档 view 码，ADR-109 §3.7，`hub_guard_union_test` 锁定）。为它造单一入口码要么破坏
「持任一子卡码即可进 hub」的并集不变量，要么造出"能开门但屋里全空"的空 hub 码，都被否决。
权限管理页的「基础资料」模块（与卡片同名）就是它的控制面：持任一主档查看码的人看得到卡，
一个查看码都没有的人看不到。

## 4. 影响面

- 迁移 `V831__common_module_permission_group.sql`（只 UPDATE 目录归类 + DO 断言）。
- `DepartmentPermissionAdminService.MODULE_ORDER` 置首；前端零改动（目录分组本就由服务端下发）。
- 契约锁定：`CommonModuleCatalogMigrationPostgresTest`（真库断言四码就位 + 策略 / 基础包不变 +
  管理码留在人事行政）、`DepartmentPermissionAdminServiceTest.catalogLeadsWithTheCommonModuleGroup`
  （目录排序）、`FeatureDirectoryAndAccessToolsTest` 夹具同步（AI 聊天回复里的「模块 · 子类」展示）。
- 文档同步：权限管理页.md（目录 13 模块）、工作台首页.md（常用功能卡与权限映射）、
  页面总览.md（common 行，顺带修正不存在的「公司通知」与误写的 `visitor:approve`）、
  权限体系总设计.md §三（补"常用功能卡不新建码"口径）。
