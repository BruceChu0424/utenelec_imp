# V457 货品后模镶件编号（rear_insert_code）

> 2026-09-02。迁移文件：`server/src/main/resources/db/migration/V457__goods_rear_insert_code.sql`
> 关联：[货品资料页面说明](../03-页面/基础资料页.md)、[迁移总索引](README.md)

## 一、背景

部分模具生产不同货品时需要**更换后模镶件**，模具师傅经常换错。老系统里这一信息只写在
货品备注（老库 `B_Goods.Paper`，自由文本，如「换后模平镶件」「换后模45A镶件」
「换后模1M仁镶件」），不结构化、无法筛选、打印时淹没在一堆杂项备注里。

本次在货品主档上新增独立字段「后模镶件编号」，紧跟模具编号展示，作为生产该货品时
需使用的后模镶件标识（模具师傅对板换件依据）。

## 二、数据库与回填口径

- `goods.rear_insert_code varchar(100)`：自由文本短码（如 `平` / `45A` / `1M仁` / `V7-012`）。
  **不建镶件主档**——现网写法五花八门，先落结构化短码，后续如需字典再升位。
- 存量回填只认**点明「后模」**的两类写法（保守解析，口径 V457 与 `migrate_goods_data.sql` 完全一致）：

| 老备注写法 | 解析结果 |
|---|---|
| `换后模平镶件` / `换后模45A镶件` / `换后模1M仁镶件` | `平` / `45A` / `1M仁`（正则 `换后模(.{1,30}?)镶件`） |
| `换前模芯V7-012  后模镶件用V7-012` | `V7-012`（正则 `后模镶件用([^ \t，。;；]{1,30})`） |

- **以下一律不回填、保持 NULL**（备注原文照迁不动，留人工判断）：`换镶件`、`换6M镶件`、
  `换多控镶件`、`换前模镶件`、`共用UT模具`、`外购/外加工` 等未点明后模或无镶件标识的写法。
- `goods.paper`（备注）**一字不动**：新字段是解析出的结构化短码，备注保留完整原文上下文。

## 三、老库重迁（migrate_goods_data.sql）

`INSERT ... SELECT` 中 `rear_insert_code` 以同一对正则从 `goods_stage.paper` 派生
（`COALESCE(换后模X镶件, 后模镶件用X)`），保证将来从老库刷新数据与 V457 存量回填口径一致；
export 侧无需改（Paper 本就在导出列里）。

## 四、服务端 / 前端接线

- 列表 `GoodsListItem` + 详情 `GoodsDetail` 新增 `mouldCode`（模具编号，UUID 关系优先、
  历史 UUID 缺失回落 legacy 快照批量解析）、`rearInsertCode`、`paper`；备注列数据源从
  `requireRemark`（老库 Require 迁移残值，真实迁移恒空）切到 `paper`。
- 筛选：`rearInsertCode`/`paper` 进 facets 与精确等值过滤；`mouldCode` 精确等值（LEFT JOIN，
  无模具货品不被整支 OR 过滤掉）；keyword 搜索新增匹配 `paper` 与 `moulds.code`
  （对齐老系统「按模具编号搜货品」习惯）。
- 导出/打印：Excel 导出列与页面打印列在「客户型号」后依次增加「模具编号」「后模镶件编号」，
  「备注」列改取 paper。
- 货品编辑表单新增「生产」组：模具（搜索选择模具主档，提交 `mouldId` UUID）+
  后模镶件编号（文本）；「基础」组补「备注」（paper）文本字段。查看态分组同步。
