# 12 - 基本单位 · 老库溯源

> 本档记录老系统计量单位源表 `B_Unit` 的真实结构、数据现状与迁移约束。
> 新库设计与迁移见 [13-基本单位-新库与迁移.md](13-基本单位-新库与迁移.md)。
> 与颜色资料（`B_Color`）同构，同属基础资料扁平字典。
> **建立时间**：2026-07-25 · **状态**：实地连老库 LocalDB 探查完成（PowerShell + SqlClient）

---

## 一、结论

- 老库单位表 = **`B_Unit`**（基础数据 `B_` 前缀，见 [01-YTDQ老库总览.md](01-YTDQ老库总览.md) §四；存储过程 `B_UnitItem_PROC` 亦涉单位）。
- **与 `B_Color` 同构**（`ID/名称/Number/ParentID/Status`），**实测扁平**（`ParentID` 全 0，66 行）。
- 货品通过 `B_Goods.UnitID`（INT）引用本表 `ID`（→ 新库 `goods.unit_legacy_id`）。

---

## 二、老库表结构

### 2.1 `B_Unit`（计量单位字典，5 列）

| 列 | 类型 | 可空 | 含义 |
|---|---|---|---|
| `ID` | int | 否 | 主键（货品 `UnitID` 引用它） |
| `Unit_Name` | varchar(50) | 否 | 单位名称（如 个/套/只/kg） |
| `Number` | varchar(50) | 否 | 编号 |
| `ParentID` | int | 否 | 父级（**实测全为 0 → 扁平**） |
| `Status` | varchar(10) | 否 | 状态（使用/禁用） |

> 注：列名是 `Unit_Name`（带下划线），与颜色的 `ColorName`（驼峰）不同，迁移时注意取数。

### 2.2 被引用关系

- `B_Goods.UnitID → B_Unit.ID`（货品计量单位）。

## 三、数据现状（实测）

| 维度 | 值 |
|---|---|
| 总行数 | **66** |
| 根（`ParentID=0`） | 66（全部扁平） |
| `Status` 分布 | 使用 66（无禁用） |
| `Unit_Name` 空串 | 1 条 |
| 货品实际引用 | 23 个不同 `UnitID`（43 个单位未被引用——多为噪音行） |

样例：`92 个/1`、`93 套/2`（`Unit_Name` 有前导空白 ` 套`）、`94 只/3`、`108 kg/17`、`109 g/18` …

---

## 四、数据质量风险（迁移必须处理）

- **非单位污染**：`Unit_Name` 混入换算系数（`1`/`2`/`0.1`/`0.12`/`0.0005`…）与产品描述（`单联单控开关7`、`16A三极插座`、`二二三极插座(七孔）` 等）。→ 迁移**原样保留**（不擅自删，保证货品 `unit_legacy_id` 引用不悬空），用户可在 UI 禁用/删除。
- **前导空白**：` 套` 等 → 迁移 `BTRIM`（含全角空格）。
- **空名称 1 条**：空串 → `NULL`。
- **`Status` 全 使用**：老库无禁用单位；列保留 `使用/禁用` 双值供后续维护。
- **货品引用孤儿 0 个**：所有 `B_Goods.UnitID` 均能在 `B_Unit` 找到。

## 五、字段映射初稿

| 老库 `B_Unit` | 新库 `units` | 转换 |
|---|---|---|
| `ID` | `legacy_id` | 直接（INT UNIQUE） |
| `Number` | `code` | 直接 |
| `Unit_Name` | `name` | `NULLIF(BTRIM(..., ' ' \|\| chr(12288)), '')` |
| `Status` | `status` | 直接（使用/禁用） |

---

## 六、迁移数据源（已落盘）

- `server/legacy_migration/data/unit.csv`（UTF-8 无 BOM，管道符分隔，表头 `legacy_id\|code\|name\|status`）。
- 由 `export_legacy.ps1 UnitData` 从老库 `B_Unit` 导出。

---

## 七、迁移要点（给迁移代码的输入约束）

1. **扁平入库**：无分类树，仅 `legacy_id/code/name/status`。
2. **trim + 空串→NULL**：`name` 去 `BTRIM` 含全角空格，空串存 NULL（修 ` 套` 前导空白）。
3. **保留噪音行**：换算系数/开关插座名原样，保证货品引用不悬空。
4. **幂等**：`TRUNCATE units` 后 COPY+INSERT，可重跑。
