# 财务报表页

> 路由：`/finance/report`（计划：`lib/features/finance/pages/finance_report_page.dart`）· Phase 3
> 上层：[Phase3-财务端总览](Phase3-财务端总览.md)

## 一、定位

finance 查看月度/季度财务汇总（报销、工资、部门成本），支持导出。图表 Phase 3 用占位，Phase 5 选定图表库后替换（见 [技术选型 §9](../01-规划/技术选型.md)）。

## 二、入口与导航
- 进入：finance 主导航「财务报表」。
- 离开：导出 → 下载文件。

## 三、响应式布局

顶部筛选 + KPI 卡 + 图表区 + 明细表。

- expanded：
```
┌──────────────────────────────────────────────┐
│ 财务报表  月份[2026-07▼] 范围[全公司▼] [导出] │

│ ┌──────┐┌──────┐┌──────┐                     │  ← KPI 卡
```

- compact：KPI 卡 2 列 + 图表纵向堆叠 + 表格转卡片。

## 四、涉及的 Uten 组件
`UtenAppBar`（视角+月份选择+导出）/ `UtenViewContextSelector` / `UtenStatCard`（KPI）/ `UtenChartPlaceholder`（Phase 5 换 fl_chart/syncfusion）/ `UtenDataTable`（明细）/ `UtenDropdown`（月份/范围）/ `UtenButton`（导出）/ `UtenEmpty`。

## 五、功能点
1. **筛选**：月份、范围（跟随视角：部门/全公司）。
2. **KPI**：报销总额、工资总额、部门成本、环比。
3. **图表**（占位）：报销趋势折线、部门成本占比饼、工资构成柱状。
4. **明细表**：可下钻的报销/工资明细。
5. **导出**：Excel/PDF（权限 `payroll:export`，导出走审计日志）。

## 六、功能链路图
```mermaid
flowchart LR
    F[选月份+范围] --> Q[查报表数据]
    Q --> K[KPI+图表+明细]
    K --> EX{导出}
    EX --> FILE[Excel/PDF+审计]
```

## 七、涉及的数据实体
`ExpenseClaim`（报销汇总）/ `PayrollSlip`+`PayrollBatch`（工资汇总）/ `Department`（成本维度）/ `AuditLog`（导出审计）。

## 八、权限要求
- finance / manager（只读）/ admin。
- 权限点：`payroll:view:all`（看全员薪资汇总，敏感）、`payroll:export`。
- manager 只读不看个人薪资明细，只看汇总。

## 九、边界情况
- 无数据：图表区 `UtenEmpty`「该期间暂无数据」。
- 导出大数据量：后台生成 + 通知下载（不阻塞 UI）。
- 性能档 lite：图表降级为静态数字表格（不渲染图表）。
- 网络：报表缓存上次结果 +「离线缓存」提示。
