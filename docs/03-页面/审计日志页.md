# 审计日志页

> 谁在什么时候做了什么：**导出下载 / 登录 / 改密 / 系统设置变更 / 数据变更**（DB 触发器）。超级管理员只读。
>
> 位置：`lib/features/admin/pages/admin_audit_log_page.dart`
> 后端：`server/.../audit/`（`AuditController` GET + `AuditQueryService` + `AuditLogRepository`；写侧 `AuditService.logExplicit` + 表触发器）。

---

## 入口

工作台 → 系统管理 →「审计日志」卡片。路由 `/admin/audit-logs`，`/admin/` 前缀守卫 `user:manage`。

---

## 功能

- **7 列**：时间 / 操作人 / 动作 / 对象类型 / 对象·说明 / IP / 结果（`MasterDataTableView`）。
- **动作 chip**（前缀匹配后端 action）：全部 / **仅导出** / 登录 / 改密 / 数据变更。
- 操作人账号搜索（LIKE）+ 翻页（按 `createdAt` DESC）。

---

## 审计记录什么

| 字段 | 说明 | 示例 |
|---|---|---|
| `actorAccount` | 谁 | `admin` |
| `createdAt` | 何时 | `2026-07-27 14:32` |
| `action` | 做什么 | `export_purchase_report` / `login` / `update_system_setting` / `insert`/`update`/`delete` |
| `targetId` | 对象·说明 | `order/detail/1234rows` / `lockout_minutes: 5 → 30` |
| `ip` / `result` | 来源 IP / 成功失败 | `192.168.1.x` / `success` |

---

## 写侧（事件落 audit_log）

- **显式事件**（`AuditService.logExplicit`）：数据导出（`export_*_report`/`export_*`）、登录、改密、改系统设置（`update_system_setting`）。
- **数据变更**（DB 触发器 `fn_audit`，V22/V23）：业务表 AFTER INSERT/UPDATE/DELETE 自动落审计。

---

## 读侧

`GET /api/admin/audit-logs`（`@PreAuthorize('user:manage')`，`JpaSpecificationExecutor` 参数化分页）：`action` 前缀模糊、`actorAccount` 子串模糊、`dateFrom`/`dateTo` 闭区间、page/size。返回 `PageResponse<AuditLogRow>`（不含 before/after JSON、user_agent，保留 ip）。
