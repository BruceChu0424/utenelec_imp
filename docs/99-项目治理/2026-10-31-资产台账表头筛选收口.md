# 资产台账表头筛选收口

本次是前端呈现与交互调整，按 `frontend-design` 复用现有 Uten 主题及组件。任务分支：`uimp/asset-header-filters-20261031`。

用户要求删除资产与待摊列表搜索框后方的状态、分类、归属部门和重置筛选，统一使用表头筛选。保留表头设置、全屏、草稿、编号/名称搜索及业务操作。

## 调用方与公共入口

| 平台 / 入口 | 实现与状态 |
|---|---|
| Web / 固定资产、长期待摊 | `FinanceAssetsPage` → `FinanceAssetWorkbenchPage` → `FinanceAssetLedgerPanel`，共用本次修改 |
| Flutter 桌面 / 固定资产、长期待摊 | 同一页面及组件，同步修改；无平台分支 |
| WPF / 资产工作台及旧资产入口 | `work-items.json` 中 W7-BIZ-060、W7-BIZ-061 仍为 todo、nativeTargets 为空；没有已迁移同责页面，本次不标完成 |

公共表头菜单仍由 `MasterDataTableView` 维护。状态使用原业务状态集；分类接入列专属 `facetPageLoaders`，保留分类编号/名称查找、加载失败及重试。原分类缓存继续用于本地草稿名称展示及搜索，并保留请求代次与身份退役时的缓存清理。

部门表头继续调用 `showUtenDepartmentPickerPanel`，为可选筛选启用新增的 `allowClear` 参数。清空仅修改面板暂存值，确定后才清除条件，取消保留原筛选。其他调用方默认保持原有必选行为。部门树、完整路径和 UUID 查询关系保留。

已删除工具栏的三项重复筛选、重置按钮、窄屏“筛选”按钮及其重复弹窗、失效方法和导入。两类台账共用一套实现。后端 API、金额计算、权限、草稿写入、幂等及未知提交合同没有变更。
