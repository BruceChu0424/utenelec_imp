# 委外发料单页(委外材料出仓单)

- **业务依据**：[ADR-143 委外按工序领直属物料、齐套通知、分批回厂](../99-决策记录-ADR/ADR-143-委外按工序领直属物料与分批回厂.md)；链路见[委外全链路 SOP](../07-业务链路/08-委外全链路-订货出仓回仓重设计.md)。
- **迁移**：[275-V798](../数据迁移/275-V798委外按工序领直属物料与分批回厂.md)。

委外材料出仓单(单据类型 EC)记录发给委外商的**直属物料**：委外件 P 的每种可发外直属物料，
按财务批准时冻结的单耗与颜色发出，委外商加工后交回 P。一张出仓单 = 委外人员一次领料提交里
「同一订货单 × 同一仓库」的物料，可以有多种物料、多行。

出仓单的唯一来源是委外任务中心「待处理·领料」：委外人员提交领料时服务端新建草稿(每行写明领料数量)，
仓库在[仓库委外出仓工作台](仓库委外出仓工作台页.md)核对、只能改少、审核出仓。本页是委外管理里的
**查看、核对与红冲**入口，不放仓库拣货动作。

## 一、页面与权限

- 列表：`/subcontract/material-issues`(委外 Hub「出仓单据 → 委外材料出仓单」)
- 详情：`/subcontract/material-issues/{id}`
- 新建：`/subcontract/material-issues/new` 不开放，页面说明「委外材料出仓单由委外人员在委外任务中心「待处理·领料」提交后生成」并给出任务中心入口；服务端手工新建同样拒绝。
- 查看权限：`subcontract_material_issue:view`；红冲：`subcontract_material_issue:reverse`；草稿拣货保存与审核只在仓库工作台，叠加 `subcontract_outbound:execute` 与 `subcontract_material_issue:edit/approve`。
- 列表列：单号、日期、委外商、发出仓、出仓状态等公共列(货品身份按名称 / 编号 / 颜色各一列)。
- 委外订货单详情的进度区点出仓单号进入本页只读详情。

## 二、单据状态

| 单据状态 | 页面行为 | 业务含义 |
|---|---|---|
| 草稿(待仓库发料) | 只读查看；拣货与审核在仓库工作台；撤回由委外人员在任务中心按订货明细办理 | 已占用库存与专属归属，但不是已发料事实，不影响委外商处台账 |
| 已审核 | 只读查看；有权限时可红冲 | 真实出库流水，已发净量已增加 |
| 已红冲 | 只读 | 保留正反向审计链 |

草稿不能删除、不能加行、不能改货品；仓库只能把数量改少(不超过领料数量)。

## 三、明细与守恒

- 每行挂一条领料计划行：物料、冻结颜色、单位与领料数量来自提交时的计划行，`planItemId` 与订货明细逐行保留，回厂交回的委外件(名称、编号)随行显示。
- 详情明细各数量列(数量/已收/已退/已损耗/在供应商处/已消费/供应商结存/冻结单耗/结案损耗)按
  2026-10-10 全站「数量 + 单位」口径内联单位显示(如 `12 PCS`)，不再有独立「单位」列。
- 审核：材料出库 + 委外商处台账增加 + 领料计划行已发净量增加(CAS 不超过计划量)。
- 下游可处理量只从具体出仓明细计算：在委外商处 = 发出 + 补发 − 已退回 − 已记损耗，由服务端锁定来源行、防并发超退或超损耗；回厂核销按每种物料的目标量逐张出仓单先进先出切片。
- 材料退(余料退回)审核：公司仓入库，增加来源明细的已退回量，并减少该物料的已发净量，退回的料重新入库后可再次领料；退料红冲反向加回(已被重新领出导致超计划量则拒绝)。
- 损耗审核：增加来源明细的损耗量。材料发出时已经离开公司仓，损耗不再扣公司库存。
- 红冲出仓：反向入库、已发净量回减；已有下游回厂核销、材料退或损耗的出仓单先红冲下游。
- 所有数量以货品当前基本单位校验；来源与明细换算率不一致时服务端拒绝审核。
