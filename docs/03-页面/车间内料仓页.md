# 车间内料仓页

> 2026-09-28 新增, 设计依据 [ADR-131 车间整批领料与盘点计耗](../99-决策记录-ADR/ADR-131-车间整批领料与盘点计耗.md)。上线顺序与日常用法见[车间内料仓上线与使用说明](../07-业务链路/车间内料仓上线与使用说明.md)。

车间内料仓是车间自己的料架 (原名线边仓)。颗粒这类"整批领料"的料由仓库按袋整批发进来, 只换位置、不算耗用; 车间照常报工, 不按工单领料。本页给车间看"内料仓里现在有多少、估计还剩多少", 并办理申请领料、退回、登记试模清机等用料, 以及进入盘点。

## 入口

- 工作台"生产部"一组, 紧挨"车间生产任务"的「车间内料仓」卡 (不挂数)。
- [我的车间任务页](我的车间任务页.md) 顶栏的「车间内料仓」按钮, 直接带上当前车间。
- 通知里"报工没审, 车间内料仓结不了账""请补产品的单个重量""有料没发进内料仓却已经在用"三类提醒, 点开落到本页。

车间成员只看得到、只办得了本车间的内料仓; 其他部门有查看权限的人可以切换看全部车间。还没有开启整批领料的车间, 页面提示"请找仓库在「车间内料仓设置」里开启"。

## 页面内容

**顶部状态条** (本期起止与结算状态, 服务端算好, 页面只显示):

| 状态 | 显示 |
|---|---|
| 开着 | 本期起始日; 可以正常领料、退回、登记 |
| 盘点中 | "正在盘点。盘完点「提交盘点」, 系统会自动结算。" 盘点开始后发的料自动算到下一期 |
| 已盘点, 结算中 | "已盘点, 系统正在自动结算, 稍等片刻就好。" 页面自动轮询 |
| 已盘点, 被拦住 | 列出"差什么、谁来补" (例如"还有 3 张报工没审核, 负责: 报工审核人或制单人"), 补完后系统自动结算 |
| 已盘点, 结算没成功 | "结算没成功, 系统会自动再试", 附最近一次失败原因的大白话 |
| 已撤销结算 | "已撤销结算, 改完请点「重新结算」; 24 小时后系统会自动重新结算" |
| 已结算 | 结算时间与经办人 |

**现存表** (每种料一行): 料号、料名、颜色、估计还剩 (公斤)、账面 (公斤)、上次盘点 (日期与数量, 没盘过显示"还没盘过")、本期领入、本期退回、其它耗用、估计已用、仓库还有, 以及提示列:

- "估计已用" = 本期已审报工量 × BOM 单个重量, 是估算, 盘点结算后才是实际用量。
- "估计还剩" = 账面 − 估计已用, 用来判断要不要申请领料。
- 提示列: "有 N 个产品没填单个重量, 估计已用偏少""有 N 张报工还没审"。

内料仓里还没有料时, 表格位置显示"仓库直接发料或车间申请领料后, 这里会显示每种料的现存"。

**记录**: 本车间的领料申请、退回申请与完成情况 (单号、类型、来源、料、状态、申请人、申请时间、完成时间); 待处理的申请可以取消 (填原因)。

## 能办的事

按钮是否出现只看服务端随数据给的"可办动作", 没有权限的人看不到按钮。

| 按钮 | 做什么 | 说明 |
|---|---|---|
| 申请领料 | 选料, 填公斤或袋数 (袋数按每袋净重自动算公斤, 可再改), 可多种料一起 | 只列整批领料的料; 同时显示"仓库还有 X 公斤""内料仓估计还剩 Y 公斤"; 提交后只生成申请并通知这批料所在仓的仓管, 不动库存 |
| 退回 | 选内料仓里有的料和公斤数 | 提示"只退没拆袋、没掺色母的料"; 仓库按实收确认后料才退回仓库 |
| 试模清机等用料 | 选料、公斤数、用在哪 (试模 / 清机 / 报废料 / 其它, 选"其它"要写说明) | 当场从内料仓记出, 记车间费用, 不摊给产品; 用量报表单列 |
| 盘点 | 进入[车间内料仓盘点页](车间内料仓盘点页.md) | 有盘点权限才出现 |
| 立即重试 / 重新结算 | 被拦住的事补完后不想等, 或撤销结算后改完了 | 有盘点权限才出现 |

所有提交都带防重复标记: 网络不稳定没确认结果时, 填写的内容保留, 再点一次不会重复登记。

## 不在本页做的事

- 认料 (新产品第一次开工选用哪种料) 与换料在[我的车间任务页](我的车间任务页.md)的开工确认表和行菜单里办。
- 仓库发料、收退回在[车间内料仓发料页](车间内料仓发料页.md)。
- 用量、浪费率、产品单耗与撤销结算在[车间内料仓用量与结算页](车间内料仓用量与结算页.md)。
