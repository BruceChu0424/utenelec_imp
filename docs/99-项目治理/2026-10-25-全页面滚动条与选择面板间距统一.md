# 全页面滚动条与选择面板间距统一

日期：2026-10-25。范围：本地 Flutter UI 修改；未提交、推送、打包或部署。沿用 `frontend-design`、Uten 主题及业务交互，不改服务端、数据库和业务计算。

## 用户要求与根因

用户要求各页面一起排查：下拉选项不显示上下滚动条，页面和组件的竖条移到内容外侧留白，宽屏页面外壳占满可用宽度，并修复不同分辨率和界面缩放下选择面板顶部间隔过大。用户随后明确：95% 只是示例，实际设计应让内容尽量大，并按真实页面观感决定克制、舒服的留白；不能把示例比例设成全局硬规则。

根因有四类：全局 `UtenScrollBehavior` 自动生成覆盖式竖条；公共主档表格另外自绘覆盖式竖条；导入差异、历史比较、价格说明、附件预览独立管理滚动条；选择面板重复叠加标题 padding、默认关闭按钮高度、正文和搜索框 padding。分辨率不是顶部间隔的唯一原因，整体界面缩放会进一步放大这些装饰留白。

## 公共实现与迁移

| 旧入口与问题 | 当前公共入口 | 接入范围及保留差异 |
|---|---|---|
| 自绘下拉自动加条，原生 Dropdown SDK 还强制常显 | `UtenDropdownScrollScope` | 公共下拉、候选建议、账号历史、上下文菜单、表头筛选、列设置和全部原生菜单触发器。保留滚轮、键盘、触控与选择；原生 iOS Dropdown 局部使用 Material 绘制以绕过 SDK 强制 Cupertino 条。 |
| 页面、列表、树的竖条压在内容上 | `UtenScrollGutter` + `UtenScrollBehavior` | 普通竖向 Scrollable 共用 16dp 末端轨道；局部轨道不再承担页面双侧留白，也不会冒充页面边距所有者。 |
| 页面正文随固定比例缩小 | `UtenContentContainer` + `UtenContentInsetsScope` | 默认、narrow、wide 均无固定版心或固定正文比例；按可用窗口宽度使用封顶 24dp 的 16 / 24dp 双侧边距，按界面倍率换算为画布尺寸。真正的页面容器共享边距所有权，嵌套只留一次。 |
| 单据页覆盖式竖条 | `UtenGridPageScrollbar` | 22 个调用文件共用外侧留白；保留底部悬浮动作让位和原控制器。 |
| 主档表体覆盖式自绘条 | `MasterDataTableView` | 表头、表体、横向条统一让出右侧 16dp 轨道，冻结列仍按各自真实 viewport 计算；保留列宽、筛选、勾选、分页、虚拟化、文字复制及行拖动。 |
| 长值、历史、说明、CSV 的独立竖条 | 同一 `UtenScrollGutter` | 已迁移 import_review_page、goods_price_analysis_page、master_record_revision_body、attachment_preview_dialog；CSV/历史按留白后实际宽度计算画布。 |
| 标题/正文/搜索框的重复顶部 padding | `UtenPanelHeader` + `UtenPanelSpacing` | 客户、供应商、货品及已选清单、员工、部门、岗位、分类、模具、仓库、财务账户、应收应付、销售订单、单据关联等同责入口；采购/委外/BOM/盘点/反查继续复用公共货品选择器。保留合法字高、触控下限、安全区和面板生命周期。 |

新旧重复布局已由共享入口替代，没有另外复制一套页面滚动算法。横向滚动条保留；固定 Column 单位菜单本来没有滚动容器，保持原选择机制。业务数量、权限、来源、原始输入、分页数据集和 B0 响应性保护不变。

实现中补齐两项跨调用方兼容：留白布局支持 `IntrinsicHeight` / 固有宽高与 dry baseline，避免导入长值单元格崩溃；自绘条通过 `PointerSignalResolver` 处理外侧轨道滚轮，避免移出内容后鼠标停在条上无法滚动，也避免覆盖模式双重滚动。Shift、反向轴、物理边界和底部让位仍遵守原合同。
