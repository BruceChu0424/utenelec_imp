# 官网管理页

状态：源码候选与本地回归完成；不代表阿里云连接、部署或岗位 UAT 已通过。界面按 `frontend-design` 设计并复用 Uten 组件、主题和字号规则。

## 入口与职责

工作台新增“官网运营”分区，`/website-management` 的入口、路由与页面共同要求 `website:view`。页面权限面为 `website.management`。保存工作台布局时保留原分组顺序和旧偏好键，新分区合并进入既有布局。

该页面负责真实连接体检、概要、网站栏目入口与受控连接配置。内容编辑在受授权的官网编辑器完成；销售询盘继续使用 `/webinquiry`，不新增另一套客户管理或跟进状态。

## 页面行为

- 进入后读取 `/api/website-management`，随后向 `/check` 发起一次真实检查。加载、检查失败、尚未配置和连接正常分别呈现，不用静态数字模拟线上状态。
- 可见的栏目包括首页与栏目、产品目录、素材与资料、新闻与案例、网站设置、发布记录。操作按 `website:content_edit`、`website:product_edit`、`website:media_manage`、`website:publish`、`website:rollback` 分开控制。
- 连接失败时编辑入口不可用，重检和已获授权的销售收件箱仍可使用。
- 连接配置只有超级管理员且持有 `authorization:manage`、服务端 `canConfigure` 才能打开；模拟身份不能配置。地址只选服务端 allowlist，凭据由服务器环境维护，界面不接收或持久化密钥。
- 配置保存使用 `expectedVersion`，不覆盖其它管理员的新配置。

## 受授权编辑跳转

Flutter 每次生成 32 字节安全随机 verifier 和 S256 challenge。`POST /open` 只提交栏目与 challenge，服务端返回固定 `/admin/imp-entry`、60 秒单次 code 和到期时间。

打开前同时验证 HTTPS、精确受信 origin、固定路径、无 userinfo/query/fragment 及有效期。仅在校验后构造 fragment `code/verifier`；不把员工 token 放到网址，不记录授权信息。Web 在当前标签跳转以避免异步授权后弹窗被拦，原生客户端使用外部浏览器。网站确认身份后消费单次凭证，编辑授权最长 5 分钟。

页面、登录身份、代操作身份、服务器或权限变化均使当前操作失效。检查回执、配置写入回执和浏览器跳转共用 `AuthenticatedRequestScope`，过期回执不得回填新身份的页面。

## 询盘与徽标

网站先持久保存咨询和投递任务，IMP 主动拉取并在入库后确认。未确认任务留待重试；官网管理页展示待同步数量不等同于销售待处理数量。

营销部“官网询盘”使用独立 `websiteInquiry` 徽标容器，红色为未认领、黄色为本人跟进中。销售管理卡不会再累加相同询盘。徽标只读取服务端统一 `/api/workbench/badges`。
