## 四、会话惯例（本项目工作方式）

1. **每完成一项**：后端 `bash compile-check.sh`（javac 全量）+ 前端 `dart analyze`（见 §五）+
   重启后端 + E2E（临时测试账号，测完即删）+ 更新对应 docs + README 状态表 + 本文件。
2. **Flyway 迁移**：实体继承 BaseEntity 必须一次带全四审计列（created/updated_at/by，V94 教训）；
   建表 SQL 带齐索引；**有并行任务在抢版本号**——新迁移先用 `ls db/migration | tail` 看最新号，
   撞号（启动报 "Found more than one migration with version N"）就把**未应用**的文件重编号。
3. **附件 Excel 原件**在 `_scratch/finance_req.xlsx` + `_scratch/all_dept_req.xlsx`（模板列结构照抄）。

## 五、操作手册（编译/重启/测试）

```bash
# 从仓库根目录执行；Java 21、Flutter 3.44.2 与 Docker 通过 JAVA_HOME/FLUTTER_HOME/PATH 配置
bash compile-check.sh
flutter analyze lib/features/xxx

# 推荐用 Maven 构建后在前台启动，配置从 server/.env 或受控环境变量读取
mvn -f server/pom.xml -DskipTests package
"$JAVA_HOME/bin/java" -jar server/target/uten-imp-server-0.1.0.jar

# 数据库工具从 PATH 调用；docker exec 必须 -i，否则 stdin 可能静默空跑
docker exec -i uten-imp-postgres psql -U "$UTEN_DB_USER" -d uten_imp -c "SQL"

# 一次性测试文件写到系统 TEMP/TMPDIR，测试结束立即删除；curl 中文 body 使用 UTF-8 文件
# 临时测试账号和 user_permission_overrides 仅在隔离环境创建，测完删除账号、授权与业务数据
```
