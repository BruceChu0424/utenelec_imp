# V765 车间直接申请原料

日期：2026-09-30。迁移 `V765__workshop_material_request_before_setup.sql`。

车间领入申请可以直接选择使用中的重量原料，不再要求员工先去基础资料修改发料方式。申请只表达物料、颜色、基本单位和数量，不改变货品、BOM 或库存。

V765 前向替换申请明细守卫，只放宽 `ISSUE + WORKSHOP_REQUEST + PENDING` 的 `ORDER` 质量单位原料。退回、仓库直接发料及实际库存流水继续要求已纳入期间管理的材料，原迁移 V740 不修改。

仓库按申请发料支持可选 `materialSetup`：只包含本次实际发出的、当前尚未设置用途的材料，携带货品版本和主料／辅料／车间费用用途。具备原货品编辑与 BOM 编辑权限的人在同页预览并确认；服务端经应用端口复用既有发料方式切换服务，与发料处于同一事务。版本或单位变化、未清旧需求、权限不足、库存不足等冲突保留原申请，不留下半次配置或库存流水。

候选专用接口 `/api/workshop-material/request-materials` 支持搜索、分页及精确 goodsIds，返回各货品的实际基本单位；原 `/materials` 仍保持期间材料用途，避免影响退料、认料和其它既有调用。申请界面使用「物料、单位、数量、袋数」字段，不把全部质量单位称为公斤。

不新增业务表、权限或清空策略。源码目录 V765/691；整合发布时按实际迁移文件目录复核。测试只使用隔离数据库，不能据此声称运行数据库已更新。
