# V621 委外前置生产承诺守恒

对应迁移：`V621__subcontract_preparation_commitment_reconciliation.sql`。

## 业务口径

委外前置自制首次下达可以按全部剩余需求建立任务，但每次生产只消费本次排产量。需求 10000、首批生产 6000 后，第二批生产 4000 只消耗既有配额；第二批生产 6000 才新增 2000 公共产出。按物料候选行与按既有任务锚点下达，结果一致。

需求量、公共量分别记录：任务 `required_qty = preparation_item.requested_qty + 未撤回前置行动的 public_surplus_qty 合计`。公共量没有需求 allocation，必须使用前置行动的 `external_document_id = preparation_item_id` 追踪。用 allocation 连接汇总会漏掉纯公共行动。

撤回同时释放归需求量与公共量；尚有对应草稿/已审核生产计划、已入库产出或已通知委外时拒绝撤回。计划与动作的历史记录保留。

## 旧数据升级

迁移不改历史行动、计划、库存或财务事实。它先核对活动任务下的前置行动公共量与有效计划公共量，且修正后的任务量不得低于已产出/已通知量；双方事实一致时才重新计算任务投影并递增版本。新增按分析、准备任务定位前置行动的部分索引，纯公共行动也能使用该索引。

缺少公共行动、多记公共行动、或者实际产出超过能够证明的承诺量时，迁移以 `23514` 拒绝并列出前 20 个任务 ID 与两侧数量。必须按可追踪的业务反向/补正流程核对后重试，禁止 `flyway repair` 或直接篡改历史来源。新迁移失败时其事务整体回滚。
