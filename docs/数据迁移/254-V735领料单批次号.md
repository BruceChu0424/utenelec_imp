# V735 领料单批次号 draw_batch_no

**日期**：2026-09-27
**改动**：`stock_documents` 增加可空列 `draw_batch_no`（text）。

## 背景

车间从「我的车间任务」一次批量领料会提交多张 DRAW 领料单（备料阶段按工单×实际仓各自建单、各自 SL 单号）。仓库待领任务里这些单分散多行，无法看出是同一个人同一批领的料。

用户口径：「这几个领料单号能不能一样，这样仓库就知道这些是一个人领料。」

## 方案

单据行在生产链 immutable 守卫（V164 `trg_guard_production_linked_stock_document_item`，`NEW.doc_id IS DISTINCT FROM OLD.doc_id` 即拒绝）下不可跨单搬移，把多张单合并成一张不可行。因此给 `stock_documents` 加批次锚点列：

- `ProductionDrawRequestService.submit` 提交成功后，把本批全部领料单写上同一批次号（取本批最小 `bill_no`，不另设取号序列）。
- V164 单据级守卫按列举字段拦截，`draw_batch_no` 不在清单内，UPDATE 放行。
- 单张领料（车间任务单行「去领料」）同样经 submit 端点，单张批次号=自身单号，语义一致：**`draw_batch_no` 恒表示最近一次批量领料提交的批次锚点**；NULL=尚未经批量领料提交（含历史存量单）。

## 透出

仓库待领任务投影（履约工作台 `WAREHOUSE_DOCUMENT_ROWS`）输出 `drawBatchNo`；前端「生产领料」待领任务表新增「领料批次」列（表头值筛选可用）。履约工作台 Row（`FulfillmentTaskRow`）末位加 `drawBatchNo` 字段，采购/委外段恒 null。

## 数据与安全

- 只加列不回填不改存量数据；`business_data_reset` 清库走 `stock_documents` CLEAR 原样覆盖。
- 不加触发器、不进 HotTableTriggerHygiene 契约范围。
