# 愿景与范围

> 本档定义 Uten IMP 要做成什么样、不做什么、给谁用、解决什么问题。

---

## 一、产品愿景

**让优腾的每一台设备、每一个员工、每一笔数据，都在一个平台上协同运转。**

- 一线员工：手机上点开就看工资条、提报销、收通知
- 人事部：员工档案、部门、入离职一目了然
- 财务部：报销审批、工资条审核全流程数字化
- 实验室 / 车间：检测数据、空调、流水线、产量、库存统一管控
- 管理层：经营数据一目了然，辅助决策

一套 Flutter 代码覆盖手机 / 平板 / 桌面 / Web，按角色分权展示。

---

## 二、目标用户

| 角色 | 主要场景 | 设备偏好 |
|---|---|---|
| 普通员工（含流水线工人） | 看工资条、提报销、收通知、提建议 | 手机为主 |
| 人事部 | 员工档案、部门管理、入离职、通知发布 | 桌面为主 |
| 财务部 | 报销审批、工资条审核、报表 | 桌面为主 |
| 实验室 / 车间 | 检测数据上传、设备控制、生产进度 | 平板 + 手机 |
| 管理层 | Dashboard、决策辅助 | 桌面 + 平板 |
| 系统管理员 | 用户权限、系统配置 | 桌面 |

**规模**：200–1000 人制造业。

---

## 三、业务范围（13+ 模块）

### 3.1 第一阶段（Phase 0-1，全员可用）

| 模块 | 主要功能 | 角色 |
|---|---|---|
| 登录认证 | 账号密码登录、登出、记住设备 | 全员 |
| 工作台 Dashboard | 关键指标概览、快捷入口 | 全员（按权限过滤内容） |
| 我的 / 个人资料 | 基本信息查看、密码修改、偏好设置 | 全员 |
| 工资条 | 月度工资条查看、历史记录、下载 | 全员 |
| 报销申请 | 提交报销单、查看进度、历史记录 | 全员 |
| 公司通知 | 通知列表、详情、已读未读 | 全员 |
| 建议箱 | 提交建议、查看回复 | 全员 |
| 设置 | 主题、语言、字号、性能档 | 全员 |

### 3.2 第二阶段（Phase 2-3，人事/财务）

| 模块 | 主要功能 | 角色 |
|---|---|---|
| 员工档案 | 增删改查、入职、离职、调岗 | 人事 |
| 部门管理 | 部门树、增删改、负责人 | 人事 |
| 工资条生成 | 按月生成、审核、发布 | 人事 + 财务 |
| 报销审批 | 审批流、批量处理、统计 | 财务 |
| 财务报表 | 月度/季度报表、导出 | 财务 |

### 3.3 第三阶段（Phase 4，生产/实验室）

| 模块 | 主要功能 | 角色 |
|---|---|---|
| 实验室检测 | 检测数据上传、查询、报告 | 实验室 |
| 楼栋空调控制 | 设备状态、远程控制、定时 | 设备 |
| 流水线进度 | 各产线进度、节拍、异常 | 车间 |
| 产量录入 | 班次产量、汇总、趋势 | 车间 |
| 库存管理 | 原料/成品库存、出入库、预警 | 仓库 |

### 3.4 第四阶段（Phase 5，管理层）

| 模块 | 主要功能 | 角色 |
|---|---|---|
| 经营 Dashboard | 全公司指标、多维分析、趋势 | 管理层 |
| 决策辅助 | 异常告警、预测、对比 | 管理层 |

---

## 四、不做的事（明确边界）

| 不做 | 原因 |
|---|---|
| 不在平台上直接发工资（只发工资条） | 财务合规，发薪走银行 |
| 不做实时视频监控 | 不在平台定位内 |
| 不做考勤打卡 | 用专门考勤机更合适（将来可读数据） |
| 不做 ERP 完整流程 | 聚焦内部协同，不做供应链 |
| 不做对外客户系统 | 这是内部平台 |
| 第一阶段不做后端 | 先验证前端方案 |

## 五、非功能性要求

| 维度 | 要求 |
|---|---|
| 多端 | 手机 / 平板 / 桌面 / Web 一套代码 |
| 响应式 | compact / medium / expanded 三档布局 |
| 性能自适应 | lite / standard / rich 三档自动降级，照顾低端机 |
| 主题 | 浅色 + 深色 |
| 国际化 | 中文 + English |
| 字号可调 | 小 / 中 / 大 / 超大 |
| 安全 | 企业级，前端埋坑，后端接入零改动 |
| 老系统融合 | 单向影子双写，详见 [06-老系统融合/](../06-老系统融合/) |

---

## 六、成功标准

- 员工一天内能用手机完成"看工资条 + 提报销 + 收通知"
- 人事能在桌面端 5 分钟内完成一次新员工建档
- 管理层打开 Dashboard 10 秒内看到全公司关键指标
- 旧设备（2GB 内存 Android）能流畅使用核心功能
- 三端（手机 / 桌面 / Web）体验一致且都"好看"
