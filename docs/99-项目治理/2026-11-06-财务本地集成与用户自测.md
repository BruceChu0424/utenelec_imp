## 3. 建议按此顺序测试

### A. 五类钱流

从首页进入“钱流管理”。用制单账号分别建立销售收款、采购付款、一般费用、其它收入、银行存取款，使用虚构金额和明确来源。

1. 保存草稿，核对账号、币种、汇率、原币、本币、手续费及来源单据。
2. 换独立审核账号审核，核对余额、现金流水、应收应付、GL 与来源链。
3. 换反审账号反审；回到制单账号修改，再由另一员工审核。
4. 连续点击保存/审核，确认只生成一份有效结果；失败或中断后先查看草稿和权威回执，不重新构造原请求。

一般费用和其它收入的新单按本位币入账；选择账户后仍需明确选择币种，不能仅凭账户名称推定已填写。销售收款需要真实发货形成应收，采购付款需要真实采购/IQC/入库或已确认对账形成应付；来源列表为空时，应先走对应源业务，不能直接造“已审”记录。

### B. 科目类别、新增、对应、修改、导入

进入总账报表的“报表取数设置”。分别检查科目分类、原目录、新增科目、业务科目对应、补建目标和元数据修改。必须按实际 UUID、币别与用途确认，不按同名自动认定对应。

使用匿名副本做导入：预览→确认应用→查看原请求回执；再测试明确重新预览的新子请求、取消、关闭重开与草稿恢复。确认父子关系、原文件标识和原请求保持，不用“当前值一样”判断旧提交成功。真实桌面财务原件保持只读，不执行宏或外链，不将原件正文或真实金额复制进日志/Git。

### C. 四类原表与首次应付

在“对账单/往来对帐单”中逐类检查委外、供应商、材料往来和客户原表。每类至少选一条有真实源业务的数据，完成双方明确预览、财务与对方确认，再核首次应付唯一生成及历史来源互斥。

首次应付设置单独测试：保存时快速重复、网络中断、关闭客户端、普通登录后从 Hub 草稿恢复；核原请求、NULL 默认日期、revision 只增加一次及本人权威回执。这与“原表确认后首次立应付”是两项不同测试。

### D. 材料 KG、塑料四表与成本

材料往来需要维护并审核真实 UNIT/WEIGHT 来源，不能只按同 SKU 或名称猜换算。塑料四表须来自同一个真实 CLOSED 月结，联合核实发、实退、盘存、实际订单、单位、方向、未归类耗用与 KG 注记。极小合法值应保留，非法/超界值应拒绝，重放旧请求不得覆盖后来的维护。

铜柱加工/酸洗与销售成本汇总分别核真实加工方、期间、单价、单位、混币、COGS 与晚成本/反向；未知与不适用不能当成零。

### E. 三张总账原表与导出

在独立报表账套选择 **2026-01-01 至 2026-01-31** 或会计月份 **2026-01**。

- 资产负债表：53 个编号项目、左右 8 列、灰底分组、脚注和长项目无裁切。匿名账套两侧期末均为 595，年初均为 500。
- 月度利润表：匿名收入 100、费用 5、净利 95；原括注红色富文本在实际 XLSX/打印中保留。
- 年度利润汇总表：截至 1 月；未来月份不适用保持空；以前年度调整在净利前，O25 百分比完整显示、没有 `###`。

三张表均实际下载 XLSX，并在 Windows 客户端“预览打印→全部结果→Microsoft Print to PDF”保存 PDF。检查整表、末尾、页数、脚注、颜色与金额同源；不要仅以预览首页、XML 或旧截图代替。

再逐一打开制造/管理/销售费用、经营损益、固定资产折旧、已折完清单与待摊摊销等变体，核原列、空隔列、全年/月份、完整目录与尾部。未配置、未覆盖和未核成本应明确保持未知。

### F. 固定资产与待摊

业务账套已留两张未批准、未激活、未过账的草稿。按制单→另一员工批准→非制单人激活→计提预览/提交→另一人审核→非制单人过账执行，核原值、计划额、实提额、一期与末次尾差、后月接续及红冲。不要开启未要求的处置/提前终止功能来替代这条核心链。

### G. 六类申请与客户发货放行

依次走出差、出差报销、费用报销、付款、预付和工资原入口。核部门、财务初核/复核、总经办、保管/付款等真实岗位与不同员工，完成退回、再提、实际资金单关联及 GL/财务确认。工资还要真实批次和岗位前置，普通钱流五单不能代替六申请。

客户现金与月结发货分别测试财务领取/快照审核、真实到账上下文、独立财务签名和仓库执行门禁；反审或权限收回后再打印，应重新检查权威状态。

### H. 大数据、窗口与恢复

业务账套有 10003 条未对应匿名压力科目，用于末尾加载、筛选、搜索与完整导出。反复切月、对象、页面、弹窗/滑窗，快速连点、取消、断网和重开；核旧结果不发布、输入/草稿/未知提交保留。窄屏和大字模式检查项目下拉面板、横滚与按钮可达。

50 万订单的历史压力数据准备已自然完成并保留，正式冻结副本、索引前后测量尚未完成。旧 current100 是合成 SQL 查询夹具，不能当真实批准链或 10000 条真实业务压力验收。
