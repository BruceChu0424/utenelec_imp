## 出差人员怎么开通、回来怎么关闭

日常公司内网仍连接公司主服务器。远程办公用浏览器打开 **https://justplayit.cn**，业务请求仍到公司主服务器，云端目前提供受限加密入口。

1. 员工出差前，在公司内网登录自己的账号，打开「设置 → 账号 → 远程身份验证」，在自己的验证器应用中完成绑定。不要把绑定密钥、验证码或密码发给别人。
2. 超级管理员从公司内网打开「系统设置 → 外网访问与连接」，确认「开放外网访问」及最多授权人数，并点击「保存设置」、按提示重新验证。当前总开关保持关闭、未预先授权人员；准备试用时由超管开启，人数保留 **5**。
3. 超管点击「管理人员授权」，进入「账号与权限管理」，选择该员工，在人员详情点击「授权外网」，按提示重新验证。名单可以随出差人员更换。5 指已授权账号数；不是同时在线人数，增加新人员前可先撤销已回公司的人员。
4. 出差时用浏览器访问上述员工入口，用原 ERP 账号、密码登录；系统要求时，再输入本人验证器的 6 位动态验证码。
5. 回来后由超管在人员详情「撤销」外网授权，也可在外网访问管理页撤销。后端会撤销旧会话和刷新凭据，员工可能需要重新登录。关闭总开关可以暂停所有外网入口，公司内网继续使用。

授权或撤销不改变员工原有业务权限。员工尚未绑定验证器、达到人数上限或总开关关闭时，外网登录不会被放行。本轮没有替员工设置密码或预先开通全员。

当前旧版 Web 实测：主脚本 gzip 后约 6.19 MB、下载约45秒；CanvasKit wasm约2.35 MB、约17秒。公网出带宽约1 Mbps，首次加载会较慢；缓存后和统一版本发布后需分别重新测试。现阶段不要据健康接口的响应时间承诺五人使用性能。

## 备份怎么用

备份已经自动运行，无需员工每天手动操作：公司每5分钟生成成套分块加密恢复点，每小时另存整包，云端每分钟更新接收状态。云端保存密文和签名，备份解密私钥不放云端。

真实隔离恢复已核验数据库516张表、1107个PGP加密值和原件对应关系；正式网关24个恢复文件及4个链接映射也已从云端读回核对。历史索引及凭据问题仍单列，备份上传成功不代表业务接管已验收。

目前本链预算10 GiB，另保留10 GiB磁盘空闲。7天完整点、30天每日点是保留规则，当前观察尚不能证明容量足够长期执行；达到保护阈值会拒绝新上传，后续需依据实际增长核定容量。尚未配置WORM或连续WAL/PITR。

运维检查、管理机密钥托管和精确恢复步骤见 [成套加密备份操作说明](../../deploy/dr-backup/README.zh-CN.md)。恢复应由运维先在隔离环境验证，不能把备份直接覆盖正在使用的公司数据库。

## 「运行与灾备」入口怎么用

独立页面 **https://admin.justplayit.cn** 已部署，应单独收藏。已实测公司业务链路不可达时，该救援页面仍可打开。

本轮新增的主站「设置 / 登录页 / 断连提示 → 运行与灾备」以及首次登记接口，还需要统一发布后才在正式主站生效。当前独立页面显示「尚未绑定救援超管」是实际状态，不能直接拿业务密码登录。

统一发布后，首次办理顺序为：

1. 运维开放不超过15分钟的登记窗口。
2. 超管本人在公司内网登录主站，打开「运行与灾备」，重新验证后取得一次性绑定入口。
3. 本人在独立页面手工将显示的设置密钥加入自己的验证器（当前独立救援页没有扫码二维码），设置独立救援口令（至少20字符），完成验证码确认。绑定地址5分钟有效，不要分享、截图发送或写进聊天。
4. 以后直接用独立救援账号、独立口令和动态验证码访问已收藏的救援页面。业务JWT和旧业务会话不能替代救援登录。

绑定后才能查看受限恢复点目录。归档发布者只能证明密文接收，不具有恢复演练或启用业务权限。独立身份及审计SQLite的异机反向密文备份尚未部署，须在正式救援能力验收前补齐；仅托管主密钥不足以恢复丢失的身份库。

## 公司主机故障时怎么切换

**现阶段不能直接启用云端业务。** 已完成的是加密入口、密文备份和独立控制面；备用业务数据库/App、恢复执行器、现场隔离签名适配器及真实启用验收尚未完成，提升保持禁止状态。

用户确认采用人工现场隔离：现场先关闭并隔离旧主服务器，保持旧主断电、断网，再由运维验证指定恢复点和权限、会话、密钥、原件，最后由超级管理员核验后人工启用已验收的备用业务环境。仅网络断开、健康检查失败或勾选一个确认框都不能证明旧主已经停写，不会自动触发另一边写入。

接管后重新接回旧主也需要受控回切与数据核对；不能直接开机接网使两份数据库同时写。待上述执行器和真实演练完成后，再开放正式切换按钮。
