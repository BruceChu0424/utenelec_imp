# 02 - 访客系统代码总结

> 访客系统：外部人员手机验证码登录 → 来访预约 → HR 审批 → 被访人确认 → 保安扫码核验。
> 前后端打通，双主体 JWT（staff / visitor），签名二维码凭证。

---

## 一、技术架构

| 层 | 实现 |
|---|---|
| 前端 | Flutter：入口选择 / 访客登录（手机+验证码）/ 预约表单 / 我的预约 / 二维码 / 审批列表 / 保安扫码（mobile_scanner）|
| 后端 | Spring Boot：`features/visitor/` 全套（Auth/Sms/Application/Approval/Directory/Security 6 个 Service + Controller）|
| 数据库 | V12 建 5 张访客表；V139 为本人、HR、被访人三类申请列表补 4 个活跃部分复合索引 |
| 鉴权 | 双主体 JWT（`typ=staff` / `typ=visitor`），`JwtAuthFilter` 按 typ 分支复查 DB 状态；visitor `acc/vno=visitorNo`、`avs` 为头像 seed，不携带原手机号 |
| 加密 | 访客手机/身份证 pgcrypto 加密；验证码 SHA-256 哈希；二维码 HMAC 签名 |
| 短信 | `SmsGateway` 接口：`LogSmsGateway`（仅开发）/ `DisabledSmsGateway`（默认、生产缺省）/ `AliyunSmsGateway`（官方国内短信 V2 SDK，生产显式启用） |
