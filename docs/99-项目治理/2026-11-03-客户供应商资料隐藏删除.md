# 客户、供应商资料隐藏删除与未分配提示

候选分支 `uimp/master-data-hide-delete-20261103`，基线 `dfe3f3b67`。本轮分类为前端、后端及共享合同修改；不包含推送、部署、正式打包或现网资料处理。主工作树既有 `pubspec.lock` 和 `tmp/` 并行改动未纳入。

## 行为合同

- 客户、供应商删除是资料隐藏：列表、分面、导出及新建候选排除；原 UUID、名称、业务状态、账款、外键及旧单据继续保留。服务端 `is_hidden/hidden_at` 与 `is_deleted` 分开，V995 前向迁移不修改历史业务数据。
- 有在办引用时，服务端在对象授权和原版本检查后返回 `confirmationRequired`。弹窗保留“去查看”“仍然删除”两个动作；关闭或去查看不发送确认隐藏。确认请求仅包含标记为可确认的条目及原版本，权限失败、版本失败和其他资料的保护不能绕过。
- 去查看以服务端可见的 `kind/id/label` 打开关联单据；应收、应付打开指定往来方和方向的台账。没有稳定 UUID 或没有查看权限的关联只显示摘要，不从单号文字猜链接。关联查看在身份、权限或读取范围失效后关闭，旧弹窗不因权限恢复而复活。
- 历史名称解析及明确 `selectableOnly=false` 的最小业务引用查询保留隐藏身份，但返回 `selectable=false`；新起业务、新换客户/供应商、学习预填及独立预收/预付禁止新引入隐藏身份。旧单原引用及经权威旧来源继承的办理继续有效。
- 负责人或业务员“未分配”共用主题错误色显示；沿用 Uten 组件、字号、间距与明暗主题，不另设颜色常量。
- 货品、颜色、单位、仓库、模具的 BOM、计量、库存、层级及在办业务保护保持原规则；本轮确认标记不适用于这些资料。
