# V857：资料修改申请幂等键完整长度

日期：2026-10-13，America/Denver。仅代表源码候选，真实业务库应用状态另行核验。

`SubmitRequest.idemKey` 允许 128 字符、`FieldChange.fieldCode` 允许 64 字符，
资料变更字段行存储 `提交标识:字段码`。原 `profile_change_requests.idem_key varchar(64)`
不足以保存该身份；普通 UUID 标识加 `emergencyContact.0.relationship` 已达 68 字符，
合法员工修改会在数据库写入时报长度错误。

本迁移只把该列扩为 `varchar(193)`（128 + 1 + 64），同步实体长度。
旧键原文、批次 UUID、字段身份及唯一约束保持；不截断或重算已有回执，不新增表或索引。
已应用的历史迁移字节不变。回滚应使用发布前备份；新增长键后不能直接缩回 64 而损坏回执。

`ProfileChangeBatchPaginationPostgresTest` 在真实 Flyway/JPA 数据库验证合法 UUID+关系字段、
声明的 193 字符边界、旧 64 字符键原文及重复键仍报唯一约束冲突。
