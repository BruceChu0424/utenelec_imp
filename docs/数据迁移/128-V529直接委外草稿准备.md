# V529 直接委外草稿准备

直接委外单的内部生产准备现已接在商业财务审批之前：草稿保存按实际目标件现货计算缺口，计划部门安排前置自制，合格目标件实际入库后才允许送财务；财务批准再次复核目标件库存并建立真实出仓预留。此实现与已有分析委外任务的原树来源分别保留。

本页记录已核实源码和本地专项，仍待全项目组合验收/发布，不表示现有开发库或公司服务器已升级。操作见[委外SOP](../07-业务链路/08-委外全链路-订货出仓回仓重设计.md)，结果见[统一验收](../99-项目治理/2026-09-07-全平台本地审计与整改验收.md)。

## 迁移与来源保护

正式文件：[V529__direct_subcontract_draft_preparation_sources.sql](../../server/src/main/resources/db/migration/V529__direct_subcontract_draft_preparation_sources.sql)。冻结SHA256：`F2E40E0BF6F2B18C73E0711A5B4A444248CF67369AC5CF3575ECF2AB33D79AF6`。

- `production_material_analysis_items`新增 `subcontract_order_item_id`真实延迟FK及 `subcontract_order_qty_base`数量快照。直接来源必须为SUBCONTRACT_PREPARATION、`SC-ORDER:{真实orderItem UUID}`，requested基本量为正且不超过冻结原订货基本量。
- 绑定只接受真实活动直接草稿行，无application_item及多来源申请归属；货品、颜色和基本单位一致。分析仓与订单仓一致，活动草稿量变更必须先取消允许取消的旧准备，不能改写冻结source/ref/requested快照。
- 一个原订货行只允许一份活动准备。取消未排产准备后可创建替代分析，历史不删除；旧手工来源唯一约束继续保留，SC-ORDER的活动唯一性由原订单锁和延迟守卫共同保护。
- 原SC-PREP与已存在planItem/跨分析权益桥继续按原守卫兼容。新SC-ORDER是直接单新增商业需求，不借已有申请来源、不复用SC-PREP字符串伪造桥。
- ALWAYS绑定/延迟守卫覆盖分析行、订单行、订单头和分析头的来源变化。现货充足的有BOM目标件可DIRECT_OUTBOUND，保留真实 `bom_has_children_snapshot`，不能假写无BOM来通过。

迁移不新增表、不清业务、不回填旧SC-PREP为直接草稿，也不改已应用V527/V528及更早文件。

| [SubcontractDraftPreparationAccessPolicy](../../server/src/main/java/com/uten/imp/features/production/SubcontractDraftPreparationAccessPolicy.java) | 仅活动账号、未离职员工、SUB_PLAN/DEPT_PROD实际主/兼职部门树及所需查看权限，并且精确匹配真实SC-ORDER来源；正常分析仍走原对象范围，写动作还需各自权限。 |

| [ProductionExecutionWorkbenchService](../../server/src/main/java/com/uten/imp/features/production/execution/ProductionExecutionWorkbenchService.java) | 直属准备按真实来源进入允许的工作台查询与分页，列表/徽章/详情和权限范围一致。 |

有子件的原分析委外仍在原树先生产目标件、实收后按批次通知委外；新直接单是在草稿期形成自己的SC-ORDER来源。这两条链都保留“计划可先下达，车间实物齐套才领料显式开工”。

## 前端入口

[subcontract_order_edit_page.dart](../../lib/features/subcontract/pages/subcontract_order_edit_page.dart)保存/回填warehouseId并提供实际叶仓选择；缺准备仓时提示，而不是构造父仓或缺仓请求。内部生产准备显示在财务之前。

[SubcontractOrderProgressService](../../server/src/main/java/com/uten/imp/features/subcontract/order/SubcontractOrderProgressService.java)返回DRAFT_PREPARATION及WAITING_PLAN/IN_PREPARATION/READY_FOR_FINANCE；[进度组件](../../lib/features/subcontract/widgets/subcontract_order_progress.dart)据此展示等待计划、生产中或可送财务，并仅在allowedActions包含OPEN_ANALYSIS时使用 `RoutePath.productionMaterialAnalysisSummary(analysisId)` 跳到真实分析汇总页。状态不代替送审/批准时服务器重算。
