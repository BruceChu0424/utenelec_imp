# 浏览器跟随服务器自动更新

本次修改分类为 Web 呈现与浏览器更新控制，复用既有服务器维护契约，不增加数据库迁移、发布版本或新的服务器权限。工作分支为 `uimp/browser-server-follow-20261101`，基于 `bd7e8525b`，任务工作树为 `D:/Projects/uten_imp_worktrees/browser-server-follow-20261101`。未合并 main、推送、部署或生成正式客户端包。

## 行为与公共入口

服务器确认进入更新或待恢复状态后，已打开的业务页和登录页显示「服务器正在更新中」。服务恢复后同时确认新鲜的维护状态、readiness `UP`、版本元数据和本机草稿存储提交，再自动替换当前 URL。保留路径、查询参数、hash、会话和草稿存储。浏览器无需选择是否更新，历史空闲更新开关不再生效。

维护状态仍由 `ServerMaintenanceController` 唯一轮询，`ServerMaintenanceHost` 仅在读取成功后通过 `publishWebServerMaintenance` 投影；网络失败不会给旧快照续期。`web/update_check.js` 是浏览器刷新唯一入口，使用维护通知与版本标记避免循环，包括同版本重启。启动前的旧入口版本核对继续由 `utenWebUpdateGate` 执行。

刷新前通过 `utenWebUpdatePrepare` 等待 `WebUpdateSafetyRegistry.prepareServerReload` 中所有已登记的本机 checkpoint。`FormDraftMixin` 取消待执行的捕获防抖并等待 `saveFormDraftNow` 的真实存储完成；随后用缓存状态证明本次可刷新，周期探针不遍历或重新编码整张表单。业务未提交与本机草稿已落盘是两个独立事实。手动关闭页面与原生安装器仍沿用原 `isSafe` 规则；服务器触发的离开授权仅消费一次。

正在登录的请求结束后才可以刷新。密码不持久化；失败的 `/auth/login` 不留下业务未知提交锁，也不自动重放登录。改密、令牌轮换、退出与全部业务写入继续保留未知结果保护。通知展示回执与原生分面、平台值批量读取沿用已审查的 `d1bd0960e` 语义修复，并在 `request_reload_semantics.dart` 统一判断；本次额外收口登录场景，未整体合并原任务的台账和文档。

## 调用方、迁移及平台差异

| 调用方 / 平台 | 公共实现与状态 |
|---|---|
| Web 新入口、深链及旧 HTML | 保留启动前版本门；有新版时先自动替换 URL，再启动 Flutter |
| Web 已打开业务路由、登录页 | 根级维护宿主投影服务器状态；统一全屏维护面，恢复后自动刷新 |
| Web 所有 `withFormDraft` 调用方 | 公共 mixin 注册并等待持久草稿 checkpoint；共享表单回归验证初始化、保存、身份变更与未知提交 |
| 未持久保护的编辑、浮窗、弹窗及结果未知命令 | 保留各自独立保护；恢复服务后使用非阻断状态条，让当前操作仍可核对和完成，保护解除后继续自动刷新 |
| Web 停服期间首次打开 | 继续由 Nginx 静态 `maintenance.html/js` 显示维护并在服务健康后重开原地址；该页面没有活编辑器 |
| Windows / Android / iOS Flutter 原生 | JS 桥为 no-op；软件安装与空闲倒计时仍走现有客户端更新流程，共享网络请求语义修复保留业务保护 |
| Win7 C# WPF 候选（x86/x64） | 浏览器页面替换不适用；不新增安装或浏览器外壳行为，不宣称完整 ERP、真机或正式分发已验收 |
| 后端 / 运维助手 / 五入口 Nginx | 沿用现有维护状态与健康协议，无接口、数据库或部署模板变更；现网状态未在本任务中改变 |

删除了浏览器手动更新品牌弹窗、按钮、空闲偏好监听与十秒倒计时实现及相应 CSS；不保留第二套 Web 手动更新入口。原生倒计时是不同运行时的安装流程，继续维护于原入口。请求重试与刷新判断共用平台值只读路径匹配，清理了重试拦截器中的重复正则。

## 发布及首次接入边界

本轮完成源码及定向回归，未执行完整远端 CI、正式 Web 构建部署、真实服务器停服更新 UAT 或任何 Windows 打包。上述浏览器桥接实测仍待在可正常启动测试渲染器的环境补验。发布继续要求完整审核源码与最终 CI 全绿。

已经加载旧脚本的页面无法被服务器追溯修改内存代码。首次上线时须先加载一次含本功能的页面，后续服务器更新才采用新的自动跟随流程。维护文件与运维助手安装仍沿用现役运维手册，不以本次源码提交宣称现网已生效。
