# 2026-10-21 原材料行情托管与迁移验证

本次在[自动行情v2](2026-10-20-原材料自动行情关联与预测验证.md)基础上补齐正式发行包、应用后台监管、系统设置与配对备份。员工仍只做一次货品与沪铜、沪铝、沪银的关联。来源、单位、历史研究状态和采购信号限制继续遵守[ADR-186](../99-决策记录-ADR/ADR-186-原材料行情手动关联与离线预测.md)。

## 已实现的运行和迁移合同

- V891登记四项可迁移系统设置，默认启用、每15分钟、1200天历史、每轮30份；保留已有值，复用超级管理员、再认证、CAS、批量事务及审计。机器路径、命令和解释器不进入数据库设置。
- 本地主服务以独立生命周期线程准备并监管所属worker，使用OS防重锁、配置摘要与本轮runId回执；新进程的90秒内心跳才确认启用已应用。关闭需停止所属进程并确认没有未知collector占用，不能杀死其它服务。
- 正式签名发布包包含平台哈希锁、完整离线wheelhouse、worker与目录；标准Ubuntu安装准备Python3.12/venv。运行缓存处于可执行系统磁盘，行情状态处于持久附件根的独立子目录。
- 系统设置页面提供原材料行情设置及实际状态卡，独立轮询并按服务端期限失效。存储成功、运行已确认、来源失败与预测状态分别显示。
- 配对备份显式导出行情原始修订、历史预测和当前状态，使用与writer相同的短写屏障；排除解释器和活锁，恢复保留旧健康证据但清除在线回执。数据库恢复保留设置及货品关联，标准新主机无需逐货品重配。

## 验证入口和证据

本机证据保存在隔离工作树的`.local-artifacts/material-managed/`和各独立Maven输出目录，不复制真实行情到源码fixture。

| 验证层 | 入口与核验范围 |
|---|---|
| 前端 | 全库format、analyze、Flutter测试、正式Web构建；窄屏/深色/大字号状态卡渲染 |
| 真HTTP及PostgreSQL | `MaterialForecastSettingsHttpPostgresTest`：完整安全链、再认证、CAS、非法批量全回滚、普通员工拒绝、一次关联后读取两次不同价格且版本仍为1 |
| 生命周期 | `MaterialForecastSupervisorTest`：未确认/旧run/过期心跳、配置重启、关闭、未知collector、防重、崩溃退避、非本地禁启动 |
| 实际运行与搬迁 | 可选`MaterialForecastManagedRuntimeSmokeTest`：真实离线Python、SHFE、HTTP、所属worker崩溃恢复、关闭再启、在线状态导出、pg_dump/restore到全新数据库与目录、自动新心跳及原关联 |
| 依赖与发布 | Windows及Linux实际离线安装、pip check、StatsForecast实际计算；准备失败不写READY、篡改/联网依赖拒绝、正式jar布局定位 |
| 备份 | Python状态导出/校验/恢复、跨进程屏障、崩溃释放、符号/硬链接与路径拒绝、修订引用完整性、hash校验、旧健康离线及配对流程兼容 |

可选真源验收需要显式的私有payload和缓存，常规CI使用确定性测试，不让默认测试访问外网：

```text
UTEN_RUN_DB_TESTS=true
mvn -Dtest=MaterialForecastSettingsHttpPostgresTest test

UTEN_RUN_MARKET_RUNTIME_SMOKE=true
mvn -Dtest=MaterialForecastManagedRuntimeSmokeTest \
    -Duten.market.test.payload=<absolute-platform-payload> \
    -Duten.market.test.cache=<absolute-private-executable-cache> \
    -Duten.market.test.python=<absolute-python-3.12> test
```
