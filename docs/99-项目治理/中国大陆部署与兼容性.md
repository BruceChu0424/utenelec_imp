# 中国大陆部署与兼容性

> 适用范围：主要用户、生产网络和数据处理活动位于中国大陆的 Uten IMP 部署。
> 技术结论：源码已建立“中文默认、北京时间业务语义、同源 Web 资源、国内短信、弱网边界”
> 基线；这不等于已经取得备案、完成个人信息合规或通过生产网络验收。
> 发布结论：仍为 **NO-GO**，须同时关闭本文和
> [生产就绪审计报告](2026-07-30-生产就绪审计报告.md)中的阻断项。

## 一、不可破坏的架构约束

1. Web 正式环境只访问同源 `/api`，不得在运行时依赖境外 CDN、公共字体、PDF.js、统计、
   地图或对象存储域名。
2. Flutter Web 必须使用 `--no-web-resources-cdn` 构建。CanvasKit、Wasm、字体和按需
   fallback 字体都随产物同源发布。
3. PostgreSQL `TIMESTAMPTZ`、Hibernate JDBC 和 JSON 线格式继续使用 UTC；“今天、当月、
   单号日期、账期日界线”等业务计算固定使用 `Asia/Shanghai`。禁止再使用
   `ZoneId.systemDefault()` 决定业务日期。
4. 首次启动默认 `zh_CN`，历史用户已保存的中文/英文偏好继续兼容；中文文案、中文字体、
   11 位手机号、`+86` 手机号和大陆居民身份证校验必须有自动化测试。
5. 网络重试仅允许幂等读请求且最多一次；写请求、审批、转账、发码等不得由客户端自动重放。
6. 网关 IP 限流只做高阈值粗粒度防洪。账号和手机号采用独立细粒度桶，不能让园区 NAT 或
   移动运营商 CGNAT 下的正常用户共享一个低配额。
7. 所有新引入的 SDK、字体、图片、地图、推送、存储、OCR、支付或监控服务，必须先登记
   运行域名、部署地域、收集字段、留存期和数据出境结论，再允许进入生产代码。

## 二、当前技术基线

### 2.1 Web 与客户端

- `web/index.html` 使用 `lang="zh-CN"`；主 UI 使用仓库内 Noto Sans SC / Roboto。
- Release Web 由 CI 强制 `--no-web-resources-cdn`，Flutter CanvasKit/Wasm 和 724 个
  fallback 字体分片同源加载；生成配置明确 `useLocalCanvasKit=true`，
  `fontFallbackBaseUrl` 指向同源 `fallback_fonts/`。
- Web 打印不再进入 `printing` 插件默认的公共 PDF.js CDN 和动态脚本路径，而是用同源
  PDF Blob 调用浏览器打印；手机浏览器不支持稳定 iframe 打印时下载 PDF。
- Nginx CSP 的 `connect-src`、`font-src`、`script-src` 均保持同源；打印只额外允许
  `frame-src blob:`，不开放第三方域名或 `unsafe-inline`。
- Nginx 对 JavaScript、Wasm、JSON、CSS 和 SVG 启用 gzip；版本钉死的 fallback 字体使用
  一年长期缓存。Brotli 只能在目标 CDN/负载均衡器确认模块、`Vary` 和缓存行为后启用。
- macOS Debug/Profile 与 Release 沙箱均具有 `com.apple.security.network.client`，否则
  正式 App 即使 API 地址正确也无法出站。
- 客户端请求采用有限连接/发送/响应超时；仅幂等读请求可对瞬时网络故障重试一次。
- 18 个高频列表页使用 generation guard；旧请求即使在新筛选结果后才返回，也不能覆盖最新数据、
  错误、页码或 loading 状态。
- 当前没有离线业务写入或可靠消息队列。断网时不得把“已点击”展示成“已提交”；恢复后由用户
  明确重试。PWA 也不宣称离线可办理业务。

`test/mainland_runtime_guard_test.dart` 持续阻止以下回归：

- 在 `lib/` 或 `web/` 重新硬编码常见公共 CDN/遥测域名；
- Web 业务代码绕过平台打印封装直接使用 `Printing`/`PdfPreview`；
- CI 丢失 `--no-web-resources-cdn`；
- `zh-CN`、同源 CSP 或 Blob 打印能力被误删。

### 2.2 中文、时间与中国数据格式

- 后端默认请求 Locale 为简体中文；协议错误码保持稳定，不依赖 JVM 所在机器的默认语言。
- 业务日界线集中在 `BusinessTime`，固定 `Asia/Shanghai`；数据库和接口时间戳继续用 UTC
  `Instant`，避免夏令时、服务器地域和容器配置改变历史时刻。
- 员工与访客手机号进入查重、哈希、登录和短信前使用同一规范化规则，`+86` 与大陆 11 位
  手机号不能被识别成两个身份。
- 身份证校验同时检查格式、校验码和合法出生日期；非法日期必须返回稳定 400，不能抛出 500。
- UI 日期、数字、金额和输入法按 `zh_CN` 展示；数据库金额继续使用明确精度的 decimal/numeric，
  不用二进制浮点承担财务值。V145 已把 `goods.price` 与 Java 全链路收敛到
  `NUMERIC(18,4)` / `BigDecimal`。
- V146 只最小化后续审计 before/after，不在 Flyway 内无界更新历史 `audit_log`；V147 把
  鉴权 IP 粗桶独立为默认 300 次/分钟，账号/手机号主体桶继续使用低阈值。

### 2.3 国内运行服务

- 当前唯一明确的外部运行时服务是阿里云短信，默认端点
  `dysmsapi.aliyuncs.com`；生产必须使用已审核的中国大陆账号、签名和模板。
- 短信 access key、secret、签名和模板只从生产密钥管理注入；验证码、完整手机号和密钥不得进入
  应用日志、代理日志、审计正文或错误响应。
- 短信发送频率以规范化手机号为细粒度主体，并保留较高阈值的 IP 防喷洒；多实例部署须使用
  PostgreSQL/Redis/网关等共享状态，不能依赖单 JVM 内存桶。
- OTP 锁、频控与 HMAC 记录先在独立事务提交，再调用供应商；明确拒绝才删除，不确定结果不自动
  重发。若要求“本地提交后进程崩溃”也不丢投递，仍需 outbox worker 与供应商回执/查询。
- 当前没有生产对象存储、地图、推送或第三方遥测。以后若增加，首选中国大陆地域、私网访问和
  服务端签名上传；客户端不得持有云厂商长期密钥。

## 三、推荐的大陆生产拓扑

```text
大陆用户
  -> 大陆 DNS / TLS / WAF 或负载均衡
  -> 同域 Nginx
       -> Flutter Web 静态资源
       -> /api -> Spring Boot（仅代理可访问）
  -> 中国大陆 PostgreSQL
  -> 中国大陆备份、日志、监控与密钥管理
  -> 阿里云短信（仅发码所需手机号和模板参数）
```

硬性要求：

- Web、API、数据库、备份、日志和密钥系统应部署在经批准的中国大陆地域与账号；
- Spring Boot 8080 不对公网开放，只允许受信网关访问；
- 生产域名、证书、DNS、WAF、短信回执和告警都在真实运营商网络验收；
- 禁止生产浏览器直连数据库、对象存储长期凭据或内部管理接口；
- 不因“国内可访问”把 CSP、TLS、CORS、权限、脱敏或审计放宽。

仓库当前只提供 Nginx 模板和开发 PostgreSQL Compose，尚无冻结的生产镜像/编排清单。上线前
必须补齐不可变后端镜像、静态站点镜像、健康检查、只读文件系统、非 root 用户、资源限制、
滚动/回滚、数据库备份恢复和镜像仓库策略，并在大陆目标环境演练。

## 四、大陆构建环境

运行时不得依赖境外网络；构建时也应可在大陆 CI 稳定复现，但镜像不是信任替代品。

Flutter 官方中国社区页给出的可选镜像变量为：

```powershell
$env:PUB_HOSTED_URL = 'https://pub.flutter-io.cn'
$env:FLUTTER_STORAGE_BASE_URL = 'https://storage.flutter-io.cn'
flutter pub get
```

官方同时明确镜像可用性和安全性不作保证，因此仍须提交 `pubspec.lock`、固定 Flutter 版本、
生成 SBOM、校验本地大资产并持续做依赖漏洞扫描。来源：
[Flutter 中国开发者指南](https://docs.flutter.cn/community/china/)。

Maven 可在受控大陆 CI 使用组织 Nexus/Artifactory 代理；若临时使用阿里云公共镜像，配置放在
CI 的 `settings.xml`，不把凭据或单一公共镜像硬编码进 `pom.xml`。来源：
[阿里云 Maven 镜像说明](https://developer.aliyun.com/mirror/maven/)。

Android 还会访问 Gradle distribution、Google Maven、Maven Central 和 Gradle Plugin Portal；
Flutter 镜像不覆盖这些来源。大陆 CI 应由组织制品代理/预热缓存提供，保留
`gradle-wrapper.properties`、依赖锁定与校验，不能把未经审核的公共镜像直接写进项目仓库。
iOS/macOS 构建同样要在受控 Apple runner 预热 CocoaPods/Swift 依赖并保留锁文件。

生产镜像应先同步到组织批准的中国大陆镜像仓库，并按 digest 拉取；不能把 Docker Hub、
GitHub Release 或境外软件源当作部署时依赖。

## 五、备案、个人信息与数据出境

以下是上线门禁，不是由代码自动完成的法律结论：

1. 若通过中国大陆公网提供互联网信息服务，应由运营主体、云服务商和法律负责人按服务性质确认
   ICP 备案或许可、公安联网备案及页面展示要求。以届时有效的工信部规则为准：
   [《互联网信息服务管理办法》](https://sdca.miit.gov.cn/zwgk/fgbz/art/2026/art_fea940f81f1d423e87101adf147ab979.html)、
   [非经营性互联网信息服务备案管理办法](https://www.miit.gov.cn/zcfg/xxtxl/art/2024/art_7e48434c08c24131b4b7eecfca5b2b6c.html)。
2. 项目处理员工身份证、手机号、银行卡、薪资、访客身份和行程，必须完成处理目的、必要性、
   法律依据、告知、权限、留存、删除、更正、导出、投诉联系人和事件响应制度。不得用一份笼统
   “同意书”替代劳动管理规则、最小必要和安全义务。依据：
   [《个人信息保护法》](https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)。
3. 当前仓库没有经运营主体/法务确认的隐私告知、员工个人信息处理规则和访客告知文本，因此这是
   **上线阻断项**。代码团队不能代替运营主体填写处理目的、期限、联系人和第三方清单。
4. 生产默认禁止把个人信息、日志、备份、错误追踪或数据库副本传到境外。确需出境时，必须在
   开通前完成数据流盘点、适用路径判断、告知/单独同意和个人信息保护影响评估等要求，并按届时
   有效规则办理。参考：
   [促进和规范数据跨境流动规定](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)、
   [国家网信办数据出境安全管理栏目](https://www.cac.gov.cn/wxzw/sjzl/sjcjaqpg/A09370801index_1.htm)。
5. 与短信、云、日志、备份和运维供应商签订的数据处理与安全条款，明确字段、目的、地域、期限、
   删除、分包、审计和事故通知；关闭未评估的境外遥测。

### 6.2 真实网络

- [ ] 中国移动/联通/电信的 4G/5G、家庭宽带、公司园区 NAT 和 VPN/专线完成登录、刷新、

- [ ] 老库手机号先解密并统一 `+86`/`0086`/分隔符/全角数字，再重新加密和计算 HMAC；输出

- [ ] 需要保留的历史审计按主键范围分批脱敏并 `VACUUM`；未上线测试审计可按批准方案清空。
- [ ] 服务器 NTP 正常；UTC 存储与北京时间业务日界线抽样一致。
- [ ] ICP/许可适用性、隐私告知、员工规则、访客告知、供应商条款和事件响应经责任人签字。

## 七、复核命令

```powershell
# 大陆运行依赖、中文入口与 Web 打印架构守卫
flutter test --no-pub test/mainland_runtime_guard_test.dart

# 当前工作树完整证据
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub
$env:UTEN_RUN_DB_TESTS = 'true'
mvn -f server/pom.xml --batch-mode --no-transfer-progress clean verify

# 生产 Web：必须同源打包运行时资源
flutter build web --release --no-pub --no-web-resources-cdn `
  --dart-define=API_BASE_URL=/api

# 业务时区不得依赖机器默认值
rg -n "ZoneId\\.systemDefault|LocalDate\\.now\\(\\)" server/src/main/java

# 仅 IO 平台封装可直接依赖 printing
rg -n "package:printing|PdfPreview\\(" lib

# 生产运行期常见境外依赖复扫；供应链来源清单不等于运行时调用
rg -n "unpkg|jsdelivr|gstatic|googleapis|googletagmanager|google-analytics|sentry" `
  lib web --glob "!web/fallback_fonts/SHA256SUMS.json"

# macOS 沙箱出站能力
rg -n "com.apple.security.network.client" macos/Runner/*.entitlements
```
