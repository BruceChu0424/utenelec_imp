# V548 产成品送检登记撤回

当前目录为 **V548 / 505 条迁移**；本篇记录 V548，兑现 [ADR-058 §4.5](../99-决策记录-ADR/ADR-058-生产成品仓库送检登记与库位快照.md)
承诺的「受控、幂等、追加式反向」，决策见 [ADR-076 §2.3](../99-决策记录-ADR/ADR-076-生产成品品质检查单聚合层.md)。

## 结构变化

- 新表 `production_finished_arrival_registration_reversals`：registration_id UNIQUE FK、reason（trim，2–500）、idempotency_key、
  request_hash、created_by、created_at；UNIQUE(created_by, idempotency_key)；只追加、`fn_audit()` 审计、清空策略 CLEAR。
- `production_finished_arrival_registration_items` 加 `reversal_id` FK（NULL = 有效登记行）；删除 V430 的
  `source_report_item_id` 终身唯一约束（动态查 `pg_constraint`，不依赖被截断的自动名），改为部分唯一索引
  `production_finished_arrival_registration_item_active_uk ... WHERE reversal_id IS NULL`。
- `production_fqc_inspections` 删除 `source_report_item_id` 唯一约束与 `production_fqc_inspection_report_pair_uk`，改为
  `production_fqc_inspection_active_report_item_uk ... WHERE status <> 'CANCELLED'`；加 (source_report_item_id, created_at, id) 历史索引。
- `production_daily_report_items(goods_id, color_id, id)` 索引：登记页逐行「同货品最近登记仓」LATERAL 反查用。
- 视图 `v_production_report_items_pending_registration`（report_item_id, report_id）：日报已审未红冲 + 带执行段 + 无有效登记行 +
  无未取消 inspection + 无 V414 历史豁免。**所有**「未登记」判断统一引用它：仓库待办 SQL、登记详情/批量详情、库位建议、
  Outbox 待登记投递重查、链路健康、数据库登记行守卫。
- 前向替换函数：
  - `fn_guard_production_finished_arrival_item`：INSERT 以视图为准（撤回后可再登记）；UPDATE 只允许撤回事务把
    `reversal_id` 从 NULL 置为当前撤回记录（会话变量 `app.production_finished_arrival_reversal_id` 必须等于该记录），其余列不可变。
  - `fn_guard_production_fqc_inspection`：来源只认 `reversal_id IS NULL` 的有效登记行。
  - `fn_guard_production_fqc_cancellation` + `production_fqc_cancellation_reason_chk`：新增 `REGISTRATION_REVERSED`，
    要求 inspection 仍 PENDING、无决定/放行/恢复授权，且撤回记录已标记其登记行；`SOURCE_REPORT_REVERSED` 分支保持 V412。
- 新守卫：撤回记录 BEFORE INSERT（只追加、必须带会话变量、日报仍已审、批次每条 inspection 仍未处理）；AFTER INSERT 落地标记登记行；
  DEFERRABLE 提交前核对批次已标记且没有残留未取消 inspection。

## 应用事务（服务端）

`POST /api/warehouse/production-finished-in/arrival-registrations/{registrationId}/reverse`（`stock_doc:view + approve` + `SUB_WH` 范围）：
按操作者 + 幂等键锁命令并重放；锁登记头与日报；预检批次状态（品质已处理 → 409）；`set_config` 会话变量 → 插入撤回记录 →
通过品质端口逐条追加取消事件。相同键相同请求返回原视图，不新增记录。撤回后登记详情返回 `reversedAt/reversalReason`，
批次列表 `reversible=false`；报工行回到待登记，可再次登记到任意仓（新批次、新 inspection、新检查单）；检查单明细与库位偏好保留。

## 边界

- 不回填、不改写任何历史登记/inspection/决定/放行字节；已应用 V430/V469/V542 不动。
- 撤回不写库存、不改 `fqty/iqty`、不影响完成率；只对 PENDING 且未处理的批次生效，不做部分撤回。
- ops 清空脚本与孪生函数补丁同步（CLEAR 268→269）；目录版本对由发布时统一登记。

正式 SQL：`server/src/main/resources/db/migration/V548__production_finished_arrival_registration_reversal.sql`。
