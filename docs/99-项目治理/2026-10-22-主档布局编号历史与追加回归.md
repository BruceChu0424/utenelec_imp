## 已确认根因与实现

| 反馈 | 根因与处理 |
|---|---|
| 查看态固定两列、编辑态顺序不同 | 货品查看态私有双列循环与编辑字段定义独立演进。改为相同 `UtenFormGrid` 容量和字段顺序；客户、供应商直接共用编辑字段定义渲染只读分组，模具和扁平主档逐项对齐。 |
| 底部像整条背景栏 | 货品整页和财务资产表单仍用 Column 底部按钮行及分隔线。改为透明 `UtenDetailActionLayout` / `UtenFloatingActionGroup`，滚动内容预留避让空间。 |
| 显示编号不可编辑 | 完整编辑表单、服务和通用行内编辑对编号限制不一致。复用权威编号服务，输入防抖查重，迟到回包隔离，检查中及冲突时阻止保存；最终数据库仍执行跨域、终身唯一守卫。关系使用 UUID。 |
| 157 条分类修改前缀失败 | PostgreSQL `lpad(sequence::text, 2, '0')` 会把三位序号截断；批处理两次重新计算候选又可能漂移。冻结一次目标编号及历史，以不截断的变长序号执行。 |
| 粘贴后末页找不到 | 原实现把新编号等同于全子树及当前排序的最后一行。新增按同一过滤、匹配级别及排序计数的定位 API，加载真实页码并纵向揭示目标行；保留横向身份列位置。 |
| 新增停用组件 | 选择器过滤与粘贴/批量/导入服务不一致。新选、换件及普通 ADD 拒绝停用；既有清单复制需有效可见源边 UUID、锁与原样内容证明，文件不能冒充历史边。 |
| BOM 颜色和组件列 | 列表批量投影 `hasBom`，有组装与无组装使用不同底色并提供文字状态；停用维持中性。组装表、预览与导出补材质及按 `stock:view` 授权的核算良品库存，统一库存聚合口径。 |
| 资料操作历史与恢复 | 原个人最近十次撤回不是跨操作者对象历史。V898/V899 追加不可变事实，提供独立的共享表格历史页；资料类型、分类树、操作、操作人、关键词及日期筛选已移入各列表头，沿用本项目表格筛选交互，游标逐页加载，双击进入独立版本详情。恢复重验权限、对象范围、并发令牌、引用及专用业务规则，并留下新记录。 |
| 多层委外追加漏提示采购 | 接管后的原路径缺口合法归零，实际缺口在汇总投影；提醒错误优先读取原始值。改用与主表及实际下达一致的权威投影及目标行桥。 |
| 停用按钮缺确认 | 多个页面直接调用状态命令。统一启停确认，取消零写请求，停用红色、停用后切换启用及相应图标。库存右上角复用正式盘点历史。 |
| 单位日常维护及多选 | 单位页面、详情、编辑、打印和导出统一维护编号、名称与状态，提供共享编辑模式、选择/多选及确认后的批量启停、删除；既有单位可查询选择，标准名称沿用现有严格目录。旧计量规则不因字段省略而清空，已有单位改名不重新判定计量。 |
| 颜色备注 | V901 新增可空备注列，贯通详情、完整保存、行内 CAS、列表/表头候选、打印与导出。请求省略备注时保留旧值，显式 null 或空文本按原生清空语义处理；899 时期不含该列的历史恢复保留当前新备注。 |
| 币种、账户批量能力 | 接入共享选择、多选、确认及逐条结果反馈，复用已有原生启停/删除命令串行执行；本位币、账户财务历史与资金事实保护继续在原服务内判断，金额及余额不进入普通表格写入。 |
| 收付款类别表格维护 | 保留专用层级树与检查器，编辑模式使用共享表格、草稿及每页50条；名称、同级排序、收款标志、付款标志与部门核算按各自权限维护。编号、层级及金额只读，专用字段 CAS 端点只合并本次修改；批量状态在同一原生层级锁下按深到浅停用、浅到深启用并逐条回原因。财务类别仍永久禁止删除，管理员也不能通过历史回到 CREATE 前绕过；V902 补齐新增路径的本人历史捕获。 |
| 客户分区卡与供应商入口 | 客户各分区卡和身份卡同宽，查看、编辑不重复增加内层缩进；供应商短交记录专用入口及其供应商UUID范围、返回位置保留，布局整理不删除业务入口。 |

收口审查又逐页对齐普通仓库、账户和结算方式的基本信息网格，保留库存、负责人及财务事实独立区域。账户自身详情最小返回已关联科目的编号、名称及删除状态，不为展示读取整个科目目录；余额继续按原权限脱敏。“全部模具”虚拟根的历史范围映射为总览，真实分类仍传 UUID。模具有车间关系时仍同位显示存放位置，并保留后台按车间解析的维护约束；本位币完整编辑与行内编辑的参考汇率锁定一致。

`material-forecast ... runtime source differs from the requested commit` 是独立的固定提交载荷校验，不能解释编号冲突。当前 24 个载荷源文件与 HEAD 字节一致，未复现该旧日志；没有放宽提交、路径或散列校验。
