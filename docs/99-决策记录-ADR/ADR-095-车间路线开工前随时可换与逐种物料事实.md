## 一、问题

用户口径(2026-09-20)：

1. 「等待物料这里应该可以随时更换下一步；测试数据里一些可以换，一些固定死了。」
2. 「物料明明没有齐，为什么显示齐了？车间内流转的，应该也是流转了才显示齐。」
3. 「车间内流转的货品数量怎么统计、显示在哪里？」
4. 「不同状态不同颜色，颜色差别大点；下一步的表头应该支持筛选。」
5. 「有些任务一部分需要取料、一部分需要直送，要理清楚；分批到货要给车间弹窗。」

复核开发库测试数据得到的真实根因：

- **冻结尺错位**：`fn_can_change_execution_route`(V611)把「任何预留已消耗(consumed_qty>0)」
  当冻结条件；而确认持续生产的那一刻，线边仓里指名给本工单的直送料会就地自动出库
  (V595「所有用户触发的齐套提升都自动出库线边仓单」)，于是 4 张刚确认持续生产的工单
  立刻被冻结——车间还没开工、没报工，什么「生产事实」都没有发生。
- **状态文案靠布尔猜**：ZX00000346(委外件未回厂)、ZX00000347(4 种同车间子件未流转)、
  ZX00000349(1 种子件未流转)三张持续生产工单显示「已提交领料 · 待仓库发料」，实际仓库早已
  把能发的都发了，卡住的是到货/直送；ZX00000350 已 1000/1000 领齐却显示「已支持部分产量」。
  原因是文案由 `issued/drawRequested/canRequestDraw/canStart` 四个布尔拼出来，没有逐种物料
  的事实(哪几种已领、哪几种缺、缺的是等采购还是等同车间子件直送)。
- 颜色：可开工与生产中同为蓝、去领料青绿与之相近、待选路线与等待物料同为琥珀。

## 二、决策

### 2.1 路线冻结尺：只有开工或已有报工才冻结

`fn_can_change_execution_route(segment)` := 段状态 ∈ {WAITING, READY, DISPATCHED} 且无日报行。
实际领料、直送投入、预留、领料草稿都**不再**冻结路线。三条路线之间的切换规则：

| 切换 | 规则 | 物理事实 |
| --- | --- | --- |
| → 持续生产 | 开工前恒可 | 已备料/已领料/直送投入原样保留，`continuous_supply=TRUE`；WAITING 时按增量备料补跑一次 |
| → 齐套生产 | 开工前恒可 | 已备物料一件不动；开工门改为「每种物料实领到位」。已离开 WAITING 的工单保留增量备料模式(`continuous_supply` 不变，READY 守卫据此继续接受部分覆盖)，仍在 WAITING 的回到整批齐套备料 |
| → 分批生产 | 仍要求 `fn_can_split_execution_batch`(未动过的任务) | 分批要拆出有谱系的独立子任务，已有预留/领料/供给绑定就不能拆；下拉里不出现该项，悬停说明原因 |

由此 `continuous_supply` 的唯一含义变为「**按增量备料**」，开工门由 `start_route` 决定：

- `fn_execution_start_material_ready`：`start_route='CONTINUOUS'` → 各项必需料共同支持正产出
  (含开工同事务将投入的指名直送料)；其它路线 → 每种物料实领量 ≥ 需求量。
- `v_production_execution_segment_materials.ready`：只有持续生产路线接受部分覆盖；曾按持续生产
  备过部分料再改齐套的工单回到 KIT_SHORT，直到每种物料全覆盖。
- Java `requireDispatchPreconditions`/`requireMaterialsIssuedForStart` 同步改看 `startRoute`。
- 变更路线的 UPDATE：`continuous_supply = CASE route WHEN CONTINUOUS THEN TRUE
  WHEN FULL_KIT THEN continuous_supply AND status<>'WAITING' ELSE FALSE END`。

### 2.2 逐种物料事实是状态文案与「物料」列的唯一来源

新增 `fn_execution_segment_material_summary(segment)`(列表每行 LATERAL 一次)与
`fn_execution_segment_material_facts(segment)`(详情逐种)。每种正式物料需求只落一个桶：

| 桶 | 判定(基础单位) | 车间看到的 |
| --- | --- | --- |
| ISSUED | 净实领 ≥ 需求量 | 已领到车间(含同车间直送已投入) |
| SHORT_DIRECT | 预留 < 需求量 且需求冻结为直送 | 等同车间子件直送——**子件工单未流转到本任务不算到料** |
| SHORT | 预留 < 需求量 | 等采购到货 / 等委外回厂 |
| DRAWABLE | 普通仓领料行有未申请量 | 已备好 · 可领料 |
| AWAITING_WAREHOUSE | 已申请未发出 | 已申请 · 待仓库发料 |
| LINE_SIDE_PENDING | 只剩线边仓直送料待开工自动投入 | 直送料待开工投入 |
| PREPARING | 已预留、领料指令未生成 | 备料中 |

汇总同时给出「已投料可产量」与「已预留可产量」(V609 冻结耗用曲线)。详情行另给
直送已交接量、直送待分配余量、承担直送责任的子件工单(`fn_workshop_direct_responsibility_allows`)，
以及「仓库已到」——按齐套提升同口径的 `batchAvailability`(专属来源权益 + 允许动用的公共库存，
扣安全库存)，因为**齐套生产到齐前不做段级预留**，只看预留会把「到了 100 还缺 900」说成「还缺 1000」。
到货进展卡(ADR-091 §2.3)的缺口清单同样扣掉这份仓库可用量。

未开工段的文案只按事实生成(`ProductionFlowStage._preparingStage`)，优先级：可开工 → 可领料 →
已交仓库待发 → 缺料(等到货 / 等同车间直送 / 齐套「已备 a/n 种」) → 备料中。「齐」只在每种
物料都实领到车间时才说：`物料已领齐 · 可开工`；部分投料是 `部分物料已投 · 可开工`。

### 2.3 页面

- 「下一步」列：等待物料分类里就是路线下拉，选中即提交；只要未开工且无报工，下拉一直开放。
  分批不在选项时悬停说明「已备部分物料，不能再拆分批」。表头筛选四桶：待选路线 / 齐套 / 持续 /
  分批(服务端 `routeFilter` 在分页前生效)。
- 新增「物料」列(等待物料与生产中都显示)：`已领 a/n 种 · 缺 k 种(直送 j) · 可领 m 种 · 待发 p 种`，
  悬停逐桶解释 + 已投料可产量；双击行的详情弹窗列出每种物料的需求 / 仓库已到 / 直送已交接 /
  已领 / 缺口 / 状态 / 子件工单。
- 颜色：待选路线=红(必须先决定) / 等待=琥珀 / 去领料=蓝 / 可开工=绿 / 待仓库发料=灰 /
  生产中=品牌青；路线徽章沿用齐套=绿、分批=蓝、持续=品红。同一分类里同时出现的档位两两不同色相。

### 2.4 路线数量：仍是三条

逐一评估过的候选：「空料先开工」(用户 2026-09-17 明确否决：每种料至少到一部分才能开工)；
「报工倒冲免领料」(要改仓库出库与成本路径，属其它模块，本轮不做，留作后续议题)；
「先开工后补料」= 持续生产；「按报工倒算、不预填开工数」= 持续生产；「进行中继续领料、单据合并」
= 持续生产的同任务补料与草稿合并(V611)。三条路线只在**开工门槛**上不同，这一点写进下拉说明。

## 三、每一种情况怎么走

| 情况 | 结果 |
| --- | --- |
| 持续生产确认后直送料自动投入，车间想改齐套 | 允许；状态保持 READY，已投直送料保留，标签「等待物料到齐 · 已备 a/n 种」，全部实领后才可开工 |
| 持续生产已备部分料，想改分批 | 409「不满足独立分批条件」且无副作用(版本不变)；下拉不出现分批，悬停说明 |
| 齐套 WAITING 什么都没备，改持续 | 允许；`continuous_supply=TRUE`，有可用料即增量预留、建草稿、升 READY |
| 齐套 READY 全部预留但未领，改持续 | 允许；预留与领料单原样保留，开工门放宽为共同支持正产出 |
| 已开工 / 已有报工 | 409「开工后不能更改生产路线」；徽章悬停说明「已有报工记录」 |
| 采购/委外件未到、仓库已把能发的发完 | 「等待到货 · 缺 k 种」(不再误说「待仓库发料」) |
| 同车间子件工单未完成 | 「等同车间直送 · 缺 k 种」；详情列出子件工单与状态；流转到本任务后转为已领 |
| 全部物料 1000/1000 实领 | 「物料已领齐 · 可开工」(不再说「部分产量」) |
| 齐套 WAITING，采购到 100 还缺 900 | 列表「等待物料到齐 · 齐套生产」；详情「仓库已到 100 / 缺口 1000(未预留)」；到货卡「仓库已到 100，还缺 900」 |
| 一部分领料、一部分直送 | 逐种各自判桶，列表「缺 k 种(直送 j)」，详情按来源标注「采购 · 仓库领料 / 同车间直送」 |
| 退料申请未收 / 已实收 | 净实领扣待退冻结与已退量(V609 口径)，可产量随之回落；不影响路线可改 |
| 品质不合格 / 待检 / 拒收 | 未正式合格入库不进预留与「仓库已到」；不影响路线可改 |
| 无物料子件的工单 | 只有齐套可选；「物料」列显示「无需物料」 |

## 四、明确不做

| 不做 | 理由 |
| --- | --- |
| 齐套生产改为增量预留(到一部分就预留一部分) | 整批齐套是「齐套优先」的调度口径(同货品多任务竞争时让一张先齐)；分析权益已按分析线先行占住到货，车间要看到货量走详情与到货卡，不改预留时机 |
| 已备料后仍允许拆分批 | 拆批要把预留/领料/供给绑定按谱系搬到子任务，ADR-078 未动过才可拆的守恒尺不放宽 |
| 报工倒冲免领料路线 | 触及仓库出库与成本路径，属其它模块 |
| 新权限码 | 改路线的人就是能开工/能提交领料的人；物料详情只读复用 `production_execution:view` |
