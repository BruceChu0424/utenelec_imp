## 云端静态分发的实施边界（尚未启用）

现有云入口只做 stream 转发，无法在不解密员工 TLS 的条件下按 URL 提供静态文件。用户提出的预置资源可以通过独立静态域名实现；该域名使用独立证书，不能把员工域名私钥、DNS 权限、业务 API 或公司凭据移到云端。原 ADR-183 的员工 TLS 与网络隔离边界保留；公开静态资源托管需要单独说明新的浏览器脚本信任边界，不能声称只是复制文件便完成。

发布流程应复用同一审核发行的 Web 文件和校验清单：临时目录上传 → 校验全部文件、完整性和当前版本 → 验证静态入口与原业务入口 → 原子切换 → 删除不再使用的旧文件；任何一步失败保留当前有效版本。旧页面和正在传输的旧资源需要有明确兼容/回退机制，不能在切换瞬间直接递归删除旧目录。不能发布第二份不对应后端版本的 Web，也不能开启未带内容指纹文件的永久缓存。

本轮没有新增静态域名/证书/云服务、没有上传静态副本、没有更改发布器、没有移动员工私钥。云端镜像及自动清理尚未实施，不能以本文件替代上线验收。1 → 20 Mbps 的现有按流量峰值调整草稿已核对价格仍为 ¥0.800/GB；提交会接受产品/SLA 协议，等待用户执行时确认。峰值本身没有新增固定月费，不承诺实际流量账单不变。
