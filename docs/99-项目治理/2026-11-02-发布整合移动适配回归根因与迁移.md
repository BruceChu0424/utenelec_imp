# 发布整合移动适配回归：公共修复与测试迁移

本阶段按 `frontend-design` 保留 Uten 现有主题、组件和桌面布局，区分产品缺陷与测试场景失真。以下为本地定向证据，不代替最终发布提交的完整 CI。

## 公共实现与适用入口

| 实际根因 | 唯一修复入口 | 调用方与保留差异 |
|---|---|---|
| 小屏返回键额外叠加 8px，已由页面容器提供的 16px gutter 被变成 24px | `UtenAppBar` 根据 `UtenContentInsetsScope` 判断边距拥有者 | 成本导入、导入预览、导入复核及其他使用公共页头的页面；无宿主边距的紧凑页头保留原留白，桌面不变 |
| 紧凑工具栏将全部 trailing widgets 当动作，分页的 `LayoutBuilder` 被送进隐藏菜单的 intrinsic 测量，历史页级联布局异常 | `MasterDataTableView` 对 leading/trailing 同用 `UtenActionOverflow.isAction` | 分页、输入、状态保持可见；只有已识别动作进入 Uten 菜单，不吞布局异常或猜测尺寸 |
| 宽窄主题切换将按钮原 `inherit=true` 替换成 typography 的 `inherit=false`，Material 动画无法插值 | `UtenControlTheme.control` 从原 ButtonStyle 按 WidgetState 解析后只改字号 | Filled/Elevated/Outlined/Text 共用一处实现，保留原字体、状态和继承规则 |
| 菜单尚持有控件时切换 BOM 模式/来源，表格短舞台重挂载导致 render tree mutation | `UtenAppBarActionScope.wrapOwnedBefore` | 原生及 Uten 导航共用：claim → 关闭 → 帧移交 → 校验稳定拥有者与 source guard → 回调；BOM 编辑/审核/前后项接入；菜单外保持同步时序 |
| 帧移交期间账号、权限、来源或回调可变化 | `UtenActionOwnerScope` + 既有 `exportContextEpochProvider` | App 组合根只投影 notifier 身份和单调 epoch；组件不决定业务权限。AppBar 校验源 revision/menu generation，Overflow 校验 revision/claim generation，包装器完整透传。账号 ABA、撤权及新读取范围不能复活旧回调 |

普通异步动作仍由原持有者等待完成；导出准备、密码取消和回执不因导航协议改动而重放。来源、金额、数量、权限、草稿和未知提交仍沿用各自业务权威。

本阶段适用于共享 Flutter Web、桌面及移动呈现。WPF 不加载这些 Dart 控件；没有修改其桌面业务或把未迁移/未完成 Win7 真机验收标成支持。

## 测试调用迁移

`test/support/uten_test_actions.dart` 统一逻辑 viewport 与实际 view，使 MediaQuery 不再保持默认 800px 而渲染约束被设为 1400/1700px。动作仅从可点击的公共菜单进入；真窄屏保留严格的可见区域、命中、编辑状态与业务断言。没有通过隐藏树操作替代交互。

本阶段已迁移的调用文件：

- `account_page_permissions_test.dart`、`currency_header_query_test.dart`：桌面精确筛选与导出仍直接可见。
- `goods_bom_columns_test.dart`、`goods_bom_tree_expansion_test.dart`：学习记录、完整深树、展开/收起、数量与平台命中规格。
- `goods_bom_edit_mode_test.dart`：真实打开紧凑菜单进入/退出编辑，校验编辑会话、末尾选择器及大字边界。
- `pages/master_complete_print_consumers_test.dart`：十类实际页面仍读取全部授权分页，不截断为当前页。
- `widgets/goods_bom_workspace_test.dart`：窄屏先打开真实菜单核对导航归属，宽屏并排与全屏保持原布局。
- `widgets/goods_cost_startup_test.dart`、`widgets/goods_cost_tab_test.dart`：真实 viewport，深树展开不再因菜单内按钮暂未展示而被 fixture 跳过；每次关闭后重新打开菜单。
- `widgets/master_record_revision_body_test.dart`：清空高度与实际紧凑动作组高度精确对应，不强制旧的多行高度阈值。
- `widgets/uten_supplier_picker_pagination_test.dart`：旧分页尚在等待时，先把已滚走的分类入口滚回可见区再切分类，继续拒绝晚到旧页。

## 已记录验证及边界

- 首次九文件定向轮：155 通过、3 个真窄屏旧动作假设失败，原日志保留。严格 16px 导入对齐、1400/1700px 桌面导出、学习/深树及全类型完整打印均通过。
- 公共生命周期轮：28 通过、0 失败；覆盖原生/Uten 导航、重复激活、权限 epoch、账号 ABA、source revision、Consumer 导出、密码取消及 await 后 ref。另补拥有者撤除取消回归并通过。
- BOM 专项：390/2x 的进入、退出和选择器，深浅主题，1440 以及 1600 全屏、1280 并排、390 工作窗分别留下通过证据；没有用代码存在代替目标机验收。
- 后续失败 delta 已确认成本深树两平台、实际复核动作高度、紧凑供应商分类切换通过。分析记录为 `build-front-release2544-delta-analyze.log`：24 项、No issues found。
- 上述集合有交集，不累加为总通过数。原始日志保留在任务工作树 `build-front-release2544-*.log`，失败不删除。

独立的 `goods_search_context` HTTP fake 仍需按主档/业务引用实际调用分别迁移；`product_category` 防抖期间导出及价格取值面板搜索弹层的测试交互仍在后续收口。这些待办不写成已通过。生产物料候选、订单链和报价历史的其他契约调查由各自集成任务继续负责。
