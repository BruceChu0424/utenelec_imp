# V541 车间默认权限收紧（一）

当前目录为 **V543 / 502 条迁移**；本篇记录 V541（2026-09-09 已应用于 dev 库）。迁移只删部门授权行，不改权限目录、不碰个人加授（`user_permission_overrides`）、不写业务数据。

## 背景

V212 起生产部 `DEPT_PROD`（6 个 `WS_*` 车间继承）默认挂了一大批供应链查看权限（生产计划/物料分析/生产报表/仓库三码/员工档案），V222（采购 IQC）、V234（物料分析）继续追加。用户 2026-09-09 口径：车间岗位只需要 **我的车间任务（`production_execution:view`）、生产日报报工（`production_daily_report:view/edit`）、FQC 成品质检送检（`production_quality_inspection:view`）**；其余入口需要个别人看时走 `/admin/permissions` 逐人加授或单独挂科室，显式授权优先于本次收回。

## 收回范围（从 DEPT_PROD 删除部门行，16 码）

| 族 | 权限码 |
|---|---|
| 生产计划 | `production_plan:view` / `production_plan:edit` / `production_plan:forward_rd` / `production_plan_cost:view` |
| 生产报表 | `production_report:view` / `production_report:export` / `production_where_used:view` |
| 物料分析 | `production_material_analysis:view`（V234 曾授） |
| 仓库 | `stock:view` / `inventory:view` / `stock_doc:view` / `planning_supply_request:view` |
| 品质 IQC | `procurement_inspection:view`（V222 曾授；FQC 送检保留） |
| 人事 | `employee:view` |
| 基础资料编辑 | `mould:edit` / `mould_category:edit`（只读查看保留，日报/报工选货品仍需要） |

保留：`production_execution:view`、`production_daily_report:view/edit`、`production_quality_inspection:view`、`mould:view`、`mould_category:view`、`goods:view`、`material_category:view`。其他部门（SUB_PLAN / DEPT_QA / 仓库科）不受影响。

## 已知残留（由 V543 收口）

V541 只列了它明确想收的 16 码，dev 库核对后仍留有与表头矛盾的行：`production_plan:view:all`（对象范围码）、`production_plan:delete/batchDelete/reverse/flags`、`production_planning_package:*`、`production_execution:overview/assign/dispatch`、`mould:create/delete/status`、`mould_category:create/delete/move/reorder`，以及 3 个 `active=false` 僵尸码仍挂在部门行。见 [141-V543](141-V543车间默认权限收紧二.md)。

## 影响面

- 车间负责人登录后工作台不再出现生产计划单、物料分析、生产报表、仓库、品质 IQC、员工档案卡片；「我的车间任务」「生产日报」「成品质检」不变。
- 因 `production_plan:view` 收回，我的车间任务页「查看生产计划」双击/行菜单会落到 `/access-denied`——前端门控随 V543 一并修复（[我的车间任务页](../03-页面/我的车间任务页.md)）。
- 迁移天然幂等（DELETE 可重放）；恢复由新的部门权限迁移或管理页重新授予。

正式 SQL：`server/src/main/resources/db/migration/V541__workshop_default_permission_lockdown.sql`。
