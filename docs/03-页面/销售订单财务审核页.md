## 一、页面职责

销售订货单经销售审核后进入本页等待财务确认（V294 闸门）；**确认后订单才对计划部可见并排产**。本页是财务的审批收件箱与决策面，与销售端订单详情彻底分离——财务在此**不**看到改量/排产进度/取消订单/红冲等销售运营操作。

## 二、列表页（审批收件箱，2026-08-18 重设计）

对齐大公司审批中心（SAP/Oracle 审批收件箱）范式：

- **顶部摘要条**：当前视图笔数 + 操作提示（"点卡片进审核详情：核对金额、发运策略与客户应收后再确认"）。
- **分段 Tab**：`待确认`（默认，可办件）/ `已驳回`（待销售修正的历史决策）。徽标计数只含未驳回待办。
- **卡片即摘要**：单号（粗体）+ 订单原币金额（`币种 金额`）；客户/业务员；交货日期带紧迫度（已逾期/临近 ≤3 天红色 + 标签，与销售列表延期预警同口径）；明细行数/开单日期；**客户应收余额**（ar_ap_ledger 未结口径）随卡展示。
- **驳回件**：左侧红色边条 + 驳回原因内嵌卡片，按钮为「查看并处理」。
- 排序：未驳回在前，交货日升序（近交期优先）。

## 三、审核详情页（专用视图）

点列表卡片进入。与销售端订单详情完全不同，面向"该不该放行"决策：

1. **状态条**：单号 + 待确认/已驳回状态与下一步说明。
2. **客户财务快照卡**（本页核心增量）：
   - 应收余额（本币，`ar_ap_ledger` direction=AR 未结 `amount_balance` 合计，与应收汇总报表同口径）；
   - 信用额度 / 铺底额（客户主档）；
   - 应收余额 > 信用额度（且已配置额度）→ 红色告警「该客户应收余额已超信用额度，请谨慎确认」；
   - 本单金额（币种 + 原币合计）。
3. **订单信息卡**：单据日期/业务员/制单员/制单时间/交货日/**币种（加粗红色）**/发运策略/结帐方式/合同号/备注。销售端不录入定金或预收；历史订金快照不能证明到账。
4. **订单资金汇总卡**（只读）：订单金额、正式 AR、现金累计已收、费用冲销、预收累计到账/已转销/可用、
   正式 AR 未收、未发运金额、计划尚需收款与超收。cashReceived 不含 writeOff；有
   hasUnallocated 时显示历史多订单 AR 来源未分配告警，不把不确定金额计入本单。
5. **产品明细**：保持全局统一表格——货品（快照优先 + 颜色·单位 + 客户型号）/数量/单价/折扣/金额（订单币种）/备注。
5. **驳回记录卡**（仅已驳回）：原因 + 驳回人 + 时间。
6. **底栏双决策**：
   - **驳回**（danger）：原因必填（≤500 字），弹窗内联校验；驳回不改订单状态与库存预留，通知归属销售（TYPE_URGENT，点通知直达订单详情）；订单留在「已驳回」Tab。
   - **确认通过**（primary）：备注选填；确认后放行计划部并通知计划员接手物料分析；既存驳回标记自动清除（驳回→修正→确认闭环）。
   - 处理中底栏常驻进度条（防连点），成功/失败走顶部通知；完成后返回列表并刷新。

## 四、后端端点（`SalesOrderFinanceConfirmController`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sales/orders/finance-confirmation/pending?rejected=` | 待确认列表；`rejected` 缺省=仅未驳回，`true`=仅已驳回，`all`=全部 |
| GET | `/api/sales/orders/finance-confirmation/count` | 徽标计数（只含未驳回可办件） |
| GET | `/api/sales/orders/{id}/finance-confirmation/review` | 审核详情（订单 + 明细 + 客户财务快照） |
| POST | `/api/sales/orders/{id}/finance-confirmation` | 确认（remark 选填；幂等；清除驳回标记） |
| POST | `/api/sales/orders/{id}/finance-confirmation/reject` | 驳回（reason 必填；通知归属销售） |

金额口径：`sales_order_finance:view` 持有者可见订单原币金额与明细价格——与 V294 待确认列表下发 `totalOriginal` 同口径（财务确认必须核对金额）。该视图不授予销售端写操作。

## 五、通知链

- 销售审核 → `SALES_ORDER_PENDING_FINANCE_CONFIRM` → 财务确认人池（直达列表页）。
- 财务确认 → `SALES_ORDER_FINANCE_CONFIRMED` → 计划员接手物料分析。
- 财务驳回 → `SALES_ORDER_FINANCE_REJECTED` → 归属销售（含驳回原因，直达订单详情）。
- 均走 business_outbox 旁路（提交后投递，不阻断业务事务）。
