# ADR-174：车间内流转免预开通内料仓（审核直送时按需开通）

- 日期：2026-10-10。
- 状态：已接受(2026-10-10，服务端源码 + 真库回归全绿；未发版，不代表公司服务器已部署)。
- 修订 [ADR-147](ADR-147-车间内料仓开通单一真源与发料来源仓.md) §2.3 的「直送只送已开通的车间」；
  开通单一真源(`workshop_bins`)、发料来源仓语义、整批领料门槛全部保留不动。

## 1. 背景

用户口径(2026-10-10)：想要车间内流转(报工转下一道工序)必须先开通（例如）装配第一车间内料仓，
这不该是必须的——车间内流转就像直接领料一样，上层工单直接领用，承接直送的内料仓始终是空的，
不应该为了流转先走一遍开通流程。

ADR-147(V802) 当年把「第一次直送自动建仓」改成「必须预先人工开通」，解决的是**开通真源治理**
(两个真源不同步、仓库资料可手工勾线边仓的乱象)，不是直送本身的业务需要。直送落账确实需要
一个真实存在的内料仓仓库行(承接在制与成本：预留、库存移动、成本产出四道硬闸都以「内料仓是
真实叶仓」为前提)，但「谁在什么时候把它建出来」是治理决策——预先人工开通与审核时系统按需
开通，数据形状完全相同。

## 2. 决策

1. **资格判定拆门槛**：`fn_workshop_direct_targets`(V837 重定义)删除
   `WORKSHOP_BIN_NOT_OPEN` 分支——收料车间没开通内料仓不再判「不可送」，候选、保存草稿、
   单条断言与数据库守卫同一把尺子全部放行。原因码、文案(`fn_workshop_direct_reason_text`)
   与 `output_route_reason` check 约束保留：V837 之前的历史报工行送仓原因仍能回看，只是
   不再产生新值。
2. **审核时按需开通**：直送审核(`ProductionWorkshopDirectTransferService.resolve`)读不到
   已开通内料仓时，经 `LineSideWarehousePort.ensureOpenedBinOf`(实现在 `WorkshopBinService`)
   建出内料仓并写开通行：
   - 与批量开通命令共用 `WORKSHOP-BIN:{车间}` 事务级建议锁，锁内复查防并发重复建仓；
   - 挂靠主仓优先取**收料需求所在仓的主仓**(行级守卫要求内料仓与收料需求同主仓，因此恒满足)，
     判断不了回落唯一主仓；
   - 发料来源仓置空(=按货品所属仓库发)；`auto_created=TRUE` 标记系统建仓，`opened_by`=审核人；
   - 复用撤销时软删的内料仓行(与开通命令同一条复用路径，编号终身占用)；
   - 名字被别的仓占用、判断不出主仓等仓库资料问题：明确拒绝(409)并点名，让审核人找仓库处理，
     不静默挂错位置。
3. **整批领料不受波及**：颗粒散料的「开启整批领料」仍必须由开通命令显式办理
   (`fn_guard_workshop_material_settings` 与复合外键不变)；按需开通只写开通行，不开启整批领料。
4. **前端零改动**：候选一旦 eligible 自然出现在报工页下拉，不再有「{车间}还没开通内料仓…」
   置灰与提示。

## 3. 边界与不变量

- 内料仓仍是真实叶仓，「不绕开『仓库』这个数据概念、只绕开『仓库』这个部门角色」的取向不变
  (ADR-127/V584 起的全部落账链路不动)。
- 行级守卫 `fn_guard_workshop_direct_transfer_item` 不变：直送明细的内料仓仍必须是收料车间
  开通行指的那一个、与收料需求同主仓——手工 SQL 依然绕不过，审核与守卫在锁后同一事务重判。
- 撤销开通语义不变：按需开通出来的内料仓收过直送后同样不能撤销(`fn_workshop_bin_revoke_blockers`
  本就以「没收过直送」为界)。
- 总览页「未开通」态只剩从未直送过的车间；做过车间内流转的车间显示「已开通」。

## 4. 验证

- `WorkshopDirectTargetReasonPostgresTest`(V837 后)：删开通行后候选/断言照常 eligible，
  跨车间等结构原因不受影响，历史文案仍可回看。
- `ProductionWorkshopDirectTransferServiceTest`：未开通走 ensure 并用返回内料仓写直送；
  ensure 失败(名字被占)异常原样抛出、一笔不写。
- `WorkshopBinBatchCommandPostgresTest`(真库)：ensure 建仓挂靠需求主仓、auto_created=TRUE、
  来源仓空、幂等复用、名字冲突 409。
- 既有直送/连续供料端到端(先开通夹具)全部不受影响。
