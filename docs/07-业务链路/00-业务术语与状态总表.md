# 业务术语与状态总表

> 别名：术语表、名词解释、俗称对照、这个词是什么意思

本表把大家平时的说法(俗称)对到平台里的正式叫法，并用一两句话说明它在平台里是什么意思、在哪里看到、详细规则看哪份说明。每个术语的完整规则以「相关文档」为准；本表只做入门解释，不代替各页面说明。

使用方法：先在「俗称/也叫」一列里找你平时的说法，再看同一行的正式术语和含义。俗称之间用「、」分隔。
