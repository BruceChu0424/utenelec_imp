# 97 · V481 采购订货单取消权限

> 2026-09-05 · 前向迁移 · 无数据改写（仅新增权限码 + 部门发放）

## 背景

用户口径（2026-09-05）：采购订货单详情页应有「取消订单」——草稿单（含已提交财务
审核在审、财务已驳回）可以取消；取消后财务任务中心不再显示该单。此前草稿单只有
「删除」（无轨迹）与「重新提交财务」，没有保留轨迹的取消出口；在审单更是只能等
财务驳回后才能动了结。

## 迁移内容

- `permissions` 新增 `purchase_order:cancel`（「取消采购订货单」，采购管理 113）。
- `department_permissions` 按 `purchase_order:submit_finance`（V196）同口径发放：
  `DEPT_PMC`、`SUB_PURCHASE`。

## 配套代码（同批落地）

- 服务端 `POST /api/purchase/orders/{id}/cancel`（`purchase_order:cancel`）：
  - 仅 `status=0`（草稿）可取消，置 `status=2`（新增常量 `STATUS_CANCELED`，
    区别于红冲 -1，保留单据轨迹）。
  - 在审单取消：`procurement_order_approval_cases` 的 PENDING case 置 `CANCELED`
    （受 V196 约束，CANCELED 不写 `decided_at`），并按
    `(PROCUREMENT_APPROVAL_CASE, caseId)` 撤回「待财务审核」居中弹卡。
  - `ProcurementApprovalProjectionQuery` 投影新增 `orderStatus==2 → "CANCELED"`
    （Flutter 既有映射「审批已取消」直接复用）。
- Flutter：`kPurchaseStatusCanceled=2`（标签「已取消」）、权限常量
  `Perm.purchaseOrderCancel`、订货单详情页草稿段新增「取消订单」按钮
  （确认弹窗 → `cancel` → 就地刷新）。

## 已审核单怎么办

已审单沿用既有「红冲」（`purchase_order:reverse`），有收退记录时红冲会被拒——
取消不越权替代红冲的下游校验。
