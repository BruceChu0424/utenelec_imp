# 字体与字号可调规范

> 当前实现使用系统文字缩放 × 用户字号档，统一注入 `MediaQuery.textScaler`；最后核对：2026-08-04。

## 一、当前实现

| 职责 | 源码 |
|---|---|
| 字号档与持久化 | [`font_scale_provider.dart`](../../lib/shared/providers/font_scale_provider.dart) |
| 设置 UI | [`uten_font_scaler.dart`](../../lib/components/settings/uten_font_scaler.dart) |
| 全局注入 | [`app.dart`](../../lib/app.dart) |
| 图标等比辅助 | [`scale.dart`](../../lib/core/responsive/scale.dart) |
| type scale | [`light_theme.dart`](../../lib/core/theme/light_theme.dart)、[`dark_theme.dart`](../../lib/core/theme/dark_theme.dart) |

`FontScale` 有五档（设置页 UI 标签：小 / 标准 / 大 / 超大 / 超超大；medium 为默认档）：

| 档位 | 因子 |
|---|---|
| small | 0.85 |
| medium | 1.0 |
| large | 1.15 |
| xLarge | 1.3 |
| xxLarge | 1.5 |

偏好保存到 `SharedPreferences` 的 `fontScale`。`UtenApp` 将设备原有
`MediaQuery.textScaler.scale(1)` 与用户因子相乘后写回全局 `MediaQuery`，因此保留系统无障碍
缩放，不会用应用设置覆盖系统选择。

## 二、字体资产

- UI 字体族：`NotoSansSC`。
- `assets/fonts/NotoSansSC.ttf`（4,092,516 B）是主 UI 字体，包含既有子集及本轮数据库审计发现的
  7 个额外缺字；`assets/fonts/Roboto-Regular.ttf`（515,100 B）提供独立西文字形。
- `assets/fonts/NotoSansSCFull.ttf`（17,772,300 B）仅打印/PDF 时按需加载，不进入 Web 首屏。
- Web 镜像 Flutter 3.44.2 engine 的全部 724 个 Noto fallback WOFF2（144 family，
  共 21,739,792 B）到 `web/fallback_fonts/`，由 `fontFallbackBaseUrl` 指向同源并按缺字懒加载；
  PWA service worker 不预缓存这些分片。这样优先保证严格 CSP、离线可控和历史/未来罕见字完整性，
  同时避免把完整打印字体塞入首屏。
- `.github/scripts/verify-font-assets.ps1` 在 CI 构建前校验 Flutter 版本、5 个本地字体/许可和
  724 个 fallback 分片，共 729 个资产的文件大小与 SHA-256；manifest 不得包含本机绝对路径。
- 本轮对 161 张表、719 个文本列、9,245,430 个非空值、86,674,055 个字符做字形覆盖审计，
  当前库缺字为 0。后续每次全量迁移都必须重跑 glyph coverage gate，不能把当前快照当永久保证。
- Noto 与 Roboto 许可证随仓库保留；替换、升级 Flutter 或再子集化时必须同步许可、manifest、
  SHA-256 和中文/符号缺字检查。

## 三、页面用法

使用 Material type role：

```dart
final text = Theme.of(context).textTheme;

Text('页面标题', style: text.headlineSmall);
Text('正文', style: text.bodyMedium);
Text('辅助信息', style: text.bodySmall);
```

不要在页面重新乘 `FontScale.factor`；全局 `textScaler` 已经生效。只有确需与文字同步的图标或
紧邻固定尺寸，才使用：

```dart
Icon(Icons.info_outline, size: context.scaled(20));
```

布局间距通常保持 token 值，不应随字号无上限放大。文字变大时优先允许换行和容器增高。

### 3.1 fontSize 硬编码的收敛与豁免（2026-08-16 口径）

业务/组件代码里**禁止新建 `TextStyle(fontSize: 数字)`**；存量已全部收敛到
`theme.textTheme.<role>`（尺寸对号入座：48/36/28=display 三档、24/20/18=headline
三档、16/15=titleLarge/bodyLarge、14=bodyMedium|titleMedium|labelLarge（按字重）、
13=bodySmall|titleSmall、12=labelMedium、11=labelSmall）。微字号（10）用既有惯例
`labelSmall?.copyWith(fontSize: 10)`；其余字段（字重/颜色/行高/字距）一律 `copyWith`。

豁免清单（保留固定数值，不视为债）：

- **打印/PDF/纸面复刻**：`pw.TextStyle`（pdf 包）与 A4 纸面预览（固定磅值对齐纸面）；
- **图形绑定注字**：环形进度图中心百分比、头像首字（size×比例）、size 参数化的小徽章
  （如 UtenNotificationBadge、待排产逾期徽标）——尺寸跟图形走，不跟文字层级走；
- **组件尺寸变体体系**：UtenButton/ClickGuard 等 sm/md/lg 档位自带的字号阶梯
  （与 iconSize/padding/最小高联动，属组件设计 token，非文字层级）；
- **带护栏注释的特例**：如字号档选择器 `_Label` 固定 13 防五档并排溢出（注释在
  `uten_font_scaler.dart`，且显式 style 会覆盖 SegmentedButton 选中态配色）。
- 定义层 `core/theme/` 两个主题文件本身是磅值来源，合法。

## 四、禁忌

- 禁止用固定高度裁剪可变字号文字。
- 禁止页面写第二套字号倍率或覆盖 `MediaQuery` 为固定 1.0。
- 禁止把正文转成图片。
- 禁止只用颜色/字号表达状态，仍需文本或语义。
- 禁止为“对齐”关闭系统字体缩放。

## 五、验收

- [ ] small/medium/large/xLarge/xxLarge 五档即时生效并可重启恢复。
- [ ] 系统字体放大与应用档位叠加后，关键页面无溢出、遮挡或不可滚动字段。
- [ ] 按钮、Tab、表格、对话框、Toast、空状态和打印预览均检查。
- [ ] 图标与文字不会严重失衡，点击目标仍至少约 44 logical pixels。
- [ ] 中文、英文、数字、长姓名和金额边界通过视觉回归。
- [ ] Web 首屏只解析主 UI Noto + Roboto，不加载完整打印字体；fallback 同源按需加载且无远程请求。
- [ ] 字体供应链脚本验证 729 个版本钉死资产，数据库 glyph coverage gate 为 0 缺字。
- [ ] 打印中文不缺字，升级 Flutter 后重新镜像并校验对应 engine fallback 集。
