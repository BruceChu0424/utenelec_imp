# ADR-196 超级管理员权限可被个人收回与外网授权放开

- 日期：2026-10-30。
- 状态：已实现；本地隔离验证通过，正式启用随下次发布。
- 修订 ADR-109 中「超管 effective 恒为全量目录码」的合成语义与授权面「不能修改本人/超管
  目标」的拦截口径，历史记录保留原始事实。
- 零新增权限码、零数据库迁移：复用 `user_permission_overrides` 差量表与 `users.remote_access`。

## 背景

此前超级管理员账号在权限体系里是「只读的全量镜像」：`PermissionResolver.permsOf()` 对超管直接
返回全部目录码，个人 grant/revoke 对超管自身不生效；授权面中央守卫
`AdminUserSupport.requireAuthorizationTarget` 把目标为超管或本人的写操作一律 403
（「不能修改超级管理员的权限」/「不能修改本人的授权策略」），`remote_access`（外网访问授权）
同守卫。结果是超管不能在权限页给自己或另一超管做任何调整，超管账号也无法开通外网访问，
出差/居家无法使用云端入口。

## 决策

1. **超管合成从「恒全量」改为「全量基线 + 个人差量」**：`baseParts` 中超管 effective =
   全部目录码 − 个人收回。依赖联动照常（收回某查看码会连带剔除依赖它的操作码），
   登录授权快照（`authorizationSnapshot`）与 `permsOf` 同源生效。
2. **超管专属码不可收回**：`SUPERADMIN_ONLY` 码（如 `authorization:manage`）只随超管身份
   生效，服务端拒绝写入对应收回（「这项权限只随超级管理员身份生效，不能收回」），合成层
   再兜底把它并回——即使覆盖表被手工污染也不会把授权管理本身锁死。
3. **加授行对超管目标剥离**：全量默认之下个人加授是冗余；更关键的是任务池/通知的发卡池
   使用 `grantedPermsOf`「真实授出」口径（按非超管合成），若对超管写入大批加授行会把
   全公司任务卡灌给超管。因此 `setPermissionOverrides` 对超管目标忽略 grants 请求
   （语义等价于恢复默认：撤掉对应收回），`grantAll` 对超管只清收回、不写加授。
4. **目标放开范围限定**：新守卫 `requireSuperAdminEditableTarget`（仅要求操作者为数据库
   确认的超管）只用于个人权限点覆盖、`grant-all` 与 `remote_access` 三处。数据范围、
   AI 授权、模板指派、配置转移仍走原 `requireAuthorizationTarget`（拒超管/本人目标）。
5. **外网授权放开**：`setRemoteAccess` 允许目标为超管或本人，其余门槛（仅超管操作、
   在职与 active 才能开通、触发器 bump auth_version、吊销 refresh token 与会话）不变。
6. **前端**：权限页对超管目标不再整页只读——普通码开关可用（来源标签「超管默认」，
   收回显示红线与「已收回」），专属码锁定并提示「不能收回」；「全部授权」可用
   （文案明确为恢复全量默认），「全部收回」对超管目标保留隐藏（一键收成光杆难以察觉，
   收回请逐项确认）；导出/模板/复制对超管仍禁用（后端配置转移链路未放开）。
7. **保持不变的安全边界**：非超管完全不能操作授权（类级 `principal.superAdmin` 门）；
   不能取消本人超管身份、最后一位超管不可降级；账号支持（锁定/停用/重置密码）仍拒
   超管目标。

## 影响

- 超管被收回某码后，`@PreAuthorize hasAuthority` 检查真实反映差量；`principal.superAdmin`
  判断（如设/取消超管）不受影响。负责人委派上限（`delegationCeiling`）随差量联动收窄，
  批量口径 SQL 对超管 grantor 的收回判定与单账号口径一致。
- `EffectivePermissionsDto.superAdmin` 语义更新：表示「默认全量、可被个人收回压过」，
  前端据此渲染「超管默认」来源与专属码锁定，而非整页只读。
- 审计：保存超管/本人权限仍走 `user_permission_override_change` 业务事件与既有审计链；
  外网授权沿用 `remote_access_grant/revoke`。

## 验证

- `PermissionResolverDependencyTest`：超管差量合成 + 依赖联动 + 专属码兜底（单测）。
- `FullChainEndToEndTest#security_superAdminSelfAndPeerOverridesAllowedWithGuards`
  （原 #33 用例改写）：本人收回生效、专属码拒收回、加授剥离无 grant 行、非超管仍拒绝。
- `PermissionAdministrationPostgresTest#superAdminAndSelfTargetsAllowPersonalRevokesAgainstTheCatalogDefault`
  （真库）：本人与另一超管目标、授权快照差量、grantAll 清收回恢复默认且幂等、不落加授行。
- 前端 `admin_permissions_layout_test.dart` 新用例：超管目标开关可编辑、专属码锁定、
  「全部授权」可用、保存只携带收回差量。
