# 表格连续分页

`MasterDataTableView` 接入 `onPageChange` 后，表体滚到底继续向下滚动会请求下一页；滚到顶部继续向上滚动时，如果前面还有未加载的页，会请求上一页并接到现有记录之前。底部页码表示视口顶部当前可见的第一条业务记录所属页，回看已加载内容时也会随之更新；它与最后请求成功的页、已加载范围分别维护。普通表格、PrimaryScrollController 联动表格、全屏和窄屏卡片共用实现。原有 `onLoadMore` 页面继续由宿主维护累计记录。

- 鼠标滚轮、触摸在对应方向的边界均可触发；横向/Shift 滚动、程序滚动和布局变化不触发分页。
- 一次只加载一页。加载期间保留已有内容，在对应方向显示进度；失败保留已有行和页码，可重试同一页，滚动不会反复重试。
- 请求目标分别取已加载范围的最小页减一、最大页加一；来回滚动不重复请求已有页，也不会越过第一页/末页。
- 可见页码更新只读取已渲染行的位置，不重新请求、不清空列表、不改动选择。分组标题、本地草稿和已淘汰但因勾选而保留的快照不参与页码判断；正在编辑跳页输入时保留输入，失焦后同步当前可见页。
- 上一页插入前只预布局本次实际新增的行，按真实高度在滚动布局阶段补偿位置，再核对可见行锚点，不依赖懒加载列表估算的总高度。短表按需补足尾部滚动空间；前导分组和本地草稿仍维持原顺序。
- 上一页、下一页按钮和输入页码仍可手动跳页；手动跳页替换当前加载范围并回顶。
- `paginationScope` 必须包含搜索、分类、状态、日期等查询身份，使用稳定标量或 Dart record，不能包含页码、loading 或每次新建的 Map/List。表头筛选和排序另由组件检查。
- 静默刷新宿主应传 `paginationRevision`（最新成功响应对象），防止保留刷新前的历史页。查询切换/普通刷新会清空累计范围。
- `rowKeyOf` / `idOf` 提供业务身份，连续页重叠时去重并以最新记录替换，不能用显示文字猜测记录相同。
- 需要选择快照、版本或批量操作的宿主传入 `MasterDataTableRowsController<T>`，从其 `items` 获取累计记录；不能继续仅从最后一次响应的 items 查找选中行。加载成功后的选择修剪应在表格同步后进行，并检查请求代数。
- `rowVisible` 对全部已加载页重新应用业务可见性规则。`unpagedItems` 用于未提交的本地草稿等非服务端分页记录，增删立即反映，且不会在累计页中重复。
- `FormDraftCategoryTable` 保持分页包装器类型稳定，透传查询/刷新身份，并把累计业务记录映射回原 DTO 控制器。本地填写草稿仍走本地继续填写/删除动作。
- family provider 页面使用 `RetainedAsyncPage` 按查询和会话保留成功结果，在下一页加载/错误期间保持表格挂载。查询变化不能沿用旧查询结果。
- 外层滚动的嵌入式表格（审计）通过控制器 `loadNextPage()` / `loadPreviousPage()` 转交公共续载逻辑，表格本身仍按内容收缩，外层按实际行锚点补偿位置。

本次为前端交互优化，不改变后端分页大小、数据查询权限、数量金额合计或业务提交接口。

## 可见页码修正（2026-10-01）

之前底部数字仅记录最后成功回包的页，回看缓存中的前页不会变化。现已独立记录可见页：例如已加载 1—3 页，滚动回看时会显示 3→2→1，重新向下看显示 1→2→3，不为更新数字重复取数。手动上一页/下一页和跳页输入以当前可见页为起点。

普通表格、选择滑窗、卡片、全屏及审计外层滚动均使用实际渲染行与视口的局部坐标判断；离屏保活行没有有效位置时忽略。有限缓存移除远端页后，所选历史快照不计入可见页，等高页面在两端替换也正确保持阅读位置。

可见页、双向续页、供应商与盘点选择等 49 项回归通过；审计事件/会话外滚页码专项 2 项通过；有限缓存窗口 4 项回归通过。修改文件静态分析和差异空白检查通过。本轮为代码修复与本地验证，未更新安装客户端。

## 右侧滑窗与弹窗（2026-09-30）

`UtenPagedPickerList<T>` 复用 `MasterDataTableView` 的双向页窗、错误重试、查询隔离与真实行高锚点；仅把表体改为调用方原有的列表行，不增加表头或改变确认方式。它自身包含分页条，需要放在有界高度内，加载时应保留组件。窄分栏的分页条自动使用紧凑页码显示。

已核对的入口：

| 入口 | 处理 |
| --- | --- |
| 客户、供应商、委外商选择 | 共用主档选择器接入双向续页，保留分类定位、搜索和确定/取消 |
| 货品选择 | 接入双向续页，保留多选及不同用途的货品权限范围 |
| 物料反查选择 | 接入双向续页，保留历史状态展示和点选返回 |
| 审计人员选择 | 接入双向续页，保留搜索防抖与旧请求隔离 |
| FQC 补产任务选择 | 接入双向续页，保留任务来源、权限及确认幂等逻辑 |
| 报工子任务选择 | 接入后端真实分页，保留完整来源组合键与跨页点选顺序 |
| 部门员工选择 | 已累计保留从第一页开始的记录，增加到底自动加载 |

仓库、部门、职位、普通员工等未分页的树/字典选择器已检查，保持原完整列表。权限管理、客户货品对照详情 Tab、材料分析窄屏候选、采购退回与财务异常的独立分页属于整页列表，不作为本轮弹层修改。
