# V538 当前主仓统一预算说明

迁移后为 **V538 / 497 条迁移**。没有新增业务表、权限码或金额字段；测试清理范围仍为 CLEAR 266 张、PRESERVE 96 张。旧迁移和已发生的库存、成本流水不改写。

## 当前业务规则

计划部选择主仓，只需知道该主仓的物料总数和缺多少。合格物料分散在同一主仓的不同子仓时合并计算，不要求计划员调整具体存放位置。同货品、同颜色在该主仓的公共安全库存只保留一次。例如 A 仓 30、B 仓 70、安全数 20，可以下达并领取 80，不能因两个子仓各扣 20 而只算 60。

正式预留、领料单和库存流水仍记录真实子仓。仓库办理领料时看到物料、实际位置和本次数量，到对应子仓取货。实际领料只消耗该单已获准的数量，仍检查该子仓实物量及其他任务的硬预留，不再次按子仓扣安全数。

待检、未入库和其他任务的专属物料不算本任务可领量。经过完整来源证明的合格专属物料继续按 [ADR-075](../99-决策记录-ADR/ADR-075-合格来源跟随实际入库仓与车间通知.md) 跟随实际入库位置；它的来源证明不会放开其他主仓的公共库存。

## 数据库与调用链

- `V538__main_warehouse_public_safety_budget.sql` 仅向前替换原分仓分配函数中的重复安全数扣减，原库存非负、其他硬预留、需求及来源身份校验保留；源函数不符合预期时拒绝迁移。
- `fn_production_qualified_formal_qty()` 从原合格来源、受益节点、正式分配及恢复事件计算专属量，不能靠调用方布尔值冒充。
- 延迟约束 `trg_main_warehouse_public_stock_budget` 在事务结束时按主仓、货品、颜色检查公共安全数。正常消耗、退回已获准物料不是新增公共占用。越主仓借用公共库存或挤占安全数仍拒绝。
- `MainWarehouseStockBudget`、`MaterialAnalysisService`、`ProductionExecutionPlanningService`、`ProductionPlanningPackageService`、`ProductionExecutionReadinessService`、`ProductionMaterialAllocationFacade` 共用主仓预算口径；计划预览允许有效主仓，初次下达直接给出正确的就绪与分仓领料结果。
- `StockDocService.issueAfterPrelock()` 先写本次领料事件、消耗原预留，再把相同 `ProductionMaterialEvent` 交给 `StockService`。`StockBalanceRepository.unboundProductionIssueQuantity()` 校验事件、原 DRAW 行、仓库、货品、颜色、单位、基础数量、预留与正反向记录净额、未绑定物理流水等事实；证明不完整就拒绝，不能仅凭单据类型跳过库存规则。

上述 Java 文件以 `server/src/main/java/com/uten/imp/` 为根：预算工具在 `common/inventory/`，分析在 `features/production/analysis/`，计划在 `features/production/mrp/`，就绪在 `features/production/fulfillment/`，库存分配在 `features/stock/allocation/`，库存记账及仓库领料在 `features/stock/`。

本次事务证明适用于现有 Spring `REQUIRED` → `MANDATORY` 的同一实际数据库事务。`xmin = pg_current_xact_id()::xid` 防止使用旧事件重复出库；当前链路没有 `NESTED` 或显式保存点。将来若引入保存点子事务，需要重新设计和验证这条证明；不能直接套用，否则会安全拒绝该次领料。

## 成本与反向

成本池仍按实际子仓、货品、颜色区分，不合并为主仓成本。A 仓 30 件、单价 2；B 仓 70 件、单价 3；领用 A 的 30 和 B 的 50，应保留车间已领未耗成本 210，B 仓剩余 20 件、成本 60。退回沿原领料及原实际仓处理，全部撤回后恢复库存 100 件、成本 270。领料不等于已登记实际耗用，不能把已领未耗成本误算成已投入生产成本。

## 本地验证与发布

`MainWarehouseSafetyBudgetEndToEndTest` 使用真实 PostgreSQL 验证上述 80 件初次下达、两仓实际领料、重复请求不重复扣减、非零成本和原领料撤回，并覆盖不足量、颜色/主仓隔离、并发及数据库直接绕过请求被拒绝。`StockServiceTest` 覆盖有证明领料、无证明拒绝和其他硬预留保护。相关计划读取测试覆盖两仓安全数单次扣除及合格专属量保护。

这份说明记录当前源码及专项证据；最终组合的全量测试、迁移恢复和公司服务器发布以统一验收记录为准。迁移不能替代后端与前端部署，发布必须使用同一版本。
