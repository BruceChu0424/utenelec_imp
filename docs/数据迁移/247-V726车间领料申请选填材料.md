# V726 车间领料申请选填材料

- 日期：2026-09-26。
- 设计：[ADR-119](../99-决策记录-ADR/ADR-119-底层自制实际领料与BOM累计学习.md)。
- 迁移：`V726__workshop_material_discovery_suggestions.sql`；只追加前向迁移，不修改 V710/V711。

## 数据变化

在 `production_material_discovery_requests` 增加 `requested_materials JSONB NOT NULL DEFAULT '[]'`，限制为最多 100 行的数组。既有请求补空数组，保持未预填的原流程。快照记录车间选择的货品、颜色、基础单位及可空的申请数量，保留提交时显示名称；身份和幂等以 UUID 为准。

扩展原追加式历史守卫，申请从 PENDING 转 CONFIGURED 或 CANCELLED 时不允许更改车间申请快照。继续由原请求表审计及业务数据清空策略管理，不增加并行库存台账，不改已有库存、报工、领料或 BOM 学习贡献。

## 应用契约

申请接口增加可选 `items`，未填写或空数组兼容原哈希。详情新增 `suggestedItems`，正式 `items` 仍是仓库配置结果。仓库只在首次加载待办时带入建议，随后保存完整材料、正数量、实际叶仓，经原事务生成精确需求、预留及 DRAW，再办理实际出库。预填数量不参与 BOM 学习，结案净耗和审核产量继续沿 V711 计算。

已选材料提交货品、颜色和基础单位 UUID，数量可空；填了则须为正数且最多四位有效小数。显示名称、编码、规格和参考库位由服务端按主档生成快照，不能把客户端展示文本当作权威身份。选填快照不承诺实际出库仓，仓库仍须选择合法实际叶仓。

仓库任务投影增加 `materialsDefined` 和 `productionProductCode/Name`。待登记材料从申请快照读取，父件只作为用途说明；没有快照时显示红底“需要填写”，不再用父件冒充材料。状态编码仍是 `MATERIALS_TO_DEFINE`，列表、计数与通知沿原口径；已知材料的用户文案改为“待核对领料”。普通 DRAW 同时带出所生产产品，材料身份仍来自真实领料明细。

## 升级及回退边界

后端读取新列，须先完成 V726 前向迁移再激活对应服务。应按原发布流程备份数据库并验证迁移目录；这里仅记录源码变更，不代表已安装业务库。需要恢复旧服务时保留新增列和申请快照，不反向删除业务记录；已预填内容应保留待重新升级读取。

后续 [V727](248-V727已知材料申请与领料单原子批量出库.md) 将已知材料申请接入原批量出库表，配置和实发可在同一事务办理；[V731](250-V731领料申请独立编号与正式单据追溯.md) 补齐申请编号与正式领料单追溯。未知材料仍先由仓库选料。选填内容自动带入不等于已经出库或已经学习 BOM。

验证包含空请求兼容、材料可选/数量可空、精确身份、同键重试/不同意图冲突、仓库接续实发、实际耗用后的 BOM 学习，以及原学习/撤回/权限回归；结果统一见[收尾记录](../99-项目治理/2026-09-26-领料申请批量出库与编号收尾.md)。
