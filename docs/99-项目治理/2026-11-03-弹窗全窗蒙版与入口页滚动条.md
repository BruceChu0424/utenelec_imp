# 弹窗全窗蒙版与入口页滚动条

本任务基于 `8937e02d2`，隔离分支为 `uimp/modal-scroll-scope-20261103`。修改属于前端呈现与交互，默认使用 `frontend-design`，沿用 Uten 主题、组件、权限、草稿、服务端权威与未知提交保护。任务未推送、部署或正式打包。

## 1. 用户要求与行为边界

- 弹窗蒙版覆盖 Windows 顶部原生尺寸控制栏，页面内其他同类弹窗一并修复。
- 窗口/当前画布宽度 `<1280` 时，工作台、通知、我的、设置及工作台直接进入的管理/浏览入口不显示页面右侧竖向滚动条，保留滑动、滚轮与内容。
- 宽度 `>=1280` 时保留原页面滚动条。新建单据、编辑、详情、历史、弹窗与局部独立面板继续使用原有滚动条，不按 URL 层数推断业务语义。
- 宽度阈值唯一维护于 `lib/core/responsive/breakpoint.dart` 的 `UtenBreakpoints.desktopStart`；WPF 通过既有生成器读取同一常量，不手工维护另一份数值。
