# 04 - 字体与字号可调

> 🔤 字号是用户**最常用**的无障碍能力。制造业现场员工年龄跨度大、视力差异大，**字号必须可调**且**全局即时生效**。
> 本项目字号一律走 token，**禁止硬编码** `fontSize: 14`。

> 相关文档：
> - 上层索引：[00-准则索引与开发清单.md](00-准则索引与开发清单.md)
> - 命名：[01-命名规范.md](01-命名规范.md)
> - 主题与配色：[08-主题与配色.md](08-主题与配色.md)（待补）

## 一、设计目标

1. **字号走 token**：所有文字通过 `Theme.of(context).textTheme` 取样式，不出现裸数字。
2. **用户可调**：设置中提供"小 / 中 / 大 / 超大"四档，默认"中"。
3. **全局即时生效**：切换档位后整棵 Widget Tree 立即重绘，**无需重启 App**。
4. **持久化**：选择记到 `shared_preferences`，下次启动恢复。
5. **无障碍兜底**：尊重系统级文字缩放（系统设置调大时，本 App 也跟着放大）。

---

## 二、字号档位定义

| 档位 | 枚举值 | 缩放因子 | bodyMedium 实际值（基准 14sp） | 适用人群 |
|---|---|---|---|---|
| 小 | `FontScale.small` | 0.85× | 11.9 sp | 视力好、信息密度优先 |
| 中 | `FontScale.medium` | 1.0× | 14 sp | **默认** |
| 大 | `FontScale.large` | 1.15× | 16.1 sp | 中老年员工 |
| 超大 | `FontScale.extraLarge` | 1.3× | 18.2 sp | 视力障碍、远距离看屏 |

> 💡 为什么不直接暴露 0.8 / 1.0 / 1.2 / 1.5 这种自由滑块？
> 自由值会破坏视觉一致性（如 1.07× 这种怪值），且测试组合爆炸。四档离散值可控、可测、可截图回归。

## 三、Material 3 Type Scale 使用

### 3.1 命名而非数字

Material 3 提供了一套语义化 Type Scale，**只认名字，不认数字**：

| Token 名 | 典型用途 | 基准（medium 档） |
|---|---|---|
| `displayLarge` / `displayMedium` / `displaySmall` | 大屏数字、登录页 Hero | 57 / 45 / 36 sp |
| `headlineLarge` / `headlineMedium` / `headlineSmall` | 页面标题、卡片大标题 | 32 / 28 / 24 sp |
| `titleLarge` / `titleMedium` / `titleSmall` | 区块标题、列表项主标题 | 22 / 16 / 14 sp |
| `bodyLarge` / `bodyMedium` / `bodySmall` | 正文、说明、辅助文字 | 16 / 14 / 12 sp |
| `labelLarge` / `labelMedium` / `labelSmall` | 按钮、Chip、标签 | 14 / 12 / 11 sp |

### 3.2 ✅ 正例 vs ❌ 反例

```dart
// ❌ 反例：硬编码字号
Text(
  '员工列表',
  style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
)

Text(
  '共 128 条',
  style: TextStyle(fontSize: 12, color: Colors.grey),
)

// ✅ 正例：走 textTheme，名字表达语义
Text(
  '员工列表',
  style: Theme.of(context).textTheme.titleLarge!,
)

Text(
  '共 128 条',
  style: Theme.of(context).textTheme.bodySmall!,
)
```

## 四、实现方式

### 4.1 两种方案对比

| 方案 | 做法 | 优点 | 缺点 | 本项目选 |
|---|---|---|---|---|
| A：MediaQuery 覆盖 `textScaler` | 在 `MaterialApp` 里用 `MediaQuery` 覆盖系统的 `textScaler` | 简单，所有 `Text` 自动响应 | 与系统级缩放叠加，难以精细控制 | ❌ |
| **B：自定义 TextTheme × 缩放因子** | 在 `ThemeData.textTheme` 里把每个 token 的 fontSize 乘以缩放因子 | 可控、可预测，与系统缩放解耦 | 需要自己生成 Theme | ✅ |

> 🎯 **本项目选 B**：自定义 `TextTheme`，所有字号 = Material 3 基准 × `FontScale.factor`。系统级 `textScaler` 保持默认（与用户设置叠加），但**业务字号由我们自己控制**，避免"用户调到超大 + 系统也调大"导致失控。

### 4.2 FontScale 枚举

放在 `lib/core/font/font_scale.dart`：

```dart
/// 字号档位。
enum FontScale {
  small(0.85),
  medium(1.0),
  large(1.15),
  extraLarge(1.3);

  final double factor;
  const FontScale(this.factor);

  String get label {
    switch (this) {
      case FontScale.small:
        return '小';
      case FontScale.medium:
        return '中';
      case FontScale.large:
        return '大';
      case FontScale.extraLarge:
        return '超大';
    }
  }

  /// 从持久化的 key 还原。
  static FontScale fromName(String? name) {
    return FontScale.values.firstWhere(
      (e) => e.name == name,
      orElse: () => FontScale.medium,
    );
  }
}
```

### 4.3 FontScaleProvider（Riverpod）

放在 `lib/core/font/font_scale_provider.dart`：

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:shared_preferences/shared_preferences.dart';

import 'font_scale.dart';

/// 字号档位状态管理。
///
/// 用法：
/// ```dart
/// final fontScale = ref.watch(fontScaleProvider);
/// ref.read(fontScaleProvider.notifier).set(FontScale.large);
/// ```
class FontScaleNotifier extends Notifier<FontScale> {
  static const _prefsKey = 'app.fontScale';

  @override
  FontScale build() {
    // 异步初始化：从 shared_preferences 读
    _loadFromPrefs();
    return FontScale.medium;
  }

  Future<void> _loadFromPrefs() async {
    final prefs = await SharedPreferences.getInstance();
    state = FontScale.fromName(prefs.getString(_prefsKey));
  }

  Future<void> set(FontScale scale) async {
    state = scale;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_prefsKey, scale.name);
  }
}

final fontScaleProvider =
    NotifierProvider<FontScaleNotifier, FontScale>(FontScaleNotifier.new);
```

> ⚠️ 命名遵循 [01-命名规范.md](01-命名规范.md) 第 2.6 节：Notifier 类名 `FontScaleNotifier`，Provider 标识 `fontScaleProvider`。

### 4.4 生成缩放后的 TextTheme

放在 `lib/core/font/scalable_text_theme.dart`：

```dart
import 'package:flutter/material.dart';
import 'font_scale.dart';

/// 根据 [scale] 生成一份缩放后的 TextTheme。
///
/// 基准来自 Material 3 默认 TextTheme，所有 fontSize × factor。
TextTheme scalableTextTheme(TextTheme base, FontScale scale) {
  final f = scale.factor;

  double scaleStyle(TextStyle? s) => (s?.fontSize ?? 14) * f;

  return base.copyWith(
    displayLarge: base.displayLarge?.copyWith(fontSize: scaleStyle(base.displayLarge)),
    displayMedium: base.displayMedium?.copyWith(fontSize: scaleStyle(base.displayMedium)),
    displaySmall: base.displaySmall?.copyWith(fontSize: scaleStyle(base.displaySmall)),
    headlineLarge: base.headlineLarge?.copyWith(fontSize: scaleStyle(base.headlineLarge)),
    headlineMedium: base.headlineMedium?.copyWith(fontSize: scaleStyle(base.headlineMedium)),
    headlineSmall: base.headlineSmall?.copyWith(fontSize: scaleStyle(base.headlineSmall)),
    titleLarge: base.titleLarge?.copyWith(fontSize: scaleStyle(base.titleLarge)),
    titleMedium: base.titleMedium?.copyWith(fontSize: scaleStyle(base.titleMedium)),
    titleSmall: base.titleSmall?.copyWith(fontSize: scaleStyle(base.titleSmall)),
    bodyLarge: base.bodyLarge?.copyWith(fontSize: scaleStyle(base.bodyLarge)),
    bodyMedium: base.bodyMedium?.copyWith(fontSize: scaleStyle(base.bodyMedium)),
    bodySmall: base.bodySmall?.copyWith(fontSize: scaleStyle(base.bodySmall)),
    labelLarge: base.labelLarge?.copyWith(fontSize: scaleStyle(base.labelLarge)),
    labelMedium: base.labelMedium?.copyWith(fontSize: scaleStyle(base.labelMedium)),
    labelSmall: base.labelSmall?.copyWith(fontSize: scaleStyle(base.labelSmall)),
  );
}
```

### 4.5 在 MaterialApp 中应用

根 Widget 用 `ConsumerWidget`，监听 `fontScaleProvider` 并把它注入 `ThemeData`：

```dart
class UtenImpApp extends ConsumerWidget {
  const UtenImpApp({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final fontScale = ref.watch(fontScaleProvider);

    final baseLight = ThemeData.light(useMaterial3: true);
    final light = baseLight.copyWith(
      textTheme: scalableTextTheme(baseLight.textTheme, fontScale),
    );

    final baseDark = ThemeData.dark(useMaterial3: true);
    final dark = baseDark.copyWith(
      textTheme: scalableTextTheme(baseDark.textTheme, fontScale),
    );

    return MaterialApp(
      title: 'Uten IMP',
      theme: light,
      darkTheme: dark,
      home: const HomePage(),
    );
  }
}
```

> 💡 切换字号时：`ref.read(fontScaleProvider.notifier).set(FontScale.large)`
> → `state` 变 → `ref.watch` 重建 `MaterialApp` → 整棵树拿到新 `textTheme` → **即时生效**，无需重启。

### 4.6 业务代码用法

```dart
class EmployeeListTile extends StatelessWidget {
  const EmployeeListTile({super.key, required this.employee});
  final Employee employee;

  @override
  Widget build(BuildContext context) {
    final tt = Theme.of(context).textTheme;
    return ListTile(
      title: Text(employee.name, style: tt.titleMedium),
      subtitle: Text(employee.departmentName, style: tt.bodySmall),
      trailing: Text(
        employee.employeeNo,
        style: tt.labelSmall,
      ),
    );
  }
}
```

> 组件内部完全不知道 `FontScale` 的存在，token 替它处理一切。

### 4.7 设置页切换 UI 示例

```dart
class FontScaleSettingTile extends ConsumerWidget {
  const FontScaleSettingTile({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final current = ref.watch(fontScaleProvider);
    final tt = Theme.of(context).textTheme;

    return ListTile(
      title: Text('字号', style: tt.titleMedium),
      subtitle: Text('当前：${current.label}', style: tt.bodySmall),
      trailing: SegmentedButton<FontScale>(
        segments: FontScale.values
            .map((e) => ButtonSegment(value: e, label: Text(e.label)))
            .toList(),
        selected: {current},
        onSelectionChanged: (set) {
          ref.read(fontScaleProvider.notifier).set(set.first);
        },
      ),
    );
  }
}
```

## 五、字体选择建议

| 选项 | 建议 | 理由 |
|---|---|---|
| 默认字体 | ✅ **用系统默认**（中文走系统黑体/PingFang/Noto Sans CJK，英文走 Roboto） | 体积零成本、各端观感自然、CJK 渲染由系统优化 |
| 自定义可变字体 | ⚠️ **不推荐**（除非有强品牌要求） | 一套思源黑体子集 5–10 MB，Web / 移动包体增大明显 |
| 等宽字体（数字对齐） | ✅ 工资条、产量报表的数字列用 `FontFeature.tabularFigures()` | 防止数字跳动，无需引入新字体 |
| 图标字体 | ✅ 用 Material Icons（默认） | 已内置，无需额外引入 |

**等宽数字示例**：

```dart
Text(
  '¥ ${slip.netPay.toStringAsFixed(2)}',
  style: tt.bodyLarge?.copyWith(
    fontFeatures: const [FontFeature.tabularFigures()],
  ),
)
```

## 六、中英文混排注意事项

| 问题 | 建议 |
|---|---|
| **行高** | CJK 字符高度比拉丁字母大；`textTheme` 默认 lineHeight 1.43 已对 CJK 友好，**不要手动把 `height` 设到 1.0**，否则中文上下贴边 |
| **字重** | 中文没有 `w300/w400/w500` 的细颗粒度区别，多数字体只有 Regular/Medium/Bold 三档；不要在中文文案上用 `w300` |
| **字间距** | 拉丁字母加 `letterSpacing` 美观，但加到中文上会显得"漏风"；标题加 `letterSpacing: 0.5` 即可，正文别加 |
| **换行** | 长英文 URL/单号不会自动断词，用 `softWrap: true` + 容器约束保证换行，必要时用 `FittedBox` |
| **标点** | 中英混排时标点挤压（如 `中,` vs `中，`）依赖字体；统一文案走 i18n，不手拼 |

## 七、禁忌清单

| 反例 | 正确做法 |
|---|---|
| `TextStyle(fontSize: 14)` | `Theme.of(context).textTheme.bodyMedium` |
| `RichText(text: TextSpan(style: TextStyle(fontSize: 12)))` | 用 `WidgetSpan` 嵌 `Text` + `textTheme`，或把 style 抽出命名 |
| `Text('xx', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold))` | `tt.titleLarge`（粗细已在 token 里） |
| 在 `MaterialApp.builder` 里覆盖 `mediaQuery.textScaler` 与用户设置打架 | 走 `ThemeData.textTheme` 路线（4.4–4.5） |
| 在 `RichText` 写死不同 `fontSize` | 整段用同一 token，差异用 `TextStyle.merge` |
| 字号档位加到 5 档、6 档 | 保持 4 档离散值 |
| 在 `SharedPreferences` 写原始 double 值（0.85 等） | 写枚举 `name`（如 `'small'`），便于迁移 |

## 八、可访问性（Accessibility）

字号可调本身就是核心无障碍能力，本项目额外要求：

| 能力 | 要求 |
|---|---|
| **系统级文字缩放** | 不强制覆盖 `textScaler`，系统调大时本 App 友好响应 |
| **TalkBack / VoiceOver** | 所有 `Text` 的语义信息由 `Semantics` 包裹（图标按钮必须有 `tooltip`） |
| **对比度** | 正文与背景对比度 ≥ 4.5:1（WCAG AA），详见 [08-主题与配色.md](08-主题与配色.md) |
| **超大档不溢出** | 字号=超大时，所有页面在三档断点下都不被截断（PR 必须附超大档截图） |
| **焦点可见** | 文本框/按钮在键盘 Tab 导航时有清晰焦点框 |

> 详见 [10-安全准则.md](10-安全准则.md) 中"无障碍"小节（占位，待补）。

## 八点五、图标与尺寸等比缩放（与字号联动）

> 🚨 **字号变大时，图标和固定尺寸也要跟着变大——不能只有字变、其他不变。**

**问题**：`MediaQuery.textScaler` 只放大 `Text`，**不放大** `Icon(size:)` / `IconButton(iconSize:)` / 固定 `SizedBox`。
用户把字号调到"超大"后，文字变大了但图标还是 24px → 视觉割裂。

**解决方案**：`context.scaled(baseValue)` 扩展（`lib/core/responsive/scale.dart`）。
它读取当前 `textScaler` 系数（系统 × 用户字号档），返回 `baseValue × 系数`。

```dart
import '../../../core/responsive/scale.dart';

// ✅ 正确：图标随字号一起缩放
Icon(Icons.person, size: context.scaled(24));

// ❌ 错误：图标固定 24px，字号变大时不跟着变
Icon(Icons.person, size: 24);
```

**哪些值要用 `context.scaled()`**：
- `Icon(size:)` / `IconButton(iconSize:)`
- `CircleAvatar(radius:)` → `radius: context.scaled(20)`
- 装饰性固定尺寸（logo 方块、头像）
- 固定间距（如果需要随字号变）

**哪些不用**：
- `TextStyle(fontSize:)` → textScaler 已经自动缩放，不需要
- `padding` / `margin` → 保持固定（布局稳定性优先）
- 响应式列数 / 断点 → 走 LayoutBuilder

## 九、对照清单（每次开发前自检）

- [ ] 所有 `Text` 的样式取自 `Theme.of(context).textTheme`，**不硬编码** `fontSize`
- [ ] `RichText` / `TextSpan` 的字号也走 token，不写死
- [ ] 数字列（工资、产量）用了 `FontFeature.tabularFigures()`
- [ ] 业务代码**不直接读** `fontScaleProvider` 来算字号（那是 Theme 的事）
- [ ] 设置页字号切换后，整页**即时生效**（自测过）
- [ ] 字号 = 超大模式下，三档断点下均不溢出、不被截断
- [ ] **图标 size 用 `context.scaled(N)`，不硬编码** `Icon(size: 24)`
- [ ] **`const Icon(...)` 改 `Icon(...)`**（`context.scaled()` 是方法调用，不能 const）
- [ ] 字号变大时图标也等比变大（切到超大档目测过）
- [ ] 中英文混排处行高合理（未手动把 `height` 设到 1.0）
- [ ] 图标按钮有 `tooltip`，关键 `Text` 有 `Semantics`
- [ ] 新增的 token 已加入 `scalableTextTheme`（如自定义了新 TextStyle）
