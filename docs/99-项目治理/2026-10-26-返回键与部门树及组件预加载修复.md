# 返回键、部门分类与组件信息预加载

本次范围为用户提出的五项界面修正：返回键命中区、桌面登录后的运行与灾备入口、权限中心两处说明、部门分类样式、货品组装信息预加载。使用 `frontend-design`，复用 Uten 主题与组件。候选位于本地工作区；未打包、上传或部署。

## 设计约束

- 保持现有背景 `#F5F7FA`、表面 `#FFFFFF`、主文字 `#0F172A`、次文字 `#475569`、交互色 `#14B8A6`、层级深色 `#115E59`，明暗模式继续由主题提供。
- 保留 NotoSansSC 与现有标题、正文层级；通过命中区与排布改善操作，不新增视觉体系。
- 顶栏为 `[贴左24px箭头 + 按钮内部可点留白][页面标题]`。返回型顶栏标题外间距为零，桌面按钮至少40，触屏采用公共最小命中区；标题与按钮不重叠。
- 部门展示复用货品分类的公共树底色、缩进、连接线、加减展开与选中反馈。权限中心去掉常驻教学说明，保留业务备注、保存状态、错误与必要操作。
- 组装信息进入时一次准备完整候选树，默认折叠；展开不取数、不插入加载说明行。首屏读取失败明确展示重试，刷新失败保留已有快照并显示错误。

## 已有实现比较与公共入口

| 职责 | 原实现及问题 | 本次公共方案与保留差异 |
|---|---|---|
| 页面返回 | `UtenBackButton` 桌面收缩为24×24，`UtenAppBar` 的默认标题间距仍不可点击 | `UtenBackButton.slotWidth` 使用公共控制尺寸，箭头保持24且贴左；`UtenAppBar.titleSpacing=0`；保留 pop、来源参数和兜底路由 |
| 裸页面返回 | 入职、离职两个状态、访客登录另写 IconButton | 接入同一按钮，保留向导上一步、草稿确认、访客入口与提交禁用 |
| 更新页返回 | 原生 AppBar 外置 end16 和 titleSpacing4 | 保留页面 start24 对齐，把返回与标题间空白纳入公共按钮，取消标题外间距 |
| 桌面窗口 | 以地址栏 URI 判断登录/灾备；push 后地址仍为登录，拖动层覆盖灾备返回键 | 复用 `pageResumeProvider` 的实际栈顶位置；`DesktopWindowHost` 的窗口控件具备自己的 Overlay；不改变灾备权限或连接含义 |
| 部门分类 | 部门管理及我的部门已共用 `UtenDepartmentTreeView`，但仍用旧层级标记样式 | 两页的唯一 `_buildTree` 启用 `flatLevelColors`，与 `CategoryPageShell`→`UtenCategoryTreeView` 共用 `UtenHierarchyTreeView`；公司根、负责人、搜索及菜单权限保留 |
| BOM子级 | `_readTree` 只读展开路径，单枝/Ctrl展开另行请求并显示临时 subtitle | 全部可达分支在 `_readTree` 准备，读取与 expanded 状态分开；复用代次缓存、同父去重、四并发及分片让帧；移除按点击取子级及临时加载行 |
| 表格新增行挂载 | 有拖拽的表格达到12行后，已缓存的新子行仍强制先绘空壳 | 公共 `UtenDeferredRowMount.admitOnFirstFrame` 只放宽首帧空壳条件，仍受原有全局预算约束。主档表仅对邻接已挂载内容、唯一稳定ID、保持原顺序的1–4行纯插入开放；初始、大批、分页与远跳保留分帧 |

- 所有静态返回入口清单见 `output/navigation-hit-targets-20261026/return-callers.json`。该清单是公共入口源码接线核对，不能当作209份页面的逐页业务验收。
- 额外迁移：`employee_onboarding_page.dart`、`employee_offboarding_workflow_page.dart` 的正常及错误态、`visitor_login_page.dart`；更新页唯一独立 AppBar 宿主同步调整。
- 显式忙碌态接入17处：人事核对、财务报价审核、付款方式、销售编辑、生产领料及批次、委外领料、车间整批领料，以及仓库委外/销售/质检/成品/生产领料批次。将原 `onPressed: busy ? null : callback` 改为 `enabled: !busy` 和原回调；未知提交条件照原样保留。完整文件和行号均在返回入口清单。原API的空回调仍用于默认返回，显式禁用不再误触默认去向。
- 部门管理的桌面左栏与窄屏目录同用 `_buildTree`；我的部门也由单一 `_buildTree` 覆盖两种布局。选择器的父级选择及确认语义保留。
- 权限说明删除位置：`AdminDepartmentPermView._scopeNotice` 及其留白；`AdminPermissionTemplatesWorkspace` 的 `permission-template-sensitive-note` 及其专用行。
- BOM保留按路径独立展开与关系身份，重复组件共用读取但各出现位置仍是独立节点。路径成环明确报错，不通过固定10层上限截断合法层级。
- 审计回包只改标记时仍就地更新；若组件身份或子树结构变化，重新准备完整快照并清除可见及隐藏别名的旧展开继承。同ID从叶节点变分支也必须完成预读，点击不承担补读。
- BOM普通浏览明确为轻量行，编辑及新增输入仍为重行；公共预算保持每帧最多4个轻量行或1个重行。完整模型、输入控制器、选择及滚动窗口保留。
- 分页箭头、表单内部上一步、附件切换和公司资料库面包屑的返回属于不同职责，继续保留各自公共入口。
