# V610 正常存放仓与车间流转位置边界

日期：2026-09-19。源码候选；不代表服务器已经安装。

## 业务语义

货品所属仓库记录正常存放归属。生产中把子件直接交给同车间上层工单，是一笔局部在制流转；系统沿用线边仓 UUID 保留数量、成本、退回和红冲的原始账，但它不能成为货品默认仓，也不能由普通采购、销售、仓库登记入口选为新单据仓。

普通仓入库继续自动学习所属仓。直送的技术入库不再覆盖它。所属仓允许普通主仓作为分类，单据实际收发仍必须是启用的记账叶仓。历史单据保留原位置显示；查询字典保留线边位置以便追溯。

## 根因与迁移

V590 的自动学习在库存过账内核无差别处理所有入库，因此直送也会把货品所属仓改成线边仓。V584 的线边守卫先对 `NOT NEW.is_line_side` 返回，导致后面的有余额禁止摘标判断永远不可达。

V610 只修正当前仍指向线边仓的 `goods.owning_warehouse_id`：取最新普通仓入库；没有入库事实时取普通仓最大正库存；都没有则清空，等待人工登记。普通仓现值不动。流水、余额、预留、报工、直送、检验和成本记录不改写。按受影响货品使用既有索引点查，避免对全部库存流水排序。

新增货品默认仓触发器拒绝线边位置，直接 SQL、旧客户端和导入也受约束。更新线边守卫：有库存或直送历史时不得摘标、改所属仓/车间或删除；普通仓已有归属货品或历史流水时不得变成线边位置；线边位置不能挂子仓。可停用、改名、改备注，历史身份不变。

应用层同步覆盖产品资料、物料分析回写、普通单据新选仓、仓库入库校验和共享 Flutter 仓库选择组件。已核验身份与专门直送权限的直送审核使用独立的线边位置校验入口，仍校验启用、记账叶仓和完整祖先。

## 验证与恢复

回归覆盖：普通入库学习不变；直送不覆盖已有归属/不为无归属货品写线边位置；普通选仓拒绝线边位置；直送专门入口接受合法线边位置；旧值保留显示但不可作为新选择；完整旧迁移目录升级后的回填、双向默认仓守卫及有库存摘标拒绝。

升级前可导出 `goods.id / owning_warehouse_id` 中指向线边仓的记录以便核对。迁移不逆向重写审计事实；需要纠正默认仓时通过正常资料入口选择有依据的普通仓。不可回滚旧应用而重新允许线边技术入库学习；应前向修正应用与迁移。未对当前业务库或服务器执行本迁移。
