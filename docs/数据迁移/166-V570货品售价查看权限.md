# V570 货品售价查看权限（goods:price:view）

> 2026-09-12。新增一个权限码并给三个部门默认授权；不改表结构、不动业务数据。

## 背景

折扣已有查看权限（V227 `goods:discount:view`，销售两线+财务），但**售价对任何
`goods:view` 持有者敞开**：货品列表、详情、Excel 导出、组装信息（BOM）行的单价/金额
全可见。用户口径：价格属敏感商务信息，默认仅财务与两条销售线可见（销售带价谈单、
财务维护价格），生产/仓库/PMC/品质等部门字段置空隐藏；后续可在权限管理页按部门/
个人增授或回收。

## 变化

### ① 权限点（permissions）

| code | name | module/category | action | bulk_assignable |
| --- | --- | --- | --- | --- |
| `goods:price:view` | 查看货品售价 | 基础资料·货品资料 | VIEW | **false**（敏感商务信息，不随「一键全部授权」发放；前端 `authorize_all_excluded.dart` 同步排除） |

surface：`basic.goods` 按 `goods:` 前缀匹配（V328 规则表），本码自动进面，页面内
「本页权限」即可对货品资料页授人。

### ② 默认授权（department_permissions）

与 V227 `goods:discount:view` 完全同线：`DEPT_SALES`、`DEPT_RAIL`、`DEPT_FIN`。
DEPT_FIN 本就持有 `goods:price:edit`，加码使口径显式。其余部门（生产/仓库/PMC/
品质等）默认不可见价格。

### ③ 读侧脱敏（服务端）

- `GoodsService`：未授权者列表/详情价格置 null + `priceMasked=true`（导出复用
  list()，同步脱敏）；**持有 `goods:price:edit` 视为可见**（编辑者必须能看到在改的价）。
- `GoodsBomService`：BOM 行单价/金额同步置 null（配件清单导出本就无价格列）。
- 前端：货品列表「价格」列、详情「价格」行/编辑表单价格字段、组装信息「单价/金额」
  两列，无授权者整列/整段移除（超管恒可见）。

### ④ 写侧守卫（GoodsService / GoodsBomService）

- `ensurePriceEditIfTouched`：价格触碰判定仅对可查看者生效——不可查看者前端隐藏
  价格字段不提交，`req.price=null` 是脱敏产物而非改价意图，恒判触碰会把他们改名字
  等正常编辑一并 403。可查看者（`goods:price:view`）无 `goods:price:edit` 改价仍 403。
- `apply()`：不可查看者提交的价格不落库（保留原值，防误清）——与折扣（V227）同款。
- BOM `apply()`：null 单价 = 脱敏产物——**新建回退组件货品价**（保住「单价取自组件」
  与成本聚合 `sourceE` 口径），**编辑保留行原值**；金额随实际落库单价重算。

## 兼容与验证

- 幂等：`ON CONFLICT`，重跑安全。
- 既有单测：`GoodsDiscountVisibilityTest` 两处「价格不受折扣可见性影响」断言已按新
  语义更新，并新增 4 个价格可见性用例（脱敏/可见/edit 蕴含 view/写侧保留+403）；
  `GoodsBomService` 构造注入新增 `SecurityContextCurrentUser`（3 个单测同步）。
- reset 脚本：`permissions/department_permissions/permission_surface*` 均 PRESERVE，
  仅追加目录映射 `(570, 528)`，CLEAR 表数不变。
- 排查口径：账号看不到价格列/字段时，查其有效权限是否含 `goods:price:view`（或
  `goods:price:edit`）；权限管理页·基础资料·货品资料 可按部门/个人增授。
