## 输入、显示和普通保存

- 货品售价、折扣和预算金额共享 native 40 位整数、24 位有效小数边界；只检范围，不改变数值。预算非负和四项费率 0–100 继续保留。V1034 只替换旧 V421 金额容量约束，不重跑 V421 历史修复，不重算已有货品。
- GoodsSaveRequest 的实际写入键仍为 price，priceText 仅是客户端编辑来源。保留 hasPrice/hasDiscount/hasCurrencyId、原权限和版本检查；预算字段补显式 presence，未出现保留原值，显式 null 才清空。
- 基本信息保存不回传预算；未编辑的价格、折扣和币种也不提交。复制新货品在原权限下采用完整预算文本；普通移动/启停不借此改旧预算。数量、单重、厚度和每袋净重的真实编辑/复制入口保完整文本，数量的 0/null 软默认规则不变。
- 详情与列表精确文本从已脱敏字段生成，不新增价格/成本读取权。库存数和折扣展示、表头搜索、排序及库存定位游标共用同一精确值，移除了相互一致但丢尾的 2 位投影。
- GoodsImport 和 BOM 导入读取 Excel 实际存储数字，显示格式不授予舍入许可；合法 40/24 原文接受，超界明确未写。原文件不改。

## 默认价格及调用方

主价的本位币资格规则不变：登记外币或缺本位币证明时不偷用。BOM 与销售/识别预填使用同源 priceText。学习来的采购/委外默认价格通过 LastTerms Exact 属性进入原控制器；供应商、颜色、单位、币种和税率须全部匹配才预填。税率比较改为十进制等值，最后一位改变会使尚未人工确认的自动价失效；人工价格不被清除。默认汇率、税率及草稿上下文保原文本，采购原“汇率前端恒 1、财务后续确认”的差异未改。

统计报价仍是原估计模型，非原始价格事实。移除最终偏差 2 位/有效样本 3 位的人为显示取位；已确认成本 ÷ (1−目标毛利率) 的报价参考走公共明确选择，未按新参考价回写已存货品或账务。

## BOM 实际采用边界

- 材料合计仍只在 PG 单一公式定义：设计 qty × 组件 c_total（原选择条件及为空时 price 回落）或 price 后求和；未改币种/单位/角色，也没有新增除以 c_total。
- 原自动 ROUND2 已移除。整数溢出、非有限数在选择小数位前拒绝；native 小数容量内完整保存，超过容量才要求本次明确选择。
- 单个用量仍保持克/基本单位、原基准产量与周期材料形状。实际写入采用后冻结原分子、基数或克换算率、单位、结果、策略及真实 actor/action/request；旧基数折为 1 前已保存来源。SQL 发料方式切换与手工/导入采用同一用途契约。
- 临时 paste/import preparedRow 仅计算并携带 transient 原输入；全部来源/权限/周期确认通过、父件明确后，在实际持久化边界才记录 input proof 和建立 PG 采用包。未变的复制/导入保原价格与总额，预审没有持久化凭证。
- 同件只改备注不回退组件现价，不把原 NULL 价补成现价，也不按新精度重算旧 total。新建、换件、数量或价格实际改变才计算新乘积。
- 两个预览/确认公共入口封存本次明确数值策略；确认没带新 header 复用已审选择，新 header 改了选择必须重预览。成功回执仍先返回原结果，不重放。
- 页面 Goods GET 读取 stored source_e。Java 调函数入口为 recalcSourceE（BOM 写入、粘贴及发料方式切换）；历史撤回、学习发布和停用 SQL 是真实写路径，不作为读取展示算法。旧 source_e 和旧 proof 不借新请求重算。
