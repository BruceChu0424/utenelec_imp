# ADR-077 车间明确提交领料后进入仓库任务

- 状态：已接受（2026-09-12）；本文记录源码规则。迁移执行、运行服务更新和岗位验收分别留证，不以本文作为部署回执。
- 依据：用户要求齐套后由车间选择任务、核对领料汇总，再明确提交仓库。
- 局部取代 ADR-073 中“齐套立即生成仓库待办”的行为；ADR-046 的实际发料、显式开工及报工边界继续有效。实际来源仓范围继续依 ADR-075。

## 办理流程

采购、委外或自制供给实际合格入库后，完整齐套仍可自动将 WAITING 推进为 READY，并保留精确物料预留及分仓 DRAW。此时 DRAW 是内部履约记录，仓库待领任务、领料单列表、角标、通知和发料命令均须通过车间提交门禁。

“我的车间任务 → 等待物料”中：

1. 未齐套显示琥珀色“车间已收到 · 等待物料”。
2. 齐套未提交显示青绿色“物料齐套 · 去领料”，可勾选或点击状态查看汇总。
3. 右下“批量领料”及任务双击详情的“去领料”打开独立领料汇总页；按实际叶仓、物料 UUID、颜色 UUID、单位 UUID 合并数量，并保留各工单及领料单来源。表前可多选、逐行填写本次申请量，后端按精确原行校验和记录。进入、刷新、返回均不提交业务。
4. 在汇总页点击“领料”后，记录车间领料意图，仓库才出现对应待发任务。本次只申请部分数量时，原应领数量不变，剩余可继续申请；仓库只能发已申请未发量。全部申请后车间显示“已提交领料 · 待仓库发料”。
5. 全部物料实际发完后显示可开工；车间明确开工后才允许报工。零物料任务继续直接进入可开工环节。

“逐行分次申请”与“先生产一部分产品”是不同动作。前者只减少本次提交仓库的物料量，不缩小执行任务，仍需领齐本执行批才能开工；后者从WAITING任务的“分批领料”进入，按[ADR-078](ADR-078-完整子批生产与实际用料余料退仓.md)先建立有完整套料证明的子批。原1000件只具备10套物料时可以先生产这10件，不能直接把原1000件任务以少领状态开工。

状态列表头提供等待物料、齐套待领料提交、已提交待仓库发料、已领齐或无需领料可开工四类筛选。筛选在服务端分页前生效，与车间筛选及关键词组合。选择可同时包含领料和开工行，两个批量按钮各自展示并处理符合条件的数量。

## 写入和历史

`POST /production/workshop-tasks/draw-request/preview` 只读当前任务、版本和精确 DRAW 明细；`/submit` 使用所审阅的版本、汇总指纹和幂等键。一次最多 50 个任务、同一车间，可跨计划和实际仓库。查看和提交均要求 `production_execution:view` 与 `production_execution:start`，并继续核对任务对象范围。

V559 在现有执行段事件账记录 `DRAW_REQUEST` 和本次精确 DRAW UUID，不新增平行任务表。提交不扣库存、不改变预留量、不自动开工。任何版本、物料、仓库或成员变化均须重新核对；同人同键完整重放返回此前结果，任一任务失败整批回滚。网络回执不确定时前端保留汇总并用同键重试。

未出库的历史自动任务需要明确提交；已实际出库的单据继续履约和反向，不补造历史申请。一个任务有多个实际仓库时，已开放的单据不重复申请，尚未开放的单据仍可提交。重建的 DRAW UUID 不继承旧单申请。没有普通执行段关联的历史或品质恢复专用单据继续按其既有流程办理。

V564 将整单可见门禁与逐行数量分开：`fn_production_draw_requested` 保留单据读取和历史可见性，`fn_production_draw_fully_requested` 控制车间继续申请入口，`fn_production_draw_pending` 与逐行累计申请量控制仓库待办、通知及可发额度。每次追加申请使用独立事件通知键，数量完全发完之前不撤掉仓库行动提醒。旧的自动通知也受门禁过滤，不能通过直链或旧通知绕过。

源单可见不表示所有物料已获发料授权：仓库单张和批量办理都只能消耗逐行“累计已申请−已实际发出”的有效余额。未选择、未申请的数量继续在车间保留；再次申请及取消出库后重新办理均复核精确来源和当前余额。接口与员工页见[我的车间任务](../03-页面/我的车间任务页.md)、[生产领料任务中心](../03-页面/生产领料任务中心页.md)、[V564数量守卫](../数据迁移/160-V564逐行分批领料申请数量.md)。

## 验证与发布

验收须覆盖齐套后仓库不可见、打开汇总零写入、提交后仓库出现、实际发完才可开工、同键重试不重复、跨车间及越权失败、指纹过期整批拒绝、分仓历史兼容、取消后重建单据重新提交。源码测试结果另记于本次治理记录；目标迁移、运行服务更新与真实岗位验收需单独完成。
