## 四、工程纪律（沿用 YTDQ.txt 要求）

- Flyway 结构迁移只允许向前演进；老库数据迁移当前是破坏性全量流程，不支持断点续跑或失败后
  原地重放。失败后按手册清理/重建目标库，从受控源快照重新执行并对账；不得用
  `IF NOT EXISTS` / `ON CONFLICT` 掩盖半迁移状态。
- 一次性测试/探针代码用完即删，注释不泄露敏感信息
- 并发：所有审核入口 PESSIMISTIC_WRITE 行锁；预留校验与建行同事务
- 跨模块不建真 FK（契约 §一），联动走 Service 层
- 通知是旁路：必须 afterCommit + 独立事务发送，失败不得影响主事务（参考 ChainNoticeService）
- 文档三件套同步：本目录 01（SOP/映射表）+ 02（维护矩阵/实现进度）+ README 阶段表
