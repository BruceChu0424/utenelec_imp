## 可复现的业务结果

| 场景 | 实际验证 |
|---|---|
| 普通生产与余料 | 实发 22，分报 40/8 和 60/12，申请退 2 时不首次学习；仓库实收退料后，100 件耗 20，BOM=0.2；原冻结需求仍 22 |
| 实际超产 | 原计划 100，实产 110、实耗 22，需求/公共分账后平均仍 0.2；同键重复审批不重复累计 |
| 非整除单位量 | 计划 3、实发 2、实耗 1.8、实际退收 0.2，BOM=0.6；不能因六位单耗舍入而少支持一件开工 |
| 多个实际仓 | 同一材料从两个叶仓领用，只形成一个材料需求，两个 DRAW 分别保留实际库存来源，不重复学习 |
| 旧知识与新草稿 | 保存/删除未审草稿不改既有有效累计、BOM 和修订号；新增实领未耗保留旧有效贡献，新批闭合才更新 |
| 真正反向 | 已审产出或真实耗用被冲销、确认退料使旧贡献失效时，撤回或修正该族贡献；草稿不能掩盖失效事实 |
| 人工与主档边界 | 人工修改/删除 BOM 后停止自动发布；环路、颜色/单位冲突、主档身份变化保留阻塞原因；普通数量更新不占全局结构锁 |
| 超产默认与记忆 | 无记忆制造叶 10%、上层 0%；学出采购原料子层仍为制造底层；显式 0、批准后的最新值、同率合并后的确认值都持久保存 |
| 错误及权限 | 无材料/未实发不能开工；缺库存、跨主仓、过期版本、不同幂等意图整笔拒绝；仓库与车间岗位/对象范围复核 |
