# 财务录入与表格公共交互统一

本轮分支 `uimp/finance-entry-ui-20261103`，从本地 `8937e02d2` 隔离实施。范围为前端呈现/交互、公共表格能力及财务报表的只读列候选合同；没有修改会计计算、账本、审核、写入幂等或数据库迁移。主工作树原有 `pubspec.lock` 和 `tmp/` 不纳入。

界面设计与审查采用默认 `frontend-design`，复用 Uten 组件、主题 token 和业务约束；不自动使用 `ui-ux-pro-max`。

## 财务五类单据

覆盖销售收款、采购付款、一般费用、其它收入和银行存取款的新建入口，以及共用选择组件的编辑/结算入口。

| 用户反馈 | 原实现与原因 | 公共入口和结果 |
|---|---|---|
| 费用项目不能就地添加 | 项目下拉未接已有类别维护模板 | `FinanceStylePicker` 复用 `showPaymentStyleAddDialog`，沿用类别表单、查重、权限、草稿及未知提交保护；费用/收入主表、批量填写和其它费用项目共用 |
| 点击后很久才显示选项 | `listenableOf` 只接表格测量，格内控件未监听选中 UUID | 项目/转入账户以局部 `ValueListenableBuilder` 在下一帧回显，不依赖父页面重建；创建名称从权威响应发布，更早的树响应不能覆盖它 |
| 部门样式不一致 | 部门管理使用层级皮肤，选择树仍用旧徽标皮肤 | `UtenDepartmentTreeView` 默认采用部门管理同源皮肤，保留树结构、展开、搜索、选择和取消 |
| 收款账户表格贴边 | 搜索框有水平内边距，表格没有 | 账户选择面板搜索和表格共用同一缩放间距，付款等同责调用同步 |
| 备注在金额和设置中间 | 新建列直接穿插旧明细列 | 五类单据共用 `financeRemarkColumn` 并置于末列；原表格键不变，以布局版本仅迁移备注位置，保留自定义列、列宽和其它设置 |
| 收款文案难懂 | 未结原币、本次分配收款 | 改为“未结金额”“本次收款金额”，付款统一为“本次付款金额”，保留原币语义提示及服务端合同 |
| 收款金额、费用、实际入账过多 | 三者在主表并排，但业务含义不同 | 主表保留收付款金额，费用与实际账户金额收进结算设置；原始控制器与草稿字段保留。校验失败定位该行并打开设置 |

金额差异仍以原服务端规则为准：同币种从到账扣费时，实际入账为收款金额减结算费用；费用另付不扣减到账金额；付款实扣包含费用。跨币种须记录银行真实账户金额，不能当作收款原币或参考汇率折算值删除。同币种实际金额留空时沿用原精确自动计算，非空原文继续校验而不静默覆盖。旧草稿费用拆分、精确小数和未知提交均保留。

## 公共表格

`UtenTotalsSummaryBar` 与 `UtenTotalEntryView` 统一使用主题 `bodyLarge`，标签和数字均为正常正文字号，不按 `density` 缩小；金额保持既有错误色/币种、数量单位分组和原始精度。带添加行的表格在宽屏同排左放添加操作、最右放汇总；窄屏或大字按阅读顺序换行，金额不缩字、不省略。

表格日期入口迁入 `toolbarActions`，与表头设置、打印和下载共处表格工具栏。`UtenTableActionScope` 只统一工具栏按钮尺寸，不改变单元格、业务表单或弹窗按钮。日期按钮仅显示选择动作；已选范围保留提示和无障碍语义。已在列头显示的重复筛选标签不再另占一行，列头筛选与清除保留。没有对应列头的全局查询前置条件按业务差异保留。完整调用及差异见 [工具栏与汇总清单](全平台整改交接/evidence/finance-entry-ui-20261103/toolbar-summary-callers.json)。

历史门控的 `UtenHistoryTimeFilter`、`UtenDocumentLifecycleFilter` 与 `WarehouseHistoryGate` 使用显式工具栏动作接入各表，保留未选择/全部/日期区间三种原语义，范围结果收进提示；卡片列表并入既有操作行。首次查询失败或尚无元数据时仍保留空表壳和日期工具栏，不让用户只能以相同日期反复重试。物料反查的关系表与实际追溯两种结果模式共用同一日期动作。

文本列输入后展示匹配候选；点选文本候选立即执行搜索。引用 ID 与展示名称不同的颜色、仓库等候选保留精确 ID 筛选。财务报表候选经 `/finance/reports/column-candidates` 使用拥有者授权投影、相同筛选条件及分页合同，不从当前页抽取名称。完整调用与报表权限验证见 [候选清单](全平台整改交接/evidence/finance-entry-ui-20261103/column-candidate-callers.json)。

本轮包含真实控件与模拟 API 的快速选择/创建、取消、延迟响应、千行连续编辑、精确金额、未知提交恢复及宽窄/大字截图。各项最终结果、日志和源码指纹由本轮证据保存。正式 CI、现网 UAT、Win7 真机及正式客户端交付独立验收；本分支没有推送、部署、正式打包或上传。
