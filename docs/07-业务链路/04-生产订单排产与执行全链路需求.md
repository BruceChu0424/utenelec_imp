# 生产订单排产与执行全链路需求规格说明书

> **文档版本**：v1.1
> **创建日期**：2026-07-30
> **更新日期**：2026-07-30
> **适用范围**：生产部、PMC部、销售部、采购部、仓库、车间
> **基于系统**：Uten IMP V90-V100 现有业务链基础上优化

---

## 一、需求背景与目标

### 1.1 背景
现有生产排产流程存在以下痛点：
1. 物料详情默认折叠，调度需要手动展开才能看到BOM和缺料情况，操作繁琐
2. 需要手动选择车间后才能生成计划，操作路径长，无法批量排产
3. 部分物料齐套、部分缺料时无法灵活拆分生产，导致整单等待
4. 缺料时没有替代料推荐，只能等采购，耽误交期
5. 排产时不考虑车间产能负荷，容易出现一个车间排满、另一个车间空闲的情况
6. 物料没有锁定机制，容易出现多个订单抢同一批料的情况
7. 超领物料没有审批流程，容易造成物料浪费
8. 急单插单时无法快速评估对现有计划的影响
9. 生产进度上报入口不清晰，车间报工不便，无法记录工时
10. 生产余料没有标准化退库流程，良品不良品不区分，容易造成物料浪费和账实不符
11. 销售无法实时看到订单生产进度、延期原因，需要反复询问生产部
12. 没有统一的生产看板，主管无法全局掌握所有车间生产情况

### 1.2 目标
1. 简化排产操作：一键生成子计划，支持批量排产，减少手动操作步骤
2. 物料信息透明：默认展开BOM物料详情，齐套状态、替代料一目了然
3. 灵活拆分生产：支持部分齐套部分生产，缺料自动推荐替代料，不因为个别缺料耽误整单进度
4. 资源合理分配：排产时自动校验产能负荷，避免资源冲突，物料自动锁定防止抢料
5. 全链路闭环：从排产→派工→领料→报工→补料→退料→入库→进度同步全流程线上化
6. 异常快速响应：插单、改量、不良、缺料等异常自动评估影响，通知相关人员
7. 跨部门协同：生产进度实时同步销售，关键节点自动通知，各部门信息一致

## 二、整体业务流程

```
销售订单审核通过
    ↓
生产部待排产列表（按交期升序，急单标红，支持多选批量排产）
    ↓
点击订单进入排产页面
├─ 订单信息区（客户、交货期、产品明细、齐套率）
└─ 物料详情区【默认展开】
    ├─ 逐行显示BOM展开物料
    ├─ 自动计算：需求量/可用库存（扣安全库存）/在途/已锁定/净需求/齐套状态
    ├─ 缺料物料自动显示可用替代料，提示是否使用替代料排产
    └─ 状态标识：🟢齐套 / 🟡部分缺料 / 🔴完全缺料
    ↓
点击【一键生成子计划】（支持多选订单批量生成）
    ↓
右侧滑入子计划编辑面板
├─ 系统自动按齐套情况+车间产能负荷拆分子计划
├─ 齐套部分 → 可执行子计划（自动锁定对应物料）
├─ 缺料部分 → 自动生成采购申请 + 待料子计划
├─ 自动校验车间未来7天产能，超负荷时推荐其他空闲车间
└─ 用户可编辑：车间/数量/日期/负责人/增删子计划/使用替代料
    ↓
确认生成正式生产计划
├─ 可生产子计划状态：待派工
├─ 待料子计划状态：待物料，关联采购申请
└─ 自动生成对应领料单，推送给仓库备料
    ↓
生产派工：调度将子计划派工到具体班组/工人
    ↓
生产执行阶段
├─ 车间领料：按单调料，超领需提交申请审批
├─ 车间报工：录入完成数量/不良数/工时/上传凭证，支持多次分批报工
├─ 补料申请：生产中物料损坏/不良提交补料申请，审批后发料
├─ 进度实时同步销售端，显示延期原因
├─ 余料退库：生产完成后剩余物料分良品/不良品退回仓库
└─ 不良品自动生成补产计划
    ↓
成品入库 → 自动释放物料锁定 → 补库存预留 → 通知销售可发货
    ↓
销售端看到订单可发货，安排出货
```

## 四、详细业务逻辑

### 4.1 物料齐套计算逻辑
```
可用库存 = 实际库存 - 安全库存 - 已锁定库存（其他订单已排产未领用的物料）
净需求 = 总需求量 - 可用库存 - 在途采购数量（预计到货日期 ≤ 计划开工日期）

齐套状态判断：
1. 净需求 ≤ 0 → 🟢齐套：物料足够，可全额排产
2. 0 < 净需求 < 总需求量 → 🟡部分缺料：可先排产（可用库存 + 在途）能支持的数量，缺额部分待采购或使用替代料
3. 净需求 ≥ 总需求量 → 🔴完全缺料：无可用库存，必须先采购或使用替代料，生成待料子计划
```

**计算口径统一**：使用现有`v_stock_available`视图的可用库存，安全库存从物料主数据读取，与全系统库存口径保持一致。

**替代料逻辑**：
- 缺料时自动读取BOM中维护的替代料关系，检查替代料的可用库存
- 如果替代料库存足够，提示用户是否使用替代料排产，用户确认后自动替换物料，直接生成可生产子计划
- 使用替代料的子计划在领料单和生产工单上明确标注替代料信息，避免车间领错料

### 4.2 物料锁定机制
- 子计划确认生成后，系统自动锁定对应数量的物料（软锁定，和销售订单预留逻辑一致）
- 锁定的物料不能被其他订单占用，避免多订单抢料
- 子计划取消或红冲时，自动释放对应锁定的物料
- 待料子计划不锁定物料，等物料齐套转为可生产状态时再锁定
- 领料出库时自动扣减对应锁定数量

### 4.3 一键生成子计划拆分规则
点击按钮后系统自动按以下优先级拆分：
1. **按产品拆分**：不同产品单独生成子计划，不合并不同产品
2. **按齐套情况拆分**：
   - 同一产品齐套部分：生成一条「可生产」状态的子计划，数量=可用库存能支持的最大产量
   - 同一产品缺料部分：如果有可用替代料且用户确认使用，生成可生产子计划；否则生成一条「待物料」状态的子计划，数量=净需求对应的产量，同时自动生成对应物料的采购申请
3. **按产能负荷拆分**：
   - 优先分配到该产品默认生产车间
   - 如果默认车间未来7天产能负荷>90%，自动推荐其他负荷低的空闲车间
   - 单条子计划数量不超过对应车间单日最大产能，超过的话自动拆分为多日生产的子计划
4. **同产品同车间同状态合并**：如果同一产品同一车间有多笔可生产数量，自动合并为一条子计划
5. **交期优先**：交期近的订单子计划开工日期优先排前，急单/特急单优先级最高
6. **批量排产**：多选订单批量生成时，按交期优先级统一分配产能，避免先排的单占满产能导致急单排不上

### 4.4 插单与重排逻辑
遇到急单需要插单时：
1. 在待排产列表将订单标记为「特急」优先级
2. 点击一键生成子计划时，系统自动重算产能：
   - 优先保证特急单的物料和产能
   - 自动计算对现有未派工计划的影响，提示哪些计划需要延期、延期几天
   - 用户确认后自动调整受影响计划的开工/完工日期，通知对应车间和销售
3. 已经派工、3天内就要开工的计划进入「冻结期」，不自动调整，需要主管手动确认才能改期，避免打乱车间已经安排好的生产

### 4.5 派工与领料流程
1. **派工**：可生产状态的子计划，调度可派工到具体班组/工人，派工后状态改为「已派工」，对应工人在「我的生产任务」中能看到该任务
2. **领料单自动生成**：子计划派工后自动生成领料单，推送给仓库备料，领料单数量严格按BOM计算（含合理损耗）
3. **领料控制**：
   - 仓库按单调料，扫码确认物料和数量，不能超单领料
   - 正常损耗范围内的领料直接发料
   - 超出BOM数量的领料需要提交【超领申请】，说明超领原因（物料损坏/不良/损耗超预期等），经生产主管审批后才能发料
   - 超领记录自动关联子计划，用于后续不良率分析和成本核算
4. **补料流程**：生产过程中物料损坏、来料不良需要补料的，提交补料申请，经主管审批后仓库发料，补料数量自动记录到子计划成本

### 4.6 部分缺料的特殊处理
这是本次需求的核心逻辑，解决"部分料够部分料不够就整单等着"的痛点：
1. **可生产部分立即执行**：齐套部分的子计划确认后，立即锁定物料、生成领料单，仓库可备料，车间可立即开工，不需要等缺料
2. **缺料部分自动跟踪**：
   - 待料子计划关联对应的采购申请
   - 采购入库时自动检查对应子计划的物料是否齐套
   - 齐套后自动将子计划状态从「待物料」改为「可生产」，同时发送通知给生产调度安排派工
   - 如果采购延期，自动更新子计划的预计开工/完工日期，同步通知销售
3. **分批次报工入库**：同一订单的不同子计划可独立报工、独立入库，入库后自动补预留，销售可分批次发货
4. **销售端可见拆分状态**：销售在订单详情页能看到"第一批X个已在生产，预计X号完成；Y个待料，预计X号到货后生产，X号完成"，以及延期原因

### 4.7 生产报工与进度上报
每个子计划独立报工，支持多次分批报工：
1. **报工入口**：
   - 生产子计划详情页顶部【进度上报】按钮
   - 车间工作台「我的待报工」列表，直接点击报工
   - 工人「我的生产任务」列表，直接点击报工
2. **报工表单字段**：
   - 子计划编号（自动带出，只读）
   - 本次完成数量（必填，数字，不能超过子计划剩余未报数量）
   - 不良品数量（必填，默认0，不能超过本次完成数量）
   - 实做工时（必填，数字，单位小时，用于绩效和成本核算）
   - 实际开工时间（日期时间，默认带出本次开工时间）
   - 本次完成时间（日期时间，默认当前时间）
   - 生产负责人（自动带出当前登录人，可修改）
   - 本次完成人员（下拉选择参与生产的工人，可多选）
   - 凭证上传（可选，支持上传最多9张生产现场/成品照片，或检验报告文件）
   - 不良原因（如果有不良品，下拉选择：来料不良/生产损坏/操作失误/其他）
   - 备注（可选）
3. **报工提交后逻辑**：
   - 自动更新子计划进度：已完成数量 = 累计报工合格数量（完成数量-不良品数量）
   - 累计实做工时，用于后续产能核算和绩效
   - 进度实时同步到销售端订单详情页，显示当前进度和预计完工时间
   - 第一次报工自动将子计划状态改为「生产中」
   - 累计合格数量 ≥ 子计划数量时，自动标记子计划为「待入库」，触发成品入库单生成
   - 不良品数量 > 0时，自动生成对应数量的补产子计划（关联原订单），同时通知生产调度和销售延期情况
   - 本次报工如果是该订单的第一次报工/最后一次报工，自动发送通知给对应销售
4. **报工审核**：工人提交的报工需要车间主管审核，审核通过后生效，审核不通过退回修改

### 4.8 余料退库流程
解决生产完成后剩余物料的管理问题，严格区分良品和不良品：
1. **退库入口**：子计划详情页，当子计划状态为「待入库」或「已完成」时，显示【余料退库】按钮
2. **退库表单**：
   - 子计划编号（自动带出）
   - 退库物料列表（自动带出该子计划领用的所有物料，显示领用数量、已使用数量、可退数量）
   - 每行物料可填写实际退库数量（不能超过可退数量），并选择退料类型：良品/不良品
   - 退库原因（下拉：剩余良品、来料不良、生产损坏、错领多领、其他）
   - 不良品处理方式（如果是不良品：报废/退供应商/返工）
   - 备注
3. **退库流程**：
   - 车间提交退库申请 → 自动生成退料单（状态=待审核）
   - 仓库收到待审核退料单，实物点收，区分良品和不良品：
     - 良品点收无误后审核通过，物料回原材料仓，增加可用库存
     - 不良品点收后入不良品仓，按选择的处理方式后续走报废/退供应商/返工流程
   - 所有物料退库完成后，子计划才能标记为「已完成」
4. **余料追溯**：余料退库记录自动关联子计划和领料单，可追溯物料来源和去向

### 4.9 销售端进度同步机制
实现生产进度对销售透明，不需要反复询问：
1. **订单详情页进度展示**：
   - 每个产品行显示生产进度条：已排产X% / 生产中X% / 已完工X%
   - 进度条不同颜色：已排产=灰色，生产中=蓝色，已完工=绿色，延期=红色
   - 鼠标悬停/点击进度条显示详细拆分：每个子计划的数量、状态、预计完工时间、延期原因（如果有）
   - 显示关键节点时间：排产时间、开工时间、预计完工时间、实际完工时间
2. **实时同步规则**：
   - 子计划生成、派工、报工、入库、退库、延期等所有状态变更，实时更新销售端进度，无人工干预
   - 数据一致性通过现有`plan_order_item_links`关联表保证，不冗余存储
3. **关键节点自动通知**（复用现有`ChainNoticeService`旁路通知机制）：
   - 子计划生成：通知销售"您的订单{orderNo}已安排生产，预计{date}完工"
   - 开始生产：通知销售"您的订单{orderNo}已开始生产"
   - 部分完工入库：通知销售"您的订单{orderNo}已有X个产品完工入库，可安排发货"
   - 全部完工入库：通知销售"您的订单{orderNo}已全部生产完成，可发货"
   - 补产/延期：通知销售"您的订单{orderNo}因{reason}，预计延期{days}天，新的预计完工日期{date}"
   - 缺料待料：通知销售"您的订单{orderNo}因物料缺料，预计延期{days}天，已安排采购"
4. **销售可见范围**：
   - 销售只能看到自己负责的订单进度（遵守现有`owner_employee_id`权限隔离）
   - 销售主管可看到所有下属订单的进度
   - 进度信息不包含成本、物料价格、内部不良率等敏感信息，只显示数量、时间和客户需要知道的延期原因

## 五、边界场景与异常处理

| 场景 | 处理逻辑 |
|---|---|
| 所有物料全缺 | 所有子计划都是「待物料」状态，自动生成全额采购申请，通知采购和销售预计交期延后 |
| 缺料有替代料 | 自动提示可用替代料，用户确认后使用替代料直接排产，无需等采购 |
| 车间产能超负荷 | 自动推荐其他空闲车间，强制分配到超负荷车间时需要主管确认 |
| 生产中物料损坏/报废 | 车间提交补料申请，说明原因，审批后发料，自动调整子计划完工日期，不良品计入不良率 |
| 超领物料 | 系统默认拦截，必须提交超领申请说明原因，生产主管审批后才能发料，超领记录留痕 |
| 订单临时改量 | 改量后自动重新计算物料需求和产能，已生成未派工的子计划自动更新数量，已派工的子计划走变更流程，通知相关人员 |
| 订单取消 | 自动取消所有未开始的子计划，释放锁定的物料，关闭对应采购申请，已领用未使用的物料自动触发退库，已生产的成品入通用库存 |
| 急单插单 | 自动评估对现有计划的影响，提示延期计划，用户确认后调整计划，冻结期内的计划需手动确认 |
| 采购提前到货 | 待料子计划自动提前转为可生产状态，通知调度可提前安排生产，可提前交期 |
| 采购延期到货 | 自动更新待料子计划的预计开工/完工日期，同步通知销售交期延后和延期原因 |
| 子计划拆分错误 | 调度可在子计划未审核前直接编辑修改，已审核的走计划变更流程 |
| 余料不退库 | 子计划无法标记为已完成，月度盘点时系统自动统计未退料的子计划提醒处理 |
| 超量报工 | 系统硬校验：累计报工数量不能超过子计划数量+合理损耗范围（默认5%，可配置），超了直接拒绝 |
| 跨车间转产 | 可直接编辑子计划的分配车间，修改后释放原车间产能，锁定新车间产能，通知新旧车间负责人 |
| 不良品超标 | 单条子计划不良率超过10%自动预警，通知生产主管介入分析原因 |
| 物料到齐后产能不足 | 物料齐套但车间排满时，自动将子计划加入待排产队列，按优先级排队，通知调度 |
| 领料时发现物料质量问题 | 直接在领料时提交来料不良报告，触发退料和补料流程，通知采购和IQC |

## 九、验收标准

1. **操作简化**：从进入订单排产页面到生成正式计划，点击次数不超过3次（进入页面→一键生成子计划→确认生成），支持批量排产
2. **物料展示**：进入排产页面后无需任何点击，直接能看到所有产品的BOM物料、齐套状态、可用替代料
3. **安全库存保护**：齐套计算自动扣除安全库存，不会占用安全库存排产
4. **物料锁定**：子计划确认后自动锁定物料，其他订单无法占用，取消后自动释放
5. **部分排产**：部分齐套的订单可以成功拆分，齐套部分能立即生成可执行计划，不需要等缺料
6. **替代料功能**：缺料时能正确显示可用替代料，选择后可直接排产
7. **产能校验**：排产时自动校验车间产能，超负荷时提示并推荐其他车间
8. **领料控制**：不能超BOM领料，超领必须走审批流程
9. **进度同步**：车间报工审核通过后10秒内，销售端订单详情页能看到进度更新和延期原因
10. **余料退库**：子计划完成必须分良品/不良品退库才能标记完成，退库审核后对应仓库库存自动增加
11. **插单功能**：急单插单时能正确评估对现有计划的影响，提示延期计划
12. **通知准确**：所有关键节点通知能准确发送到对应人员，没有漏发、错发
13. **数据一致**：排产、锁定、领料、报工、补料、退库、入库全流程操作后，库存数量、订单数量、计划数量完全一致，没有账实不符
14. **异常处理**：改量、取消、不良、采购延期、插单、超领等异常场景都能正确处理，没有数据错乱
