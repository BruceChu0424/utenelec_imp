# V788：报价议价与客户确认

迁移文件：`server/src/main/resources/db/migration/V788__sales_quote_negotiation_and_customer_acceptance.sql`。业务规则见 [ADR-139](../99-决策记录-ADR/ADR-139-销售报价议价客户确认与货品报价历史.md)。

- 报价表新增重议价来源、客户接受时间／人员／版本、取消原因／时间／人员。
- 客户接受三字段必须同时为空或同时有值；取消必须具有完整事实且状态为已取消。
- 活跃重议价来源建立唯一索引，保证同一原报价的重复请求复用新报价。
- 报价明细价格来源增加 SALES；财务单价仍须有财务定价时间。
- 不可变修订日志允许销售编辑、客户接受、取消及转单动作；新增快照 GIN 索引用于货品报价历史。

历史报价不补造客户同意。旧的已核价未转单报价需要销售实际登记客户接受；已转单的报价与订单保留原来身份。没有更新货品资料标价、库存、应收账或已发生履约数据。

上线前应备份数据库，核对现有迁移序列、来源订单关系和未转单报价。代码与前端须同批更新：报价编辑、提交、删除和转换均需要修订号，旧客户端会被拒绝并要求刷新。

本迁移不提供删列回滚。尚未接受新业务时可以按发布计划恢复一致的升级前备份；已经记录客户同意或产生新报价后，应保留这些商业事实，用前向修复处理。不得修改已应用迁移、执行 flyway repair 或删除报价历史来伪造兼容。

本地 Testcontainers 验证与生产迁移分开记录；本次开发不自动执行目标服务器迁移。
