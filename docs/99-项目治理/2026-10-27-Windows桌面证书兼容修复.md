# Windows 桌面证书兼容修复

## 结果

公司服务器已更换为兼容已发布 Windows 桌面版的证书链，用户在原桌面版重新登录后明确确认“已能正常登录”。没有重打或重装桌面版，没有替换公司根，也没有关闭证书验证。浏览器根信任安装保持有效。

## 根因及修复

首轮 HTTPS 运维在中间签发者添加了 critical IP nameConstraints。Windows 原生 X509Chain 和 OpenSSL 均能通过，实际 Windows Dart 3.12.2 连接真实公司服务器时返回：

```text
CERTIFICATE_VERIFY_FAILED: unsupported name constraint type
```

桌面版没有固定叶子证书；它固定验证公司根 PEM 的 SHA-256，并使用同一根建立独立 SecurityContext。公司根和资产均未变化，错误发生在提交账号密码之前。因此根安装或密码错误不是本次登录失败原因。

先恢复原有效根直签证书以恢复桌面 TLS，再使用相同签发者公钥及 subject 重签中间 CA：保持 critical CA TRUE/pathlen:0、keyCertSign/cRLSign 和三个精确 DNS 名称约束，移除 Dart/BoringSSL 不支持的 IP 名称约束；随后在正式 systemd 沙箱内重新签发和加载叶子。叶子继续包含三个审核 DNS 和精确内网 IP SAN，续期代码继续严格验证 SAN、根、密钥和链。

保留差异：DNS 签发范围由 CA 名称约束限定；IP 签发范围由固定审核的签发器及叶子校验器限定，不再声称 CA 扩展能在密码学层面限制 IP /32。签发者私钥仍为公司 root-only，服务不读取根私钥。把扩展改成非 critical 不能解决已识别扩展的匹配缺项。官方实现与兼容性记录：[BoringSSL](https://raw.githubusercontent.com/google/boringssl/main/crypto/x509/v3_ncons.cc)、[Dart tools](https://raw.githubusercontent.com/dart-lang/tools/main/pkgs/boring/test/conformance/x509_limbo_expected_failures.txt)。

新叶子 UTC 到期 `2027-10-27T16:22:05Z`，SHA-256 `E9CB180441EEF948731CFE205F34CCDB06449E54175CBA90CBA3BAC88472F3A2`。兼容签发者 UTC 到期 `2031-10-26T16:21:02Z`，根保持原值和 2036 到期。部署源码 SHA-256 `797960b605d4f76568b1d45bf4c332521a6b04a059489cf951898cddd06e4f74`，渲染后安装 SHA-256 `3197bb9733dcf0dde7e46977973125693823e990a6e38c1d378f80c0bc104852`。

## 验证

- 真实服务器新链在 Windows Dart 中，内网 IP 和主域均完成严格 TLS 握手；诊断经服务器管理网络连接，应用层按原 LAN ACL 返回 403，不能把该管理网络诊断当成业务权限放开或实际登录成功。
- 用户在原 Windows 桌面版确认正常登录，提供实际 LAN 登录验收。
- 新证书在 Windows 原生链验证通过（内部 CA 无公开 CRL，检查模式为 NoCheck），链状态无错误；OpenSSL 按 IP 和 serverAuth 验证通过，真实 LAN readiness 为 UP，Nginx 与应用 active。
- `test/core/network/company_tls_test.dart` 18 项通过：新增四项真实 Dart TLS 正负回归，在同一根、签发者 key/subject、叶子 SAN 下仅切换 IP nameConstraints；DNS-only 在 IP/主域均成功，带 IP 约束在两者均复现原生错误，HTTP 请求计数为零。两个 profile 均先通过 OpenSSL，避免使用本身无效链冒充兼容性测试。
- 自动续期 17 项隔离真实 OpenSSL 回归和原有 21 项 systemd/host 契约通过；新增拒绝旧 IP 名称约束。没有修改原契约测试来放行现场地址。

每日检查和提前 30 天自动续期沿用原任务，兼容性通过后恢复 timer。后续签发策略变更必须同时验收 Windows Dart 与实际公司网络 adapter，不能再以浏览器或 OpenSSL 验证替代。固定入口、监控、回滚及员工工具见 [LAN_TLS](../../deploy/simple/LAN_TLS.zh-CN.md)。
