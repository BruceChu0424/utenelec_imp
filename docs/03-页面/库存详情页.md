# 库存详情页

> 状态：已实现(2026-09-01 库存查询合并；2026-09-28 按 [ADR-135](../99-决策记录-ADR/ADR-135-仓库重量账与单重自学习.md) / V743 改为「库存余额 | 出入库流水 | 单重学习」三段面板)。
> 即时库存页双击货品行进入的单货品库存工作台；原「库存余额」「出入库流水」两页并入本页(旧路由 `/stock/balance`、`/stock/movement` 重定向保深链)。
> **Owner**：仓库 / PMC 运营部 | **创建日期**：2026-09-01 | **最后更新**：2026-09-28

## 一、页面与权限

- 路由：`/stock/item/:goodsId?tab=balance|ledger|weight`(路由名 `stock-item-detail`；库存类路由前缀要求 `stock:view`)。
  `tab` 缺省或认不出时落「库存余额」；拼链接用 `RouteName.stockItemDetail(goodsId, tab: 'ledger')`。
- 页面宿主 `lib/features/stock/pages/stock_item_detail_page.dart` 只负责标题(货品名 · 编号 · 系列 · 库位)、刷新与返回即刷新；
  三个分段是共享面板 [GoodsStockLedgerPanel](../02-组件库/GoodsStockLedgerPanel.md)(`lib/shared/stock_ledger/`)，
  与[货品详情「库存与出入库」页签](基础资料页.md)完全同一套。
- 动作权限：
  - 调整余额：`stock:balance:adjust`(高权限，自动生成已审核 `CHECK` 盘点单)。
  - 核重(只改库存重量)：`stock:weight:manage`(V743 新增，默认授给持有 `stock_doc:edit` 的仓储部)。
  - 称样校准：`warehouse_inbound:stock_in` / `stock_doc:edit` / `stock:weight:manage` 任一。
  - 设定单重、学习设置、排除/恢复称重记录、从今天起重新学习：`stock:weight:manage`。
  - 「各供应商」单重对比：`stock_report:view` 或 `stock:weight:manage`(供应商级数字属于报表级数据)。
- 页面权限面：`warehouse.stock-item`(V450 关联 `stock:view`、`stock:balance:adjust`；V743 再挂 `stock:weight:manage`)。

## 二、页面结构

```
┌──────────────────────────────────────────────────────────────┐
│ ← 货品名 · 编号 · 系列 · 库位                              ⟳ │
│ 库存 1,200 个 · ≈3.52 kg | 单重 2.93 g (±1.8%) | 最后入库 ... │  ← KPI 条
│ [库存余额] [出入库流水] [单重学习]        重量单位: 自动 ▾   │
├──────────────────────────────────────────────────────────────┤
│ 当前分段的表格 / 卡片                                        │
└──────────────────────────────────────────────────────────────┘
```

1. **KPI 条**(`GET /api/stock/insights/goods/{goodsId}`，`stock:view`)：库存数量 · 库存重量、当前单重与区间半宽、最后入库 / 最后出库、
   90 天日均出库 · 约可用天数、ABC(近 90 天无出库显示「ABC: 近90天无出库」)、30 天内库龄占比。只给货品级数字，不含供应商级数据；
   接口失败时整条隐藏，不影响下方分段。
2. **分段工具条**(`UtenFilterToolbar`，无搜索框)：库存余额 | 出入库流水 | 单重学习，行尾「重量单位: 自动▾」
   (账号级显示偏好，仓库各查询页共用)。
3. **库存余额**(`GET /api/stock/balances?goodsId=`)：列 仓库 | 颜色 | 库存数量 | 单位 | 库存重量 | 最后变动 | 操作。
   - 重量估算前缀「≈」(`weightEstimated`)，未知显示「未称」，不显示成 0。
   - 行操作：**查看流水**(切到流水分段并筛到该仓库 + 颜色；无颜色维度按 `colorNull=true`)、
     **调整**(`stock:balance:adjust`，打开余额详情面板的调整模式)、**核重**(`stock:weight:manage`；
     基本单位本身是重量单位的货品不显示，重量随数量精确换算)。
   - **不良品处置**([ADR-146](../99-决策记录-ADR/ADR-146-不良品仓业务规则与可用量单一口径.md))：仓库列里不良品仓带「不良品」标签。良品仓行有「转不良品仓」、
     不良品仓行有「不良复判转回」(能不能办由 `GET /api/stock/docs/defective-moves/options` 按独立权限
     `stock:defective_transfer` / `stock:defective_release` 下发，页面不拼权限)；点开右侧面板，货品、颜色、来源仓带入，
     调出/调入仓用仓库侧滑面板按用途选(转不良只能调入不良品仓、复判转回只能从不良品仓调出)，填数量和原因(必填)后
     「提交并过账」= `POST /api/stock/docs/defective-moves` 一次生成并审核一张调拨单(同一面板内重试沿用同一提交键，不会重复过账)。
     发出后结果未知(超时/断网/服务端 5xx)时面板顶部提示「上次提交的结果还没确认, 内容已锁定」，调出/调入仓、数量、原因都锁定，
     只能按原内容重试；服务端明确拒绝时什么都没办，内容可以改了再提交(同一提交键换内容服务端回 409)。
     「转不良品仓」记录的是事实，本仓的货就算全被预留占着也照样转得出去(只守在手数量)；转走后已经没有实物的预留由服务端列出，
     成功后另弹一条提醒「这些预留已经没有实物, 请通知相关人员」(例「「包材仓库」的包装袋还有 2000 已被预留……有 3 的预留已经没有实物」)。
   - 余额详情面板三种模式：详情 / 调整(目标数量 + 可选「调整后重量」，填了按盘点定重，不填按数量推算) /
     核重(「核定后重量」必须 > 0，原因 2-200 字；数量 ≤ 0 时不能核重)。重量输入都接受 850g、1.2t、3斤 这类带单位写法。
4. **出入库流水**(`GET /api/stock/goods/{goodsId}/ledger`，`stock:view`)：存货明细账。
   - 筛选：日期范围(默认近 90 天含今天)、「仓库(含下级)」选择器、表头筛选 类型 / 颜色 / 仓库(服务端 facet，一次一个值；
     颜色「无颜色」桶值 `__null__`)、「显示重量调整」开关。
   - 列：日期 | 类型 | 单号 | 往来方 | 仓库 | 颜色 | 收入数量 | 发出数量 | 结存数量 | 单位 | 收入重量 | 发出重量 | 结存重量 | 操作人 | 备注。
   - 汇总条：期初结存 · 本期收入 · 本期发出 · 期末结存(数量与重量都由服务端算)；范围内调拨、重量尾差调整不为 0 时追加显示；
     有未称行时注明「另有 N 行未称」。
   - 类型文案由服务端给：红冲行带「(红冲)」，报废单的其它出库显示「报废出库」；重量调整行显示
     重量起算 / 重量尾差调整 / 盘点定重 / 人工核重 / 撤销盘点重量。
   - 重量悬停说明来源：实称 / 按数量(精确) / 按比例分摊 / ≈按库存均重 / ≈按单重估算。未称的流水重量显示「未称」，
     结存重量未知显示「未知」。
   - 单号可点：按服务端 `sourceDocType` + `sourceDocCode`(仓库单据的 doc_type)跳来源单据；旧的按流水类型猜单据类型的代码已删除。
   - 往来方(供应商 / 委外商 / 客户 / 车间)只给持有该来源单据查看权限的人，否则显示「已隐藏」；调拨对方仓库不隐藏。
5. **单重学习**(`/api/stock/weight/goods/{goodsId}`)：
   - 卡片：当前单重、可靠度徽标(可靠 / 可参考 / 未学准)、依据(称重学习 N 次(有效 M) · 最近 / 人工设定 / 按过往领料推算 /
     货品资料的设计单重)、领料实发比应发偏差、单重可能已变化与称重矛盾提醒。
   - 按钮：称样校准(打开共享[称样校准弹窗](../02-组件库/WeighCountDialog.md))、设定单重(设定或取消人工单重，必须写原因)、从今天起重新学习。
   - 子分段：称重记录(服务端分页；来源/状态表头筛选；管理权限可排除/恢复，排除原因选填 2-200 字；来源单据被清空时显示「来源单据已清空」)、
     各供应商、学习设置(默认皮重 · 核对容差% · 单件离散% · 参与学习 · 批次切换 自动/手动，按版本号乐观锁保存)。
   - 基本单位就是重量单位的货品只显示说明「重量按数量精确换算，不需要学习单重」。

## 三、接口口径

- **流水**：`GET /api/stock/goods/{goodsId}/ledger?warehouseId&colorId|colorNull&dateFrom&dateTo&movementTypes&direction&includeWeightAdjustments&page&size`
  - `dateFrom` / `dateTo` 为业务日期(含 `dateTo` 当天)；`size` 最大 100；`movementTypes` 逗号分隔，伪类型 `W` = 重量调整。
  - 结存按「当前余额反推」：锚点是范围内当前余额，窗口内流水与重量调整按 `(transaction_date DESC, ledger_seq DESC)` 倒推；
    类型 / 方向 / 截止日只筛显示行，不改结存。基本单位是重量单位的货品结存重量直接按数量 × 系数。
  - 行字段：`rowKind`('M' 库存流水 / 'W' 重量调整)、`typeLabel`、`sourceDocType` / `sourceDocId` / `sourceDocCode` / `billNo`、
    `counterpartKind` / `counterpartName` / `counterpartMasked`、`qtySigned`(W 行为 null)、`weightKgSigned`(千克，null=未称；W 行为调整差额)、
    `weightSource`、`adjustmentKind`、`balanceQtyAfter`、`balanceWeightKgAfter`、`operatorName`、`amountLocal`(按 `goods:cost:view` 脱敏，`costMasked`)。
  - 汇总 `summary`：期初/期末/本期收发数量与重量、`internalTransferQty`、`inWeightUnknownRows` / `outWeightUnknownRows`、`residualKg`；
    `facets`：`movementType` / `warehouse` / `color`。
- **旧接口 `GET /api/stock/movements` 已删除**(连同 `MovementRow`、客户端 `repo.movements` 与 `ApiEndpoints.stockMovements`)。
- **余额**：`GET /api/stock/balances` 行增加 `weightEstimated`；`POST /api/stock/balances/adjust` 可选 `targetWeightKg`(千克，最多 4 位小数；
  目标数量为 0 时不能带；数量不变而重量不同也允许)，结果增加 `afterWeightKg`。
- **核重**：`POST /api/stock/weight/balances/set {warehouseId, goodsId, colorId, expectedWeightKg, targetWeightKg, reason, idempotencyKey}`
  → 写一条 MANUAL 重量调整(不动数量、不生成单据、不进单重学习)；`expectedWeightKg` 与当前不一致返回 409。

## 四、性能口径(大数据量)

- 余额按货品：`idx_stock_balances_goods_cover (goods_id) INCLUDE (warehouse_id, color_id, qty, weight, weight_estimated, last_movement_date)`
  覆盖索引免回表(V450 建，V743 重建时加入 `weight_estimated`)。
- 流水按货品倒序：`idx_sm_goods_ledger (goods_id, transaction_date DESC, ledger_seq DESC)`(V743 取代 `idx_sm_goods_date`；
  V450 的 `idx_stock_movements_goods_date` 已在 V676 作为冗余索引删除)；重量调整账另有
  `idx_stock_weight_adjustments_goods_ledger (goods_id, transaction_date DESC, ledger_seq DESC)`。
- `ledger_seq` 是流水与重量调整共用的记账顺序号：仓库单据按单据日期零点记账、同单同刻，只靠时间排序无法严格前后相接。

## 五、深链与兼容

- 即时库存行双击 → 本页(库存余额)。
- `/stock/balance` → 重定向 `/stock/instant-inventory`；`/stock/movement?goodsId=X` → 重定向 `/stock/item/X?tab=ledger`
  (货品详情、物料反查等旧深链落到出入库流水分段)；无 goodsId 的 movement 旧链回即时库存。
- 库存分析页「查看流水」「查看单重学习」分别带 `?tab=ledger`、`?tab=weight` 进入本页。
- 余额调整链路(`POST /stock/balances/adjust`)与 CHECK 单语义不变，只是可以顺带定重。
