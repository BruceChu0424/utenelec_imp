# 2026-10-20 货品顶层组件批量维护验证

范围：隔离分支 `uimp/bom-edit-and-trace` 上的后续源码实现。设计遵循 `frontend-design` 并复用 Uten 组件，具体规则见 [ADR-185](../99-决策记录-ADR/ADR-185-组装编辑草稿与共享组件同步.md)。本次没有提交、合并、打包、部署或操作业务数据库。

## 实现结果

| 用户需求 | 实现 |
| --- | --- |
| 货品资料批量添加 | 单品或多选右键进入批量维护，默认且固定维护所选货品顶层；可直接选组件，也可使用已复制组件 |
| 已有功能复用 | 提取共用组件选择器、数量输入和期间物料数量换算；复用原 APPEND/REPLACE、批删、学习与审计规则 |
| 已有组件处理 | ADD 对相同组件 UUID 跳过，保留原数量、其他字段、学习及审计状态；不按名字合并 |
| 指定移除 | REMOVE 仅删除指定 UUID 的直属关系，未命中跳过，停用旧组件可选；不删除货品主档、不递归修改共享子件内部 |
| 整份覆盖命名 | 旧入口明确为“覆盖整份组装清单(使用已复制组件)”，仅单个目标；原清空明确为“清空顶层组装清单”，预选现有关系进入 REMOVE 预览 |
| 权限 | ADD 要求编辑+新增组件；REMOVE 要求编辑+删除组件；OVERWRITE 要求三项权限。入口隐藏、保留回调、预览及提交均复检 |
| 二次确认 | 先显示逐货品新增、更新、移除、跳过数量，以及可见/隐藏的共享影响与业务提醒，再确认整批提交 |
| 冲突与结果不明 | 锁后复核状态指纹及共享影响；任一失败整批回滚。提交回执丢失时锁定输入，以同 token 核对原结果；关闭则刷新，不误报成功 |
| 身份变化 | 弹窗推入前绑定原身份，撤权时关闭主窗与期间物料子确认；旧组件复制请求迟到不能回写新账号剪贴板 |
| 功能边界 | 指定 A 组件替换成 B 组件继续在物料反查；没有新增货品列表指定替换入口；新建货品副本附带组件仍走原新建流程 |

一次最多 50 个目标货品；添加/单品覆盖最多 200 个组件，指定移除最多 500 个组件，保留原批删上限。实际新增、更新、移除合计最多 2000 条。若选中的货品本身被其他产品引用，确认仍展示真实共享影响。
