旧 `versionedSummaryTestResponse` 仍服务独立 JSON 页契约，仅增加保留原默认值的 scopeVersion 参数，供新流入口复用字面行切片；不把旧 JSON 调用方冒充流调用方。独立生产协议反例保留自己的损坏帧构造，不能批量迁移成永远有效的正例。

## 唯一同步 canonical 契约文本入口
