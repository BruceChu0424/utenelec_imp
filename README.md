# 优腾·综合管理平台（Uten IMP）

> **Uten Integrated Management Platform** — 制造业 200–1000 人规模的一体化企业管理后台。
> 一套 Flutter 代码覆盖 手机 / 平板 / 桌面 / Web，按部门（行政与人力资源/生产/工程研发/PMC/品质/综合营销/新媒体/轨道/财税）+ 权限点分权展示。

## 🛠 技术栈

- **Flutter 3.41+ / Dart 3.x** —— 最新 stable，企业主流
- **Riverpod 2.x** —— 类型安全、可测试的状态管理
- **go_router** —— 官方推荐路由，支持 Web/深链 + 路由守卫
- **Material 3** —— 设计系统底座
- **intl + gen_l10n** —— 官方国际化方案
- **shared_preferences** —— 偏好持久化（主题/语言/字号/性能档）
- **device_info_plus** —— 设备能力检测，喂给性能分级
- **hive** —— Mock 数据本地持久化（前端阶段）
- **very_good_analysis** —— 严格 lint 规则

详细选型理由见 [docs/01-规划/技术选型.md](docs/01-规划/技术选型.md) 和 [docs/99-决策记录-ADR/](docs/99-决策记录-ADR/)。

## 🚀 如何运行

```bash
# 1. 安装依赖
flutter pub get

# 2. 生成国际化文件（修改 arb 后需重新生成）
flutter gen-l10n

# 3. 运行（自动检测平台）
flutter run

# 4. 指定平台
flutter run -d chrome        # Web（推荐：浏览器拉宽即可看到响应式效果）
flutter run -d windows       # Windows 桌面
flutter run -d android       # Android（需模拟器或真机）

# 代码检查
flutter analyze

# 格式化
dart format .
```

> Flutter SDK 安装见 https://docs.flutter.dev/get-started/install
> 当前已验证：Flutter 3.44.2 stable、Windows 桌面、Web 构建均通过。

### Phase 0 地基 Demo 体验路径

1. 启动 App → 登录页（深绿青绿渐变 + 玻璃拟态卡片 + 进场动画）
2. 任意输入账号密码点登录 → 进入工作台首页
3. 工作台：4 个 StatCard + stagger 进场动画 + 数字滚动（性能档=rich 时）
4. 设置页：主题（浅/深）、语言（中/英）、字号（小/中/大/超大）、性能档（自动/省电/标准/极致）全部即时生效
5. **响应式验证**：Web 端拖动浏览器窗口宽度，工作台网格列数随容器宽度自适应（UI v4 起导航为全断点统一的底部悬浮胶囊，不再按宽度切换形态）
6. **性能档验证**：设置页切到"省电"，回到工作台看数字滚动动画消失（lite 档禁用）
7. 退出登录 → 回到登录页
