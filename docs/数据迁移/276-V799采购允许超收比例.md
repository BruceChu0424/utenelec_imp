# V799 采购允许超收比例

日期：2026-10-04。迁移 `V799__purchase_over_receipt_tolerance.sql`(本分支临时号, 合并进 main 时按 main 头 +1 重编号)。决策见 [ADR-144](../99-决策记录-ADR/ADR-144-采购允许超收比例与超出部分财务审批.md)。

采购下单可以给每行填「允许超收%」。累计净收货在「订货量 + 允许超收量 + 已退货 + 已过账财务批准超量 + 质检退回补货额度」以内照常入库、立应付, 不打扰财务; 超过的整张收货单照 ADR-019 隔离待财务。允许超收量只有一个口径: `T(q, p) = ROUND(q × COALESCE(p,0) / 100, 4)`(订货单位, 四舍五入), 数据库函数 `fn_purchase_over_receipt_tolerance` 与 Java `PurchaseOverReceiptTolerance` 逐位一致。比例为空等同 0, 即今天的严格口径。

## 结构变化

- `goods.purchase_allowed_over_receipt_pct NUMERIC(5,2)`, 0 到 100: 货品记忆值。保存采购订货单时按该货品最后一行非空值回写, 空行不清记忆; `/api/purchase/orders/last-terms` 预填并标来源 `GOODS_MASTER`(比例不随价格脱敏)。货品主档「采购默认」区经 `PUT /api/master/goods/{id}/purchase-receipt-policy` 单独修改, 只要 `goods:edit`。
- `purchase_order_items.allowed_over_receipt_pct NUMERIC(5,2)`, 0 到 100: 订货明细的允许超收%, 保存即冻结。新增采购专用冻结触发器 `trg_purchase_order_allowed_over_receipt_frozen`(照 V760 总金额冻结写法): 只有草稿且未进入财务审核、未批准的订单能改; 共享的 V438 商业冻结触发器不重建。
- `procurement_arrival_exceptions` 加四个快照列 `order_qty_snapshot`、`allowed_over_receipt_pct_snapshot`、`tolerance_qty_snapshot`、`prior_net_received_qty_snapshot`, 只有采购到货异常写(首次登记与重新检出都写), 一条 CHECK 保证要么全空、要么是采购且允许超收量等于按订货量和比例算出的值。到货异常通知与任务卡据此写「订 Q, 允许超收 p%(最多 Q+T), 此前已收 R, 本次实到 D」。

## 共享函数锚点补丁

三处都按现时定义(`pg_get_functiondef`)替换并核对命中次数, 锚点对不上即整次迁移失败:

- `fn_guard_procurement_received_with_arrival_allowance`(采购、委外共用): 只在 `TG_ARGV[0]='PURCHASE'` 分支给收货容量加 T(当前订货量, p)。
- `fn_guard_return_allowance`(采购、委外、销售共用): 只在 `purchase_order_items` 分支给退货红冲容量加 T × 换算率, 比例内收货的退货可以正常红冲。
- `fn_procurement_approval_display_snapshot`: 明细多出 `allowedOverReceiptPct`(trim_scale 文本), 财务审核页与改单复审对比读它。

共享函数只经 `to_jsonb(NEW)` 读比例, 不直接写 `NEW.allowed_over_receipt_pct`, 委外与销售表没有这列也不会在它们的触发器上报错。迁移末尾核对补丁结果。

## 不变的部分

- 预计到货仍在累计达到订货量时关闭, `ordered_qty` 与 `arrival_overage_posted_qty` 永远不含允许超收量。
- 委外订货不加超收比例, 委外回厂口径不变。
- 不加表、不加权限、不改存量数据; 新列沿用所在表的审计与测试清空政策(货品主档保留, 订单与到货异常清空)。

## 验证

在隔离的临时库(由 V794 模板库建出, 先套 V795 至 V797)上验证: 订 100、p=5% 收 105 通过、105.0001 被拒; 未填比例的行仍按 100 拦; 比例内收货的退货红冲通过, 未填比例时同样操作被拒; 草稿可改比例, 进入财务审核后改比例被拒、同值写入不受影响; 审批展示快照带出比例; 快照列 CHECK 拒绝算错的允许超收量与委外异常写快照; 委外订货行收货与退货守卫照常。源码目录不代表业务库已安装。
