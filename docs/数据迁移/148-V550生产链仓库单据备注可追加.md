# 148 · V550 生产链仓库单据备注可追加

> 迁移文件：`server/src/main/resources/db/migration/V550__production_linked_stock_document_remark_mutable.sql`（2026-09-10）

## 背景

V164/V232 的 `fn_guard_production_linked_stock_document` 把 `remark` 列入生产链仓库单据
（生产领料/退料/完工入库等）的「身份不可变」集合，任何 UPDATE 改到 remark 都被 23514 拒绝。
2026-09-10 出库弹窗与领料任务中心批量出库把「出库备注」追加到 `stock_documents.remark`
（`StockDocService.appendIssueRemark`：按「；」拼接、整条相同去重、单条 ≤200 / 总长 ≤500），
生产链领料单一带备注出库就被触发器拒绝——`FullChainEndToEndTest` 批量出库场景坐实，
此前的单张出库备注同样从未在生产链单据上生效过。

## 变更

- `CREATE OR REPLACE FUNCTION fn_guard_production_linked_stock_document()`：函数体复制自 V232，
  **只去掉 `NEW.remark IS DISTINCT FROM OLD.remark` 一行**；删除守卫、报工/库存清理授权分支、
  其余身份列（类型/单号/日期/仓库/供应商/客户/人员/计划号/来源单号/部门/班组/金额/删除标记）原样保留。
- 无表结构变更、无数据回填；已应用的 V164/V232 文件不改。

## 影响

- 出库（单张/批量）备注对生产链单据生效；备注仍只经出库流程追加，通用 CRUD 不开放。
- 清空业务数据脚本目录版本对推进到 V550/508（`server/ops/reset_business_data.sql`）。
