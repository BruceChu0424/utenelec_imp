# V527/V528 采购与委外收货撤回

本页记录未被后续业务使用的采购/委外收货撤回及对应本地专项证据。它不等于全部退货、补回代际和财务反向场景已完成，也不是目标库已应用或服务器已部署的证明。前置实现见[126启动整合](126-V513至V526启动整合与业务守卫.md)，当前组合状态见[统一验收](../99-项目治理/2026-09-07-全平台本地审计与整改验收.md)。

## 问题与结果

采购合格入库后，原费用价值已从QUALITY_PASSED位置转入库存；撤回不能只扣实物或用当前均价猜原费用，必须恢复原合格保管区间，再沿品质/收货反向。委外还含公司自有材料成本，须先按同一回厂实耗恢复材料来源，再撤回加工费和实际库存。已发货/已用或仍有成本分配依赖时整次拒绝，不留下半笔反向。

## V527 持久化合同

文件：[V527__unused_procurement_stock_in_reversal.sql](../../server/src/main/resources/db/migration/V527__unused_procurement_stock_in_reversal.sql)。

- `stock_value_events.position_store_reversal_of`唯一引用原入库价值事件，`stock_value_position_transfers.reversal_of_transfer_id`唯一引用原保管转移，均为延迟外键。
- 增加POSITION_STORE_REVERSE事件和REVERSED_POOL_CURSOR节点形状；保留原入库/转移/节点，不改旧事实，也不建立新的费用取得。
- `fn_stock_value_unused_receipt_head`检查当前池是否仍可沿明确的未用撤回链回到原入库头，有界检查而非按日期/货号猜来源。
- `fn_check_stock_value_reverse_transfer`核原source slice/root、数量区间、分母、修订和QUALITY_PASSED归位；`fn_check_stock_value_reverse_store`核实物反向、恢复保管、剩余库存池和对应posting守恒。
- 延迟约束均ALWAYS；普通转移守卫只对明确反向分支分派给专用校验，不关闭来源保护。

业务接线位于[ProcurementInventoryValueService.reverseStock/qualityReversed/receiptReversed](../../server/src/main/java/com/uten/imp/features/stock/valuation/ProcurementInventoryValueService.java)、[InventoryPositionService](../../server/src/main/java/com/uten/imp/features/stock/valuation/InventoryPositionService.java)及采购/委外收货原反向事务。部分入库或多次入库按实际已入切片恢复，未入量不伪造库存流水。

## V528 委外材料与产出退役

文件：[V528__unused_subcontract_receipt_value_reversal.sql](../../server/src/main/resources/db/migration/V528__unused_subcontract_receipt_value_reversal.sql)，接续V527。

- `stock_value_production_cost_outputs.withdrawn_movement_id`引用真实反向库存流水。原产出记录只能一次登记此字段，其它字段不可变，不能删除；撤回产出不再进入未来成本分配。
- `fn_stock_value_stored_cost_reversible`核成本对象类型、自有材料已按原数量完整恢复、无未解份额及待处理任务；正常损耗对象已有投入等情形仍拒绝。
- `fn_check_withdrawn_cost_output`将退出的产出与原入库、POSITION_STORE_REVERSE及真实负向SUBCONTRACT_RECEIPT流水一一对应。
- `fn_check_subcontract_material_unconsume`要求CONSUMPTION_RETURN匹配同一 `subcontract_receipt_material_consumptions.reversal_of` 和原材料成本节点，恢复SUBCONTRACT_WIP原owner，不改成整单平均来源。
- 未确认来源可能已知金额为0，此时不要求制造零posting，但数量、区间和来源守卫仍执行；这不等于确认该来源实际价值为0。

服务入口：[SubcontractOwnMaterialCostService](../../server/src/main/java/com/uten/imp/features/stock/valuation/SubcontractOwnMaterialCostService.java)、[SubcontractReceiptService.reverse](../../server/src/main/java/com/uten/imp/features/subcontract/receipt/SubcontractReceiptService.java)。实际成本及复杂反向边界见[成本专题](../99-项目治理/库存实际成本接线与验收.md)。
