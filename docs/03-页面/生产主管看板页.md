> **页面状态**：计划与真实子计划导航已实现；生产发布仍为 **NO-GO**
> **更新日期**：2026-08-01

---

## 一、当前页面边界

当前“生产主管看板”落在生产调度工作台的生产进度页，重点是计划追踪、筛选、置顶和下钻，不应宣称已有有限产能负荷、OEE、质量成本或实时车间大屏。

父计划卡展示单号、状态、车间、工期、今日完工、计划量和入库量；存在 `subplan_links` 时可展开真实自制件子计划进度。

## 二、独立点击域

| 点击区域 | 行为 |
|---|---|
| 父计划表头 | 打开父计划详情 |
| “子计划 N 张” | 仅展开/收起 |
| 具体子计划行 | 打开该子计划详情 |
| 置顶/重要菜单 | 只修改相应标记 |

以上点击域必须互不吞事件。子计划 ID 为空、路由失败或无权访问时显示明确反馈，不允许出现“点了没反应”。

## 三、状态与权限

- 查看计划不等于可编辑、派工或报工；
- 卡片状态来自服务端计划与入库事实，页面不直接改生产状态；
- 草稿、已审核、红冲、已完成和延期必须分别显示；
- 子计划展开后仍按自身状态和数量展示，不继承父计划的完成状态；
- 服务端对象范围与权限校验是最终边界。

## 四、后续完整看板

未来完整生产主管看板可增加待派工、生产中、待审核报工、待清料、延期、待料、粗产能和 Outbox 水位，但只有在标准工时、产能日历、质量与投影 SLO 有可靠数据后才能展示。当前不得用伪精确百分比代替缺失主数据。
