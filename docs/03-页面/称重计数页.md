# 称重计数页

> 路由：`/warehouse/weigh-count`(`lib/features/warehouse/pages/warehouse_weigh_count_page.dart`)
> 权限：`stock:view` 进页；保存抽样另需 `warehouse_inbound:stock_in` / `stock_doc:edit` / `stock:weight:manage` 任一 · 页面权限面 `warehouse.stock-item`
> 上层：仓库管理 hub → 「库存查询」分区「称重计数」卡 · 决策：[ADR-135](../99-决策记录-ADR/ADR-135-仓库重量账与单重自学习.md) §3.4
> **创建日期**：2026-09-28 · **状态**：源码候选

## 一、定位

手机放在秤旁用的独立页：选一个货品，把货放上秤，按学到的单重折算大约多少件；单重还没学准时数 10 件以上放秤录一次「本批抽样」，
单重立即重算、越学越准。**本页不改任何库存**：只算数，可选保存抽样(一条 SAMPLE 称重观测)，不调用任何出入库过账接口(有测试断言)。
单据里要把称重结果写进数量或重量时，用各采集表格格内的 ⚖ 称重计数弹窗，那是同一个面板。

## 二、页面结构

1. **选货品**：未选时显示操作说明与「选择货品」按钮(`showUtenGoodsPicker`，范围全部货品)；选好后顶部显示货品名称 / 编号 / 单位，可「换一个」，
   并提供「查看本货品的单重学习」(打开[库存详情页](库存详情页.md) `?tab=weight`，需 `stock:view`)。
2. **称重面板**：嵌入共享 `WeighCountPanel`(场景 `standalone`，与[称重计数弹窗](../02-组件库/WeighCountDialog.md)同一份面板)：
   - 毛重(可「再称一次」多次相加) − 皮重 × 件数(箱/袋/托盘，可预填默认皮重或最近一次皮重) = 净重；
   - 按当前单重折算件数，给 95% 区间与可靠度徽标(可靠 / 可参考 / 未学准)和依据说明，超过一定件数时提示「超过 N 个时称重计数只是估算」；
   - 可选「本批抽样」(数量 + 重量，抽样单位默认克)，抽样会与已有单重融合收窄区间；按件计的数量折算后取整；
   - 按钮：「清空重来」、「保存抽样」(有抽样且有称样权限时可点)。
3. **保存后**：提示「抽样已保存, 当前单重 …」，显示按刚保存的抽样重算后的单重，并重置面板以便称下一批。
4. **无称样权限**：页面顶部提示「你没有称样权限: 可以称重算数, 但抽样不会保存进单重学习」，仍可称重算数。

## 三、接口

- `POST /api/stock/weight/params`(`stock:view`)：取货品的单重参数(依据、单重、区间参数、默认皮重 / 最近皮重、可靠度等)。
- `POST /api/stock/weight/goods/{goodsId}/samples`(称样三权限任一)：`{qty(基本单位), weight(净重，按 weightUnit), weightUnit, tareKg?, supplierId?, warehouseId?, newRegime, remark, idempotencyKey}`；
  服务端同步重算并返回最新单重详情。按重量计的货品与关闭了学习的货品返回 409；同一幂等键不同内容返回 409。

## 四、权限与边界

- hub 卡与路由守卫只要 `stock:view`(七个部门持有，含品质、研发)，谁都能称重算数；保存抽样由页面与服务端按称样三权限再把关。
  若以后只想给仓库人员看到这张卡，需同时改 `permission_by_path.dart` 与 `test/route_permission_full_coverage_test.dart` 的已核对清单。
- 「记住为本货品皮重」只对持有 `stock:weight:manage` 的账号显示(需要改货品称重设置)；其余账号的皮重记忆靠服务端返回的最近一次皮重。
- 不接秤硬件：输入统一走这一个面板，将来加「读秤」只改一处。
