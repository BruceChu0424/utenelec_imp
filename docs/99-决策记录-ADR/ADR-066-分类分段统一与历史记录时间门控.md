# ADR-066：分类分段统一范式——去「全部」段 + 末尾历史记录时间门控 + 详情页直达生成订货单

- 日期：2026-09-03
- 状态：已决策（源码候选；本地全绿，未发版）
- 相关：ADR-007（工作台集散与三层权限）、[UtenFilterToolbar 契约](../02-组件库/UtenFilterToolbar.md)、
  [UtenHistoryTimeFilter 契约](../02-组件库/UtenHistoryTimeFilter.md)、
  [权限体系总设计](../05-架构/权限体系总设计.md)

## 1. 背景与决策

2026-09-01 建立的 UtenFilterToolbar 统一筛选范式中仍残留三类不一致：单据列表
用 DocKpiBar 状态卡条 / ChoiceChip（默认选「全部」、无徽章）；任务工作台用
指标卡 + 下拉；各页「回到全量」依赖「全部」段，数据量大时首屏即全量加载。
用户 2026-09-03 提出统一收口，经两轮选择题确认口径后决策：

1. **分类行只放阶段，不放「全部」段**。旧式页面（采购 4 单据列表、委外 8 业务
   列表、仓库 8 类单据列表、委外准备中心、任务工作台、委外申请分解页）全部
   换 UtenFilterToolbar 分段卡。
2. **默认不选 = 不发请求**。未选分类显示引导占位（UtenFilterPlaceholder）；
   点击分段后才加载。任务工作台类页面进页面仅拉一次 size=1 概览取徽章计数。
3. **末尾「历史记录/历史单据」段承担「翻旧账」**：选中后渲染时间门控行
   （UtenHistoryTimeFilter：时间段/全部，默认不选不加载），选定后按
   dateFrom/dateTo 加载（**不限状态**）。有子类别的页面历史段放在小类行末尾
   （品质检查结果的状态行；任务工作台/委外分解的异常小类行同现但历史在阶段行末尾）。
4. **徽章只挂待处理段**：单据列表页申请页挂「计划已下达（待分解）」计数、
   其余挂「草稿」计数（2026-09-03 用户确认，**修订** 2026-09-01「草稿一律
   不挂」口径——仅限单据列表页；任务中心草稿段仍不挂）。任务工作台阶段/异常
   分段挂后端全量计数。
5. **任务工作台「已完成/已领取」不占段**，归入历史记录（时间门控浏览）；
   异常维度转小类行（选中阶段后出现，无「全部异常」）。
6. **仓库出库/入库任务中心各小类行同步收口**：小类默认不选；原「出仓历史/
   收货历史」升级为标准「历史单据」段（时间门控）；销售出库状态行加已出库
   （两种模式一致）+ 末尾历史单据。
7. **详情页直达生成订货单**：采购申请详情页底部新增「生成采购订货单」
   （权限 `purchase_order:create + purchase_order:decompose`，申请 status=1），
   委外申请详情页对称新增「生成委外订货单」——均带全部明细 id 直达订货编辑页，
   复用任务中心同一条链路（后端分解预览自动过滤已分解完的明细）。

## 2. 权限口径（零新增权限码）

历史记录/历史单据视图**复用各页面已有 view 权限**（采购单据历史 =
`purchase_*:view`，委外 = `subcontract_*:view`，仓库六类实物历史沿用 V445 独立
码）；详情页生成按钮复用既有 `*_order:decompose`/`create` 按钮级权限。
不新增权限码、不新增迁移、reset 白名单与码表计数不变——工作台「无专属目录码
是设计决策」（权限体系总设计 §三）继续适用。

## 3. 后端配套（均为查询参数扩展，无 schema 变更）

- 仓库实物单据历史六接口、品质检查结果 list、履约任务工作台三接口、销售出库
  工作台 list 新增 `dateFrom/dateTo`（ISO 日期）；原生 SQL 判空一律
  `CAST(:param AS date) IS NULL OR ...`。
- 工作台日期过滤只作用于行/汇总查询；状态/异常/待完成计数恒传 null 保持
  角标全量口径。
- 采购/委外单据列表、仓库原生单据列表、委外申请列表的日期参数此前已支持。

## 4. 已知例外

- **委外准备中心**无时间门控历史段：其两个任务接口（前置自制任务/分析账本）
  走 Port 适配层，无日期过滤；终态（目标件已出仓/已取消）保留为显式阶段段。
  若需时间门控需扩展 Port 查询（待用户确认是否值得）。
- 报表页/应付工作区等「视图切换」工具条维持恒选中例外（契约 §二.5）。
- 采购 4 单据列表页的「合计」列与折叠头布局等页面细节不变。

## 5. 同日第二轮扩展（销售 + 生产，2026-09-03 下午）

1. **销售订货单列表**：顶部 4 张统计卡（待生产/生产中/待发货/本月完成）转
   大类分段卡（计数转徽章，stats 全量口径；钻取口径不变——chain/closed/本月
   月初）+ 小类状态行（草稿/已审/红冲，无「全部」段，默认不选=全部效果，
   大类选中即加载）+ 末尾历史记录时间门控；可发货置顶小开关保留。
2. **出货/退货/报价列表**（同组件）跟随单行范式：状态行 + 末尾历史记录。
3. **订单进度查询**：指标卡退役 → 财务驳回/待排产/生产中/可发货分段卡
   （stage-counts 徽章）+ 搜索 + 末尾历史记录（**已发货入历史**：SHIPPED +
   时间门控）；「待完成」聚合视图由默认占位语义取代。`/sales/orders/progress`
   新增 keyword/dateFrom/dateTo 可选参数（CAST 判空）。
4. **生产调度与进度**：AppBar 下 TabBar（待排产/进行中/已完成）退役 →
   大类分段卡（待排产/进行中/历史记录 + 页级搜索；默认不选占位，路由深链
   预选例外：schedule→待排产、progress→进行中）；**已完成并入历史**
   （时间门控，planProgress 原生支持 dateFrom/dateTo）；待排产/进行中各自
   筛选保留，搜索统一到大类行。
5. **任务工作台异常行去聚合**：`OVERDUE_ANY`（全部逾期）不再显示——旧指标卡
   遗留的聚合筛选与具体异常段重复，且聚合段无法回退到"无异常"（分段单选点
   已选段不回调）；`OperationsWorkbenchData.exceptionOptions` 层过滤。

## 6. 影响

- 前端 20+ 页面/组件统一到同一交互模型；DocKpiBar 在单据列表退役（当时组件保留
  未删；**2026-09-04 后记**：全站零引用后已随死码清理删除，见 组件总览）；
  MetricFilterCards 不再用于任务工作台/订单进度查询。
- 大量既有 widget 测试按「先点分段再断言」模型更新（语义不削弱：权限隐藏、
  脱敏、批量门禁断言保留）。
- 页面文档/页面总览/权限文档同步更新（见各文档 2026-09-03 备注）。
