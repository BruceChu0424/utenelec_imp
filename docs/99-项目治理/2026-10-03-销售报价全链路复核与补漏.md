## 原始需求对应链路

| 需求 | 当前实现与验收点 |
|---|---|
| 报价表头与新建订货一致 | 共用销售编辑页；共同字段排列一致，选择客户带默认结账方式，业务员默认当前员工，报价自动显示本位币，有效期追加在共同信息后 |
| 仅有报价权限也能开单 | 默认条款、币种字典、结账方式字典允许销售开单能力读取；客户范围、启用状态和主档管理权限分别检查 |
| 销售改价格、折扣、数量 | 只改报价单据事实，不改货品资料；无价格权限不能提交隐藏价格；服务端精确计算金额 |
| 财务核价并修改 | 当前版本与本人有效认领；价格、折扣、数量、删行一起校验；未保存修改不能确认或直接退回；双击与旧响应有防护 |
| 反复议价及客户不同意 | 退回或重新修改后重新提交，旧财务／客户同意不复用；取消须原因，历史保留 |
| 修改格红线、新值红字 | 稳定行 ID 比较，只划变化格，末尾追加新值；真删行整行划去；仅表头变化也默认显示最新变化 |
| 销售记录客户同意后转订货 | 客户同意绑定当前修订，过期或未确认不能转；锁行与唯一来源防重复；新订单仍是草稿，继续保存、审查及财务审核 |
| 订货不绕过已核价条款 | 来源报价的价格／折扣锁定，客户与币种同样锁定；空币种与本位币规范化后比较；改量或少行不再误报“与报价一致” |
| 订货财务拒绝后重新报价 | 原订单先按原取消／红冲规则安全终止，再创建独立新报价；首次替代事实封存旧订单，新报价取消／删除后旧订单也不能恢复 |
| 货品中看历次客户报价 | 使用当次快照、明确权限、精确十进制文本；缺失旧身份不回填当前客户；关联订单客户必须与快照一致；无订单则看只读快照 |
| 对应订单与重新报价跳转 | 有权的财务／销售详情分别使用正确入口；首次重新报价已删除时仍可通过历史只读入口查看，不能借历史入口恢复写入 |
| 任务分类、通知与徽章 | 待财务、待客户同意、待生成订货分别计数；模块不重复累计；取消即撤待办，迟到通知不能复活已结束任务，同接收人的未办结卡去重 |
| 无客户模板时上传学习 | 下载入口提示上传或标准格式；支持空白／带样例 Excel、多工作表，陌生报价表也能明确选择并独立识别 |
| AI 识别出错可核对修正 | 受控下拉修正安全可见列的含义，服务端复验必需字段、重复角色、隐藏列与合并覆盖；不执行任意公式，不修改原 AI 结果 |
| 客户模板持续学习与下载 | 确认映射留证并复用，包含模板专用折扣角色；重新学习同一文件有独立尝试身份；采用重试不能换映射，下载绑定所选模板版本与报价版本 |
| 数据、权限和并发不串线 | 账号／服务器／权限变化使旧任务、旧弹窗和旧文件写入失效，切出去再切回来也不复活；所有服务端写入口独立校验 |

## 本轮补漏

1. 财务“退回销售”原先可能丢弃未保存修改；保存从续租开始就防重入，晚响应不能在新身份页面恢复旧数据。
2. 先改基价再改成交价原先可能回到旧基价；非法成交价也不能被误判为没有修改。后端成交价与直接报价统一精度边界。
3. 最新仅修改支付方式或有效期时，修订对照原先可能停在更早的行变化。
4. 报价转单后原先可在订单更新中换客户／币种，继续套用原价格，现已在前后端封锁并在财审比较中复核。
5. 安全取消后的重新报价补齐永久封存事实，禁止同一次封存夹带业务字段改写；复制新报价前不再就地归一旧报价明细。
6. 已封存订单与软删除单据混页时，历史投影不得覆盖业务只读标志；列表批删也复核封存／历史标志。
7. 取消时撤回审核卡，投递前再检查订单实际阶段；旧取消事件不能撤掉恢复后的新待办，旧财审／计划事件不能复活终止订单的任务。
8. 货品报价历史接入公共会话查看保护，权限撤回再恢复须重新读取；只读财务可以查看快照，原弹窗不能复活；返回关联订单后重新核对历史。
9. 模板选择与采用证据原先只记录模板 ID，可能静默变成后来的版本；现记录确切版本及确认映射，缺失旧证据时明确重新核对。
10. 工作表选择、合并／隐藏位置、Excel 转义显示文字、数量与折扣显示精度均按实际工作簿校验，避免底层数值正确而客户看到错误值。
11. 人工确认后的完整列映射持续复用，不依赖尚未清理的 AI 任务；同一文件的新一轮学习与原采用重试分开处理。
12. 公共导出及文件保存过程绑定发起时上下文，旧操作不能保存到新身份，也不能在结束时清除新操作的忙碌状态。

## 明确边界

模板支持 15 MiB 以内的 xlsx／xls，采用清洁版式；不执行来源宏、外部链接和任意公式，不承诺图片与复杂嵌入对象逐像素还原。未启用 AI 时常见表头仍可规则识别，无法识别时明确提示，允许修正已提取的列映射。

本地自动化与源码检查不能替代安装版本、实际销售／财务岗位和真实 AI 服务商的目标环境验收。本轮未执行发布或业务数据库迁移；不承诺未执行环境下绝对不会出现任何错误。
