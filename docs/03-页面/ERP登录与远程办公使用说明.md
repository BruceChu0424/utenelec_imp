# ERP 登录与远程办公使用说明

核对日期：2026-10-23。本文供员工和超级管理员照着操作，不涉及服务器密码、备份解密密钥或业务数据恢复命令。

## 先确认打开哪个网站

| 使用场景 | 入口 | 谁可以用、填什么账号 |
| --- | --- | --- |
| 在公司正常办公 | 公司原有 ERP 客户端或原内部入口 | 使用本人现有 ERP 登录账号和密码 |
| 出差、在公司外使用 ERP | [https://justplayit.cn](https://justplayit.cn) | 已获外网授权的员工；同一套 ERP 登录账号、密码，外加本人验证器动态码 |
| 超管日常管理人员和权限 | 在公司内部入口登录原 ERP | 使用超级管理员自己的 ERP 账号，再从系统设置、账号与权限管理操作 |
| 公司主站故障时的独立救援 | [https://admin.justplayit.cn](https://admin.justplayit.cn) | 仅已单独绑定的救援超管；独立救援口令及独立动态码 |

**普通员工和超管的日常 ERP 网页都是 justplayit.cn。admin 子域名是独立救援页面，不是日常人员授权页面。**

当前核对结果：两个公网地址 HTTPS 均正常；外网总开关关闭、最多授权5人、已授权0人。因此员工不能仅凭知道网址就直接外网登录。超级管理员应先完成下面的开通步骤。

日常远程验证和按人授权是现有业务版本已经具备的功能。新增的主站「运行与灾备」入口、首次救援身份登记接口仍待与其他任务统一发布；目前独立救援页显示尚未绑定超管，业务接管也未开放。

## 员工：出差前先准备好

### 1. 在公司内网用自己的账号登录

使用原有 ERP 客户端或公司原内部入口。此处必须是服务器识别为内部入口的连接；人在公司、连接了公司 Wi-Fi，但打开公网 justplayit.cn，仍可能按外网入口处理。

账号填写**管理员实际开通的登录账号，通常是手机号**。已有工号账号可以沿用；不要认为任意员工工号或姓名都能登录。新员工先让管理员开通账号，用安全交付的临时密码完成首次登录，并按提示修改密码。

### 2. 绑定手机验证器

1. 打开「设置 → 账号 → 远程身份验证」。
2. 点击「绑定验证器」。出现「请确认是你本人」时，输入当前 ERP 登录密码。
3. 手机上使用支持动态验证码的身份验证器应用，例如 Microsoft Authenticator 或 Google Authenticator。它们的官方说明分别为：[Microsoft 添加其他账户](https://support.microsoft.com/zh-cn/authenticator/how-to-add-your-accounts-to-microsoft-authenticator)、[Google Authenticator 使用说明](https://support.google.com/accounts/answer/1066447?hl=zh-Hans)。
4. 在验证器中添加账户，扫描 ERP 页面显示的二维码。扫描不方便时，按页面的「设置密钥」手工添加；类型选基于时间，使用6位、30秒、SHA1参数。二维码账户标识为 `Uten ERP:登录账号`。
5. 把手机上新生成的6位数字填回 ERP 页面，点击「确认绑定」。看到「验证器已绑定」才算成功。

动态码由验证器产生，**不是短信验证码**。本次绑定10分钟有效，过期或离开页面后重新发起。二维码和设置密钥只属于本人，不要截图发群、发给管理员或写进聊天。

### 3. 请超管开通外网资格

绑定验证器后，告诉超管自己的已开通登录账号，请其按下面的管理员步骤授权。绑定验证器本身不会开通外网权限。

## 超管：今天谁出差，就开通谁

1. 从公司**内部入口**，以超级管理员本人登录 ERP。
2. 打开「系统设置 → 外网访问与连接」。
3. 打开「开放外网访问」，将「最多授权人数」保持为5，点击「保存设置」，按弹窗重新输入管理员当前密码。只拨动开关而不保存不会生效。
4. 点击「管理人员授权」，进入「账号与权限管理」。
5. 搜索员工姓名、工号或登录账号，选中正确人员，核对其账号及验证器状态。
6. 在人员详情顶部点击「授权外网」，确认后按提示重新验证管理员密码。
7. 让员工使用公司外的网络测试一次，例如自己的手机移动网络，确认能用同一 ERP 账号、密码和验证器完成登录。

5人指**已经获授权的账号总数**，不是当前在线数。名单可以随出差人员更换；需要换人时先撤销回来的人，再授权新人员。授权只开放登录入口，不增加该员工原有的业务权限。

## 员工：出差时怎么登录

1. 用电脑或手机浏览器打开 [https://justplayit.cn](https://justplayit.cn)。不需要填写服务器 IP、端口或阿里云控制台账号。
2. 等 ERP 登录页面加载完成。当前带宽约1 Mbps，首次加载大资源约需一分钟，避免反复刷新导致重新加载。
3. 输入与公司内网相同的 ERP 登录账号和密码，点击登录。
4. 系统要求外网身份验证时，页面会显示「动态验证码」输入框。
5. 打开本人手机验证器，找到 ERP 对应账户，输入当前新生成的6位数字，再提交登录。
6. 进入平台后，只能使用本人原有权限范围内的功能。

同一枚验证码不能重复使用。刚用于绑定、登录或会话验证后，应等验证器号码更新再使用；不要拿超管救援账户的动态码填在员工登录页。

目前远程使用以浏览器网址为准；不要自行把已安装客户端的服务器地址改成任意网站。

## 员工回来后怎么关闭

超管在内部入口打开「外网访问与连接」，在「已授权人员」列表对该员工点击「取消授权」并确认；也可进入该员工详情顶部取消授权。

取消后，该员工原有登录会话和刷新凭据失效，员工在公司内部也可能需要重新登录。其业务资料和业务权限仍保留。

若要暂停所有人的外网办公，关闭「开放外网访问」并保存。总开关与人员名单分别管理，关闭总开关不会清空原授权名单。

## 登录问题对照

| 看到什么 | 应该怎么做 |
| --- | --- |
| 账号或密码错误 | 核对管理员实际开通的登录账号和本人密码；不要把姓名当账号，不连续试猜密码 |
| 公司当前已关闭员工外网访问 | 超管从公司内部入口开启总开关并保存；员工不能自行绕过 |
| 该账号未授权外网访问 | 联系超管为正确账号授权 |
| 尚未绑定验证器 | 本人回公司内部入口完成绑定，再由超管授权 |
| 验证码错误、过期或已使用 | 检查选中的验证器账户、手机自动日期时间，等待下一枚验证码再提交 |
| 验证码错误次数过多 | 停止反复尝试，按提示等待15分钟 |
| 达到授权人数上限 | 超管先撤销已经回公司、不再需要外网权限的账号 |
| 忘记密码 | 联系公司的账号支持人员办理重置，不把旧密码或身份证发进聊天 |
| 手机丢失或更换、验证器无法使用 | 先联系超管取消外网资格；超管在内网核实身份后「重置验证器」、填写原因并重新验证，再由员工本人重新绑定 |
| 救援网站提示尚未绑定超管 | 首次救援登记还未完成，不能用 ERP 密码反复尝试；按下面的发布后流程办理 |

向管理员反馈时，提供使用的网址、提示文字和发生时间即可。不要提供密码、二维码、设置密钥或动态验证码。

## 超管：独立救援网站怎么用

请收藏 [https://admin.justplayit.cn](https://admin.justplayit.cn)。该页面独立于公司业务服务；已验证公司业务链路中断时它仍能打开。

**当前首次救援身份登记尚未完成。以下绑定流程需要新主站入口和登记接口统一发布后再办理：**

1. 运维开放不超过15分钟的登记窗口。
2. 超管本人从公司内部入口进入「运行与灾备」，重新验证当前 ERP 密码，点击「绑定独立救援身份」，再点击「继续绑定独立救援身份」。一次性入口5分钟有效，不要分享地址。
3. 在独立救援页面，用手机验证器**手工添加**页面显示的设置密钥；当前救援页没有扫码二维码。
4. 设置至少20字符的独立救援口令，并填入该救援验证器对应的新6位验证码，确认绑定。
5. 绑定后等下一枚验证码，再用已绑定账号、独立救援口令和独立动态码登录。不要把员工 ERP 密码和员工验证器动态码混用。

自动加密备份已经运行，员工无需操作。独立救援身份绑定后才能在受控页面查看恢复点；文件已上传或密文校验通过，不表示业务接管已验收。

**当前还不能点击启用云端业务接管。** 备用业务环境、可信现场隔离与恢复/启用执行器尚未验收。采用已确认的人工流程：现场先关机、断网隔离旧主，运维验证成套恢复证据，再由超管人工启用已验收的备用业务环境。网络断开本身不会自动切换。

完整运维状态、测试入口及待办见 [运行与灾备使用说明](../05-架构/运行与灾备-使用说明.md)。本文随本地主分支保留，等待统一提交；本次没有发布代码或更改任何人员授权。
