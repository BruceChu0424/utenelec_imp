# UtenFilterChip

用于独立开关类筛选，保留原生 FilterChip 的键盘、焦点、禁用、选中语义和 `onSelected(bool)`。普通分类导航继续使用 UtenSegmentRow。

标签按实际文字宽度换行，勾选图标和内边距由同一标签布局测量，避免原生 Chip 先量高度再扣图标宽度造成第二行裁切。窄容器中图标与标签可以分行，不缩字，也支持表格工具栏的 intrinsic 测量。

标准桌面最小目标40，触屏实际窗口目标至少48×48，85%缩小仍补足目标。字号取现有 Chip 主题；圆角取统一控件主题，内边距12/8。选项身份、查询、保存和权限仍由调用方控制。

已统一价格趋势参考线、仓库洞察、即时库存、货品收发流水、货架标签及通知祝福模板的10个筛选入口。标签、原key、avatar、selected和回调均保留。

回归覆盖85%/100%/200%、完整非线性系统字号、IntrinsicHeight环境、全文字形边界与真实边缘点击。运行结果以[整体验收记录](../99-项目治理/2026-10-13-全平台界面整改覆盖与验收.md)为准。
