# V534：服务器状态只读权限

新增 `server_status:view`，归属系统管理/服务器状态。该权限只允许读取服务器状态缓存；不开放权限管理、重启服务、删除文件或执行系统命令，也不向普通部门自动授予。

工作台卡片、路由 `/admin/server-status`、后端 `GET /api/admin/server-status` 使用同一权限。页面进入后台或离开后停止轮询；原有通用 `/admin/` 授权管理判断前，需先处理本页的独立只读权限。

迁移不增加业务表，CLEAR/PRESERVE 分类不变，源码目录为V534/493。既有迁移字节保留，V533附件历史路由与原件身份规则不受影响。接口与采样口径见 [服务器状态页](../03-页面/服务器状态页.md)。
