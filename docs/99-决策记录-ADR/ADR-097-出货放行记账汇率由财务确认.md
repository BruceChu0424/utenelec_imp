# ADR-097 出货放行记账汇率由财务确认

- **状态**：已接受(2026-09-21，V632，零新增权限码)
- **相关**：[ADR-053 多币种收款毛额净额与追加式账户流水](ADR-053-多币种收款毛额净额与追加式账户流水.md)、
  [ADR-030 销售待收计划与正式应收分层](ADR-030-销售待收计划与正式应收分层.md)、
  [222 V632 出货放行记账汇率与标准收付款方式](../数据迁移/222-V632出货放行记账汇率与标准收付款方式.md)、
  [客户零星发货与出货财务审核](../03-页面/客户零星发货与出货财务审核.md)、[钱流单据页](../03-页面/钱流单据页.md)

## 背景

ADR-053 定下「销售不录汇率；仓库 SHIPPED 时锁定币种主档汇率立应收」。V631 又在财审放行前校验主档汇率大于 0，
否则 409 让财务先去基础资料维护。用户 2026-09-21 实测美金订单时的反馈是：财务审批出货单的时候就应该能填汇率，
收款单那边也一样；不清楚业内逻辑，要求参考别人的做法。

调研了金蝶云星空、用友 U8、SAP SD 与 Odoo 的公开文档与社区问答，四家对「业务单据上的汇率」口径一致：

1. **记账汇率在单据制单/审核时从汇率表自动带出，审核前可改，审核后冻结在单据上**；之后再改汇率表不影响已审单据
   (金蝶社区「单据上的汇率按当时做的时候自动取数，与后面改无关」；SAP 销售订单头「Exch.rate-acct.」手工值优先于
   OB08 汇率表并复制到开票会计汇率 VBRK-KURRF；用友 U8 记账汇率制单时自动显示、可改，凭证记账后锁定)。
2. **本位币汇率恒为 1**，不允许改。
3. **收款按到账当天/银行回单的实际汇率**，与应收记账汇率的差额是已实现汇兑损益，进财务费用；期末对未核销外币应收按期末汇率
   调汇是未实现汇兑损益(两笔交易观，企业会计准则第 19 号)。收入按出库/应收日汇率固定，收款汇率不回调收入。
4. 汇率表(主档)只是默认值来源，由财务维护；ERP 通常按日期维护一张汇率表。

本系统收款侧(V407)已经是第 3 条：收款单「本批汇率报价」按银行回单填，`exchangeDiff` 进「收款汇兑损益」。缺的是第 1、2 条：
出货这一头没有「带出 + 可改 + 冻结」的动作，汇率只能在基础资料改，而基础资料一改会影响后面所有单。

## 决策

**出货的记账汇率在财务放行这一刻确认并冻结到本单；仓库确认出库按冻结值折算本币立应收。**

- 财审页「记账汇率」框预填：本单已冻结的 > 本位币 1 > 币种主档参考汇率 > 空(主档没维护，要财务填)。
- 财务可按放行当日汇率修改；放行请求带 `exchangeRate`，服务端校验大于 0、最多 6 位小数、本位币只能是 1。
- 放行写入 `sales_shipments.exchange_rate`，放行事件记录汇率与来源(`CURRENCY_MASTER` 与主档相同 / `FINANCE_MANUAL` 财务手填)，
  形成可追溯证据；撤回放行或商业内容变更撤回时清空，下次放行重新预填。
- 主档没维护参考汇率**不再挡放行**：财务在放行时填即可(空着放行仍被拦下)。主档只是默认值来源，维护它是为了下次自动预填。
- 仓库确认出库：有放行事件且冻结汇率大于 0 就按冻结值；V632 之前放行的老单没有冻结值，仍回落到主档(FOR SHARE)，历史行为不变。
- 收款单沿用 ADR-053：「本批汇率报价」按币种预填主档参考汇率(本位币锁 1，主档没有则留空由财务按银行回单填)，收款汇率与
  应收记账汇率的差额照旧进汇兑损益，不回调应收。

同批顺手修的两处收款单可用性问题(同一用户反馈)：

- V273 只带 3 条「待同步名称」的收付款方式占位行且不进选择器，没导入 recstyle.csv 的安装(含清库后的公司库)收款单「收款方式」
  下拉为空又必填，收款单存不了。V632 在没有任何已确认方式时补一套标准方式；前端字典为空时提示并允许先保存(服务端本就允许空)。
- 「货款收款(核销应收)」引用的是已发货的应收，订单没出货时列表必然为空；空列表处加「改为登记订单预收」一键切换并直接打开订单选择。

## 明确不做

- **不做按日期的汇率表**。主档仍是单值参考汇率；每张单据放行时冻结自己的汇率已经能表达「不同日期不同汇率」，
  等真实需要按日查询历史汇率再加表。
- **不做期末调汇/未实现汇兑损益**。ADR-053 §十二仍列为 NO-GO 项，本 ADR 不改变。
- **销售端仍不录汇率**(ADR-053 §二 1)。销售订单/出货草稿的 `exchange_rate` 继续置空。
- **批量放行不带逐单汇率**：财务工作台多选放行沿用主档参考汇率；主档没维护的单据在批里仍 409，需逐单进审核页填写。
