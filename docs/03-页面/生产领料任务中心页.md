## 一、页面与权限

- 路由：`/warehouse/tasks/draw`（路由名 `warehouse-draw-tasks`）。
- **进入权限**：`stock_doc:view`。领料单/生产退料由生产链自动生成、无手工新建入口
  （2026-09-04 撤除，见「四、业务口径」）；草稿生产领料首次“出库”要求
  `stock_doc:approve ∩ stock_doc:issue`，同一事务审核并扣账；
  后续分批出库要求 `stock_doc:issue`，取消出库要求 `stock_doc:reverse_issue`，红冲仍按
  `stock_doc:reverse` 门控。
- 页面权限面：`warehouse.draw-tasks`（V450）。

## 二、页面结构

对齐品质部检查结果页范式：**进页面不预选大类**（内容区显示「在上方选择分类后
开始办理」引导空态，不加载任何分段数据）；各分段的小类行只随选中的大类出现
（结构上等价于大类未选时小类锁定）。

1. **页级工具条**：大类分段 = 待领任务 / 领料单 / 生产退料 + 胶囊搜索（关键字
   下发当前分段）。徽章只挂真实待办（**草稿不计入待办数**）：待领任务 =
   已提交且仍有申请未发量的履约待领数；生产退料另有正式待收申请徽章，领料单和普通草稿/历史不冒充待办。
2. **待领任务段**（`WarehouseDrawTaskSegment`）：与 `/operations/workbench/warehouse`
   履约工作台同源（生产物料需求 × DRAW 领料单 open_qty 投影），**按领料单归组
   （2026-09-03 用户确认，与 ADR-065 修订后的采购/委外同口径）**：一行=一张
   DRAW 领料单，多物料单货品列显示「N 种物料 · N 行待领」、待领数量列显示行数，
   并新增领料单号列；单货品单据照旧逐列显示货品与数量。小类分段 =
   待完成(默认) / 已领取；待完成合并未领和部分领取，行状态仍按实际出库进度
   （全部行未出库=待备料、出过一部分=部分领取、全部出完=已领取）；双击进对应
   `/warehouse/DRAW/:id` 领料单办理分批出库。草稿首次出库自动完成审核，不再先点独立
   “审核”；无对象权限的行只读（服务端裁剪）。
   - **批量出库（2026-09-09；2026-09-10 修订）**：表头复选框多选 + 右下角悬浮
     「批量出库」（`POST /stock/docs/issue-batch`，`stock_doc:issue` 才渲染按钮）。
     勾选**跨页保留**（切换子分类/关键字时重置；刷新后本页已领完的单自动剔除，
     整个结果只有一页时不在页内的单也剔除），提交时把全部勾选的领料单 id 发给服务端，
     **一次最多 50 张**（超出先提示取消勾选；服务端 422 也带同一句字段级说明）。
     进入独立批量页核对最新明细，并提供「统一备注」（选填 ≤200 字，随每张单追加到单据备注）。
     服务端取得单据行锁后，按「本次可发 = 累计有效申请量 − 已实际发出量」办理，不能将未申请的原需求余量一并发出，
     **草稿单走与详情页相同的「审核并出库」路径**（生产链 DRAW 全部以草稿生成），
     因此勾选含草稿单时当前账号还需 `stock_doc:approve`：前端按钮置灰并提示，服务端
     FORBIDDEN 并列出草稿单号。**任一单失败整批回滚**，错误统一带单号
     （「领料单 {单号}：{原因}」，错误码不变）；已出完的单自动跳过（skipped）。
     幂等见「四、业务口径」。
3. **领料单与生产退料的普通单据/历史部分**（`WarehouseStockDocSegment(DRAW|WDRAW)`）：正式待收退料另由专用待收任务办理并计数。
   不渲染 icon+标题分段头；状态小类（全部/草稿/已审/红冲）与出库进度小类
   （未出库/部分出库/已出完）**进页面均不预选**（空集 = 不过滤），这些普通单据/历史列表不挂
   待办徽章（草稿不计入待办数）；全部分类栏最下方为总结行（左「共 N 条 · 双击办理」；
   2026-09-04 起无新建按钮，见「四、业务口径」）；双击进详情（生产 DRAW 为出库即审核、多轮
   分批出库、取消出库与红冲；其它库存单据保留各自审核门禁）。从领料单发起的退料带来源行锁定与最大可退量（`?drawId=`
   预填链路保留）。

## 三、角标口径

- 待领任务徽章 = `GET /operations/workbench/warehouse/count`
  （`countPending('WAREHOUSE')`：v_fulfillment_workbench_actions 中
  WAREHOUSE 部门 × DRAW 单 open_qty > 0 的**领料单张数**，2026-09-03 起
  与列表归组口径一致；未挂单的行级需求退回行级计数兜底）。
- 领料单和普通草稿/历史不挂待办徽章；生产退料的正式待收申请单独计数。
- hub「生产领料任务中心」卡徽标 = 已提交待领任务数 + 正式待收退料数；
  工作台仓库卡 = 三张任务中心卡之和。
- **待领任务子分类计数**（当前为待完成 / 已领取）：
  「待完成」是已申请且待发的总量段 → 红徽章；旧“待备料/部分领取”不再作为并列分类
  （同一批活不在一行里红两遍，见 [徽章与计数口径](../00-项目准则/14-徽章与计数口径.md)）。计数口径 =
  `GET /operations/workbench/warehouse/status-breakdown`
  （`warehouseStatusBreakdown()`）。2026-09-10 起与列表**同一段 SQL**
  （`FulfillmentWorkbenchQueryService.WAREHOUSE_DOCUMENT_ROWS`，即列表的单据归组
  `sourceView`）取 `task_status` 再计数：整单状态按全部行判定（含已出完的 DONE 行，
  任一行≠READY_TO_PICK 即 PARTIAL），与列表分段和列表返回的 `summary.statusCounts`
  逐条相等；`OPEN_ANY = READY_TO_PICK + PARTIAL`，已领取为终态不计数。
  此前徽章独立写的一段 SQL 只看 open_qty>0 的行，「部分领取」单会被记成「待备料」。
  计数端点失败时前端清空徽章并写日志（不再 `catch(_)` 静默留旧值）。

本轮申请量全部发出后可退出待发队列，原工单是否领齐仍按完整需求与累计实发判断；原需求还有未申请量时由车间再次提交。内部DRAW生成、打开页面和通知到达都不增加申请额度，详见[ADR-077](../99-决策记录-ADR/ADR-077-车间明确提交领料后进入仓库任务.md)。

## 四、业务口径与边界

- 生产链（物料分析/报工）生成的 DRAW/FINISHED_IN 单据禁止通用编辑/删除
  （`fn_is_production_linked_stock_document` 服务端守卫）。生产领料/退料域整体归
  生产链所有：领料单/生产退料不提供手工新建入口（2026-09-04 撤除）——手工单没有
  计划包与执行段映射，审核/出库会被台账守卫一致拒绝（「必须且只能关联一张有效生产
  计划」「没有且仅有一个有效生产计划包，禁止发料」）；临时性出入库请用其它入库/其它出库。
- 领料分批出库（issue）幂等；草稿首次出库的审核与扣账共用同一事务，响应丢失以同一
  幂等键重放不会重复扣库存。取消出库必须填写原因，以反向流水恢复库存和占用，不修改
  或抹除原出库历史；退料只退已领良品，数量 ≤ 来源行可退量。
- **批量出库幂等**：前端每次点击生成 UUID 批量键；服务端为每张单派生**子幂等键 =
  SHA-256(操作人 userId + 批量键 + 单据 UUID)**（64 位十六进制，
  `StockDocService.batchChildIdempotencyKey`），不同操作人复用同一批量键不会撞
  台账的「相同幂等键对应不同领退料请求」。同人同键重放时，已出完的单按子键在
  `production_material_stock_events` 找到 ISSUE 事件即计入 `replayedCount`；整批无新增
  出库即响应 `replayed=true`，前端提示「本批此前已完成」；换批量键时已出完的单只是
  `skippedCount`。响应 `StockDocIssueBatchResponse{issuedCount, skippedCount,
  replayedCount, replayed, issuedDocNos}`。
- **出库备注**（2026-09-12 起单张详情在表格上方「出库备注(选填)」+ 逐行「行备注」列编辑；批量出库仍走「统一备注」）：随正向出库 `reason` 追加到
  单据 `remark`，单条 ≤200 字（输入框同值）、多轮用「；」连接、总长 ≤500；判重按
  「；」拆条整条相同才跳过（此前 `contains` 判重会把「A」当成「AB」的重复丢掉）。
  草稿首轮「出库即审核」同样带备注（此前被静默丢弃）。取消出库的 reason 仍走取消原因
  审计，不落 remark。
- **出库凭证/照片**（附件 ownerType=`STOCK_DOCUMENT`）：常驻领料单详情页（不再只在出库
  弹窗内），可看/可管口径见[出入库记录页](出入库记录页.md)「十、仓库单据凭证附件」。
