# 05 - 国际化与多语言

> 所有用户可见文案必须走 i18n。本规范**全局强制**执行，禁止把中文/英文字符串硬编码到 Widget 里。
> 本准则是 [00-准则索引与开发清单.md](00-准则索引与开发清单.md) 第 4 条"国际化多语言"的展开。

---

## 一、设计目标

| 目标 | 说明 |
|---|---|
| 全量覆盖 | 所有面向用户的文案（按钮、提示、错误、空状态、表单标签等）都从 arb 文件取 |
| 双语→多语支持 | 首次启动固定中国大陆简体中文 `zh_CN`，可切换英文 `en_US`、韩语 `ko_KR`，未来可加其它语言而不改业务代码 |
| 即时切换 | 用户切语言后整树重建，不要求重启 App |
| 持久化记忆 | 用户选过的语言写入本地，下次启动直接套用 |
| 架构预留 RTL | 当前仅 LTR，但布局用 `start/end`、`Directionality`，将来加阿语不返工 |

---

## 二、技术方案选型

| 方案 | 是否采用 | 理由 |
|---|---|---|
| **Flutter 官方 `intl` + `gen_l10n`** | ✅ 采用 | 官方工具链，零额外依赖，IDE 补全好，ARB 标准化 |
| `easy_localization` | ❌ 不用 | 多一层封装、与官方重复、官方已能覆盖全部需求 |
| `GetX` 自带 i18n | ❌ 不用 | 本项目不用 GetX |
| 手写 Map<String,Map> | ❌ 不用 | 缺复数、缺类型安全、缺占位符校验 |

**依赖（pubspec.yaml 片段）**：

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  intl: any # 由 flutter_localizations 自动锁定兼容版本
  shared_preferences: ^2.2.0

flutter:
  generate: true # ⭐ 必须 true，启用 gen_l10n
```

## 三、目录结构与配置

### 3.1 目录结构

```
lib/
└── core/
    └── l10n/
        ├── app_zh.arb        # 中文（默认/兜底模板）
        ├── app_en.arb        # 英文
        ├── app_ko.arb        # 韩语
        └── README.md         # 给翻译人员看的说明（可选）
l10n.yaml                     # 项目根目录
```

> 命名说明：按 Flutter 官方默认约定使用 `app_<locale>.arb`。所有 arb 文件 key 必须完全一致，缺 key 会在 gen 阶段报错。

### 3.2 `l10n.yaml`（项目根目录）

```yaml
arb-dir: lib/core/l10n
template-arb-file: app_zh.arb   # 中文为模板（兜底语言）
output-localization-file: app_localizations.dart
output-class: AppLocalizations
preferred-supported-locales: [zh, en, ko]   # 解析顺序；新增语言在此与 arb 文件同步
output-dir: lib/core/l10n/gen   # 生成到仓库内，便于本地 import 和调试
nullable-getter: false          # AppLocalizations.of(context) 返回非空，简化调用
```

### 3.3 MaterialApp 绑定

```dart
// lib/core/app.dart
class UtenApp extends ConsumerWidget {
  const UtenApp({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final locale = ref.watch(localeProvider);
    final router = ref.watch(routerProvider);

    return MaterialApp.router(
      title: 'Uten IMP',
      debugShowCheckedModeBanner: false,
      theme: ref.watch(themeProvider),
      darkTheme: ref.watch(themeProvider-dark),
      locale: locale,
      localizationsDelegates: AppLocalizations.localizationsDelegates,
      supportedLocales: AppLocalizations.supportedLocales,
      routerConfig: router,
    );
  }
}
```

## 四、命名规范

### 4.1 key 命名规则

| 规则 | 说明 | 示例 |
|---|---|---|
| **lowerCamelCase** | 所有 key 一律小驼峰 | `loginTitle` 而非 `login_title` / `LoginTitle` |
| **按 Feature 分组前缀** | 同一功能/模块用统一前缀 | `employee*`、`payroll*`、`expense*` |
| **通用文案加 `common` 前缀** | 跨模块复用的文案集中放 | `commonConfirm`、`commonCancel`、`commonRetry` |
| **状态/枚举映射** | 业务状态有专属 key | `employeeStatusActive`、`employeeStatusOnLeave` |
| **错误加 `error` 前缀** | 错误文案统一前缀便于审计 | `errorNetwork`、`errorRequiredField` |
| **占位符用语义名** | 不用 `{0}`、`{1}` | `welcomeMessage` 用 `{userName}` 而非 `{0}` |

### 4.2 命名反例

| ❌ 反例 | ✅ 正例 |
|---|---|
| `login_title` | `loginTitle` |
| `LoginTitle` | `loginTitle` |
| `btn1`、`text_a` | `commonConfirm` |
| `txt1`（无语义） | `payrollSlipNetSalary` |
| `emp_name` | `employeeName` |

## 六、占位符与复数

### 6.1 占位符（{name}）

- 占位符**用语义名**（`{userName}`、`{count}`、`{field}`），不用位置序号。
- 占位符类型必须在 `@key.placeholders` 里声明（`String` / `int` / `num` / `DateTime`）。
- 类型声明错误会在 `gen-l10n` 阶段报错，运行时不会再有 `dynamic` 隐患。

### 6.2 复数（plural）

- 中英文复数差异大（英文区分 `=1` / `other`，中文只有 `other`），**任何带数量的文案必须用 ICU 复数语法**。
- 反例（中英都错）：

```
"recordCount": "共 {count} 条记录"        ❌ 不支持复数
"recordCount": "1 record(s)"              ❌ 拼接式伪复数
```

- 正例：见上面 `recordCount`、`unreadNotice`。

### 6.3 日期/数字

- **不翻译**：日期、数字、金额一律用 `intl` 的 `NumberFormat` / `DateFormat` 格式化，不靠字符串拼接。
- 金额按 locale 走货币符号（人民币 ¥ / 美元 $）。

## 七、Widget 中如何调用

### 7.1 基础调用

```dart
import 'package:flutter_gen/gen_l10n/app_localizations.dart';

class LoginPage extends ConsumerWidget {
  const LoginPage({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final l = AppLocalizations.of(context);

    return Scaffold(
      appBar: UtenAppBar(title: Text(l.loginTitle)),
      body: Column(
        children: [
          Text(l.loginSubtitle),
          UtenInput(label: l.loginUsernameLabel),
          UtenInput(label: l.loginPasswordLabel, obscure: true),
          UtenButton(
            label: l.loginButton,
            onPressed: () => ref.read(loginProvider.notifier).submit(),
          ),
        ],
      ),
    );
  }
}
```

### 7.2 带占位符

```dart
Text(l.welcomeMessage('张三'));   // 你好，张三！今天也要加油哦。
Text(l.errorRequiredField(l.loginUsernameLabel)); // 用户名不能为空
```

### 7.3 带复数

```dart
Text(l.recordCount(42));   // 中文：42 条记录；英文：42 records
Text(l.recordCount(1));    // 中文：1 条记录；英文：1 record
```

### 7.4 在非 Widget 场景（Repository / Service）

- 业务层不能直接拿 `BuildContext`，**禁止** `AppLocalizations.of(context)` 传进 Service。
- 错误码用枚举返回，UI 层再映射成文案：

```dart
enum AppErrorCode { network, auth, requiredField, unknown }

// 业务层
throw AppException(code: AppErrorCode.network);

// UI 层
String _mapError(BuildContext c, AppErrorCode code) {
  final l = AppLocalizations.of(c);
  switch (code) {
    case AppErrorCode.network: return l.errorNetwork;
    case AppErrorCode.requiredField: return l.errorRequiredField('xxx');
    case AppErrorCode.auth: return l.loginFailed;
    case AppErrorCode.unknown: return l.commonEmpty;
  }
}
```

## 八、LocaleProvider（Riverpod 实现）

### 8.1 Provider 定义

```dart
// lib/shared/providers/locale_provider.dart
const chinaLocale = Locale('zh', 'CN');
const englishLocale = Locale('en', 'US');
const koreanLocale = Locale('ko', 'KR');
const supportedLocales = [chinaLocale, englishLocale, koreanLocale];

class LocaleNotifier extends Notifier<Locale> {
  static const _key = 'locale';

  @override
  Locale build() {
    final saved = ref.read(sharedPreferencesProvider).getString(_key);
    final locale = switch (saved) {
      'en' || 'en_US' || 'en-US' => englishLocale,
      'ko' || 'ko_KR' || 'ko-KR' => koreanLocale,
      _ => chinaLocale, // 首次启动和未知旧值都按中国大陆中文
    };
    Intl.defaultLocale = locale.toString();
    return locale;
  }

  Future<void> set(Locale locale) async {
    final normalized = switch (locale.languageCode) {
      'en' => englishLocale,
      'ko' => koreanLocale,
      _ => chinaLocale,
    };
    await ref
        .read(sharedPreferencesProvider)
        .setString(_key, normalized.toString());
    Intl.defaultLocale = normalized.toString();
    state = normalized;
  }
}
```

### 8.2 MaterialApp 取值

`MaterialApp.router` 直接使用 `ref.watch(localeProvider)`，并将 `supportedLocales` 设为上面的
`zh_CN/en_US/ko_KR` 列表。项目主要服务中国大陆用户，首次启动不跟随设备语言；用户主动切换后的
历史 `zh/en/ko` 偏好继续兼容。

> `localeProvider` 状态变化 → `MaterialApp.router` 的 `locale` 变化 → Flutter 自动重建
> Localizations → **所有 `AppLocalizations.of(context)` 即时拿到新文案**，不需要手动 setState。

### 8.3 语言切换 UI

```dart
class LanguageSettingsPage extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final current = ref.watch(localeProvider);
    // 语言名用母语写死，不翻译（见下方说明）。
    const options = <(Locale, String)>[
      (chinaLocale, '简体中文（中国大陆）'),
      (englishLocale, 'English'),
      (koreanLocale, '한국어'),
    ];

    return RadioGroup<String>(
      groupValue: current.toLanguageTag(),
      onChanged: (tag) {
        if (tag == null) return;
        final selected = options
            .map((o) => o.$1)
            .firstWhere((l) => l.toLanguageTag() == tag);
        ref.read(localeProvider.notifier).set(selected);
      },
      child: Column(
        children: [
          for (final (locale, label) in options)
            RadioListTile<String>(
              title: Text(label),
              value: locale.toLanguageTag(),
            ),
        ],
      ),
    );
  }
}
```

> 注意：`简体中文（中国大陆）`、`English`、`한국어` 这几个**语言名本身**不翻译，直接写死。语言切换页是唯一允许硬编码这些标签的地方。

## 九、不翻译的内容

| 类型 | 处理 | 示例 |
|---|---|---|
| 品牌名 | 永远是 `Uten` / `优腾`，不走 arb | `Text('Uten IMP')` |
| 技术术语 | API、ID、URL、HTTP 状态码 | `Text('HTTP $code')` |
| 数字 | 用 `NumberFormat` 格式化 | `NumberFormat.decimalPattern().format(12345)` |
| 日期 | 用 `DateFormat` 按 locale 格式化 | `DateFormat.yMd(locale).format(now)` |
| 邮箱 / 手机号 | 不翻译 | `Text(user.email)` |
| 单位 | 用 locale-aware formatter | `NumberFormat.currency(locale: ...)` |
| 代码片段 / 错误堆栈 | 不翻译 | — |

## 十、RTL 支持（架构预留）

当前仅 LTR（中文 + 英文），但所有布局必须按"将来加阿语"的假设来写。

| 规则 | 说明 |
|---|---|
| 用 `EdgeInsetsDirectional` | 不用 `EdgeInsets.fromLTRB`，用 `EdgeInsetsDirectional.only(start: 16, end: 16)` |
| 用 `start/end` 对齐 | `AlignmentDirectional.centerStart`，不用 `Alignment.centerLeft` |
| 用 `MarginDirectional` / `PositionedDirectional` | 不用 `Positioned(left: 0)` |
| 图标方向 | 含方向的图标（返回箭头、列表箭头）用 `matchTextDirection: true` |
| 行文本对齐 | `textAlign: TextAlign.start`，不用 `TextAlign.left` |
| 验证 | DevTools 切到 RTL，目测整页无错位（即使当前没阿语，每发一个大版本也跑一次） |

> 不强制现在跑 RTL 预览，但禁止任何会破坏 RTL 的硬编码 left/right。代码评审要扫一遍。

## 十一、禁忌（PR 直接打回）

| ❌ 禁止 | ✅ 应该 |
|---|---|
| `Text('登录')` 硬编码中文 | `Text(l.loginTitle)` |
| `Text('Sign in')` 硬编码英文 | `Text(l.loginTitle)` |
| arb 里写 HTML（`<b>xxx</b>`） | 富文本用 `RichText` + 不同 `TextSpan` 组合 |
| arb 里写 Markdown | UI 层用 `MarkdownBody`，arb 只放纯文本 |
| 占位符用 `{0}`、`{1}` | 用语义名 `{userName}` |
| 不声明 placeholder 类型 | 在 `@key.placeholders` 写明 `type` |
| 复数靠字符串拼接（`x record(s)`） | 用 ICU `{count, plural, ...}` |
| Service / Repository 拿 context 调 i18n | 业务层抛枚举，UI 层映射 |
| arb 文件 key 不对齐（某语言有别的语言没有） | zh/en/ko 三个 arb 的 key 必须完全一致 |
| 同一文案在两个 key 里重复 | 抽到 `common*` 复用 |
| 语言列表项本身做翻译 | 语言名用母语写死 |

## 十二、对照清单（每次提交前自检）

- [ ] 所有用户可见的中文/英文字符串都改成了 `AppLocalizations.of(context).xxx`
- [ ] `pubspec.yaml` 的 `flutter.generate: true` 仍开启
- [ ] 新增的 key 走 lowerCamelCase，并带模块前缀
- [ ] 新增的 key 在 `app_zh.arb`、`app_en.arb`、`app_ko.arb` 三个文件里都补齐
- [ ] 用到占位符的 key 在 `@key.placeholders` 里声明了 `type`
- [ ] 带数量的文案用了 ICU `{count, plural, ...}`，没有 `record(s)` 拼接
- [ ] 日期、数字、金额走 `intl` 的 `NumberFormat` / `DateFormat`，没手拼
- [ ] 业务层没拿 `BuildContext` 调 i18n（错误用枚举返回）
- [ ] 布局用了 `EdgeInsetsDirectional` / `start` / `end`，没硬编码 `left` / `right`
- [ ] 没有把品牌名 `Uten`、技术术语、HTML、Markdown 写进 arb
- [ ] 切换语言后整树能即时更新（手测过一次）
- [ ] 重启 App 后语言偏好被保留（手测过一次）
