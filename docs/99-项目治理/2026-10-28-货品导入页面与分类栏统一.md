# 货品导入页面与分类栏统一

## 本次范围与公共入口

用户反馈确认导入货品页的返回键、搜索框和分类树贴着左侧边缘，要求与货品资料页统一。本次按 `frontend-design` 复用现有 Uten 主题和组件，检查独立导入路由的整页边距，并统一导入分类栏。

| 已有入口 | 本次比较结果 | 接入与保留差异 |
|---|---|---|
| `UtenContentContainer.wide` | 公共水平边距按可用宽度取 16/24dp，整体字号放大时反向换算，嵌套不重复叠加 | 三个独立导入页面统一在整个 Scaffold 外使用；外层主题底色覆盖留白，避免独立路由露出黑边 |
| `CategoryPageShell._buildTree` | 货品资料分类栏使用公共树的紧凑层级配色、选中色块、连接线和点行展开 | 导入预览复用相同公共树及视觉参数，不接入全库搜索、分类增改删和业务 Provider |
| `UtenHierarchySearchHeader` / `UtenSearchBar` | 统一搜索框高度、图标、边框与顶部 12 / 底部 8 间距 | 仅搜索本次导入文件的分类，输入监听仍由公共树负责 |
| `UtenHierarchyRowSkin` | 深色根行及普通子行的前景色由公共树提供 | 导入分类数量从公共行皮肤取色，根行数量保持白色 |

## 清理与保留规则

- 删除导入预览页单独拼装的分类标题和 Material `ListTile`；“全部货品”改用公共按钮，并通过公共目录选择回调在窄窗返回表格。
- 删除复核、成本导入页正文中的重复水平容器，只保留适用的竖向间距。
- 导入分类仍保持路径 JSON 身份、原始顺序、所有祖先汇总数量及完整数据，不提升唯一根、不合并同名层级。
- 导入预览默认展开仍为 100 层，使自动选中的深层路径可见；普通货品资料的初始收起规则保持自己的业务配置。
- 分类搜索、展开和筛选不清除表格勾选或修正草稿；预览、重新检测、原值/导入值、混合模式替换及未知提交规则均复用现有实现。
