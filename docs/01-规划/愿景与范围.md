# 愿景与范围

> 本档定义 Uten IMP 要做成什么样、不做什么、给谁用、解决什么问题。
>
> **2026-08-09 部署范围**：平台默认供公司局域网员工使用；只有被管理员显式授予
> `remote_access` 的员工才能经云端入口居家/出差办公。在公司网络内仍优先使用本地入口。后端采用
> 公司本地唯一写主库、阿里云异步物理热备；断网时本地继续工作、云端业务请求 503，不建设通用
> 离线双写或自动冲突合并。当前仍为 **NO-GO**，详见
> [新库上线与首装操作指引](../99-项目治理/2026-09-01-新库上线与首装操作指引.md)。

## 一、产品愿景

**让优腾的每一台设备、每一个员工、每一笔数据，都在一个平台上协同运转。**

- 一线员工：手机上点开就看工资条、提报销、收通知
- 人事部：员工档案、部门、入离职一目了然
- 财务部：报销审批、工资条审核、钱流报表与资产/待摊子账数字化
- 实验室 / 车间：检测数据、空调、流水线、产量、库存统一管控
- 管理层：经营数据一目了然，辅助决策

一套 Flutter 代码覆盖手机 / 平板 / 桌面 / Web，按后端合成权限点与数据范围展示；角色体系已下线。

---

## 二、目标用户

| 角色 | 主要场景 | 设备偏好 |
|---|---|---|
| 普通员工（含流水线工人） | 在公司网内看工资条、提报销、收通知、提建议；获授权者可远程使用 | 手机为主 |
| 人事部 | 员工档案、部门管理、入离职、通知发布 | 桌面为主 |
| 财务部 | 报销审批、工资条审核、钱流/总账报表、资产与待摊台账及月结 | 桌面为主 |
| 实验室 / 车间 | 检测数据上传、设备控制、生产进度 | 平板 + 手机 |
| 管理层 | Dashboard、决策辅助 | 桌面 + 平板 |
| 系统管理员 | 用户权限、系统配置 | 桌面 |

**规模**：200–1000 人制造业。

## 四、不做的事（明确边界）

| 不做 | 原因 |
|---|---|
| 不在平台上直接发工资（只发工资条） | 财务合规，发薪走银行 |
| 不做实时视频监控 | 不在平台定位内 |
| 不做考勤打卡 | 用专门考勤机更合适（将来可读数据） |
| 不把已有页面和源码宣传成“完整通用 ERP 已上线” | 平台已覆盖销售、采购、委外、生产、库存和财务等内部链路，但各业务域仍按迁移、对账、岗位/实物 UAT 和生产门禁逐项验收 |
| 不把“资产安全骨架”宣传成完整资产 ERP 已上线 | 初始确认/处置/终止事件反冲、完整清算、TAX、历史期初、来源/附件等仍是生产阻断 |
| 不做对外客户系统 | 这是内部平台 |
| 不做数据库双主、客户端业务离线队列或通用自动冲突合并 | 财务、库存、审批等跨域写入不能用时间戳盲合并；当前以单主和云端断链 503 保证一致性。如以后确需分区双写，必须逐业务域另立 ADR、幂等键、冲突规则与补偿流程 |
| 不让员工手填任意服务器地址 | 防止 token、refresh token 或登录密码被发送到恶意主机；Release 端点由构建和同源入口固化 |

## 五、非功能性要求

| 维度 | 要求 |
|---|---|
| 多端 | 手机 / 平板 / 桌面 / Web 一套代码 |
| 响应式 | compact / medium / expanded 三档布局 |
| 性能自适应 | lite / standard / rich 三档自动降级，照顾低端机 |
| 主题 | 浅色 + 深色 |
| 国际化 | 中文 + English |
| 字号可调 | 小 / 标准 / 大 / 超大 / 超超大 五档 |
| 安全 | 默认拒绝、后端权威、最小权限、审计可追溯；前端显隐不替代服务端鉴权 |
| 可用性与一致性 | 公司本地唯一写主库；云端异步热备且分区时 fail-closed 503；量化 RPO/RTO、PITR 和灾备演练后才可生产 |
| 老系统融合 | 按 [ADR-017](../99-决策记录-ADR/ADR-017-模块化单体与异步旁路.md) 模块化迁移、对账、统一切换写入口（单向影子双写已随 ADR-005 退役）；不改变本平台数据库单主约束 |

## 六、成功标准

- 员工一天内能用手机完成"看工资条 + 提报销 + 收通知"
- 人事能在桌面端 5 分钟内完成一次新员工建档
- 管理层打开 Dashboard 10 秒内看到全公司关键指标
- 旧设备（2GB 内存 Android）能流畅使用核心功能
- 三端（手机 / 桌面 / Web）体验一致且都"好看"
- 未授权员工在家庭/公网入口不能登录或刷新；授权、撤权和旧 token 失效有可审计证据
- 公司/云端链路中断时不产生双边业务写；恢复后复制追平、备份恢复与业务对账满足已签字 RPO/RTO
