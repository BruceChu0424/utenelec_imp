# 报销业务设置页

路由：`/expense/settings`。入口：钱流/财务管理中的“报销业务设置”。实现：`lib/features/expense/pages/expense_settings_page.dart`。
关联：[员工报销 SOP](../07-业务链路/员工报销全链路-SOP.md)、[V617](../数据迁移/207-V617报销凭证核验与财务设置.md)。

## 定位与字段

财务维护员工申请与公司内部打印所需的最小信息，不配置多级审批、税率或国家机关差旅限额。

| 字段 | 用途与约束 |
|---|---|
| 公司名称 | 报销抬头与打印展示，保存必填，最多200字 |
| 纳税人识别号 | 供员工对照票面，允许为空；提供时为15、18或20位大写字母数字 |
| 提交说明 | 公司凭证要求和办理说明，最多2000字；不得声称无票说明自动可扣除 |
| 提交时必须登记票据 | 默认关闭；启用时至少登记一张票据，`OTHER` 合法凭证也计入 |

关闭票据登记要求不免除附件与报销依据要求。系统仍在提交时验证明细日期/用途与可用凭证附件，
审批时验证已登记票据的人工核验。公司名称和税号当前为实时配置，未冻结到历史报销单。

## 权限与保存

页面和 `PUT /api/expense-claims/settings` 使用独立 `expense:settings`。权限须明确授予，
不能因已有审核/付款权默认允许改公司制度。报销申请、审核、付款人员可以读取设置作为提示。
保存携带 `version`，服务端按版本更新并留下审计；旧版本冲突时刷新核对，不覆盖他人设置。

使用 `UtenAppBar`、统一容器和字段样式，网络按钮进入忙态，结果以顶部通知反馈。
OCR 地址、模型版本、存储、密钥和数据库配置均由运维维护，不从此页面编辑。
