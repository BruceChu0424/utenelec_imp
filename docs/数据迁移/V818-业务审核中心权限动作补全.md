# V818 业务审核中心权限动作补全

`finance.audit-center` 页面内嵌多个审核队列，队列自身不展示顶栏。V812 只挂查看码，使该页面及钱流父页的权限抽屉无法授予实际审核能力。

本迁移把 `finance.order-approval`、`finance.sales-order-confirmation`、`finance.sales-shipment-audit` 三个现行权限面的完整集合补入审核中心，并加入 IQC 贷项的全量查看、金额查看、确认、零金额结案和反向权限。实物退回不属于财务办理范围，不加入。单层 `finance.hub → finance.audit-center` 模型不变；各独立队列入口继续使用原权限面。

只写 `permission_surface_permissions`，不新增权限码、不修改授权策略、不写部门默认授权或个人覆盖。审核仍须通过对应接口的财务资格、个人点名、认领、版本和对象范围校验。已有 V812 迁移保持原字节，通过前向迁移补全。

回归：`PermissionSurfaceCatalogPostgresTest.auditCenterAndFinanceHubIncludeEveryEmbeddedQueueAction` 在全量迁移后的独立 PostgreSQL 中核对父页及中心完整覆盖三队列，并排除仓库实物动作和系统授权管理码。本说明不代表业务服务器已经安装。
