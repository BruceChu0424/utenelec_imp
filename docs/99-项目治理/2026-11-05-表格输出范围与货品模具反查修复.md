## 公共入口与完整调用清单

逐入口清单及保留差异见 [表格输出范围覆盖清单](表格输出范围-20261105/coverage.json)。它包含公共按钮调用、专用纸面输出及原件/附件的范围分类；搜索命中仅用于定位，适用性按实际数据集与提交语义审查。

- `UtenExportButton`：同一文件设置弹窗完成范围选择；冻结身份、请求代次、权限、文件选项及服务端数据集。主档走私有 `selectedIds`，报表走授权源行选择，旧接口的大集合筛选走私有正文。
- 选中输出在动作确认后核对 `capabilities.selectionVersion`。缺少新范围合同的旧服务端拒绝本次选中输出，保留全部输出兼容；不会把未知的新字段忽略后当作全量成功。一个确认动作的复制、能力核对和下载共用等待层，交互式任务窗口及再认证时让位。
- `UtenTableOutputSelection`、表格投影注册：区分业务勾选与纯输出选择；分片生成原始 selector，使用精确十进制文本，统一缺省 null。BOM 的一个业务关系可对应多次出现，输出按 occurrence 逐项保全。
- `showUtenPrintPreview`、完整分页加载器：完整取当前范围，再按真实身份/原始事实选择；不再静默使用前 2000 行。账号、权限、查询退役或取消后不发布迟到纸面。
- `MasterExportSelection`：在拥有者查询的权限及筛选 predicate 内与 UUID 集合求交，逐项完整核对；大集合分组避免参数 padding 超界。`ExportRowSelection`：只筛选服务端已授权事实，不使用客户端内容生成输出单元格。
- 六域明细从实际物理行或既有源事件粒度提供隐藏 `__lineId`。同一单据内可见内容完全相同的两行仍可分别选择；原 `__srcId` 导航保留。汇总不加入明细 ID 拆组，隐藏身份不进入可见列或 Excel 表头。实际服务与页面验证见 [真实行身份增量](表格输出范围-20261105/report-line-identity-validation.json)。
- `ExportDocumentProjectionService`：多分表选中输出只保留目标业务分表并核对完整性；XLSX/PDF 同一事实合同。成本材料沿用原路径，费用使用共享稳定身份，不改金额、币种、精度或来源。

独立的导出范围前置 UI 已从普通导出入口移除；预览中的下载沿用已冻结范围。保留业务特有的格式、section、来源及审核合同，不合并为第二套计算。

## 业务差异与边界

- 全部始终指当前授权查询的完整结果，保留原有禁用/占位、库存归属、单据阶段及权限资格；不越过原查询扩大范围。选中记录已删除、失去权限、脱离筛选或身份不唯一时，整次拒绝，不静默少导出。
- 已确认财务原件、报价模板、报销/申请原件、批工单确认包、组织图和附件按各自完整源文档输出。原件不能用部分明细配完整合计；行级选择使用对应明细报表。
- 物料反查分类作用于成品/半成品的 BOM 与历史关系；实际追溯保留自身库存及执行证据口径。历史关系可以输出；含历史关系的替换整次拒绝，不偷偷只替换当前 BOM 子集。
- 主档任务、报表任务及原历史文件各自冻结。未知提交只核对原编号；新选中的范围不能自动替换旧任务，也不能把旧全量文件当成本次选中结果。
- 服务端输出与客户端文件预算仍有明确上限；完整性检查不会用截断换响应性。BOM 保留既有 11 层/2000 行文件边界，循环、不可见或未编号组件整次拒绝。

货品导入/模具、物料反查、货架、车间、审计、财务及工作台尚未迁入原生的入口，继续在 `clients/windows_legacy/progress/work-items.json` 与分项证据登记未迁移，未新开占位写入口。最终整合重新生成 canonical 指纹，不修改原状态、DoD 或验收分母。
